대시보드는 **입력층 · 은닉층 · 출력층 · 학습방법 · 평가방법 · 개념 · 모델** 로 나뉩니다.
원하는 항목을 아래 작업대로 **드래그**해서 놓으세요. (칩을 클릭하면 그 글로 이동)

- **조합** — 층을 순서대로 벨트에 올려 **⚙ 제작** → 모델을 인식합니다. (예: 입력 → 합성곱 → 풀링 → 완전연결 → 출력 = CNN)
- **합성** — 상자에 개념을 담고 **✦ 합성** → 상위 개념을 만듭니다. (예: 물리 + 화학 = 물리화학 · LLM + CNN + 로보틱스 = VLA · 정밀도 + 재현율 = F1)

결과 이름을 누르면 그 글로 이동합니다.
