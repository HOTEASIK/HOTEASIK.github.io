대시보드는 **입력층 · 은닉층 · 출력층 · 학습방법 · 평가방법 · 개념 · 모델** 로 나뉘어
위에서 아래로 나열됩니다. 위쪽 **조합 작업대 / 합성 작업대** 버튼을 누르면
화면 하단에 작업대가 고정으로 떠서, 대시보드를 스크롤하며 부품을 **드래그**할 수 있습니다.

- **조합 (적층형)** — ① 층을 순서대로 벨트에, ② 학습 방법(옵티마이저·손실함수 등)을 옆 칸에 올려 **⚙ 제작** → 모델을 인식합니다. (예: 입력 → 합성곱 → 풀링 → 완전연결 → 출력 = CNN)
- **조합 (순환형)** — 순환 셀(RNN·LSTM)을 올리고 **↩ 되먹임**을 켜서 끝을 처음으로 이어 주면 순환 신경망으로 인식합니다. (예: 입력 → 순환 → 완전연결 + 되먹임 = RNN)
- **합성** — 상자에 개념을 담고 **✦ 합성** → 상위 개념을 만듭니다. (예: 물리 + 화학 = 물리화학 · LLM + CNN + 로보틱스 = VLA · 정밀도 + 재현율 = F1)

칩을 클릭하면 그 글로, 결과 이름을 누르면 완성된 모델·개념 글로 이동합니다.
