# PyQt5 (Python Qt5 Bindings)

## 1. 정의 (Definition)
**PyQt5**는 Digia(현 Qt Company)의 C++ 크로스 플랫폼 GUI 프레임워크인 **Qt v5**를 파이썬(Python) 언어에서 사용할 수 있도록 래핑한 라이브러리입니다. Riverbank Computing에서 개발 및 유지보수하며, 오랜 기간 동안 파이썬 데스크톱 애플리케이션 개발의 표준으로 사용되어 왔습니다.

---

## 2. 핵심 요약 (Core Concepts)
* **GUI & Event-Driven Architecture:** 이벤트 기반 프로그래밍 프레임워크로, 사용자 입력 및 시스템 이벤트에 반응하는 가품질 GUI 애플리케이션을 제작할 수 있습니다.
* **Signal & Slot 메커니즘:** 객체 간 느슨한 결합(Loose Coupling)을 제공하는 PyQt의 핵심 통신 메커니즘입니다.
* **Qt Designer 지원:** WYSIWYG 형태의 인터페이스 디자이너를 통해 `.ui` 파일 형태로 레이아웃을 시각적으로 설계하고 파이썬 코드로 변환할 수 있습니다.

---

## 3. 주요 특징 (Features)
1. **풍부한 위젯 세트:** 버튼, 텍스트 상자, 테이블, 트리 View부터 2D Graphic Scene, WebEngine 등 다양한 컨트롤 지원
2. **크로스 플랫폼:** Windows, macOS, Linux에서 별도의 코드 수정 없이 동일한 인터페이스 동작
3. **안정성 및 생태계:** 오랜 기간 축적된 자료와 커뮤니티 라이브러리 ecosystem 형성
4. **enum 및 클래스 구조:** Qt5 네임스페이스 규칙에 따라 `QCoreApplication`, `QGuiApplication`, `QApplication` 등의 모듈 분리

---

## 4. 주요 기본 코드 (Basic Example)

다음은 간단한 창을 띄우고 버튼 클릭 이벤트를 처리하는 PyQt5 기본 코드입니다.

```python
import sys
from PyQt5.QtWidgets import QApplication, QWidget, QPushButton, QVBoxLayout, QLabel
from PyQt5.QtCore import Qt

class PyQt5App(QWidget):
    def __init__(self):
        super().__init__()
        self.initUI()

    def initUI(self):
        self.setWindowTitle('PyQt5 Basic Example')
        self.setGeometry(300, 300, 400, 200)

        # 레이아웃 배치
        layout = QVBoxLayout()

        # 라벨 생성
        self.label = QLabel('버튼을 눌러보세요.', self)
        self.label.setAlignment(Qt.AlignCenter)
        layout.addWidget(self.label)

        # 버튼 생성 및 Signal-Slot 연결
        self.btn = QPushButton('클릭', self)
        self.btn.clicked.connect(self.on_click)
        layout.addWidget(self.btn)

        self.setLayout(layout)

    def on_click(self):
        self.label.setText('PyQt5 버튼이 클릭되었습니다!')

if __name__ == '__main__':
    app = QApplication(sys.argv)
    ex = PyQt5App()
    ex.show()
    sys.exit(app.exec_())
```
