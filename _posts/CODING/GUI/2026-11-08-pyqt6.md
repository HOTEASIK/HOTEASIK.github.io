# PyQt6 (Python Qt6 Bindings)

## 1. 정의 (Definition)
**PyQt6**는 C++ 크로스 플랫폼 프레임워크의 최신 주요 버전인 **Qt v6**를 파이썬 언어로 바인딩한 최신 프레임워크입니다. PyQt5의 후속 버전으로, 차세대 그래픽 파이프라인 지원과 고해상도 모니터(HiDPI) 처리 개선, 현대적인 파이썬 타입 규격을 엄격히 적용한 것이 특징입니다.

---

## 2. 핵심 요약 (Core Concepts)
* **Qt 6 기반 차세대 프레임워크:** Vulkan, Metal, Direct3D 12 등 모던 3D API를 지원하는 RHI(Rendering Hardware Interface) 도합.
* **Strict Enum/Flag 규칙:** PyQt5에 비해 열거형(Enum) 선언 시 모듈 경로를 정확히 명시해야 하는 명확한 타입 정책 적용.
* **호환성 변환:** `exec_()` 대신 `exec()` 메서드를 사용하는 등 파이썬 3 표준 키워드 스타일과 완벽한 통합.

---

## 3. 주요 특징 (Features)
1. **엄격해진 Enum 사용 방식:**
   * PyQt5: `Qt.AlignCenter`
   * PyQt6: `Qt.AlignmentFlag.AlignCenter`와 같이 하위 플래그 명시 필수
2. **파이썬 3 표준 메서드 이름:**
   * `QApplication.exec_()` 대신 `QApplication.exec()` 사용
3. **향상된 HiDPI 및 멀티 모니터 레이아웃:** 스케일링 설정 자동 도입으로 고해상도 디스플레이 처리 향상
4. **성능 개선:** 그래픽 엔진 가속화 및 최신 그래픽 카드 드라이버 호환성 강화

---

## 4. 주요 기본 코드 (Basic Example)

다음은 PyQt6를 사용한 기본 위젯 창 및 이벤트 처리 예제입니다.

```python
import sys
from PyQt6.QtWidgets import QApplication, QWidget, QPushButton, QVBoxLayout, QLabel
from PyQt6.QtCore import Qt

class PyQt6App(QWidget):
    def __init__(self):
        super().__init__()
        self.initUI()

    def initUI(self):
        self.setWindowTitle('PyQt6 Basic Example')
        self.setGeometry(300, 300, 400, 200)

        # 레이아웃 배치
        layout = QVBoxLayout()

        # 라벨 생성 (PyQt6의 AlignmentFlag 적용)
        self.label = QLabel('버튼을 눌러보세요.', self)
        self.label.setAlignment(Qt.AlignmentFlag.AlignCenter)
        layout.addWidget(self.label)

        # 버튼 생성 및 Signal-Slot 연결
        self.btn = QPushButton('클릭', self)
        self.btn.clicked.connect(self.on_click)
        layout.addWidget(self.btn)

        self.setLayout(layout)

    def on_click(self):
        self.label.setText('PyQt6 버튼이 클릭되었습니다!')

if __name__ == '__main__':
    app = QApplication(sys.argv)
    ex = PyQt6App()
    ex.show()
    # PyQt6에서는 exec_() 대신 exec()를 사용합니다.
    sys.exit(app.exec())
```
