# 정의
오픈 소스 **관계형 데이터베이스 관리 시스템(RDBMS)**. 다양한 플랫폼에서 쓸 수 있고, 빠른 성능·확장성·높은 안정성이 특징이다.

- 관계형(RDBMS): 테이블 기반 — MySQL, Oracle, PostgreSQL, SQLite
- 비관계형(NoSQL): 문서·키-값·컬럼 기반 — MongoDB, Redis

# 설치 (Windows, 강의 기준)
1. mysql.com → DOWNLOADS → **MySQL Community Server** → `mysql-8.4.x-winx64.msi`
2. **MySQL Configurator** 실행
   - 데이터 경로: `C:\ProgramData\MySQL\MySQL Server 8.4\`
   - Root Password 설정
   - Windows Service Name: `MySQL84`
3. **Command Line Client** 실행 → 비밀번호 입력

```sql
SELECT version();   -- 버전이 출력되면 설치 완료
```

# 작성 규칙
- **예약어는 대문자** (`SELECT`, `FROM`, `WHERE` …), 테이블·컬럼명은 소문자로 쓰면 읽기 쉽다
- 문장 끝은 `;`
- 테이블명·컬럼명으로 예약어는 쓸 수 없다 → [[테이블(Table)]]
