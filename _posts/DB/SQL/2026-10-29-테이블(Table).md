# 정의
데이터를 저장하는 가장 기본적인 데이터베이스 객체. **행(Row)과 열(Column)** 으로 구성된 2차원 형태이며, SQL의 실행 대상이다.

# 생성
```sql
CREATE TABLE 테이블명 (
    컬럼명1  데이터타입  [제약조건],
    컬럼명2  데이터타입  [제약조건],
    ...
);
DROP TABLE 테이블명;
```

## 생성 규칙
- 테이블명·컬럼명 최대 길이 **64자**
- **예약어 사용 불가**
- 문자, 숫자, `_`, `$` 사용 가능 / 첫 글자는 문자 또는 `_`
- 한 테이블의 컬럼은 최대 **4096개** (테이블·컬럼 크기에 따라 더 적을 수 있음)

# 옵션
## 데이터 타입
| 구분 | 타입 | 설명 · 예 |
|---|---|---|
| 문자 | `CHAR(n)` | 고정 길이 문자열 — 국가 코드 |
| | `VARCHAR(n)` | 가변 길이 문자열 — 이름, 주소 |
| | `TEXT` | 대량 문자열 — 설명, 본문 |
| 숫자 | `INT` | 정수 — 나이, 개수 |
| | `DECIMAL(m,d)` | 정밀 소수 — m: 전체 자리수, d: 소수점 이하 |
| 날짜 | `DATE` | `YYYY-MM-DD` |
| | `DATETIME` | `YYYY-MM-DD HH:MM:SS` |

## NULL과 제약 조건
- **NULL**: 데이터가 없음. 컬럼 기본값은 NULL 허용
- `NOT NULL` · `UNIQUE` · `PRIMARY KEY` · `FOREIGN KEY` · `CHECK`(8.0 이상) · `DEFAULT` · `AUTO_INCREMENT` → [[제약조건(Constraints)]]

# 예제
```sql
CREATE TABLE employees (
    employee_id     INT PRIMARY KEY AUTO_INCREMENT,
    name            VARCHAR(50) NOT NULL,
    department_name VARCHAR(50),
    salary          DECIMAL(10,2) CHECK (salary > 0),
    hiredate        DATE DEFAULT (CURRENT_DATE)
);
SHOW TABLES;            -- 테이블 목록
DESCRIBE employees;     -- 구조 확인
```
