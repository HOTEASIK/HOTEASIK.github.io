# 정의
**DML (Data Manipulation Language, 데이터 조작 언어)**: 테이블 안의 **데이터**를 조회·삽입·수정·삭제한다. 구조를 바꾸는 [[DDL]]과 구분된다.

# 명령어
- **SELECT** : 테이블이나 뷰에 있는 데이터를 조회
- **INSERT** : 데이터를 신규로 생성
- **UPDATE** : 기 생성된 데이터를 수정
- **DELETE** : 데이터 삭제

## SELECT
```sql
SELECT 컬럼명 FROM 테이블명 [WHERE 조건] [ORDER BY 컬럼명];

SELECT * FROM employees;                              -- 전체
SELECT name, salary FROM employees WHERE salary > 6000;
SELECT * FROM employees ORDER BY salary DESC;         -- 내림차순
```
- `*` = 모든 컬럼, 여러 조건은 `AND` / `OR`로 연결

## INSERT
```sql
INSERT INTO 테이블명 (컬럼1, 컬럼2) VALUES (값1, 값2);   -- 컬럼 명시 (권장, DEFAULT 활용 가능)
INSERT INTO 테이블명 VALUES (값1, 값2, ...);             -- 모든 컬럼에 순서대로
INSERT INTO new_employees SELECT * FROM employees WHERE salary < 5000;  -- 조회 결과로 삽입
```
- 값의 **순서와 타입**이 컬럼 순서·타입과 일치해야 한다

## UPDATE
```sql
UPDATE 테이블명 SET 컬럼1 = 값1, 컬럼2 = 값2 [WHERE 조건];
```

## DELETE
```sql
DELETE FROM 테이블명 [WHERE 조건];
DELETE FROM employees WHERE employee_id = 4;
```

# 주의
- UPDATE·DELETE에서 **WHERE를 빼면 테이블의 모든 행**이 바뀌거나 지워진다
- 실수했다면 [[TCL]]의 ROLLBACK으로 되돌린다 (AUTOCOMMIT이 꺼져 있을 때)
