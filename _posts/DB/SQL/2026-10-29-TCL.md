# 정의
**TCL (Transaction Control Language, 트랜잭션 제어 언어)**: [[DML]]로 바꾼 내용을 **영구 저장할지, 되돌릴지** 정한다. [[DCL]]로 분류하는 경우도 있다.

# 명령어
- **COMMIT** : 변경된 데이터를 최종 적용
- **ROLLBACK** : 변경된 데이터를 적용하지 않고 이전 상태로 되돌림

# AUTOCOMMIT
MySQL은 기본이 **자동 커밋**이라, 문장 하나가 실행될 때마다 바로 COMMIT 된다. ROLLBACK을 쓰려면 먼저 꺼야 한다.

```sql
SELECT @@AUTOCOMMIT;   -- 1이면 켜짐
SET AUTOCOMMIT = 0;    -- 해제 (세션 단위, 일시적)
SET AUTOCOMMIT = 1;    -- 다시 설정 (기본)
```

완전히 끄려면 `C:\ProgramData\MySQL\MySQL Server X.X\my.ini`의 `[mysqld]`에 `autocommit = 0`을 넣고 MySQL 서비스를 재시작한다.

# 예제
```sql
INSERT INTO employees VALUES (3, '조세호', '개발팀', 6000, '2025-02-07');
COMMIT;                                     -- 여기까지 확정

DELETE FROM employees WHERE employee_id = 3;
ROLLBACK;                                   -- 마지막 COMMIT 시점으로 복구
SELECT * FROM employees;                    -- 3번 사원이 다시 보인다
```
