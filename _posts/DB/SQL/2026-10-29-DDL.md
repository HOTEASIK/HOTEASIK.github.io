# 정의
**DDL (Data Definition Language, 데이터 정의 언어)**: 데이터베이스의 **구조**(데이터베이스·테이블·뷰·인덱스 같은 객체)를 만들고 바꾸고 지운다.

# 명령어
- **CREATE** : 테이블이나 인덱스, 뷰 등 데이터베이스 객체를 생성
- **ALTER** : 기 생성된 데이터베이스 객체를 수정
- **DROP** : 생성된 데이터베이스 객체를 영구히 삭제

# 예제
```sql
CREATE DATABASE ExampleDB;
SHOW DATABASES;
USE ExampleDB;

CREATE TABLE employees (
    employee_id INT PRIMARY KEY AUTO_INCREMENT,
    name        VARCHAR(50) NOT NULL
);
ALTER TABLE employees ADD COLUMN salary DECIMAL(10,2);

CREATE VIEW developer_view AS
SELECT name, salary FROM employees WHERE department_name = '개발팀';

DROP VIEW developer_view;
DROP TABLE employees;
DROP DATABASE ExampleDB;
```
