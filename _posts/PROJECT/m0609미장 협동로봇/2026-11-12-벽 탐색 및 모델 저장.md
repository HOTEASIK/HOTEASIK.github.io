# 개요
로봇이 벽을 9곳 찌르고(프로빙), 가로 2줄·세로 3줄로 미끄러지며(스캔) 점을 모은 뒤 벽 평면과 휘어짐을 모델링한다. 결과는 파일로 저장하고 RViz에 띄운다.

# 0. 빌드
코드를 고칠 때마다 다시 빌드한다.
```bash
cd ~/ws_cobot_pjt/ws_dsr
colcon build --packages-select rokey1
source install/setup.bash
```
새 터미널마다 `source ~/ws_cobot_pjt/ws_dsr/install/setup.bash`

# 1. 가상 환경 (에뮬레이터)
에뮬레이터 이미지: `doosanrobot/dsr_emulator:3.0.1`

터미널 1: bringup (RViz 같이 뜸)
```bash
ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=virtual host:=127.0.0.1 port:=12345 model:=m0609
```
- `mode:=virtual`이면 에뮬레이터 컨테이너가 자동으로 뜬다.
- `model:=m0609` 필수. 빼면 기본값 m1013으로 뜨는데 코드는 m0609 기준이다.
- RViz에 로봇이 보이고 로그가 잠잠해질 때까지 10~20초 기다린다.

RViz 설정 (탐색 전에)
1. Add → By display type → rviz_default_plugins → MarkerArray
2. MarkerArray의 Topic에 `/dsr01/wall_markers` 입력
3. Durability Policy를 Transient Local로 (탐색이 끝난 뒤 켜도 보이게)
4. Global Options → Fixed Frame = `base_link`

터미널 2: 탐색
```bash
ros2 run rokey1 wall_navigation --ros-args -p mode:=virtual
```
- `mode` 기본값이 virtual이라 `--ros-args` 부분은 빼도 된다.
- 프로빙 9점 → 가로 스캔 2줄 → 세로 스캔 3줄 순서. 점이 RViz에 실시간으로 찍힌다.
- 끝나면 평면·법선 화살표·곡면·텍스트가 표시되고 matplotlib 창도 뜬다. 창을 닫아야 프로그램이 끝나고, 닫아도 RViz 표시는 남는다.
- 가상 벽은 X=550mm (로봇 앞 약 0.55m)

# 2. 실제 로봇
터미널 1
```bash
ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=real host:=192.168.1.100 port:=12345 model:=m0609
```
실행 전 체크 (`wall_navigation.py` 맨 위 설정값)
- `WALL_GUESS_X`: 실제 벽보다 조금 앞으로. 줄자로 재서 맞춘다.
- `GRID_Y`, `GRID_Z`, `SCAN_Y_RANGE`, `SCAN_COLS_Y`, `SCAN_Z_RANGE`: 벽 안쪽이면서 작업 영역 안
- `TOOL_NAME`, `TCP_NAME`: 티칭 펜던트에 등록된 이름과 같게
- 처음엔 `PROBE_VEL`, `FORCE_THRESHOLD`를 작게

터미널 2
```bash
ros2 run rokey1 wall_navigation --ros-args -p mode:=real
```
- `[REAL] ... y 입력:`이 나오면 주변 확인 후 y
- Ctrl+C → 정지 → 힘 제어 해제 → 데이터 저장 → 홈 복귀. 비상 시엔 펜던트 비상정지

# 3. 저장된 모델 다시 보기
데이터: `~/wall_scan_data/scan_날짜_시간.json`, 결과: `_model.json`, `_model.png`
```bash
ros2 run rokey1 wall_modeling                      # 최근 데이터 → 그림 창
ros2 run rokey1 wall_modeling --rviz --no-show     # 최근 데이터 → RViz (Ctrl+C까지)
ros2 run rokey1 wall_modeling ~/wall_scan_data/scan_20261112_101010.json --rviz
```
`--rviz`와 그림 창을 같이 쓰면 창을 닫은 뒤부터 RViz로 보낸다.

## 옵션 (wall_navigation)

| 옵션 | 설명 |
|---|---|
| `-p show_plot:=false` | 그림 창 없이 PNG만 저장 |
| `-p rviz:=false` | RViz 표시 끄기 |
| `-p modeling:=false` | 탐색만, 모델링 생략 |

# 4. 세로 스캔 추가
- 기존 가로 스캔(높이 고정, Y 이동)에 세로 스캔(Y 고정, Z 이동)을 더해 가로 2줄 + 세로 3줄 격자로 벽을 덮는다.
  - `SCAN_COLS_Y = [-100, 0, 100]`, `SCAN_Z_RANGE = (300, 500)`
  - 세로 줄은 지그재그로 이동 거리 단축
- 가로/세로를 `sliding_scan(plane, 시작(y,z), 끝(y,z), kind)` 하나로 합침. 실제 로봇에선 X 방향을 힘 제어가 맡아 세로로 움직여도 벽 굴곡을 따라간다.
- 점 종류를 `scan_h`(가로), `scan_v`(세로)로 나눠 저장. 예전 데이터도 읽힌다.
- 가로·세로 줄이 만나는 교차점에서 두 측정의 X 차이를 로그로 출력 → 실제 로봇 측정 일관성 확인용

결과: 가로 스캔만 쓰면 위아래 휘어짐을 약 1/3로 작게 잡았다(v² −2.9e-5, 좌우 u² −9.3e-5). 세로 스캔을 더하면 v² −8.7e-5로 좌우와 비슷해졌다. 가상 모드는 노이즈가 없어 법선 오차는 두 경우 모두 0° → 기울기 정확도 차이는 실제 로봇에서 확인해야 한다.

# 5. RViz 표시 (`wall_rviz.py`)
토픽 `/dsr01/wall_markers` (MarkerArray). 탐색 중엔 점이 찍힐 때마다 갱신, 끝나면 최종 모델까지 표시.

| Namespace | 내용 |
|---|---|
| probe | 프로빙 접촉점 (빨강) |
| scan_h / scan_v | 가로 스캔 점 (파랑) / 세로 스캔 점 (주황) |
| plane / normal | 벽 평면 (반투명 초록) / 법선 화살표 |
| surface | 휘어짐 곡면. 파랑 = 들어간 곳, 빨강 = 튀어나온 곳 |
| outlier / info | 이상치 점 / 평면식·평탄도 텍스트 |

- `package.xml`에 `geometry_msgs`, `visualization_msgs` 의존성 추가
- `wall_modeling.py`의 `model_from_file()`에 `on_model` 콜백 → 그림 창보다 RViz로 먼저 보냄

# 안 될 때
- `서비스 대기 중: ...` 반복: bringup이 덜 떴거나 실패. 터미널 1 로그 확인
- `접촉 없음`: 가상 벽은 X=550mm. `WALL_GUESS_X`(550)나 `VIRTUAL_WALL['x0']`을 바꿨다면 두 값을 맞춘다.
- 이동 중 에러(관절 한계, 특이점): 탐색 영역이 작업 범위를 벗어남. `GRID_Y`, `GRID_Z`, `READY_J`를 줄인다.
- RViz에 아무것도 안 보임
  - Fixed Frame = `base_link`인지
  - 탐색이 끝난 뒤 RViz를 켰다면 Durability를 Transient Local로 하거나 `wall_modeling --rviz`로 다시 띄운다.
  - `ros2 topic echo /dsr01/wall_markers --once`로 토픽이 나오는지 확인
  - MarkerArray를 펼치면 Namespace별로 켜고 끌 수 있다.
