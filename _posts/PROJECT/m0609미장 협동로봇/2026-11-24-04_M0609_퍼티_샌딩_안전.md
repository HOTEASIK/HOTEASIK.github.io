# 퍼티 공정

```
/process/putty_pickup  (헤라 집기 1회)
   → 틈마다 [ /process/putty_scoop (뜨기) → /process/putty (도포) ]
   → /process/putty_return (헤라 반납 1회)
```

- 처음에는 "판에 퍼티 묻히기 → 바르기"였지만, 퍼티 팀이 실제 동작 순서를 바꾸면서 실행기도 맞춰 변경
- 힘제어 값(`putty_scrape`, `putty_scoop`)은 `robot.yaml`로 분리
- 두산 `DSR_ROBOT2` 대신 **`dsr_msgs2` 서비스를 직접 호출 + 타임아웃** → 취소·시간 초과·알람 확인 가능

# 샌딩 공정 (`sanding_job.py`)

1. **경로 계산 (로봇 안 움직임)**: 벽 법선으로 벽에 90°인 자세, TCP z ≥ 바닥 + 50 mm
2. 도구 집기 (이미 들고 있으면 생략)
3. 몸체 쪽 위에서 작업 자세로 바꾼 뒤 수직 하강
4. 벽 쪽으로 15 mm/s로 수평 이동 → 외력 5 N 이상이면 접촉 → `align_to_wall`로 자세 맞춤
5. 순응·힘제어 ON → 틈 끝까지 좌우 ±12.5 mm **지그재그**
6. 힘제어 OFF → 후퇴 → 상승 → 다음 틈이 있으면 들고 끝, 마지막이면 반납

## 도구 상태 관리

| 상태 | 의미 | 새 goal |
|---|---|---|
| `empty` | 도구 없음 | 집고 시작 |
| `held` | 들고 있음 (같은 run) | 바로 시작 |
| `unknown` | 앞 작업이 도중에 멈춰 위치 모름 | **거부** (`E_GRIP`) |

## 예외 → 오류 코드

| 예외 | 코드 | 로봇 상태 |
|---|---|---|
| `PlanError` | `E_SINGULAR` | 안 움직임, 도구 상태 그대로 |
| `Canceled` | `CANCELED` | 그 자리 정지 |
| `Abort` | `E_FORCE` | 샌딩 중 이상 → 후퇴함 |
| 기타 | `E_GRIP` / `E_MOTION` | 그 자리 정지 |

# 힘제어 품질 기록

`force_stats.summarize(fz, target, tol)` → 목표 힘 ±tol 안에 있던 **비율(contact_ratio)** 과 통계(JSON)를 Feedback에 담아 DB에 남깁니다.
"바르긴 했는데 제대로 눌렀나?"를 나중에 숫자로 확인할 수 있습니다.

# 안전 장치 모음

| 위치 | 장치 |
|---|---|
| 공통 | 이동 후 **실제 위치로 도착 확인** — 컨트롤러가 실패해도 "성공"으로 응답하는 경우가 있었음 |
| 공통 | 움직이기 전에 IK·특이점·J3 한계·충돌(FK 샘플링) 검사 |
| 샌딩 | 외력 한계 초과 / 벽 안으로 너무 들어감 / 도구 기울어짐 → 정지 |
| 샌딩 | 누르는 힘이 허용 범위 밖이면 goal 거부 |
| 퍼티·샌딩 | 벽 4점이 없으면 `E_NO_WALL`, 로봇 안 움직임 |
| HMI | 비상정지 중·공정 실행 중에는 그리퍼 열기/닫기 거부 (쥔 도구 낙하 방지) |
| HMI | 비상정지 후 RESET 전까지 새 작업 불가 |
| 종료 처리 | `safe_shutdown`: 정리 함수마다 try/except → 하나가 실패해도 `destroy_node`·`rclpy.shutdown`은 반드시 실행 |

> 소프트웨어 정지는 보조 수단입니다. 실물 운용에서는 **하드웨어 비상정지 버튼**이 1차 수단입니다.

# 공통 모듈 (`utils/`)

| 파일 | 역할 |
|---|---|
| `robot.py` | 로봇 ID·모델·Tool·TCP·홈 자세 (하드코딩 13곳 대체) |
| `config.py` | yaml 로드, virtual 덮어쓰기 |
| `worker_process.py` | 작업 노드를 새 세션 프로세스로 격리, freeze/terminate/kill |
| `move_stop.py` | `DSR_ROBOT2`에 없는 정지 서비스 직접 호출 |
| `shutdown.py` | 안전한 종료 순서 |
| `force_stats.py` | 힘 통계 |
| `wall.py` | 벽 4점 → 법선 |
