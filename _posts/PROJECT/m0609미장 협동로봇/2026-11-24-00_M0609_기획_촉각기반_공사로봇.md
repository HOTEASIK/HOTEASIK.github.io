# 배경

- 퍼티 샌딩은 **분진 노출이 큰 기피 작업** → 작업자 건강 위험, 인력 확보 어려움
- 평탄도·이음매 품질이 **숙련도에 따라 편차**가 크고, 결과가 수치로 남지 않음
- 1차 목표: ① 작업자 분진 노출 감소 ② 품질의 **정량 기록** (인건비 절감은 이후 단계)

# 제약: 비전·LLM·VLA 사용 불가

과제 조건상 카메라 모델을 쓸 수 없어서, 로봇이 **시각장애인처럼 접촉 위치와 힘의 방향만으로** 일하도록 설계했습니다.
돌아보면 이 제약에 장점도 있었습니다.

- 분진·도료 미스트로 카메라가 오염됨
- 흰 퍼티 벽은 텍스처가 없어 깊이 추정이 어렵고, 0.5 mm 단차는 조명 영향이 큼
- 촉각은 **결과(평탄도)를 직접 측정**함

# 시스템 구상

```
[앱(태블릿/PC)] ──JSON──> [제어 PC: Task Manager]
                                 │  ROS2 서비스 / DRL
                                 ▼
                        [M0609 컨트롤러] ── DO ──> 샌더 ON/OFF
                                 │
                        [관절 토크센서 → 툴 끝 외력 추정]
```

M0609은 6축 **관절 토크센서**가 있어서, 별도 F/T 센서 없이 툴 끝 외력을 추정할 수 있다는 점을 전제로 했습니다.

# 공통 기반 로직 — "손끝으로 더듬기"

모든 작업은 아래 모듈을 조합합니다.

| 모듈 | 하는 일 |
|---|---|
| `zero_force` | 접촉 없는 상태에서 0.5초간 50회 평균 → 힘 영점. 툴 교체·재료 적재 후마다 |
| `touch_probe` | 순응제어로 천천히 접근 → \|F·dir\| > 임계값이면 정지 → 접촉점 + **힘 방향** 반환 |
| `fit_plane` | 접촉점 3×3 → SVD로 평면·법선, 잔차로 평탄도 |
| `edge_scan` | 누르며 미끄러지다 힘이 빠지면(끝·구멍), 옆에서 밀리면(코너) 경계 |
| `force_contact` | 순응제어 + 목표 힘. **Rx·Ry 강성을 낮추면 툴이 스스로 면에 평평하게 붙음** |
| `contact_monitor` | 접촉 중 항상: 힘 잃음 / 과부하 / 기울어짐(Mx·My) / 마찰 변화 감시 |
| `height_map` | 일정한 힘으로 스윕 → 툴 Z = 표면 높이 → 10 mm 격자 높이맵 |

**공통 상태머신**

```
IDLE → SETUP(툴·영점) → LOCALIZE(프로빙·평면) → PLAN(경로) → EXECUTE → VERIFY → DONE
어디서든: PAUSE ⇄ 재개 / ABORT → SAFE_RETRACT / 오류 → ERROR / 사람 필요 → WAIT_HUMAN
```

# 범위 — 6개 기능을 한 번에 하지 않는다

| 단계 | 내용 |
|---|---|
| 0단계 PoC (2주) | 토크센서로 충분히 감지되는지 검증 |
| 1단계 | **퍼티 샌딩** + 공통 모듈 |
| 2단계 | 메시 붙이기(사람 보조), 메시 위 퍼티 |
| 3단계 | 자동 이음매 탐색, 전체 퍼티, 금속 샌딩·프라이머 |

퍼티 샌딩을 먼저 고른 이유: 가장 기피하는 작업이고, "높이맵 → 갈기 → 재측정"으로 **촉각만으로 결과 검증이 가능**하며, 공통 모듈을 거의 다 씀.

# PoC 검증 계획 (전제 확인)

전제: **"관절 토크센서만으로 0.5 mm 단차와 5 N 접촉을 구별할 수 있다"**

| # | 항목 | 통과 기준 |
|---|---|---|
| 1 | 정지 시 힘 노이즈 | Fz 표준편차 ≤ 1.0 N |
| 2 | 이동 중 힘 노이즈 | 오차 피크 ≤ 3 N |
| 3 | 힘 유지 오차 (5/10/25 N) | 평균 오차 ≤ 20 %, 접촉 끊김 0회 |
| 4 | 단차·틈 감지 | 0.5 mm 이상 감지율 ≥ 95 %, 오탐 ≤ 5 % |
| 6 | 높이맵 반복성 | 격자별 편차 ≤ 0.2 mm |
| 8 | 대차 반력 | 60 N 누름 후 베이스 이동 ≤ 0.5 mm |

실패하면: 손목 F/T 센서 추가(플랜 B) → 그래도 안 되면 자동 탐색 대신 사람이 지정하는 방식만 운용.
