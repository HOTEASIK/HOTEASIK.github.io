# 프로젝트 개요

두산 협동로봇 **M0609 + RG2 그리퍼**로 벽의 틈을 찾아 **퍼티로 메우고 샌딩**까지 하는 미장 공정을 ROS2로 자동화한 팀 프로젝트입니다.

- 과정: [협동-1] ROS2를 활용한 로봇 자동화 공정 시스템 구현 (5~10차시)
- 팀: 5명 (탐색 / 내부 탐색 / 퍼티 / 샌딩 / 통합·HMI·DB)
- 내 담당: **외부 탐색(wall_tap), 웹 HMI, DB 연동·전체 공정 실행기, 코드 병합·공통 모듈**

# 공정 순서

```
외부 탐색(EXPLORE) → 내부 탐색(INNER_EXPLORE) → 퍼티(PUTTY) → 샌딩(SANDING)
   벽 높이·너비         벽 안의 세로 틈            헤라로 뜨고 바르기     틈마다 지그재그 연마
```

| 단계 | 하는 일 | 결과 |
|---|---|---|
| 외부 탐색 | 탐침으로 벽을 힘제어로 "찍어서" 바닥·표면·윗면·좌우 끝을 찾음 | 벽 4점 (top, floor, right, left) |
| 내부 탐색 | 빈 그리퍼 끝으로 벽면을 훑어 세로 틈 검출 | 틈 목록 `[sx,sy,sz,ex,ey,ez]` |
| 퍼티 | 헤라 집기 1회 → 틈마다 (뜨기 → 도포) → 헤라 반납 | task_log |
| 샌딩 | 벽 법선에 수직인 자세로 접촉 → 힘제어 ON → 좌우 ±12.5 mm 지그재그 | task_log |

# 하드웨어 / 소프트웨어

| 항목 | 내용 |
|---|---|
| 로봇 | Doosan M0609 (실물 + 에뮬레이터 virtual 모드) |
| 그리퍼 | OnRobot RG2, 컨트롤러 디지털 출력 |
| OS / 미들웨어 | Ubuntu, ROS2 + `dsr_controller2` |
| 언어 | Python (ament_python 패키지 `rokey1`), 인터페이스 패키지 `rokey_interfaces` |
| DB | MySQL (pymysql) |
| HMI | 표준 라이브러리 `ThreadingHTTPServer` + SSE, 순수 JS |
| 설정 | `config/robot.yaml` 하나 (빌드 없이 재시작만으로 반영) |

# 전체 구조

```
브라우저 ⇄ HTTP/SSE ⇄ hmi_server ─ process_runner ─goal→ /process/explore        (외부 탐색)
                         │                         ─goal→ /process/inner_explore  (내부 탐색)
                         │                         ─goal→ /process/putty_*        (퍼티)
                         │                         ─goal→ /process/sanding        (샌딩)
                         └─ utils/db.py → MySQL (run / wall / gap / task_log / quality)
```

- 모든 공정이 **같은 Action 양식(`Process.action`)** 을 씁니다.
- Feedback 1번 = DB `task_log` 1줄 → 모든 세부 동작이 기록됩니다.
- DB에 쓰는 곳은 HMI 서버 **한 곳뿐**입니다.
