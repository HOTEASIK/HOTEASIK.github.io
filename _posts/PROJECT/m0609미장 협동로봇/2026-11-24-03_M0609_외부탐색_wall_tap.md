# 목표

카메라 없이 **탐침으로 벽을 찍어서(tap)** 벽의 높이·너비와 4개 기준점을 구합니다.
결과(벽 4점)는 DB에 저장되고, 내부 탐색 범위·벽 법선·퍼티/샌딩 자세 계산에 쓰입니다.

# 측정 순서 (`WallTapper.run`)

1. `measure_floor`: −Z로 힘제어 → 바닥 z
2. `find_wall`: 바닥에서 조금 올린 높이에서 +X로 전진 → 벽 표면 x
3. `measure_height`: z를 올리며 찍음 → 윗면 → 높이 = top_z − floor_z
4. `swap_tool`: 탐침 반납 → 그리퍼 닫기 → 이후는 **손끝**으로 측정
5. `measure_width`: 윗면 30 mm 아래에서 왼쪽 → 오른쪽 끝점 → 너비
6. `save`: 결과 JSON + 찍기마다 힘 시계열(`_trace.json`) + 이동 중 힘·관절(`_motion.csv`)

# 찍기 1회 — 접촉 판정

단순히 "힘 > N"으로 판정하면 노이즈나 탄성 탐침 때문에 오판이 많았습니다. 그래서 조건을 여러 겹으로 걸었습니다.

| 요소 | 내용 |
|---|---|
| 진입 임계값 | `th_in = max(contact, k_sigma × σ)` — σ는 시작할 때 잰 노이즈를 진행 방향으로 투영한 값 |
| 해제 임계값 | `th_out = hyst × th_in` (히스테리시스) |
| 방향 | 진행 방향을 **거슬러** 미는 힘만: `max(0, −F·d)` |
| 확정 | `th_in`을 `contact_hold`초 유지 **그리고** (위치가 멈춤 **또는** 접촉 뒤 일정 거리 더 밀림) |
| 안 닿음 | 진행 거리 > `depth` (힘이 걸려 있으면 탐침 휨을 고려해 조금 더 대기) |
| 안전 중단 | 힘제어 속도 초과, 시간 초과 → `TapError` |
| 사전 중단 | 임계값이 지령 힘의 80% 초과 → 노이즈가 너무 커서 시작 전에 중단 |

**깊이 검사**: 닿았어도 표면보다 너무 깊으면 "안 닿음"으로 바꿉니다. 탐침 끝이 윗면을 넘어가 몸통이 걸린 경우를 걸러내기 위해서입니다.

# 끝점 찾기 — 이분탐색 (`find_edge`)

```
step(30 mm)씩 찍기
  → 2번 연속 안 닿음 (miss_confirm)
  → (마지막 닿음, 첫 안 닿음) 구간을 tol(1 mm)까지 이분탐색
```

- 일정 간격으로만 찍으면 정밀도 = 간격, 촘촘히 찍으면 시간이 오래 걸림
- **성긴 탐색 + 이분탐색**으로 찍기 횟수를 줄이면서 1 mm 정밀도 확보
- `hint`: 다른 선에서 찾은 끝점 근처부터 시작해 횟수를 더 줄임

# 자세 변경과 특이점 대응

벽 양쪽 끝을 재려면 손목 자세를 크게 바꿔야 하는데, 이때 **특이점·관절 한계·충돌**이 가장 큰 문제였습니다.

| 함수 | 하는 일 |
|---|---|
| `reorient_via_home` | 벽에서 물러남 → 홈 → 경유점(movej) → 수직 하강. 경유점은 격자로 찾고 \|J3\| ≤ 135°, 바닥·벽 여유 조건 확인 |
| `move_over` | 반대쪽 자세가 같으면 손목을 뒤집지 않고 위로 넘어감 |
| `_ref_ik` | 기준 관절값의 solution space로 IK, J4/J6은 ±360° 중 가까운 해 |
| `_sweep` | 관절 보간 경로를 FK로 20등분 → 탐침 최저 z·벽 쪽 최대값 계산 (충돌 사전 점검) |
| `_check_j3` | 목표 J3가 한계를 넘으면 **움직이기 전에** 정지 |
| `check_singularity` | 예상 경로에서 \|J5\| < 기준이면 중단 |

핵심 원칙은 **"움직이기 전에 계산으로 검사한다"** 입니다. 손목이 반쯤 돈 상태로 멈추면 복구가 훨씬 어렵기 때문입니다.

# 액션 서버 — `explore_server.py`

- 로봇을 직접 움직이지 않고 측정 노드를 **별도 프로세스**로 띄움 → 취소·크래시를 격리
- 결과 JSON → 벽 4점
  - 옆·위 좌표는 측정 **중앙값**, 벽 쪽 좌표는 **실제 접촉점** → 벽 기울기가 4점에 남음
  - 좌우 끝을 15 mm씩 안쪽으로 보정 (손끝 폭)
- 취소·시간 초과 시 정지 순서:
  1. `SIGSTOP`으로 프로세스 동결
  2. `move_stop(QSTOP)`
  3. `SIGKILL` (자동 홈 복귀 방지)
  4. 힘·순응 해제

# 벽 법선 — `utils/wall.py`

```python
n = normalize(cross(right - left, top - floor))  # 로봇 쪽을 향하도록 부호 맞춤
```

4점이 없거나 한 줄 위에 있으면 `None` → 퍼티·샌딩은 `E_NO_WALL`로 **움직이지 않고** 종료합니다.
