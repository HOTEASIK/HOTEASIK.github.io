# 3. 환경 설정과 기본 명령어

## Windows 환경 준비

강의 자료는 Windows에서 Docker Desktop과 WSL 2 또는 Hyper-V 기반 실행 환경을 준비하는 흐름을 다룹니다. 설치 전 운영체제 에디션과 버전, 하드웨어 가상화 지원 여부, 메모리와 디스크 여유 공간을 확인합니다. BIOS/UEFI에서 가상화 기능이 꺼져 있으면 Docker Desktop이 실행되지 않을 수 있습니다.

설치 요구 사항은 Windows 및 Docker Desktop 버전에 따라 달라질 수 있으므로, 실제 설치 시 [Docker Desktop Windows 설치 안내](https://docs.docker.com/desktop/setup/install/windows-install/)를 확인합니다. 강의 자료에 적힌 버전·요구 조건은 자료 작성 시점의 안내로 취급합니다.

## 명령어 기본

### 이미지

```bash
docker login
docker pull ubuntu
docker image ls
docker image rm ubuntu
```

- `pull`: 레지스트리에서 이미지 가져오기
- `image ls` 또는 `images`: 로컬 이미지 목록 확인
- `image rm` 또는 `rmi`: 이미지 삭제

### 컨테이너

```bash
docker run -it ubuntu bash
docker ps
docker ps -a
docker start <컨테이너명>
docker stop <컨테이너명>
docker rename <기존이름> <새이름>
docker rm <컨테이너명>
```

- `run`: 이미지로 새 컨테이너를 만들고 실행합니다. 로컬에 이미지가 없으면 내려받을 수 있습니다.
- `-i`: 표준 입력을 열어 둡니다.
- `-t`: 터미널을 연결합니다. 셸 실습에서는 보통 `-it`를 함께 씁니다.
- `-d`: 백그라운드에서 실행합니다.
- `ps`: 실행 중인 컨테이너를 표시합니다. `-a`를 추가하면 종료된 컨테이너도 포함합니다.
- `start`, `stop`: 기존 컨테이너를 다시 시작하거나 중지합니다.
- `rm`: 컨테이너를 삭제합니다. 보존이 필요한 데이터는 먼저 볼륨에 있는지 확인합니다.

### 컨테이너 안에서 작업

```bash
docker exec -it <컨테이너명> bash
docker exec <컨테이너명> ls /var/www
docker logs <컨테이너명>
```

`exec`는 실행 중인 컨테이너 안에서 새 프로세스를 실행합니다. 이미지에 `bash`가 없으면 `sh`를 사용해야 할 수 있습니다. `attach`는 컨테이너의 주 프로세스 입출력에 연결하는 명령이므로, 셸을 새로 열 때는 보통 `exec`가 편리합니다.

### 파일과 저장 공간

```bash
docker cp ./file.txt <컨테이너명>:/tmp/file.txt
docker cp <컨테이너명>:/tmp/result.txt ./result.txt
docker run -it -v /c/rokey:/rokey continuumio/miniconda3 /bin/bash
```

`-v`는 호스트 경로와 컨테이너 경로를 연결합니다. Windows 경로 표현은 사용 중인 터미널과 Docker Desktop 설정에 따라 달라질 수 있습니다. 컨테이너 수명과 무관하게 보존할 데이터라면 Docker 볼륨을 고려합니다.

### 네트워크

```bash
docker network ls
docker network create app-net
docker network connect app-net <컨테이너명>
```

같은 사용자 정의 네트워크에 연결된 컨테이너는 네트워크를 통해 서로 통신할 수 있습니다. 호스트에서 서비스에 접속해야 할 때는 `-p 호스트포트:컨테이너포트`로 포트를 공개합니다.

## 명령 형태

`docker image ls`와 `docker images`, `docker container ps`와 `docker ps`처럼 짧은 별칭이 있습니다. 학습 초반에는 `docker image`, `docker container`처럼 대상이 드러나는 형식을 익히면 명령의 의미를 파악하기 쉽습니다.
