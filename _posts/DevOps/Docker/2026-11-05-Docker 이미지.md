# 정의
컨테이너 생성 목적의 템플릿(=형식) 파일 
애플리케이션 실행에 필요한 모든 요소를 하나로 패키징 
	실행환경(운영체제), 애플리케이션(코드), 라이브러리, 설정 등


# 특징 

1. 이미지와 컨테이너 관계
	이미지: 설계도 
	컨테이너: 애플리케이션(코드)실행 결과물

2. 
# 실행

## 웹페이지 
### 만들기

docker pull nginx
	nginx: 웹 요청을 받아서 웹페이지를 보여주는 프로그램 

docker run -d -p 8080:80 --name webserver nginx
	 -d : 백그라운드 실행
	 -p : 포트 번호 설정
	 --name

### 삭제

docker stop webserver 
	웹 서버 정지
docker rm webserver
	웹 서버 지우기
docker rmi nginx
	nginx 지우기

## 기존 컨테이너 활용
### commit

docker run -it --name myubuntu ubuntu:22.04 bash
	run: 바로 실행

exit
	 탈출

docker commit myubuntu myubuntu:vim
	commit 명령으로 이미지 생성
