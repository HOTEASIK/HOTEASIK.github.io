# 파라미터

## 정의·핵심
- **정의**: 노드가 가진 **설정값**. 코드를 고치지 않고 밖에서 읽고 바꾼다 — 최대 속도, 센서 주기, 배경색, 로봇 이름 (기초 4·5차시).
- **비유**: 다이얼(손잡이). 통신이 아니라 「노드에 붙은 조절 손잡이」 다. 데이터를 흘려보내는 게 아니라 값을 정해 둔다.
- **노드마다 따로**: 파라미터는 노드에 속한다 — `/turtlesim`의 `background_b`처럼 「노드 이름 + 파라미터 이름」 으로 가리킨다.
- **자료형**: bool, int, double, string, 배열 등. 잘못된 타입으로 set하면 거절된다.
- **흔한 실수**: 한 번 정하면 되는 설정을 토픽으로 계속 쏘는 것 → 파라미터로.
- **바꾸는 세 방법**: 실행 중 `ros2 param set`, 실행 시 `--ros-args -p 이름:=값`, YAML 파일(`--params-file`).
- turtlesim은 배경색이 바뀐 뒤 화면이 바로 안 바뀌면 `/clear` 서비스를 부르면 반영된다.
- 코드에서 선언·읽기·콜백은 [[rclpy 파라미터]], [[파라미터 콜백]].

## 원리·구조
```
/turtlesim 노드
 ├─ background_r = 69
 ├─ background_g = 86
 ├─ background_b = 255   ← ros2 param set /turtlesim background_b 255
 └─ use_sim_time = false (모든 노드 기본)
```

## 코드 예시
```python
# 노드별 파라미터 저장소 + 타입 검사 흉내
params = {"/turtlesim": {"background_b": 255, "use_sim_time": False}}
def param_set(node, name, value):
    old = params[node].get(name)
    if old is not None and type(old) is not type(value):
        return "Setting parameter failed: wrong type"
    params[node][name] = value
    return "Set parameter successful"
print(param_set("/turtlesim", "background_b", 0))      # Set parameter successful
print(param_set("/turtlesim", "background_b", "red"))  # Setting parameter failed: wrong type
```
```bash
ros2 param list /turtlesim
ros2 param get /turtlesim background_b
ros2 param set /turtlesim background_b 255
ros2 run turtlesim turtlesim_node --ros-args -p background_r:=200
ros2 param dump /turtlesim > turtle.yaml
```
