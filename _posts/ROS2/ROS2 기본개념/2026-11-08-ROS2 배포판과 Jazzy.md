# ROS2 배포판과 Jazzy

## 정의·핵심
- **배포판(distribution)**: ROS2는 해마다 이름을 붙인 배포판을 낸다. 알파벳 순서의 "형용사+거북이 종" 이름 (기초 3차시).
- **우리 과정은 Jazzy Jalisco**: 2024년 5월 23일 출시, **5년 지원 LTS**, **Ubuntu 24.04(noble)와 짝**을 이룬다 (Tier 1 플랫폼).
- **배포판과 우분투는 짝이 있다**

| 배포판 | 나온 때 | 짝 우분투 | 우리 과정에서 |
|---|---|---|---|
| Humble | 2022 | 22.04 | 8기 자료의 기준 — 훌륭한 LTS지만 우리는 24.04에서 시작 |
| **Jazzy Jalisco** | 2024.5 | **24.04 noble** | 기준 — 5년 LTS |
| Lyrical Luth | 2026.5 | 26.04 | 2031년까지 LTS, Tier 1이 26.04 (2026-09 확인) |

- 우분투가 22.04면 Jazzy가 아니라 Humble용 저장소를 봐야 한다 — 버전 불일치가 설치 실패 1순위.
- **왜 Jazzy인가** (입문 1차시): 24.04 위의 LTS라 오래 쓴다. 배포판 이름이 바뀌어도 노드·토픽·발행·구독 뼈대는 그대로 — 한 번 익히면 버전이 올라가도 다시 배울 일은 거의 없다.
- 배포판 이름은 경로와 패키지 이름에 들어간다: `/opt/ros/jazzy`, `ros-jazzy-desktop`, 환경변수 `ROS_DISTRO=jazzy`.
- Jazzy에서 바뀐 것 중 실습에서 만나는 것: Gazebo 신형(gz sim) + ros_gz, TurtleBot3/Nav2의 `cmd_vel`이 **TwistStamped** (실습 5차시).

## 원리·구조
```
/opt/ros/jazzy/
 ├─ setup.bash        ← source 대상
 ├─ bin/  lib/  share/  (설치된 패키지들)
apt 패키지 이름:  ros-<배포판>-<패키지 이름의 _를 -로>   예) ros-jazzy-turtlesim
```

## 코드 예시
```python
# apt 패키지 이름 규칙: ros-<distro>-<pkg에서 '_'를 '-'로>
def apt_name(pkg, distro="jazzy"):
    return f"ros-{distro}-{pkg.replace('_', '-')}"
print(apt_name("turtlesim"))            # ros-jazzy-turtlesim
print(apt_name("slam_toolbox"))         # ros-jazzy-slam-toolbox
print(apt_name("ros_gz"))               # ros-jazzy-ros-gz
```
```bash
printenv ROS_DISTRO     # jazzy
ls /opt/ros
```
