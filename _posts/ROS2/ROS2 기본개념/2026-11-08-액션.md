# 액션

## 정의·핵심
- **정의**: **오래 걸리는 작업**을 위한 통신. 목표(goal)를 보내면 서버가 진행 상황(feedback)을 중간중간 알려 주고, 끝나면 결과(result)를 준다. 도중에 **취소(cancel)** 도 된다 (기초 4·5차시).
- **비유**: 택배 — 주문(goal)하면 「배송 출발 / 지역 도착」 알림(feedback)이 오고, 도착(result)하면 끝. 마음이 바뀌면 주문 취소.
- **서비스와의 차이**: 서비스는 답이 올 때까지 막혀 기다리지만, 액션은 기다리는 동안에도 상황을 보고받고, 멈추게 할 수 있다.
- **언제 쓰나**: 목표 지점까지 이동(Nav2 `navigate_to_pose`), 로봇팔 동작, 거북이 회전(`/turtle1/rotate_absolute`).
- **속은 토픽+서비스 묶음**: goal·cancel·result는 서비스, feedback·status는 토픽으로 구현돼 있다.
- **타입**: `패키지/action/타입`, 파일은 goal / result / feedback 세 부분이 `---` 두 개로 나뉜다.

## 원리·구조
```
[클라이언트] ─goal {theta: 1.57}─→ [액션 서버 /turtle1/rotate_absolute]
             ←── accepted ────────
             ←── feedback {remaining: 1.2} ─ (여러 번)
             ←── feedback {remaining: 0.4} ─
             ←── result {delta: 1.57} ─────
             (도중에) ── cancel ──→
RotateAbsolute.action:
  float32 theta        # goal
  ---
  float32 delta        # result
  ---
  float32 remaining    # feedback
```

## 코드 예시
```python
# goal → feedback 여러 번 → result, 도중 취소 가능
def rotate(target, step=0.5, cancel_at=None):
    cur = 0.0
    while cur < target:
        cur = min(cur + step, target)
        print(f"feedback remaining={target - cur:.2f}")
        if cancel_at is not None and cur >= cancel_at:
            return "CANCELED"
    return f"SUCCEEDED delta={cur:.2f}"
print(rotate(1.57))                  # remaining=1.07, 0.57, 0.07, 0.00 → SUCCEEDED delta=1.57
print(rotate(1.57, cancel_at=1.0))   # remaining=1.07, 0.57 → CANCELED
```
```bash
ros2 action list -t
ros2 action send_goal /turtle1/rotate_absolute turtlesim/action/RotateAbsolute "{theta: 1.57}" --feedback
```
