# remap

## 정의·핵심
- **정의**: 코드를 고치지 않고 실행할 때 **토픽·서비스·노드 이름을 바꿔 끼우는** 기능. `--ros-args -r 원래이름:=새이름` (기초 4·5차시).
- **왜**: teleop은 언제나 `/turtle1/cmd_vel`로만 보낸다. turtle2를 조종하려면 코드를 고치는 대신 이름표만 바꿔 단다 → `-r /turtle1/cmd_vel:=/turtle2/cmd_vel`.
- **어댑터 역할**: 드라이버는 `/scan`으로 내는데 받는 노드는 `/laser`를 기다린다 → `-r /scan:=/laser`. 남이 만든 노드끼리 잇는 플러그 변환기.
- **문법 주의**
  - 반드시 **`:=`** (콜론+등호). `=` 하나면 인식 실패 → 에러 또는 무시.
  - `--ros-args` 뒤에 써야 한다. 여러 개면 `-r a:=b -r c:=d`.
  - 특수 이름: `__node:=새노드이름`, `__ns:=/네임스페이스`.
- **이름이 곧 약속**: talker를 `-r chatter:=greeting`으로 띄우면, 기존 listener는 `/chatter`만 듣고 있어 아무것도 못 받는다 — 에러 없이 조용히.
- **remap vs namespace**: remap은 토픽 하나를 집는 **핀셋**, namespace는 노드의 이름 전체를 쓸어 옮기는 **빗자루**.

## 원리·구조
```
기본:   [teleop] ─/turtle1/cmd_vel→ [turtle1]
remap:  [teleop -r /turtle1/cmd_vel:=/turtle2/cmd_vel] ─/turtle2/cmd_vel→ [turtle2]
```

## 코드 예시
```python
# --ros-args -r 규칙 해석 흉내
def parse_remaps(args):
    rules = {}
    for i, a in enumerate(args):
        if a == "-r":
            rule = args[i + 1]
            if ":=" not in rule:
                raise ValueError(f"잘못된 remap: {rule!r} (':=' 필요)")
            src, dst = rule.split(":=", 1)
            rules[src] = dst
    return rules
def resolve(name, rules): return rules.get(name, name)

r = parse_remaps(["--ros-args", "-r", "/turtle1/cmd_vel:=/turtle2/cmd_vel"])
print(resolve("/turtle1/cmd_vel", r))   # /turtle2/cmd_vel
print(resolve("/turtle1/pose", r))      # /turtle1/pose  ← 지정한 것만 바뀜
try:
    parse_remaps(["--ros-args", "-r", "/scan=/laser"])
except ValueError as e:
    print(e)                            # 잘못된 remap: '/scan=/laser' (':=' 필요)
```

ros2 run turtlesim turtle_teleop_key --ros-args -r /turtle1/cmd_vel:=/turtle2/cmd_vel
