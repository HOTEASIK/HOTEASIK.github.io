# 서비스

## 정의·핵심
- **정의**: **요청(request) 하나에 응답(response) 하나**를 주고받는 동기형 통신. 클라이언트가 묻고, 서버가 답한다. 비유는 **전화** — 걸고, 묻고, 답을 듣고 끊는다 (기초 4·5차시).
- **토픽과의 차이**: 토픽은 듣는 사람이 있든 없든 계속 흘려보내지만, 서비스는 **필요할 때 한 번** 부르고 **답을 기다린다**.
- **언제 쓰나**: 짧게 끝나는 일회성 작업 — 펜 색 바꾸기(`/turtle1/set_pen`), 순간 이동(`teleport_absolute`), 거북이 추가(`/spawn`), 화면 지우기(`/clear`), 계산 요청.
- **흔한 실수**: 오래 걸리는 일(이동 10초)을 서비스로 만들면 클라이언트가 그동안 멈춰 기다린다 → **액션**으로.
- **타입**: `패키지/srv/타입`. 요청부와 응답부가 `---`로 나뉜다. 예 `turtlesim/srv/Spawn`: x, y, theta, name → name.
- 서버가 없으면 클라이언트는 `waiting for service to become available...`에서 멈춘다.

## 원리·구조
```
[클라이언트] ──request {x:2, y:2, name:'t2'}──→ [서버 /spawn]
             ←──────response {name:'t2'}────────
srv 파일:
  float32 x
  float32 y
  float32 theta
  string name
  ---
  string name
```

## 코드 예시
```python
# 요청-응답: 서버 함수가 있어야 답이 온다
servers = {"/spawn": lambda req: {"name": req.get("name") or "turtle2"}}
def call(name, req):
    if name not in servers: return "waiting for service to become available..."
    return servers[name](req)
print(call("/spawn", {"x": 2.0, "y": 2.0, "name": "t2"}))   # {'name': 't2'}
print(call("/spwan", {}))                                   # waiting for service to become available...
```
```bash
ros2 service list -t
ros2 service type /spawn                        # turtlesim/srv/Spawn
ros2 service call /spawn turtlesim/srv/Spawn "{x: 2.0, y: 2.0, theta: 0.0, name: 't2'}"
```
