# ROS2 설치

## 정의·핵심
- **정의**: Ubuntu 24.04(네이티브)에 ROS2 Jazzy를 apt로 설치하는 과정. 명령이 길어 보여도 뼈대는 셋 — **창고 주소 등록 → ROS 받아 깔기 → 환경 켜기** (기초 3차시). 외우려 하지 말고 「아, 지금 창고 등록하는 거구나」 정도만 따라온다.
- **① 첫 단추**: `lsb_release -a` 로 24.04(noble) 확인 — 버전이 다르면 뒤의 저장소가 어긋난다. locale을 UTF-8로 맞춘다(빼면 한글·특수문자가 깨지거나 경고).
- **② 창고 주소 등록** (여섯 줄): software-properties-common·curl 설치 → `add-apt-repository universe` → 최신 `ros-apt-source` 버전 이름을 받아 `ROS_APT_SOURCE_VERSION`에 저장 → 그 버전의 `.deb`를 받아 설치. 긴 두 줄은 보충자료에서 한 글자도 바꾸지 말고 복사.
  - 버전 이름이 비어 있으면: 네트워크 문제나 GitHub API 횟수 제한(미인증 시간당 60회 — 강의실에서 걸리기 쉽다) → releases 페이지에서 확인해 `export ROS_APT_SOURCE_VERSION=버전` 으로 직접 지정.
- **③ 본체 설치**: `sudo apt install -y ros-jazzy-desktop ros-dev-tools` — 용량이 커서 5~15분, 가장 오래 걸린다. `desktop`은 RViz 같은 시각화 도구까지 포함한 묶음, `ros-dev-tools`는 colcon·rosdep 등 개발 도구.
- **④ 환경 켜기**: `source /opt/ros/jazzy/setup.bash` (PATH·LD_LIBRARY_PATH·PYTHONPATH 반영) + `.bashrc`에 등록.
- **⑤ 점검**: `ros2 --help`(사용법이 뜨면 성공), `printenv ROS_DISTRO`(jazzy). 일부러 source 없이 쳐서 `command not found`를 한 번 본다.
- 다운로드가 몰리면 와이파이가 느려진다 — 가능하면 쉬는 시간에 미리.

## 원리·구조
| 증상 | 원인 → 처방 |
|---|---|
| `lsb_release`가 22.04 | 구버전 우분투 → 24.04 재설치 |
| add-apt-repository: command not found | software-properties-common 미설치 → 설치 후 재시도 |
| GPG error · NO_PUBKEY | 저장소 키(.deb) 등록 실패 → .deb 설치 단계 재실행 후 `apt update` |
| Unable to locate package ros-jazzy-desktop | 저장소 등록 누락 → 등록 단계 다시, `apt update` |
| 다운로드 멈춤/타임아웃 | 네트워크 혼잡 → 잠시 뒤 재시도 |
| Could not get lock | 다른 apt·자동 업데이트 실행 중 → 기다렸다 재시도 |
| No space left on device | 디스크 부족 → 정리 후 재시도 |
| ros2: command not found | source 안 함 → `source /opt/ros/jazzy/setup.bash` |
| ROS_DISTRO 비어 있음 | 환경 미적용 → 새 터미널 또는 다시 source |

## 코드 예시
```bash
lsb_release -a
sudo apt update && sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
sudo apt install -y software-properties-common curl
sudo add-apt-repository universe
# (긴 명령 ①·② — 보충자료에서 복사: ros-apt-source 버전 받기, .deb 받기)
echo $ROS_APT_SOURCE_VERSION
sudo apt install -y /tmp/ros2-apt-source.deb
sudo apt update && sudo apt upgrade -y
sudo apt install -y ros-jazzy-desktop ros-dev-tools
source /opt/ros/jazzy/setup.bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
ros2 --help
printenv ROS_DISTRO     # jazzy
```
