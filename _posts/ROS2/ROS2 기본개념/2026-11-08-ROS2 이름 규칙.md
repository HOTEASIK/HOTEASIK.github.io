# ROS2 이름 규칙

## 정의·핵심
- **기본 원칙**: 패키지·노드·토픽 이름은 **snake_case** — 소문자, 숫자, 밑줄(`_`) (입문 1차시).
  - 대문자 금지: `MyNode` ✗ → `my_node`.
  - 하이픈 금지: `my-robot` ✗ — 파이썬 `import my-robot`은 문법이 깨진다. 빌드가 통과해도 실행 때 못 찾는 **조용한 실패**가 잦다.
  - 숫자로 시작 금지: `2nd_cam` ✗ → `cam_2`.
  - 토픽은 `/`로 계층을 나눈다: `/robot1/camera/image_raw`. `//` 연속, 끝 `/` 금지.
- **토픽 이름은 정확히 일치**해야 한다 — 한 글자, 대소문자, 앞의 `/` 유무(상대·절대)까지. 틀려도 에러가 안 나 찾기 어렵다.
- **좋은 이름 예**: talker/listener(역할), `camera_publisher`, `lidar_driver`, `path_planner` — 노드는 `_node`·`_driver`·`_publisher` 같은 역할 꼬리, 토픽은 내용(`image_raw`, `scan`, `cmd_vel`).
- **이름은 약속**: 남이 만든 노드와 붙일 때 관례 이름(`/scan`, `/odom`, `/cmd_vel`, `/tf`)을 따르면 remap 없이 바로 연결된다.

## 원리·구조
| 대상 | 규칙 | 좋은 예 | 나쁜 예 |
|---|---|---|---|
| 패키지 | 소문자+밑줄, 문자로 시작 | `my_robot_pkg` | `My-Robot` |
| 노드 | 소문자+밑줄 | `camera_publisher` | `CameraNode` |
| 토픽 | 소문자+밑줄, `/` 계층 | `/robot1/cmd_vel` | `/Robot1//cmdVel/` |
| 메시지 타입 | CamelCase (예외) | `Twist`, `LaserScan` | `twist` |

## 코드 예시
```python
import re
NAME = re.compile(r"^[a-z][a-z0-9_]*$")
def check(name):
    if "-" in name: return "✗ 하이픈 — import 불가"
    if name[:1].isdigit(): return "✗ 숫자로 시작"
    if name != name.lower(): return "✗ 대문자"
    return "✓" if NAME.match(name) else "✗ 허용 안 되는 문자"
for n in ["my_robot_pkg", "my-robot", "2nd_cam", "MyNode", "cam_2"]:
    print(f"{n:13} {check(n)}")
# my_robot_pkg  ✓ / my-robot ✗ 하이픈 — import 불가 / 2nd_cam ✗ 숫자로 시작 / MyNode ✗ 대문자 / cam_2 ✓

def topic_ok(t):
    return bool(re.fullmatch(r"/?[a-z][a-z0-9_]*(/[a-z][a-z0-9_]*)*", t))
print(topic_ok("/robot1/cmd_vel"), topic_ok("/Robot1//cmdVel/"))   # True False
```
