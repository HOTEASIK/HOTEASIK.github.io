# teleop 키보드 조종

## 정의·핵심
- **정의**: teleoperation(원격 조종). 키보드 입력을 속도 명령(Twist)으로 바꿔 `cmd_vel` 토픽에 발행하는 노드. turtlesim에서는 `turtle_teleop_key` (기초 4차시).
- **포인트 하나 — 포커스**: 키 입력은 **teleop을 띄운 터미널이 활성화(포커스)돼 있을 때만** 먹힌다. 거북이 창을 클릭하면 키가 안 먹는다 → 다시 teleop 터미널을 클릭.
- **조작**: 방향키 ↑↓ 전진·후진, ←→ 회전. `G B V C D E R T` 키는 절대 각도 회전(액션 `rotate_absolute`를 부른다), `F`는 회전 취소, `Q` 종료.
- **노드 둘이 토픽 하나로 연결**: `/teleop_turtle` —`/turtle1/cmd_vel`→ `/turtlesim`. rqt_graph에서 이 화살표를 눈으로 본다.
- **실제 로봇도 같다**: TurtleBot3는 `ros2 run turtlebot3_teleop teleop_keyboard`(w/x 전후, a/d 회전, s 정지). Jazzy에서는 Twist가 아닌 **TwistStamped**로 발행 (실습 5차시).
- **다른 거북이 조종**: teleop은 늘 `/turtle1/cmd_vel`로 보낸다 → `-r`로 **remap**하면 turtle2를 조종.

## 원리·구조
```
[키보드] → [/teleop_turtle] ──/turtle1/cmd_vel (Twist)──→ [/turtlesim]
            ↑ 키 → linear.x=±2.0 / angular.z=±2.0
```

## 코드 예시
```python
# 키 → Twist 변환 흉내 (turtle_teleop_key의 스케일 2.0)
KEYMAP = {"UP": (1, 0), "DOWN": (-1, 0), "LEFT": (0, 1), "RIGHT": (0, -1)}
def key_to_twist(key, scale_lin=2.0, scale_ang=2.0):
    lin, ang = KEYMAP.get(key, (0, 0))
    return {"linear": {"x": lin * scale_lin}, "angular": {"z": ang * scale_ang}}
print(key_to_twist("UP"))      # {'linear': {'x': 2.0}, 'angular': {'z': 0.0}}
print(key_to_twist("LEFT"))    # {'linear': {'x': 0.0}, 'angular': {'z': 2.0}}
```
```bash
ros2 run turtlesim turtlesim_node            # 터미널 A
ros2 run turtlesim turtle_teleop_key         # 터미널 B — 이 창을 클릭한 상태로 방향키
ros2 run turtlesim turtle_teleop_key --ros-args -r /turtle1/cmd_vel:=/turtle2/cmd_vel
```
