# 인터페이스
칸 이름 오류 vs 자료형 오류
	이름이 틀리면 바로 에러가 나지만, 자료형은 조용히 지나갈 수 있어서 더 위험합니다.

# 타이머
타이머 주기가 짧을수록 CPU 부하는 커집니다

# 콜백 막힘
**막힘을 풀려면 두 조건이 모두 필요합니다**: ① `MultiThreadedExecutor` ② 콜백을 **서로 다른 그룹**에 두기

- 실행기만 바꾸고 그룹을 안 나누면 기본 그룹 하나에 몰려서 여전히 막힙니다.

- 그룹만 나누고 실행기가 하나면 일손이 하나라서 여전히 막힙니다

| 실행기 | 그룹 | 결과 |
|---|---|---|
| 단일 | 하나 | 막힘 |
| 멀티 | 하나(기본) | 여전히 막힘 |
| 단일 | 나눔 | 여전히 막힘 |
| 멀티 | 나눔 | 풀림 |

자세한 내용 → [[spin]]

# 노드
- `rclpy.spin(node)`을 빼먹으면 노드가 즉시 종료되고 콜백이 한 번도 안 울린다
- 콜백은 직접 부르지 않는다 — 등록만 하면 spin이 부른다

# 파라미터
- `get_parameter('이름')`만 쓰고 `.value`를 빼먹으면 숫자가 아니라 파라미터 객체가 들어간다
- 실수 파라미터에 `2`처럼 정수를 넣으면 `set`이 거부된다 → `2.0`
- `ros2 param set`으로 바꾼 값은 재시작하면 사라진다 → YAML 파일로 관리
- 자세한 내용 → [[파라미터(parameter)]]

# 통신
- 같은 와이파이에서 옆자리 메시지가 들어오면 `ROS_DOMAIN_ID`를 다르게 준다 — `export`는 노드를 띄우기 **전에**
- 토픽이 안 이어지면 의심 순서: ① 토픽 이름 → ② 메시지 타입 → ③ 처음 뜬 경고 한 줄(QoS 불일치)

# 로그
- `debug()`로 찍은 줄이 안 보이는 건 코드 오류가 아니라 기본 문턱이 INFO라서다 → [[로그 (log)]]
