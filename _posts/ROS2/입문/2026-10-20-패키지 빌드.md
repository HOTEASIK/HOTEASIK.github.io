# 방법

1. 작업 폴더안에 src 폴더로 이동
	cd
2. 패키지 만들기
	ros2 pkg create --build-type ament_python my_pkg --dependencies rclpy
3. 작업 폴더로 이동
	cd ..
4. colcon build
	빌드 결과 폴더: `build/`, `install/`, `log/
	`src` 안에서 colcon build를 하면 안됨
		패키지 구조를 올바르게 인식 못함
		그래도 했으면 [[클린 빌드]]실행
5. source install/setup.bash
	underlay 먼저 소스 그후 overlay 소스
		환경 변수의 우선순위를 올바르게 설정하여 내가 수정한 코드가 시스템 기본 버전보다 먼저 인식되도록 하기 위함
		- 같은 이름의 패키지가 있으면 overlay가 우선합니다.
	
	source를 빠뜨리면: `Package not found`가 나고 탭 자동완성도 안 됩니다.
	다른 터미널 마다 source 필요
		source는 현재 터미널에만 적용되기 때문
