# 정의
**Hz (헤르츠)** = 1초에 몇 번 일어나는가. ROS2에서는 토픽 발행·타이머·제어 루프의 **주기**를 말할 때 쓴다.

#### 초(Second) 과 Hz
1/hz = 초(Second)

| Hz | 주기 | 예 |
|---|---|---|
| 1 Hz | 1.0 s | 상태 보고 |
| 10 Hz | 0.1 s | `/cmd_vel` 반복 발행 |
| 30 Hz | 0.033 s | 카메라 |
| 62.5 Hz | 0.016 s | turtlesim `/turtle1/pose` |

# 코드
```python
self.create_timer(0.1, self.cb)      # 0.1초 주기 = 10Hz
```
```bash
ros2 topic pub -r 10 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0}}"   # 초당 10회
```
로봇 제어 명령은 한 번 보내고 끝이 아니라 일정 주기로 계속 보내야 동작이 이어진다.

# 주기 측정 — `ros2 topic hz`
```bash
ros2 topic hz /turtle1/pose
# average rate: 62.491
# min: 0.015s max: 0.017s std dev: 0.00048s window: 64
```
| 항목 | 뜻 |
|---|---|
| average rate | 평균 발행 주기(Hz) |
| min · max | 가장 빠른·느린 간격 |
| std dev | 주기가 얼마나 들쭉날쭉한지 |
| window | 평균 낸 표본 개수 |

- 30Hz로 돌아야 할 센서가 5Hz로 잡히면 → 드라이버가 버거워하거나 시스템 부하
- 동작이 버벅이면 hz(얼마나 자주) → bw(얼마나 많이) 순으로 본다
- 타이머 주기가 짧을수록(Hz가 높을수록) CPU 부하가 커진다
