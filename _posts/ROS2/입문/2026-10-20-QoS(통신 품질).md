# 정의 

데이터를 배달하는 규칙과 서비스의 품질
노드끼리 데이터를 주고받을 때 어떤 방식으로 안전하게 혹은 빠르게 배달할지 정하는 약속

# 큐 깊이
[[QoS depth(큐 깊이)]]
데이터를 얼마나 가지고 있을지 정하는 설정값
# 종류
  • History (Keep Last / Keep All): 
  - 데이터를 큐(Queue)에 유지하는 방식으로, 최신 N개의 데이터만 유지하거나 시스템 메모리가 허용하는 한 모든 데이터를 보관하도록 제어함. 컴퓨터 자원 관리를 위해 이런 방식을 택함

  • Reliability (Reliable / Best Effort): 
	  - Reliable은  데이터에 '일련번호(Sequence Number)' 매기고 ACK(확인 응답)와 NACK(재전송 요청)을 통해 데이터 손실을 감지하고 데이터 손실 시 재전송을 보장하여 신뢰성을 높이고, 
	  - Best Effort는 재전송 없이 빠른 전송을 우선함.
	 - 각 퍼블,서브 가 위 옵션이 동일해야함

  • Durability (Transient Local / Volatile):
	  - 노드가 늦게 켜졌을 때, 이전 데이터를 재전송받을지(Transient Local) 
	  - 연결된 시점 이후의 데이터만 받을지(Volatile)
	  데이터의 발생 빈도와 로봇 시스템의 상태을 보고 결정함.
