# 정의
**환경 변수**: 프로그램들이 공통으로 참고하는 메모. 셸(터미널)이 들고 있다가, 그 셸에서 실행한 프로그램에 물려준다.

| 변수 | 뜻 |
|---|---|
| `$HOME` | 홈 폴더 경로 |
| `$PATH` | 명령을 찾아볼 폴더 목록 (콜론으로 구분). 목록에 없는 폴더의 프로그램은 이름만으로 못 찾는다 |
| `$ROS_DISTRO` | 켜 둔 ROS 배포판 (예: `jazzy`) |
| `$ROS_DOMAIN_ID` | 통신할 논리 네트워크 번호 (기본 0) |

# 특징

export
	해당 터미널에만 환경 변수 지정
- 터미널을 닫으면 사라지고, 다른 터미널에는 적용되지 않는다
- **이미 떠 있는 노드는 나중에 export 해도 바뀌지 않는다** → export 먼저, 그다음 `ros2 run`
- 계속 쓰려면 `~/.bashrc`에 적어 두면 새 터미널마다 자동 적용
- `source`는 파일 속 명령을 **지금 이 셸에서** 실행해 환경 변수를 반영한다

# 코드
```bash
echo $PATH                    # 읽기
echo $HOME
export MY_TEST=hello          # 만들기 (이 터미널에만)
echo $MY_TEST                 # → hello
printenv ROS_DISTRO           # → jazzy
unset MY_TEST                 # 지우기
```

## ROS2에서 자주 쓰는 것
```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc   # 새 터미널마다 ROS 환경 켜기
export ROS_DOMAIN_ID=7                                  # 같은 번호끼리만 통신 (0~101 권장)

# SROS2 보안
export ROS_SECURITY_KEYSTORE=~/sros2_keystore
export ROS_SECURITY_ENABLE=true
export ROS_SECURITY_STRATEGY=Enforce
```
