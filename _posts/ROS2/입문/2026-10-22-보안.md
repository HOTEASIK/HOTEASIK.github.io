# 코드
## 보안 키 설정
ros2 security create_keystore ~/sros2_keystore
	중앙 보안 키 저장소(Keystore) 생성


ros2 security create_enclave ~/sros2_keystore/ /talker_listener/talker
	talker 노드를 위한 개별 보안 인증서 발급


ros2 security create_enclave ~/sros2_keystore/ /talker_listener/listener
	listener 노드를 위한 개별 보안 인증서 발급

## 보안 활성화
export ROS_SECURITY_KEYSTORE = ~/sros2_keystore
	**보안 키 저장소 경로 지정:** ROS 2 노드들이 암호화 통신을 할 때 필요한 암호화 키, 인증서(CA), 보안 정책 파일들이 저장되는 디렉토리 경로를 설정
export ROS_SECURITY_ENABLE = true
	**보안 기능 활성화:** ROS 2의 **보안(DDS-Security) 기능을 켭니다.** 이 값이 `true`로 설정되면, ROS 2는 노드 간 통신을 암호화하고 인증된 노드만 통신에 참여할 수 있도록 제어하기 시작합니다.
export ROS_SECURITY_STRATEGY=Enforce
	**보안 정책 강제 적용:** 보안을 얼마나 엄격하게 적용할지 결정합니다. 
	`Enforce`(강제)로 설정하면, **유효한 보안 인증서가 없는 노드는 네트워크 참여가 완전히 차단**되며 통신이 불가능해집니다. (참고: 다른 옵션인 `Permissive`는 인증서가 없는 노드도 경고만 띄우고 통신을 허용합니다.)
	**`Permissive`** (기본값)
