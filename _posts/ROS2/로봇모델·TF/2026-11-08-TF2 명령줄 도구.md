# TF2 명령줄 도구

## 정의·핵심
- **정의**: 코드 없이 TF를 내고 읽고 그리는 명령 넷 (실습 4차시).
- **`static_transform_publisher`**: 고정 변환 발행 — `ros2 run tf2_ros static_transform_publisher --x 1 --y 0 --z 0 --frame-id base_link --child-frame-id sensor`(그 밖 `--roll --pitch --yaw`, `--qx … --qw`). 화면 `Spinning until stopped - publishing transform translation: ('1.000000', …) from 'base_link' to 'sensor'` — 받는 쪽이 나중에 붙어도 받게 끌 때까지 떠 있다.
- **`tf2_echo A B`**: A 기준 B 변환을 1초마다 — `ros2 run tf2_ros tf2_echo base_link sensor`.
  - `Translation: [1.000, 0.000, 0.000]`
  - 회전 세 줄은 같은 회전: `Quaternion (xyzw) [0,0,0,1]`(회전 없음) · `RPY (radian)` · `RPY (degree)`. `-0.000`은 아주 작은 음수가 반올림된 것.
  - `Matrix` 넉 줄 = 회전+이동을 담은 4×4 변환 행렬 — 맨 오른쪽 열 위 세 칸이 Translation.
  - static이면 `At time 0.0`, dynamic이면 실제 시각.
- **`view_frames`**: 5초 듣고(`Listening to tf data for 5.0 seconds...`) 트리를 PDF로 — 파일명은 `frames_<날짜>_<시각>.pdf`(+ `.gv`), frames.pdf가 아니다. 출력의 `frame_yaml`만 봐도 `sensor: parent: 'base_link'`. 화살표는 부모→자식, 옆에 Broadcaster. `cd ~ && ros2 run tf2_tools view_frames`.
- **`ros2 topic echo /tf` / `/tf_static`**: 발행되는 변환 원본.
- **두 단계 합치기 실습**: base_link→sensor(x 1) + sensor→camera(`--z 0.2`) → `tf2_echo base_link camera` = `[1.000, 0.000, 0.200]` — 아무도 base_link→camera를 직접 발행하지 않았다.

## 원리·구조
```
$ ros2 run tf2_ros tf2_echo base_link arm_link     (슬라이더 1.570)
- Translation: [0.000, 0.000, 0.300]
- Rotation: in Quaternion (xyzw) [0.000, 0.707, 0.000, 0.707]
- Rotation: in RPY (radian) [0.000, 1.570, 0.000]
- Rotation: in RPY (degree) [0.000, 89.954, 0.000]
- Matrix:
  0.001  0.000  1.000  0.000
  0.000  1.000  0.000  0.000
 -1.000  0.000  0.001  0.300
  0.000  0.000  0.000  1.000
```

## 코드 예시
```python
# tf2_echo 한 덩어리 재현: y축 1.570 rad 회전 + z 0.3 이동
import math
import numpy as np
p = 1.570
q = (0.0, round(math.sin(p / 2), 3), 0.0, round(math.cos(p / 2), 3))
R = np.array([[math.cos(p), 0, math.sin(p)], [0, 1, 0], [-math.sin(p), 0, math.cos(p)]])
T = np.eye(4); T[:3, :3] = R; T[:3, 3] = [0, 0, 0.3]
print("Quaternion (xyzw)", q)                         # Quaternion (xyzw) (0.0, 0.707, 0.0, 0.707)
print("RPY (degree)", round(math.degrees(p), 3))      # RPY (degree) 89.954
for row in np.round(T, 3):
    print("  ".join(f"{v:6.3f}" for v in row + 0.0))
#  0.001   0.000   1.000   0.000
#  0.000   1.000   0.000   0.000
# -1.000   0.000   0.001   0.300
#  0.000   0.000   0.000   1.000
```
```bash
ros2 run tf2_ros static_transform_publisher --z 0.2 --frame-id sensor --child-frame-id camera
ros2 run tf2_ros tf2_echo base_link camera
cd ~ && ros2 run tf2_tools view_frames && ls ~/frames_*
ros2 topic echo /tf_static --once
```
