# URDF

## 정의·핵심
- **정의**: URDF(Unified Robot Description Format) — 로봇을 **링크(link, 뼈대)** 와 **조인트(joint, 관절)** 의 집합으로 기술하는 표준 XML 형식. 로봇의 생김새를 적은 문서 (실습 4차시).
- **사람은 눈을 감고도 손끝이 어디 있는지 안다 — 로봇은 그것을 글로 받아야 한다.**
- **왜 적어 두나**: 시각화(RViz)·충돌 검사·운동학 계산·시뮬레이션 넷 모두 「형상과 관절 구조」라는 같은 정보가 필요하다 — URDF 한 곳에 모아 두루 재사용.
- **링크**: 이름과 모양만 적는다(`<visual><geometry><box size=…/>`). 어디에 붙는지는 조인트가 정한다.
- **조인트**: `<parent>`·`<child>`로 두 링크를 부모-자식으로 잇고, `<origin xyz rpy>`가 **부모 좌표계 기준 상대 위치**, `<axis>`가 회전·이동 축, `<limit>`이 범위.
- **최소 예제 simple_arm**: base_link(0.3×0.3×0.1 상자) + arm_link(반지름 0.03, 길이 0.4 원기둥) + revolute 조인트 shoulder(z 0.3 위, y축 회전, ±1.57). 저장 자리 `~/ros2_ws/simple_arm.urdf`.
- **모든 링크는 하나의 트리로**: URDF 링크 트리가 곧 TF 트리의 골격 — 끊긴 링크는 [[check_urdf]]가 「Two root links found」로 알려 준다.
- **손으로 적어 보는 까닭**: 요즘은 제조사·CAD가 주지만, 남의 URDF를 읽고 고치고 「어느 조인트의 origin이 잘못됐는지」 짚으려면 구조를 알아야 한다.
- **준비**: `sudo apt install -y ros-jazzy-urdf-tutorial` — joint_state_publisher(_gui)·urdf_launch·urdf_tutorial·xacro 다섯이 깔린다. 건너뛰면 `Package 'joint_state_publisher_gui' not found`.

## 원리·구조
```
base_link (몸통, 루트)
   │  shoulder: revolute, origin z=0.3, axis y, ±1.57
   ▼
arm_link (팔)
```

## 코드 예시
```python
# simple_arm.urdf를 파싱해 링크 트리와 조인트 정보 뽑기
import xml.etree.ElementTree as ET
urdf = """<?xml version="1.0"?>
<robot name="simple_arm">
  <link name="base_link"><visual><geometry><box size="0.3 0.3 0.1"/></geometry></visual></link>
  <link name="arm_link"><visual><geometry><cylinder radius="0.03" length="0.4"/></geometry></visual></link>
  <joint name="shoulder" type="revolute">
    <parent link="base_link"/><child link="arm_link"/>
    <origin xyz="0 0 0.3" rpy="0 0 0"/><axis xyz="0 1 0"/>
    <limit lower="-1.57" upper="1.57" effort="10" velocity="1.0"/>
  </joint>
</robot>"""
robot = ET.fromstring(urdf)
print(robot.get("name"), [l.get("name") for l in robot.findall("link")])   # simple_arm ['base_link', 'arm_link']
for j in robot.findall("joint"):
    print(j.get("name"), j.get("type"), j.find("parent").get("link"), "→", j.find("child").get("link"),
          j.find("origin").get("xyz"), j.find("limit").get("upper"))
# shoulder revolute base_link → arm_link 0 0 0.3 1.57
```

## 수업 메모

### 정의
로봇의 기본 구조를 정의하는 표준 포맷
**URDF (Unified Robot Description Format)**: 로봇을 **링크(link)와 조인트(joint)의 집합**으로 기술하는 표준 XML 형식 — 로봇의 생김새를 적은 문서다. 사람은 눈을 감고도 손끝이 어디 있는지 알지만, 로봇은 그것을 글로 받아야 한다.

- **링크** = 뼈대 (몸통·팔·바퀴). 이름과 모양만 적는다
- **조인트** = 관절. 두 링크를 부모-자식으로 잇고, 움직이는 방식과 상대 위치를 정한다

### 왜 적어 두나
한 번 적어 둔 URDF를 여러 도구가 함께 쓴다.

| 쓰는 곳 | 필요한 정보 |
|---|---|
| 시각화 | RViz로 3D 모델 보기 |
| 충돌 검사 | 부품끼리 부딪히는지 |
| 운동학 계산 | 관절을 얼마나 돌리면 손끝이 어디로 가는지 |
| 시뮬레이션 | 가상 세계에서 움직이기 |

### 예제
```xml
<?xml version="1.0"?>
<robot name="simple_arm">
  <link name="base_link">
    <visual><geometry><box size="0.3 0.3 0.1"/></geometry></visual>
  </link>
  <link name="arm_link">
    <visual><geometry><cylinder radius="0.03" length="0.4"/></geometry></visual>
  </link>
  <joint name="shoulder" type="revolute">
    <parent link="base_link"/>
    <child  link="arm_link"/>
    <origin xyz="0 0 0.3" rpy="0 0 0"/>   <!-- 몸통에서 0.3m 위 -->
    <axis xyz="0 1 0"/>                    <!-- y축 중심 회전 -->
    <limit lower="-1.57" upper="1.57" effort="10" velocity="1.0"/>
  </joint>
</robot>
```

#### 조인트 타입
| 타입 | 움직임 | 예 |
|---|---|---|
| fixed | 고정 | 몸통에 단 센서 |
| revolute | 제한 있는 회전 | 팔꿈치 |
| continuous | 제한 없는 회전 | 바퀴 |
| prismatic | 직선 이동 | 리프트, 그리퍼 |

### 검사와 활용
```bash
sudo apt install -y ros-jazzy-urdf-tutorial   # urdf_tutorial, joint_state_publisher_gui, xacro 등
check_urdf simple_arm.urdf                    # 문법 검사 + 링크 트리 요약
```
- URDF만으로는 정적인 그림 한 장이다. **robot_state_publisher**가 URDF + `/joint_states`를 받아 모든 링크의 위치 관계를 [[TF2]]로 발행한다
- Jazzy의 robot_state_publisher는 파일 경로가 아니라 **내용**을 `robot_description` 파라미터로 받는다 → launch 파일에서 읽어 넘긴다
- fixed 조인트는 `/tf_static`, 움직이는 조인트는 `/joint_states`가 와야 `/tf`로 나온다
- 반복이 많으면 `xacro`로 줄여 쓴다
