# xacro

## 정의·핵심
- **정의**: XML 매크로 — 매크로·변수·수식으로 **반복을 줄여 쓰는 URDF 확장**. 실행 시점에 순수 URDF로 펼친다 (실습 4차시).
- **왜**: 바퀴 네 개처럼 같은 구조가 반복되면 순수 URDF는 같은 XML을 여러 번 베껴 써야 한다.
- **문법**: `xmlns:xacro="http://www.ros.org/wiki/xacro"`, `<xacro:property name value/>`, `${수식}`, `<xacro:macro name params>…</xacro:macro>`, `<xacro:include filename/>`.
- **원칙은 같다**: 대본에서 파일을 그대로 읽는 대신 **xacro로 펼친 글자**를 `robot_description`으로 넘긴다(`xacro.process_file(path).toxml()` 또는 `Command(['xacro ', path])`).
- **명령줄 덫**: `-p robot_description:="$(xacro …)"`도 `$(cat …)`처럼 YAML 특수 글자에 걸려 `Couldn't parse parameter override rule` → Aborted. xacro는 펼친 결과 머리에 자기 주석 넉 줄을 더 붙인다 → 대본으로 건넨다.
- **학습 순서**: 순수 URDF로 구조를 익히고, 반복이 많아지면 xacro로. `display.launch.py`도 내부에서 xacro를 부른다(`Command: xacro …`).
- 설치: `ros-jazzy-xacro`(urdf_tutorial이 끌어온다).

## 원리·구조
```xml
<robot name="car" xmlns:xacro="http://www.ros.org/wiki/xacro">
  <xacro:property name="r" value="0.05"/>
  <xacro:macro name="wheel" params="name x y">
    <link name="${name}"><visual><geometry><cylinder radius="${r}" length="0.02"/></geometry></visual></link>
    <joint name="${name}_joint" type="continuous">
      <parent link="base_link"/><child link="${name}"/><origin xyz="${x} ${y} 0"/>
    </joint>
  </xacro:macro>
  <xacro:wheel name="fl" x="0.1" y="0.1"/>   <!-- 네 줄로 바퀴 넷 -->
</robot>
```

## 코드 예시
```python
# xacro가 하는 일 흉내: 매크로를 펼쳐 바퀴 넷의 링크·조인트 생성
r = 0.05
def wheel(name, x, y):
    return (f'<link name="{name}"><visual><geometry><cylinder radius="{r}" length="0.02"/></geometry></visual></link>\n'
            f'<joint name="{name}_joint" type="continuous"><parent link="base_link"/><child link="{name}"/>'
            f'<origin xyz="{x} {y} 0"/></joint>')
expanded = "\n".join(wheel(n, x, y) for n, x, y in
                     [("fl", 0.1, 0.1), ("fr", 0.1, -0.1), ("rl", -0.1, 0.1), ("rr", -0.1, -0.1)])
print(expanded.count("<link"), expanded.count('type="continuous"'))   # 4 4
print(len(expanded.splitlines()), "줄 ← 매크로 호출 4줄")              # 8 줄 ← 매크로 호출 4줄
```
