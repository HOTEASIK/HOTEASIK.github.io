# 조인트 타입

## 정의·핵심
- **정의**: URDF `<joint type="…">` — 두 링크가 **어떻게 움직이는지**를 정한다 (실습 4차시).
- **fixed**: 안 움직임 — 센서를 몸통에 단단히 장착. robot_state_publisher가 `/tf_static`으로 한 번 낸다.
- **revolute**: **제한 있는** 회전 — 팔꿈치(각도 한계). `<limit lower upper effort velocity>` 필수. 슬라이더는 lower~upper.
- **continuous**: 제한 없는 회전 — 굴러가는 바퀴.
- **prismatic**: 직선 이동 — 신축 리프트·그리퍼. 한계는 미터.
- (그 밖 URDF 규격: floating·planar — 이 과정에선 다루지 않음)
- **움직이는 조인트는 관절 값이 와야 변환이 나온다**: revolute 아래 arm_link는 `/joint_states`가 오기 전까지 `tf2_echo`가 `frame does not exist`만 되풀이.
- **실습 확인(shoulder, axis y)**: 슬라이더를 끝까지 끌면 Translation은 [0, 0, 0.3] 그대로, RPY 가운데 칸(피치)만 1.570 — `<limit upper="1.57">`에서 멈춘다.
- **도전 ① 그리퍼**: `gripper_joint` prismatic, 부모 arm_link, origin z 0.2(원기둥 길이 0.4의 절반 = 팔 끝), axis x, 0~0.05 m → 슬라이더 둘, `tf2_echo arm_link gripper_link` = [0, 0, 0.200]. lower가 0이라 손잡이는 왼쪽 끝에서 시작.

## 원리·구조
| 타입 | 움직임 | 한계 | 예 | TF 토픽 |
|---|---|---|---|---|
| fixed | 없음 | — | 센서 장착 | /tf_static |
| revolute | 회전 | 라디안 | 팔꿈치 | /tf |
| continuous | 무제한 회전 | 없음 | 바퀴 | /tf |
| prismatic | 직선 | 미터 | 리프트·그리퍼 | /tf |

## 코드 예시
```python
# 조인트 타입별로 슬라이더 값을 한계 안으로 자르기 (joint_state_publisher_gui가 하는 일)
import math
joints = {"shoulder": ("revolute", -1.57, 1.57), "wheel": ("continuous", None, None),
          "gripper_joint": ("prismatic", 0.0, 0.05), "sensor_mount": ("fixed", None, None)}
def clamp(name, v):
    t, lo, hi = joints[name]
    if t == "fixed": return None                      # 슬라이더 없음
    if t == "continuous": return round(math.remainder(v, 2 * math.pi), 3)
    return min(max(v, lo), hi)
print(clamp("shoulder", 2.0), clamp("gripper_joint", -0.1), clamp("wheel", 7.0), clamp("sensor_mount", 1))
# 1.57 0.0 0.717 None
print([n for n, (t, *_) in joints.items() if t != "fixed"])   # ['shoulder', 'wheel', 'gripper_joint']
```
