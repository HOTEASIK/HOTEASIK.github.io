# TF2 오류 해독

## 정의·핵심
- **정의**: TF 관련 메시지·증상을 원인으로 바로 옮기는 표 — 「TF 문제의 대부분은 발행하는 쪽의 문제」 (실습 4차시).
- **`Invalid frame ID "camera" passed to canTransform argument source_frame - frame does not exist`**: 그 프레임을 아무도 발행하지 않았다(오타 `sensr` 포함)·발행자가 아직 안 떴다. **탓하는 이름이 곧 아무도 모르는 프레임**. 발행자를 다 끈 뒤 새로 띄운 tf2_echo는 `"base_link" … target_frame`을 탓한다(base_link조차 모른다). → `ros2 topic echo /tf_static`, view_frames.
- **`Could not find a connection between 'base_link' and 'odom' because they are not part of the same tree. Tf has two or more unconnected trees.`**: 트리가 둘로 나뉨 → view_frames로 끊긴 지점, 중간 변환 발행자를 찾는다.
- **`Lookup would require extrapolation into the future`**: 조회 시점이 가진 변환보다 미래 → 최신 `Time()`으로 조회하거나 발행 주기 점검.
- **값이 일정하게 어긋남(손끝이 매번 같은 양만큼 빗나감)**: static 변환 값 오등록 또는 조회·측정 시점 어긋남 → `tf2_echo base_link camera_link`를 실제 장착 치수와 대조, 측정 시점 타임스탬프로 조회.
- **dynamic 프레임이 멈춰 보임**: broadcaster가 주기 발행을 안 함 → 바뀔 때마다 sendTransform.
- **tf2_echo가 frame does not exist만 되풀이(URDF)**: 관절 상태가 안 들어와 revolute 아래 변환을 못 냄 또는 rsp가 안 떴음 → 슬라이더를 띄우고 `/joint_states` 확인.
- **RViz가 빨갛다 `Frame [map] does not exist`**: Fixed Frame이 트리에 없는 map → base_link 등 루트로. RViz TF 축은 x 빨강·y 초록·z 파랑.
- **display.launch.py `model:=파일이름`만**: urdf_tutorial 패키지 폴더에서 찾아 `FileNotFoundError` … 맨 끝 `AttributeError: module 'xml' has no attribute 'parsers'` — 끝 줄이 아니라 맨 위를 본다. `model:=$HOME/ros2_ws/simple_arm.urdf` 절대경로.
- **「팔이 엉뚱한 곳을 잡으면」**: 트리를 그린다 → 끊긴 곳의 발행자를 찾는다 → RViz TF로 본다.

## 원리·구조
| 메시지 핵심어 | 원인 | 첫 조치 |
|---|---|---|
| frame does not exist | 발행자 없음·오타 | /tf_static echo, view_frames |
| not part of the same tree | 트리 둘 | 끊긴 곳의 중간 변환 |
| extrapolation into the future | 시점이 미래 | Time()로, 주기 점검 |
| (경고 없음) 일정한 오차 | static 값 오등록 | 치수 대조 |
| (경고 없음) 프레임 멈춤 | 주기 발행 안 함 | 타이머로 sendTransform |

## 코드 예시
```python
# TF 오류 한 줄 → 원인·조치
import re
TABLE = [(r'Invalid frame ID "(\w+)".*does not exist', "프레임 '{0}'를 아무도 발행하지 않음(오타?) → view_frames"),
         (r"between '(\w+)' and '(\w+)' because they are not part of the same tree", "'{0}'와 '{1}' 트리가 끊김 → 중간 변환 발행"),
         (r"extrapolation into the future", "조회 시점이 미래 → Time()으로 최신 조회"),
         (r'"(\w+)" passed to lookupTransform argument target_frame does not exist', "새 리스너가 '{0}'를 모름 → 발행자 확인")]
def explain(msg):
    for pat, fix in TABLE:
        m = re.search(pat, msg)
        if m: return fix.format(*m.groups())
    return "표에 없음"
print(explain('Invalid frame ID "camera" passed to canTransform argument source_frame - frame does not exist'))
# 프레임 'camera'를 아무도 발행하지 않음(오타?) → view_frames
print(explain("Could not find a connection between 'base_link' and 'odom' because they are not part of the same tree.Tf has two or more unconnected trees."))
# 'base_link'와 'odom' 트리가 끊김 → 중간 변환 발행
print(explain("Lookup would require extrapolation into the future"))
# 조회 시점이 미래 → Time()으로 최신 조회
```
