# TF 리스너

## 정의·핵심
- **정의**: `/tf`·`/tf_static`을 들어 **버퍼에 쌓아 두고**, 두 좌표계 사이 변환을 조회하는 코드 쪽 도구 — `tf2_ros.Buffer` + `tf2_ros.TransformListener` (실습 4차시).
- **Buffer**: 받은 변환을 시각과 함께 보관. **TransformListener(buffer, node)**: 이 노드가 /tf·/tf_static을 구독해 버퍼를 채운다.
- **`lookup_transform(target, source, time)`**: source 좌표계를 target 기준으로. `rclpy.time.Time()`(시각 0) = 「가진 것 가운데 최신 변환」.
- **예외 셋 — 「변환을 못 찾는다」가 코드에선 이렇게**: `LookupException`(프레임 없음) · `ConnectivityException`(트리가 끊김) · `ExtrapolationException`(조회 시점이 가진 변환 범위 밖). 잡아서 경고 한 줄 남기고 다음 주기를 기다리면 노드가 죽지 않는다.
- **tf_reader.py**: 1초 타이머로 `base_link → sensor` 조회 → `base_link->sensor = (1.0, 0.0, 0.0)`.
- **발행자를 끄면**: 떠 있던 리스너는 static 옛 값을 조용히 계속 쓰고, **새로 띄운** 리스너만 `[WARN] … 변환 조회 실패(트리 끊김 가능): "base_link" passed to lookupTransform argument target_frame does not exist.`
- **켜자마자 조회하면** 버퍼가 아직 비어 첫 몇 번은 실패할 수 있다 — 예외 처리로 넘기거나 `can_transform`/timeout.

## 원리·구조
```
/tf, /tf_static ──▶ TransformListener ──▶ Buffer (시각별 보관)
                                              │
               lookup_transform('base_link', 'sensor', Time())
                                              ▼
                               TransformStamped (translation, rotation)
```

## 코드 예시
```python
# tf_reader.py — base_link -> sensor 변환을 1초마다 조회
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException
from tf2_ros import Buffer, TransformListener
from tf2_ros import LookupException, ConnectivityException, ExtrapolationException


class TfReader(Node):
    def __init__(self):
        super().__init__('tf_reader')
        self._buffer = Buffer()
        self._listener = TransformListener(self._buffer, self)
        self.create_timer(1.0, self._lookup)

    def _lookup(self):
        try:
            tf = self._buffer.lookup_transform(
                'base_link', 'sensor', rclpy.time.Time())   # 최신 변환
            tr = tf.transform.translation
            self.get_logger().info(f'base_link->sensor = ({tr.x}, {tr.y}, {tr.z})')
        except (LookupException, ConnectivityException, ExtrapolationException) as e:
            self.get_logger().warn(f'변환 조회 실패(트리 끊김 가능): {e}')


def main():
    rclpy.init()
    node = TfReader()
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()


if __name__ == '__main__':
    main()
```
```bash
ros2 run my_py_pkg static_sensor_tf     # 터미널 A
ros2 run my_py_pkg tf_reader            # 터미널 B: base_link->sensor = (1.0, 0.0, 0.0)
```
