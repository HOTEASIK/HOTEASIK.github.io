# TF 브로드캐스터

## 정의·핵심
- **정의**: 좌표 변환을 `/tf`·`/tf_static`으로 **내보내는** 코드 쪽 도구 — `tf2_ros.StaticTransformBroadcaster`(고정) / `tf2_ros.TransformBroadcaster`(움직이는) (실습 4차시).
- **메시지**: `geometry_msgs/msg/TransformStamped` — `header.stamp`(시각) · `header.frame_id`(부모) · `child_frame_id`(자식) · `transform.translation.x/y/z` · `transform.rotation.x/y/z/w`.
- **회전 없음 = 단위 쿼터니언** `rotation.w = 1.0` (나머지 0). 각도를 넣으려면 RPY → 쿼터니언 변환.
- **static_sensor_tf.py**: `base_link → sensor` x 1m를 `__init__`에서 한 번 `sendTransform` → 로그 `static TF 발행: base_link -> sensor`. 명령줄 `static_transform_publisher`가 하는 일을 코드로.
- **같은 변환을 두 곳에서 내지 않는다**: 명령줄 static_transform_publisher는 꺼 두고 띄운다 — 한 프레임은 한 발행자.
- **dynamic은 주기마다**: 타이머 콜백에서 시각을 갱신해 매번 `sendTransform`. 안 그러면 「dynamic 프레임이 멈춰 보임」.
- **등록**: entry_points `'static_sensor_tf = my_py_pkg.static_sensor_tf:main'` → `ros2 pkg executables my_py_pkg` 줄 수 확인(모자라면 콤마부터).
- 종료 골격은 lc_talker와 같다(`^C`만, 종료 코드 0).

## 원리·구조
```
TransformStamped
  header.stamp = now
  header.frame_id = 'base_link'      ← 부모
  child_frame_id  = 'sensor'         ← 자식
  transform.translation = (1.0, 0, 0)
  transform.rotation    = (0, 0, 0, 1)
StaticTransformBroadcaster.sendTransform(t) → /tf_static (한 번)
TransformBroadcaster.sendTransform(t)       → /tf (주기마다)
```

## 코드 예시
```python
# static_sensor_tf.py — base_link -> sensor 고정 변환을 한 번 발행
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException
from tf2_ros import StaticTransformBroadcaster
from geometry_msgs.msg import TransformStamped


class StaticSensorTf(Node):
    def __init__(self):
        super().__init__('static_sensor_tf')
        self._br = StaticTransformBroadcaster(self)
        t = TransformStamped()
        t.header.stamp = self.get_clock().now().to_msg()
        t.header.frame_id = 'base_link'        # 부모 좌표계
        t.child_frame_id = 'sensor'            # 자식 좌표계
        t.transform.translation.x = 1.0        # x로 1m 앞
        t.transform.rotation.w = 1.0           # 회전 없음(단위 쿼터니언)
        self._br.sendTransform(t)
        self.get_logger().info('static TF 발행: base_link -> sensor')


def main():
    rclpy.init()
    node = StaticSensorTf()
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()


if __name__ == '__main__':
    main()
```
