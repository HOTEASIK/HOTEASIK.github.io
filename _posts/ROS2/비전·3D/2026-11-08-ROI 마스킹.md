# ROI 마스킹

## 정의·핵심
- **정의**: ROI(Region of Interest, 관심 영역) — 도로가 있을 법한 **화면 아래쪽 사다리꼴만** 남기고 하늘·좌우 건물·나무의 경계는 지운다. 엉뚱한 경계를 차선으로 오인할 위험이 줄고 Hough도 정확해진다 (실습 6차시).
- **구멍 뚫은 검은 종이**: 엣지 영상 위에 도로 모양 구멍의 종이를 덮어 구멍으로 보이는 부분만.
  - `np.zeros_like(edges)` — 같은 크기의 검은 도화지
  - `cv2.fillPoly(mask, roi, 255)` — 사다리꼴만 255로 칠함
  - `cv2.bitwise_and(edges, mask)` — 픽셀끼리 AND: 마스크 0인 자리는 지워지고 255인 자리는 엣지 값 그대로
- **좌표의 뜻**: `(0, h)`·`(w, h)` 화면 왼쪽·오른쪽 아래, `(0.6w, 0.6h)`·`(0.4w, 0.6h)` 위에서 6할 내려온 높이에서 가운데로 좁혀짐 — 원근으로 모이는 도로 모양. 카메라 각도가 다르면 비율을 조정.
  - 합성 프레임 두 선의 위 끝은 y=280, 0.6h는 288 → 위 끝 8픽셀 남짓이 사다리꼴 밖으로 잘린다(그 부분은 원래 색이 남는다).
- **엣지 다음에 건다**: 컬러 원본에 먼저 걸면 Canny가 잘라 낸 사다리꼴 테두리까지 새 엣지로 잡아 가짜 직선을 만들 수 있다. ROI 없이 Hough하면 지평선·가드레일까지 직선으로 섞인다.
- **약해지는 장면**: 가파른 언덕·급커브 — 도로가 사다리꼴 밖으로 나간다.
- **색 마스킹도 같은 원리**: `cv2.inRange`로 만든 마스크를 `bitwise_and(frame, frame, mask=color_mask)` — 흑백 앞, 색이 살아 있는 컬러에서.

## 원리·구조
```
edges            mask(사다리꼴=255)        masked = edges AND mask
■■□□■■□□        □□□□□□□□                □□□□□□□□
□■■□□■■□   AND  □□□■■□□□           =    □□□□□□□□
□□■■■■□□        □■■■■■■□                □□■■■■□□
```

## 코드 예시
```python
# 위쪽 잡음 선과 아래쪽 차선이 섞인 엣지에서 ROI가 위쪽만 지우는지
import cv2
import numpy as np
h, w = 480, 640
edges = np.zeros((h, w), dtype=np.uint8)
cv2.line(edges, (0, 100), (639, 100), 255, 1)          # 하늘·지평선 같은 위쪽 잡음
cv2.line(edges, (200, 479), (300, 300), 255, 1)        # 차선
mask = np.zeros_like(edges)
roi = np.array([[(0, h), (w, h), (int(w*0.6), int(h*0.6)), (int(w*0.4), int(h*0.6))]])
cv2.fillPoly(mask, roi, 255)
masked = cv2.bitwise_and(edges, mask)
print(roi.tolist())                     # [[[0, 480], [640, 480], [384, 288], [256, 288]]]
print(int((edges[100] > 0).sum()), int((masked[100] > 0).sum()))   # 640 0  ← 위쪽 잡음은 지워졌다
print(int((edges[400] > 0).sum()), int((masked[400] > 0).sum()))   # 1 1    ← 차선은 남았다
print(int(h * 0.6))                     # 288  ← 합성 선 위 끝 y=280은 사다리꼴 밖
```
