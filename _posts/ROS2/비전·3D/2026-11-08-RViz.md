# RViz

## 정의·핵심
- **정의**: RViz(rviz2) — 토픽으로 흐르는 데이터(점구름·TF·지도·로봇 모델 등)를 **3D 화면에 그려 주는 ROS 표준 시각화 도구**. `ros2 run rviz2 rviz2` (실습 7차시).
- **Display 추가**: 왼쪽 아래 **Add → By topic** 탭 → `/points` 아래 `PointCloud2` 고르고 OK. 토픽이 늦게 떴으면 목록에 없다 — 창을 다시 연다.
- **Fixed Frame**(Global Options): 화면의 기준 좌표계. 처음 띄운 RViz는 `map`. 점의 `header.frame_id`와 같으면 변환 없이 그린다.
  - 다르면(예: `base_link`) — 메시지는 계속 받지만(`Topic ✓ 31 messages received`) `Showing [0] points`, `Transform ✗ Could not transform from…`, PointCloud2 줄이 빨간 `Status: Error`. 토픽은 그대로 흐르는데 화면만 빈다.
- **Global Status: W…(주황)** 를 펼치면 `No tf data.` — TF를 알려 주는 노드가 없다는 경고. 점의 frame_id와 Fixed Frame이 둘 다 map이면 넘겨도 된다. **볼 것은 PointCloud2 줄의 `Status: Ok`**.
- **Size (m)**: 점 크기, 처음 값 0.01 — 안 보이면 키운다. 마우스로 끌어 시점을 돌린다(옆·위에서).
- **결과를 색으로 나눠 보기**: Display를 펼쳐 `Color Transformer`를 `FlatColor`로 → 바로 아래 `Color`를 토픽마다 다르게(/ground 회색, /objects 빨강). 코드는 손대지 않는다.
- **「RViz에 안 보여요」 단골 셋**: 프레임 불일치 → Size 과소 → 시점 이탈. 그 전에 **데이터 단계**(`ros2 topic hz /points`)와 **표시 단계**를 나눈다.
- **창이 안 뜨면**: `qt.qpa.xcb: could not connect to display` … `[ros2run]: Aborted` — `echo $DISPLAY`가 빈 줄이면 화면 없는 터미널. RViz는 화면을 보는 도구라 offscreen으로 띄우지 않는다 → 데스크톱 터미널에서.

## 원리·구조
```
/points (frame_id=map) ──▶ RViz Display(PointCloud2)
                               │ Fixed Frame == frame_id ?  → 그대로 그림
                               │ 다르면 TF로 frame_id → Fixed Frame 변환
                               └ TF 없음 → Transform ✗, Showing [0]
```

## 코드 예시
```python
# RViz가 점을 그릴지 정하는 규칙 흉내: Fixed Frame과 frame_id, TF 유무
def rviz_show(n_points, frame_id, fixed_frame, tf_pairs=()):
    if frame_id == fixed_frame or (frame_id, fixed_frame) in tf_pairs:
        return f"Status: Ok  Showing [{n_points}]"
    return f"Status: Error  Showing [0]  Could not transform from [{frame_id}] to [{fixed_frame}]"
print(rviz_show(14000, "map", "map"))
print(rviz_show(14000, "map", "base_link"))
print(rviz_show(14000, "map", "base_link", tf_pairs={("map", "base_link")}))
# Status: Ok  Showing [14000]
# Status: Error  Showing [0]  Could not transform from [map] to [base_link]
# Status: Ok  Showing [14000]
```
```bash
ros2 run rviz2 rviz2
ros2 topic hz /points          # 데이터 단계부터
echo $DISPLAY                  # 빈 줄이면 화면 없는 터미널
```
