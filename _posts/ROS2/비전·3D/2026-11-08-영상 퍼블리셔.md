# 영상 퍼블리셔

## 정의·핵심
- **정의**: `/camera/image_raw`로 영상(파일 또는 합성 프레임)을 타이머 주기로 발행하는 입력 노드 `camera_publisher` — 카메라 없이도 토픽이 흐르게 한다 (실습 6차시).
- **왜 먼저 만드나**: 구독자는 본디 수동적 — 발행자가 없으면 콜백이 한 번도 안 불리고 **경고도 없다**. 처음 영상 노드에서 가장 흔한 막힘.
- **두 길**: 영상 파일이 있으면 `cv2.VideoCapture`로 한 프레임씩, 없으면 코드 안에서 **합성 프레임**(검은 바탕에 왼쪽 노랑·오른쪽 흰 차선). 만드는 노드와 처리하는 노드를 나눠 두면 입력을 진짜 카메라·시뮬레이터로 갈아 끼워도 처리 노드는 그대로.
- **타이머**: `create_timer(1.0 / 15.0, self.tick)` — 15Hz. 30Hz로 바꾸면 `average rate: 29.968`, 간격 0.066→0.033초. 주기는 타이머 간격의 역수, 받는 쪽 부담도 두 배.
- **경로는 `os.path.expanduser`**: `~`를 홈으로 푸는 것은 셸이지 OpenCV가 아니다 — `cv2.VideoCapture('~/lane.mp4')`는 파일이 있어도 못 열고 `Error opening bin: syntax error`.
- **자동 폴백·되감기**: 못 열면 `[WARN] … 영상 파일을 못 열어 합성 프레임을 발행합니다.` · 영상 끝이면 `CAP_PROP_POS_FRAMES`를 0으로 되감기 · 그래도 실패하면 합성 — 「토픽이 멈추면 받는 노드가 공회전」을 막는 안전망.
- **헤더를 채운다**: `header.stamp = now`, `header.frame_id = 'camera'` — 여러 센서를 시각으로 맞추거나 영상 속 위치를 로봇 좌표로 바꿀 때 필요.
- **종료 골격**: `try: spin / except (KeyboardInterrupt, ExternalShutdownException) / finally: destroy_node; try_shutdown` → `^C`만 남고 종료 코드 0. 옛 꼴(`spin` 뒤 `shutdown`)은 트레이스백 + `[ros2run]: Interrupt`(254).
- **등록**: `'camera_publisher = my_py_pkg.camera_publisher:main'` — 있던 줄 아래 · 앞 줄 끝 콤마 · 먼저 `cp setup.py setup.py.bak`. 빌드는 워크스페이스 루트에서.

## 원리·구조
```
__init__: bridge · pub(Image,'/camera/image_raw',10) · VideoCapture(expanduser) · timer(1/15)
tick    : frame = 영상 read() ─실패→ 되감기 ─실패→ make_synthetic()
          msg = cv2_to_imgmsg(frame,'bgr8'); header.stamp/frame_id; publish
```

## 코드 예시
```python
# camera_publisher.py — /camera/image_raw 로 영상(또는 합성 프레임)을 15Hz 발행
import os
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2
import numpy as np


class CameraPublisher(Node):
    def __init__(self):
        super().__init__('camera_publisher')
        self.bridge = CvBridge()
        self.pub = self.create_publisher(Image, '/camera/image_raw', 10)
        self.video_path = os.path.expanduser('~/lane.mp4')
        self.cap = cv2.VideoCapture(self.video_path)
        self.use_video = self.cap.isOpened()
        if not self.use_video:
            self.get_logger().warn('영상 파일을 못 열어 합성 프레임을 발행합니다.')
        self.timer = self.create_timer(1.0 / 15.0, self.tick)

    def make_synthetic(self):
        frame = np.zeros((480, 640, 3), dtype=np.uint8)
        cv2.line(frame, (200, 480), (300, 280), (0, 255, 255), 6)    # 노랑 — BGR 순서
        cv2.line(frame, (440, 480), (340, 280), (255, 255, 255), 6)  # 흰색
        return frame

    def tick(self):
        frame = None
        if self.use_video:
            ok, frame = self.cap.read()
            if not ok:
                self.cap.set(cv2.CAP_PROP_POS_FRAMES, 0)
                ok, frame = self.cap.read()
                if not ok:
                    frame = None
        if frame is None:
            frame = self.make_synthetic()
        msg = self.bridge.cv2_to_imgmsg(frame, encoding='bgr8')
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = 'camera'
        self.pub.publish(msg)


def main():
    rclpy.init()
    node = CameraPublisher()
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()


if __name__ == '__main__':
    main()
```
