# 차선 검출 파이프라인

## 정의·핵심
- **정의**: 오랫동안 다듬어진 고전 차선 검출의 다섯 단계 — **grayscale → Canny → ROI → Hough → overlay**. 노드 `lane_detector`의 콜백 안에 그대로 줄지어 들어간다 (실습 6차시).
  - ① 흑백 — 색을 버린다(채널 셋→하나, 계산이 가볍다)
  - ② Canny — 경계만 남긴다
  - ③ ROI — 도로만 본다
  - ④ HoughLinesP — 직선을 찾는다
  - ⑤ overlay — 원본 컬러 위에 빨강으로 그려 `/lane/overlay`로 발행
- **순서는 의존 관계**: 흑백이어야 Canny가 한 채널에서 경계를 잡고, 경계가 있어야 ROI가 「경계 점 중 도로」를 남기고, 좁혀야 Hough가 엉뚱한 직선에 안 흔들린다. ROI를 컬러 원본에 먼저 걸면 사다리꼴 테두리가 가짜 엣지가 된다.
- **자료형 변화**: (세로,가로,3) 컬러 → (세로,가로) 밝기 → 0/255 이진 → 직선 좌표 목록 → 다시 컬러 위 선. 포장하는 것은 컬러 `frame`이라 bgr8 — `edges`를 bgr8로 포장하면 `incompatible type 8UC1`.
- **방어적 코딩**: 직선이 하나도 없는 프레임에선 `lines`가 `None` → 검사 없이 `lines[:, 0]`이면 `TypeError: 'NoneType' object is not subscriptable`로 노드 전체가 죽는다 → `if lines is not None:`.
- **헤더 옮기기**: `out.header = msg.header` — 빼면 stamp 0·frame_id `''`.
- **결과**: 노란·흰 선 위에 빨간 선(빨간 픽셀 왼쪽 1782·오른쪽 1948), `/lane/overlay` hz ≈ 입력(14.990) — 제때 처리 중. 원본 토픽 `Subscription count: 2`(viewer·lane_detector).
- **파일로 한 번만 저장**: 깃발 `self.saved` + `ok = cv2.imwrite(path, frame)` 반환값 로그. `/root/…`는 `permission denied` 경고 + False, `'~/…'`는 경고 없이 False — 노드는 멀쩡히 돈다.
- **한계와 보강**: 밝기 가정(바랜 차선·그림자·역광) → 색 마스킹, 직선 가정(급커브) → 2차 곡선 피팅, 흔들림 → 칼만 필터. 딥러닝(의미 분할·LaneATT·YOLO)으로 바꿔도 콜백 안 코드만 바뀌고 cv_bridge·구독·발행 골격은 같다.

## 원리·구조
```
frame(480,640,3) ─gray─▶ (480,640) ─Canny(50,150)─▶ 0/255 ─ROI 사다리꼴 AND─▶ masked
   ─HoughLinesP(1, π/180, 50, minLineLength=40, maxLineGap=20)─▶ lines (N,1,4)
   ─cv2.line 빨강─▶ frame ─cv2_to_imgmsg('bgr8')─▶ /lane/overlay
```

## 코드 예시
```python
# 합성 프레임으로 다섯 단계를 끝까지 — 단계마다 모양과 결과
import cv2
import numpy as np
frame = np.zeros((480, 640, 3), dtype=np.uint8)
cv2.line(frame, (200, 480), (300, 280), (0, 255, 255), 6)
cv2.line(frame, (440, 480), (340, 280), (255, 255, 255), 6)
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)                      # ①
edges = cv2.Canny(gray, 50, 150)                                    # ②
h, w = edges.shape
mask = np.zeros_like(edges)                                         # ③
roi = np.array([[(0, h), (w, h), (int(w*0.6), int(h*0.6)), (int(w*0.4), int(h*0.6))]])
cv2.fillPoly(mask, roi, 255)
masked = cv2.bitwise_and(edges, mask)
lines = cv2.HoughLinesP(masked, 1, np.pi/180, 50, minLineLength=40, maxLineGap=20)   # ④
print(frame.shape, gray.shape, sorted(set(np.unique(edges).tolist())))   # (480, 640, 3) (480, 640) [0, 255]
print(lines is not None, lines.shape[1:], lines.dtype)              # True (1, 4) int32  ← (직선 수, 1, 4)
if lines is not None:                                               # ⑤
    for x1, y1, x2, y2 in lines[:, 0]:
        cv2.line(frame, (int(x1), int(y1)), (int(x2), int(y2)), (0, 0, 255), 3)
red = np.all(frame == (0, 0, 255), axis=2)
print(red[:, :320].sum() > 0, red[:, 320:].sum() > 0)               # True True  ← 두 선 모두 잡혔다
blank = cv2.Canny(np.zeros((480, 640), np.uint8), 50, 150)
print(cv2.HoughLinesP(blank, 1, np.pi/180, 50, minLineLength=40, maxLineGap=20))   # None ← 검사가 필요한 까닭
```
