# Hough 직선 변환

## 정의·핵심
- **정의**: 남은 경계 점 가운데 **한 줄로 늘어선 직선**을 찾는 변환. 점들이 직접 직선을 그리게 하지 않고, 각 점이 자기를 지날 수 있는 직선들에 **한 표씩 던지게** 한다 (실습 6차시).
- **투표**: 경계 점 하나를 지나는 직선은 무수히 많다 → 한 직선에 점이 늘어서면 그 직선에만 표가 몰린다 → 표가 문턱(50)을 넘은 직선을 진짜로 채택.
- **`cv2.HoughLinesP(masked, 1, np.pi/180, 50, minLineLength=40, maxLineGap=20)`**: P(확률적) 판 — 표본을 써서 빠르고 **양 끝점 좌표**를 바로 돌려준다.
  - `1`·`np.pi/180` — 거리 ρ 1픽셀, 각도 θ 1도 간격의 투표함
  - `50` — 채택 문턱(표 수)
  - `minLineLength` — 너무 짧은 선분을 버리는 기준(너무 짧게 → 잡음 선이 섞임)
  - `maxLineGap` — 같은 직선으로 이어 줄 점 사이 최대 간격(너무 크게 → 떨어진 선까지 무리하게 잇는다). 점선 차선 영상에서 차이가 보인다.
- **돌려주는 것**: 영상이 아니라 `(직선 수, 1, 4)` 배열 — 마지막 넷이 `x1, y1, x2, y2`. 하나도 없으면 **`None`** → `if lines is not None:`.
- **한 선이 여러 선분으로**: Hough는 한 차선을 여러 선분으로 쪼개 돌려줄 수 있다 → 끝점 평균으로 구한 오차가 계산(0.19)과 실측(0.17)이 조금 다른 까닭.
- **가정**: 차선이 직선에 가깝다 — 많이 굽은 길에선 약하다(→ 2차 곡선 피팅).

## 원리·구조
```
직선:  ρ = x·cosθ + y·sinθ
점 (x, y) 하나 → (θ, ρ) 평면의 곡선 하나 → 곡선들이 한 점에서 겹치는 (θ, ρ) = 그 점들을 다 지나는 직선
누적 배열 acc[θ][ρ] += 1  →  acc ≥ threshold 인 칸이 직선
```

## 코드 예시
```python
# 투표 원리를 손으로: 한 직선 위 점들은 같은 (θ, ρ) 칸에 표가 몰린다
import math
from collections import Counter
pts = [(x, 2 * x + 10) for x in range(0, 50, 5)] + [(7, 90), (33, 3)]   # 직선 위 10점 + 잡음 2점
votes = Counter()
for x, y in pts:
    for deg in range(0, 180):
        t = math.radians(deg)
        votes[(deg, round(x * math.cos(t) + y * math.sin(t)))] += 1
(best, n), = votes.most_common(1)
print(best, n)          # (153, 5) 10  ← 직선 위 10점이 한 칸에 몰렸다, 잡음 2점은 못 끼었다
```
```python
# OpenCV HoughLinesP: 끝점 배열을 돌려주고, 직선이 없으면 None
import cv2
import numpy as np
img = np.zeros((200, 200), np.uint8)
cv2.line(img, (20, 180), (120, 30), 255, 1)
lines = cv2.HoughLinesP(img, 1, np.pi / 180, 50, minLineLength=40, maxLineGap=20)
print(lines.shape[1:], len(lines) >= 1)          # (1, 4) True
x1, y1, x2, y2 = lines[0, 0]
print(abs(int(x2) - int(x1)) > 40)               # True  ← 끝점 좌표를 바로 준다
print(cv2.HoughLinesP(np.zeros((200, 200), np.uint8), 1, np.pi / 180, 50))   # None
```
