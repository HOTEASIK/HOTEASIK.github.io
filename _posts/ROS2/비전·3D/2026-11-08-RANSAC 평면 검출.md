# RANSAC 평면 검출

## 정의·핵심
- **정의**: 점구름 속에서 **하나의 평면 위에 가장 많이 모인 점**(바닥·벽)을 찾는다 — Open3D `pcd.segment_plane(distance_threshold, ransac_n, num_iterations)` (실습 7차시).
- **RANSAC(RANdom SAmple Consensus)**: ① 무작위로 세 점을 골라 평면 하나를 가정 → ② 그 평면에 충분히 가까운 점(**인라이어**)이 몇 개인지 헤아림 → ③ 수백~수천 번 반복해 가장 많은 점이 **동의한** 평면을 고른다. 멀리 떨어진 점은 아웃라이어.
- **왜 강한가**: 잡음이 섞여도 진짜 바닥엔 압도적으로 많은 점이 동의한다 — 바닥을 빼고 남은 점이 곧 물체.
- **왜 무작위인가**: 세 점 조합이 너무 많아 전부 검사할 수 없다. 충분히 시도하면 한 번쯤은 바닥 위 세 점을 뽑는다 → 같은 입력에서도 실행마다 바닥 점 수가 조금씩 다르다(1900~3200). 고칠 것이 아니다.
- **전제**: 바닥 점이 전체에서 충분한 비중을 차지해야 한다.
- **세 인자**:
  - `distance_threshold`(0.01 = 1cm) — 작으면 바닥이 쪼개지고, 크면 낮은 물체까지 빨려 든다. 실측: 바닥 잡음(σ 0.005)이 1cm 밖으로 튀어 물체 쪽 65~369점, 정육면체 자리 314~324점은 거의 일정.
  - `ransac_n`(3) — 평면은 세 점이면 결정.
  - `num_iterations`(1000) — 키우면 안정적이지만 계산이 는다. 10·100·1000·5000 모두 평면은 늘 바닥이었다.
- **돌려주는 것**: `plane` = ax+by+cz+d=0의 (a,b,c,d), `(a,b,c)`가 법선 — 바닥이면 |c|가 1 근처(위를 향함), 벽이면 a나 b가 크다. `inliers` = 인덱스 → `select_by_index(inliers)` / `invert=True`.
- `segment_plane`은 **가장 큰 평면 하나만** — 벽까지 떼려면 반복.
- 물체 0점·바닥 0점이면 distance_threshold부터(1cm 근처).

## 원리·구조
```
반복 k번:  (p1,p2,p3) 무작위 → n = (p2−p1)×(p3−p1)/|…|,  d = −n·p1
           inliers = { i : |n·xi + d| < threshold }
가장 큰 inliers의 평면 채택 → 바닥 = inliers, 물체 = 나머지
```

## 코드 예시
```python
# numpy로 RANSAC: 바닥 + 정육면체 장면에서 바닥 평면 찾기
import numpy as np
rng = np.random.default_rng(0)
ground = rng.uniform(-1, 1, (3000, 3)); ground[:, 2] = rng.normal(0, 0.005, 3000)
cube = rng.uniform(0, 0.3, (500, 3)); cube[:, 2] += 0.1
xyz = np.vstack([ground, cube])
def segment_plane(p, threshold=0.01, iters=200):
    best_in, best_plane = None, None
    for _ in range(iters):
        a, b, c = p[rng.choice(len(p), 3, replace=False)]
        n = np.cross(b - a, c - a)
        if np.linalg.norm(n) < 1e-9: continue
        n = n / np.linalg.norm(n); d = -n @ a
        inl = np.nonzero(np.abs(p @ n + d) < threshold)[0]
        if best_in is None or len(inl) > len(best_in):
            best_in, best_plane = inl, (*n, d)
    return best_plane, best_in
plane, inliers = segment_plane(xyz)
objects = np.delete(xyz, inliers, axis=0)
print(round(abs(plane[2]), 2))                                   # 1.0  ← |c|가 1: 법선이 위, 바닥
print(len(inliers) > 2500, len(objects))                         # True 650
print(int((objects[:, 2] > 0.07).sum()))                         # 500  ← 남은 650 중 정육면체 500, 나머지 150은 1cm 밖으로 튄 바닥 잡음
```
```text
plane, inliers = pcd.segment_plane(distance_threshold=0.01, ransac_n=3, num_iterations=1000)
ground = pcd.select_by_index(inliers)
objects = pcd.select_by_index(inliers, invert=True)
```
