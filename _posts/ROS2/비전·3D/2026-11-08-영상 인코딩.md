# 영상 인코딩

## 정의·핵심
- **정의**: `encoding` — 색을 어떤 순서로 몇 비트로 적었는지 알려 주는 약속. cv_bridge 두 함수에 넘기는 `'bgr8'` 따위 (실습 6차시).
- **대표 넷**:
  - `bgr8` — 파랑·초록·빨강 각 8비트(0~255), OpenCV 기본 순서. 일반 컬러에서 가장 널리.
  - `rgb8` — 순서만 뒤집힘.
  - `mono8` — 흑백, 밝기 채널 하나.
  - `32FC1` — 32비트 실수 채널 하나(깊이 영상, m 단위) → `passthrough`로 받는다.
- **OpenCV 자료형 이름**: `8UC1`(8비트·채널 1) · `8UC3`(채널 3) · `32FC1`.
- **어긋나면 두 가지 — 꼴이 다르다**:
  - **받을 때**(imgmsg_to_cv2) 색 순서가 틀리면 **멈추지 않고 색만 바뀐다** — 오류 한 줄 없음. 노란 선 픽셀 bgr8 `[0, 255, 255]` · rgb8 `[255, 255, 0]` → imshow는 BGR로 읽어 하늘색(시안). 흰 선은 세 값이 다 255라 그대로(픽셀 차이 합 0). 흑백·컬러를 바꿔 풀어도 cv_bridge가 변환해 준다.
  - **보낼 때**(cv2_to_imgmsg) 배열과 이름이 어긋나면 **그 자리에서 멈춘다** — `CvBridgeError: encoding specified as bgr8, but image has incompatible type 8UC1`(흑백 배열을 bgr8로) / `…8UC3`(컬러를 mono8로).
- 조용히 틀리는 쪽(받는 쪽)이 더 무섭다 — 색을 보고서야 안다.
- **고르는 기준**: 형식을 알면 그 이름 직접(`'bgr8'`), 모르거나 원본 보존이면 `'passthrough'`, 망설여지면 `ros2 topic echo <토픽> --field encoding --once`(→ `bgr8`). passthrough로 흑백을 받아 `COLOR_BGR2GRAY`를 대면 `cv2.error`.
- **포장할 배열의 채널 수를 보고 이름을 고른다**: 컬러 frame → bgr8, 중간 결과 gray·edges → mono8.

## 원리·구조
| 인코딩 | OpenCV 형 | 채널 | 쓰임 |
|---|---|---|---|
| bgr8 | 8UC3 | 3 | 일반 컬러(OpenCV 기본) |
| rgb8 | 8UC3 | 3 | 일부 GUI·딥러닝 |
| mono8 | 8UC1 | 1 | 흑백·엣지 |
| 32FC1 | 32FC1 | 1 | 깊이(m) |

## 코드 예시
```python
# 받을 때 순서가 틀리면 색만 바뀌고, 보낼 때 채널이 틀리면 멈춘다 — 흉내
import numpy as np
yellow_bgr = np.array([0, 255, 255], dtype=np.uint8)
white = np.array([255, 255, 255], dtype=np.uint8)
print(yellow_bgr[::-1].tolist(), white[::-1].tolist())    # [255, 255, 0] [255, 255, 255]
CH = {"bgr8": 3, "rgb8": 3, "mono8": 1}
def cv2_to_imgmsg(arr, enc):
    ch = 1 if arr.ndim == 2 else arr.shape[2]
    if ch != CH[enc]:
        raise ValueError(f"encoding specified as {enc}, but image has incompatible type 8UC{ch}")
    return "ok"
gray = np.zeros((480, 640), dtype=np.uint8)
print(cv2_to_imgmsg(gray, "mono8"))                      # ok
try:
    cv2_to_imgmsg(gray, "bgr8")
except ValueError as e:
    print(e)          # encoding specified as bgr8, but image has incompatible type 8UC1
```
```bash
ros2 topic echo /camera/image_raw --field encoding --once
```
