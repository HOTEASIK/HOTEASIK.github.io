# 복셀 다운샘플링

## 정의·핵심
- **정의**: 공간을 작은 정육면체 격자(**voxel** = volume + pixel, 3D 공간의 한 칸)로 나누고 칸마다 점을 하나(보통 평균 위치)만 남겨 점 개수를 줄인다 — Open3D `pcd.voxel_down_sample(voxel_size)` (실습 7차시).
- **왜**: 점이 수만~수십만이면 이후 모든 연산이 점 개수에 비례해 느려진다. RANSAC은 반복마다 전체 점과의 거리를 계산한다.
- **언제**: 평면·물체 같은 무거운 연산 **직전에 한 번** — 「무거운 연산 앞에서 데이터를 먼저 가볍게」.
- **손잡이 하나 — `voxel_size`(격자 한 변, m)**: 정밀도와 속도의 균형.
  - 격자가 물체보다 크면 물체 전체가 한 칸에 빨려 들어가 점 하나로 뭉개진다.
  - 너무 작으면 거의 줄지 않는다.
  - 0.3 m 정육면체엔 5cm가 무난.
- **실측(14000점 장면)**:

| voxel_size | 다운샘플 뒤 | 바닥 | 물체 | 시간 |
|---|---|---|---|---|
| 0.5 (50cm) | 29 | 22 | 7 | 0.7 ms |
| 0.05 (5cm) | 2918 | 2401 | 517 | 1.3 ms |
| 0.01 (1cm) | 13066 | 10515 | 2551 | 4.2 ms |
| 없음 | 14000 | 10993 | 3007 | 1.9 ms |

  - 0.5는 정육면체보다 커 물체가 7점으로 뭉개졌다. 이 장면에선 모두 5 ms 아래 — 다운샘플을 뺀 쪽이 0.01보다 빠르기까지(격자 나누기에도 값이 든다). 속도 이득은 점이 수십만 개일 때 벌어진다.
- **이웃 간격이 바뀐다**: 5cm 격자 뒤 남은 점끼리 간격도 5cm 안팎 → DBSCAN의 eps를 0.05로 두면 이웃을 못 찾는다(→ [[DBSCAN 클러스터링]]).

## 원리·구조
```
칸 번호 = floor((점 − 최소점) / voxel_size)  →  같은 번호끼리 묶어 평균  →  칸 수 = 남은 점 수
```

## 코드 예시
```python
# numpy로 복셀 다운샘플: 같은 칸의 점을 평균 하나로
import numpy as np
rng = np.random.default_rng(0)
n = 12000
ground = rng.uniform(-1.0, 1.0, size=(n, 3)); ground[:, 2] = rng.normal(0.0, 0.005, size=n)
cube = rng.uniform(0.0, 0.3, size=(n // 6, 3)); cube[:, 2] += 0.1
xyz = np.vstack([ground, cube])
def voxel_down(p, size):
    idx = np.floor((p - p.min(axis=0)) / size).astype(np.int64)
    _, inv = np.unique(idx, axis=0, return_inverse=True)
    inv = inv.ravel()
    sums = np.zeros((inv.max() + 1, 3)); np.add.at(sums, inv, p)
    return sums / np.bincount(inv)[:, None]
for size in (0.5, 0.05, 0.01):
    d = voxel_down(xyz, size)
    print(size, len(d), int((d[:, 2] > 0.07).sum()))        # 남은 점 · 바닥 위로 높은 점(물체 쪽)
# 0.5 16 1        ← 정육면체가 점 하나로 뭉개졌다
# 0.05 1850 251
# 0.01 13145 1934 ← 거의 안 줄었다
```
```text
pcd = pcd.voxel_down_sample(0.05)     # Open3D 한 줄
```
