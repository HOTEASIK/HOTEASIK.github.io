# 차선 추종 제어

## 정의·핵심
- **정의**: 차선 검출 노드가 차선 중앙의 **오차**를 숫자 토픽 `/lane/offset`(std_msgs/Float32)으로 내보내고, 제어 노드 `lane_follower`가 그 숫자를 조향 명령 `/cmd_vel`(geometry_msgs/Twist)로 바꾼다 — 인지의 출력이 제어의 입력이 된다 (실습 6차시).
- **오차 계산(lane_detector 안, 직선이 있을 때만)**: `xs = lines[:, 0, [0, 2]]`(모든 선분의 x1·x2) → `center = float(xs.mean())` → `offset = (center - w/2) / (w/2)` — **-1(왼쪽 끝) ~ +1(오른쪽 끝)**.
- **규칙 — 차선 가운데 쪽으로 튼다**: 차선 가운데가 화면 오른쪽(+) = 로봇이 차선 왼쪽으로 치우침 → 오른쪽으로. ROS에서 오른쪽 회전은 `angular.z` **음수** → `cmd.angular.z = -gain * offset`.
- **비례 제어**: 오차가 크면 크게, 작으면 작게. `speed`(0.5)·`gain`(1.0)을 파라미터로 — 로봇·영상마다 맞는 값이 다르다. 현장은 오차 변화까지 보는 PID 따위.
- **실측**: 합성 프레임(좌우 대칭)에서 `data: 0.0299…` → `angular.z: -0.0299…`, `linear.x: 0.5` — 0이 아닌 까닭은 Hough가 선을 쪼개는 방식·ROI에 잘리는 정도의 몫. 차선을 +60 옮기면 계산 (260+360+500+400)/4 = 380 → +0.19, 실측 +0.17 → 거북이가 시계 방향으로 감긴다(theta −0.30 → −0.83 → −1.35 → −1.88).
- **노드를 나눈 값**: 차선 찾는 방법(색 마스킹·학습 모델)이 바뀌어도, 로봇이 바뀌어도 `/lane/offset`이라는 숫자 약속만 같으면 다른 쪽은 손대지 않는다.
- **거북이에 잇기**: `ros2 run my_py_pkg lane_follower --ros-args -r /cmd_vel:=/turtle1/cmd_vel` — 코드 그대로 이름만 리맵. 여기까진 고리의 앞부분(보고 → 명령), 카메라가 로봇과 함께 움직여야 닫힌다.

## 원리·구조
```
/camera/image_raw ─▶ lane_detector ─/lane/offset (Float32, -1~+1)─▶ lane_follower ─/cmd_vel─▶ 로봇
                                                             linear.x = speed
                                                             angular.z = -gain × offset
```

## 코드 예시
```python
# 끝점 → 오차 → 회전 명령 (lines 모양 (N,1,4) 그대로)
import numpy as np
w = 640
def offset_of(lines):
    xs = lines[:, 0, [0, 2]]
    center = float(xs.mean())
    return (center - w / 2) / (w / 2)
def cmd(offset, speed=0.5, gain=1.0):
    return {"linear.x": speed, "angular.z": round(-gain * offset, 4)}
sym = np.array([[[200, 480, 300, 280]], [[440, 480, 340, 280]]])        # 좌우 대칭 차선
moved = sym + np.array([60, 0, 60, 0])                                  # +60 옮김
for name, ls in (("대칭", sym), ("+60", moved)):
    off = offset_of(ls)
    print(name, round(off, 4), cmd(off))
# 대칭 0.0 {'linear.x': 0.5, 'angular.z': -0.0}
# +60 0.1875 {'linear.x': 0.5, 'angular.z': -0.1875}   ← 차선이 오른쪽 → 오른쪽(음수)으로
```
```python
# lane_follower.py 핵심
import rclpy
from rclpy.node import Node
from std_msgs.msg import Float32
from geometry_msgs.msg import Twist


class LaneFollower(Node):
    def __init__(self):
        super().__init__('lane_follower')
        self.declare_parameter('speed', 0.5)
        self.declare_parameter('gain', 1.0)
        self.pub = self.create_publisher(Twist, '/cmd_vel', 10)
        self.create_subscription(Float32, '/lane/offset', self.cb, 10)

    def cb(self, msg):
        cmd = Twist()
        cmd.linear.x = self.get_parameter('speed').value
        cmd.angular.z = -self.get_parameter('gain').value * msg.data   # 오른쪽(+) → 오른쪽 회전(음수)
        self.pub.publish(cmd)
```
```bash
ros2 run my_py_pkg lane_follower --ros-args -r /cmd_vel:=/turtle1/cmd_vel
ros2 topic echo /lane/offset --once
ros2 topic echo /cmd_vel --once
```
