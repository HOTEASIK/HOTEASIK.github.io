# Canny 엣지

## 정의·핵심
- **정의**: `cv2.Canny(gray, 50, 150)` — 흑백 영상에서 **밝기가 급격히 바뀌는 경계선만** 골라 0/255 이진 영상으로 남긴다. 차선은 도로 바닥과 밝기 차이가 커서 또렷한 선으로 잡힌다 (실습 6차시).
- **임계값 둘 — 이력 임계화(hysteresis)**: 선 하나로 자르면 그 근처에서 경계가 들쭉날쭉 끊긴다.
  - 높은 값(150)을 넘으면 → 강한 경계, 무조건 채택
  - 낮은 값(50)~높은 값 사이 → 약한 경계, 강한 경계에 이어져 있을 때만 살림
  - 낮은 값 아래 → 버림
  - 또렷한 차선은 끊김 없이 이어지고 배경 잡음은 걸러진다. 높은 값을 낮은 값의 두세 배로 두는 것이 무난한 출발점.
- **⚠ 문턱의 단위는 밝기 차이가 아니라 기울기**: 이웃 몇 픽셀(Sobel)로 계산한 「밝기가 얼마나 가파르게 바뀌나」에 댄다. 실습에서 밝기 계단 차이 10·13·20·30은 경계 0픽셀, 40·60·183은 모두 같은 60픽셀 — 「차이가 150을 넘어야 경계」가 아니다.
- **흑백 다음에**: 밝기 채널 하나에서 경계를 깔끔히 잡는다.
- **임계값 손대기**: 너무 낮게 → 도로 미세 무늬까지 지저분, 너무 높게 → 흐릿한 차선이 통째로 사라짐. 합성 프레임(검은 바탕)에선 canny_low 80·300·1000에서 그대로, 3000에서야 사라졌다 — 실제 도로는 더 낮은 값에서 흐려진다.
- **파라미터로**: `declare_parameter('canny_low', 50)` → 콜백에서 `get_parameter('canny_low').value` → 띄운 채 `ros2 param set /lane_detector canny_low 80`(`Set parameter successful`) — 다시 빌드 없이 다음 프레임부터 반영.

## 원리·구조
```
gray ─Sobel─▶ 기울기 크기·방향 ─비최대 억제(가늘게)─▶ 이력 임계화(low, high) ─▶ edges(0/255)
```

## 코드 예시
```python
# 밝기 계단의 차이를 바꿔 가며 Canny(50,150)가 잡는 경계 픽셀 수 세기
import cv2
import numpy as np
for diff in (10, 30, 40, 60, 183):
    img = np.full((60, 100), 62, dtype=np.uint8)
    img[:, 50:] = 62 + diff                     # 가운데 세로 계단
    edges = cv2.Canny(img, 50, 150)
    print(diff, int((edges > 0).sum()))
# 10 0
# 30 0
# 40 60
# 60 60
# 183 60   ← 문턱을 넘으면 차이와 상관없이 같은 60픽셀(세로 60줄 × 1)
```
```text
# 파라미터로 바꾸는 꼴 (lane_detector 안)
self.declare_parameter('canny_low', 50)
self.declare_parameter('canny_high', 150)
low = self.get_parameter('canny_low').value
high = self.get_parameter('canny_high').value
edges = cv2.Canny(gray, low, high)
```
```bash
ros2 param set /lane_detector canny_low 80
ros2 param get /lane_detector canny_low      # Integer value is: 80
```
