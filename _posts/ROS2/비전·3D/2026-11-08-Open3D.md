# Open3D

## 정의·핵심
- **정의**: 3D 점구름 처리에 특화된 파이썬 라이브러리 — numpy가 수치를 담는 일반 그릇이라면 Open3D `PointCloud`는 점 좌표에 색·법선(normal)까지 담는 **전용 그릇**. 다운샘플·평면 검출·시각화를 메서드 한 번으로 (실습 7차시). 현장에선 PCL도 널리 쓰이지만 흐름은 같다.
- **apt에 없다**: `apt-cache policy python3-open3d` → `Candidate: (none)` → PyPI에서 pip로, 방(venv)에 들인다(→ [[ROS2와 venv]]). `pip install open3d` → `open3d-0.20.0`, 바퀴 400.8 MB, 방 1.1 GB, 47개 패키지가 깔렸는데 numpy는 없다(시스템 1.26.4로 충분).
- **처리 흐름 여섯 단계**:
  - ① `read_points_numpy` — 메시지 → (N,3)
  - ② `o3d.utility.Vector3dVector(xyz)` — 배열을 감싸 `pcd.points`에
  - ③ `voxel_down_sample(0.05)` — 줄이기
  - ④ `segment_plane(distance_threshold=0.01, ransac_n=3, num_iterations=1000)` → `plane`(a,b,c,d), `inliers`(인덱스)
  - ⑤ `select_by_index(inliers)` 바닥 / `select_by_index(inliers, invert=True)` 물체
  - ⑥ `np.asarray(…points, dtype=np.float32)` → `create_cloud_xyz32` → `/ground`·`/objects`
- **노드 첫 줄에 어느 파이썬인지 찍는다**: `python=… numpy=… open3d=…` — 방을 다룰 때 가장 먼저 보고 싶은 값.
- **실측**: `바닥 2619 점, 물체 606 점` 따위 — 14000점이 5cm 격자로 3000점 남짓, 다수가 바닥. 프레임마다 흔들리는 것은 정상(입력 난수·RANSAC 무작위).
- **파일로**: `o3d.io.write_point_cloud('objects.ply', objects)` — `ros2 run`을 친 폴더에 생긴다. `read_point_cloud`·`draw_geometries([pcd])`로 창.
  - `draw_geometries`는 창을 닫을 때까지 돌아오지 않는다 → 노드에선 파일·토픽으로 내보내고 창은 따로.
  - 화면 없는 터미널에선 `No display detected, falling back to EGL offscreen rendering.` 뒤 멈추고 Ctrl+C로도 안 끝났다 → 터미널을 닫는다.

## 원리·구조
```
xyz (N,3) ─Vector3dVector─▶ pcd ─voxel_down_sample─▶ pcd' ─segment_plane─▶ (plane, inliers)
                                                         ├ select_by_index(inliers)            → ground
                                                         └ select_by_index(inliers, invert=True) → objects ─cluster_dbscan─▶ labels
```

## 코드 예시
```python
# o3d_node.py 콜백 — 감싸고 · 줄이고 · 찾고 · 나눈다 (방 안에서 ros2 run --prefix python)
import sys
import numpy as np
import open3d as o3d
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import PointCloud2
from sensor_msgs_py import point_cloud2
from sensor_msgs_py.point_cloud2 import read_points_numpy


class O3dNode(Node):
    def __init__(self):
        super().__init__('o3d_node')
        self.get_logger().info(f'python={sys.executable} numpy={np.__version__} open3d={o3d.__version__}')
        self.create_subscription(PointCloud2, '/points', self.cb, 10)
        self.pub_ground = self.create_publisher(PointCloud2, '/ground', 10)
        self.pub_objects = self.create_publisher(PointCloud2, '/objects', 10)

    def cb(self, msg):
        xyz = read_points_numpy(msg, field_names=['x', 'y', 'z'], skip_nans=True)
        pcd = o3d.geometry.PointCloud()
        pcd.points = o3d.utility.Vector3dVector(xyz)
        pcd = pcd.voxel_down_sample(0.05)
        plane, inliers = pcd.segment_plane(distance_threshold=0.01, ransac_n=3, num_iterations=1000)
        ground = pcd.select_by_index(inliers)
        objects = pcd.select_by_index(inliers, invert=True)
        self.get_logger().info(f'바닥 {len(ground.points)} 점, 물체 {len(objects.points)} 점')
        g = np.asarray(ground.points, dtype=np.float32)
        o = np.asarray(objects.points, dtype=np.float32)
        self.pub_ground.publish(point_cloud2.create_cloud_xyz32(msg.header, g))
        self.pub_objects.publish(point_cloud2.create_cloud_xyz32(msg.header, o))
```
