# 라이다와 깊이 카메라

## 정의·핵심
- **정의**: 공간을 점 수만 개로 **직접 찍는** 두 센서. 결과물은 똑같이 (x, y, z)의 모임 — 그래서 합성 점구름으로도 처리 흐름을 익힐 수 있다 (실습 7차시).
- **라이다(LiDAR)**: 레이저 펄스를 사방으로 쏜다 → 물체에 맞고 되돌아오는 시간(ToF)을 재 거리 계산 → 빛이 닿은 지점마다 좌표 하나 → 모이면 점구름. 회전·주사하니 점이 360도에 고르게 흩어진다 → `height=1`, `width`=점 개수. 부가 속성은 반사 강도(intensity)·링(ring) 번호 — 재질이 다른 표면(도로 차선) 구분 단서.
- **깊이 카메라**: 스테레오·구조광·ToF로 화각 안 **픽셀마다** 거리 → 바라보는 한 방향에 격자형으로 정렬 → `height`·`width`가 영상처럼 의미를 갖는다. 부가 속성은 색(r,g,b) — 컬러 입체라 디버깅이 쉽다. 깊이 영상은 `32FC1`(→ cv_bridge `passthrough`).
- **잘 맞는 상황이 다르다**:
  - 라이다 — 어두워도 거리가 정확, 측정 범위가 넓다 / 점이 상대적으로 희소, 색 없음.
  - 깊이 카메라 — 점이 촘촘, 색을 함께 / 밝은 햇빛·반사가 심한 표면에서 흔들림.
- **센서 퓨전**: 둘을 함께 달아 서로의 약점을 메운다 — 점구름이 된 뒤 처리는 한 흐름. 실제 라이다는 보통 10~20Hz로 점구름을 쏟아낸다.
- **ToF 거리**: 거리 = 빛의 속도 × 왕복 시간 / 2.

## 원리·구조
```
라이다: (거리 r, 방위 θ, 고각 φ) → x = r·cosφ·cosθ, y = r·cosφ·sinθ, z = r·sinφ     height=1, width=N
깊이  : 픽셀 (u, v) + 깊이 Z → X = (u − cx)·Z / fx, Y = (v − cy)·Z / fy               height=H, width=W
```

## 코드 예시
```python
# 라이다 한 줄과 깊이 영상 한 장을 각각 (N,3) 점으로
import numpy as np
c = 299_792_458.0
print(round(c * 20e-9 / 2, 3), "m")                # 2.998 m  ← 왕복 20 ns
theta = np.radians(np.arange(0, 360, 90))          # 4방향 스캔, 모두 2 m
r = np.full(4, 2.0)
lidar = np.stack([r * np.cos(theta), r * np.sin(theta), np.zeros(4)], axis=1).round(3)
print(lidar.tolist())   # [[2.0, 0.0, 0.0], [0.0, 2.0, 0.0], [-2.0, 0.0, 0.0], [-0.0, -2.0, 0.0]]
H, W, fx, fy, cx, cy = 2, 3, 1.0, 1.0, 1.0, 0.5    # 아주 작은 깊이 영상
Z = np.full((H, W), 1.5, dtype=np.float32)         # 32FC1, 모두 1.5 m
v, u = np.mgrid[0:H, 0:W]
pts = np.stack([(u - cx) * Z / fx, (v - cy) * Z / fy, Z], axis=-1).reshape(-1, 3)
print(pts.shape, pts[0].tolist(), pts[-1].tolist())   # (6, 3) [-1.5, -0.75, 1.5] [1.5, 0.75, 1.5]
```
