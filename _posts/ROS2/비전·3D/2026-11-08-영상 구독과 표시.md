# 영상 구독과 표시

## 정의·핵심
- **정의**: `/camera/image_raw`를 구독해 cv_bridge로 풀고 `cv2.imshow`로 창에 띄우는 뷰어 노드 `viewer` — 콜백 세 줄: **풀고, 띄우고, 그릴 틈을 준다** (실습 6차시).
- **`cv2.waitKey(1)`**: OpenCV 창이 화면을 새로 그릴 짧은 틈 — imshow와 늘 한 쌍. 빼면 `camera` 창은 떠도 그림이 한 번도 안 그려진다(검은 띠), 오류·경고도 없다.
- **실행 차례(터미널 셋)**: ① `camera_publisher`(입력) → ② `ros2 topic hz`(흐름 확인) → ③ `viewer`(표시). 새 터미널마다 `source`.
- **안 뜨면 「입력이냐 표시냐」부터**: hz에 숫자가 나오면 표시 쪽, `does not appear to be published yet`이면 입력 쪽. 콜백이 한 번도 안 불리면 창 자체가 안 만들어진다(imshow가 콜백 안).
- **창이 안 뜨는 터미널**: `qt.qpa.xcb: could not connect to display` … `[ros2run]: Aborted`(종료 코드 250) — 파이썬 예외가 아니라 프로세스가 통째로 끝나 try로 못 살린다. 첫 프레임이 와서 imshow를 부르는 순간 난다.
  - 차례 셋: `echo $DISPLAY` 확인 → 데스크톱 터미널에서 → 그래도 안 되면 `QT_QPA_PLATFORM=offscreen ros2 run my_py_pkg viewer`(창 없이 노드만, 구독은 산다 — `Subscription count: 1`).
- **rqt_image_view**: `ros2 run rqt_image_view rqt_image_view /lane/overlay` — 표시 책임을 노드 밖 표준 도구로. 이름 없이 띄우면 토픽 칸이 비어 있다 → 새로고침. 한 번 고른 토픽은 기억된다.
- 창 없이 결과를 남기려면 `cv2.imwrite` — 실패해도 예외 없이 `False`만 돌려주니 반환값을 로그로(→ [[차선 검출 파이프라인]]).

## 원리·구조
```
세 관문으로 좁힌다
 ① 입력이 들어오나   ros2 topic hz · list · info
 ② 변환이 맞나       --field encoding --once
 ③ 표시가 되나       echo $DISPLAY · waitKey(1)
```

## 코드 예시
```python
# viewer.py — 구독해 풀고 창에 띄운다
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2


class Viewer(Node):
    def __init__(self):
        super().__init__('viewer')
        self.bridge = CvBridge()
        self.create_subscription(Image, '/camera/image_raw', self.cb, 10)

    def cb(self, msg):
        frame = self.bridge.imgmsg_to_cv2(msg, 'bgr8')
        cv2.imshow('camera', frame)        # 화면에 띄우기
        cv2.waitKey(1)                     # 그릴 틈 — 빼면 검은 띠


def main():
    rclpy.init()
    node = Viewer()
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()
```
```python
# 「입력이냐 표시냐」 나누기 흉내
def diagnose(hz_output, display):
    if "does not appear to be published" in hz_output:
        return "입력 쪽: camera_publisher를 먼저 띄웠나, 토픽 이름이 같나"
    if not display:
        return "표시 쪽: 데스크톱 터미널 또는 QT_QPA_PLATFORM=offscreen"
    return "표시 쪽: waitKey(1)·인코딩 확인"
print(diagnose("WARNING: topic [/camera/image_raw] does not appear to be published yet", ":0"))
print(diagnose("average rate: 14.995", ""))
# 입력 쪽: camera_publisher를 먼저 띄웠나, 토픽 이름이 같나
# 표시 쪽: 데스크톱 터미널 또는 QT_QPA_PLATFORM=offscreen
```
```bash
ros2 run my_py_pkg viewer
QT_QPA_PLATFORM=offscreen ros2 run my_py_pkg viewer
ros2 run rqt_image_view rqt_image_view /camera/image_raw
```
