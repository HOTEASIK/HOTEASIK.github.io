# 점구름 발행

## 정의·핵심
- **정의**: numpy (N,3) float32 배열을 `point_cloud2.create_cloud_xyz32(header, pts)`로 PointCloud2에 묶어 발행 — **read_points의 반대 방향** (실습 7차시).
- **왜 합성 퍼블리셔부터**: 실습 환경엔 라이다도 bag도 없다 → 구독 노드는 한 줄도 안 찍고 기다리고, `ros2 topic echo /points`는 `WARNING: topic [/points] does not appear to be published yet` · `Could not determine the type for the passed topic`. 구독은 발행이 있어야 동작한다.
- **`pc_pub`**: 바닥 평면(z≈0, 표준편차 0.005) 12000점 + 바닥 위 0.1 m에 띄운 0~0.3 m 정육면체 2000점(12000//6) = **14000점**을 `create_timer(0.5, …)`(2Hz)로 `/points`에. `header.frame_id = 'map'` — RViz Fixed Frame 처음 값과 맞물린다.
- **합성 데이터로 연습하는 까닭 — 답을 미리 안다**: RANSAC이 바닥을 골라내고 정육면체를 물체로 남기는지 대조할 수 있다. 실제 센서로 넘어갈 땐 토픽 이름만 바꾸고 구독·처리 코드는 그대로.
- **구독 쪽 `cloud_node`**: 콜백 한 줄 `read_points_numpy` → `점 개수: 14000`이 0.5초마다. 한 번만 찍히고 멈추면 발행이 끊겼거나 콜백 예외, 아예 없으면 발행 노드 미실행·source 빠뜨림.
- **처리 결과를 되돌려 보내기**: Open3D 결과를 `np.asarray(ground.points, dtype=np.float32)`로 (M,3)으로 되돌려 `create_cloud_xyz32(msg.header, g)` — 헤더(frame_id map)를 받은 것 그대로 써야 RViz가 같은 자리에 겹쳐 그린다. 「토픽으로 받아 처리하고 토픽으로 내보내는」 인지 노드의 전형.
- **5Hz로**: `create_timer(0.2, …)` → `ros2 topic hz /points` = `average rate: 5.001`. 실제 주기는 코드가 아니라 hz로 확인.
- **등록 실수**: 모듈 이름 오타 `cloud_nod` → 빌드는 지나가고 실행에서 `ModuleNotFoundError`. 앞 줄 콤마 빠뜨림 → `RuntimeError: 'distutils.core.setup()' was never called` · `1 package failed` — 설치 폴더는 앞 판 그대로라 고치기 전 화면이 뜬다. 블록을 통째로 덮어쓰면 입문 노드가 `StopIteration` → `cp setup.py.bak setup.py`.

## 원리·구조
```
numpy (N,3) float32 ─create_cloud_xyz32(header, pts)─▶ PointCloud2 ─/points─▶ cloud_node: read_points_numpy ─▶ (N,3)
                                                                         └──▶ RViz PointCloud2 표시
```

## 코드 예시
```python
# pc_pub.py — 바닥 + 정육면체 합성 점구름을 2Hz로 /points 에
import numpy as np
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException
from sensor_msgs.msg import PointCloud2
from sensor_msgs_py import point_cloud2
from std_msgs.msg import Header


class CloudPub(Node):
    def __init__(self):
        super().__init__('cloud_pub')
        self.pub = self.create_publisher(PointCloud2, '/points', 10)
        self.create_timer(0.5, self.tick)   # 2Hz 발행

    def make_points(self, n=12000):
        ground = np.random.uniform(-1.0, 1.0, size=(n, 3))
        ground[:, 2] = np.random.normal(0.0, 0.005, size=n)
        cube = np.random.uniform(0.0, 0.3, size=(n // 6, 3))
        cube[:, 2] += 0.1
        return np.vstack([ground, cube]).astype(np.float32)

    def tick(self):
        pts = self.make_points()
        header = Header()
        header.stamp = self.get_clock().now().to_msg()
        header.frame_id = 'map'                # RViz Fixed Frame과 맞추기
        self.pub.publish(point_cloud2.create_cloud_xyz32(header, pts))
        self.get_logger().info(f'발행: {len(pts)} 점')


def main():
    rclpy.init()
    node = CloudPub()
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()
```
```python
# 묶기 ↔ 풀기 왕복 흉내 (create_cloud_xyz32 ↔ read_points_numpy)
import numpy as np
pts = np.random.default_rng(1).uniform(-1, 1, (14000, 3)).astype(np.float32)
data, point_step = pts.tobytes(), 12
back = np.frombuffer(data, dtype=np.float32).reshape(-1, 3)
print(len(data), len(data) // point_step, np.array_equal(back, pts))   # 168000 14000 True
```
