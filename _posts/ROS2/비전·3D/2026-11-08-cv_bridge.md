# cv_bridge

## 정의·핵심
- **정의**: ROS의 `sensor_msgs/Image`(노드 사이를 오가는 형식)와 OpenCV의 numpy 배열(계산하는 형식)을 잇는 **양방향 번역기** (실습 6차시).
- **왜**: 같은 숫자 격자라도 담는 방식이 달라 그대로는 안 통한다 — 한글 파일과 워드 파일. 통신에 강한 형식(헤더·인코딩까지)과 계산에 강한 형식을 나눠 두고 전담 번역기를 둔다. 소켓에서 글자를 바이트로 포장했다 푸는 직렬화와 결이 같다.
- **함수 둘 — 이름이 곧 방향**:
  - `imgmsg_to_cv2(msg, 'bgr8')` — 받을 때(입구): Image → numpy.
  - `cv2_to_imgmsg(frame, 'bgr8')` — 보낼 때(출구): numpy → Image.
- **다리 객체는 생성자에서 한 번**: `self.bridge = CvBridge()` — publisher·subscriber처럼 만들어 두고 콜백에서 다시 쓴다.
- **불러오기 확인**: `cv_bridge ok 4.6.0 1.26.4`(OpenCV·numpy 판). source 안 한 셸이면 `ModuleNotFoundError: No module named 'cv_bridge'` → `source /opt/ros/jazzy/setup.bash`.
- **pip로 OpenCV를 따로 들이지 않는다**: venv에 `pip install opencv-python` → opencv 5·numpy 2가 들어와 `cv2_to_imgmsg`가 **`KeyError: 16`**으로 멈췄다. apt로 깔린 ROS 쪽 파이썬을 그대로 쓴다.
- **package.xml**: 실습 환경은 안 적어도 됐지만 관례로 `<depend>sensor_msgs</depend>`·`<depend>cv_bridge</depend>` — 다른 컴퓨터로 옮겨 rosdep할 때 읽는다.
- **passthrough**: `imgmsg_to_cv2(msg, 'passthrough')` — 변환 없이 들어온 형식 그대로(깊이 영상 32FC1 등). 32FC1을 bgr8로 풀면 `[32FC1] is not a color format. but [bgr8] is.` 로 거절.

## 원리·구조
```
/camera/image_raw ─▶ imgmsg_to_cv2 ─▶ numpy (480,640,3) ─▶ OpenCV 처리 ─▶ cv2_to_imgmsg ─▶ /lane/overlay
     Image            (입구: 풀기)                                     (출구: 포장)        Image
```

## 코드 예시
```python
# 뷰어처럼: 받아서 풀고, 처리 뒤 다시 포장해 발행
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2


class Relay(Node):
    def __init__(self):
        super().__init__('relay')
        self.bridge = CvBridge()                     # 생성자에서 한 번
        self.create_subscription(Image, '/camera/image_raw', self.cb, 10)
        self.pub = self.create_publisher(Image, '/camera/gray', 10)

    def cb(self, msg):
        frame = self.bridge.imgmsg_to_cv2(msg, 'bgr8')        # 풀기
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        out = self.bridge.cv2_to_imgmsg(gray, 'mono8')       # 채널 1 → mono8
        out.header = msg.header
        self.pub.publish(out)
```
```python
# cv_bridge가 하는 일 흉내: data 바이트 + height·width·step → numpy, 그리고 거꾸로
import numpy as np
frame = np.zeros((2, 3, 3), dtype=np.uint8); frame[0, 0] = (200, 0, 0)
msg = {"height": 2, "width": 3, "encoding": "bgr8", "step": 3 * 3, "data": frame.tobytes()}
back = np.frombuffer(msg["data"], dtype=np.uint8).reshape(msg["height"], msg["width"], 3)
print(len(msg["data"]), msg["step"], back[0, 0].tolist(), np.array_equal(back, frame))
# 18 9 [200, 0, 0] True
```
