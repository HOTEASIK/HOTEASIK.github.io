# ROS2와 venv

## 정의·핵심
- **정의**: apt에 없는 파이썬 패키지(Open3D)를 ROS 위에서 쓰려고 **파이썬 가상환경(venv, 따로 떨어진 방)** 을 얹는 법과 주의 넷 (실습 7차시).
- **시스템 파이썬엔 바로 안 깔린다**: 실습 환경엔 pip도 없다(`bash: pip: command not found`) → `sudo apt install -y python3-venv python3-pip`. 그래도 `pip install open3d` → `error: externally-managed-environment`(PEP 668). ROS 노드가 도는 파이썬이 바로 시스템 파이썬이라, 새 numpy가 apt 판을 덮으면 ROS 쪽이 깨질 수 있어서 막는다. `--break-system-packages`는 쓰지 않는다(오류문 스스로 at the risk of breaking).
- **① 방에서 시스템 패키지가 보이게 — `--system-site-packages`**: 빈 방이면 `import rclpy`가 `ModuleNotFoundError: No module named 'yaml'`로 멈춘다(rclpy는 ROS setup.bash가 길을 열지만 numpy·yaml은 apt가 시스템에 깐 것). `python3 -m venv --system-site-packages ~/o3d_venv` → 방 안에서 온 것은 open3d 하나뿐, numpy는 `/usr/lib/python3/dist-packages`, rclpy는 `/opt/ros/jazzy`.
- **② source는 둘 다 — 순서는 상관없다**: ROS→방, 방→ROS 모두 된다. 방만 켜면 `No module named 'rclpy'`, ROS만 켜면 `No module named 'open3d'`. 깨지는 것은 순서가 아니라 **빠뜨림** — 프롬프트 앞 `(o3d_venv)`가 표시.
- **③ colcon build는 방을 모른다**: `head -1 $(which ros2)` → `#!/usr/bin/python3`. 방을 켜고 빌드해도 실행 파일 첫 줄은 `#!/usr/bin/python3` → `ros2 run my_py_pkg o3d_node`가 `No module named 'open3d'`.
  - 해결: 방을 켠 터미널에서 **`ros2 run --prefix python my_py_pkg o3d_node`** — 첫 줄 대신 지금 켜진 python. 방을 끈 터미널이면 `FileNotFoundError: … 'python'`(실습 환경의 python은 방 안에만).
  - 다른 길 `python -m colcon build` — 그릇 안 모든 노드 첫 줄이 방 파이썬으로 바뀌어 그릇 전체가 방에 묶인다. 방을 지우자 입문 노드까지 `FileNotFoundError`.
- **④ 현장에서 venv가 드문 까닭**: colcon·ros2 run은 시스템 파이썬, rosdep은 package.xml로 apt 꾸러미를 깐다 — 방은 다른 사람의 빌드를 따라가지 않는다 → 먼저 apt, 없으면 환경 전체를 **도커 이미지**로.
- **실제로 부딪힌 일**: 방에 numpy 2가 들어오자 cv_bridge가 `numpy.core.multiarray failed to import` → 그 방을 버리고 다시. 방을 워크스페이스 안에 만들면 `colcon list`에 `IPython doctest plugin`이 끼어든다 → 방은 `~/o3d_venv`처럼 밖에.

## 원리·구조
| 켠 것 | import rclpy | import open3d |
|---|---|---|
| ROS → 방 | 된다 | 된다 |
| 방 → ROS | 된다 | 된다 |
| 방만 | No module named 'rclpy' | 된다 |
| ROS만 | 된다 | No module named 'open3d' |

## 코드 예시
```python
# 실행 파일 첫 줄(shebang)이 어느 파이썬을 부르나 — ros2 run vs --prefix python 흉내
def run(shebang, prefix=None, venv_on=False):
    py = prefix if prefix else shebang
    if py == "python" and not venv_on:
        return "FileNotFoundError: [Errno 2] No such file or directory: 'python'"
    has_o3d = (py == "python" and venv_on)
    return "바닥 2619 점, 물체 606 점" if has_o3d else "ModuleNotFoundError: No module named 'open3d'"
first_line = "/usr/bin/python3"           # colcon은 방을 모른다
print(run(first_line, venv_on=True))                     # ModuleNotFoundError: No module named 'open3d'
print(run(first_line, prefix="python", venv_on=True))    # 바닥 2619 점, 물체 606 점
print(run(first_line, prefix="python", venv_on=False))   # FileNotFoundError: [Errno 2] No such file or directory: 'python'
```
```bash
sudo apt install -y python3-venv python3-pip
python3 -m venv --system-site-packages ~/o3d_venv
source ~/o3d_venv/bin/activate && which python3     # /home/student/o3d_venv/bin/python3
pip install open3d                                  # 끝 줄에 numpy가 끼어 있는지 본다
head -1 ~/ros2_ws/install/my_py_pkg/lib/my_py_pkg/o3d_node   # #!/usr/bin/python3
ros2 run --prefix python my_py_pkg o3d_node
```
