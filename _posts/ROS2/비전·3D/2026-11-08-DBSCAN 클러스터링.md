# DBSCAN 클러스터링

## 정의·핵심
- **정의**: DBSCAN(Density-Based Spatial Clustering of Applications with Noise) — **가까이 모인 점들끼리 한 덩어리로** 묶는 방법. Open3D `objects.cluster_dbscan(eps=…, min_points=…)` → 점마다 덩어리 번호, **-1은 잡음**(어디에도 안 묶인 점) (실습 7차시).
- **인자 둘**:
  - `eps` — 이 거리 안이면 같은 덩어리로 보는 반경
  - `min_points` — 한 덩어리로 인정하기 위한 최소 이웃 수
- **군집 수** = `labels.max() + 1`.
- **함정 — 오류 없이 0**: 실습에서 `eps=0.05, min_points=10` → `물체 군집 수: 0`(물체 486점 모두 -1). 5cm 다운샘플 뒤 남은 점끼리 간격도 5cm 안팎이라 반경 0.05 안에서 이웃을 10개나 못 찾는다.
- **eps를 키워 가며(min_points 10, 일곱 프레임)**:
  - 0.05 → 0 0 0 0 0 0 0
  - **0.08 → 1 1 1 1 1 1 1**(314점 덩어리 = 정육면체) ← 정답
  - 0.1 → 1 1 2 1 2 1 3
  - 0.15 → 1 1 3 5 2 2 2
  - 0.2 → 2 1 5 1 3 2 3
  - 0.1·0.15의 작은 덩어리는 물체 쪽으로 넘어온 바닥 잡음이 뭉친 것 — **한 프레임에서 1이 나왔다고 끝이 아니다**, 여러 프레임과 덩어리 점 수까지 본다.
- **순서**: 바닥을 먼저 떼지 않고 곧장 클러스터링하면 바닥 점들이 모든 물체를 하나로 이어 붙인다 → 현장 표준 흐름은 **다운샘플 → 평면 제거 → 클러스터링**(장애물 덩어리).

## 원리·구조
```
핵심점: 반경 eps 안 이웃 ≥ min_points
핵심점에서 eps 안으로 닿는 점들을 차례로 이어 한 덩어리
어느 핵심점에도 안 닿는 점 = -1(잡음)
```

## 코드 예시
```python
# 5cm 격자 간격으로 놓인 정육면체 점들 — eps가 격자 간격보다 작거나 같으면 0개
import numpy as np
g = np.arange(0, 0.3, 0.05)
cube = np.array([(x, y, z + 0.1) for x in g for y in g for z in g])      # 6×6×6 = 216점, 간격 0.05
noise = np.array([[0.8, 0.8, 0.0], [-0.7, 0.5, 0.01]])                  # 멀리 떨어진 잡음 2점
pts = np.vstack([cube, noise])
def dbscan(p, eps, min_points):
    D = np.linalg.norm(p[:, None] - p[None], axis=2)
    nb = [np.nonzero(D[i] < eps)[0] for i in range(len(p))]           # 자기 자신 포함
    core = [len(n) >= min_points for n in nb]
    labels, c = np.full(len(p), -1), 0
    for i in range(len(p)):
        if labels[i] != -1 or not core[i]: continue
        stack = [i]; labels[i] = c
        while stack:
            j = stack.pop()
            if not core[j]: continue
            for k in nb[j]:
                if labels[k] == -1: labels[k] = c; stack.append(k)
        c += 1
    return labels
for eps in (0.05, 0.08, 0.2):
    lab = dbscan(pts, eps, 10)
    print(eps, lab.max() + 1, int((lab == -1).sum()))      # 군집 수 · 잡음 점 수
# 0.05 0 218  ← 오류 없이 0: 이웃이 반경 안에 안 든다, 전부 잡음
# 0.08 1 2    ← 정육면체 하나, 멀리 떨어진 2점만 잡음
# 0.2 1 2
```
