# 점구름

## 정의·핵심
- **정의**: 점구름(Point Cloud) — 3차원 공간상의 점들을 좌표로 모아 놓은 집합. 점 하나는 최소 `(x, y, z)` 실수 셋, 경우에 따라 색(r,g,b)·반사 강도(intensity) (실습 7차시).
- **왜 필요한가 — 픽셀은 거리를 모른다**: 2D 픽셀은 「이 화면 위치의 색」만 안다. 거리(깊이)가 없으면 「저 의자가 1 m 앞인지 5 m 앞인지」 몰라 부딪히지 않고 다니기조차 어렵다.
- **왜 점으로**: 센서가 실제로 재는 것은 「빛이 어느 한 지점에 닿았다」는 사실뿐 → 가장 날것의 형태가 점들의 모임. 면·부피·평면·물체·장애물은 측정이 아니라 **해석** — 점 위에 의미를 얹어 가는 것이 3D 인지의 순서.
- **점 N개 = `(N, 3)` 배열 하나**: 앞 차시 영상의 (높이, 너비, 색) 배열처럼 numpy 연산이 그대로 통한다(`xyz[:, 2].min()` = 가장 낮은 점의 높이).
- **좌표계 약속**: 같은 의자라도 카메라 원점·로봇 본체 원점에 따라 좌표가 다르다 → `header.frame_id`. 센서·본체·지도 좌표계 사이는 TF가 잇는다. 실습은 합성 점구름을 곧장 `map`으로 발행해 변환을 생략.
- **처리는 스트림**: 퍼블리셔 2Hz면 콜백도 초당 두 번 — 콜백은 짧게, 무거운 일은 다운샘플로 가볍게.
- **현장**: 라이다 점구름으로 자율주행차·AMR이 둘레를 3D로 파악 → 평면 검출로 바닥을 빼면 장애물이 남고 → 충돌 회피의 첫 단추. 흐름: 풀기 → 다운샘플 → 평면 제거 → 클러스터링. 딥러닝 3D 검출·점유 인지·BEV 퓨전으로 옮겨 가도 RANSAC·다운샘플은 전후처리 단골.

## 원리·구조
| 항목 | 2D 영상(Image) | 3D 점구름(Point Cloud) |
|---|---|---|
| 기본 단위 | 픽셀(화면 위치 + 색) | 점(공간 좌표 x,y,z) |
| 배열 모양 | (높이, 너비, 색) | (N, 3) |
| 거리 정보 | 없음 | 있음 |
| ROS 메시지 | sensor_msgs/Image | sensor_msgs/PointCloud2 |
| 푸는 도구 | cv_bridge | read_points / read_points_numpy |
| 처리 라이브러리 | OpenCV | Open3D(또는 PCL) |
| 대표 작업 | 색·모양 검출 | 평면 검출·물체 분리 |
| RViz 표시 | Image | PointCloud2 |

## 코드 예시
```python
# 실습 pc_pub의 합성 장면: 바닥 평면 12000점 + 정육면체 2000점 = (14000, 3)
import numpy as np
np.random.seed(0)
n = 12000
ground = np.random.uniform(-1.0, 1.0, size=(n, 3))
ground[:, 2] = np.random.normal(0.0, 0.005, size=n)      # z≈0 평면
cube = np.random.uniform(0.0, 0.3, size=(n // 6, 3))     # 0~0.3 m 정육면체
cube[:, 2] += 0.1                                         # 바닥 위로 띄움
xyz = np.vstack([ground, cube]).astype(np.float32)
print(xyz.shape, xyz.dtype)                               # (14000, 3) float32
print(round(float(xyz[:, 2].min()), 2), round(float(xyz[:, 2].max()), 2))   # -0.02 0.4
print(int((xyz[:, 2] > 0.07).sum()))                      # 2000  ← 바닥 위 0.07 m보다 높은 점 = 정육면체
d = np.linalg.norm(xyz, axis=1)                           # 원점에서의 거리 — 2D 영상엔 없던 정보
print(round(float(d.min()), 3) >= 0.0, round(float(d.max()), 2))   # True 1.41  ← 바닥 모서리 √2
```
