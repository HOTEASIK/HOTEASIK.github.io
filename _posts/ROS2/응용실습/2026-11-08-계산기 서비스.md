# 계산기 서비스

## 정의·핵심
- **정의**: 두 수와 연산자를 보내면 결과와 성공 여부가 돌아오는 서비스 한 쌍 `calc_client → calc_server` — 응용 사다리의 **첫 칸** (입문 6차시).
- **왜 서비스인가 — 문법보다 데이터의 성질**: 한 번 묻고 곧 답하며 성패를 알아야 하는 거래. 흐르는가(토픽), 한 번 오가는가(서비스), 오래 걸리는가(액션), 설정값인가(파라미터) — 네 갈래만 따져도 후보가 좁혀진다.
- **AddTwoInts로는 모자란다** — 연산자 칸이 없다 → 양식부터 짓는다 `my_interfaces/srv/Calc.srv`:
  - 요청 셋 `float64 a` · `float64 b` · `string op`('+','-','*','/')
  - 응답 둘 `float64 result` · `bool ok`
- **ok가 하는 일**: 0으로 나누기·모르는 연산자를 알린다 — result 0.0만으론 「진짜 0」과 「실패」를 못 가른다. 응답 객체는 미리 만들어진 빈 것(result=0.0, ok=False)이라 실패 땐 채우지 않는다.
- **0으로 나누기를 막지 않으면** `ZeroDivisionError: float division by zero`로 서버가 죽는다.
- **함정**:
  - 콜백 이름을 `handle`로 지으면 Node 내부 속성을 가려 노드가 안 뜬다(`the context manager protocol`) → `on_request`.
  - `return res`를 빠뜨리면 응답이 영영 안 온다.
  - 명령행 인자는 문자열 — `float()` 안 하면 float64 칸에서 Abort.
  - 곱하기는 셸이 `*`를 먼저 해석 → `'*'`.
- **클라이언트를 짜기 전에 `ros2 service call`로 서버부터** — 「문제를 반으로 가르기」. 실측 `Calc_Response(result=9.0, ok=True)` / `(result=0.0, ok=False)`.
- **클라이언트**: `wait_for_service(timeout_sec=1.0)` 반복 → `call_async`(송장번호 future) → `spin_until_future_complete` → `future.result()`. 한 번 답 받고 끝나는 노드라 try 없이 정리.

## 원리·구조
```
calc_client 6 3 +  ──Calc.Request(a=6.0, b=3.0, op='+')──▶ /calc ──▶ calc_server.on_request
                   ◀──Calc.Response(result=9.0, ok=True)──────────────┘
```

## 코드 예시
```python
# on_request 로직만 떼어 시험 — 빈 응답(0.0, False)에서 시작
class Res:
    def __init__(self): self.result, self.ok = 0.0, False
def on_request(a, b, op):
    res = Res()
    if op == '+':   res.result = a + b; res.ok = True
    elif op == '-': res.result = a - b; res.ok = True
    elif op == '*': res.result = a * b; res.ok = True
    elif op == '/':
        if b != 0: res.result = a / b; res.ok = True
    return res
for a, b, op in [(6, 3, '+'), (6, 0, '/'), (6, 3, '%'), (6, 3, '/')]:
    r = on_request(float(a), float(b), op)
    print(f"{a} {op} {b} → result={r.result}, ok={r.ok}")
# 6 + 3 → result=9.0, ok=True
# 6 / 0 → result=0.0, ok=False
# 6 % 3 → result=0.0, ok=False
# 6 / 3 → result=2.0, ok=True
```
```python
# calc_server.py 핵심
import rclpy
from rclpy.node import Node
from my_interfaces.srv import Calc


class CalcServer(Node):
    def __init__(self):
        super().__init__('calc_server')
        self.srv = self.create_service(Calc, 'calc', self.on_request)   # handle 이라 짓지 않는다

    def on_request(self, req, res):
        if req.op == '+':
            res.result = req.a + req.b; res.ok = True
        elif req.op == '/' and req.b != 0:
            res.result = req.a / req.b; res.ok = True
        else:
            res.ok = False
        return res                                   # 빠뜨리면 응답 없음
```
```bash
ros2 service call /calc my_interfaces/srv/Calc "{a: 6, b: 3, op: '+'}"
ros2 run my_py_pkg calc_client 6 3 '*'
```
