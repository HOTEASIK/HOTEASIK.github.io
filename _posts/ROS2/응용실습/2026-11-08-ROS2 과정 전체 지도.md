# ROS2 과정 전체 지도

## 정의·핵심
- **정의**: 기초 5 · 입문 9 · 실습 8, **22일**을 한 길로 꿴 지도 — 쓰는 법에서 만드는 법으로, 만드는 법에서 진짜 로봇으로 키우는 법으로 (실습 8차시).
- **세 과정이 남긴 능력**:
  - **기초(1~5일) — ROS를 쓴다 · 맥락**: 컴퓨터 구조·리눅스·네트워크라는 땅 → 소켓으로 「통신은 손이 많이 간다」를 겪음 → ROS2 설치·talker/listener·turtlesim 「이름(토픽)만 맞추면 통한다」 → 거북이로 통신 넷·RQT·bag.
  - **입문(6~14일) — ROS로 만든다 · 제작 능력**: 그릇 my_py_pkg와 양식 패키지 → 토픽·서비스 노드, Executor·launch → 액션·파라미터 → 계산기·행맨 조립 → bag·Jupyter 분석 → 순찰 로봇.
  - **실습(15~22일) — 진짜 로봇으로 키운다 · 운용 능력**: CLI 진단 → QoS·Intra-Process → Component·RQT → Lifecycle·Security·URDF·TF2 → Gazebo·SLAM·Nav2 → OpenCV 차선 → 점구름·Open3D → 핵심정리.
- **서사 한 문장**: 수고에서 시작해 자율주행으로 끝난다. 소켓의 불편(IP·포트 지정, 재접속, 직렬화)을 겪은 사람에게 ROS는 그 수고를 덜어 주는 도구로 보인다 — 좋은 도구의 가치는 그 도구가 없던 때를 알아야 보인다.
- **추상도 사다리**: 기초(바이트·소켓·프로세스) → 입문(노드·토픽·인터페이스) → 실습(자율주행·인지·시뮬레이션). 직접 올라온 사람은 위층 문제에서 아래층으로 내려가 원인을 찾는다 — 「도구를 쓰는 사람」과 「도구를 이해하는 사람」의 차이.
- **통신 넷 — 입문의 심장**: 토픽(방송, `create_publisher`/`create_subscription`) · 서비스(전화, `create_service`/`create_client`+`call_async`) · 액션(택배, `ActionServer`/`ActionClient`+feedback·취소) · 파라미터(설정 손잡이, `declare_parameter`/`get_parameter().value`/set).
- **가져갈 습관 셋**: 기능이 필요하면 「어떤 통신으로?」부터 · 안 되면 「어느 층의 문제?」부터 · 막히면 코드를 고치기 전에 진단 도구로 먼저.
- **현장이 신입에게 기대하는 것**: 「거북이를 돌려 봤다」가 아니라 「노드를 직접 짜고, 통신을 진단하고, 시뮬레이션을 돌려 봤다」 — 항목들이 어떻게 한 시스템으로 엮이는지를 설명할 수 있는 것.

## 원리·구조
| 과정 | 일차 | 다룬 층 | 남긴 것 | 이 볼트의 분류 |
|---|---|---|---|---|
| 기초 | 1~5 | 바이트·소켓·프로세스 | 맥락 | 01~04 |
| 입문 | 6~14 | 노드·토픽·인터페이스 | 제작 능력 | 04~06 · 12 |
| 실습 | 15~22 | 진단·품질·시뮬·인지 | 운용 능력 | 07~11 · 12 |

## 코드 예시
```python
# 22일을 일차 → (과정, 차시)로 — 과정 경계 확인
COURSES = [("기초", 5), ("입문", 9), ("실습", 8)]
def where(day):
    start = 1
    for name, n in COURSES:
        if day < start + n: return name, day - start + 1
        start += n
    return "수료", None
print(sum(n for _, n in COURSES))                       # 22
print([where(d) for d in (1, 5, 6, 11, 14, 15, 22)])
# [('기초', 1), ('기초', 5), ('입문', 1), ('입문', 6), ('입문', 9), ('실습', 1), ('실습', 8)]
```
```python
# 기능 하나에 통신 고르기 — 네 갈래 질문
def pick(flows, needs_reply, long_running, is_setting):
    if is_setting: return "파라미터"
    if flows: return "토픽"
    if long_running: return "액션"
    return "서비스" if needs_reply else "토픽"
robot = {"센서값": (True, False, False, False), "목적지 설정": (False, True, False, False),
         "그곳까지 이동": (False, True, True, False), "최고 속도": (False, False, False, True)}
print({k: pick(*v) for k, v in robot.items()})
# {'센서값': '토픽', '목적지 설정': '서비스', '그곳까지 이동': '액션', '최고 속도': '파라미터'}
```
