# 행맨 액션

## 정의·핵심
- **정의**: 같은 게임의 둘째 입구 — **목표 하나가 한 판**. `round_client`가 글자열을 목표로 맡기면 `round_server`가 글자마다 피드백으로 보드를, 끝나면 결과로 승패를 돌려준다 (입문 7차시).
- **양식 `my_interfaces/action/PlayRound.action`**:
  - Goal `string letters` — 이번 판에 차례로 넣어 볼 글자들
  - Result `bool won` · `string board` · `int32 tries`
  - Feedback `string letter` · `string board`
- **빌드 절차**: `my_interfaces/CMakeLists.txt`의 `rosidl_generate_interfaces` 목록 끝에 `"action/PlayRound.action"` 한 줄. 빠뜨리면 빌드는 조용히 지나가고 `ros2 interface show`가 not found.
- **토픽 입구와의 차이**: 토픽 쪽 상태는 노드가 사는 동안 쌓이고 보드는 누구든 듣는다. 액션 쪽 상태(`found`)는 **판마다 새로** 시작하고, 피드백은 목표를 보낸 클라이언트만 받는다.
- **서버 `execute`**: 글자마다 `publish_feedback` → `time.sleep(1)`(고민 흉내) → 다 맞히면 남은 글자는 안 쓰고 `break` → `goal_handle.succeed()` → Result.
- **명령행으로 먼저**: `ros2 action send_goal /play_round my_interfaces/action/PlayRound "{letters: 'hleo'}" --feedback` → 보드 `h _ _ _ _ → h _ l l _ → h e l l _ → h e l l o`, `won: true`, `tries: 4`. `'xyz'`면 `_ _ _ _ _`, won false.
- **클라이언트**: `ActionClient` → `wait_for_server(timeout_sec=5.0)` → `send_goal_async(goal, feedback_callback=self.on_fb)` → `on_accept`(접수증 `accepted`) → `get_result_async()` → `on_result`에서 `'승리' if r.won else '패배'` → `done = True`로 main의 `spin_once` 반복을 멈춘다. 실측 `승리 — h e l l o (4글자)`, `패배 — _ _ _ _ _ (3글자)`.
- **판 도중에 끄면** 서버·클라이언트 화면에 줄이 남는다 — 고장이 아니다, 판이 끝난 뒤에 끈다. 양식 이름 오타(`PlayGame`)는 send_goal에서 바로 걸린다.

## 원리·구조
```
round_client ─Goal(letters='hleo')─▶ /play_round ─▶ round_server.execute
             ◀ Feedback(letter, board) × 글자마다 ─┤ found = set() (판마다 새로)
             ◀ Result(won, board, tries) ──────────┘ succeed()
```

## 코드 예시
```python
# round_server.execute를 ROS 없이 — 피드백 목록과 결과
def play_round(letters, answer='hello'):
    found, tries, feedback = set(), 0, []
    board = lambda: ' '.join(c if c in found else '_' for c in answer)
    for letter in letters.lower():
        tries += 1
        if letter in answer: found.add(letter)
        feedback.append(f'{letter} → {board()}')
        if all(c in found for c in answer): break
    won = all(c in found for c in answer)
    return feedback, ('승리' if won else '패배'), board(), tries
for letters in ('hleo', 'xyz', 'helloxyz'):
    fb, verdict, b, t = play_round(letters)
    print(fb[-1], '|', f'{verdict} — {b} ({t}글자)')
# o → h e l l o | 승리 — h e l l o (4글자)
# z → _ _ _ _ _ | 패배 — _ _ _ _ _ (3글자)
# o → h e l l o | 승리 — h e l l o (5글자)  ← 다 맞히면 남은 xyz는 안 쓴다
```
```python
# round_client 핵심 — 접수 → 결과를 콜백으로 잇는다
from rclpy.action import ActionClient
from my_interfaces.action import PlayRound


def send(self, letters):
    goal = PlayRound.Goal(); goal.letters = letters
    fut = self.cli.send_goal_async(goal, feedback_callback=self.on_fb)
    fut.add_done_callback(self.on_accept)


def on_accept(self, fut):
    gh = fut.result()
    if not gh.accepted:
        self.done = True
        return
    gh.get_result_async().add_done_callback(self.on_result)
```

```bash
ros2 action send_goal /play_round my_interfaces/action/PlayRound "{letters: 'hleo'}" --feedback

```
