# 통합 launch

## 정의·핵심
- **정의**: 앞 차시들에서 만든 노드를 **대본 한 장**으로 함께 띄우는 일 — 입문 끝의 `intro_final.launch.py`(노드 넷·그릇 둘)와 실습 끝의 `wrapup.launch.py`(노드 일곱 + 조건 둘) (입문 9차시 · 실습 8차시).
- **무엇을 넣나 — 노드의 수명이 대본의 수명과 같은가**: 늘 떠 있어야 할 노드(goal_publisher·goal_subscriber·calc_server·round_server)만. 부를 때마다 켜고 끝나는 노드(calc_client·round_client·guess_publisher)는 필요할 때 따로.
- **`package=`는 노드가 사는 그릇**: 빈 첫 그릇 `my_first_package`를 적으면 `package 'my_first_package' found at … but libexec directory '…/lib/my_first_package' does not exist`. round_server는 `package='hangman'` — 대본 그릇의 package.xml에 적지 않아도 됐다.
- **설치 목록은 `glob`으로**: `('share/' + package_name + '/launch', ['launch/bringup.launch.py'])`는 파일 하나만 올려 새 대본이 `file 'intro_final.launch.py' was not found in the share directory` → `glob('launch/*.launch.py')`(맨 위 `from glob import glob`). 등록 줄이 「있는지」가 아니라 **무엇을 올리는지** 읽는다. `ls install/my_py_pkg/share/my_py_pkg/launch`로 확인. `os.path.join` 꼴을 import os 없이 옮기면 `NameError: name 'os' is not defined`.
- **실측(intro_final)**: `process started` 넷, 줄마다 `[calc_server-3]` 같은 꼬리표. 새 터미널 `ros2 node list` → 넷, `ros2 service call /calc …` → `result=9.0, ok=True`, `send_goal /play_round "{letters: hleo}"` → `won: true`·`SUCCEEDED`.
- **wrapup.launch.py**: 인자 둘 `use_sim`(true)·`record`(false) — `DeclareLaunchArgument` + `LaunchConfiguration`.
  - `condition=IfCondition(use_sim)` turtlesim(`name='sim'`)
  - 실습6 camera_publisher·lane_detector·lane_follower(`remappings=[('/cmd_vel', '/turtle1/cmd_vel')]`)
  - 실습4 static_sensor_tf, 실습7 pc_pub·cloud_node
  - `ExecuteProcess(cmd=['ros2','bag','record','--topics', …], condition=IfCondition(record))`
  - o3d_node는 방을 켠 터미널에서 `--prefix python`으로만 서서 대본에서 뺀다.
- **실측(wrapup)**: 뜰 때 `process started` 일곱 줄(대괄호 안 = 실행 이름-차례 번호), 끌 때 `process has finished cleanly` 일곱 줄. `pc_pub-6`의 노드 이름은 `[cloud_pub]`. `use_sim:=false`면 여섯(/sim만 빠짐 — IfCondition이 인자를 읽었다는 표시). `record:=true`면 `[ros2-8] … rosbag2_recorder: Starting recording to 'rosbag2_…'`, 형식 mcap. lane.mp4 없을 때 GStreamer 경고 + 합성 프레임 폴백은 고칠 것이 아니다.

## 원리·구조
```
ros2 launch my_py_pkg wrapup.launch.py use_sim:=true record:=false
 ├─ [IfCondition use_sim] turtlesim_node (sim)
 ├─ camera_publisher → lane_detector → lane_follower (-r /cmd_vel → /turtle1/cmd_vel)
 ├─ static_sensor_tf
 ├─ pc_pub (cloud_pub) → cloud_node
 └─ [IfCondition record] ExecuteProcess: ros2 bag record
```

## 코드 예시
```python
# wrapup.launch.py — 인자 둘, 조건 둘, 리맵 하나
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, ExecuteProcess
from launch.conditions import IfCondition
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node


def generate_launch_description():
    use_sim = LaunchConfiguration('use_sim')
    record = LaunchConfiguration('record')
    return LaunchDescription([
        DeclareLaunchArgument('use_sim', default_value='true', description='turtlesim 을 함께 띄울지'),
        DeclareLaunchArgument('record', default_value='false', description='bag 으로 녹화할지'),
        Node(package='turtlesim', executable='turtlesim_node', name='sim', output='screen',
             condition=IfCondition(use_sim)),
        Node(package='my_py_pkg', executable='camera_publisher', output='screen'),
        Node(package='my_py_pkg', executable='lane_detector', output='screen'),
        Node(package='my_py_pkg', executable='lane_follower', output='screen',
             remappings=[('/cmd_vel', '/turtle1/cmd_vel')]),
        Node(package='my_py_pkg', executable='static_sensor_tf', output='screen'),
        Node(package='my_py_pkg', executable='pc_pub', output='screen'),
        Node(package='my_py_pkg', executable='cloud_node', output='screen'),
        ExecuteProcess(cmd=['ros2', 'bag', 'record', '--topics',
                            '/lane/offset', '/turtle1/cmd_vel', '/turtle1/pose'],
                       output='screen', condition=IfCondition(record)),
    ])
```
```python
# 인자에 따라 뜨는 프로세스 세기 — IfCondition 흉내
entries = [("turtlesim_node", "use_sim"), ("camera_publisher", None), ("lane_detector", None),
           ("lane_follower", None), ("static_sensor_tf", None), ("pc_pub", None), ("cloud_node", None),
           ("ros2", "record")]
def started(**args):
    on = [n for n, cond in entries if cond is None or args.get(cond) == "true"]
    return [f"{n}-{i}" for i, n in enumerate(on, 1)]
print(len(started(use_sim="true", record="false")))      # 7
print(len(started(use_sim="false", record="false")))     # 6
print(started(use_sim="true", record="true")[-1])        # ros2-8
```
```bash
ros2 launch my_py_pkg wrapup.launch.py
ros2 launch my_py_pkg wrapup.launch.py use_sim:=false
ros2 launch my_py_pkg wrapup.launch.py record:=true
ls install/my_py_pkg/share/my_py_pkg/launch
```
