# ROS2 트러블슈팅 총정리

## 정의·핵심
- **정의**: 과정 내내 실습 환경에 실제로 찍힌 오류를 **네 묶음**으로 모은 함정 표. 막혔을 때 「어느 층의 문제인가」부터 나누고, 코드를 고치기 전에 진단 도구로 시스템을 먼저 본다 (실습 8차시).
- **① 환경·실행 — 가장 자주, 가장 먼저**: 새 터미널마다 source를 잊는 일이 대부분.
  - `ros2: command not found` → `source /opt/ros/jazzy/setup.bash`
  - `Package 'my_py_pkg' not found` → `cd ~/ros2_ws && source install/setup.bash`
  - 다른 PC 노드가 보임/안 보임 → `ROS_DOMAIN_ID` 양쪽 같게
- **② 빌드·등록 — 거의 늘 setup.py의 작은 누락**:
  - `No executable found` → entry_points에 줄이 없거나 다시 빌드 안 함
  - `ModuleNotFoundError: No module named 'my_py_pkg.lane_detector'`(목록엔 보임) → 파일이 안쪽 `my_py_pkg/`에 없다
  - 입문 노드가 `StopIteration`·`Process exited with failure 1` → entry_points 블록을 통째로 덮어씀 → `cp setup.py.bak setup.py` 뒤 한 줄씩
  - `file '….launch.py' was not found in the share directory` → 빌드 안 함 또는 launch 줄이 파일 이름 꼴 → glob
  - `NameError: name 'os' is not defined` → import 없이 옮긴 줄
  - `src` 안에서 빌드 → `Failed to find the following files` + src에 build·install·log → 지우고 루트에서
  - `executable '…' not found on the libexec directory` → 대본의 실행 이름이 entry_points에 없다 → `ros2 pkg executables`와 한 글자씩 대조
- **③ 통신 — 노드는 멀쩡한데 데이터만 안 온다**, 원인마다 남기는 신호가 다르다:
  - 토픽 이름 불일치 → **아무 신호도 없다** → `topic list`·리맵
  - QoS 불일치 → `[WARN] … offering incompatible QoS. No messages will be received from it. Last incompatible policy: RELIABILITY` → `topic info --verbose`. 옵션 없는 echo는 발행자에 맞춰 붙어서 보인다.
  - 서비스 응답이 영영 안 옴 → 콜백의 `return response` 누락
  - `… Tf has two or more unconnected trees.` → TF 트리가 끊김 → `view_frames`
  - 변환은 되는데 값이 일정하게 어긋남 → static 변환 값 오등록
- **④ 창·그래픽·파이썬 환경 — 코드가 아니라 실행 환경**:
  - `qt.qpa.xcb: could not connect to display` … `[ros2run]: Aborted`(종료 코드 250, try로 못 살린다) → `echo $DISPLAY` → 데스크톱 터미널 → `QT_QPA_PLATFORM=offscreen`
  - gz sim이 굼뜨다(오류 없음) → `real_time_factor` — 느린 것이지 틀린 것이 아니다
  - `No module named 'open3d'` → colcon은 방을 모른다 → 방 켜고 `--prefix python`
  - pip로 들인 numpy 2·opencv 5 → cv_bridge `KeyError: 16` → apt 판 그대로

## 원리·구조
```
막혔다 → 어느 묶음인가?
  ① 명령·패키지가 없다          → source · ROS_DOMAIN_ID
  ② 목록·실행 파일·대본이 없다   → setup.py · 빌드 자리 · 다시 빌드
  ③ 떴는데 데이터가 없다        → 이름(무신호) · QoS(WARN) · TF(오류) · 응답(return)
  ④ 창·import에서 죽는다        → DISPLAY · 방(venv) · apt 판
```

## 코드 예시
```python
# 화면의 글자로 묶음과 처방 찾기
RULES = [
    ("command not found", "①", "source /opt/ros/jazzy/setup.bash"),
    ("Package '", "①", "cd ~/ros2_ws && source install/setup.bash"),
    ("No executable found", "②", "entry_points 확인 후 다시 빌드"),
    ("was not found in the share directory", "②", "빌드 · launch 줄을 glob 꼴로"),
    ("StopIteration", "②", "setup.py.bak로 되돌리고 한 줄씩"),
    ("incompatible QoS", "③", "topic info --verbose로 양쪽 대조"),
    ("unconnected trees", "③", "view_frames로 끊긴 지점"),
    ("could not connect to display", "④", "DISPLAY 확인 · offscreen"),
    ("No module named 'open3d'", "④", "방 켜고 ros2 run --prefix python"),
]
def triage(msg):
    for key, group, fix in RULES:
        if key in msg: return group, fix
    return "③", "아무 신호 없음 → topic list로 이름부터"
for m in ["bash: ros2: command not found",
          "Package 'my_py_pkg' not found",
          "[WARN] ... offering incompatible QoS. No messages will be received from it.",
          "qt.qpa.xcb: could not connect to display",
          ""]:
    print(triage(m))
# ('①', 'source /opt/ros/jazzy/setup.bash')
# ('①', 'cd ~/ros2_ws && source install/setup.bash')
# ('③', 'topic info --verbose로 양쪽 대조')
# ('④', 'DISPLAY 확인 · offscreen')
# ('③', '아무 신호 없음 → topic list로 이름부터')
```
