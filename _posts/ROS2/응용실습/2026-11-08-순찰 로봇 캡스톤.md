# 순찰 로봇 캡스톤

## 정의·핵심
- **정의**: 입문 과정을 닫는 과제 — 건물 복도를 도는 순찰 로봇(진짜 바퀴 없음: 한 바퀴 = 2초 기다림, 구역·배터리는 글자·숫자)을 **설계부터** 짓는다. 로봇 노드 하나와 명령행 관제까지 (입문 9차시).
- **설계 — 기능마다 통신을 묻는다**:
  - 상태를 알린다 — 계속 흐르고, 듣는 쪽이 몇인지 모르고, 답이 필요 없다 → **토픽** `/robot/status`
  - 짧은 명령 — 한 번 묻고 받아들였는지 알아야 한다 → **서비스** `/robot/command`
  - 순찰 — 오래 걸리고 진행을 알린다 → **액션** `/robot/patrol`
  - 발행 주기 — 코드 밖에서 조정 → **파라미터** `period`(통신이 아니라 손잡이)
  - 잘못 고르면: 순찰을 서비스로 → 몇 바퀴째인지 모른다 / 상태를 서비스로 → 여럿이 지켜보려면 저마다 계속 물어야 / 명령을 토픽으로 → 받아들였는지가 안 돌아온다.
- **노드는 `robot` 하나**: 배터리·위치는 한 곳에 — 명령(채움)·순찰(옮기며 씀)·상태(내보냄)가 같은 값을 읽고 쓴다. calculator와 같은 꼴. 이름표는 `/robot/` 아래로 모은다.
- **그릇 둘**: `patrol_msgs`(ament_cmake, 양식 셋 — `_msgs`는 std_msgs 같은 양식 패키지 이름 꼴) · `patrol_pkg`(ament_python, 노드·대본).
  - `RobotStatus.msg`: `float64 battery` · `string position`
  - `Command.srv`: `string order` --- `bool accepted`(CHARGE·HOME만 알아듣고 모르는 명령엔 false — Calc의 ok 자리)
  - `Patrol.action`: `int32 laps` --- `bool completed` --- `int32 progress`
- **실측**: `CHARGE`·`HOME` → accepted=True, `JUMP`·`charge`(소문자) → False. 순찰 3바퀴 → `순찰 1/3 — zone-B, 배터리 95.0` … `3/3 — zone-A, 배터리 85.0`, `completed: true`. 칸을 안 채우고 내보내면 `battery: 0.0`, `position: ''`(조용한 고장).
- **순찰 도중에 묻기**: 창구 하나면 `CHARGE → accepted=True`가 `순찰 5/5` 줄 바로 다음에야 찍힌다 → 셋을 `ReentrantCallbackGroup` + `MultiThreadedExecutor`로.
- **period 손잡이**: `create_timer` 때 한 번 읽고 끝이라 `param set /robot period 0.2`가 `Set parameter successful`이어도 박자 그대로 → 설정 콜백에서 `destroy_timer` 뒤 새 주기로 다시 만든다, 0 이하는 `Setting parameter failed: period 는 0 보다 커야 한다`. hz는 켠 뒤 평균이라 **새로 켜서** 잰다. 대본에서 `parameters=[{'period': 0.5}]` → `average rate: 2.000`.
- **사다리 여섯 단**: ⓪ 서버 창 · ① node list · ② node info·topic info(Type) · ③ echo·service call·send_goal · ④ 오래 걸리는 일 도중에도 흐르나 · ⑤ 끝 상태와 설정(param get·hz). 「목록에 보이면 살아 있다」는 거짓일 수 있다(데몬이 죽은 노드를 보여 줌 → `--no-daemon`) — 그래서 ⓪이 앞.

## 원리·구조
```
명령행 관제 ─service /robot/command (CHARGE/HOME)─▶ ┌──────────────────────┐ ─topic /robot/status─▶ 듣는 쪽 누구든
           ─action  /robot/patrol (laps)──────────▶ │ robot: battery, zone │
           ─param   period────────────────────────▶ └──────────────────────┘  (Reentrant + MultiThreaded)
```

## 코드 예시
```python
# robot 노드의 상태 로직만 — 명령·순찰·period 검증
ZONES = ['zone-A', 'zone-B', 'zone-C']
class Robot:
    def __init__(self): self.battery, self.zone_index, self.position, self.period = 100.0, 0, ZONES[0], 1.0
    def on_command(self, order):
        if order == 'CHARGE': self.battery = 100.0; return True
        if order == 'HOME': self.position = 'home'; return True
        return False
    def patrol(self, laps):
        for lap in range(1, laps + 1):
            self.zone_index = (self.zone_index + 1) % len(ZONES)
            self.position = ZONES[self.zone_index]
            self.battery = max(self.battery - 5.0, 0.0)
            print(f'순찰 {lap}/{laps} — {self.position}, 배터리 {self.battery}')
        return True
    def set_period(self, v):
        if not isinstance(v, (int, float)) or v <= 0: return 'Setting parameter failed: period 는 0 보다 커야 한다'
        self.period = v; return f'Set parameter successful → {1 / v:.3f} Hz'
r = Robot()
print([(o, r.on_command(o)) for o in ('CHARGE', 'HOME', 'JUMP', 'charge')])
r.position = ZONES[0]
print('completed:', r.patrol(3))
print(r.set_period(0.2)); print(r.set_period(0.0))
# [('CHARGE', True), ('HOME', True), ('JUMP', False), ('charge', False)]
# 순찰 1/3 — zone-B, 배터리 95.0
# 순찰 2/3 — zone-C, 배터리 90.0
# 순찰 3/3 — zone-A, 배터리 85.0
# completed: True
# Set parameter successful → 5.000 Hz
# Setting parameter failed: period 는 0 보다 커야 한다
```
```text
# period 설정 콜백 (robot 노드 안) — 타이머를 다시 만든다
def on_set(self, params):
    for p in params:
        if p.name == 'period':
            if p.value <= 0:
                return SetParametersResult(successful=False, reason='period 는 0 보다 커야 한다')
            self.destroy_timer(self.timer)
            self.timer = self.create_timer(p.value, self.report, callback_group=self.group)
    return SetParametersResult(successful=True)
```
```bash
ros2 service call /robot/command patrol_msgs/srv/Command "{order: 'CHARGE'}"
ros2 action send_goal /robot/patrol patrol_msgs/action/Patrol "{laps: 3}" --feedback
ros2 param set /robot period 0.2
ros2 topic hz /robot/status        # 새로 켜서 잰다
```
