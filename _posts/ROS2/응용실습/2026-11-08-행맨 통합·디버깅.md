# 행맨 통합·디버깅

## 정의·핵심
- **정의**: 계산기와 행맨을 함께 띄우고 **명령행만으로 구조를 읽은 뒤**, 행맨에 맞춘 **진단 사다리 네 단**으로 일부러 만든 고장 다섯을 찾는다 (입문 7차시).
- **통합 한 판(터미널 셋)**: ① `ros2 run hangman game_node` ② `ros2 topic echo /board` ③ `guess_publisher h/e/l/o` 차례로 → 게임 로그 `정답!` 넷과 `승리! 단어 완성`. 보드 터미널을 띄운 뒤 첫 추측을 잃으면 h 칸이 비어 `_ e l l o` — 빈 칸 글자를 한 번 더.
- **노드 목록에 서는 것 / 안 서는 것**: 계속 살아 있는 우리 노드(`/game_node`·`/round_server`·대본이 띄운 둘)만. `echo`·`topic pub`의 숨은 노드(`_ros2cli_`로 시작)와 한 번 쏘고 끝나는 `guess_publisher`는 없다. `ros2 node info /game_node` → 구독 `/guess`, 발행 `/board`.
- **사다리 네 단**(여섯 단을 행맨에 맞춰 — 그림 단은 node info가, 이름·연결은 topic info 한 번으로):
  - ① 노드가 살아 있나 — `ros2 node list`
  - ② 이름·타입이 같고 양쪽이 이어졌나 — `ros2 topic info /이름`: `Type:` 줄이 하나인가, 있어야 할 쪽이 1 이상인가
  - ③ 데이터가 흐르나 — `ros2 topic echo`
  - ④ 제 박자로 흐르나 — `ros2 topic hz`
  - 위에서부터 한 단씩 정상을 확정하며 내려간다. 걸리면 그 아래는 안 본다.
- **사다리를 탈 땐 추측을 계속 흘린다**: `ros2 topic pub -r 2 /guess std_msgs/msg/String "{data: 'x'}"` — 한 번 쏘는 발행자면 정상일 때도 ② 단 `Publisher count: 0`. 틀린 글자 x면 보드는 그대로이면서 발행만 계속.
- **고장 다섯 — 어느 것도 경고를 띄우지 않는다**:
  - ㉮ 노드를 안 켰다 → ① 단
  - ㉯ 이름이 한 글자 갈라졌다(`/guesses`) → ② 단, 양쪽에 0이 하나씩 → `topic list`·`node info`
  - ㉰ 이름은 같은데 타입이 갈라졌다 → ② 단, 수는 1·1인데 `Type:`이 둘 → `-v`로 누가 어느 타입인지
  - ㉱ 이어졌는데 흐르지 않는다 → ③ 단, echo는 조용한데 게임 로그는 찍힌다 → 콜백 안 발행 줄·조건
  - ㉲ 흐르는데 박자가 밀린다 → ④ 단, `/guess` 5Hz인데 `/board` 1Hz, 멈춘 뒤에도 열 줄(큐 깊이 10) → 콜백이 무엇을 붙들고 있나
- 넷 다 통과하면 통신은 정상 — 규칙 쪽을 본다.

## 원리·구조
| 단 | 명령 | 정상 | 고장 신호 |
|---|---|---|---|
| ① | node list | game_node가 보인다 | 없다(㉮) |
| ② | topic info | Type 하나 · 양쪽 ≥1 | 0이 있다(㉯) · Type 둘(㉰) |
| ③ | topic echo | 값이 찍힌다 | 조용하다(㉱) |
| ④ | topic hz | 박자를 따라간다 | 느리다(㉲) |

## 코드 예시
```python
# 사다리 네 단을 위에서부터 — 처음 걸리는 단과 처방
def ladder(s):
    if "game_node" not in s["nodes"]:
        return "① 노드를 띄운다"
    t = s["guess_info"]
    if t["pub"] == 0 or t["sub"] == 0:
        return "② 이름을 맞춘다 (topic list · node info)"
    if len(t["types"]) > 1:
        return "② 타입을 맞춘다 (topic info -v)"
    if not s["board_echo"]:
        return "③ 콜백 안 — 발행 줄·조건"
    if s["board_hz"] < s["guess_hz"]:
        return "④ 콜백이 오래 붙든다"
    return "통신 정상 — 규칙 쪽을 본다"
ok = {"nodes": ["game_node"], "guess_info": {"pub": 1, "sub": 1, "types": ["std_msgs/msg/String"]},
      "board_echo": True, "board_hz": 2.0, "guess_hz": 2.0}
faults = {
    "㉮": {**ok, "nodes": []},
    "㉯": {**ok, "guess_info": {"pub": 1, "sub": 0, "types": ["std_msgs/msg/String"]}},
    "㉰": {**ok, "guess_info": {"pub": 1, "sub": 1, "types": ["std_msgs/msg/String", "std_msgs/msg/Int32"]}},
    "㉱": {**ok, "board_echo": False},
    "㉲": {**ok, "board_hz": 1.0, "guess_hz": 5.0},
}
print("정상", ladder(ok))
for k, v in faults.items():
    print(k, ladder(v))
# 정상 통신 정상 — 규칙 쪽을 본다
# ㉮ ① 노드를 띄운다
# ㉯ ② 이름을 맞춘다 (topic list · node info)
# ㉰ ② 타입을 맞춘다 (topic info -v)
# ㉱ ③ 콜백 안 — 발행 줄·조건
# ㉲ ④ 콜백이 오래 붙든다
```
```bash
ros2 topic pub -r 2 /guess std_msgs/msg/String "{data: 'x'}"
ros2 node list
ros2 topic info /guess -v
ros2 topic echo /board
ros2 topic hz /board
```
