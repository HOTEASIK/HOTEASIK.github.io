# 계산기 노드 시스템

## 정의·핵심
- **정의**: 응용 사다리의 **둘째 칸** — 네 노드가 토픽·서비스·액션·파라미터를 나눠 쓰는 계산기. 노드 패키지 `ex_calculator`와 양식 패키지 `msg_srv_action_interface_example`을 새로 만든다 (입문 6차시).
- **성질이 셋이니 통신도 셋**:
  - `argument` — 두 수를 1초마다 토픽 `arithmetic_argument`(ArithmeticArgument: stamp, argument_a, argument_b)로. 범위는 파라미터 `min_random_num`(1)·`max_random_num`(9).
  - `operator` — 연산자를 서비스 `arithmetic_operator`(ArithmeticOperator: 상수 PLUS=1·MINUS=2·MULTIPLY=3·DIVISION=4, `int8 arithmetic_operator` → `float32 arithmetic_result`)로. 요청엔 수가 없다 — 가운데가 든 최신 두 수를 쓴다. 이름으로 부른다(`operator plus`, `+`는 KeyError).
  - `checker` — 목표 합계를 액션 `arithmetic_checker`(ArithmeticChecker: `goal_sum` → `all_formula`·`total_sum`, 피드백 `formula`)로 맡기고 진행을 받는다.
  - `calculator` — **가운데 노드 하나가 구독·서비스 서버·액션 서버를 함께** 받으며 상태(argument_a·b, argument_result, argument_formula)를 모은다.
- **누적은 「닿을 때까지」**: 마지막 계산 답을 1초마다 더한다 — 누적 98 + 곱하기 답 56 → **154**에서 끝(목표 100). 연산자 호출이 한 번도 없으면 `누적 0.0 / 100.0`만 되풀이(창구 문제가 아니다 — 계산: 줄이 없다).
- **창구(executor)와 콜백 그룹**: 셋을 한 `ReentrantCallbackGroup`에 두고 `MultiThreadedExecutor` → 누적이 오르는 동안 `수신:` 줄이 사이사이 계속. `USE_MULTI = False`(창구 하나, rclpy.spin)면 누적 9초 동안 수신이 **한 줄도 없다**가 점검 끝 직후 밀려 있던 수신 아홉 줄이 0.013초 안에 쏟아진다.
- **설정 콜백**: `add_on_set_parameters_callback` — min이 max보다 크면 `SetParametersResult(successful=False, reason='min 이 max 보다 크다')`로 거부, 값 유지.
- **launch와 param yaml**: 늘 떠 있어야 할 `argument`·`calculator`만 대본에(operator·checker는 부를 때마다 켜고 끝난다). `param/arithmetic_config.yaml`(min 10·max 99)을 `get_package_share_directory` 절대경로로, `DeclareLaunchArgument('param_dir')`로 바꿀 수 있게. 다른 파일은 `param_dir:=$HOME/…`(`~`는 단어 맨 앞이 아니라 안 풀린다).

## 원리·구조
```
argument ──topic arithmetic_argument (1s)──▶ ┌────────────┐ ◀──service arithmetic_operator── operator
                                              │ calculator │
  (param min/max · yaml)                      └────────────┘ ◀──action arithmetic_checker─── checker
                                         Reentrant 그룹 + MultiThreadedExecutor
```

## 코드 예시
```python
# 누적 점검 흉내: 마지막 계산 답을 1초마다 더해 목표에 「닿을 때까지」
def check(goal_sum, results_by_sec):
    total, formulas = 0.0, []
    last = 0.0
    for sec, r in enumerate(results_by_sec):
        if r is not None: last = r            # 그 사이 operator 호출로 답이 바뀜
        total += last
        formulas.append(last)
        if total >= goal_sum: return total, len(formulas)
    return total, None                        # 끝내 못 닿음
print(check(100.0, [14.0] + [None] * 6 + [56.0]))   # (154.0, 8)  ← 누적 98에 곱하기 답 56이 한 번에
print(check(100.0, [None] * 5))                                   # (0.0, None)  ← 누적 0.0 되풀이
```
```text
# 설정 콜백 — 범위가 뒤집히면 거부
from rcl_interfaces.msg import SetParametersResult


def on_set(self, params):
    lo, hi = self.min_random_num, self.max_random_num
    for p in params:
        if p.name == 'min_random_num': lo = p.value
        elif p.name == 'max_random_num': hi = p.value
    if lo > hi:
        return SetParametersResult(successful=False, reason='min 이 max 보다 크다')
    self.min_random_num, self.max_random_num = lo, hi
    return SetParametersResult(successful=True)
```
```bash
ros2 launch ex_calculator arithmetic.launch.py
ros2 run ex_calculator operator plus
ros2 run ex_calculator checker 100
ros2 param set /argument min_random_num 50
```
