# 행맨 게임 노드

## 정의·핵심
- **정의**: 글자 하나를 보내면 보드가 돌아오는 게임의 **상태 노드** `game_node` — `/guess`를 구독하고 `/board`를 발행하며, 그 사이에 맞힌 글자(`found`)를 **기억**한다 (입문 7차시).
- **계산기와의 차이**: calculator는 세 통신을 받는 쪽이었다 — 행맨은 받으면서 내보내고 그 사이에 상태를 든다. 입력을 받아 상태를 바꾸고 결과를 내보내는 꼴은 로봇 제어 노드의 뼈대와 같다(신호등·자판기·동작 모드도 상태 기계).
- **토픽 둘, 표준 타입**: 추측·보드 둘 다 문자열 하나면 충분 → `std_msgs/String`을 빌린다. 코드의 `'guess'`와 명령행의 `/guess`는 같은 이름.
- **상태**: 정답 `'hello'`, `found = set()`(같은 글자를 여러 번 보내도 한 번), 틀린 횟수 `wrong`(도전: 파라미터 `max_wrong` 6 → 남은 목숨, `게임 오버 (정답: hello)`).
- **콜백 앞머리 — 다듬고 한 글자만**: `strip().lower()` 뒤 `len != 1`이면 `한 글자만 입력하세요`. 빼면 `'he' in 'hello'`(부분 문자열도 참)로 `정답! he`인데 보드는 `_ _ _ _ _` 그대로.
- **사건 발행**: 추측이 와야만 보드를 낸다 — 아무도 안 보내면 `/board`는 영영 조용(고장이 아니라 사건이 없는 것). 주기 발행(my_publisher의 타이머)과 대비.
- **추측 노드 `guess_publisher`**: 한 번 쏘고 끝나는 발행자 — `spin_once`로 틈을 주고 보낸 뒤 또 틈. 연결이 잡히기 전에 끝나면 첫 글자를 잃는다(19판 중 6판, 모두 보드 터미널을 띄운 뒤의 첫 추측) → 받는 쪽(`get_subscription_count()`)을 기다리게 고치면 열 번 모두 받았다.
- **명령행 테스트**: `ros2 topic pub --once /guess std_msgs/msg/String "{data: 'h'}"` → `data: h _ _ _ _`, 이어 `e` → `h e _ _ _`(토픽 왕복 완성). `Waiting for at least 1 matching subscription(s)...`가 먼저 떠도 된다.

## 원리·구조
```
guess_publisher ─/guess (String)─▶ game_node [answer='hello', found={…}, wrong] ─/board (String)─▶ echo · 구독자 여럿
                                     on_guess: 다듬기 → 한 글자 검증 → found/wrong 갱신 → 보드 발행 → 승리 판정
```

## 코드 예시
```python
# game_node의 규칙만 떼어 — ROS 없이 콜백을 차례로 불러 본다
class Game:
    def __init__(self, answer='hello', max_wrong=6):
        self.answer, self.found, self.wrong, self.max_wrong = answer, set(), 0, max_wrong
    def board(self):
        return ' '.join(c if c in self.found else '_' for c in self.answer)
    def on_guess(self, data):
        if self.wrong >= self.max_wrong: return '이미 끝난 판'
        letter = data.strip().lower()
        if len(letter) != 1: return '한 글자만 입력하세요'
        if letter in self.answer: self.found.add(letter)
        else: self.wrong += 1
        out = self.board()
        if self.wrong >= self.max_wrong: out += f'  게임 오버 (정답: {self.answer})'
        if all(c in self.found for c in self.answer): out += '  승리!'
        return out
g = Game()
for d in ['h', ' E ', 'he', 'x', 'l', 'o']:
    print(repr(d), '→', g.on_guess(d))
# 'h' → h _ _ _ _
# ' E ' → h e _ _ _
# 'he' → 한 글자만 입력하세요
# 'x' → h e _ _ _
# 'l' → h e l l _
# 'o' → h e l l o  승리!
g2 = Game(max_wrong=2)
print(g2.on_guess('x'), '|', g2.on_guess('z'), '|', g2.on_guess('h'))
# _ _ _ _ _ | _ _ _ _ _  게임 오버 (정답: hello) | 이미 끝난 판
```
```bash
ros2 run hangman game_node
ros2 topic echo /board
ros2 topic pub --once /guess std_msgs/msg/String "{data: 'h'}"
ros2 run hangman guess_publisher e
```
