# 임베디드 시스템과 SBC

## 정의·핵심
- **임베디드(내장형) 시스템**: 기계 속에 박혀 **한 가지 일만** 하는 작은 컴퓨터. 전자레인지는 「버튼을 누르면 3분 돌려라」만 평생 한다. 메모리를 빈틈없이 통제해야 해 C/C++가 선호된다 (기초 3차시).
- **IoT(사물 인터넷)**: 센서 달린 사물들이 인터넷으로 데이터를 주고받는다 (밖에서 폰으로 보일러 켜기).
- **로봇 컴퓨터는 크게 둘 — 역할 분담**
  - **SBC(싱글 보드 컴퓨터)**: CPU·메모리·저장장치를 보드 한 장에. 리눅스를 올려 영상 처리·복잡한 연산 = **무거운 판단**. 라즈베리파이, 비글본, NVIDIA Jetson.
  - **제어기(Controller)**: 특정 작업을 빠르고 정확하게(실시간) 처리 = **정확한 타이밍**. 보통 MCU + 가벼운 실시간 OS(RTOS). 산업용 PLC, 자동차 ECU.
  - TurtleBot3에는 라즈베리파이(SBC)와 OpenCR(제어기)이 함께 들어가 시리얼로 대화한다.
- **펌웨어**: ROM·플래시에 새겨져 하드웨어를 직접 부리는 프로그램 (프린터 제어, 라우터 부팅).
- **ROS는 어느 층에 사나** (3.4): 펌웨어보다 위, 우리가 짜는 노드보다 아래 — **미들웨어**. 정확히는 DDS가 미들웨어이고 ROS는 그 위에 로봇 개발자가 쓰기 좋게 올린 한 겹.

## 원리·구조
| 층 | 하는 일 | 예 |
|---|---|---|
| 우리가 짜는 노드 | 이름(토픽)만 맞추고 대화 | 카메라 노드, 모터 노드 |
| 미들웨어 | 프로그램끼리 데이터 중개 | ROS(DDS), 메시징 미들웨어 |
| 펌웨어 | 하드웨어 직접 제어 | OpenCR 펌웨어, 라우터 부팅 |
```
[SBC: 라즈베리파이 + Ubuntu + ROS2] ──USB·UART 시리얼──→ [제어기: OpenCR (MCU)] → 모터·엔코더
       무거운 판단(SLAM·인식)                                  정확한 타이밍(PWM·펄스 카운트)
```

## 코드 예시
```python
# 임베디드식 '한 가지 일만' 하는 고정 주기 루프 흉내 (제어기의 역할)
import time
period, ticks, t0 = 0.01, [], time.perf_counter()     # 100Hz 제어 주기
for k in range(5):
    ticks.append(round(time.perf_counter() - t0, 2))
    time.sleep(max(0, t0 + (k + 1) * period - time.perf_counter()))  # 다음 박자까지 대기
print(len(ticks), ticks[0])                          # 5 0.0
```
