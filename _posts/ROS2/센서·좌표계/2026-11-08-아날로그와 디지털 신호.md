# 아날로그와 디지털 신호

## 정의·핵심
- **아날로그 신호**: 값이 **매끄럽게 이어지는** 신호. 전압·전류의 세기 자체가 정보다 (기초 3차시).
  - 예: 어떤 온도센서 사양 「측정 범위 −100℃ ~ +100℃, 출력 4~20mA」 → 4mA = −100℃, 12mA = 0℃, 20mA = +100℃. 전류 세기를 읽으면 온도를 거꾸로 알 수 있게 **비례**로 설계해 둔 것.
  - 4~20mA 전류 루프는 0mA가 "단선"으로 구분돼 산업 현장에서 많이 쓴다.
- **디지털 신호**: 켜짐(HIGH)과 꺼짐(LOW) **두 값뿐**.
- **둘을 오가는 다리**
  - 아날로그 → 디지털: **ADC** (연속값을 일정 간격으로 끊어 숫자로).
  - 디지털 → 아날로그처럼: **PWM**(켜진 시간 비율) 또는 DAC.
- **흐름**: 아날로그 센서가 매끄러운 값을 만든다 → ADC가 숫자로 바꾼다 → 컴퓨터가 판단한다 → PWM이나 DAC로 아날로그로 내보낸다.

## 원리·구조
$$I = 4 + 16\cdot\frac{T - T_{min}}{T_{max}-T_{min}}\ [\text{mA}]
\quad\Longleftrightarrow\quad
T = T_{min} + (T_{max}-T_{min})\cdot\frac{I-4}{16}$$
```
아날로그:  ／￣＼＿／￣    (연속)
디지털  :  ┌┐ ┌──┐ ┌┐     (0 또는 1)
```

## 코드 예시
```python
# 4~20mA 전류값을 온도로 되읽기 (아날로그 → 숫자 해석)
def mA_to_temp(i, t_min=-100, t_max=100):
    return t_min + (t_max - t_min) * (i - 4) / 16
print([mA_to_temp(i) for i in (4, 8, 12, 20)])   # [-100.0, -50.0, 0.0, 100.0]
print(mA_to_temp(0) < -100)                       # True  (범위 밖 → 단선 의심)
```
