# 로봇 시스템 구성

## 정의·핵심
- **기능으로 나누면 — 감지·판단·행동의 고리** (기초 3차시)
  - Sense(입력): 센서로 세상을 느낀다.
  - Plan(처리): 컴퓨터로 어떻게 할지 생각한다.
  - Act(출력): 모터로 움직인다.
  - 1초에 수십 번 쉬지 않고 반복. 로봇청소기: 거리센서로 벽을 느끼고 → 「막혔으니 돌자」 → 바퀴를 돌린다. 기술적으로는 인식·분석·동작이라고도 부른다.
- **물건으로 나누면 — 세 요소**: 셋 중 하나만 빠져도 로봇은 서지 않는다.
  - 기계(뼈대·관절): 프레임·바퀴·링크와 조인트·기어와 벨트.
  - 전기·전자(신경·혈관): 센서·액추에이터·배선·전원부·모터 드라이버·제어 보드.
  - 소프트웨어(머리): 판단·명령 프로그램, 프로그램을 잇는 미들웨어.
  - 컵 하나를 집을 때도 기계(링크·그리퍼)가 움직이고, 전기(모터·엔코더)가 일으키고 되읽으며, 소프트웨어(제어 알고리즘)가 얼마나 돌릴지 계산한다.
- **센서·판단·모터는 다른 팀이 맡는다**: 현업에서는 보통 다른 팀·다른 프로그램 → 그래서 주고받아야 하고, 그 주고받기를 깔끔하게 해 주는 접착제가 **ROS**.
  - 산업용 센서의 핀 3개(Txd·Rxd·Gnd)는 RS-485 — 한 선에 여러 장치를 엮는 발상은 ROS가 여러 노드를 한 토픽으로 엮는 것과 닮았다.
- 다음 물음: 카메라는 머리에, 바퀴는 바닥에 있다 → 카메라가 본 컵이 손 기준으로는 어디일까? → **좌표계**.

## 원리·구조
```
 ┌── Sense ──┐     ┌── Plan ──┐     ┌── Act ──┐
 │ 센서 노드  │ ──→ │ 판단 노드 │ ──→ │ 모터 노드 │
 └───────────┘ 토픽 └──────────┘ 토픽 └─────────┘
        ↑                                   │
        └──────────── 세상(환경) ←──────────┘
```

## 코드 예시
```python
# Sense-Plan-Act 고리: 벽까지 거리를 보고 멈추거나 도는 로봇청소기
dist = 1.0
log = []
for step in range(6):
    sensed = round(dist, 2)                       # Sense
    action = "turn" if sensed <= 0.3 else "go"    # Plan
    if action == "go": dist -= 0.2                # Act (세상이 바뀐다)
    else: dist = 1.0                              # 돌아서 새 방향
    log.append((sensed, action))
print(log)
# [(1.0, 'go'), (0.8, 'go'), (0.6, 'go'), (0.4, 'go'), (0.2, 'turn'), (1.0, 'go')]
```
