# 액추에이터

## 정의·핵심
- **정의**: 전기 신호를 받아 **실제로 움직이는 근육**. 센서가 입력이라면 반대편에서 판단을 「실행」하는 출력 (기초 3차시).
- **모터 네 종류**
  - **DC 모터**: 전압을 걸면 계속 돈다. 빠르지만 각도 제어는 약함 → 바퀴, 팬.
  - **서보모터**: 목표 각도를 주면 그 각도로 정확히 돌고 멈춘다 → 로봇 팔 관절, 그리퍼, 카메라 각도. 속에 엔코더가 있어 닫힌 고리. 각도는 PWM 펄스폭으로 받는다(1.0~2.0ms).
  - **스테퍼모터**: 한 펄스에 정해진 각도만큼 또각또각 → 3D 프린터, 한 칸씩 정밀 이동.
  - **BLDC 모터**: 브러시가 없어 마찰·소음이 적고 효율이 높다 → 드론 프로펠러, 고성능 휠, 전기차.
- **ROS에서**: 판단 노드가 `/cmd_vel`(Twist) 같은 명령을 발행 → 모터 드라이버 노드·제어보드가 받아 PWM·전류로 바꿔 모터를 돌린다. 팔 로봇은 관절 명령(두산 `MoveJoint` 서비스 등)으로.

## 원리·구조
| 모터 | 어떻게 도나 | 어디에 쓰나 |
|---|---|---|
| DC | 전압 → 계속 회전 | 바퀴, 팬 |
| 서보 | 목표 각도로 정확히 | 팔 관절, 그리퍼 |
| 스테퍼 | 펄스당 정해진 각도 | 3D 프린터 |
| BLDC | 브러시 없음, 고효율 | 드론, 전기차 |

## 코드 예시
```python
# 스테퍼: 1.8°/스텝 모터로 90° 돌리려면 몇 펄스? / 서보: 각도 → 펄스폭
step_deg = 1.8
print(round(90 / step_deg), "펄스")                 # 50 펄스
def servo_pulse_ms(angle):
    return 1.0 + angle / 180 * 1.0
print([servo_pulse_ms(a) for a in (0, 90, 180)])   # [1.0, 1.5, 2.0]
```
