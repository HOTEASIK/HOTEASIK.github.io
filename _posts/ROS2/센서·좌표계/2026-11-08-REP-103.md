# REP-103

## 정의·핵심
- **정의**: ROS의 **좌표 축 방향·단위 약속** (ROS Enhancement Proposal 103, ros.org/reps/rep-0103.html). 기준 하나를 정해도 그 안에서 어느 쪽이 앞이고 왼쪽인지 또 약속이 필요하다 (기초 3차시).
- **몸통 프레임(base_link 같은)**: **+X 앞, +Y 왼쪽, +Z 위**.
- **카메라 같은 광학 센서 프레임(`*_optical_frame`)**: **+X 오른쪽, +Y 아래, +Z 렌즈가 보는 방향(앞)**.
- **오른손 법칙**: 오른손 엄지=X, 검지=Y, 중지=Z. 회전의 양(+) 방향은 축을 엄지로 쥐었을 때 나머지 손가락이 감기는 방향(반시계) → 요(z축) +는 왼쪽으로 돌기.
- **단위**: 길이 미터(m), 각도 라디안(rad), 시간 초(s). `cmd_vel`의 `linear.x`는 m/s, `angular.z`는 rad/s.
- **왜 중요한가**: 이 약속 덕분에 남이 짠 ROS 패키지도 「몸통 프레임이면 앞이 +X」라고 믿고 쓴다. 나중에 TF2로 `base_link ↔ laser` 변환을 다룰 때도 전제로 깔려 있다.
- 몸으로 해 보기: 마주 본 사람이 오른손을 들면 내게는 왼쪽 — 기준이 바뀌면 방향이 뒤집힌다.

## 원리·구조
```
 몸통 base_link (위에서 봄)          카메라 optical frame (렌즈 뒤에서 봄)
        +X (앞)                              +Z (앞, 화면 안쪽)
         ↑                                  ┌──────→ +X (오른쪽)
 +Y ←────●  (+Z: 화면 밖, 위)               │
 (왼쪽)                                     ↓ +Y (아래)
```

## 코드 예시
```python
# 카메라 광학 프레임 점(x 오른쪽, y 아래, z 앞) → 몸통 규약(x 앞, y 왼쪽, z 위)
import numpy as np
R = np.array([[0, 0, 1],      # 몸통 x(앞)   = 광학 z
              [-1, 0, 0],     # 몸통 y(왼쪽) = −광학 x
              [0, -1, 0]])    # 몸통 z(위)   = −광학 y
p_opt = np.array([0.1, -0.2, 0.5])          # 렌즈 앞 0.5m, 오른쪽 0.1m, 위 0.2m
print(R @ p_opt)                             # [ 0.5 -0.1  0.2]
print(np.allclose(np.cross(R[0], R[1]), R[2]))   # True  (오른손 좌표계 유지)
```
