# 센서 특성

## 정의·핵심
- **정의**: 센서를 고를 때 저울질하는 지표들. 핵심만 추리면 열 가지다 (기초 3차시).

| 지표 | 무엇을 보나 | 지표 | 무엇을 보나 |
|---|---|---|---|
| 가격 | 팔 때 단가에 반영 | 감도 | 입력 변화에 얼마나 민감한가 |
| 크기·무게 | 작업 영역에 비해 과하지 않나 | 선형성 | 입력과 출력이 비례하는가 |
| 출력 형태 | 아날로그면 ADC가 더 필요 | 응답시간 | 출력이 입력을 따라잡는 시간 |
| 인터페이싱 | 제어기와 연결 방식이 맞나 | 정확성·반복정밀도 | 목표치에 가깝나, 늘 같은 값인가 |
| 분해능 | 측정할 수 있는 최소 단위 | 신뢰성 | 고장 없이 운용된 정도 |

- **헷갈리기 쉬운 두 쌍**
  - **감도 vs 응답시간**: 얼마나 *작은* 변화까지 잡느냐 vs 변화를 얼마나 *빨리* 따라잡느냐.
  - **정확성 vs 반복정밀도**: 과녁 한가운데에 얼마나 가까운가(평균의 치우침) vs 여러 번 쐈을 때 탄착군이 얼마나 모였나(흩어짐).
  - 늘 한곳에 빗맞으면 정밀도는 높지만 정확하지는 않다 → 이런 고정 치우침은 **보정(calibration)** 으로 빼낼 수 있다.
- 센서는 무작정 비싼 것이 아니라 상황에 맞는 것을 고른다.

## 원리·구조
```
정확 O·정밀 O   정확 X·정밀 O   정확 O·정밀 X   정확 X·정밀 X
    ◎•••            ◎   •••        • ◎  •         •   ◎
                                     •                  •
```
$$\text{정확성 오차} = |\bar{x}-x_{참}|,\qquad \text{반복정밀도} \sim \sigma(x)$$

## 코드 예시
```python
# 두 거리 센서로 참값 2.00m를 10번 잰 결과: 정확성(평균 치우침) vs 정밀도(표준편차)
import numpy as np
true = 2.00
a = np.array([2.21, 2.20, 2.19, 2.20, 2.21, 2.20, 2.19, 2.20, 2.21, 2.20])  # 늘 한곳에 빗맞음
b = np.array([1.90, 2.12, 2.03, 1.95, 2.08, 1.97, 2.05, 1.92, 2.10, 1.98])  # 평균은 맞지만 흩어짐
for name, x in (("A", a), ("B", b)):
    print(name, "치우침", round(abs(x.mean() - true), 3), "흩어짐", round(x.std(), 3))
# A 치우침 0.201 흩어짐 0.007   ← 정밀하지만 부정확 → 0.2m 보정하면 해결
# B 치우침 0.01 흩어짐 0.073    ← 정확하지만 덜 정밀
```
