# 엔코더

## 정의·핵심
- **정의**: 모터·바퀴의 **회전량**을 펄스 수로 세는 센서. 회전량 × 바퀴 둘레로 이동거리를 계산한다 (기초 3차시).
- **강점**: 정밀하고 싸다. 서보모터 속 위치 센서가 바로 엔코더 — 명령대로 움직였는지 스스로 되읽는 **닫힌 고리**를 이룬다.
- **한계 — 미끄러짐과 누적 오차**: 엔코더는 바퀴가 돈 만큼만 안다. 바닥이 미끄러워 헛돌면 「2미터 갔다」는데 실제로는 1.9미터. 이 오차는 시간이 갈수록 **누적**된다 → IMU·라이다와 퓨전해 깎아낸다.
- **ROS에서**: 바퀴 엔코더 값으로 계산한 위치가 **오도메트리**(`/odom`, `odom → base_link` TF). TurtleBot3는 OpenCR 보드가 엔코더를 읽어 시리얼로 보고한다.
- 차동 구동 로봇은 왼·오른 바퀴 엔코더의 차이로 회전까지 계산한다.

## 원리·구조
$$d = \frac{\text{펄스 수}}{\text{1회전 펄스(PPR)}}\times 2\pi r$$
$$\text{차동 구동: } \Delta s = \frac{d_R + d_L}{2},\quad \Delta\theta = \frac{d_R - d_L}{L}\ (L:\text{바퀴 간격})$$

## 코드 예시
```python
import math
PPR, r = 4096, 0.033                       # 1회전 4096펄스, 바퀴 반지름 3.3cm (예시 값)
def dist(pulses):
    return pulses / PPR * 2 * math.pi * r
pulses = round(2.0 / (2 * math.pi * r) * PPR)   # 2m 가는 데 필요한 펄스
print(pulses, round(dist(pulses), 3))           # 39509 2.0

slip = 0.05                                      # 5% 헛돎
print("실제 이동", round(dist(pulses) * (1 - slip), 2))   # 실제 이동 1.9
# 10번 반복하면 오차도 10배로 누적
print("누적 오차", round(10 * dist(pulses) * slip, 2), "m")   # 누적 오차 1.0 m
```
