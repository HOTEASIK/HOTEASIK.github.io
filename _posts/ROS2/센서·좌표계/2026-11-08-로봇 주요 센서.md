# 로봇 주요 센서

## 정의·핵심
- **정의**: 로봇이 가장 많이 쓰는 다섯 센서 — 라이다·카메라·IMU·엔코더·초음파. 무엇을 재고, 어디에 강하고, 어떤 한계가 있는지가 갈린다 (기초 3차시).
- **완벽한 센서는 없다** → 실제 로봇은 여러 센서를 함께 달아 약점을 메운다 = **센서 퓨전**.
  - 엔코더는 「2미터 갔다」는데 바닥이 미끄러워 실제로는 1.9미터 → IMU·라이다 값을 보태 미끄러짐 오차를 깎는다.
  - 카메라 「저게 사람」 + 라이다 「2.3미터 앞」 → 「2.3미터 앞에 사람이 있다」는 온전한 판단.
  - 카메라파 대 라이다파 — 테슬라 옵티머스는 "사람도 눈 두 개로 다닌다"며 카메라만 고집. 정답은 아직 없다.
- 합치려면 데이터를 **같은 규칙으로** 주고받아야 하고, 그 규칙이 ROS(표준 메시지 + 좌표계 약속)다.
- **ROS 표준 메시지**: 라이다 `sensor_msgs/LaserScan`·`PointCloud2`, 카메라 `sensor_msgs/Image`, IMU `sensor_msgs/Imu`, 엔코더 → `nav_msgs/Odometry`, 초음파 `sensor_msgs/Range`.

## 원리·구조
| 센서 | 재는 것 | 강점 | 한계 |
|---|---|---|---|
| 라이다 | 거리(360도 지도) | 어두워도 정확, 넓은 범위 | 색·글자 불가, 유리·거울 약함, 고가 |
| 카메라 | 색·모양·글자 | 풍부한 정보, 인식에 강함 | 거리 직접 측정 어려움, 어둠·역광 약함 |
| IMU | 기울기·가속·회전 | 균형·자세 추정 필수 | 누적 드리프트, 단독 위치추정 부정확 |
| 엔코더 | 회전량·이동거리 | 정밀, 저가 | 미끄러짐 시 오차 누적 |
| 초음파 | 가까운 거리 | 저가·단순 | 짧은 범위, 방향 분해능 낮음 |

## 코드 예시
```python
# 아주 단순한 센서 퓨전: 분산이 작은(믿을 만한) 센서에 더 큰 가중치 (역분산 가중 평균)
enc, var_enc = 2.00, 0.04     # 엔코더: 미끄러짐으로 불확실
lid, var_lid = 1.90, 0.01     # 라이다로 잰 이동거리: 더 정확
w_enc, w_lid = 1 / var_enc, 1 / var_lid
fused = (w_enc * enc + w_lid * lid) / (w_enc + w_lid)
print(round(fused, 3), round(1 / (w_enc + w_lid), 4))   # 1.92 0.008  ← 둘보다 분산이 작다
```
