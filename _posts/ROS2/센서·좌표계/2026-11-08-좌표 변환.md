# 좌표 변환

## 정의·핵심
- **정의**: 한 프레임 기준으로 적힌 위치를 다른 프레임 기준으로 **번역**하는 일. 카메라가 「컵이 내 앞 50센티」라고 알려줘도, 컵을 잡으려면 몸통에 붙은 손 기준 위치가 필요하다 → 카메라 기준을 손 기준으로 번역 (기초 3차시).
- **변환(transform)** = 두 프레임 사이의 고정(또는 움직이는) 위치 관계 = **평행이동 + 회전**.
- **숫자 하나로 그려 보기** (⚡ 심화): 라이다가 몸통(`base_link`) 한가운데서 앞 20cm·위 30cm에 고정 → 변환 (0.20, 0, 0.30). 라이다가 정면 벽을 `laser` 기준 (2.0, 0, 0)으로 보고 → 변환을 더하면 몸통 기준 (2.20, 0, 0.30). "라이다는 정면 2미터라는데, 몸통 기준으로는 2.2미터다".
- 센서가 비스듬히 기울어 달려 있으면 **회전까지 섞여** 계산이 복잡해진다 → 회전 행렬(또는 쿼터니언) + 이동을 한 표에 담은 **4×4 변환 행렬**.
- `tf2_echo`의 마지막 `Matrix` 넉 줄이 바로 이 행렬이다 — 맨 오른쪽 열 위 세 칸이 Translation (실습 4차시).
- 좋은 소식: 우리가 직접 계산하지 않아도 된다 — **TF2**가 해 준다.

## 원리·구조
$$p_{base} = R\,p_{laser} + t
\qquad\Longleftrightarrow\qquad
\begin{bmatrix}p_{base}\\1\end{bmatrix}=
\begin{bmatrix}R & t\\ 0 & 1\end{bmatrix}
\begin{bmatrix}p_{laser}\\1\end{bmatrix}$$
$$R_z(\psi)=\begin{bmatrix}\cos\psi&-\sin\psi&0\\ \sin\psi&\cos\psi&0\\0&0&1\end{bmatrix}$$

## 코드 예시
```python
import numpy as np
def T(R, t):
    M = np.eye(4); M[:3, :3] = R; M[:3, 3] = t; return M
def Rz(deg):
    a = np.deg2rad(deg); c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])

wall_laser = np.array([2.0, 0, 0, 1])
T_base_laser = T(np.eye(3), [0.20, 0, 0.30])          # 회전 없음
print(np.round(T_base_laser @ wall_laser, 3)[:3])     # [2.2 0.  0.3]

T_tilt = T(Rz(90), [0.20, 0, 0.30])                   # 라이다가 왼쪽으로 90° 돌아 달림
print(np.round(T_tilt @ wall_laser, 3)[:3])           # [0.2 2.  0.3]
print(np.round(np.linalg.inv(T_base_laser) @ np.array([2.2, 0, 0.3, 1]), 3)[:3])   # [2. 0. 0.]  (역변환)
```
