# ADC

## 정의·핵심
- **정의**: Analog-to-Digital Converter. 아날로그 센서의 연속값을 **일정 간격으로 끊어 숫자로** 바꾸는 장치. 디지털 컴퓨터가 아날로그 센서를 읽으려면 반드시 거친다 (기초 3차시).
- **분해능(resolution)**: 끊는 칸의 개수.
  - 10비트: 0~1023, 1024단계 / 12비트: 0~4095, 4096단계.
  - 같은 0~5V 입력이라도 12비트가 더 잘게 쪼개 미세한 변화를 잡는다.
- **샘플링**: 시간 방향으로도 일정 간격마다 값을 찍는다(샘플링 주기). 너무 드물게 찍으면 빠른 변화를 놓친다.
- **양자화 오차**: 칸 사이의 값은 가까운 칸으로 반올림되므로 최대 ½칸만큼의 오차가 생긴다.
- ROS 토픽 위를 흐르는 숫자들도 거슬러 올라가면 거의 다 ADC를 한 번 거친 값이다.

## 원리·구조
$$\text{코드} = \operatorname{round}\!\left(\frac{V_{in}}{V_{ref}}\,(2^{n}-1)\right),\qquad
\text{한 칸} = \frac{V_{ref}}{2^{n}-1}$$
| ADC | 범위 | 칸 개수 | 0~5V에서 한 칸 |
|---|---|---|---|
| 10비트 | 0~1023 | 1024 | 약 4.9 mV |
| 12비트 | 0~4095 | 4096 | 약 1.2 mV |

## 코드 예시
```python
# 같은 전압을 10비트·12비트 ADC로 읽고, 되돌렸을 때 오차 비교
def adc(v, bits, vref=5.0):
    return round(v / vref * (2 ** bits - 1))
def back(code, bits, vref=5.0):
    return code * vref / (2 ** bits - 1)
v = 1.2345
for bits in (10, 12):
    c = adc(v, bits)
    print(bits, c, round(abs(back(c, bits) - v) * 1000, 3), "mV 오차")
# 10 253 2.059 mV 오차
# 12 1011 0.068 mV 오차
print(round(5.0 / 1023 * 1000, 2), round(5.0 / 4095 * 1000, 2))   # 4.89 1.22
```
