# PWM

## 정의·핵심
- **정의**: Pulse Width Modulation(펄스 폭 변조). 켜짐·꺼짐 두 값뿐인 디지털 신호로, **켜진 시간의 비율**을 조절해 아날로그처럼 「세기」를 표현하는 방법 (기초 3차시).
- **듀티 사이클(duty cycle)**: 한 주기 중 켜진 시간의 비율.
- **예**: 켜짐 5ms + 꺼짐 5ms → 한 주기 10ms → 1초에 100번 → 주파수 100Hz, 듀티 50%.
- **쓰임**
  - LED 밝기: 켜진 시간 20%면 어둑, 80%면 환하다 — 눈에는 밝기 차이로 느껴진다.
  - DC 모터 속도: 듀티가 클수록 평균 전압↑ → 빨리 돈다.
  - **서보모터 각도**: 흔한 서보는 주기 20ms(50Hz) 신호에서 켜진 시간으로 각도를 받는다 — 1.0ms 0°, 1.5ms 90°, 2.0ms 180°.
- 두 값뿐인 디지털이 **시간 비율 하나로** 각도와 밝기를 만든다.

## 원리·구조
$$\text{듀티} = \frac{t_{on}}{T},\qquad f = \frac{1}{T},\qquad V_{평균} = \text{듀티}\times V_{max}$$
```
듀티 20%: ┌┐────┌┐────┌┐────
듀티 80%: ┌────┐┌────┐┌────┐
```

## 코드 예시
```python
# PWM 기본 계산 + 서보 펄스폭 → 각도 (1.0ms=0°, 2.0ms=180°)
t_on, t_off = 5e-3, 5e-3
T = t_on + t_off
print(round(1 / T), "Hz", t_on / T * 100, "%")      # 100 Hz 50.0 %

def servo_angle(pulse_ms):
    return (pulse_ms - 1.0) / 1.0 * 180
print([servo_angle(p) for p in (1.0, 1.5, 2.0)])    # [0.0, 90.0, 180.0]
print(0.8 * 5.0, "V")                               # 4.0 V  (듀티 80%, 5V 평균 전압)
```
