# 오일러 각과 짐벌 락

## 정의·핵심
- **오일러 각(RPY)**: 회전을 세 축 회전의 순서로 적는 방법 — **롤(roll, x축)·피치(pitch, y축)·요(yaw, z축)**. 사람이 각도를 적을 때 쓰기 쉽다 (기초 3차시, 실습 4차시).
- **짐벌 락(gimbal lock)** (⚡ 심화): 요·피치·롤 세 고리를 순서대로 겹쳐 돌릴 때, 가운데 **피치 고리가 정확히 90°로 서면** 요와 롤이 같은 축을 돌리게 되어 3차원이 2차원으로 주저앉는다 — 한 축의 자유도를 잃는다.
- **그래서 실무는 쿼터니언**: 회전을 한 축 중심으로 한 번에 다루는 네 숫자 (x, y, z, w). ROS 메시지에서 orientation을 x, y, z, w로 적는 것이 그것. 사람이 RPY로 적고 라이브러리로 쿼터니언으로 바꿔 넣는다.
- `tf2_echo` 출력은 같은 회전을 세 줄로 보여 준다: Quaternion (xyzw), RPY (radian), RPY (degree). `-0.000`은 아주 작은 음수가 반올림된 것 — 0과 같다 (실습 4차시).
- 단위 주의: ROS는 라디안. `static_transform_publisher`의 `--yaw 1.5708` = 90°.

## 원리·구조
$$R = R_z(\text{yaw})\,R_y(\text{pitch})\,R_x(\text{roll})$$
- pitch = 90°이면 $R = R_z(\text{yaw})R_y(90°)R_x(\text{roll})$ 이 **yaw − roll** 에만 의존 → yaw와 roll이 구분되지 않는다.

## 코드 예시
```python
import numpy as np
def Rx(a): c, s = np.cos(a), np.sin(a); return np.array([[1,0,0],[0,c,-s],[0,s,c]])
def Ry(a): c, s = np.cos(a), np.sin(a); return np.array([[c,0,s],[0,1,0],[-s,0,c]])
def Rz(a): c, s = np.cos(a), np.sin(a); return np.array([[c,-s,0],[s,c,0],[0,0,1]])
def rpy(r, p, y): return Rz(y) @ Ry(p) @ Rx(r)

d = np.deg2rad
# 피치 90°: (roll 10°, yaw 30°) 와 (roll 0°, yaw 20°) 가 같은 회전이 된다 → 한 축이 사라짐
A = rpy(d(10), d(90), d(30))
B = rpy(d(0),  d(90), d(20))
print(np.allclose(A, B))                               # True  (짐벌 락)
# 피치 45°에서는 구분된다
print(np.allclose(rpy(d(10), d(45), d(30)), rpy(0, d(45), d(20))))   # False
```
