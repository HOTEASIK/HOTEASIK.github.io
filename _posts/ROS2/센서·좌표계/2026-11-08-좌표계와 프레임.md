# 좌표계와 프레임

## 정의·핵심
- **정의**: 위치·방향을 잴 때의 **기준**. ROS에서는 기준 하나하나를 **프레임(frame)** 이라 부르고 이름을 붙인다(`map`, `odom`, `base_link`, `laser`, `camera_link`) (기초 3차시).
- **같은 컵인데 답이 다 다르다 — 누구 기준이냐의 문제**
  - 카페에서 "컵 어디 있어?" → 「내 앞 30센티」(내 몸 기준), 「창가 테이블 위」(테이블 기준), 「입구에서 오른쪽 구석」(카페 기준).
  - 로봇도 기준을 여러 개 동시에 갖는다: 「렌즈 앞 50센티」(카메라), 「앞쪽 1.2미터」(몸통 base), 방 전체(월드).
  - 모두 맞는 말이다. **기준이 다를 뿐**.
- **좌표계의 옷 세 벌** (⚡ 심화): 같은 점을 다른 옷으로 적을 수 있다.
  - 직교(데카르트) (x, y, z): 직선 이동할 때.
  - 원통 (r, θ, z): 평면에서 회전(턴테이블)할 때.
  - 구면 (r, θ, φ): 공간에서 방향을 틀며 회전할 때 — 라이다의 거리·각도가 이 꼴.
  - 정답인 좌표계가 있는 게 아니라 풀려는 움직임에 맞춰 계산이 쉬운 옷을 고른다.
- **자유도(DOF)**: 자유로운 강체 하나는 6자유도 — 이동 3(앞뒤·좌우·상하) + 회전 3(롤·피치·요). ROS의 `Pose` = position(x,y,z) + orientation(쿼터니언).
- 어렵다면 「**기준이 다르면 좌표도 다르다**」만 챙겨도 지장이 없다.

## 원리·구조
$$x = r\cos\theta,\quad y = r\sin\theta \qquad(\text{원통·극좌표} \to \text{직교})$$
$$x = r\sin\phi\cos\theta,\ y = r\sin\phi\sin\theta,\ z = r\cos\phi \qquad(\text{구면} \to \text{직교})$$

## 코드 예시
```python
# 라이다가 준 (거리 r, 각도 θ)를 직교 좌표로 — 같은 점, 다른 옷
import numpy as np
r, theta = 2.0, np.deg2rad(90)            # 왼쪽 90°, 2m
x, y = r * np.cos(theta), r * np.sin(theta)
print(round(x, 3), round(y, 3))           # 0.0 2.0
# 되돌리기
print(round(np.hypot(x, y), 3), round(np.rad2deg(np.arctan2(y, x)), 1))   # 2.0 90.0
```
