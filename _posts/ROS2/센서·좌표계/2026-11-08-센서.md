# 센서

## 정의·핵심
- **정의**: 바깥세상의 물리량(빛·소리·거리·온도·기울기)을 **숫자로 바꾸는 번역기**. 컴퓨터는 「밝다」「시끄럽다」를 알아듣지 못하고, 아는 것은 오직 숫자뿐이다 (기초 3차시).
- **사람의 감각과 대응**
  - 시각: 광센서·이미지센서 (빛·색·패턴)
  - 청각: 마이크·초음파센서
  - 후각: 가스센서·연기센서 / 미각: 이온센서·바이오센서
  - 촉각: 온도·압력·습도센서
  - 스마트폰에도 센서가 스무 개쯤 있다 (귀에 대면 화면이 꺼지는 근접센서 등).
- **로봇에서의 자리**: 느끼고(Sense) → 생각하고(Plan) → 움직이는(Act) 고리의 입력. ROS 토픽 위를 흐르는 숫자들도 거슬러 올라가면 거의 다 센서 → ADC를 거친 값이다.
- **고르는 기준**: 무작정 비싼 것이 아니라 상황에 맞는 것 — 가격·크기·무게·출력 형태·인터페이싱·분해능·감도·선형성·응답시간·정확성/반복정밀도·신뢰성 (열 가지 지표).
- **완벽한 센서는 없다** → 여러 센서를 함께 달아 서로의 약점을 메우는 **센서 퓨전**.
- **ROS에서 센서는 노드**: 센서 드라이버 노드가 `/scan`(LaserScan), `/image_raw`(Image), `/imu`(Imu), `/points`(PointCloud2) 같은 토픽으로 발행한다.

## 원리·구조
```
물리량 → [센서 소자] → 전기 신호(아날로그) → [ADC] → 숫자 → [드라이버 노드] → ROS 토픽
```

## 코드 예시
```python
# 센서 = 물리량을 숫자로: 온도를 4~20mA 전류로 바꾸는 선형 센서 흉내
def temp_to_mA(t, t_min=-100, t_max=100):
    return 4 + 16 * (t - t_min) / (t_max - t_min)
for t in (-100, 0, 100):
    print(t, "℃ →", temp_to_mA(t), "mA")
# -100 ℃ → 4.0 mA
# 0 ℃ → 12.0 mA
# 100 ℃ → 20.0 mA
```
