# 프레임 사슬

## 정의·핵심
- **정의**: 프레임 사이의 변환을 **죽 이어** 멀리 떨어진 두 프레임의 관계를 한 번에 구하는 것. 변환을 이으면 「라이다가 본 벽이 방 지도 위 어디인지」까지 나온다 (기초 3차시 ⚡).
- **로봇의 대표 사슬**: `map → odom → base_link → laser`
  - `map`: 방 전체를 기준으로 잰다 (SLAM·AMCL이 낸다).
  - `odom`: 출발점을 기준으로 잰다 (바퀴 오도메트리, 매끄럽지만 서서히 어긋남).
  - `base_link`: 몸통을 기준으로.
  - `laser`: 라이다를 기준으로 — `base_link → laser`는 **고정 변환**(static).
- 로봇이 방 안을 굴러다니면 방 전체 기준 위에서 몸통이 매 순간 움직인다 → `odom → base_link`는 계속 바뀌는 변환(dynamic).
- **손으로 따라가지 않는다 — TF2가 따라간다**: 변환만 등록해 두면 TF2가 사슬을 알아서 따라가 답을 낸다. 각 프레임은 부모가 **하나뿐**인 **트리** 구조여야 한다.
- 나중에 만나면 「아, 그때 그 컵 얘기!」라고 떠올리면 된다.

## 원리·구조
$$T_{map}^{laser} = T_{map}^{odom}\;T_{odom}^{base}\;T_{base}^{laser}$$
$$p_{map} = T_{map}^{laser}\,p_{laser}$$
```
map ──(SLAM/AMCL)──→ odom ──(바퀴 오도메트리)──→ base_link ──(고정)──→ laser
```

## 코드 예시
```python
import numpy as np
def T(yaw_deg, tx, ty, tz=0.0):
    a = np.deg2rad(yaw_deg); c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0, tx], [s, c, 0, ty], [0, 0, 1, tz], [0, 0, 0, 1]])

T_map_odom  = T(0, 0.5, 0.0)          # 지도 보정
T_odom_base = T(90, 3.0, 1.0)         # 로봇이 (3,1)에서 왼쪽(90°)을 보고 있음
T_base_laser = T(0, 0.20, 0.0, 0.30)  # 라이다 고정 위치
wall_laser = np.array([2.0, 0, 0, 1])     # 라이다 정면 2m
p_map = T_map_odom @ T_odom_base @ T_base_laser @ wall_laser
print(np.round(p_map[:3], 3))             # [3.5 3.2 0.3]
```
