# 텍스트 편집기

## 정의·핵심
- **정의**: 코드·설정 파일(.py, package.xml, setup.py, .yaml, .bashrc)을 고치는 도구. 터미널 안에서 쓰는 nano·vim과, 창으로 쓰는 VS Code·gedit가 있다 (기초 1차시).
- **nano**: 입문용. 메모장에 가깝고, 화면 아래에 단축키 안내가 뜬다.
  - 저장: `Ctrl+O` → Enter, 나가기: `Ctrl+X`.
- **vim**: 손에 익으면 훨씬 빠르지만 진입장벽이 있다.
  - `i` 로 입력 모드, `Esc` 후 `:wq` 저장·종료, `:q!` 저장 없이 종료.
  - 실수로 vim이 열렸을 때 빠져나오는 법만은 알아 둔다.
- **VS Code**: 강의 개발 도구. `.deb`를 받아 `sudo dpkg -i code_…deb` 로 설치 (우분투 설치 가이드). 터미널에서 `code .` 로 현재 폴더를 연다.
- 편집기·환경변수·프로세스, 이 셋은 ROS를 다룰 때 **매일** 쓰는 도구다. 지금은 nano로 충분하다.
- 화면 없는 로봇 PC(SSH 접속)에서는 nano·vim이 사실상 유일한 편집기다.

## 원리·구조
| 편집기 | 저장·종료 | 특징 |
|---|---|---|
| nano | Ctrl+O → Enter, Ctrl+X | 쉽다, 단축키 안내 표시 |
| vim | Esc 후 `:wq` (`:q!` 버림) | 모드 전환, 빠르다 |
| VS Code | Ctrl+S | 창 기반, 확장·디버깅 |

## 코드 예시
```bash
nano hello.py          # 고친 뒤 Ctrl+O → Enter, Ctrl+X
nano ~/.bashrc         # source 줄 추가할 때
vim hello.py           # i → 수정 → Esc → :wq
code ~/ros2_ws         # VS Code로 워크스페이스 열기
```
