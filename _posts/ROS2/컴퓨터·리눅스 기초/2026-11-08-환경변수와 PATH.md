# 환경변수와 PATH

## 정의·핵심
- **환경변수**: 프로그램들이 **공통으로 참고하는 메모** (기초 2차시). 어느 프로그램이든 이 메모를 읽는다.
  - `$HOME`: 홈 폴더 경로 → 그래서 프로그램들이 사용자의 집이 어디인지 안다.
  - `$PATH`: 명령 실행 파일을 찾아볼 **디렉터리 목록**(콜론으로 구분).
- **명령은 어디서 찾나** (기초 1차시): `ls`를 치면 셸이 PATH에 적힌 폴더를 **앞에서부터 차례로** 뒤져, 찾으면 실행하고 없으면 `command not found`. 설치했는데 못 찾는다면 PATH를 의심한다.
- **export**: 환경변수를 새로 만들거나 바꾼다. `export MY_PORT=9090`. 그 터미널(과 거기서 띄운 자식 프로세스)에만 적용된다 — 새 터미널은 모른다.
- **which**: 명령이 실제로 어느 폴더의 파일인지. `which ls`, `which ros2`.
- **ROS와의 연결**: ROS2는 환경변수로 움직인다.
  - `source /opt/ros/jazzy/setup.bash` 가 PATH·PYTHONPATH·AMENT_PREFIX_PATH 등을 채워야 `ros2` 명령이 보인다.
  - `ROS_DOMAIN_ID`, `ROS_DISTRO`, `RMW_IMPLEMENTATION`, `ROS_SECURITY_*` 도 모두 환경변수.
  - "명령을 못 찾는다"를 만나면 이 메모부터 떠올린다.

## 원리·구조
```
$ ros2 ...
  셸: PATH = /opt/ros/jazzy/bin:/usr/local/bin:/usr/bin:/bin
        ① /opt/ros/jazzy/bin/ros2 ?  ← 있으면 실행
        ② /usr/local/bin/ros2 ?
        ...
        끝까지 없으면 → command not found
```

## 코드 예시
```python
# PATH 앞에서부터 찾기 + 환경변수는 자식 프로세스로 물려준다
import os, subprocess, sys, shutil
print(shutil.which(os.path.basename(sys.executable)) is not None)   # True  (which python)

env = dict(os.environ, MY_PORT="9090")          # export MY_PORT=9090
out = subprocess.run([sys.executable, "-c", "import os; print(os.environ.get('MY_PORT'))"],
                     env=env, capture_output=True, text=True).stdout.strip()
print(out)                                      # 9090  (자식은 물려받는다)
print(os.environ.get("MY_PORT"))                # None  (부모 자신의 환경은 그대로)
```
```bash
echo $PATH
echo $HOME
which ls
export MY_TEST=hello
echo $MY_TEST          # hello
printenv | grep ROS    # ROS 관련 환경변수 보기
```
