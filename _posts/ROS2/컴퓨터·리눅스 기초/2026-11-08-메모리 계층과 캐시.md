# 메모리 계층과 캐시

## 정의·핵심
- **정의**: CPU에 가까울수록 빠르고 작고 비싼 기억장치를 여러 단으로 쌓은 구조. 레지스터 → L1 → L2 → L3 캐시 → RAM → 저장장치 (기초 1차시).
- **캐시**: CPU 가까이 자주 쓰는 데이터를 모아 두는 작은 고속 메모리.
  - **캐시 적중(hit)**: 가까운 데서 바로 찾음 → 기다림 없이 일한다.
  - **캐시 미스(miss)**: 못 찾아 RAM까지 내려감 → CPU가 멍하니 기다린다.
- **왜 중요한가**: "같은 데이터를 자주, 가까이 모아 쓰는" 코드가 빠르다(지역성).
- **현장 사례** (기초 1차시): 같은 사양의 두 로봇 중 한쪽이 눈에 띄게 느렸다. 겉으론 CPU가 노는 것 같았지만 데이터를 띄엄띄엄 읽어 기다리고 있었다 → 픽셀을 **한 줄씩 차례로** 훑게 바꾸자 처리량이 회복됐다.

## 원리·구조
| 계층 | 위치 | 대략 용량 | 상대 속도 | 전원 끄면 |
|---|---|---|---|---|
| 레지스터 | CPU 코어 안 | 수십~수백 B | 가장 빠름(1클록) | 사라짐 |
| L1 캐시 | 코어 전용 | 수십 KB | 매우 빠름 | 사라짐 |
| L2 캐시 | 코어 전용 | 수백 KB~수 MB | 빠름 | 사라짐 |
| L3 캐시 | 코어 공유 | 수 MB~수십 MB | 비교적 빠름 | 사라짐 |
| RAM | 메인보드 | 수~수십 GB | 느림 | 사라짐 |
| 저장장치 | SSD/HDD | 수백 GB~수 TB | 매우 느림 | 남음 |

- 영상은 행(row) 단위로 메모리에 연속 저장된다 → 행 방향으로 읽으면 연속 접근(적중↑), 열 방향으로 건너뛰며 읽으면 미스↑.

## 코드 예시
```python
# 같은 합계를 '연속 접근'과 '건너뛰기 접근'으로 계산해 시간을 비교한다
import numpy as np, time
img = np.ones((3000, 3000), dtype=np.float32)   # 영상 한 장이라 가정 (행 우선 저장)

t = time.perf_counter(); s1 = sum(img[r, :].sum() for r in range(3000)); a = time.perf_counter() - t  # 행 = 연속
t = time.perf_counter(); s2 = sum(img[:, c].sum() for c in range(3000)); b = time.perf_counter() - t  # 열 = 건너뛰기
print(s1 == s2)                    # True  (결과는 같다)
print("열 방향이 더 느림:", b > a)   # 보통 True (캐시 미스가 많다)
```
