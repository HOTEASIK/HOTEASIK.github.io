# 파이프와 리다이렉션

## 정의·핵심
- **정의**: 리눅스는 모든 명령에 **입력(stdin)·출력(stdout)·오류(stderr)** 통로를 달아 둔다. 그 방향을 바꾸는 것이 리다이렉션과 파이프다 (기초 1차시).
- **리다이렉션 `>` `>>`**: 출력을 화면 대신 파일로 돌린다.
  - `>` 덮어쓰기, `>>` 끝에 한 줄 추가.
- **파이프 `|`**: 앞 명령의 출력을 뒤 명령의 입력으로 흘려보낸다.
- **함께 쓰기**: 걸러서 → 정렬해서 → 파일로 저장. `cat fruits.txt | grep a | sort > a_fruits.txt`
- **로봇 현장에서** (미니 프로젝트 2 — 로그 분석): 오류만 추려 세는 것이 장애를 분류할 때 가장 먼저 하는 동작.
  - `grep ERROR logs/robot.log > logs/errors.txt` → `cat logs/errors.txt | wc -l`
- ROS에서도 `ros2 topic list | grep turtle`, `ros2 topic echo /scan > scan.txt` 처럼 매일 쓴다.

## 원리·구조
```
echo "apple"  ──stdout──→ [화면]          (기본)
echo "apple"  >  fruits.txt               (덮어쓰기)
echo "banana" >> fruits.txt               (이어 붙이기)
cat fruits.txt │ grep an │ wc -l          (파이프로 잇기)
```
| 기호 | 하는 일 |
|---|---|
| `>` | 출력을 파일에 저장(덮어쓰기) |
| `>>` | 파일 끝에 추가 |
| `\|` | 앞 출력 → 뒤 입력 |
| `2>` | 오류 통로만 파일로 |

## 코드 예시
```python
# 'cat fruits.txt | grep an' 과 'grep a | sort' 를 파이썬으로 흉내 낸다
lines = []
lines.append("apple")      # echo "apple"  > fruits.txt
lines.append("banana")     # echo "banana" >> fruits.txt
lines.append("cherry")     # echo "cherry" >> fruits.txt
print([l for l in lines if "an" in l])            # ['banana']        (grep an)
print(len(lines))                                 # 3                 (wc -l)
print(sorted(l for l in lines if "a" in l))       # ['apple', 'banana']  (grep a | sort)
```
```bash
echo "apple"  > fruits.txt
echo "banana" >> fruits.txt
echo "cherry" >> fruits.txt
cat fruits.txt | grep an        # banana
cat fruits.txt | wc -l          # 3
cat fruits.txt | grep a | sort > a_fruits.txt
```
