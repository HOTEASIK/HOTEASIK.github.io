# CPU·메모리·저장장치

## 정의·핵심
- **정의**: 컴퓨터를 이루는 **세 기둥**. 계산하는 두뇌(CPU), 빠른 책상(RAM), 꺼도 남는 서랍(저장장치) (기초 1차시).
- **CPU**: 명령어를 읽어 해석하고 실행한다. 내부는 ALU(연산)·제어장치·레지스터. 일하는 쪽이고 값이 비싸다.
- **RAM(주기억장치)**: 실행 중인 것이 올라가 일하는 곳. 빠르지만 전원을 끄면 사라진다(휘발성).
- **저장장치(SSD/HDD)**: 꺼도 남아 영구 보관한다. 크고 싸지만 느리다.
- **설계 원칙**: 빠른 건 비싸고 작고, 영구적인 건 싸고 크지만 느리다 → 카메라 프레임은 RAM에서 처리하고, AI 모델·지도 파일은 저장장치에 둔다.
- **「빠르다」의 두 가지 뜻**
  - 클럭 속도: 1초에 박자를 몇 번 맞추는가 (3.0GHz = 1초에 30억 번). 높을수록 **하나를 빨리** 끝낸다 → 반응 속도.
  - 코어 수: 일꾼이 몇 명인가 (4코어 = 넷까지 진짜 동시 처리) → **동시 처리량**. 잘게 나눌 수 없는 작업은 코어를 늘려도 빨라지지 않는다.
- **내 환경에서 숫자로 읽기** (기초 1차시 환경 점검 6종): `nproc`(코어 수), `free -h`(RAM 여유=책상), `df -h`(디스크 여유=서랍). 로봇이 느리다 싶을 때 가장 먼저 치는 명령들이다. 숫자는 사람마다 다르게 나오는 게 정상이고, 확인할 것은 에러 없이 답이 돌아오는가다.

## 원리·구조
| 담아 두는 층 | 역할 | 비유 | 속도 | 전원 끄면 | 용량·가격 |
|---|---|---|---|---|---|
| 레지스터·캐시 | 자주 쓰는 값을 곁에 | 손 위·책상 옆 메모지 | 가장 빠름 | 사라짐 | 아주 작고 비쌈 |
| RAM | 실행 중인 것이 일함 | 책상 | 빠름 | 사라짐 | 작고 비쌈 |
| 저장장치(SSD) | 꺼도 남아 보관 | 서랍 | 느림 | 남음 | 크고 쌈 |

- CPU는 일하는 쪽이라 "담아 두는 층" 표에 없다.

## 코드 예시
```python
# 이 PC의 코어 수와 디스크 여유를 파이썬으로 읽는다 (nproc, df -h 와 같은 정보)
import os, shutil
cores = os.cpu_count()
total, used, free = shutil.disk_usage(os.path.abspath(os.sep))
print("코어 수 > 0:", cores > 0)
print("디스크 여유 비율 0~1:", 0 <= free / total <= 1)
# 코어 수 > 0: True
# 디스크 여유 비율 0~1: True
```
```bash
nproc        # 코어 수
free -h      # RAM 여유
df -h        # 디스크 여유
```
