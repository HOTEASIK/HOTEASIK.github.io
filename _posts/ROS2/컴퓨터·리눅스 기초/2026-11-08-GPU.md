# GPU

## 정의·핵심
- **정의**: 단순한 계산을 한꺼번에 처리하는 **수천 개의 작은 코어**로 이뤄진 연산 장치. 똑같은 계산을 아주 많이 해야 할 때 압도적으로 빠르다 (기초 1차시).
- **CPU와의 차이**
  - CPU: 복잡한 일을 빠르게 처리하는 소수의 강한 코어. 한 줄씩 순서대로.
  - GPU: 수천 줄을 한 번에 펼쳐 처리. 서로 기다릴 필요가 없는 계산을 한꺼번에 → **병렬성**.
- **AI에 강한 이유**: 신경망은 숫자를 곱하고 더하는 행렬 계산의 반복이라 서로 기다릴 필요가 없다.
- **주의**: 병렬성은 "잘게 쪼갤 수 있는 일"에만 통한다. 순서대로 풀어야 하는 일(앞 결과가 다음 입력이 되는 일)은 여전히 CPU가 유리하다.
- **로봇에서**: 카메라 영상 인식·점구름 처리처럼 픽셀·점마다 같은 계산을 하는 일은 GPU, 상태 판단·제어 순서는 CPU.
- **「빠르다」의 두 축**과 연결: 클럭(하나를 빨리) vs 코어 수(동시에 많이). GPU는 코어 수 쪽의 극단이다.

## 원리·구조
```
CPU:  [강한 코어 4~16개]  →  a1, a2, a3 ... 차례로
GPU:  [작은 코어 수천 개] →  a1 a2 a3 ... aN 한 번에
         ↑ 서로 독립인 계산(행렬 곱의 각 원소)일 때만 이득
```
- 행렬 곱 $C = AB$ 의 각 원소 $c_{ij}=\sum_k a_{ik}b_{kj}$ 는 서로 독립 → 병렬화가 쉽다.
- 누적합 $x_t = x_{t-1} + u_t$ 는 앞 값을 기다려야 하므로 병렬화가 어렵다.

## 코드 예시
```python
# '서로 독립인 계산'은 한꺼번에(벡터화), '앞 값에 의존하는 계산'은 차례로만 가능
import numpy as np
a = np.arange(1, 6)
print(a * 2)                 # [ 2  4  6  8 10]  각 원소 독립 → 병렬화 가능
x = 0
for u in a:                  # x_t = x_{t-1} + u_t : 앞 결과를 기다려야 함
    x = x + u
print(x)                     # 15
```
