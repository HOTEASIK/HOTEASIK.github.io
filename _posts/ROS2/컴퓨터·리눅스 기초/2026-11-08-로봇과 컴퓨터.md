# 로봇과 컴퓨터

## 정의·핵심
- **정의**: 로봇은 결국 **움직이는 컴퓨터**다. 센서로 들어온 값을 컴퓨터가 판단하고, 모터로 내보내는 흐름 전체가 로봇이다 (기초 1차시).
- **입력·판단·출력**: 로봇을 한 문장으로 줄이면 "센서로 보고(카메라·거리센서) → 컴퓨터로 판단하고(1초에 수십 번) → 모터로 움직인다(바퀴·로봇팔)".
  - 이 세 가지가 그대로 ROS의 **노드 그래프**가 된다. 노드·토픽·서비스는 모두 "보고 판단해 움직이는 일"을 소프트웨어로 짜는 도구다.
  - 입력·판단·출력의 뼈대가 곧 컴퓨터 구조이므로, 이를 모르면 "왜 이 노드는 빠른데 저 노드는 버벅이지?"에 매번 막힌다.
- **로봇의 역사** (기초 1차시)
  - 1920 R.U.R.: 체코어 '로보타(고된 노동)'에서 온 단어. 처음부터 "사람이 하기 힘든 일을 대신하는 기계"라는 뜻.
  - 1954 특허 → 1961 GM 유니메이트: 상상이 현실이 됨. 사람을 닮기보다 용도에 맞는 기계.
  - 1960년대 공장 로봇: 힘세고 정확했지만 **앞을 못 봤다** — 1cm만 어긋나도 허공에 용접.
  - 1972 Shakey: 처음으로 카메라로 보고 스스로 판단.
  - 2010.3 ROS Box Turtle: 그 "보고 판단하는" 소프트웨어를 표준화. 우리가 배우는 것은 그 ROS의 최신판.
- **왜 지금인가**: AI의 세 번째 파도 — 인식하는 AI → 만들어내는 AI(ChatGPT) → **몸을 가진 AI(로봇)**. 그 흐름을 움직이는 것은 결국 소프트웨어이고, ROS를 다룰 줄 아는 사람이 부족하다.
- **자율성의 세 단계**: 사람이 얼마나 덜 개입하는가의 사다리.
  1. 수동 — 사람이 직접 조작
  2. 자동화 — 정해진 순서를 그대로 반복 (앞을 못 보던 공장 로봇, 정해진 경로만 도는 컨베이어 로봇)
  3. 자율 — 스스로 보고 판단해 행동 (ROS가 다루려는 단계)

## 원리·구조
```
 [센서 입력]          [판단]               [모터 출력]
 카메라·라이다  →   컴퓨터(CPU·메모리)  →   바퀴·로봇팔
      │                 │                    │
   센서 노드   ─토픽→   판단 노드   ─토픽→    모터 노드      ← ROS로 옮기면
```
- 사람의 손잡이 = 터미널 CLI, 컴퓨터 관리자 = 운영체제(우분투)

## 코드 예시
```python
# 입력·판단·출력을 가장 단순한 루프로 흉내 낸다
def sense(t):            # 입력: 앞 장애물까지 거리(m)
    return 2.0 - 0.5 * t

def decide(dist):        # 판단: 0.5m 이하면 멈춤
    return 0.0 if dist <= 0.5 else 0.2

def act(speed):          # 출력: 속도 명령
    return f"속도 {speed} m/s"

for t in range(4):
    d = sense(t)
    print(t, d, act(decide(d)))
# 0 2.0 속도 0.2 m/s
# 1 1.5 속도 0.2 m/s
# 2 1.0 속도 0.2 m/s
# 3 0.5 속도 0.0 m/s
```
