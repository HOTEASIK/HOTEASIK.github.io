# apt 패키지 매니저

## 정의·핵심
- **패키지 매니저**: 리눅스에서 프로그램을 깔 때 쓰는 **중앙 창구**. 윈도우처럼 설치 파일을 내려받아 더블클릭하지 않고 명령 한 줄로 끝낸다 (기초 1차시).
- **apt(Advanced Package Tool)**: 우분투(데비안 계열)의 패키지 매니저.
  - 저장소(repository): 믿을 수 있는 곳에서 소프트웨어를 받는다.
  - **의존성까지 자동으로** 챙긴다.
  - 설치·업데이트·삭제가 일관되게 처리된다.
- **왜 중요한가**: ROS2 설치도 같은 흐름(`sudo apt install ros-jazzy-desktop`)이라, apt를 손에 익히면 ROS 설치가 막막하지 않다.
- **update vs upgrade**: `update`는 설치 가능한 목록(저장소 정보)만 갱신, `upgrade`는 그 목록을 보고 깔린 것들을 새 버전으로 교체 (`-y`는 확인을 자동 yes).
- **remove vs purge vs autoremove** (기초 1차시 실습, screen 패키지)
  - `remove`: 본체 제거, **설정 파일은 남김** (`/etc/screenrc` 남음, `dpkg -l` 상태 `rc`).
  - `purge`: 설정 파일까지 깨끗이 제거.
  - `autoremove`: 축이 다르다 — 지정 없이 아무도 안 쓰는 의존성 찌꺼기만 지운다.
- **흔한 막힘**
  - sudo 없이 `apt install` → 권한 오류. 설치는 시스템 전체를 바꾸므로 관리자 권한 필요.
  - `Unable to locate package` → 목록 갱신 안 함 → `sudo apt update` 먼저.
- 현장에서는 새 로봇 PC를 셋업할 때 **검색 → 설치 → 확인 → 정리** 순서로 친다.

## 원리·구조
| 명령 | 하는 일 |
|---|---|
| `sudo apt update` | 목록 갱신 (검색·설치 전 습관) |
| `sudo apt upgrade -y` | 깔린 것들을 새 버전으로 |
| `apt search tree` | 이름·설명에 키워드가 든 후보 찾기 |
| `apt show tree` | 후보 하나의 설명·버전·의존성·크기 |
| `sudo apt install tree` | 설치 (의존성 자동) |
| `sudo apt remove 이름` | 제거, 설정 남김 |
| `sudo apt purge 이름` | 설정까지 제거 |
| `sudo apt autoremove` | 안 쓰는 의존성 정리 |
| `dpkg -l \| grep 이름` | 설치 상태 확인 (`ii` 설치됨, `rc` 설정만 남음) |

## 코드 예시
```bash
sudo apt update
apt search tree
apt show tree
sudo apt install tree && tree --version
sudo apt install screen && ls /etc/screenrc
sudo apt remove screen && ls /etc/screenrc     # 아직 남아 있다
dpkg -l | grep screen                          # rc
sudo apt purge screen && ls /etc/screenrc      # No such file or directory
sudo apt autoremove
```
