# 운영체제와 커널

## 정의·핵심
- **운영체제(OS)**: 프로그램들이 저마다 "CPU 내가 다 쓸래!" 하고 달려들지 않게 하는 **심판이자 매니저** (기초 1차시). 하는 일 다섯:
  1. 프로세스 관리 — CPU 순서를 정한다(스케줄링). "CPU는 몇 개뿐인데 프로세스는 수백 개"라는 질문의 답.
  2. 메모리 관리 — RAM을 잘라 나눠준다.
  3. 파일 시스템 관리 — 만들고 읽고 쓰고 지운다.
  4. 입출력·장치 관리 — 드라이버로 다룬다.
  5. 자원 보호와 권한 — 접근을 통제한다. 옆 프로세스의 책상을 못 보게 막는 것도 OS다.
- **커널(kernel)**: OS의 핵심부. 하드웨어에 직접 손대는 부분.
- **사용자 모드 / 커널 모드**
  - 사용자 모드: 내가 만든 프로그램이 도는 곳. 하드웨어에 직접 손대지 못한다.
  - 커널 모드: 하드웨어(디스크·네트워크·장치)에 직접 손댄다.
  - 일반 프로그램은 사용자 모드에서 돌다가, 필요할 때만 **시스템 호출(system call)** 로 커널에 일을 부탁한다.
  - 이 구분이 시스템을 안전하게 지키는 **벽**이다.
- 우분투에서 커널 버전은 `uname -r` 로 본다 (환경 점검 6종).

## 원리·구조
```
┌───────────────────────────┐
│ 사용자 모드: 내 노드, 파이썬 │
└─────────────┬─────────────┘
              │ 시스템 호출 (파일 열기, 소켓 보내기 …)
┌─────────────▼─────────────┐
│ 커널 모드: 스케줄러·메모리·  │
│ 파일 시스템·드라이버         │
└─────────────┬─────────────┘
┌─────────────▼─────────────┐
│ 하드웨어: CPU·RAM·디스크·NIC │
└───────────────────────────┘
```

## 코드 예시
```python
# open()/write() 같은 평범한 함수 뒤에서 시스템 호출이 커널에 일을 부탁한다
import os, tempfile
path = os.path.join(tempfile.gettempdir(), "sys_demo.txt")
fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC)  # open 시스템 호출 → 파일 기술자(정수)
n = os.write(fd, b"hello kernel")                           # write 시스템 호출 → 쓴 바이트 수
os.close(fd)
print(type(fd).__name__, n)   # int 12
os.remove(path)
```
```bash
uname -r          # 커널 버전
```
