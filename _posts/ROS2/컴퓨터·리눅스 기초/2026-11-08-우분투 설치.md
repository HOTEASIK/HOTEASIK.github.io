# 우분투 설치

## 정의·핵심
- **정의**: Ubuntu 24.04 LTS를 PC에 설치하는 과정. 강의는 **amd64(x86-64) PC + Windows 10/11 듀얼 부팅**을 가정한다 (우분투 설치 가이드, 기초 1차시).
- **준비물**
  - 8GB 이상 USB (이미지 6GB 내외), 중요한 파일은 외부 저장소에 **백업**.
  - 이미지: `ubuntu-24.04.x-desktop-amd64.iso` (Desktop Image).
  - Rufus: 부팅 가능한 ISO를 USB에 굽는 도구. 포맷할 USB 외에는 USB 장치를 빼 두는 것을 권장.
- **듀얼 부팅 파티션**: Windows `diskmgmt.msc` → (C:) 우클릭 → **볼륨 축소**로 빈 공간 확보 (256GB 이상 권장). 독립된 저장 공간을 쓰는 것이 안전.
- **BIOS**: OS 이전에 가장 먼저 도는 기본 소프트웨어(Basic Input Output System). 재부팅하며 제조사 키(HP F10, Asus·Samsung F2/DEL, Lenovo F1/F2 등)를 연타해 진입 → 부팅 순서를 USB로 바꾼다. 설치 중 **USB 연결 해제 절대 금지**.
- **설치 화면 선택** (가이드 순서)
  1. Try or Install Ubuntu
  2. 언어 **English** (기본 폴더 이름을 영어로 만들기 위해) → 키보드 English(US)
  3. Do not connect to the internet → Install Ubuntu → Interactive installation → Default selection
  4. 디스크: 듀얼 부팅이면 *Install Ubuntu alongside (기존 OS)*, 통째로 바꾸면 *Erase disk and install Ubuntu*
  5. 사용자 이름·비밀번호 → 시간대 Asia/Seoul → Install → Restart now → USB 제거 후 Enter
- **설치 후 첫 의식** (기초 1차시 1.5): `sudo apt update && sudo apt upgrade -y` → `lsb_release -a`로 24.04/noble 확인 → 환경 점검 6종.
- **개발 도구**: VS Code `.deb`를 받아 `sudo dpkg -i code_...deb` 로 설치 (Tab 자동완성 활용). 터미널에서 비밀번호를 쳐도 화면에 아무것도 안 보이는 게 정상.

## 원리·구조
```
ISO 다운로드 → Rufus로 USB 굽기 → (듀얼) 볼륨 축소 → BIOS에서 USB 부팅
 → 설치 마법사 → 재부팅 → apt update/upgrade → 환경 점검
```
| 체크리스트 (기초 1차시 1.5 C) |
|---|
| 1. `sudo apt update && sudo apt upgrade -y` |
| 2. `lsb_release -a` 로 24.04 / noble 확인 |
| 3. 점검 6줄(whoami·uname -r·nproc·free -h·df -h·ip addr)이 모두 답을 내는지 |
| 4. nproc·free -h 값을 메모해 코어 수·RAM과 연결 |
| 5. (선택) `sudo apt install build-essential -y` |

## 코드 예시
```bash
sudo apt update && sudo apt upgrade -y
lsb_release -a
whoami; uname -r; nproc; free -h; df -h; ip addr | grep inet
sudo dpkg -i code_*.deb        # VS Code 설치
```
