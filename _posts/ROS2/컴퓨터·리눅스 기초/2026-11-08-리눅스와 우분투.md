# 리눅스와 우분투

## 정의·핵심
- **리눅스(Linux)**: 1991년 리누스 토르발스가 유닉스(1969, 벨연구소)를 본떠 만든 오픈소스 운영체제 (기초 1차시).
- **우분투(Ubuntu)**: 리눅스 배포판 중 **데비안 계열**(apt·.deb). 레드햇 계열(yum/dnf·.rpm)은 서버용으로 강세.
- **왜 하필 리눅스인가**: 로봇과 서버는 거의 다 리눅스를 쓴다.
  - 공짜·오픈소스라 누구나 고쳐 쓴다, 가볍고 안정적이다, 글(스크립트)로 자동화하기 좋다.
  - **ROS2가 우분투를 기준 환경으로** 만들어져 있다 — ROS2 Jazzy는 Ubuntu 24.04를 Tier 1으로 둔다. 리눅스를 모르면 ROS는 시작조차 어렵다.
- **우분투를 읽는 세 가지**
  - 버전 번호: "24.04" = 2024년 4월 출시 (매년 4월·10월, 연 2회).
  - **LTS**: 짝수 해 4월판은 보안 업데이트를 5년 받는다. 24.04는 2029년 5월까지. 한 번 깔아 오래 돌리는 로봇·서버에서 사실상 표준.
  - 코드네임: 형용사+동물. 24.04 = **Noble Numbat** (`lsb_release -a` 에 `noble`).
- 화면은 GNOME이 맡지만 진짜 주무대는 **터미널**이다.
- **현장 — 새벽에 죽은 로봇 서버** (기초 1차시): 물류센터 관제 서버가 새벽 3시에 멈춤 → 노트북으로 SSH 접속 → 터미널로 죽은 프로세스 확인 → 로그를 grep으로 훑어 원인 찾기 → 죽은 노드 재실행. GUI 없이 글만으로 가능한 것이 리눅스의 힘.

## 원리·구조
| 항목 | Windows | 리눅스(우분투) |
|---|---|---|
| 비용·공개 | 유료·폐쇄 | 무료·오픈소스 |
| 주 사용처 | 일반 데스크톱 | 서버·로봇·임베디드 |
| 손잡이(셸) | CMD·파워셸 | bash |
| 패키지 설치 | 설치 파일 더블클릭 | apt 등 패키지 매니저 |
| 장치 접근 | 장치마다 전용 프로그램 | "모든 게 파일"(/dev 통일) |
| ROS2 지원 | 제한적 | 1순위(기준 환경) |

## 코드 예시
```bash
lsb_release -a
# Distributor ID: Ubuntu
# Description:    Ubuntu 24.04 LTS
# Release:        24.04
# Codename:       noble
```
```python
# 우분투 버전 번호 읽기: "YY.MM", 짝수 해 4월판이 LTS
def is_lts(ver):
    yy, mm = map(int, ver.split("."))
    return yy % 2 == 0 and mm == 4
for v in ["22.04", "23.10", "24.04", "25.04"]:
    print(v, is_lts(v))
# 22.04 True
# 23.10 False
# 24.04 True
# 25.04 False
```
