# 리눅스 기본 명령어

## 정의·핵심
- **정의**: 터미널에서 길찾기·파일 다루기·프로세스 관리를 하는 기본 명령들. "나 지금 어디 있고(pwd), 여기 뭐가 있고(ls), 어디로 가지(cd)"가 길찾기의 기초다 (기초 1차시).
- **길찾기·파일**: 여섯 줄로 거의 다 된다 — `pwd`, `ls`, `cd`, `mkdir`, `find`, `rm`.
  - `mkdir -p ~/ros2_ws/src` : 중간 폴더까지 한 번에 — ROS 워크스페이스 만들기가 곧 폴더 만들기다.
  - `rm` 은 **복구되지 않는다** (`-r` 폴더, `-f` 강제).
- **파일 통째로 써넣기 (heredoc)**: ROS에서 정말 자주 쓰는 손놀림.
  ```
  cat > hello.py << 'EOF'
  print("Hello ROS")
  EOF
  ```
- **복사·이동**: `cp a b`, `mv a b`(이름 바꾸기 = 이동).
- **프로세스**: `ps aux | grep 이름`(grep 자신도 한 줄 같이 뜬다), `명령 &`(백그라운드), `kill PID`.
- **환경 점검 6종**: `whoami`, `uname -r`, `nproc`, `free -h`, `df -h`, `ip addr | grep inet`.
- **오류 해독** (기초 1차시 1.7 G)

| 증상 | 원인 | 해결 |
|---|---|---|
| Permission denied | 실행 권한 없음 / 관리자 권한 필요 | `chmod +x` / `sudo` |
| No such file or directory | 경로 오타·상대 경로 착각 | `pwd` 확인 후 절대 경로 |
| Unable to locate package | 목록 갱신 안 함 | `sudo apt update` |
| No space left on device | 디스크·로그 가득 | 오래된 로그 정리, `df -h` |

## 원리·구조
| 명령 | 하는 일 (옵션) |
|---|---|
| `pwd` | 현재 위치 (print working directory) |
| `ls` | 목록 — `-a` 숨김, `-l` 상세, `-F` 종류, `-R` 하위까지 |
| `cd` | 이동 — `~` 홈, `..` 상위, `.` 현재, `-` 직전 |
| `mkdir` | 폴더 생성 — `-p` 중간 폴더까지 |
| `cp` / `mv` | 복사 / 이동·이름 바꾸기 |
| `rm` | 삭제 — `-r` 폴더, `-f` 강제 |
| `cat` | 파일 내용 출력 |
| `ps aux` / `kill PID` | 프로세스 보기 / 종료 |

## 코드 예시
```bash
pwd
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws && pwd            # /home/사용자이름/ros2_ws
cat > hello.py << 'EOF'
print("Hello ROS")
EOF
cat hello.py
cp hello.py hello2.py
mv hello2.py world.py
ls -l
sleep 300 &
ps aux | grep sleep
kill <PID>
```
