# find와 grep

## 정의·핵심
- **find**: 이름은 아는데 어디 뒀는지 모를 때 **파일을** 찾는다. `find 경로 -name 패턴` (기초 1차시).
  - `find . -name "*.py"` : 현재 위치 아래 모든 .py 파일의 경로.
  - `find ~/ros2_ws -name "hello.py"` : 특정 폴더 아래에서 정확한 이름으로.
- **grep**: 파일이나 출력 **내용 안에서** 특정 글자가 든 줄만 골라낸다.
  - `grep ERROR logs/robot.log` : ERROR가 든 줄만.
  - 파이프와 함께: `ps aux | grep sleep`, `cat fruits.txt | grep an`.
  - 자주 쓰는 옵션: `-i` 대소문자 무시, `-n` 줄 번호, `-r` 폴더 전체, `-v` 반대로(빼기), `-c` 개수.
- **차이**: find는 "어떤 파일이 어디 있나", grep은 "어떤 줄에 무엇이 있나".
- **현장** (기초 1차시): 새벽에 죽은 로봇 서버 — 로그 파일을 grep으로 훑어 원인을 찾는다. ROS에서는 `ros2 pkg executables | grep my_py_pkg`, `ros2 topic list | grep cmd_vel`.

## 원리·구조
```
find  : 디렉터리 트리를 돌며 '이름·조건'이 맞는 파일 경로를 출력
grep  : 입력을 한 줄씩 읽어 '패턴'이 든 줄만 출력
```

## 코드 예시
```python
# find(이름으로 파일 찾기)와 grep(내용으로 줄 찾기)을 파이썬으로 흉내
import os, tempfile, fnmatch
root = tempfile.mkdtemp()
os.makedirs(os.path.join(root, "src", "pkg"))
for name, text in [("src/pkg/node.py", "print('hi')"), ("notes.txt", "x"),
                   ("robot.log", "INFO start\nERROR lidar lost\nWARN slow\nERROR motor")]:
    open(os.path.join(root, name), "w").write(text)

found = [os.path.relpath(os.path.join(d, f), root).replace(os.sep, "/")
         for d, _, fs in os.walk(root) for f in fs if fnmatch.fnmatch(f, "*.py")]
print(found)                                   # ['src/pkg/node.py']   (find . -name "*.py")
errs = [l for l in open(os.path.join(root, "robot.log")).read().splitlines() if "ERROR" in l]
print(errs, len(errs))                         # ['ERROR lidar lost', 'ERROR motor'] 2  (grep ERROR | wc -l)
```
```bash
find . -name "*.py"
find ~/ros2_ws -name "hello.py"
grep ERROR logs/robot.log > logs/errors.txt
grep -rn "create_publisher" ~/ros2_ws/src
```
