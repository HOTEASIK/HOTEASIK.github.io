# sudo와 root

## 정의·핵심
- **root**: 리눅스의 최고 관리자 계정. 시스템 전체를 바꿀 수 있다.
- **sudo**: "superuser do" — 일반 사용자가 **이 명령 하나만** 관리자 권한으로 실행하게 한다. 실행 시 내 계정 비밀번호를 묻는다(터미널에 입력해도 화면에 아무것도 안 보이는 게 정상).
- **언제 필요한가** (기초 1차시)
  - 소프트웨어 설치·삭제 (`sudo apt install …`): 시스템 전체를 바꾸는 일이라 관리자 권한 필요.
  - `/etc`, `/opt` 같은 시스템 폴더 수정.
- **일부러 막혀보기**: `apt install tree` → 권한 오류로 막힘 → `sudo apt install tree` 로 해결.
- **주의 — sudo로 뚫지 말 것**: 장치 권한 문제(예: USB 라이다 `/dev/ttyUSB0` 접근 거부)는 sudo로 노드를 띄우는 대신 내 계정을 **dialout 그룹**에 넣어 해결한다. sudo로 실행하면 root의 환경(ROS 소싱이 안 된 환경)에서 돌거나, root 소유 파일이 생겨 나중에 일반 사용자로 빌드할 때 막힌다.
- 콜콘 빌드(`colcon build`)나 `ros2 run`에는 sudo를 붙이지 않는다.

## 원리·구조
```
일반 사용자 ──(sudo 명령)──→ 비밀번호 확인 ──→ 그 명령만 root 권한으로 실행
                                          (끝나면 다시 일반 사용자)
```
| 상황 | 올바른 처방 |
|---|---|
| apt 설치 | `sudo apt install …` |
| 스크립트 실행 권한 없음 | `chmod +x` (sudo 아님) |
| 시리얼 장치 Permission denied | `sudo usermod -aG dialout $USER` 후 재로그인 |

## 코드 예시
```bash
apt install tree                 # 권한 오류
sudo apt install tree            # 해결
groups                           # 내가 속한 그룹 확인
sudo usermod -aG dialout $USER   # 시리얼 장치 그룹에 나를 추가 (재로그인 필요)
```
