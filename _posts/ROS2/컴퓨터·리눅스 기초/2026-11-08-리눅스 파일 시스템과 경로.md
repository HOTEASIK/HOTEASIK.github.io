# 리눅스 파일 시스템과 경로

## 정의·핵심
- **모든 것은 파일이다** (기초 1차시): 리눅스는 거의 모든 것을 파일로 취급한다.
  - 문서: 우리가 만들고 읽는 일반 파일.
  - 장치: USB 라이다가 `/dev/ttyUSB0` 이라는 파일로 잡힌다.
  - 프로세스 정보: 실행 중인 상태·커널 상태까지 파일처럼 읽힌다(`/proc`).
  - 윈도우는 장치마다 전용 프로그램을 두지만 리눅스는 "파일" 하나로 통일 → 센서·장치가 잔뜩 붙는 로봇에서 큰 힘.
- **트리 구조**: 모든 파일은 루트(`/`)에서 갈라져 나온다.
- **절대 경로 vs 상대 경로**
  - 절대 경로: 루트부터 끝까지 다 적는다. 예 `/home/hong/ros2_ws`. 어디서 부르든 같은 곳 → 안전.
  - 상대 경로: 지금 위치 기준. 예 `../src`. 위치에 따라 가리키는 곳이 달라진다.
  - 현장: "분명히 만들었는데 없다"의 상당수는 상대 경로가 기준점을 잃은 경우 → 헷갈리면 절대 경로로.
  - 특수 기호: `~` 홈, `..` 상위, `.` 현재, `-`(cd에서) 직전 폴더.
- "파일을 못 찾겠다" → `pwd` → `ls` → `cd` 로 내 위치부터 짚는다.

## 원리·구조
FHS — 루트 아래 주요 디렉터리 (기초 1차시 부록)
```
/ (루트)
├─ /bin /sbin  기본 명령어·시스템 관리용 실행 파일
├─ /etc        시스템 설정 파일
├─ /home       사용자별 홈 디렉터리 (~)
├─ /dev        장치 파일 (디스크·센서 등)
├─ /usr        응용 프로그램·라이브러리 공유
├─ /var        로그 등 운영 중 변하는 데이터
└─ /opt        외부(타사) 프로그램 설치 — ROS도 여기 (/opt/ros/jazzy)
```

## 코드 예시
```python
# 절대 경로와 상대 경로: 상대 경로는 '지금 위치'에 따라 결과가 달라진다
from pathlib import PurePosixPath as P
here1 = P("/home/hong/ros2_ws/src")
here2 = P("/home/hong")
rel = P("../build")
print(here1 / rel)                      # /home/hong/ros2_ws/src/../build
print(P("/home/hong/ros2_ws/build").is_absolute(), rel.is_absolute())   # True False
import posixpath
print(posixpath.normpath(str(here1 / rel)))   # /home/hong/ros2_ws/build
print(posixpath.normpath(str(here2 / rel)))   # /home/build   ← 기준점이 바뀌면 엉뚱한 곳
```
```bash
pwd
ls /opt/ros
ls /dev/ttyUSB*      # USB 시리얼 장치 파일
```
