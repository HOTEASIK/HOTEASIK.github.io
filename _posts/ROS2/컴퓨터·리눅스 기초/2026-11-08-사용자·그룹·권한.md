# 사용자·그룹·권한

## 정의·핵심
- **정의**: 리눅스는 모든 파일에 **소유자와 그룹**을 함께 적어 두고, 세 부류(소유자·그룹·기타)마다 읽기(r)·쓰기(w)·실행(x) 권한을 따로 준다 (기초 1차시).
  - 소유자(owner): 파일에 이름이 적힌 사람.
  - 그룹(group): 그 파일의 그룹에 속한 사람.
  - 기타(others): 그 밖의 모든 사람.
- **권한 표기 읽기**: `-rwxr-xr-x`
  - 맨 앞 한 자리는 종류(`-` 파일, `d` 디렉터리) — 숫자로 세지 않는다.
  - 다음 세 자리씩 소유자·그룹·기타. r=4, w=2, x=1을 더한다 → `755`.
- **일부러 막혀보기** (기초 1차시 1.7 C): `echo 'echo 안녕' > run.sh` → `./run.sh` → `Permission denied` (권한 `-rw-r--r--`, x 없음) → `chmod +x run.sh` → `안녕`.
- **자주 쓰는 숫자 모드**: `644`(소유자 rw-, 나머지 r-- : 읽기 위주 파일), `700`(소유자만 rwx : 비공개 스크립트), `755`(실행 파일).
- **로봇에서**: 시리얼 장치 권한은 보통 `dialout` 그룹에 묶여 있다 → USB 라이다가 막히면 sudo로 뚫는 대신 내 계정을 그 그룹에 넣는다. 권한은 **생존 기술**이다.

## 원리·구조
| 자리 | 글자 | 뜻 | 숫자 |
|---|---|---|---|
| 소유자 | rwx | 4+2+1 | 7 |
| 그룹 | r-x | 4+1 | 5 |
| 기타 | r-x | 4+1 | 5 |

$$\text{권한 숫자} = 4r + 2w + 1x \quad(\text{부류마다 한 자리})$$

## 코드 예시
```python
# rwx 문자열 ↔ 숫자 모드 변환 (chmod 755 = -rwxr-xr-x)
def to_num(s):                       # s 예: "rwxr-xr-x"
    val = {"r": 4, "w": 2, "x": 1, "-": 0}
    return "".join(str(sum(val[c] for c in s[i:i+3])) for i in (0, 3, 6))

def to_str(n):
    return "".join(("r" if d & 4 else "-") + ("w" if d & 2 else "-") + ("x" if d & 1 else "-")
                   for d in map(int, str(n)))

print(to_num("rwxr-xr-x"), to_num("rw-r--r--"), to_num("rwx------"))   # 755 644 700
print(to_str(755), to_str(644))                                          # rwxr-xr-x rw-r--r--
```
```bash
ls -l run.sh             # -rw-r--r--
chmod +x run.sh          # 실행 권한 추가
chmod 644 hello.py
chmod 700 run.sh
ls -l hello.py run.sh
```
