# source와 .bashrc

## 정의·핵심
- **source**: 파일 속 명령을 **새 프로세스 없이 지금 이 셸에서** 실행해, 환경변수 변경을 현재 터미널에 반영한다 (기초 1차시).
  - `bash script.sh` 로 실행하면 자식 셸에서 돌고 끝나므로, 그 안에서 바꾼 환경변수는 부모(내 터미널)에 남지 않는다.
  - `source script.sh` (또는 `. script.sh`)는 지금 셸에서 돌기 때문에 남는다.
- **ROS에서 가장 많이 치는 이유**: `source /opt/ros/jazzy/setup.bash` 를 쳐야 그 터미널이 ROS를 안다. **새 터미널은 ROS를 모른다** (입문 1차시).
  - 내 워크스페이스를 빌드한 뒤에는 `source ~/ros2_ws/install/setup.bash` 를 한 겹 더 (overlay).
  - 빌드는 한 번, source는 **터미널마다 매번**.
- **.bashrc**: 새 터미널이 열릴 때마다 bash가 자동으로 읽는 설정 파일(`~/.bashrc`). 여기에 source 줄을 넣어 두면 매번 칠 필요가 없다 (입문 1차시 심화).
- **alias**: 긴 명령에 짧은 별명을 붙인다. 예 `alias cb='cd ~/ros2_ws && colcon build'`.
- **주의**: `.bashrc`를 고친 뒤에는 이미 열린 터미널에 `source ~/.bashrc` 해야 반영된다. `.bashrc`에 여러 워크스페이스를 겹겹이 넣으면 어느 패키지가 쓰이는지 헷갈린다.

## 원리·구조
```
bash setup.sh   →  [자식 셸] export X=1  → 끝나면 사라짐  → 내 셸: X 없음
source setup.sh →  [지금 셸] export X=1                    → 내 셸: X=1
```

## 코드 예시
```python
# '자식 프로세스에서 바꾼 환경변수는 부모에 남지 않는다'를 확인 (bash script.sh 와 같은 상황)
import os, subprocess, sys
subprocess.run([sys.executable, "-c", "import os; os.environ['ROS_DISTRO']='jazzy'"])
print(os.environ.get("ROS_DISTRO") == "jazzy")   # False  ← 그래서 source가 필요하다

os.environ["ROS_DISTRO"] = "jazzy"                # 지금 프로세스에서 바꾸기 = source
print(os.environ["ROS_DISTRO"])                   # jazzy
```
```bash
source /opt/ros/jazzy/setup.bash
echo $ROS_DISTRO                      # jazzy
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
echo "alias sb='source ~/ros2_ws/install/setup.bash'" >> ~/.bashrc
source ~/.bashrc
```
