# 코스트맵

## 정의·핵심
- **정의**: 비용 지도(costmap) — 벽 둘레에 보이지 않는 **위험 띠**를 둘러 「가까이 가면 비용이 높다」고 표시한 격자. RViz에서 분홍·하늘색 띠 (실습 5차시).
- **덕분에**: 로봇이 벽에 딱 붙어 지나가는 대신 여유를 두고 지나간다.
- **전역 비용 지도(global_costmap)**: 바탕은 미리 만든 지도 — 지도가 바뀔 때 바뀐다. planner_server가 쓴다. 켜려면 `map ↔ base_link` 변환이 있어야 한다 → 초기 위치가 없으면 이것부터 못 켜져 Aborting bringup.
- **지역 비용 지도(local_costmap)**: 바탕은 지금 라이다에 잡힌 장애물 — 사람이 앞을 막으면 즉시. controller_server가 보고 경로를 살짝 튼다. 로봇 둘레 일정 창만.
- **층(layer)**: static(지도) · obstacle(센서) · inflation(팽창 — 장애물에서 멀어질수록 비용이 줄어드는 띠). 팽창 반경·로봇 반경이 파라미터.
- **경로를 못 찾을 때**: 출발점·도착점이 위험 띠에 파묻혔다 → RViz에서 띠가 출발점 둘레를 막고 있지 않은지, 벽에 너무 붙었으면 살짝 떨어뜨린다. 「벽에 너무 붙는다」면 inflation 쪽 파라미터.
- **복구 행동의 하나**: 막히면 비용 지도를 지우고 다시 계획한다.

## 원리·구조
```
비용 값 (nav2 기준)
254 LETHAL     장애물 칸
253 INSCRIBED  로봇 중심이 오면 몸이 닿는 거리
 …  팽창 띠   멀어질수록 지수적으로 감소
  0 FREE
255 UNKNOWN
```

## 코드 예시
```python
# 팽창 층 흉내: 장애물에서의 거리로 비용 매기기
import math
def inflation_cost(d, robot_r=0.22, inflate_r=0.55, scale=3.0):
    if d == 0: return 254                     # LETHAL
    if d <= robot_r: return 253               # INSCRIBED
    if d > inflate_r: return 0
    return int(252 * math.exp(-scale * (d - robot_r)))
row = [inflation_cost(round(d * 0.05, 2)) for d in range(0, 13)]
print(row)
# [254, 253, 253, 253, 253, 230, 198, 170, 146, 126, 108, 93, 0]
```
