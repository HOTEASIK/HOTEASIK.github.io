# Gazebo

## 정의·핵심
- **정의**: 물리(중력·충돌)를 계산하고 가상 센서값을 만드는 로봇 시뮬레이터. Jazzy는 신형 **gz sim(Harmonic 세대)** — 구형 Gazebo Classic은 공식 지원이 끝난 세대 (실습 5차시).
- **세대 구분**: 실행 `gazebo`(Classic) vs `gz sim`(신형). 다리 꾸러미 `gazebo_ros` vs **`ros_gz`**(안에 ros_gz_bridge·ros_gz_sim). `roslaunch gazebo_ros …`·`spawn_entity.py` 꼴이면 Classic 자료 — Jazzy에서 꾸러미를 못 찾는다. 검색한 해법이 안 먹히면 그 자료가 어느 세대인지부터.
- **설치**: `sudo apt install -y ros-jazzy-ros-gz` → `which gz` = `/opt/ros/jazzy/opt/gz_tools_vendor/bin/gz`(ROS 꾸러미가 Gazebo를 함께 들고 왔다), `gz sim --versions` = 8.15.0. `gz` 명령을 못 찾으면 미설치이거나 ROS 환경을 안 읽은 셸.
- **띄우기**: 인자 없이 `gz sim` → 「Gazebo quick start」 예제 월드 고르는 창. `gz sim shapes.sdf` → 도형 여섯, **멈춘 채 시작**(왼쪽 아래 ▶를 눌러야 시간이 흐른다 — 안 움직여도 고장 아님). turtlebot3 월드는 처음부터 흐른다.
- **가상 센서**: 라이다 = 광선을 쏘아 닿는 거리 배열, 카메라 = 장면 렌더링, IMU = 물리 엔진의 가속도·각속도. **출력이 실제 센서와 같은 메시지 타입** → ROS 노드는 가상인지 실물인지 가릴 필요가 없다(코드는 두고 센서 출처만 바꾼다).
- **느리면 `real_time_factor`**: `gz topic -e -t /stats -n 3` — 1 근처면 실시간(실습 환경 0.999…), 0.25면 실제 1초에 0.25초. 로봇이 굼뜬 건 틀린 게 아니라 느린 것.
- **화면이 없으면**: `qt.qpa.xcb: could not connect to display` → 창 없이 서버만 `gz sim -s -r shapes.sdf`, 확인은 `gz topic -l`(/clock·/stats)과 ROS CLI. RViz는 소프트웨어 렌더링·offscreen으로도 안 선다 — `echo $DISPLAY`.
- **세 층 진단**: 설치 층(올바른 세대 꾸러미) → 환경 층(셸이 꾸러미·모델 경로를 읽나) → 연결 층(토픽·타입·방향).

## 원리·구조
```
gz sim  (물리 엔진 + 가상 센서)
   │ gz 토픽: /cmd_vel /scan /odom /clock  (gz.msgs.*)
   ▼ ros_gz_bridge
ROS 토픽: /cmd_vel /scan /odom /clock (geometry_msgs, sensor_msgs, nav_msgs, rosgraph_msgs)
```

## 코드 예시
```python
# 가상 라이다 흉내: 원점에서 광선을 쏘아 반지름 2 m 원형 벽까지의 거리 (안쪽 상자 장애물 포함)
import math
def ray(angle, wall_r=2.0, box=(1.0, -0.2, 1.4, 0.2), max_range=3.5):
    dx, dy = math.cos(angle), math.sin(angle)
    d = wall_r
    x0, y0, x1, y1 = box
    for t in [i * 0.001 for i in range(1, 3500)]:
        x, y = dx * t, dy * t
        if x0 <= x <= x1 and y0 <= y <= y1: d = t; break
    return round(min(d, max_range), 2)
scan = [ray(math.radians(a)) for a in (0, 90, 180, 270)]
print(scan)   # [1.0, 2.0, 2.0, 2.0]  ← 앞(0°)만 상자에 막혀 1.0 m
```
```bash
sudo apt install -y ros-jazzy-ros-gz
which gz; gz sim --versions
gz sim shapes.sdf
gz sim -s -r shapes.sdf && gz topic -l
gz topic -e -t /stats -n 3
```
