# 경로 계획과 장애물 회피

## 정의·핵심
- **정의**: Nav2의 길찾기는 사람의 운전과 닮았다 — **큰 그림(전역 계획)** 과 **즉석 조정(지역 제어)** 이 함께 돈다 (실습 5차시).
- **전역 계획 — planner_server**: 출발 전 내비게이션이 큰 경로를 그려 주듯 전역 비용 지도 위에서 「이 길로 가자」(A*·Dijkstra 계열, 기본 NavFn).
- **지역 제어 — controller_server**: 운전 중 앞차·사람을 보고 핸들을 미세하게 조정하듯 지역 비용 지도를 보며 경로를 따라 /cmd_vel을 낸다(DWB·MPPI 등).
- **실습 로그(목적지 (1.5, 0.0))**: `[bt_navigator]: Begin navigating from current location (-1.97, -0.52) to (1.50, 0.00)` → `[controller_server]: Failed to make progress`(가는 도중 네 번) → `[follow_path] [ActionServer] Aborting handle.` → `[controller_server]: Reached the goal!` → `[bt_navigator]: Goal succeeded`. 패널 `Feedback: reached · Time taken: 57 s · Recoveries: 5`.
- **복구 행동(recovery)**: 정해진 시간 안에 충분히 못 나아가면 「막혔나」 → 제자리에서 살짝 회전해 주변을 다시 살피거나 비용 지도를 지우고 다시 계획 → 다시 간다. 순서를 정하는 것이 **행동 트리**(bt_navigator의 bt). 곧장 포기하지 않는다.
- **경로를 못 찾는다**: 벽 안·지도 밖에 찍었다(흰 칸 한가운데에 다시) · 출발·도착점이 위험 띠에 파묻혔다 · 지도의 해상도·원점이 실제와 어긋났다. 대개 목적지나 지도의 문제지 Nav2 고장은 드물다.
- **길목에 기둥**이 있게 목적지를 고르면 RViz에서 비용 지도 띠를 피해 휘는 경로가 보인다.

## 원리·구조
```
목적지 ─▶ bt_navigator (행동 트리)
            ├─ ComputePathToPose → planner_server  (global_costmap) → 경로
            ├─ FollowPath        → controller_server (local_costmap) → /cmd_vel
            └─ 실패 시 Recovery: Spin · ClearCostmap · Wait → 재시도
```

## 코드 예시
```python
# 전역 계획 흉내: 격자 위 A* — 기둥(#)을 돌아가는 경로
import heapq
grid = ["..........",
        "....#.....",
        "....#.....",
        "....#.....",
        ".........."]
def astar(s, g):
    H = lambda p: abs(p[0] - g[0]) + abs(p[1] - g[1])
    openq, came, cost = [(H(s), s)], {s: None}, {s: 0}
    while openq:
        _, cur = heapq.heappop(openq)
        if cur == g: break
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            n = (cur[0] + dr, cur[1] + dc)
            if 0 <= n[0] < 5 and 0 <= n[1] < 10 and grid[n[0]][n[1]] != "#" and cost[cur] + 1 < cost.get(n, 1e9):
                cost[n] = cost[cur] + 1; came[n] = cur; heapq.heappush(openq, (cost[n] + H(n), n))
    path, p = [], g
    while p: path.append(p); p = came[p]
    return path[::-1]
path = astar((2, 1), (2, 8))
print(len(path) - 1, "칸", (2, 4) in path)   # 11 칸 False  ← 직선 7칸 대신 기둥을 돌아 11칸
```
