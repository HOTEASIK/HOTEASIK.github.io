# AMCL

## 정의·핵심
- **정의**: AMCL(Adaptive Monte Carlo Localization) — **완성된 지도 위에서 나를 찾아내는** 위치 추정. 라이다 모양과 지도를 맞춰 「지금 내가 정확히 어디 있나」를 추정한다 (실습 5차시).
- **SLAM과의 자리**: SLAM = 지도를 만드는 단계, AMCL = 그 지도를 다시 쓰며 내 위치만 잡는 운영 단계. 청소 로봇이 처음 한 바퀴(SLAM) 뒤엔 저장한 지도로 위치만 추정하는 것과 같다.
- **원리(파티클 필터)**: 「대략 이쯤」이라는 첫 짐작에서 후보 위치(파티클)를 흩뿌리고 → 움직임만큼 옮기고 → 각 후보에서 보일 스캔과 실제 스캔을 견줘 잘 맞는 후보에 무게 → 다시 뽑기를 되풀이해 범위를 좁혀 간다.
- **초기 위치가 필요하다**: Nav2 데모는 띄우자마자 2초쯤마다 `[amcl]: AMCL cannot publish a pose or update the transform. Please set the initial pose...` — 「지도는 있는데 그 위 어디에 로봇을 놓을지 모르겠다」.
- **초기 위치 주기**: RViz 「2D Pose Estimate」 → 로봇이 있는 자리(데모는 대략 x −2.0, y −0.5)를 클릭한 채 보는 쪽으로 끌어 놓는다. 단추가 보내는 것은 `/initialpose`(geometry_msgs/msg/PoseWithCovarianceStamped, `header.frame_id: map`).
- **1분 안에**: 안 주면 AMCL이 `map ↔ base_link` 변환을 못 내 global_costmap이 못 켜지고 관리자가 `Aborting bringup` — [[Nav2]]. 늦게 줘도 안 풀린다 → 끄고 다시 띄워 곧바로.
- **AMCL이 내는 것**: TF `map → odom`(오도메트리 드리프트를 보정), `/amcl_pose`.
- `slam:=True`로 띄우면 AMCL 대신 slam_toolbox가 지도를 그리며 주행 — 초기 위치 불필요(서 있는 자리가 출발점).

## 원리·구조
```
파티클 N개 (x, y, θ)
  ① 예측: /odom 이동량만큼 옮기고 잡음 더하기
  ② 갱신: 각 파티클 위치에서 지도로 예상한 스캔 vs 실제 /scan → 가중치
  ③ 재표본: 가중치 큰 파티클을 더 많이 복제
  → 평균 = 추정 위치 → TF map→odom
```

## 코드 예시
```python
# 1차원 복도 파티클 필터: 문 위치(지도)와 「문이 보인다」 관측으로 위치 좁히기
import random
random.seed(3)
doors = [1.0, 2.0, 5.0, 9.0]
def sees_door(x): return any(abs(x - d) < 0.5 for d in doors)
true_x = 0.8
parts = [random.uniform(0, 10) for _ in range(2000)]
def near(): return sum(abs(p - true_x) < 0.5 for p in parts) / len(parts)
print("처음", round(near(), 2))                         # 처음 0.1  ← 고르게 흩뿌림
for step in range(8):
    obs = sees_door(true_x)
    w = [0.9 if sees_door(p) == obs else 0.1 for p in parts]   # 갱신
    parts = random.choices(parts, weights=w, k=len(parts))     # 재표본
    true_x += 1.0                                              # 1 m 이동
    parts = [p + 1.0 + random.gauss(0, 0.05) for p in parts]   # 예측
print("8걸음 뒤", round(near(), 2))                      # 8걸음 뒤 0.76  ← 참 위치 ±0.5 m에 76%가 모였다
```
```bash
ros2 topic pub --once /initialpose geometry_msgs/msg/PoseWithCovarianceStamped \
  "{header: {frame_id: map}, pose: {pose: {position: {x: -2.0, y: -0.5, z: 0.0}, orientation: {w: 1.0}}}}"
ros2 topic echo --once /amcl_pose
```
