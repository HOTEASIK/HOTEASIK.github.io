# 점유 격자 지도

## 정의·핵심
- **정의**: 공간을 일정한 크기의 칸으로 나눠 칸마다 **비었다 / 막혔다 / 모른다**를 적은 2D 지도 — `nav_msgs/msg/OccupancyGrid`, 토픽 `/map` (실습 5차시).
- **칸 값**: 0(빈 칸) ~ 100(막힘), -1(모름). `info.resolution`(한 칸 m, 0.05), `info.width`·`height`(칸 수), `info.origin`(왼쪽 아래 칸의 세계 좌표).
- **저장 — map_saver_cli**: `ros2 run nav2_map_server map_saver_cli -f ~/map` → `~/map.yaml` + `~/map.pgm` 한 쌍. 끝에 `Map saved successfully`. `Received a 98 X 102 map @ 0.05 m/pix`.
  - WARN 셋(`Free threshold unspecified. Setting it to default value: 0.250000`, Occupied 0.65, `Image format unspecified. Setting it to: pgm`)은 기본값 안내 — 걱정하지 않는다.
  - 첫 번에 `[map_saver]: Failed to spin map subscription` → `Process exited with failure 1`로 끝날 수 있다 — 한 번 더 치거나 `--ros-args -p save_map_timeout:=10.0`. 원인은 가려내지 못했다.
- **두 파일**: `map.pgm` 흑백 그림(지도 자체) · `map.yaml` 메타데이터 — `image: map.pgm`, `mode: trinary`, `resolution: 0.050`, `origin: [-0.924, -2.059, 0]`, `negate: 0`, `occupied_thresh: 0.65`, `free_thresh: 0.196`. 쓰는 쪽은 둘을 한 쌍으로 읽는다.
- **pgm 읽는 법(trinary)**: 밝기 p를 (255−p)/255 점유 확률로 보고 occupied_thresh 이상이면 막힘(검정), free_thresh 이하면 빈 칸(흰색), 사이는 모름(회색).
- **읽어 쓰기**: Nav2의 map_server가 yaml을 읽는다(`Loading yaml file: …/tb3_sandbox.yaml`), 내 지도는 `map:=$HOME/map.yaml`. 다른 이름으로 저장하면 앞 지도를 안 덮는다(`-f ~/map_nav2slam`).
- **지속성**: 지도는 한 번 발행하고 끝나는 데이터 — `/map`은 RELIABLE + TRANSIENT_LOCAL이라 늦게 켠 RViz도 받는다.

## 원리·구조
```
map.yaml                         map.pgm (98 × 102 칸, 칸당 0.05 m → 4.9 m × 5.1 m)
image: map.pgm                   검정 = 벽(막힘) · 흰색 = 빈 칸 · 회색 = 모름
resolution: 0.050
origin: [-0.924, -2.059, 0]      ← 왼쪽 아래 칸의 (x, y, yaw)
```

## 코드 예시
```python
# 세계 좌표 ↔ 격자 칸, pgm 밝기 → trinary 칸 값
res, origin = 0.05, (-0.924, -2.059)
def world_to_cell(x, y): return int((x - origin[0]) // res), int((y - origin[1]) // res)
def cell_to_world(i, j): return round(origin[0] + (i + 0.5) * res, 3), round(origin[1] + (j + 0.5) * res, 3)
print(world_to_cell(0.0, 0.0))     # (18, 41)
print(cell_to_world(18, 41))       # (0.001, 0.016)
def trinary(p, occ=0.65, free=0.196):
    occ_prob = (255 - p) / 255
    return 100 if occ_prob > occ else 0 if occ_prob < free else -1
print([trinary(p) for p in (0, 254, 205)])   # [100, 0, -1]
print(round(98 * res, 2), "m x", round(102 * res, 2), "m")   # 4.9 m x 5.1 m
```
```bash
ros2 run nav2_map_server map_saver_cli -f ~/map
ls -la ~/map.* && cat ~/map.yaml
ros2 launch nav2_bringup tb3_simulation_launch.py map:=$HOME/map.yaml
```
