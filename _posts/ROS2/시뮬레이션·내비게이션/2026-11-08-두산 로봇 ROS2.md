# 두산 로봇 ROS2

## 정의·핵심
- **정의**: 국산 협동로봇 팔(두산 m1013 등)을 ROS2로 다루는 제조사 꾸러미 **doosan-robot2**(jazzy 브랜치) — 이동(어디로 갈 것인가) 대신 **조작**(무엇을 어떻게 다룰 것인가) (실습 5차시).
- **소스로만 받는다**(apt 배포 아님): `git clone -b jazzy https://github.com/DoosanRobotics/doosan-robot2.git` → rosdep(처음이면 `sudo rosdep init`·`rosdep update`) → `colcon build`(꾸러미 29개, 12코어 6분쯤, `2 packages had stderr output`은 경고뿐). `dsr_description2`만 고르면 xacro가 `dsr_controller2`를 찾다 launch가 죽는다 — 전체를 빌드.
- **팔 세우기**: `ros2 launch dsr_description2 dsr_description.launch.py model:=m1013` → static_transform_publisher·robot_state_publisher(`Robot initialized`)·joint_state_publisher_gui(joint_1~joint_6 슬라이더 여섯)·rviz2. 앞 차시 4.3과 같은 꼴 — URDF를 대본이 xacro로 펼쳐 건넨다.
- **m1013**: 앞 두 자리 = 들 수 있는 무게 10 kg, 뒤 두 자리 = 팔 길이 1300 mm. 관절 여섯 = 위치 셋 + 방향 셋(산업용 팔 대부분 6축).
- **명령은 외우지 않고 찾는다**: `dsr_msgs2`의 서비스 140개 — `ros2 interface list | grep dsr_msgs2/srv | grep -i move`(15줄). 갈래: 움직여라(MoveJoint·MoveLine·MoveCircle…) · 멈춰라(MoveStop·MovePause·MoveResume) · 기다려라(MoveWait).
- **MoveJoint 꼴**: `float64[6] pos`(목표 관절 각도 **[degree]**) · `vel`[deg/sec] · `acc`[deg/sec2] · time · radius · mode(ABSOLUTE 0 / RELATIVE 1) · sync_type … `---` `bool success`. **단위 주의**: 명령은 도(90.0), TF·/joint_states는 라디안(1.5707963267950003).
- **관절로 vs 손끝으로**: MoveJoint는 관절 여섯 각도(곡선 경로, 못 갈 일 거의 없음), MoveLine은 손끝 위치·방향(직선, 팔이 안 닿으면 실패). 순기구학(각도→손끝)은 답이 하나, 역기구학(손끝→각도)은 여럿이거나 없다.
- **가상 모드**: `ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=virtual model:=m1013` — 「제어기 없이 그리기」가 아니라 **제어기 에뮬레이터**(Docker 이미지 doosanrobot/dsr_emulator:3.0.1, 127.0.0.1:12345)와 ros2_control_node가 통신. Docker가 없으면 `docker: command not found` → `Connection refused` → `DRCF connecting ERROR!!!`·`Failed to initialize hardware 'm1013'`, RViz엔 격자만, Ctrl+C 두 번.
- **서비스 이름은 목록에서**: `/dsr01/dsr_controller2/motion/move_joint`(로봇 이름 + 제어기 이름). 가운데를 빼고 짐작한 `/dsr01/motion/move_joint`는 `waiting for service to become available...`에서 멈춘다 → `ros2 service list | grep motion`.
- 저장소 예제 `single_robot_simple`은 jazzy 판에서 `NameError: name 'SetSingularityHandlingForce' is not defined` — 명령을 하나씩 service call로.

## 원리·구조
| | 이동 로봇(turtlebot3) | 팔 로봇(두산) |
|---|---|---|
| 목표 | 공간을 이동 | 끝단을 원하는 자리로 |
| 명령 | /cmd_vel 토픽 · Nav2 목적지 | move_joint · move_line 서비스 |
| 좌표의 초점 | 로봇 ↔ 지도 | 관절 각도 ↔ 끝단 위치 |
| 공통 | URDF · TF · 토픽 · 서비스 · 노드 | |

## 코드 예시
```python
# MoveJoint 요청은 도, /joint_states는 라디안 — 단위 변환과 2축 순기구학 맛보기
import math
pos_deg = [0.0, 0.0, 90.0, 0.0, 90.0, 0.0]
print([round(math.radians(d), 4) for d in pos_deg])   # [0.0, 0.0, 1.5708, 0.0, 1.5708, 0.0]
def fk(q1, q2, l1=0.62, l2=0.56):                      # 평면 2링크: 각도 → 손끝 (x, z)
    a, b = math.radians(q1), math.radians(q1 + q2)
    return round(l1 * math.cos(a) + l2 * math.cos(b), 3), round(l1 * math.sin(a) + l2 * math.sin(b), 3)
print(fk(90, -90))    # (0.56, 0.62)
print(fk(0, 0))       # (1.18, 0.0)  ← 다 펴면 팔 길이
reach = 0.62 + 0.56
print("역기구학 해 없음" if math.hypot(1.5, 0.3) > reach else "해 있음")   # 역기구학 해 없음
```
```bash
ros2 launch dsr_description2 dsr_description.launch.py model:=m1013
ros2 interface show dsr_msgs2/srv/MoveJoint
ros2 service list | grep motion
ros2 service call /dsr01/dsr_controller2/motion/move_joint dsr_msgs2/srv/MoveJoint \
  "{pos: [0.0, 0.0, 90.0, 0.0, 90.0, 0.0], vel: 30.0, acc: 30.0}"
ros2 service call /dsr01/dsr_controller2/aux_control/get_current_posj dsr_msgs2/srv/GetCurrentPosj "{}"
```
