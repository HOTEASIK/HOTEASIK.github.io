# Nav2

## 정의·핵심
- **정의**: Navigation2 — 경로 계획·장애물 회피·위치 추정(AMCL)을 묶은 ROS2 **자율주행 스택**. 목적지를 찍으면 로봇이 알아서 간다 (실습 5차시).
- **관리되는 노드 열 개 남짓을 관리자가 차례로 켠다**: `lifecycle_manager_navigation`이 map_server·amcl·planner_server·controller_server·bt_navigator·costmap 등을 configure→activate. 다 켜면 `[lifecycle_manager_navigation]: Managed nodes are active`, RViz Navigation 2 패널 Navigation·Localization `active`.
- **데모**: `sudo apt install -y ros-jazzy-navigation2 ros-jazzy-nav2-bringup` → `ros2 launch nav2_bringup tb3_simulation_launch.py`. 기본 `headless:=True`라 Gazebo 창 없이 RViz만(`headless:=False`면 Gazebo도). 로봇은 waffle, 월드 tb3_sandbox, 지도 `nav2_bringup/maps/tb3_sandbox.yaml`.
- **⚠ 띄우자마자 1분 안에 초기 위치**: 안 주면 약 60초 뒤 `Failed to activate global_costmap because transform from base_link to map did not become available before timeout` → `[lifecycle_manager_navigation] Failed to bring up all requested nodes. Aborting bringup.` → `ros2 lifecycle get /planner_server` = `inactive [2]`. 늦게 줘도 안 풀린다 — 끄고 다시. 느려서 생기는 일이 아니다(real_time_factor 1 근처에서도).
- **협업 그림**: Gazebo(가상 라이다·오도메트리) → AMCL(지도 위 내 위치) → Nav2(비용 지도 위 경로 → /cmd_vel) → 다리 → 가상 로봇. 모든 좌표는 TF가 묶고 노드는 관리자가 켠다. 한 칸이라도 빠지면 전체가 멈춘다.
- **설정이 많은 까닭**: 온갖 모양·크기 로봇에 두루 쓰이도록 — 크기·최대 속도·회전 반경·안전 여유·볼 거리 모두 파라미터. 처음엔 turtlebot3 표준 설정 그대로, 증상(「벽에 너무 붙는다」)이 보이면 한두 개씩.
- **이 데모의 /cmd_vel은 Twist**(turtlebot3 월드는 TwistStamped).
- **끌 때 빨간 줄은 고장이 아니다**: `CRITICAL FAILURE: SERVER map_server IS DOWN after not receiving a heartbeat for 4000 ms`, `process has died [… exit code -6 …]` — 띄워 놓은 채 나오면 그때는 진짜 죽은 것.
- **SLAM하며 주행**: `slam:=True` — `lifecycle_manager_slam`·`lifecycle_manager_navigation` 둘 다 active, 초기 위치 불필요.
- **안 움직이면 — 위치·생애주기·시간**: Aborting bringup 찾기 → lifecycle get → 끄고 다시 곧바로 2D Pose Estimate → Managed nodes are active 뒤에 목적지. use_sim_time 어긋남도.

## 원리·구조
```
lifecycle_manager_navigation
 ├─ map_server     (지도 읽기)
 ├─ amcl           (map→odom)
 ├─ planner_server (전역 경로)      ← global_costmap
 ├─ controller_server (지역 제어 → /cmd_vel) ← local_costmap
 ├─ behavior_server (복구 행동)
 └─ bt_navigator   (행동 트리: NavigateToPose)
```

## 코드 예시
```python
# 관리자 흉내: 차례로 activate하다 TF가 없으면 시간 초과 → Aborting bringup
def bringup(nodes, tf_map_base_ready, timeout=60):
    state = {n: "inactive" for n in nodes}
    for n in nodes:
        if n == "global_costmap" and not tf_map_base_ready:
            return (f"Failed to activate {n} because transform from base_link to map did not become "
                    f"available before timeout → Aborting bringup."), state
        state[n] = "active"
    return "Managed nodes are active", state
nodes = ["map_server", "amcl", "global_costmap", "planner_server", "controller_server", "bt_navigator"]
msg, st = bringup(nodes, tf_map_base_ready=False)
print(msg.split(" → ")[1], st["planner_server"])     # Aborting bringup. inactive
msg, st = bringup(nodes, tf_map_base_ready=True)    # 초기 위치를 준 판
print(msg, all(v == "active" for v in st.values()))  # Managed nodes are active True
```
```bash
sudo apt install -y ros-jazzy-navigation2 ros-jazzy-nav2-bringup
ros2 launch nav2_bringup tb3_simulation_launch.py
ros2 launch nav2_bringup tb3_simulation_launch.py headless:=False
ros2 launch nav2_bringup tb3_simulation_launch.py slam:=True
ros2 lifecycle get /planner_server
```
