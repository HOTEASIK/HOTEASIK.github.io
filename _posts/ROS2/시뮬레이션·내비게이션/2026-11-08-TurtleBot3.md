# TurtleBot3

## 정의·핵심
- **정의**: ROBOTIS의 **교육용 표준 이동 로봇** — 작고 라이다와 바퀴를 갖춰 SLAM·Nav2를 배우기에 알맞다. 전 세계 강의·튜토리얼이 기준으로 삼아 막히면 찾기 쉽고, 시뮬레이션과 실물이 거의 같은 인터페이스 (실습 5차시).
- **기종**: burger(가장 단순한 두 바퀴, 기본 실습에 가볍다, 라이다 3.5 m) · waffle·waffle_pi(카메라 — 인지 실습까지). 「지금 어느 기종을 띄웠는가」를 늘 의식 — Nav2 데모는 TURTLEBOT3_MODEL을 안 읽고 스스로 waffle.
- **설치 두 줄 — 띄우기 전에**: `ros-jazzy-turtlebot3 ros-jazzy-turtlebot3-msgs` + `ros-jazzy-turtlebot3-gazebo`(월드와 launch). 둘째를 빠뜨리면 `Package 'turtlebot3_gazebo' not found`. 첫 줄이 slam_toolbox·nav2_map_server·nav2_bringup 등을 함께 데려온다.
- **띄우기**: `export TURTLEBOT3_MODEL=burger` → `ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py` — `urdf_file_name : turtlebot3_burger.urdf`, `Robot initialized`, `[ros_gz_sim]: Entity creation successful.`, 다리 일곱. 육각형 벽과 기둥 아홉.
- **기종을 안 정하면**: `[ERROR] [launch]: Caught exception in launch (see debug for traceback): 'TURTLEBOT3_MODEL'` — 작은따옴표 안 이름 하나 = 「이 이름의 값을 찾다가 없었다」. 매번 치기 싫으면 `echo 'export TURTLEBOT3_MODEL=burger' >> ~/.bashrc`.
- **오타 `burgr`**: 월드는 뜨는데 로봇이 없다 — `[Errno 2] No such file or directory: … turtlebot3_burgr.urdf'`. `echo $TURTLEBOT3_MODEL`.
- **조종기**: `ros2 run turtlebot3_teleop teleop_keyboard` — w/x 선속도(burger ~0.22), a/d 각속도(~2.84), w 한 번에 0.01씩, s·space 정지. 키를 누를 때만 쏜다.
- **이 월드의 /cmd_vel은 TwistStamped**: teleop_keyboard가 내고 ros_gz_bridge가 받는다.
- **완료 판정**: `ros2 topic echo --once /odom --field pose.pose.position` x가 거의 0 → 0.134(13 cm 남짓 전진).

## 원리·구조
```
teleop_keyboard ─/cmd_vel (TwistStamped)→ ros_gz_bridge → Gazebo burger
Gazebo ─(odom, scan, clock …)→ ros_gz_bridge → /odom /scan /clock
turtlebot3_burger.urdf → robot_state_publisher → /tf
```

## 코드 예시
```python
# teleop_keyboard 흉내: 키마다 0.01씩, 기종별 최대값에서 자른다
LIMIT = {"burger": (0.22, 2.84), "waffle": (0.26, 1.82)}
def press(keys, model="burger"):
    lin = ang = 0.0
    for k in keys:
        if k == "w": lin += 0.01
        elif k == "x": lin -= 0.01
        elif k == "a": ang += 0.1
        elif k == "d": ang -= 0.1
        elif k in "s ": lin = ang = 0.0
        lin = max(-LIMIT[model][0], min(LIMIT[model][0], round(lin, 2)))
        ang = max(-LIMIT[model][1], min(LIMIT[model][1], round(ang, 2)))
    return f"currently: linear velocity {lin}  angular velocity {ang}"
print(press("ww"))          # currently: linear velocity 0.02  angular velocity 0.0
print(press("w" * 30))      # currently: linear velocity 0.22  angular velocity 0.0
print(press("wwwa s"))      # currently: linear velocity 0.0  angular velocity 0.0
```
```bash
sudo apt install -y ros-jazzy-turtlebot3 ros-jazzy-turtlebot3-msgs
sudo apt install -y ros-jazzy-turtlebot3-gazebo
export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py
ros2 run turtlebot3_teleop teleop_keyboard
```
