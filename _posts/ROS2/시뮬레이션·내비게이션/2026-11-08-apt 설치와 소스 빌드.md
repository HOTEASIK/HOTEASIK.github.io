# apt 설치와 소스 빌드

## 정의·핵심
- **정의**: ROS 꾸러미를 얻는 두 길 — **apt**는 완성품(`/opt/ros/jazzy`), **소스 빌드**는 저장소를 받아 내 워크스페이스에서 빌드(`~/ros2_ws/install`) (실습 5차시).
- **언제 소스로**: 꾸러미를 직접 고치거나 최신 변경을 받아야 할 때, apt로 배포되지 않을 때(두산 doosan-robot2).
- **리듬(어느 꾸러미든 같다)**: ① `git clone -b jazzy …`(배포판 브랜치) ② `rosdep install --from-paths src --ignore-src -r -y`(기대는 꾸러미를 apt로 채움) ③ `colcon build` ④ `source install/setup.bash`.
  - turtlebot3_simulations는 turtlebot3·turtlebot3_msgs에 기댄다 — 셋 다 jazzy로 받는다 → `Summary: 12 packages finished [1min 56s]`.
- **rosdep 처음이면 멈춘다**: `ERROR: your rosdep installation has not been initialized yet. Please run: sudo rosdep init / rosdep update` — 컴퓨터마다 한 번. rosdep = package.xml의 의존성을 apt 꾸러미 이름으로 바꿔 깔아 주는 도구.
- **어느 쪽이 쓰이나**: 같은 꾸러미가 두 곳에 있으면 source한 overlay가 덮는다 — `ros2 pkg prefix turtlebot3_gazebo` → `/home/student/ros2_ws/install/turtlebot3_gazebo`. 새 터미널에서 source를 빼먹으면 다시 apt 판 — 두 판이 섞일 때 헷갈리는 까닭.
- **빌드 범위**: 두산처럼 큰 꾸러미를 받은 뒤엔 `--packages-select my_py_pkg`로 고르는 습관(전체 29개 재빌드를 피함). 반대로 일부만 고르면 의존하는 꾸러미가 없어 실행에서 죽는다(`package 'dsr_controller2' not found`).
- **stderr output 두 줄**은 경고를 냈다는 표시일 뿐 finished면 빌드는 끝났다.

## 원리·구조
| 기준 | apt 설치 | 소스 빌드(jazzy 브랜치) |
|---|---|---|
| 설치 난이도 | 두 줄 | clone · 의존성 · 빌드 |
| 소요 시간 | 짧다 | 길다(빌드 대기) |
| 코드 수정 | 안 된다 | 된다 |
| 최신 변경 | 배포 시점까지 | 브랜치 최신까지 |
| 권장 대상 | 처음 따라 하는 학습자 | 꾸러미를 손봐야 하는 개발자 |

## 코드 예시
```python
# 같은 꾸러미가 underlay·overlay 둘에 있을 때 어느 쪽이 쓰이나 (뒤에 source한 쪽이 앞)
def prefix(pkg, sourced):
    search = []
    for ws in sourced:                      # source 순서대로 앞에 끼워 넣는다
        search.insert(0, ws)
    for ws, pkgs in search:
        if pkg in pkgs: return ws
    return f"Package '{pkg}' not found"
apt = ("/opt/ros/jazzy", {"turtlebot3_gazebo", "turtlesim"})
mine = ("/home/student/ros2_ws/install", {"turtlebot3_gazebo", "my_py_pkg"})
print(prefix("turtlebot3_gazebo", [apt, mine]))   # /home/student/ros2_ws/install
print(prefix("turtlebot3_gazebo", [apt]))         # /opt/ros/jazzy  ← 새 터미널에서 source를 빼먹음
print(prefix("dsr_controller2", [apt, mine]))     # Package 'dsr_controller2' not found
```
```bash
cd ~/ros2_ws/src
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3_msgs.git
git clone -b jazzy https://github.com/ROBOTIS-GIT/turtlebot3_simulations.git
cd ~/ros2_ws
sudo rosdep init && rosdep update          # 컴퓨터마다 한 번
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install && source install/setup.bash
ros2 pkg prefix turtlebot3_gazebo
```
