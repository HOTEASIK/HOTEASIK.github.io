# SLAM

## 정의·핵심
- **정의**: SLAM(Simultaneous Localization And Mapping) — **위치를 알아내면서 동시에 지도를 그린다**. 지도를 그리려면 내 위치를, 내 위치를 알려면 지도를 알아야 하는 닭과 달걀 문제를 라이다 측정과 이동 추정을 끊임없이 맞춰 가며 함께 푼다 (실습 5차시).
- **slam_toolbox = 2D SLAM**: 바닥과 나란한 한 층 라이다 스캔 → 위에서 내려다본 평면도. 청소·안내 로봇처럼 바닥이 평평한 실내에 충분. 3D SLAM은 계단·복잡한 공간까지, 계산이 무겁다.
- **띄우기**: `sudo apt install -y ros-jazzy-slam-toolbox` → `ros2 launch slam_toolbox online_async_launch.py use_sim_time:=true`. 로그 `Configuring` → `[LifecycleLaunch] Slamtoolbox node is activating.` → `Activating` — 관리되는 노드를 launch가 대신 올렸다. `Registering sensor: [Custom Described Lidar]`.
- **online_async**: online = 돌아다니는 그 시간에(offline은 기록 데이터를 나중에), async = 데이터 속도에 얽매지 않고 갱신해 무거운 계산이 몰려도 멈칫하지 않게.
- **넘어가도 되는 경고**: `Message Filter dropping message …`(켤 때 한두 번), `maximum laser range setting (20.0 m) exceeds the capabilities of the used Lidar (3.5 m)`.
- **RViz는 따로**: `rviz2 -d /opt/ros/jazzy/share/nav2_bringup/rviz/nav2_default_view.rviz`(Map·LaserScan·TF, Fixed Frame map). 지도가 자라는 건 숫자로도 — `ros2 topic echo --once /map --field info.width` 89 → 98칸, 한 칸 0.05 m.
- **원리 ① 스캔 정합(scan matching)**: 조금 움직인 뒤 다시 잰 스캔을 앞 스캔과 겹쳐 「얼마나 움직였는지」를 거꾸로 추정.
- **원리 ② 루프 클로저(loop closure)**: 누적 오차로 한 바퀴 돌아오면 시작과 끝이 어긋나 벽이 이중으로 그려진다 → 「전에 와 본 곳」임을 알아채 오차를 한꺼번에 편다.
- **좋은 지도를 만드는 요령**: 천천히 부드럽게(w 몇 번만) · 막다른 곳·모서리까지 골고루 · 출발점을 한 번 더 지나 고리를 닫는다. 뒤틀리면 속도를 낮추고 특징 뚜렷한 길로, 그래도면 use_sim_time·TF.
- **지도 다 그린 뒤**: 매핑 모드로 계속 켜 둘 까닭이 없다 → 저장([[점유 격자 지도]]) → 운영은 [[AMCL]]이 「있는 지도 위에서 내 위치만」.

## 원리·구조
```
스캔 t ─┐
        ├─ 정합 → Δ(x, y, θ) → 위치 갱신 → 지도에 벽 쌓기
스캔 t+1┘
… 한 바퀴 → "여기 와 봤다" → 루프 클로저 → 누적 오차 펴기
```

## 코드 예시
```python
# 스캔 정합 흉내: 두 스캔(점 집합)을 겹치게 하는 이동량을 격자 탐색으로 찾는다
import numpy as np
wall = np.array([[x, 2.0] for x in np.linspace(-1, 1, 21)] + [[2.0, y] for y in np.linspace(-1, 2, 31)])
true_move = np.array([0.3, -0.1])
scan2 = wall - true_move                     # 로봇이 움직인 뒤 본 같은 벽
best, best_err = None, 1e9
for dx in np.arange(-0.5, 0.51, 0.05):
    for dy in np.arange(-0.5, 0.51, 0.05):
        moved = scan2 + [dx, dy]
        err = np.mean([np.min(np.linalg.norm(wall - p, axis=1)) for p in moved])
        if err < best_err: best, best_err = (round(float(dx), 2), round(float(dy), 2)), err
print(best)        # (0.3, -0.1)  ← 스캔 차이로 이동량을 거꾸로 추정
```

 slam_toolbox로 지도를 만들고, nav2_map_server로 저장하는 방식이 기본입니다. 아래 명령은 Jazzy 기준입니다.

  1. 설치

  sudo apt install ros-jazzy-slam-toolbox ros-jazzy-navigation2 ros-jazzy-nav2-bringup

  2. 미리 갖춰야 할 것

  |    항목    |                           토픽/TF                           |
  |---|---|
  │ 2D LiDAR   │ /scan (sensor_msgs/LaserScan)                               │
  │ 오도메트리 │ odom → base_link TF                                         │
  │ 센서 위치  │ base_link → laser TF (URDF 또는 static_transform_publisher) │


  ▎ TF가 끊겨 있으면 지도가 만들어지지 않습니다. ros2 run tf2_tools view_frames로 먼저 확인하세요.

  3. 실행 순서

  # 1) 로봇 또는 시뮬레이션 실행 (예: TurtleBot3 Gazebo)
  ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py

  # 2) SLAM 실행 (온라인 비동기 모드)
  ros2 launch slam_toolbox online_async_launch.py use_sim_time:=true

  # 3) 로봇 조종
  ros2 run teleop_twist_keyboard teleop_twist_keyboard

  # 4) RViz에서 확인: Fixed Frame = map, Map 디스플레이 추가 (토픽 /map)
  rviz2

  로봇을 천천히 움직여 공간 전체를 돌고, 출발점으로 다시 돌아오면 루프 클로저가 일어나 지도가 보정됩니다.

  4. 지도 저장

  ros2 run nav2_map_server map_saver_cli -f ~/maps/my_map

  → 지도가 my_map.pgm(이미지)과 my_map.yaml(해상도·원점) 두 파일로 저장됩니다. 이 파일은 나중에 Nav2 주행에 씁니다.
  ros2 launch nav2_bringup bringup_launch.py map:=$HOME/maps/my_map.yaml
