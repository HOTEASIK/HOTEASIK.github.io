# ros_gz 브리지

## 정의·핵심
- **정의**: `ros_gz_bridge` — Gazebo 토픽(gz.msgs)과 ROS2 토픽 사이의 **번역기·다리**. 다리가 없으면 Gazebo는 혼자 돌고 ROS2는 빈 토픽만 바라본다 (실습 5차시).
- **한 줄로 놓기**: `ros2 run ros_gz_bridge parameter_bridge /cmd_vel@geometry_msgs/msg/Twist@gz.msgs.Twist`.
- **표기**: `토픽@ROS타입[방향기호]Gz타입` — `@` 양방향 · `[` Gazebo→ROS(라이다 /scan·오도메트리 /odom·시계 /clock) · `]` ROS→Gazebo(단방향 제어 명령). `[`·`]`는 셸이 다르게 읽지 않게 **따옴표**로 감싼다.
- **로그가 다리 수**: `@`면 `Creating GZ->ROS Bridge: [/cmd_vel (gz.msgs.Twist) -> /cmd_vel (geometry_msgs/msg/Twist)]`와 `Creating ROS->GZ Bridge: …` 두 줄, `[`면 GZ->ROS 한 줄만.
- **확인**: `ros2 topic info /cmd_vel -v` 발행자 자리에 `ros_gz_bridge`.
- **목록에 있다 ≠ 값이 흐른다**: shapes 월드엔 /cmd_vel을 받거나 내는 모델이 없어 `echo`가 기다리기만 한다 — 다리 위를 지나갈 짐이 없다. 시계 다리는 Gazebo 자신이 내므로 값이 온다(멈춘 채면 sec 0, ▶ 뒤 nanosec 906000000).
- **타입 짝이 안 맞으면**: `std_msgs/msg/String`+`gz.msgs.Twist` → `[WARN] … Failed to create a bridge for topic [/v5b_test] … No template specialization…` — 프로세스는 안 죽어 놓치기 쉽다. 문서에서 지원 짝을 확인하고 다리 로그에 WARN이 없는지 훑는다.
- **같은 이름, 다른 타입**: /cmd_vel의 ROS 쪽이 손으로 놓은 다리는 Twist, turtlebot3 월드는 **TwistStamped**, Nav2 데모는 다시 Twist — 이름만 보고 짐작하지 않고 `topic info`로.
- **닫힌 고리**: 명령(/cmd_vel)은 안으로, 관측(/scan·/odom)은 밖으로 — 한쪽이 막히면 고리 전체가 멈춘다.
- **실무**: 이을 토픽이 여럿이면 YAML 설정 파일이나 launch 대본에 — turtlebot3 launch는 다리 일곱 개를 한 번에(clock·odom·scan·cmd_vel 등).

## 원리·구조
| 기호 | 방향 | 예 |
|---|---|---|
| `@` | 양방향 | `/cmd_vel@geometry_msgs/msg/Twist@gz.msgs.Twist` |
| `[` | Gazebo → ROS | `'/clock@rosgraph_msgs/msg/Clock[gz.msgs.Clock'` |
| `]` | ROS → Gazebo | `'/cmd_vel@geometry_msgs/msg/Twist]gz.msgs.Twist'` |

## 코드 예시
```python
# 다리 표기 해석기 — 어떤 로그 줄이 나올지 미리 맞혀 본다
import re
def bridge(spec):
    topic, ros_t, sym, gz_t = re.match(r"(/[\w/]+)@([\w/]+)([@\[\]])([\w.]+)", spec).groups()
    lines = []
    if sym in "@[": lines.append(f"Creating GZ->ROS Bridge: [{topic} ({gz_t}) -> {topic} ({ros_t})]")
    if sym in "@]": lines.append(f"Creating ROS->GZ Bridge: [{topic} ({ros_t}) -> {topic} ({gz_t})]")
    return lines
for s in ("/cmd_vel@geometry_msgs/msg/Twist@gz.msgs.Twist", "/clock@rosgraph_msgs/msg/Clock[gz.msgs.Clock"):
    print(len(bridge(s)), bridge(s)[0])
# 2 Creating GZ->ROS Bridge: [/cmd_vel (gz.msgs.Twist) -> /cmd_vel (geometry_msgs/msg/Twist)]
# 1 Creating GZ->ROS Bridge: [/clock (gz.msgs.Clock) -> /clock (rosgraph_msgs/msg/Clock)]
```
```bash
ros2 run ros_gz_bridge parameter_bridge /cmd_vel@geometry_msgs/msg/Twist@gz.msgs.Twist
ros2 run ros_gz_bridge parameter_bridge '/clock@rosgraph_msgs/msg/Clock[gz.msgs.Clock'
ros2 topic info /cmd_vel -v
ros2 topic echo --once /clock
```
