# Nav2 목표 전송

## 정의·핵심
- **정의**: Nav2에게 「여기로 가라」를 보내는 방법 셋 — RViz 단추, 토픽, **액션 `NavigateToPose`** (실습 5차시).
- **RViz 「Nav2 Goal」**: 이 데모 설정의 단추 이름 — 다른 자료의 「2D Goal Pose」와 같은 것. 지도 위 빈 곳(흰 칸)을 클릭한 채 바라볼 쪽으로 끌어 놓는다. 보내는 것은 `/goal_pose`(geometry_msgs/msg/PoseStamped).
- **먼저 초기 위치**: 「2D Pose Estimate」(/initialpose) → `Managed nodes are active` 뒤에 목적지.
- **액션 `/navigate_to_pose`**(nav2_msgs/action/NavigateToPose): 목표 `pose`(PoseStamped, frame_id map), 피드백 `current_pose`·`distance_remaining`·`number_of_recoveries`·`navigation_time`, 결과. bt_navigator가 액션 서버 — 진행률을 받는 「택배」.
- **명령줄**: `ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose "{pose: {header: {frame_id: map}, pose: {position: {x: 1.5, y: 0.0}, orientation: {w: 1.0}}}}" --feedback`.
- **코드**: `nav2_simple_commander`의 `BasicNavigator` — `setInitialPose`, `waitUntilNav2Active`, `goToPose`, `isTaskComplete`, `getFeedback`, `getResult`.
- **이어 찍기**: 앞 목적지에 닿은 뒤 찍으면 출발점이 바뀌어 찍힌다 — `Begin navigating from current location (1.57, 0.01) to (-1.50, -0.50)` → 또 `Goal succeeded`.
- **방향**: orientation은 쿼터니언 — 요 θ면 z = sin(θ/2), w = cos(θ/2).

## 원리·구조
```
RViz Nav2 Goal ─▶ /goal_pose ─┐
ros2 action send_goal ────────┼─▶ bt_navigator (/navigate_to_pose 액션 서버)
BasicNavigator.goToPose ──────┘        ├─ feedback: distance_remaining, recoveries
                                       └─ result → "Goal succeeded"
```

## 코드 예시
```python
# nav2_simple_commander로 목적지 하나 보내기
import rclpy
from geometry_msgs.msg import PoseStamped
from nav2_simple_commander.robot_navigator import BasicNavigator, TaskResult


def make_pose(nav, x, y, w=1.0):
    p = PoseStamped()
    p.header.frame_id = 'map'
    p.header.stamp = nav.get_clock().now().to_msg()
    p.pose.position.x, p.pose.position.y = x, y
    p.pose.orientation.w = w
    return p


rclpy.init()
nav = BasicNavigator()
nav.setInitialPose(make_pose(nav, -2.0, -0.5))
nav.waitUntilNav2Active()
nav.goToPose(make_pose(nav, 1.5, 0.0))
while not nav.isTaskComplete():
    fb = nav.getFeedback()
    if fb:
        print(f'남은 거리 {fb.distance_remaining:.2f} m')
print('Goal succeeded' if nav.getResult() == TaskResult.SUCCEEDED else 'failed')
rclpy.shutdown()
```

```python
# 바라볼 방향(요) → orientation 칸
import math
for deg in (0, 90, 180):
    t = math.radians(deg)
    print(deg, {"z": round(math.sin(t / 2), 3), "w": round(math.cos(t / 2), 3)})
# 0 {'z': 0.0, 'w': 1.0}
# 90 {'z': 0.707, 'w': 0.707}
# 180 {'z': 1.0, 'w': 0.0}
```
