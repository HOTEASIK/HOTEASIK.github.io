# ros2 action

## 정의·핵심
- **정의**: 액션을 보고 남의 노드에 목표를 보내는 명령 — `list -t`, `info`, `send_goal` (기초 5차시, 입문 5차시, 실습 1차시).
- **`action info /이름`**: 그 액션에 붙은 서버·클라이언트 수 — 짧다.
- **`send_goal ... --feedback`**: 목표 → 수락(`Goal accepted with ID: ...` 32자리, 매번 다름) → 피드백(여러 번) → 결과 → `Goal finished with status: SUCCEEDED`. `--feedback`을 빼면 결과만.
- **목표 칸 이름을 모르면** `ros2 interface show turtlesim/action/RotateAbsolute`.
- **도중 Ctrl+C**: 다른 명령과 달리 두 줄 — `Canceling goal...` 후 취소 결과. 취소는 서버 터미널과 클라이언트 터미널에 나뉘어 찍힌다.
- **명령을 친 쪽은 결과를 찍고, 서버는 로그를 찍는다**: 두 터미널을 함께 본다.
- **CLI로 먼저**: 내 액션 클라이언트를 짜기 전에 send_goal로 서버를 검증 — 의심의 범위를 좁힌다.
- **status 번호**: 화면에는 이름(SUCCEEDED·CANCELED·ABORTED), 내부에는 번호(4·5·6).

## 원리·구조
```
$ ros2 action send_goal /turtle1/rotate_absolute turtlesim/action/RotateAbsolute "{theta: 1.57}" --feedback
Waiting for an action server to become available...
Sending goal:
     theta: 1.57
Goal accepted with ID: 6f0b...
Feedback:
    remaining: 1.24
...
Result:
    delta: -1.552
Goal finished with status: SUCCEEDED
```

## 코드 예시
```python
# send_goal 출력에서 결과 상태와 피드백 개수 뽑기
out = """Goal accepted with ID: ab21f311107c424da9db145398d62841
Feedback:
    current: 1
Feedback:
    current: 2
Result:
    sequence: [1, 2]
Goal finished with status: SUCCEEDED"""
lines = out.splitlines()
gid = lines[0].split(": ")[1]
print(len(gid), lines.count("Feedback:"), lines[-1].rsplit(" ", 1)[1])   # 32 2 SUCCEEDED
```
