# 진단 사다리

## 정의·핵심
- **정의**: 「로봇이 안 움직인다」를 만났을 때 **위에서부터 한 칸씩 내려가며** 확인하는 순서 — 노드 → 연결 → 이름 → 값 → 빠르기 (입문 3차시, 실습 1차시).
- **규칙**: 첫 이상에서 **멈춘다**. 가장 위의 이상을 고치고, 고쳤으면 **처음부터 다시** 내려간다(아래 칸 이상은 위 칸 때문일 때가 많다).
- **① node list** — 노드가 살아 있나. `--no-daemon`으로 데몬의 낡은 목록을 피한다. 안 보이면: 실행 안 됨·죽음.
- **② node info** — 맞는 토픽을 구독·발행하나. 다르면: 토픽 이름이 틀렸다.
- **③ topic list** — 보내는 이름 = 듣는 이름인가. 비슷한 이름이 따로 서 있으면(`/cmd_vel`과 `/turtle1/cmd_vel`): 오타·namespace → remap.
- **④ topic echo** — 의미 있는 값이 흐르나. 안 오면 발행 멈춤, 와도 전부 0이면 보내는 쪽 로직.
- **⑤ topic hz** — 기대한 빠르기인가. 느리면 발행자 과부하·타이머 설정.
- **QoS 갈래**: echo로 값은 보이는데 거북이는 안 움직인다 → 로그에서 `[WARN] New publisher discovered … offering incompatible QoS … Last incompatible policy: RELIABILITY_QOS_POLICY`를 찾고 `topic info --verbose`로 양쪽 QoS를 비교 (echo는 자기 QoS를 맞춰 붙기 때문에 값이 보일 수 있다).
- **기록**: 칸마다 「명령 · 본 것 · 판단」을 한 줄씩 남기면 도움 요청·인수인계가 빠르다.

## 원리·구조
| 칸 | 명령 | 정상 | 아니면 의심 |
|---|---|---|---|
| ① | `ros2 node list --no-daemon` | 노드 이름이 보인다 | 노드가 안 켜졌다·죽었다, 데몬 낡은 목록 |
| ② | `ros2 node info /노드` | 맞는 토픽을 구독 | 토픽 이름 틀림 |
| ③ | `ros2 topic list` | 보낸 이름 = 들은 이름 | 비슷한 이름이 따로 — 오타·namespace |
| ④ | `ros2 topic echo /토픽` | 의미 있는 값이 흐름 | 발행 멈춤, 값이 0 |
| ⑤ | `ros2 topic hz /토픽` | 기대 주기 | 발행자 과부하 |
| 갈래 | `ros2 topic info -v /토픽` | QoS가 맞음 | RELIABILITY 불일치 |

## 코드 예시
```python
# 사다리를 위에서부터 내려가다 첫 이상에서 멈춘다
LADDER = [("① node list", lambda s: "/turtlesim" in s["nodes"], "노드가 안 켜졌다"),
          ("② node info", lambda s: s["sub"] == "/turtle1/cmd_vel", "구독 토픽 이름이 틀렸다"),
          ("③ topic list", lambda s: s["pub"] == s["sub"], "보내는 이름과 듣는 이름이 다르다"),
          ("④ echo", lambda s: any(s["values"]), "값이 0이거나 안 온다"),
          ("⑤ hz", lambda s: s["hz"] >= 0.8 * s["want_hz"], "발행이 느리다")]
def diagnose(s):
    for name, ok, why in LADDER:
        if not ok(s):
            return f"{name} 에서 멈춤: {why}"
    return "사다리 통과 → QoS 갈래 확인"
state = {"nodes": ["/turtlesim", "/my_driver"], "sub": "/turtle1/cmd_vel",
         "pub": "/cmd_vel", "values": [0.5], "hz": 10, "want_hz": 10}
print(diagnose(state))                   # ③ topic list 에서 멈춤: 보내는 이름과 듣는 이름이 다르다
state["pub"] = "/turtle1/cmd_vel"        # remap으로 고치고 처음부터 다시
print(diagnose(state))                   # 사다리 통과 → QoS 갈래 확인
```
```bash
ros2 node list --no-daemon
ros2 node info /turtlesim
ros2 topic list
ros2 topic echo /turtle1/cmd_vel --once
ros2 topic hz /turtle1/cmd_vel
ros2 topic info -v /turtle1/cmd_vel
```
