# ros2 doctor

## 정의·핵심
- **정의**: ROS2 **설치·환경·네트워크·토픽 상태를 자동 점검**하는 명령 (실습 1차시 심화).
- **`ros2 doctor`**: 점검 몇 가지를 돌려 경고를 찍고 끝에 `All 5 checks passed` 같은 요약 — **긴 출력은 끝 줄부터 읽는다**(QoS 경고를 찾을 때와 같은 눈).
- **흔한 알림**
  - 꾸러미 알림 `local: … < latest: …` — 깔린 꾸러미가 최신판보다 뒤처졌다(네트워크가 없으면 이 점검은 건너뛴다). 몇 줄이 나오는지는 날마다 다르다.
  - 토픽 알림 `UserWarning: Subscriber without publisher detected on /turtle1/cmd_vel.` — 듣는 쪽만 있고 보내는 쪽이 없다(거북이를 띄워만 두면 나온다) / 반대로 `Publisher without subscriber`.
- **`ros2 doctor --report`**: NETWORK CONFIGURATION, PLATFORM INFORMATION, RMW MIDDLEWARE, ROS 2 INFORMATION, PACKAGE VERSIONS 등으로 나뉜 보고 — **도움을 청할 때 함께 공유**한다(배포판·RMW·네트워크 인터페이스가 한눈에).
- **함께 쓰는 보조 명령**: `ros2 interface show`(메시지 구조), `ros2 daemon status/stop`(목록을 믿을 수 있나), `ros2 topic info`(발행자가 있긴 한가 — echo 전에 먼저).
- 통신이 아예 안 될 때(다른 PC와): report의 네트워크 칸, `ROS_DOMAIN_ID`, 방화벽·멀티캐스트를 확인.

## 원리·구조
```
$ ros2 doctor
.../topic_check.py: UserWarning: Subscriber without publisher detected on /turtle1/cmd_vel.
All 5 checks passed
$ ros2 doctor --report | grep -A3 "RMW MIDDLEWARE"
 RMW MIDDLEWARE
middleware name    : rmw_fastrtps_cpp
```

## 코드 예시
```python
# doctor 출력은 끝 줄부터: 요약 → 경고 종류별 정리
out = """/opt/ros/jazzy/.../package.py: UserWarning: ros-jazzy-rviz2 : local: 14.1.5 < latest: 14.1.6
/opt/ros/jazzy/.../topic.py: UserWarning: Subscriber without publisher detected on /turtle1/cmd_vel.
All 5 checks passed"""
lines = out.splitlines()
print("요약:", lines[-1])                                           # 요약: All 5 checks passed
for l in lines[:-1]:
    msg = l.split("UserWarning: ", 1)[1]
    kind = "꾸러미" if "latest" in msg else "토픽"
    print(kind, "→", msg)
# 꾸러미 → ros-jazzy-rviz2 : local: 14.1.5 < latest: 14.1.6
# 토픽 → Subscriber without publisher detected on /turtle1/cmd_vel.
```
```bash
ros2 doctor
ros2 doctor --report > doctor_report.txt
ros2 daemon status
```
