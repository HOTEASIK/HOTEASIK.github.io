# ros2 run

## 정의·핵심
- **정의**: 패키지 안의 실행 파일 하나를 띄우는 명령. `ros2 run <패키지> <실행 이름> [인자] [--ros-args ...]` (기초 3·4차시, 입문 3차시).
- **실행 이름**: 파이썬 패키지는 setup.py `entry_points`에 등록한 왼쪽 이름, C++은 CMake로 설치한 실행 파일 이름. 노드 이름과 다를 수 있다(`turtlesim_node` → `/turtlesim`).
- **찾는 곳**: `install/<패키지>/lib/<패키지>/` (source 된 경로들에서).
- **`--ros-args` 뒤**: `-r 원래:=새`(remap), `-r __ns:=/robot1`, `-r __node:=이름`, `-p 이름:=값`(파라미터), `--params-file f.yaml`, `--log-level 노드:=debug`.
- **그 앞의 인자**는 프로그램 자신이 받는다 — `ros2 run my_py_pkg add_client 3 4` → `sys.argv[1:]`.
- **오류 두 꼴**: 실행 이름을 틀리면 `No executable found`(이름도 따옴표도 없다), 패키지 이름을 틀리면 `Package 'my_py_pkgX' not found`(따옴표와 이름이 붙는다) — 화면이 어느 쪽을 틀렸는지 먼저 알려 준다.
- **실행 파일 목록**: `ros2 pkg executables turtlesim`.
- 화면이 없는 원격 터미널에서 GUI 노드는 `QT_QPA_PLATFORM=offscreen ros2 run turtlesim turtlesim_node`로 창 없이 띄울 수 있다.

## 원리·구조
```
ros2 run my_py_pkg my_publisher --ros-args -r chatter:=talk -p rate:=2.0
        └패키지┘ └실행 이름┘       └────── ROS가 해석하는 인자 ──────┘
```

## 코드 예시
```python
# argv 를 프로그램 인자와 --ros-args 로 가르기 (rclpy.utilities.remove_ros_args 와 같은 생각)
def split_args(argv):
    if "--ros-args" not in argv: return argv, []
    i = argv.index("--ros-args")
    rest = argv[i + 1:]
    end = rest.index("--") if "--" in rest else len(rest)
    return argv[:i] + rest[end + 1:], rest[:end]
print(split_args(["add_client", "3", "4"]))
# (['add_client', '3', '4'], [])
print(split_args(["add_client", "3", "4", "--ros-args", "-r", "__ns:=/r1", "-p", "x:=1"]))
# (['add_client', '3', '4'], ['-r', '__ns:=/r1', '-p', 'x:=1'])
```
```bash
ros2 pkg executables turtlesim
ros2 run turtlesim turtlesim_node --ros-args -r __node:=my_turtle -p background_r:=200
ros2 run my_py_pkg add_client 3 4
```
