# rqt_graph

## 정의·핵심
- **정의**: 노드(타원)와 토픽(사각형)의 연결 관계를 **그림(배선도)** 으로 보여 주는 rqt 플러그인. 머릿속 배선도를 화면에 띄운다 (기초 5차시, 실습 3차시).
- **무엇을 보여 주고 무엇을 안 보여 주나**: 「누가 누구와 연결돼 있나」(구조)는 보이지만, 선을 타고 **어떤 값이 흐르는지는 안 보인다** → 값은 `topic echo`. 먼저 graph로 「연결이 맞나」, 맞는데도 이상하면 echo로 「값이 맞나」.
- **끊긴 곳을 찾는 진단 도구**: 두 노드를 띄웠는데 동작이 없으면, 보통 한쪽은 `/scan`으로 보내고 다른 쪽은 `/laser`를 듣고 있다 — 그림에서 두 토픽 상자가 따로 떠 있다. **가장 쓸모 있는 정보는 「없는 화살표」**.
- **함정 셋**
  1. 새로 켠 노드가 안 보이면 → 좌상단 **새로고침**(스스로 갱신하지 않는다).
  2. 화살표가 하나도 안 보이면 → 드롭다운을 **「Nodes/Topics (all)」** 로.
  3. cmd_vel 연결이 안 잡히면 → 거북이가 **실제로 움직이는 동안** 새로고침.
- **turtlesim 예**: `/teleop_turtle → /turtle1/cmd_vel → /turtlesim`.
- **namespace 확인**: robot1·robot2·robot3을 띄우고 그래프에서 세 묶음의 선이 안 엉키는지 본다.
- 숨은 토픽·디버그 노드를 감추는 체크박스(Hide: Debug, tf 등)도 있다.

## 원리·구조
```
 (/teleop_turtle) ──▶ [/turtle1/cmd_vel] ──▶ (/turtlesim) ──▶ [/turtle1/pose]
 끊긴 예:  (/lidar_driver) ──▶ [/scan]          [/laser] ──▶ (/mapper)    ← 화살표 없음
```

## 코드 예시
```python
# rqt_graph가 하는 일: 발행/구독 목록으로 간선 만들고, 끊긴 토픽 찾기
pubs = {"/lidar_driver": ["/scan"], "/teleop_turtle": ["/turtle1/cmd_vel"]}
subs = {"/mapper": ["/laser"], "/turtlesim": ["/turtle1/cmd_vel"]}
edges, topics_p, topics_s = [], set(), set()
for n, ts in pubs.items():
    for t in ts: topics_p.add(t); edges += [(n, t)]
for n, ts in subs.items():
    for t in ts: topics_s.add(t); edges += [(t, n)]
print(sorted(topics_p & topics_s))           # ['/turtle1/cmd_vel']  ← 이어진 토픽
print("발행만:", sorted(topics_p - topics_s), "구독만:", sorted(topics_s - topics_p))
# 발행만: ['/scan'] 구독만: ['/laser']   ← remap 후보: -r /scan:=/laser
```

```bash
rqt_graph
ros2 run rqt_graph rqt_graph
```
