# ros2 node

## 정의·핵심
- **`ros2 node list`**: 누가 살아 있는가 — 로봇을 켜고 가장 먼저 치는 명령. 진단 사다리 ①단계 (기초 4차시, 실습 1차시).
- **`ros2 node info /이름`**: 그 노드 하나의 연결을 펼친다 — Subscribers(받는 토픽) / Publishers(내보내는 토픽) / Service Servers / Service Clients / Action Servers / Action Clients. node list가 「누가」라면 info는 「무엇을 주고받나」.
- **읽는 법**: `/turtlesim`은 `/turtle1/cmd_vel`을 Subscribers에, `/turtle1/pose`·`/turtle1/color_sensor`를 Publishers에 둔다. 모든 노드에 딸려 나오는 `/parameter_events`, `/rosout`, `/노드/get_parameters` 등 설정용 서비스는 기본으로 붙는 것.
- **처음 받은 로봇 패키지 앞에서**: 문서를 찾기 전에 `node list` → `node info`로 「이 노드가 무엇을 기대하는가」를 먼저 읽는다.
- **목록이 이상하면**: 갑자기 죽은 노드가 남아 보이면 데몬의 옛 기억 → `ros2 node list --no-daemon`. Ctrl+C로 정상 종료한 노드는 즉시 빠진다(실험에선 강제 종료 노드가 스무 초 가까이 남았다).
- **같은 이름 둘**: 경고와 함께 시스템이 혼란 — 이름을 바꿔 띄운다(`__node:=`, launch `name=`).
- namespace가 있으면 `/robot1/turtlesim`처럼 폴더 안에 보인다.

## 원리·구조
```
$ ros2 node info /turtlesim
/turtlesim
  Subscribers:
    /parameter_events: rcl_interfaces/msg/ParameterEvent
    /turtle1/cmd_vel: geometry_msgs/msg/Twist
  Publishers:
    /parameter_events: rcl_interfaces/msg/ParameterEvent
    /rosout: rcl_interfaces/msg/Log
    /turtle1/color_sensor: turtlesim/msg/Color
    /turtle1/pose: turtlesim/msg/Pose
  Service Servers:
    /clear: std_srvs/srv/Empty
    /spawn: turtlesim/srv/Spawn
    ...
  Action Servers:
    /turtle1/rotate_absolute: turtlesim/action/RotateAbsolute
```

## 코드 예시
```python
# node info 출력을 파싱해 "기본으로 붙는 것"을 걸러 내 노드만의 연결 보기
info = """/turtlesim
  Subscribers:
    /parameter_events: rcl_interfaces/msg/ParameterEvent
    /turtle1/cmd_vel: geometry_msgs/msg/Twist
  Publishers:
    /parameter_events: rcl_interfaces/msg/ParameterEvent
    /rosout: rcl_interfaces/msg/Log
    /turtle1/pose: turtlesim/msg/Pose"""
BUILTIN = {"/parameter_events", "/rosout"}
sec, out = None, {}
for line in info.splitlines()[1:]:
    if line.endswith(":") and line.startswith("  ") and not line.startswith("    "):
        sec = line.strip(" :"); out[sec] = []
    elif line.startswith("    "):
        name = line.strip().split(":")[0]
        if name not in BUILTIN: out[sec].append(name)
print(out)   # {'Subscribers': ['/turtle1/cmd_vel'], 'Publishers': ['/turtle1/pose']}
```
```bash
ros2 node list
ros2 node info /turtlesim
ros2 node list --no-daemon
```
