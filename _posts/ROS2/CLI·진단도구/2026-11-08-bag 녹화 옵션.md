# bag 녹화 옵션

## 정의·핵심
- **정의**: `ros2 bag record`에서 **무엇을·어디에·어떻게** 담을지 고르는 옵션들 (입문 8차시).
- **무엇을**
  - `--topics /a /b` — 이름을 골라 담는다. 토픽을 옵션 없이 늘어놓는 옛 꼴은 이제 **deprecated** — WARN이 찍힌다.
  - `-a` — 전부. 단 숨은 토픽(`_`로 시작)은 안 들어간다.
  - `-e "정규식"` — 이름이 맞는 것만. `-a`와 함께 주면 `-a`가 이긴다(전부 녹화).
  - `--exclude-regex "/rosout|/parameter_events|/events/.*"` — 시끄러운 시스템 토픽 빼기(`-a`와 짝).
- **어디에**: `-o 폴더` — 같은 이름이 있으면 오류.
- **어떻게**
  - `-s mcap|sqlite3` — 저장 형식(기본 mcap, sqlite3는 `.db3`).
  - `--compression-mode file|message --compression-format zstd` — 압축. file은 통째로(`.mcap.zstd`), message는 메시지마다.
  - `-d 3` — **3초마다 새 파일로 나눈다**(split). 10초 녹화면 파일 4개. play의 `-d`(지연)와 뜻이 다르다.
- **실측(입문 8차시)**: 같은 녹화를 plain 12.7 KiB / zfile 4.6 KiB / zmsg 13.5 KiB — 작은 메시지를 하나씩 압축하면 머리말 때문에 **오히려 커진다**. 작은 메시지가 많으면 file 모드.

## 원리·구조
| 하고 싶은 것 | 옵션 |
|---|---|
| 두 토픽만 | `--topics /a /b` |
| 전부, 시스템 토픽 빼고 | `-a --exclude-regex "/rosout\|/parameter_events"` |
| turtle1 아래 전부 | `-e "/turtle1/.*"` |
| 폴더 이름 | `-o run1` |
| 작게 | `--compression-mode file --compression-format zstd` |
| 긴 녹화를 토막으로 | `-d 60` (초) |

## 코드 예시
```python
# 녹화 옵션이 고르는 토픽을 흉내 낸다: -a, -e, --exclude-regex
import re
topics = ["/turtle1/cmd_vel", "/turtle1/pose", "/rosout", "/parameter_events", "/events/read_split", "/_hidden"]
visible = [t for t in topics if not t.split("/")[-1].startswith("_")]
def record(a=False, e=None, exclude=None):
    sel = visible if a else [t for t in visible if e and re.search(e, t)]
    return [t for t in sel if not (exclude and re.search(exclude, t))]
print(record(e="/turtle1/.*"))          # ['/turtle1/cmd_vel', '/turtle1/pose']
print(record(a=True, exclude="/rosout|/parameter_events|/events/.*"))   # ['/turtle1/cmd_vel', '/turtle1/pose']
print(len(record(a=True, e="/turtle1/.*")))   # 5  ← -a가 이긴다(숨은 토픽은 빠짐)
# 실측 크기 비교 (KiB)
size = {"plain": 12.7, "zfile": 4.6, "zmsg": 13.5}
print(min(size, key=size.get), round(size["zfile"] / size["plain"] * 100), "%")   # zfile 36 %
```
```bash
ros2 bag record -o plain --topics /turtle1/cmd_vel /turtle1/pose
ros2 bag record -o zfile --compression-mode file --compression-format zstd --topics /turtle1/pose
ros2 bag record -o allbag -a --exclude-regex "/rosout|/parameter_events|/events/.*"
ros2 bag record -o split -d 3 --topics /turtle1/pose
```
