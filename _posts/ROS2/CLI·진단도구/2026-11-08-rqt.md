# rqt

## 정의·핵심
- **정의**: ROS2의 **GUI 진단 도구 모음**. 코드를 고치지 않고 돌아가는 시스템을 눈으로 진단한다. 작은 도구(플러그인)의 묶음으로 설계 — 필요한 것만 골라 쓰고 새 도구는 기존 것을 건드리지 않고 더한다(컴포넌트와 통하는 사고방식) (기초 5차시, 실습 3차시).
- **자주 쓰는 넷** — 기억 고리: 구조는 graph, 로그는 console, 값은 plot, 설정은 reconfigure.
- **증상이 도구를 고른다**: ① 값이 안 온다 → graph(없는 화살표가 답일 때가 많다) ② 값이 튄다 → plot ③ 왜 실패했나 → console(심각도로 걸러) ④ 바꿔 보고 싶다 → reconfigure(빌드 왕복 없이) ⑤ 그림이 그대로 → graph 새로고침(스스로 갱신 안 됨) ⑥ 너무 느리다 → rqt로는 부족, `topic hz`·`bw` 명령줄이 낫다. **창을 넷 다 켜는 것은 진단이 아니다.**
- **명령줄과 짝**: GUI는 CLI의 대체가 아니다. console은 로그가 없으면 아무것도 없다(로그 없음 ≠ 문제 없음), reconfigure는 파라미터를 드러낸 노드만 목록에 있다.
- **협업**: 「여기 화살표가 끊겨 있다」는 rqt_graph 캡처 한 장이 토픽 목록을 늘어놓는 것보다 빠르다.
- **창이 안 뜨면**: 띄운 터미널이 화면에 이어져 있지 않다(원격 SSH) — `could not connect to display`, `no Qt platform plugin could be initialized`. 데스크톱의 터미널에서 띄운다.
- 그 밖: Message Publisher, Service Caller, Topic Monitor, Image View, TF Tree 등 — `rqt` 실행 후 Plugins 메뉴에서.

## 원리·구조
| 플러그인 | 보여 주는 것 | 대표 상황 |
|---|---|---|
| rqt_graph | 노드–토픽 연결 그림 | 끊긴 연결 찾기 |
| rqt_console | 여러 노드 로그를 한 창에, 심각도 필터 | 오류 추적, 간헐적 경고 |
| rqt_plot | 토픽 값을 시간축 곡선으로 | 값이 튀거나 흔들릴 때 |
| rqt_reconfigure | 파라미터를 슬라이더·입력창으로 | 코드 수정 없이 튜닝 |

## 코드 예시
```python
# 증상 → 먼저 열 창 (실습 3차시 정답표)
FIRST = {"값이 안 온다": ("rqt_graph", "연결이 있나부터"),
         "값이 튄다": ("rqt_plot", "곡선의 모양으로"),
         "왜 실패했나": ("rqt_console", "심각도로 걸러 읽는다"),
         "바꿔 보고 싶다": ("rqt_reconfigure", "빌드 없이 값만"),
         "너무 느리다": ("ros2 topic hz / bw", "GUI가 늘 정답은 아니다")}
for s in ("값이 안 온다", "너무 느리다"):
    tool, why = FIRST[s]; print(f"{s} → {tool} ({why})")
# 값이 안 온다 → rqt_graph (연결이 있나부터)
# 너무 느리다 → ros2 topic hz / bw (GUI가 늘 정답은 아니다)
```
```bash
rqt
rqt_graph
ros2 run rqt_console rqt_console
ros2 run rqt_plot rqt_plot /turtle1/pose/x
ros2 run rqt_reconfigure rqt_reconfigure
```
