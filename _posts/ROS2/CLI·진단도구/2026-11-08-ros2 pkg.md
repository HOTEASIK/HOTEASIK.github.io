# ros2 pkg

## 정의·핵심
- **정의**: 설치된 패키지를 묻는 명령 묶음 (입문 1차시, 실습 1·5차시). 만들기 `create`는 [[ros2 pkg create]].
- **`list`**: 지금 터미널이 아는 모든 패키지 — `| grep my_py_pkg`로 내 패키지가 정식 등록됐는지(빌드 + source 확인). 안 뜨면 overlay source를 먼저 의심.
- **`executables 패키지`**: 그 그릇에 든 실행 파일 — `ros2 run` 뒤에 칠 이름을 찾을 때. 패키지 없이 치면 전부.
- **`prefix 패키지`**: 어디에 설치됐나 — `/opt/ros/jazzy`(apt 판)인지 `~/ros2_ws/install/…`(내가 빌드한 판)인지. 같은 패키지가 두 곳에 있을 때 어느 쪽이 쓰이는지 가린다.
- **`xml 패키지`**: 그 패키지의 package.xml 내용 — 의존성 확인.
- **`--share`**: `ros2 pkg prefix --share turtlebot3_gazebo` → share 폴더(launch·모델·config가 사는 곳).
- **진단 쓰임**: `Package '…' not found`를 받았을 때 → `pkg list | grep`으로 정말 없는지(→ 설치·빌드) / 있는데 run이 못 찾는지(→ 실행 이름·entry_points).

## 원리·구조
```
$ ros2 pkg prefix turtlebot3_gazebo
/home/student/ros2_ws/install/turtlebot3_gazebo     ← 소스판이 apt판을 덮었다
$ ros2 pkg executables turtlesim
turtlesim draw_square
turtlesim mimic
turtlesim turtle_teleop_key
turtlesim turtlesim_node
```

## 코드 예시
```python
# pkg executables 출력 → 패키지별 실행 파일 dict, 그리고 오타 추천
import difflib
out = """turtlesim draw_square
turtlesim mimic
turtlesim turtle_teleop_key
turtlesim turtlesim_node"""
exes = {}
for line in out.splitlines():
    pkg, exe = line.split(); exes.setdefault(pkg, []).append(exe)
print(exes["turtlesim"])                                        # ['draw_square', 'mimic', 'turtle_teleop_key', 'turtlesim_node']
print(difflib.get_close_matches("turtle_node", exes["turtlesim"], n=1))   # ['turtlesim_node']
```
```bash
ros2 pkg list | grep -E 'my_first_package|my_py_pkg'
ros2 pkg executables turtlesim
ros2 pkg prefix turtlesim
ros2 pkg prefix --share turtlebot3_gazebo
ros2 pkg xml turtlesim | head
```
