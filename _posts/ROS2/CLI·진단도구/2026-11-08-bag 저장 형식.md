# bag 저장 형식

## 정의·핵심
- **정의**: bag 폴더 안 데이터 파일을 담는 그릇(storage plugin). Jazzy 기본은 **mcap**, 예전 기본은 **sqlite3**(`.db3`) (입문 8차시).
- **폴더 구성**: `metadata.yaml`(어떤 토픽·몇 개·얼마 동안·어떤 형식) + `이름_0.mcap`(나뉘면 `_1`, `_2` …). `info`는 metadata를 읽어 보여 준다.
- **mcap**: 녹화에 맞춘 이어 쓰기 형식 — 빠르고, 메시지 스키마를 함께 담아 다른 도구(Foxglove 등)에서도 연다. Storage id: `mcap`.
- **sqlite3**: 데이터베이스 파일 — `-s sqlite3`로 고른다. 옛 bag·다른 팀 bag을 열 때 만난다.
- **직렬화 형식(Serialization Format)**: 둘 다 메시지 자체는 **cdr**(DDS가 전선에 싣는 바이트) 그대로 저장 — 그래서 [[rosbag2_py]]로 읽으면 바이트가 나오고 `deserialize_message`로 풀어야 한다.
- **압축 파일**: file 압축이면 `.mcap.zstd`, message 압축이면 확장자는 그대로 `.mcap`이고 안의 메시지만 압축.
- **형식을 몰라도 된다**: play·info는 metadata를 보고 알아서 고른다. 코드에서 열 때만 `storage_id`를 맞춘다.

## 원리·구조
```
turtle_bag/
├── metadata.yaml        ← storage_identifier: mcap, topics, message_count, duration
└── turtle_bag_0.mcap    ← cdr 바이트 + 타임스탬프 + 스키마
sqlite_bag/
├── metadata.yaml        ← storage_identifier: sqlite3
└── sqlite_bag_0.db3
```

## 코드 예시
```python
# 폴더 속 파일 확장자로 storage id 짐작하기
def storage_of(files):
    for f in files:
        if f.endswith(".mcap") or f.endswith(".mcap.zstd"): return "mcap"
        if f.endswith(".db3"): return "sqlite3"
    return "?"
print(storage_of(["metadata.yaml", "turtle_bag_0.mcap"]))        # mcap
print(storage_of(["metadata.yaml", "sqlite_bag_0.db3"]))         # sqlite3
print(storage_of(["metadata.yaml", "zfile_0.mcap.zstd"]))        # mcap
split = [f"split_{i}.mcap" for i in range(4)]
print(len(split), "파일 /", storage_of(split))                    # 4 파일 / mcap
```
