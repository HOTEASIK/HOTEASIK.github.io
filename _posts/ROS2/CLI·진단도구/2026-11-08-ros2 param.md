# ros2 param

## 정의·핵심
- **정의**: 켜져 있는 노드의 파라미터를 보고 바꾸고 저장·복원하는 명령 (기초 4·5차시, 입문 5차시, 실습 1차시).
- **들여다보기**: `list`(노드 이름 아래 두 칸 들여써 찍힘) · `get /노드 이름` · `describe /노드 이름`(자료형·제약).
- **바꾸기**: `set /노드 이름 값` — 성공 `Set parameter successful`, 실패 `Setting parameter failed: …`(동사 꼴이 달라 훑어 읽기 쉽다). 도는 노드에만 적용 — 껐다 켜면 기본값.
- **저장·복원 한 바퀴**: `dump /turtlesim > turtle_params.yaml`(백업) → `set background_r 255`(일부러 바꿈, 배경이 분홍빛으로) → `load /turtlesim turtle_params.yaml`(되돌림).
- **load는 줄마다 결과를 찍는다**: 실패 줄이 섞여도 고장이 아니다 — 읽기 전용 파라미터(`start_type_description_service`, turtlesim의 qos 관련 등)는 다시 못 넣는다.
- **load는 맨 윗줄의 노드 이름을 본다**: 파일 속 노드 이름과 대상 노드가 달라도 load 명령의 대상 노드에 넣는다(맨 윗줄은 `--params-file`로 켤 때 쓰인다) — YAML로 배경색 바꾸기 실습.
- **turtlesim 배경**: set 직후 반영되지 않으면 `/clear` 서비스.

## 원리·구조
| 명령 | 언제 |
|---|---|
| `param list [/노드]` | 무엇이 있나 |
| `param get /노드 p` | 지금 값 |
| `param describe /노드 p` | 자료형·제약 |
| `param set /노드 p v` | 임시로 맞춘다 |
| `param dump /노드 > f.yaml` | 좋은 값을 찾았을 때 저장 |
| `param load /노드 f.yaml` | 도는 노드를 되돌릴 때 |
| `--ros-args --params-file f.yaml` | 처음부터 그 값으로 |

## 코드 예시
```python
# load 결과 줄 세기: 실패가 읽기 전용뿐이면 OK
out = """Set parameter background_b successful
Set parameter background_g successful
Set parameter background_r successful
Set parameter qos_overrides./parameter_events.publisher.depth failed: parameter 'qos_overrides./parameter_events.publisher.depth' cannot be set because it is read-only
Set parameter start_type_description_service failed: parameter 'start_type_description_service' cannot be set because it is read-only
Set parameter use_sim_time successful"""
ok = [l.split()[2] for l in out.splitlines() if l.endswith("successful")]
fail = [l.split()[2] for l in out.splitlines() if "failed" in l]
print(len(ok), "성공 /", len(fail), "실패")                     # 4 성공 / 2 실패
print("문제 없음" if all("read-only" in l for l in out.splitlines() if "failed" in l) else "확인 필요")   # 문제 없음
```
```bash
ros2 param list /turtlesim
ros2 param get /turtlesim background_r
ros2 param dump /turtlesim > turtle_params.yaml
ros2 param set /turtlesim background_r 255
ros2 param load /turtlesim turtle_params.yaml
```
