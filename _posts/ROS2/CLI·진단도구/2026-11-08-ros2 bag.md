# ros2 bag

## 정의·핵심
- **정의**: 토픽에 흐르는 메시지를 시간과 함께 **녹화(record)** 하고, 나중에 그대로 **재생(play)** 하는 도구. 로봇 없이도 같은 상황을 몇 번이고 다시 만든다 (입문 8차시).
- **세 동사**: `record`(녹화) · `info`(무엇이 들었나) · `play`(재생). 녹화는 Ctrl+C로 끝낸다.
- **bag은 폴더다**: `-o 이름`으로 폴더 이름을 정한다(없으면 `rosbag2_날짜_시각`). 안에 `metadata.yaml` + 데이터 파일(`.mcap` 또는 `.db3`).
- **같은 이름으로 다시 녹화하면 오류** — 폴더가 이미 있다. 지우거나 이름을 바꾼다.
- **`info`로 먼저 확인**: Files, Storage id(mcap), Duration, Messages, Topic information(토픽마다 Type·Count·Serialization Format: cdr). 아무것도 안 흐를 때 녹화하면 `Count: 0` — 빈 bag.
- **play 옵션**: `--rate 2.0`(배속) · `-l`(반복) · `--topics`(골라 재생) · `-x 정규식`(빼고 재생, play 전용) · `-d 1`(1초 기다렸다 시작 — record의 `-d`는 파일 나누기라 뜻이 다르다).
- **재생 전 teleop은 끈다** — 재생된 cmd_vel과 키보드 명령이 섞인다.
- **첫 메시지가 빠질 수 있다**: 재생 직후 구독자가 아직 발견 중이면 앞부분을 놓친다 → `-d`로 잠깐 기다리게.
- 녹화 세부는 [[bag 녹화 옵션]], 파일 형식은 [[bag 저장 형식]], 코드로 읽고 쓰기는 [[rosbag2_py]].

## 원리·구조
```
$ ros2 bag record -o turtle_bag --topics /turtle1/cmd_vel /turtle1/pose
$ ros2 bag info turtle_bag
Files:             turtle_bag_0.mcap
Storage id:        mcap
Duration:          12.4s
Messages:          820
Topic information: Topic: /turtle1/cmd_vel | Type: geometry_msgs/msg/Twist | Count: 45 | Serialization Format: cdr
                   Topic: /turtle1/pose | Type: turtlesim/msg/Pose | Count: 775 | Serialization Format: cdr
$ ros2 bag play turtle_bag --rate 2.0
```

## 코드 예시
```python
# bag info 출력에서 토픽별 Count 뽑기 → 빈 토픽 찾기
info = """Topic information: Topic: /turtle1/cmd_vel | Type: geometry_msgs/msg/Twist | Count: 45 | Serialization Format: cdr
                   Topic: /turtle1/pose | Type: turtlesim/msg/Pose | Count: 775 | Serialization Format: cdr
                   Topic: /scan | Type: sensor_msgs/msg/LaserScan | Count: 0 | Serialization Format: cdr"""
counts = {}
for line in info.splitlines():
    parts = [p.strip() for p in line.split("|")]
    topic = parts[0].split("Topic: ")[-1]
    counts[topic] = int(parts[2].split(": ")[1])
print(counts)                                   # {'/turtle1/cmd_vel': 45, '/turtle1/pose': 775, '/scan': 0}
print([t for t, c in counts.items() if c == 0]) # ['/scan']  ← 녹화 때 안 흐르던 토픽
```
```bash
ros2 bag record -o turtle_bag --topics /turtle1/cmd_vel /turtle1/pose
ros2 bag info turtle_bag
ros2 bag play turtle_bag -l --rate 0.5
ros2 bag play turtle_bag -x "/turtle1/pose" -d 1
```
