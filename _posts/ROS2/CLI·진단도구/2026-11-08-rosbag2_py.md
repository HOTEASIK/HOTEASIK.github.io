# rosbag2_py

## 정의·핵심
- **정의**: bag을 **파이썬 코드로 쓰고 읽는** 라이브러리 — 노드 없이도 bag을 만들고, 녹화본을 분석·가공한다 (입문 8차시).
- **쓰기 4단계**: `SequentialWriter()` → `open(StorageOptions(uri='code_bag', storage_id='mcap'), ConverterOptions('cdr', 'cdr'))` → `create_topic(TopicMetadata(id=0, name=…, type=…, serialization_format='cdr'))` → `write(토픽, serialize_message(msg), 시각_ns)`.
  - Jazzy의 `TopicMetadata`는 **id가 필수**.
  - `write`에 msg를 그냥 넣으면 `TypeError: write(): incompatible function arguments` — **바이트로 직렬화**해서.
  - 다시 돌리면 `RuntimeError: Bag directory already exists` — 폴더를 지우고.
  - 시각을 `i * 10**9`처럼 0부터 주면 info에 **1970년** 날짜로 찍힌다(유닉스 시각 0) — 실제 시각을 쓰려면 `node.get_clock().now().nanoseconds` 또는 `time.time_ns()`.
- **읽기**: `SequentialReader()` → `open(...)` → `while has_next(): topic, data, t = read_next()` → `deserialize_message(data, String)`.
  - **타입을 잘못 주면**: 오류 없이 엉뚱한 값(Int32로 풀면 `data=15` 같은)이 나오거나 `RMWError` — bag은 바이트만 기억한다.
  - 올바른 타입은 `get_all_topics_and_types()`로 묻고, `rosidl_runtime_py.utilities.get_message("std_msgs/msg/String")`으로 클래스를 얻는다.
- **쓰임**: 녹화본에서 특정 구간만 잘라 새 bag, 값 통계·그래프, 테스트용 가짜 데이터 생성.

## 원리·구조
```
쓰기: msg ─serialize_message→ bytes ─write(topic, bytes, t_ns)→ bag
읽기: bag ─read_next→ (topic, bytes, t_ns) ─deserialize_message(bytes, 타입)→ msg
타입 정보: reader.get_all_topics_and_types() → [TopicMetadata(name, type, ...)]
```

## 코드 예시
```python
import time
import rosbag2_py
from rclpy.serialization import serialize_message, deserialize_message
from rosidl_runtime_py.utilities import get_message
from std_msgs.msg import String

storage = rosbag2_py.StorageOptions(uri="code_bag", storage_id="mcap")
conv = rosbag2_py.ConverterOptions("cdr", "cdr")

writer = rosbag2_py.SequentialWriter()
writer.open(storage, conv)
writer.create_topic(rosbag2_py.TopicMetadata(
    id=0, name="/chatter", type="std_msgs/msg/String", serialization_format="cdr"))
for i in range(5):
    writer.write("/chatter", serialize_message(String(data=f"hello {i}")), time.time_ns())
del writer                                   # 닫기

reader = rosbag2_py.SequentialReader()
reader.open(storage, conv)
types = {m.name: m.type for m in reader.get_all_topics_and_types()}
while reader.has_next():
    topic, data, t = reader.read_next()
    msg = deserialize_message(data, get_message(types[topic]))
    print(topic, msg.data)                   # /chatter hello 0 … hello 4
```
