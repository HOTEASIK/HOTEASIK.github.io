# SROS2

## 정의·핵심
- **정의**: ROS2 통신에 **인증**(상대가 정말 그 노드인가)과 **암호화**(제3자가 못 읽게)를 더하는 도구 — 바탕은 DDS-Security 표준 (실습 4차시).
- **기본은 무방비**: 같은 네트워크의 누구나 토픽을 echo로 엿보고 가짜 노드로 명령을 흘릴 수 있다 — 모터 명령에 가짜 값, 카메라 엿보기는 제품에서 곧 사고.
- **enclave**: 노드의 **신분증(인증서)·출입증(권한) 묶음** — keystore(금고) 안에 경로 꼴(`/talker_listener/talker`)로 보관. 통신하는 **노드마다 따로** 만든다.
- **네 단계**: ① `ros2 security create_keystore ~/sros2_keystore` ② `create_enclave ~/sros2_keystore /talker_listener/talker`(노드마다) ③ 터미널마다 export 세 줄 ④ `--ros-args --enclave /talker_listener/talker`로 실행.
- **환경변수 셋**: `ROS_SECURITY_KEYSTORE`(금고 위치) · `ROS_SECURITY_ENABLE=true`(빠지면 보안 자체가 꺼짐) · `ROS_SECURITY_STRATEGY=Enforce|Permissive`. 환경변수는 그 터미널에만 산다 — 터미널마다 다시. 한 번에 점검 `env | grep ROS_SECURITY`.
- **Enforce vs Permissive**: 보안 파일을 못 찾은 노드를 Enforce는 띄우지 않고(효과가 보인다), Permissive는 띄우기는 한다 — 그래서 켜졌는지 헷갈린다(뜨지만 보안 켜진 상대와 통하지 않음).
- **켜졌다는 표시**: 첫 줄 `[rcl]: Found security directory: …/enclaves/talker_listener/talker`.
- **무엇을 빠뜨렸나 — 「크게 죽었나, 조용히 못 받나」**
  - 크게 죽음(enclave 쪽): `--enclave` 빠뜨림 → `couldn't find all security files!` · enclave 없음/경로 오타 → `SECURITY ERROR: directory '…' does not exist.` → `[ros2run]: Aborted`.
  - 조용함(export 쪽): 보안 없이 떠서 아무것도 안 찍히고 에러도 없이 못 받는다.
- **도메인 번호가 금고에 박힌다**: 금고를 만든 터미널의 `ROS_DOMAIN_ID`(없으면 0)가 governance.xml `<domains><id>`에 적힌다. 다르면 `Not found topic access rule for topic ros_discovery_info` … `could not create data writer` → 둘 다 Aborted — 메시지에 「도메인」이라는 말이 없다.
- **보안을 켜면**: 보안 없는 터미널의 `node list`엔 talker가 안 보이고 echo는 `does not appear to be published yet`. 진단 도구용 enclave도 준비해 둔다.
- **끝나면 터미널을 닫는다**: export가 남은 터미널에선 상관없는 노드(robot_state_publisher)도 enclave를 찾다 Aborted. 닫기 어려우면 `unset ROS_SECURITY_KEYSTORE ROS_SECURITY_ENABLE ROS_SECURITY_STRATEGY`.

## 원리·구조
```
~/sros2_keystore/
├── enclaves/
│   ├── governance.xml / .p7s     ← 금고 전체 규칙 (<domains><id>0</id>)
│   └── talker_listener/
│       ├── talker/   (개인키 · 인증서 · permissions)
│       └── listener/
└── (CA 자료)
```

## 코드 예시
```python
# 증상으로 빠뜨린 것 가리기
def which_side(aborted, log):
    if aborted:
        if "does not exist" in log: return "enclave 없음 또는 --enclave 경로 오타"
        if "couldn't find all security files" in log: return "--enclave 빠뜨림 (그 터미널에 export는 있음)"
        if "ros_discovery_info" in log: return "ROS_DOMAIN_ID가 금고와 다름"
        return "enclave 쪽 확인"
    return "그 터미널에서 export 세 줄 안 함 (또는 Permissive)"
print(which_side(True, "what(): failed to initialize rcl node: couldn't find all security files!"))
# --enclave 빠뜨림 (그 터미널에 export는 있음)
print(which_side(True, "[SECURITY Error] Not found topic access rule for topic ros_discovery_info"))
# ROS_DOMAIN_ID가 금고와 다름
print(which_side(False, ""))
# 그 터미널에서 export 세 줄 안 함 (또는 Permissive)
```
```bash
ros2 security create_keystore ~/sros2_keystore
ros2 security create_enclave ~/sros2_keystore /talker_listener/talker
ros2 security create_enclave ~/sros2_keystore /talker_listener/listener
export ROS_SECURITY_KEYSTORE=~/sros2_keystore
export ROS_SECURITY_ENABLE=true
export ROS_SECURITY_STRATEGY=Enforce
ros2 run demo_nodes_cpp talker --ros-args --enclave /talker_listener/talker
grep -n -A3 "<domains>" ~/sros2_keystore/enclaves/governance.xml
```
