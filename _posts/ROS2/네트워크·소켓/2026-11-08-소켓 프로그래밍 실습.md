# 소켓 프로그래밍 실습

## 정의·핵심
- **정의**: 두 파이썬 프로그램(server.py·client.py)이 소켓으로 직접 대화하게 만들며, 단계마다 늘어나는 **수작업**을 겪는 기초 2차시 메인 실습. 매 단계 끝에 "ROS는 어떻게 하는지"를 짚는다.
- **다섯 단계**
  1. **한 마디 주고받기**: 서버를 먼저(터미널 A), 클라이언트를 나중(터미널 B). → ROS는 이름만 맞추면 알아서 찾고 켜는 순서도 상관없다.
  2. **계속 주고받기**: `while True` + `if not data: break`. 이 한 줄이 없으면 상대가 나가도 서버는 빈 데이터를 무한히 받으며 헛돈다(CPU가 빈 루프, 컴퓨터가 뜨거워짐). → ROS 토픽은 publish 한 줄이고 연결 관리도 자동.
  3. **직렬화**: 숫자 23은 `str(23).encode()`, 여러 값은 `"leo,5.0,2.0"`을 콤마로 이어 보내고 `split(",")`로 복원. 순서가 하나라도 틀리면 x와 y가 뒤바뀐다. → ROS는 메시지 타입을 한 번 정의하면 포장·해체 자동.
  4. **클라이언트를 둘로**: client2.py도 `connect()`는 성공하지만 서버가 `accept()`를 한 번만 불러 응답이 없다가 `Connection reset by peer`. 둘 다 받으려면 손님마다 스레드나 `select` → 코드가 복잡해진다. 노드 N개면 연결 수 N(N−1)/2 (10개 45, 20개 190) → **배선 지옥**. → ROS는 한 토픽에 몇 개가 붙든 구독만 하면 된다.
  5. **일부러 깨뜨리기**: encode/decode를 빼면 `b'...'`가 보이거나 타입 에러, 클라이언트 포트만 9091로 바꾸면 영영 연결 안 됨 → 통신은 **양쪽이 같은 약속을 지켜야만** 성립 → 프로토콜.
- **도전 과제**: ① 메아리 채팅("확인: ..." 돌려주기) ② 파일 전송(1024바이트씩 조각내 보내고 이어 붙이기 = 패킷) ③ 양방향 채팅(`input`, 'bye' 종료 약속) ④ 실행 파일로 빌드(Ubuntu 24.04는 전역 pip 설치를 막으므로 pipx로 격리 설치).

## 원리·구조
$$\text{연결 수} = \frac{N(N-1)}{2}\qquad N=10 \Rightarrow 45,\; N=20 \Rightarrow 190$$
```
# server.py (강의 원문)                 # client.py
import socket                          import socket
s = socket.socket()                    s = socket.socket()
s.bind(('localhost', 9090))            s.connect(('localhost', 9090))
s.listen(1)                            s.send("안녕, 서버".encode())
print("기다리는 중...")                  print("답:", s.recv(1024).decode())
conn, addr = s.accept()                s.close()
print("받음:", conn.recv(1024).decode())
conn.send("안녕, 클라이언트".encode())
conn.close()
```

## 코드 예시
```python
# ② 계속 주고받기 + ③ 직렬화 + 끊김 처리(if not data: break) 를 한 번에 확인
import socket, threading
srv = socket.socket(); srv.bind(("localhost", 0)); srv.listen(1)
port = srv.getsockname()[1]

def serve():
    conn, _ = srv.accept()
    while True:
        data = conn.recv(1024).decode()
        if not data:                                   # 상대가 나감
            print("상대가 나갔어요"); break
        name, x, y = data.split(",")                   # 받는 쪽이 같은 규칙으로 복원
        conn.send(f"확인: {name} x={float(x)} y={float(y)}".encode())
    conn.close()

t = threading.Thread(target=serve); t.start()
c = socket.socket(); c.connect(("localhost", port))
for msg in ["leo,5.0,2.0", "amy,1.5,3.0"]:
    c.send(msg.encode()); print(c.recv(1024).decode())
c.close(); t.join(); srv.close()
print([n * (n - 1) // 2 for n in (2, 10, 20)])
# 확인: leo x=5.0 y=2.0
# 확인: amy x=1.5 y=3.0
# 상대가 나갔어요
# [1, 45, 190]
```
