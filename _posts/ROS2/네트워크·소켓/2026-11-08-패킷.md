# 패킷

## 정의·핵심
- **정의**: 데이터를 통째로 보내지 않고 작은 조각으로 쪼개 보낼 때 그 **조각 하나** (기초 2차시).
- **택배 비유**: 큰 짐을 여러 상자에 나눠 담고 → 상자마다 받는 주소를 붙인다 → 한 상자가 늦거나 길을 헤매도 나머지는 먼저 간다 → 도착해서 번호 순서대로 다시 합친다 → 빠진 상자만 다시 부친다.
- **왜 쪼개나**: 통째로 보내다 끊기면 처음부터 다시지만, 조각으로 나누면 **빠진 조각만** 다시 보내면 된다.
- **코드에서 만나는 곳**: 소켓 도전 과제 "파일 전송" — 파일을 1024바이트씩 조각내 보내고 이어 붙여 복원. `recv(1024)` 의 1024가 한 번에 받을 최대 바이트.
- **로봇에서**: 영상·점구름처럼 큰 메시지는 여러 패킷으로 쪼개져 간다 — WiFi에서 조각 하나만 빠져도 메시지 전체가 유실되거나(Best Effort) 재전송으로 늦어진다(Reliable). 실습 2차시 QoS의 출발점.

## 원리·구조
```
보낼 데이터 (3000 B)
 ├─ 패킷 #0 [헤더: 주소·번호] 1024 B
 ├─ 패킷 #1 [헤더: 주소·번호] 1024 B
 └─ 패킷 #2 [헤더: 주소·번호]  952 B
도착: 번호 순 정렬 → 이어 붙여 복원 / 빠진 번호만 재요청
```

## 코드 예시
```python
# 1024바이트씩 조각내기 → 순서가 섞여 도착 → 번호로 정렬해 복원
import random
data = bytes(range(256)) * 12                  # 3072 B
packets = [(i, data[o:o + 1024]) for i, o in enumerate(range(0, len(data), 1024))]
print(len(packets), [len(p) for _, p in packets])   # 3 [1024, 1024, 1024]
random.seed(0); random.shuffle(packets)        # 길을 헤매 순서가 섞임
restored = b"".join(p for _, p in sorted(packets))
print(restored == data)                         # True
```
