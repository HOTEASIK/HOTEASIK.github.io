# IP 주소와 포트

## 정의·핵심
- **IP 주소**: 수많은 컴퓨터 중 **어느 컴퓨터인지** 가리키는 주소. 우편으로 치면 건물 주소. 예 `192.168.0.5` (기초 2차시).
- **포트(port)**: 그 컴퓨터 안의 **어느 프로그램인지** 가리키는 번호. 건물의 호수. 예 `9090`.
  - 같은 컴퓨터라도 포트가 80이면 웹 서버에게, 9090이면 실습 서버에게 연결된다.
- **IP와 포트를 묶은 통신 창구가 곧 소켓**이다.
- **바로잡을 것** (기초 2차시)
  - "IP만 있으면 통신 끝" ✗ — 한 컴퓨터에 프로그램이 여럿이라 포트까지 있어야 콕 집힌다.
  - "포트는 아무거나 써도 됨" ✗ — 0~1023은 시스템 예약. 실습은 보통 8000~65000대.
- **IPv4**: 32비트, 약 43억 개뿐이라 IPv6로 넘어가는 중 (기초 1차시 예고).
- 내 주소 확인: `ip addr | grep inet` (환경 점검 6종).
- **ROS와 비교**: 소켓은 받는 쪽 IP를 손으로 적고 양쪽 포트를 똑같이 맞춰야 했다 → ROS2는 DDS가 같은 네트워크에서 상대를 **자동 발견**하므로 이름(토픽)만 맞추면 된다 (기초 3차시).

## 원리·구조
| 구분 | 무엇을 가리키나 | 우편 비유 | 예 |
|---|---|---|---|
| IP | 어느 컴퓨터 | 건물 주소 | 192.168.0.5 |
| 포트 | 그 안의 어느 프로그램 | 호수 | 9090 |
| 소켓 | IP + 포트 창구 | 건물 주소 + 호수 | ('localhost', 9090) |

$$\text{IPv4 주소 수} = 2^{32} \approx 4.3\times10^{9}$$

## 코드 예시
```python
import ipaddress
ip = ipaddress.ip_address("192.168.0.5")
print(ip.version, ip.is_private)                 # 4 True   (사설망 주소)
print(ipaddress.ip_address("127.0.0.1").is_loopback)   # True  (localhost)
print(2 ** 32)                                   # 4294967296  (약 43억)
def port_kind(p):
    return "시스템 예약" if p <= 1023 else "사용 가능"
print(port_kind(80), port_kind(9090))            # 시스템 예약 사용 가능
```
```bash
ip addr | grep inet      # 내 IP
```
