# OSI 7계층과 프로토콜

## 정의·핵심
- **프로토콜**: 양쪽이 미리 같은 방식을 약속해야만 통한다 — 그 **약속**. 전화는 "여보세요"로 시작하고, 편지는 받는 사람·보내는 사람·내용 순서로 적는다. HTTP·TCP/IP가 그런 약속이다 (기초 2차시).
- 소켓 실습에서 encode/decode·포트 하나만 어긋나도 깨진 것은 우연이 아니다 — 약속 위에서만 통신이 된다. 코드의 `SOCK_STREAM` 이 TCP라는 프로토콜이다.
- **약속은 층층이 쌓여 있다**: 통신 하나에 약속이 한 개가 아니라 전기 신호·봉투·받을 프로그램이 다 따로 약속돼 있다. 각 층은 **자기 일만** 한다 — 도로가 바뀌어도 상자 안 물건은 그대로 간다.
- **OSI 7계층**: 이름 일곱 개를 외우는 게 아니라 "층층이 쌓여 있다"는 그림 하나를 가져간다. 한 층만 어긋나도 깨진다.
- **막히면 아래에서 위로 좁힌다**: 통신이 안 될 때 가장 먼저 `ping`. 답이 오면 최소한 길은 뚫려 있다. 맨 아래부터 위로 하나씩 지우고, 처음 막히는 줄이 범인.
- ROS2 진단도 같은 방식이다 — 네트워크(ping·DOMAIN_ID) → 발견(node list) → 연결(topic info) → 내용(echo) 순 (실습 1차시 진단 사다리).

## 원리·구조
| 층 | 하는 일 | 택배 비유 | 우리 실습 |
|---|---|---|---|
| 7 응용·6 표현·5 세션 | 데이터·표현 방식·대화 유지 | 상자 안 물건·포장 | "안녕, 서버", encode/직렬화 |
| 4 전송 | 포트로 프로그램 구분, TCP/UDP | 건물 안 호실 | 포트 9090 |
| 3 네트워크 | IP로 어느 컴퓨터인지 | 건물 주소 | 127.0.0.1 |
| 2 데이터링크 | 같은 네트워크 안 전달 | 동네 배송 | 공유기 |
| 1 물리 | 전기 신호가 매체를 탐 | 트럭·도로 | 랜선·와이파이 |

| 어느 층이 막혔나 | 증상 | 의심할 것 |
|---|---|---|
| 물리·연결 | ping조차 답 없음 | 랜선·와이파이, 전원, 상대 꺼짐 |
| 주소·포트 | ping은 되는데 연결 거부 | 서버 안 켬, 포트 틀림, 방화벽 |
| 포트 점유 | 서버가 안 떠짐 | 이전 프로그램이 포트를 안 놓음 |
| 응용·표현 | 연결은 되는데 글자가 깨짐 | encode/decode 짝, 직렬화 규칙 |

## 코드 예시
```python
# 층마다 자기 봉투를 씌우고(캡슐화), 받는 쪽은 바깥부터 벗긴다
msg = "안녕, 서버"
app = msg.encode("utf-8")                       # 7~5층: 표현(encode)
seg = b"PORT:9090|" + app                       # 4층: 포트
pkt = b"IP:127.0.0.1|" + seg                    # 3층: IP
ip, rest = pkt.split(b"|", 1)
port, payload = rest.split(b"|", 1)
print(ip.decode(), port.decode(), payload.decode("utf-8"))   # IP:127.0.0.1 PORT:9090 안녕, 서버
print(payload.decode("latin-1") != msg)        # True  (표현 층 약속이 어긋나면 깨진다)
```
```bash
ping -c 3 192.168.0.5     # 맨 아래 층부터
```
