# 소켓

## 정의·핵심
- **정의**: IP와 포트를 묶은 **통신 창구**. 격리된 프로세스끼리(같은 PC든 다른 PC든) 데이터를 주고받게 해 주는 운영체제의 통로 중 하나 (기초 2차시).
- **왜 배우나**: 프로세스는 서로의 책상(메모리)을 못 본다(격리) → 대화하려면 정해진 창구가 필요하다. 소켓으로 직접 짜 보며 손이 얼마나 가는지 겪어 봐야 ROS의 고마움이 진하게 남는다.
- **전화 거는 절차와 같다**
  - 서버: `socket()` 전화기 장만 → `bind()` 내 IP·포트 개통 → `listen()` 벨이 울리게 대기 → `accept()` 수화기 들기.
  - 클라이언트: `connect()` 상대 번호로 걸기 → `send()`/`recv()` 말하고 듣기 → `close()` 수화기 내려놓기.
- **바이트만 흐른다**: 통신선으로는 글자가 아니라 바이트만 → 보낼 때 `encode`, 받을 때 `decode`. 짝이 어긋나면 글자가 깨지거나 에러.
- **블로킹**: `accept`·`recv`는 상대가 올 때까지 그 줄에서 멈춘다 — 정상.
- **끊김 대비는 내 몫**: 상대가 나가면 `recv`가 빈 값(`b''`)을 받는다 → `if not data: break`. 더 단단히는 `try … except`로 감싼다.
- `socket`은 **라이브러리**(상자 하나), ROS는 **프레임워크**(부엌 전체)다.

## 원리·구조
| 단계 | 하는 일 | 전화 비유 |
|---|---|---|
| socket() | 통신용 창구 생성 | 전화기 장만 |
| bind() | 내 IP·포트를 창구에 건다 | 번호 개통 |
| listen() | 받을 준비 | 벨이 울리게 대기 |
| accept() | 한 통을 받는다(블로킹) | 수화기 들기 |
| connect() (클라) | 상대 IP·포트로 연결 | 전화 걸기 |
| send()/recv() | 보내고 받기 | 말하고 듣기 |
| close() | 연결 닫기 | 수화기 내려놓기 |

## 코드 예시
```python
# 서버(스레드)와 클라이언트를 한 파일에서 띄워 인사 한 번 주고받기
import socket, threading
srv = socket.socket()                  # 기본값 = AF_INET + SOCK_STREAM(TCP)
srv.bind(("localhost", 0)); srv.listen(1)
port = srv.getsockname()[1]

def serve():
    conn, addr = srv.accept()          # 블로킹: 손님이 올 때까지 대기
    print("받음:", conn.recv(1024).decode())
    conn.send("안녕, 클라이언트".encode())
    conn.close()

t = threading.Thread(target=serve); t.start()
c = socket.socket(); c.connect(("localhost", port))
c.send("안녕, 서버".encode())
print("답:", c.recv(1024).decode())
c.close(); t.join(); srv.close()
# 받음: 안녕, 서버
# 답: 안녕, 클라이언트
```
