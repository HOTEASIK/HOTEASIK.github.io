# 소켓 오류 해독

## 정의·핵심
- **정의**: 소켓 실습에서 단골로 만나는 에러를 화면에 뜨는 말로 원인과 해결로 가르는 표 (기초 2차시). 초보자는 보통 **포트 충돌, 서버 순서, encode 빠뜨리기**로 한두 번은 막힌다 — 막히고 푸는 과정이 정상이다.
- **ConnectionRefusedError**: 서버를 안 켜고 클라이언트부터 켬 → 빈 식당에 손님이 먼저 간 것. 서버 먼저.
- **Address already in use**: 포트가 이미 점유됨(이전 서버가 아직 살아 있거나 막 끈 직후 TIME_WAIT). Ctrl+C로 종료 후 재실행, 또는 포트를 9091로. 서버 쪽에서 `SO_REUSEADDR` 옵션으로 막 끈 포트를 다시 쓸 수 있다.
- **b'\x...' 로 글자가 깨짐**: decode 빠뜨림 → `.decode()` 추가.
- **TypeError: ... bytes ...**: encode 빠뜨림(문자열을 그대로 send) → `.encode()` 추가.
- **Connection reset by peer**: 상대가 연결을 일방적으로 끊음 (예: 서버가 accept 한 번만 하고 끝나 둘째 클라이언트가 끊김).
- **화면이 멈춤 (정상)**: accept/recv가 상대를 기다리는 블로킹 → 다른 터미널에서 상대 실행.

## 원리·구조
| 화면에 뜨는 것 | 원인 | 해결 |
|---|---|---|
| ConnectionRefusedError | 서버 안 켜고 클라이언트부터 | 서버 먼저 실행 |
| Address already in use | 포트 점유 | 종료 후 재실행 / 포트 변경 / SO_REUSEADDR |
| `b'\x...'` 글자 깨짐 | decode 빠뜨림 | `.decode()` |
| TypeError: ... bytes ... | encode 빠뜨림 | `.encode()` |
| 화면 멈춤 | 블로킹 대기(정상) | 상대 프로그램 실행 |

## 코드 예시
```python
import socket
# ① encode 빠뜨리기 → TypeError
a, b = socket.socketpair()
try:
    a.send("안녕")
except TypeError as e:
    print("TypeError:", "bytes" in str(e))       # TypeError: True
# ② decode 빠뜨리기 → 바이트 표시가 그대로
a.send("안녕".encode()); print(b.recv(1024))    # b'\xec\x95\x88\xeb\x85\x95'
a.close(); b.close()
# ③ 같은 포트를 두 번 bind → Address already in use
s1 = socket.socket(); s1.bind(("localhost", 0)); s1.listen(1)
s2 = socket.socket()
try:
    s2.bind(("localhost", s1.getsockname()[1]))
except OSError as e:
    print("OSError (포트 점유):", e.errno in (98, 48, 10048))   # OSError (포트 점유): True
s1.close(); s2.close()
```
