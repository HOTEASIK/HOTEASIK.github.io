# 직렬화와 역직렬화

## 정의·핵심
- **직렬화(serialization)**: 숫자·여러 값·구조체를 통신선이나 파일에 실을 수 있게 **바이트 줄로 포장**하는 일. **역직렬화**는 받는 쪽에서 원래 값으로 푸는 일 (기초 2차시).
- **왜 필요한가**: 통신선으로는 바이트만 흐른다. 숫자 23을 그냥 보내면 선을 타지 못한다 → 글자로 포장(`str(23).encode()`) → 받는 쪽이 풀고(`decode`) → `int`로 되돌린다. 한 값을 보내는 데도 포장과 해체가 두 번씩.
- **받는 쪽은 보내는 쪽이 포장한 규칙대로** 되돌려야 원래 값이 된다.
  - 여러 값: `"leo,5.0,2.0"` 콤마로 이어 붙임 → `split(",")`로 복원.
  - 순서가 하나라도 틀리면 x와 y가 뒤바뀌어 로봇이 엉뚱한 방향으로 간다 — 콤마 하나가 사고로.
- **ROS에서는**: 메시지 타입(.msg)을 한 번 정의해 두면 포장·해체를 자동 처리한다(DDS의 CDR 직렬화). 그래서 `msg.data = 23` 처럼 값만 넣으면 된다.
- **비용**: 프로세스 사이 통신은 매번 직렬화·복사가 든다 → 큰 영상·점구름에서는 부담 → 같은 프로세스 안에서 포인터로 넘기는 **Intra-Process 통신**의 동기 (실습 2차시).
- **rosbag**도 메시지를 직렬화된 바이트로 저장하고, 읽을 때 `deserialize_message`로 푼다 (입문 8차시).

## 원리·구조
```
보내는 쪽:  (name, x, y) ─join(",")→ "leo,5.0,2.0" ─encode→ b'leo,5.0,2.0'  ──선──→
받는 쪽:   b'leo,5.0,2.0' ─decode→ "leo,5.0,2.0" ─split(",")→ float 변환 → (name, x, y)
```
| 방식 | 예 | 특징 |
|---|---|---|
| 구분자 문자열 | `"leo,5.0,2.0"` | 쉽지만 순서·구분자 약속을 손으로 맞춤 |
| JSON | `{"x":5.0}` | 키로 찾아 순서 실수에 강함 |
| 바이너리(struct) | `struct.pack('<ff',…)` | 작고 빠름, 형식 약속 필수 |
| ROS 메시지 | `.msg` → CDR | 타입 정의로 자동 |

## 코드 예시
```python
import json, struct
# ① 문자열 + 구분자
wire = ",".join(["leo", "5.0", "2.0"]).encode()
name, x, y = wire.decode().split(",")
print(name, float(x), float(y))                     # leo 5.0 2.0
# 순서 약속이 어긋나면 x·y가 뒤바뀐다
y2, x2 = map(float, wire.decode().split(",")[1:])
print(x2, y2)                                       # 2.0 5.0
# ② JSON: 키로 복원
print(json.loads(json.dumps({"name": "leo", "x": 5.0, "y": 2.0}))["y"])   # 2.0
# ③ 바이너리: float 두 개 = 8바이트
b = struct.pack("<ff", 5.0, 2.0)
print(len(b), struct.unpack("<ff", b))              # 8 (5.0, 2.0)
```
