# launch 파일

## 정의·핵심
- **정의**: 여러 노드를 **한 명령으로 함께 띄우는 대본**. 노드는 부품, launch 파일은 대본. 보통 패키지의 `launch/` 폴더에 `*.launch.py` (입문 4차시).
- **필요한 까닭 셋**: 터미널을 노드 수만큼 열지 않는다 / 이름·파라미터·리맵을 한곳에 적어 재현한다 / 한 번에 끈다(Ctrl+C).
- **뼈대 두 부분**: 진입 함수 `generate_launch_description()`(정확히 이 이름 — launch 도구가 찾는다) + 그 함수가 돌려주는 `LaunchDescription([...])`. `Node(package=, executable=)` 하나가 「이 노드를 켜라」 한 줄 — executable은 entry_points의 실행 이름(=`ros2 run` 뒤에 적던 이름).
- **왜 파이썬**: 조건·반복·경로 계산이 자유롭다 — XML·YAML launch도 있지만 파이썬이 사실상 표준.
- **`name=`**: 같은 실행 파일을 둘 띄울 때의 이름표 — 안 주면 이름이 겹쳐 한쪽이 가려진다.
- **설치해야 찾는다**: `ros2 launch`는 소스가 아니라 `install/…/share/패키지/`에서 찾는다 → setup.py data_files에 `('share/' + package_name + '/launch', ['launch/bringup.launch.py'])` 추가. 안 하면 빌드는 성공하고 실행에서 `file 'bringup.launch.py' was not found in the share directory of package 'my_py_pkg'`. 여럿이면 `glob('launch/*.launch.py')`.
- **콤마 함정**: 새 줄을 더할 때 **앞 줄 끝 콤마**를 빠뜨리면 `TypeError: 'tuple' object is not callable`로 빌드가 멈춘다.
- **로그**: 세 노드의 로그가 한 터미널에 `[my_publisher-1]` 꼬리표와 함께 섞여 흐른다. `ros2 node list`로 세 이름 확인.
- **대본 모으기**: `IncludeLaunchDescription`으로 작은 대본을 큰 대본에 — `*_bringup` 패키지.

## 원리·구조
```
ros2 launch my_py_pkg bringup.launch.py
  → install/my_py_pkg/share/my_py_pkg/launch/bringup.launch.py
  → generate_launch_description() → [Node, Node, Node] → 프로세스 셋
```

## 코드 예시
```python
# launch/bringup.launch.py
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(package='my_py_pkg', executable='my_publisher', name='pub_a'),
        Node(package='my_py_pkg', executable='my_publisher', name='pub_b'),
        Node(package='my_py_pkg', executable='my_subscriber', output='screen'),
    ])
```
```python
# setup.py 일부 — launch 파일 설치
import os
from glob import glob
package_name = 'my_py_pkg'
data_files = [
    ('share/ament_index/resource_index/packages', ['resource/' + package_name]),
    ('share/' + package_name, ['package.xml']),
    (os.path.join('share', package_name, 'launch'), glob('launch/*.launch.py')),
]
print(data_files[2][0])     # share/my_py_pkg/launch   (Windows에서는 share\my_py_pkg\launch)
```
```bash
ros2 launch my_py_pkg bringup.launch.py
ros2 node list      # /pub_a  /pub_b  /my_subscriber
```

## 수업 메모

### 정의
여러 개의 로봇 노드, 파라미터, 실행 설정 등을 파이썬 코드로 정의하여 한 번에 실행하고 관리하기 위한 스크립트 파일

### 특징
- `generate_launch_description()` 함수가 필수입니다.
	런치 파일이 실행될 때 `ros2 launch` 명령어에 의해 호출되는 핵심 진입점 함수로, `LaunchDescription` 객체를 반환

- 대본 파일을 `setup.py`의 `data_files`에 등록해야 합니다. 빠뜨리면 빌드는 성공하지만 launch할 때 `not found`가 납니다.

- `glob('launch/*.launch.py')`로 쓰면 폴더 안의 대본이 자동으로 모두 설치됩니다.

- 대본에 넣을 노드 기준: 사람 손 없이 계속 도는 노드인가? (대화형 노드는 뺌)

- **`LaunchDescription`**: 실행할 노드나 프로세스들의 작업 목록을 담는 컨테이너 역할을 합니다
### 코드 
파이썬 패키지안에 launch 폴더 만들어서 작업
#### 라이브러리 임포트
``` python
from launch import LaunchDescription # 런치 파일의 가장 바탕이 되는 뼈대(구조)를 만드는 클래스
from launch_ros.actions import Node # ROS 2의 Node(개별 OS 프로세스)를 실행하기 위한 액션 클래스
```

#### 여러 노드를 열기 
```python

def generate_launch_description():
    return LaunchDescription([
        Node(package='my_py_pkg', executable='my_publisher'),
        Node(package='my_py_pkg', executable='my_subscriber'),
    ])
```
#### 같은 노드 여러 개 열기 
```python
def generate_launch_description():
	return LaunchDescription([
	    Node(package='my_py_pkg', executable='my_publisher', name=f"Robot{i}") for i in range(10)
	])
	# → Robot0~Robot9 노드 10개가 모두 같은 /chatter에 발행 (N:1 토픽)
```

### 파라미터 주입
```python
Node(..., parameters=[{"threshold": 0.4}])
ComposableNodeContainer(..., arguments=['--ros-args', '--log-level', 'rcl:=debug'])

```

#### 실행
``` bash
ros2 launch <패키지 이름> <런치 파일 이름>
```
