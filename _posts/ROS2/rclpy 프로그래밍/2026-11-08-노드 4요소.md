# 노드 4요소

## 정의·핵심
- **정의**: 모든 rclpy 노드가 예외 없이 거치는 공통 뼈대 네 단계 — **초기화 → 노드 정의 → 통로 열기 → 살려두기**, 그리고 마무리 (입문 3·4차시).
- **일생 세 단계가 코드로는 넷**: 「생성·설정」이 둘로 갈라진다 — ROS 통신 토대를 올리는 일(`rclpy.init`)과 내 노드를 만들어 통로를 다는 일(`class X(Node)` + `create_*`)은 다른 동작이라서.
- **퍼블리셔든 서브스크라이버든 서비스 서버든**, ③에서 무엇을 여느냐만 다르고 ①·②·④는 글자까지 똑같다 — 한 번 익히면 다른 노드도 곧바로 읽힌다.
- **spin을 빼먹는 사고**: 로그 한 줄 없이 곧바로 끝난다 — 타이머는 설치만 됐을 뿐 한 번도 못 울렸다.
- **init과 shutdown은 한 쌍**: 전등을 켰으면 끈다. init은 DDS 하부 구조를 올리고, 종료 처리는 자원을 되돌린다.

## 원리·구조
| 요소 | 실제 코드 | 빠지면 |
|---|---|---|
| ① 초기화 | `rclpy.init()` | 노드 생성 자체가 실패 |
| ② 노드 정의 | `class X(Node)` + `super().__init__('이름')` | 통로·로그 등을 못 씀 |
| ③ 통로 열기 | `create_publisher`·`create_subscription`·`create_timer`·`create_service`·`create_client` | 통신·주기 동작 없음 |
| ④ 살려두기 | `rclpy.spin(node)` | 즉시 종료 (콜백이 한 번도 안 울림) |
| (마무리) | `node.destroy_node()` · `rclpy.try_shutdown()` | 자원 정리 안 될 수 있음 |

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException
from std_msgs.msg import String

class MyPublisher(Node):                                        # ② 노드 정의
    def __init__(self):
        super().__init__('my_publisher')                        #    ros2 node list에 뜨는 이름
        self.pub = self.create_publisher(String, 'chatter', 10) # ③ 통로
        self.create_timer(1.0, self.tick)                       # ③ 알람
        self.i = 0

    def tick(self):
        msg = String(); msg.data = f'Hello ROS: {self.i}'
        self.pub.publish(msg); self.i += 1

def main():
    rclpy.init()                                                # ① 초기화
    node = MyPublisher()
    try:
        rclpy.spin(node)                                        # ④ 살려두기
    except (KeyboardInterrupt, ExternalShutdownException):
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()

if __name__ == '__main__':
    main()
```
