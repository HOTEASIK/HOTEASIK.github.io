# 액션 클라이언트

## 정의·핵심
- **정의**: 목표를 보내고, 피드백을 받아 찍고, 결과를 받는 쪽. `ActionClient(self, CountUp, 'count_up')` (입문 5차시).
- **콜백이 셋** (택배 받는 쪽): 주문 접수 확인(`on_accept`) · 배송 중 알림(`feedback_callback`) · 도착 결과(`on_result`).
- **흐름**: `wait_for_server()` → `send_goal_async(goal, feedback_callback=...)` → future에 `add_done_callback(on_accept)` → `on_accept`에서 `goal_handle.get_result_async().add_done_callback(on_result)`.
- **콜백이 줄줄이 이어지는 까닭 — 미래값**: 멈춰 기다리면 피드백도 취소도 못 한다 → 「채워지면 불러 달라」를 사슬로 건다.
- **함정 — `wait_for_server()`는 끝없이 기다린다**: 서버 없이 띄우면 멈춘 듯 보인다(오류 아님) → 완성형은 `wait_for_server(timeout_sec=5.0)`.
- **완성형에서 늘어난 셋**: 타임아웃 · 거부 처리(`if not goal_handle.accepted`) · 취소 요청(`goal_handle.cancel_goal_async()`). 종료는 콜백 안에서 `rclpy.shutdown()` 대신 `self.done` 플래그만 세우고 main 한 곳에서.
- **배열 결과는 껍질이 있다**: `int32[]`는 파이썬에서 `array('i', [1, 2, 3])`로 온다 → `list()`로 한 겹 벗긴다.
- **액션은 합본**: 피드백 부분은 토픽(서버 publish_feedback = 퍼블리셔, feedback_callback = 서브스크라이버), 주문·결과 부분은 서비스.

## 원리·구조
```
send_goal_async ─fut─→ on_accept(fut): gh = fut.result(); if not gh.accepted: 거부
        │                               gh.get_result_async() ─fut─→ on_result(fut)
        └ feedback_callback(fb_msg)  ← 여러 번         result.sequence, status
```

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from rclpy.action import ActionClient
from my_interfaces.action import CountUp

class CountUpClient(Node):
    def __init__(self):
        super().__init__('count_up_client')
        self.cli = ActionClient(self, CountUp, 'count_up')
        self.done = False

    def send(self, target):
        if not self.cli.wait_for_server(timeout_sec=5.0):
            self.get_logger().error('서버 없음'); self.done = True; return
        fut = self.cli.send_goal_async(CountUp.Goal(target=target), feedback_callback=self.on_fb)
        fut.add_done_callback(self.on_accept)

    def on_fb(self, fb_msg):
        self.get_logger().info(f'피드백: {fb_msg.feedback.current}')

    def on_accept(self, fut):
        gh = fut.result()
        if not gh.accepted:
            self.get_logger().warning('거부됨'); self.done = True; return
        gh.get_result_async().add_done_callback(self.on_result)

    def on_result(self, fut):
        self.get_logger().info(f'결과: {list(fut.result().result.sequence)}')
        self.done = True

def main():
    rclpy.init()
    node = CountUpClient(); node.send(5)
    while rclpy.ok() and not node.done:
        rclpy.spin_once(node, timeout_sec=0.1)
    node.destroy_node(); rclpy.try_shutdown()
```
