# 서브스크라이버

## 정의·핵심
- **정의**: 토픽을 받는 쪽. `self.create_subscription(타입, '토픽', 콜백, 큐깊이)` — 메시지가 도착할 때마다 spin이 콜백을 불러 준다 (입문 3차시).
- **퍼블리셔와 다른 점 둘**: ① 타이머가 없다 — 도착이 계기다 ② 콜백이 인자 `msg`를 받는다 → `msg.data`처럼 바로 꺼낸다.
- **같아야 이어지는 셋**: 토픽 이름(한 글자까지), 메시지 타입, (QoS 호환). 하나라도 어긋나면 에러 없이 안 받는다.
- **연결 형태**: 1:N(구독자 여럿), N:1(발행자 여럿), N:N 모두 자연스럽다.
- **늦게 켜도 된다**: 발행자가 이미 0번부터 보냈어도, 구독자는 켠 뒤의 것부터 받는다 — 0번이 없다고 실패가 아니다. 볼 것은 짝(발행 번호와 수신 번호가 맞는가).
- **변수에 담아 둔다**: `self.sub = self.create_subscription(...)` — 반환값을 버리면 가비지 컬렉션으로 사라질 수 있어 관례상 붙잡아 둔다.
- **커스텀 타입은 칸 이름으로 꺼낸다**: `msg.turtle_name`, `msg.x` — 콤마로 자를 필요가 없다.

## 원리·구조
```
/chatter ──도착──→ (대기열 depth 10) ──spin이 꺼냄──→ on_msg(msg)
                                                      └ self.get_logger().info(msg.data)
```

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MySubscriber(Node):
    def __init__(self):
        super().__init__('my_subscriber')
        self.sub = self.create_subscription(String, 'chatter', self.on_msg, 10)

    def on_msg(self, msg):
        self.get_logger().info(f'수신: "{msg.data}"')

def main():
    rclpy.init()
    node = MySubscriber()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()
```
```bash
ros2 run my_py_pkg my_subscriber
ros2 topic info /chatter      # Publisher count: 1, Subscription count: 1
```
