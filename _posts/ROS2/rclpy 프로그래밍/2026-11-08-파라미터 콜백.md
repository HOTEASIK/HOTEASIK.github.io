# 파라미터 콜백

## 정의·핵심
- **정의**: 누군가 파라미터를 바꾸려 하는 **순간을 가로채** 허용할지 거부할지 판정하는 설정 콜백. `self.add_on_set_parameters_callback(self.on_set)` (입문 5차시).
- **왜 필요한가**: 값을 한 번 읽어 무언가를 세팅해 두는 노드(예: 주기 값으로 타이머를 만들어 둠)는 값이 바뀌어도 세팅이 스스로 바뀌지 않는다 → 바뀌는 순간을 붙잡아 다시 세팅.
- **모양**: `on_set(self, params)` — 바뀌려는 파라미터 리스트를 받아 `SetParametersResult(successful=True/False, reason='...')`를 돌려준다.
- **판정만 한다**: 콜백은 값을 바꾸지 않고 받을지만 정한다. False면 이전 값 그대로 — 바꿨다 되돌리는 게 아니라 애초에 들이지 않는다. CLI에는 `Setting parameter failed: 속도는 0 이상`처럼 reason이 붙는다.
- **검증 셋**: 범위(0 이상, 상한 이하) · 형식(정해진 후보 중 하나) · 의존(두 값이 모순되지 않는가).
- **자료형이 다른 값은 콜백에 닿기도 전에 거부**된다 — 선언 때 기본값으로 자료형을 정하는 것이 첫 검증.
- **검증을 한 군데에 모으면** 곳곳에 흩어 두는 것보다 고치기 쉽다.
- (Jazzy) 바뀐 **뒤**에 반응하는 `add_post_set_parameters_callback`도 있다 — 타이머 재생성 같은 후처리용.

## 원리·구조
```
ros2 param set /param_demo speed -1.0
   → 자료형 검사(double?) → on_set([Parameter speed=-1.0])
        → successful=False, reason='속도는 0 이상' → 값 유지 1.0
```

## 코드 예시
```python
# 설정 콜백의 판정 흐름을 순수 파이썬으로
from dataclasses import dataclass
@dataclass
class Result: successful: bool; reason: str = ""
params = {"speed": 1.0, "mode": "auto"}
def on_set(changes):
    for name, v in changes:
        if name == "speed" and v < 0: return Result(False, "속도는 0 이상")
        if name == "mode" and v not in ("auto", "manual"): return Result(False, "mode 후보 아님")
    return Result(True)
def param_set(name, v):
    if type(v) is not type(params[name]): return "Setting parameter failed: 자료형 불일치"
    r = on_set([(name, v)])
    if not r.successful: return f"Setting parameter failed: {r.reason}"
    params[name] = v; return "Set parameter successful"
print(param_set("speed", -1.0), params["speed"])   # Setting parameter failed: 속도는 0 이상 1.0
print(param_set("speed", 2.5), params["speed"])    # Set parameter successful 2.5
print(param_set("speed", 3))                       # Setting parameter failed: 자료형 불일치
```
```python
from rclpy.node import Node
from rcl_interfaces.msg import SetParametersResult

class Guarded(Node):
    def __init__(self):
        super().__init__('param_demo')
        self.declare_parameter('speed', 1.0)
        self.add_on_set_parameters_callback(self.on_set)

    def on_set(self, params):
        for p in params:
            if p.name == 'speed' and p.value < 0:
                return SetParametersResult(successful=False, reason='속도는 0 이상')
        return SetParametersResult(successful=True)
```
