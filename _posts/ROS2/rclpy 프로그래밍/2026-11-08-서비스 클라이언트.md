# 서비스 클라이언트

## 정의·핵심
- **정의**: 서버에 전화를 걸어 요청을 보내고 응답을 받는 노드 — 손님. `self.create_client(타입, '이름')` (입문 3차시).
- **부품 다섯**: ① 같은 이름으로 클라이언트 생성(서버와 글자 하나 다르면 안 됨) ② `wait_for_service(timeout_sec=1.0)`로 서버가 뜰 때까지 기다림 ③ `타입.Request()`를 채움 ④ `call_async(req)` → future ⑤ `spin_until_future_complete`로 기다려 `future.result()`.
- **켜는 순서가 바뀌어도**: ②의 while 덕분에 서버가 늦게 떠도 바로 실패하지 않는다 — 「서버를 기다리는 중...」 반복 후 연결.
- **기다리는 자리는 main**: 콜백이 아니라 main에서 부른 send 안에서 기다리니 데드락이 없다.
- **답을 받으면 끝나는 노드**: spin으로 살려 두지 않는다.
- **위치 투명성**: 서버가 어느 컴퓨터·어느 노드에 있는지 몰라도 이름으로 부른다.
- **흔한 오류**: 「서버를 기다리는 중...」만 반복(서버 미실행·이름 오타) / 응답이 영영 안 옴(서버 `return res` 누락) / 콜백 안에서 호출했더니 조용히 멈춤(데드락) / `IndexError: list index out of range`(인자 `3 4` 누락).

## 원리·구조
```
add_client 3 4
  wait_for_service ─→ Request(a=3,b=4) ─→ call_async ─→ future(빈 송장)
  spin_until_future_complete ...... 서버 응답 도착 → future.result().sum = 7
```

## 코드 예시
```python
import sys
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts

class AddClient(Node):
    def __init__(self):
        super().__init__('add_client')
        self.cli = self.create_client(AddTwoInts, 'add_two_ints')
        while not self.cli.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('서버를 기다리는 중... (add_two_ints)')

    def send(self, a, b):
        req = AddTwoInts.Request()
        req.a, req.b = a, b
        future = self.cli.call_async(req)
        rclpy.spin_until_future_complete(self, future)
        return future.result()

def main():
    rclpy.init()
    node = AddClient()
    res = node.send(int(sys.argv[1]), int(sys.argv[2]))
    node.get_logger().info(f'답 도착: {res.sum}')
    node.destroy_node()
    rclpy.try_shutdown()
```
