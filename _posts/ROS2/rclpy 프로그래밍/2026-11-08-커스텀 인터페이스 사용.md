# 커스텀 인터페이스 사용

## 정의·핵심
- **정의**: 직접 만든 `my_interfaces`의 양식(TurtleGoal.msg, AddThreeInts.srv)을 노드 패키지에서 가져와 토픽·서비스에 싣는 것 (입문 3차시 실습 C).
- **두 줄이 짝**: package.xml `<depend>my_interfaces</depend>`(신고) + 코드 `from my_interfaces.msg import TurtleGoal`(가져오기). 신고가 빌드 차례를 바꾼다 — my_interfaces 먼저, my_py_pkg 나중.
- **문자열 퍼블리셔와 달라진 셋**: import 줄, 타입 이름, 칸 채우기(`msg.turtle_name`, `msg.x`…).
- **자료형은 양식대로**: `float64` 칸에 `5`를 넣으면 대입·발행에서 `AssertionError: The 'x' field must be of type 'float'` → `5.0`. 칸 이름을 틀리면 대입에서 `AttributeError`.
- **받는 쪽은 칸 이름으로 꺼낸다**: 콤마로 자를 필요가 없다. `echo`에 네 칸이 양식 그대로 찍힌다.
- **서비스는 `Request()`**: `AddThreeInts.Request()` 후 `req.a, req.b, req.c`, 서버는 `res.sum = req.a + req.b + req.c`.
- **양식을 잊었을 때**: `ros2 interface show my_interfaces/msg/TurtleGoal` — 주석까지 나온다.
- **양식 칸을 늘렸는데 한쪽만 빌드**: 두 노드가 서로 다른 모양을 기대 → 기댄 패키지를 모두 재빌드.
- **신고를 지워도 내 자리에서는 빌드가 될 수 있다** — 「내 자리에서」와 「어디서든」은 다르다.

## 원리·구조
| 증상 | 원인 → 해결 |
|---|---|
| `ModuleNotFoundError: No module named 'my_interfaces'` | 양식 미빌드·source 안 함 |
| `AssertionError ... must be of type 'float'` | `5` → `5.0` |
| `AttributeError: 'TurtleGoal' object has no attribute 'name'` | 칸 이름 오타 → interface show |
| 토픽은 보이는데 안 받음 | 토픽 이름·타입 경로 불일치 |

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from my_interfaces.msg import TurtleGoal
from my_interfaces.srv import AddThreeInts

class GoalPublisher(Node):
    def __init__(self):
        super().__init__('goal_publisher')
        self.pub = self.create_publisher(TurtleGoal, 'turtle_goal', 10)
        self.create_timer(1.0, self.tick)

    def tick(self):
        msg = TurtleGoal()
        msg.turtle_name = 'leo'
        msg.x, msg.y, msg.speed = 5.0, 2.0, 1.5     # 5 가 아니라 5.0
        self.pub.publish(msg)

class AddThreeServer(Node):
    def __init__(self):
        super().__init__('add_three_server')
        self.create_service(AddThreeInts, 'add_three_ints', self.on_request)

    def on_request(self, req, res):
        res.sum = req.a + req.b + req.c
        return res
```
