# 서비스 서버

## 정의·핵심
- **정의**: 요청이 오면 받아 처리하고 응답을 돌려주는 노드 — 콜센터 직원. `self.create_service(타입, '이름', 콜백)` (입문 3차시).
- **부품 넷**: 타입 가져오기(`from example_interfaces.srv import AddTwoInts`) · 회선 개설(`create_service`) · 요청 처리 콜백 · 살려두기(spin).
- **콜백의 두 인자**: `req` — 클라이언트가 보낸 값으로 이미 채워져 들어온다(읽기만). `res` — ROS가 빈 채로 건넨다 → 칸을 채워 **반드시 `return res`**.
- **return 누락**: 서버는 요청 로그까지 찍고 `send_response`에서 TypeError로 죽는다(`[ros2run]: Process exited with failure 1`). 클라이언트 터미널은 아무 일 없이 기다리기만 한다 → **양쪽 터미널을 다 본다**.
- **콜백 이름**: `handle`처럼 Node가 쓰는 이름 금지 — `on_request`.
- **띄우면 멈춘 듯 서 있는 게 정상**: 「전화 대기 중...」 한 줄 뒤 조용 — 문 열고 손님을 기다리는 점원.
- **검증은 CLI 먼저**: 클라이언트를 짜기 전에 `ros2 service call`로 서버만 시험 — 문제를 반으로 가르기.
- **의존 신고**: package.xml `<depend>example_interfaces</depend>` (설치와 신고는 다른 문제).

## 원리·구조
```
 클라이언트 ── req{a:3, b:4} ──→ [add_server: on_request(req, res)]
            ←── res{sum:7} ──────   res.sum = req.a + req.b; return res
```

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from example_interfaces.srv import AddTwoInts

class AddServer(Node):
    def __init__(self):
        super().__init__('add_server')
        self.srv = self.create_service(AddTwoInts, 'add_two_ints', self.on_request)
        self.get_logger().info('전화 대기 중... (add_two_ints)')

    def on_request(self, req, res):
        res.sum = req.a + req.b
        self.get_logger().info(f'요청: {req.a} + {req.b} = {res.sum}')
        return res          # ★ 빼먹으면 응답을 못 보내고 죽는다
```
```bash
ros2 run my_py_pkg add_server
ros2 service call /add_two_ints example_interfaces/srv/AddTwoInts "{a: 3, b: 4}"
# example_interfaces.srv.AddTwoInts_Response(sum=7)
```
