# 실행기

## 정의·핵심
- **정의**: Executor. 준비된 콜백을 골라 **어느 일손(스레드)에게 실행시킬지 정하는 쪽** — 은행으로 치면 창구 수와 누구를 들여보낼지 정하는 지점장 (입문 4차시).
- **SingleThreadedExecutor**: 창구 하나. `rclpy.spin`이 안에서 쓰는 기본값. 단순·예측 가능·경쟁 상태 없음 — 대신 느린 콜백 하나가 전체를 막는다.
- **MultiThreadedExecutor**: 창구 여럿(`num_threads`로 지정, 기본은 환경에 맞춰). 콜백그룹이 허락할 때만 동시에 돈다 — 대신 공유 자원 동시 접근을 직접 관리해야 한다.
- **실행기만 바꿔서는 안 풀린다**: 그룹을 안 준 콜백은 전부 노드의 **기본 그룹(배타적)** 에 들어가 여전히 한 번에 하나.
- **노드 여럿**: `ex.add_node(a); ex.add_node(b)` — 한 프로세스 안 여러 노드를 같은 일손 묶음으로.
- **원칙**: 기본값으로 옳게 만들고, 막힘이 실제로 문제가 될 때만 창구를 늘린다.
- **현장**: 이족보행 균형 제어(0.5초)와 영상 처리(2초)가 한 노드 한 창구면, 영상 처리 2초 동안 제어가 한 번도 못 돈다 → 로봇이 기운다.

## 원리·구조
| USE_MULTI | SPLIT_GROUP | 결과 | 왜 |
|---|---|---|---|
| False | False | 막힌다 | 창구가 하나 |
| True | False | 여전히 막힌다 | 둘 다 같은 기본 그룹 |
| False | True | 여전히 막힌다 | 나눠 줄 창구가 하나 |
| True | True | **풀린다** | 창구도 여럿, 그룹도 갈림 |

## 코드 예시
```python
import time
import rclpy
from rclpy.node import Node
from rclpy.executors import MultiThreadedExecutor
from rclpy.callback_groups import MutuallyExclusiveCallbackGroup

USE_MULTI, SPLIT_GROUP = True, True

class ExecutorDemo(Node):
    def __init__(self):
        super().__init__('executor_demo')
        self.n = 0
        slow_group = MutuallyExclusiveCallbackGroup() if SPLIT_GROUP else None
        self.create_timer(0.5, self.fast_cb)
        self.create_timer(2.0, self.slow_cb, callback_group=slow_group)

    def fast_cb(self):
        self.n += 1; self.get_logger().info(f'fast tick {self.n}')

    def slow_cb(self):
        self.get_logger().info('slow 시작'); time.sleep(2); self.get_logger().info('slow 끝')

def main():
    rclpy.init()
    node = ExecutorDemo()
    try:
        if USE_MULTI:
            ex = MultiThreadedExecutor(); ex.add_node(node); ex.spin()
        else:
            rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node(); rclpy.try_shutdown()
```
