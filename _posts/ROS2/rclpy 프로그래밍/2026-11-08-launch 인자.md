# launch 인자

## 정의·핵심
- **정의**: 실행할 때 값을 받아 쓰는 launch 파일의 입력. 파일을 두 벌 만드는 대신 `ros2 launch 패키지 파일 이름:=값`으로 바꾼다 (입문 4차시 심화).
- **가져오는 넷**: `LaunchDescription`, `DeclareLaunchArgument`(인자 선언과 기본값), `LaunchConfiguration`(받은 값을 담을 자리), `Node`.
- **흐름**: `ns = LaunchConfiguration('robot')` → `DeclareLaunchArgument('robot', default_value='r1')` → `Node(..., namespace=ns)`. 값을 안 주면 기본값 r1, `robot:=r2`면 r2.
- **LaunchConfiguration은 지연 평가**: 파이썬 문자열이 아니라 실행 시점에 채워지는 자리표시 — `ns + '/x'` 같은 문자열 연산 대신 `PathJoinSubstitution`, `PythonExpression` 등을 쓴다.
- **확인**: `ros2 launch … --show-args`로 받을 수 있는 인자와 기본값 목록.
- **자주 쓰는 인자**: `use_sim_time`(Gazebo와 함께), `robot`/`namespace`, `params_file`, `map`(Nav2), `model`(TurtleBot3 기종).
- 두 번째로 켜기 전에 첫 launch를 Ctrl+C로 끈다.

## 원리·구조
```
ros2 launch my_py_pkg bringup_arg.launch.py robot:=r2
   DeclareLaunchArgument('robot', default_value='r1')
   LaunchConfiguration('robot')  ── 실행 시 'r2'로 채워짐 ──→ Node(namespace='r2')
   결과: /r2/my_publisher, /r2/chatter
```

## 코드 예시
```python
# launch/bringup_arg.launch.py
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node

def generate_launch_description():
    ns = LaunchConfiguration('robot')
    use_sim = LaunchConfiguration('use_sim_time')
    return LaunchDescription([
        DeclareLaunchArgument('robot', default_value='r1', description='로봇 네임스페이스'),
        DeclareLaunchArgument('use_sim_time', default_value='false'),
        Node(package='my_py_pkg', executable='my_publisher',
             namespace=ns, parameters=[{'use_sim_time': use_sim}]),
    ])
```
```python
# 인자 해석 흉내: 선언된 기본값 + 명령줄 이름:=값
declared = {"robot": "r1", "use_sim_time": "false"}
def resolve(argv):
    given = dict(a.split(":=", 1) for a in argv if ":=" in a)
    unknown = set(given) - set(declared)
    if unknown: return f"알 수 없는 인자: {sorted(unknown)}"
    return {**declared, **given}
print(resolve([]))                     # {'robot': 'r1', 'use_sim_time': 'false'}
print(resolve(["robot:=r2"]))          # {'robot': 'r2', 'use_sim_time': 'false'}
print(resolve(["robto:=r2"]))          # 알 수 없는 인자: ['robto']
```

```bash
ros2 launch my_py_pkg bringup_arg.launch.py --show-args

```
