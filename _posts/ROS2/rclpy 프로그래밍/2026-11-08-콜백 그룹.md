# 콜백 그룹

## 정의·핵심
- **정의**: 「이 콜백들을 동시에 돌려도 되는가」를 실행기에 알려 주는 **표식(허락)**. `callback_group=` 인자로 타이머·구독·서비스·클라이언트·액션에 붙인다 (입문 4·5차시).
- **기본 그룹**: 그룹을 안 준 콜백은 전부 노드의 기본 그룹 하나 — **배타적**이다. 그래서 MultiThreadedExecutor로 바꿔도 막힘이 그대로인 일이 흔하다.
- **두 종류**

| | MutuallyExclusive (배타적) | Reentrant (재진입) |
|---|---|---|
| 같은 그룹 안 | 한 번에 하나 | 여럿이 동시에 (같은 콜백끼리도) |
| 다른 그룹끼리 | 동시에 돌 수 있다 | 동시에 돌 수 있다 |
| 기본값 | 예 | 명시해야 |
| 맞는 자리 | 같은 변수·파일·하드웨어를 건드리는 콜백끼리 | 서로 완전히 독립적인 작업 |
| 조심 | 서로를 동기 호출하면 데드락 | 공유 변수 → 경쟁 상태 |

- **배타는 같은 그룹 안에서만 걸린다**: 느린 콜백 하나를 **새 배타적 그룹**으로 빼면 기본 그룹 콜백과 동시에 돈다 — 입문의 기본 처방(+ MultiThreadedExecutor).
- **재진입을 기본 처방으로 삼지 않는 까닭**: 주기 2초에 2초 걸리는 콜백이면 앞 실행이 끝나기 전에 다음이 시작 — 같은 함수가 겹겹이 쌓인다. 필요한 만큼만 연다.
- **그룹을 고르는 세 물음**: 같은 자원을 건드리나? (→ 같은 배타 그룹) / 오래 걸리나? (→ 따로 뺀다) / 자기 자신과 겹쳐도 되나? (→ 그때만 재진입).
- **액션 서버 완성형**: 취소 콜백이 실행 중에 들어와야 하므로 `ReentrantCallbackGroup` + `MultiThreadedExecutor`.

## 원리·구조
```
기본 그룹(배타) : [fast_cb][control_cb]   ← 둘은 서로 한 번에 하나
heavy_group(배타): [image_cb]               ← 다른 그룹이라 위와 동시에 돈다
                       (MultiThreadedExecutor의 다른 창구에서)
```

## 코드 예시
```python
from rclpy.node import Node
from rclpy.callback_groups import MutuallyExclusiveCallbackGroup, ReentrantCallbackGroup
from sensor_msgs.msg import Image

class Fusion(Node):
    def __init__(self):
        super().__init__('fusion')
        heavy_group = MutuallyExclusiveCallbackGroup()
        self.create_subscription(Image, '/camera', self.image_cb, 10,
                                 callback_group=heavy_group)   # 무거운 영상 처리만 따로
        self.create_timer(0.5, self.control_cb)                # 기본 그룹에 남김
        self.free = ReentrantCallbackGroup()                   # 정말 독립적인 일에만

    def image_cb(self, msg): pass
    def control_cb(self): pass
```
