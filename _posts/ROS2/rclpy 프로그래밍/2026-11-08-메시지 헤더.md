# 메시지 헤더

## 정의·핵심
- **정의**: `std_msgs/Header` — 메시지에 붙는 메타 정보. 픽셀·거리값 같은 내용과 별개로 **언제(stamp)** 와 **어느 좌표계(frame_id)** 를 담는다 (실습 6차시).
  - `header.stamp`: 이 데이터가 언제 찍혔나 (`builtin_interfaces/Time` — sec, nanosec).
  - `header.frame_id`: 어느 좌표계(어느 카메라·센서)에서 왔나 — 예 `'camera'`, `'base_scan'`, `'map'`.
- **붙는 메시지**: Image, LaserScan, PointCloud2, Imu, Odometry, `*Stamped`(PoseStamped, TwistStamped, TransformStamped)…
- **채우는 법**: 발행할 때 `msg.header.stamp = self.get_clock().now().to_msg()`, `msg.header.frame_id = 'camera'`. 시뮬레이션이면 `use_sim_time`에 따라 시계가 `/clock`을 따른다.
- **가공 노드는 옮긴다**: 받은 영상을 처리해 다시 낼 때 `out.header = msg.header` — 받은 프레임의 시각·좌표계를 결과에 그대로. 안 옮기면 결과 헤더가 `stamp sec: 0 nanosec: 0`, `frame_id ''`로 비어 나간다.
- **지금 비어 있어도 화면 표시·차선 검출은 된다** — 그러나 여러 센서를 시각으로 맞추거나(동기화) 영상 속 위치를 로봇 좌표로 바꿀 때(TF) 반드시 필요 → 습관처럼 채운다. RViz는 frame_id가 TF에 없으면 표시하지 못한다.

## 원리·구조
```
std_msgs/Header
  builtin_interfaces/Time stamp   { int32 sec, uint32 nanosec }
  string frame_id
sensor_msgs/Image = header + height, width, encoding, step, data[]
```

## 코드 예시
```python
# stamp(sec, nanosec) ↔ 초, 두 센서 메시지 시각 맞추기
import time
def now_stamp(t=None):
    t = time.time() if t is None else t
    sec = int(t); return {"sec": sec, "nanosec": int(round((t - sec) * 1e9))}
def to_sec(s): return s["sec"] + s["nanosec"] * 1e-9
cam = {"header": {"stamp": now_stamp(100.250), "frame_id": "camera"}}
lidar = {"header": {"stamp": now_stamp(100.262), "frame_id": "base_scan"}}
dt = abs(to_sec(cam["header"]["stamp"]) - to_sec(lidar["header"]["stamp"]))
print(cam["header"]["stamp"], f"차이 {dt*1000:.0f} ms", "동기화 OK" if dt < 0.05 else "버림")
# {'sec': 100, 'nanosec': 250000000} 차이 12 ms 동기화 OK

out = {"header": dict(cam["header"])}          # out.header = msg.header
print(out["header"]["frame_id"])               # camera
empty = {"stamp": {"sec": 0, "nanosec": 0}, "frame_id": ""}
print(empty)                                   # 옮기지 않으면 이렇게 비어 나간다
```
```python
from rclpy.node import Node
from sensor_msgs.msg import Image

def stamp_image(node: Node, msg: Image, frame='camera'):
    msg.header.stamp = node.get_clock().now().to_msg()
    msg.header.frame_id = frame
    return msg
```
