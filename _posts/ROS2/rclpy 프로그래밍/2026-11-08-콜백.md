# 콜백

## 정의·핵심
- **정의**: 특정 사건이 일어나면 대신 불러 달라고 ROS에 **미리 맡겨 두는 함수**. 식당의 진동벨 — 음식이 나오면 울린다. 내가 직접 부르지 않고 spin(실행기)이 불러 준다 (입문 1·3·4차시).
- **왜 while이 아닌가**: `while`로 메시지 도착을 계속 살피면 그것만 하느라 다른 일을 못 하고 자원을 버린다(바쁜 대기). 콜백은 쉬다가 사건이 생길 때만 깨어나, 센서 수십 개도 깔끔하게 다룬다.
- **프레임워크라서 생기는 모양**: 라이브러리는 내가 부르고, 프레임워크는 나를 부른다(제어의 역전).
- **종류**: 타이머 콜백, 구독 콜백(msg), 서비스 콜백(req, res), 액션 콜백(goal_handle), 파라미터 설정 콜백(params), future 완료 콜백.
- **한 번에 하나씩 차례로** (기본 실행기): 콜백 하나를 끝까지 실행한 뒤 다음 일감 → 서로 가로채지 않으니 콜백 안에서 변수를 건드려도 충돌 걱정이 없다. 대신 **하나가 길면 다 밀린다** → 콜백은 짧고 빠르게.
- **콜백을 길게 만드는 넷**: `time.sleep`, 무거운 연산(영상 한 장 통째·큰 점군), 응답을 기다리는 동기 호출, 파일·네트워크 입출력.
- **콜백 안에서 기다리지 않는다**: 콜백 안에서 `spin_until_future_complete`·동기 `call` → 데드락 위험.

## 원리·구조
```
spin 루프:  수집(준비된 일감?) → 선택(하나 꺼냄) → 실행(콜백 끝까지) → 반복
            └ 실행에 오래 머물면 수집으로 못 돌아가 다른 콜백 차례가 안 생긴다
```

## 코드 예시
```python
# 콜백 등록 → 이벤트 루프가 불러 준다 (spin의 축소판)
import heapq
class MiniSpin:
    def __init__(self): self.q, self.seq = [], 0
    def post(self, t, cb, *args):
        heapq.heappush(self.q, (t, self.seq, cb, args)); self.seq += 1
    def spin(self):
        while self.q:
            t, _, cb, args = heapq.heappop(self.q)
            cb(t, *args)                     # 내가 아니라 루프가 부른다

loop = MiniSpin()
def on_scan(t, ranges): print(f"{t:.1f}s 구독 콜백 min={min(ranges)}")
def on_timer(t): print(f"{t:.1f}s 타이머 콜백")
loop.post(0.5, on_timer); loop.post(0.3, on_scan, [1.2, 0.4]); loop.post(1.0, on_timer)
loop.spin()
# 0.3s 구독 콜백 min=0.4 / 0.5s 타이머 콜백 / 1.0s 타이머 콜백
```
