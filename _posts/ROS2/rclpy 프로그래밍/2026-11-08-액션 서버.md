# 액션 서버

## 정의·핵심
- **정의**: 목표를 받아 오래 걸리는 일을 하며 피드백을 보내고 결과로 마무리하는 쪽. `ActionServer(self, CountUp, 'count_up', self.execute)` (입문 5차시).
- **인자 넷**: `self` · 양식 `CountUp` · 이름표 `'count_up'`(액션의 주소 — 클라이언트와 같아야) · 실행 함수.
- **goal_handle — 접수증 한 장**: 요청 `goal_handle.request.target` / 진행 알림 `publish_feedback(fb)` / 종결 도장 `succeed()`·`canceled()`·`abort()` / 취소 요청 여부 `is_cancel_requested`.
- **실행 함수는 Result를 반환**: 도장을 찍고 `return result`.
- **종결 도장 셋**: 끝까지 수행 → `succeed()`(SUCCEEDED) / 취소를 받아 멈춤 → `canceled()`(CANCELED) / 장애로 포기 → `abort()`(ABORTED). 어떤 경로든 하나를 찍지 않으면 클라이언트가 결과를 영영 못 받는다.
- **기본형의 빈틈** (일부러 막혀 보기): ㉠ 두 번째 목표는 앞 목표가 끝날 때까지 밀린다 ㉡ 클라이언트에서 Ctrl+C(취소)를 눌러도 서버는 끝까지 센다 — 취소 콜백이 없고 일손이 하나라 `execute`가 창구를 붙들고 있다.
- **완성형**: `goal_callback`(ACCEPT/REJECT) · `cancel_callback`(ACCEPT/REJECT) · `ReentrantCallbackGroup` · `MultiThreadedExecutor` · 루프마다 `is_cancel_requested` 확인.
- **서비스 서버와 비교**: 판단 지점이 하나(응답) → 셋(받을지, 처리하며 알리기, 취소 받을지).

## 원리·구조
```
goal ─→ goal_callback(ACCEPT?) ─→ execute(goal_handle)
                                    for i in 1..target:
                                      if is_cancel_requested: canceled(); return
                                      publish_feedback(current=i); sleep(1)
                                    succeed(); return Result(sequence)
cancel ─→ cancel_callback(ACCEPT?) ─→ is_cancel_requested = True
```

## 코드 예시
```python
import time
import rclpy
from rclpy.node import Node
from rclpy.action import ActionServer, GoalResponse, CancelResponse
from rclpy.callback_groups import ReentrantCallbackGroup
from rclpy.executors import MultiThreadedExecutor
from my_interfaces.action import CountUp

class CountUpServer(Node):
    def __init__(self):
        super().__init__('count_up_server')
        self.server = ActionServer(
            self, CountUp, 'count_up', self.execute,
            goal_callback=lambda goal: GoalResponse.ACCEPT if goal.target > 0 else GoalResponse.REJECT,
            cancel_callback=lambda gh: CancelResponse.ACCEPT,
            callback_group=ReentrantCallbackGroup())

    def execute(self, goal_handle):
        fb, seq = CountUp.Feedback(), []
        for i in range(1, goal_handle.request.target + 1):
            if goal_handle.is_cancel_requested:
                goal_handle.canceled()
                return CountUp.Result(sequence=seq)
            seq.append(i); fb.current = i
            goal_handle.publish_feedback(fb)
            self.get_logger().info(f'세는 중... {i}')
            time.sleep(1)
        goal_handle.succeed()
        return CountUp.Result(sequence=seq)

def main():
    rclpy.init()
    node = CountUpServer()
    ex = MultiThreadedExecutor(); ex.add_node(node)
    try:
        ex.spin()
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node(); rclpy.try_shutdown()
```
```bash
ros2 action send_goal /count_up my_interfaces/action/CountUp "{target: 5}" --feedback
# Goal accepted with ID: ... / Feedback: current: 1 ... / Goal finished with status: SUCCEEDED
```
