# 타이머

## 정의·핵심
- **정의**: 콜백을 **정해진 주기로** 불러 주는 알람. `self.create_timer(주기_초, 콜백)` — 첫 호출은 한 주기가 지난 뒤 (입문 3·4차시).
- **콜백을 부르는 두 계기**: 타이머 콜백(주기가 될 때, 인자 없음) / 구독 콜백(메시지가 도착할 때, 인자 msg).
- **주기와 Hz는 역수**: `create_timer(0.1, …)` = 10Hz. 1Hz는 눈으로 따라가기 좋고, 카메라는 30Hz 안팎, 제어 명령은 수십~수백 Hz.

$$f\,[\text{Hz}] = \frac{1}{T\,[\text{s}]}$$

- **놓친 차례는 사라진다**: 다른 콜백이 창구를 붙잡아 타이머 차례가 지나가면, 풀려난 뒤 몰아서 처리하지 않고 **다음 차례부터** 다시 돈다 (입문 4차시 executor_demo — fast tick 번호가 하나씩만 오른다).
- **바뀐 주기 반영**: 타이머는 만들 때 주기가 정해진다 — 파라미터로 주기를 바꾸려면 설정 콜백에서 타이머를 취소하고 새로 만든다.
- **멈추기·다시**: `self.timer.cancel()`, `self.timer.reset()`.
- **시뮬레이션 시간**: `use_sim_time=True`면 타이머도 `/clock`을 따른다.

## 원리·구조
```
시각  0.5   1.0   1.5   2.0 ─slow 2초─ 4.0   4.5
fast   ●     ●     ●     ●   (놓침×3)   ●     ●      ← 몰아서 나오지 않는다
```

## 코드 예시
```python
# 단일 창구에서 0.5초 타이머 + 2초 걸리는 콜백(주기 2초) — 몇 번 도는지 시뮬레이션
def simulate(until=8.0, fast=0.5, slow_period=2.0, slow_cost=2.0):
    t, next_fast, next_slow, log = 0.0, fast, slow_period, []
    while t < until:
        due = min(next_fast, next_slow)
        t = max(t, due)
        if next_fast <= t and next_fast <= next_slow:
            log.append(f"{t:.1f} fast")
            while next_fast <= t: next_fast += fast      # 놓친 차례는 버리고 다음 차례로
        else:
            log.append(f"{t:.1f} slow")
            t += slow_cost
            next_slow += slow_period
    return log
print(simulate())
# ['0.5 fast', '1.0 fast', '1.5 fast', '2.0 fast', '2.0 slow', '4.0 fast', '4.0 slow', '6.0 fast', '6.0 slow']
print([round(1 / T) for T in (1.0, 0.2, 0.1)])   # [1, 5, 10]  ← 주기 → Hz
```
