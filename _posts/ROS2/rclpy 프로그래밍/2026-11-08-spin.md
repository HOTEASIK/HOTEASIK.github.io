# spin

## 정의·핵심
- **정의**: `rclpy.spin(node)` — 노드를 살려 두고 **콜백을 실제로 불러 주는 엔진**. 단순히 기다리는 함수가 아니다. 4요소 중 셋(init·Node·create_*)이 준비라면 spin은 운전 — 심장이 뛰어야 피가 돌듯 (입문 3·4차시).
- **한 바퀴**: 수집(타이머가 울렸나, 메시지가 왔나) → 선택(일감 하나) → 실행(콜백 끝까지) → 다시 수집. Ctrl+C까지 반복.
- **콜백을 직접 부르는 코드가 없던 이유**: spin이 대신 부른다.
- **뒤에 실행기가 숨어 있다**: `rclpy.spin(node)` = 기본 실행기(SingleThreadedExecutor)를 만들고 → `add_node` → `spin()` 세 줄의 줄임.
- **형제들**
  - `rclpy.spin_once(node, timeout_sec=0.1)`: 일감 하나만 처리하고 돌아온다 — 내 while 루프 안에서 섞어 쓸 때.
  - `rclpy.spin_until_future_complete(node, future)`: future가 채워질 때까지만 — 서비스 클라이언트 main에서. **콜백 안에서는 쓰지 않는다**(데드락).
- **spin을 빼먹으면**: main이 그대로 반환 → 노드가 즉시 종료, 타이머는 한 번도 안 울림.
- **spin 뒤 코드는 Ctrl+C 이후에야** 실행된다 — spin 아래에 로직을 두지 않는다.

## 원리·구조
| 함수 | 언제 돌아오나 | 쓰는 자리 |
|---|---|---|
| `spin(node)` | 종료(Ctrl+C)될 때 | 일반 노드의 main |
| `spin_once(node, timeout_sec)` | 일감 하나 처리 또는 타임아웃 | 직접 만든 루프 |
| `spin_until_future_complete(node, fut)` | future 완료 시 | 서비스·액션 클라이언트 main |
| `executor.spin()` | 종료될 때 | 멀티스레드·노드 여럿 |

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from rclpy.executors import SingleThreadedExecutor

def main():
    rclpy.init()
    node = Node('spin_demo')
    node.create_timer(0.5, lambda: node.get_logger().info('tick'))

    # rclpy.spin(node) 한 줄이 감춘 세 줄
    ex = SingleThreadedExecutor()
    ex.add_node(node)
    try:
        ex.spin()
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.try_shutdown()

def loop_style():
    rclpy.init()
    node = Node('loop_demo')
    for _ in range(10):                       # 내 루프 + spin_once
        rclpy.spin_once(node, timeout_sec=0.1)
    node.destroy_node(); rclpy.try_shutdown()
```
