# 퍼블리셔

## 정의·핵심
- **정의**: 토픽에 메시지를 내보내는 쪽. `self.create_publisher(타입, '토픽', 큐깊이)`로 통로를 열고 `publish(msg)`로 보낸다 (입문 3차시).
- **인자 셋**: `String` 메시지 타입(어떤 그릇) · `'chatter'` 토픽 이름(어느 채널) · `10` QoS depth(밀릴 때 몇 개까지 쌓을지). 연결 상대(IP·포트)는 적지 않는다 — 같은 토픽 이름끼리 ROS가 잇는다.
- **보통 타이머와 짝**: `create_timer(1.0, self.tick)`이 1초마다 tick을 부르고, tick 안에서 메시지를 만들어 발행 — 무엇을 보낼지는 나, 통신은 ROS.
- **듣는 사람이 0명이어도 똑같이 발행**: 카메라 노드는 영상을 누가 쓸지 몰라도 된다 → 인식 노드를 나중에 붙여도 카메라 코드는 한 글자도 안 바뀐다(느슨한 결합).
- **로그는 값이 아니라 꼴을 본다**: `[INFO] [시각] [my_publisher]: 발행: "Hello ROS: 0"` — 시각 간격이 타이머 주기와 맞는지, 첫 줄은 1초가 안 될 수 있다(노드가 서고 첫 타이머까지).
- **확인 순서**: 발행 로그 → `ros2 topic echo /chatter` → `topic hz` → 구독자 연결.
- **커스텀 타입**: 자료형을 양식대로 — `float64` 칸에 `5`(int)를 넣으면 발행 단계에서 `AssertionError`, `5.0`으로.

## 원리·구조
```
create_timer(1.0) ──1초마다──→ tick()
                                 ├ msg = String(); msg.data = '...'
                                 └ self.pub.publish(msg) ──/chatter──→ (구독자 0..N)
```

## 코드 예시
```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MyPublisher(Node):
    def __init__(self):
        super().__init__('my_publisher')
        self.pub = self.create_publisher(String, 'chatter', 10)
        self.i = 0
        self.create_timer(1.0, self.tick)
        self.get_logger().info('my_publisher 시작 — /chatter 로 발행합니다.')

    def tick(self):
        msg = String()
        msg.data = f'Hello ROS: {self.i}'
        self.pub.publish(msg)
        self.get_logger().info(f'발행: "{msg.data}"')
        self.i += 1
```
```bash
# setup.py: 'my_publisher = my_py_pkg.my_publisher:main'
cd ~/ros2_ws && colcon build --packages-select my_py_pkg && source install/setup.bash
ros2 run my_py_pkg my_publisher
ros2 topic echo /chatter
```
