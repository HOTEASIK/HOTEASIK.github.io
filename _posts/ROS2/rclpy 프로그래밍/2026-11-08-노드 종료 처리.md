# 노드 종료 처리

## 정의·핵심
- **정의**: Ctrl+C 등으로 노드를 끌 때 **빨간 글씨 없이 자원을 정리하고 끝나게** 하는 main의 `try/except/finally` 골격 (입문 3·4차시).
- **예외 둘을 함께 잡는다**: Ctrl+C를 누르면 rclpy가 먼저 신호를 받아 통신 토대를 내린다 → spin은 `KeyboardInterrupt` 또는 `ExternalShutdownException`을 던진다. 둘 다 오류가 아니니 `pass`.
- **`try_shutdown`을 쓴다**: 이미 내려간 토대에 `rclpy.shutdown()`을 또 부르면 `rcl_shutdown already called` → 빨간 Traceback·종료 코드 1. `try_shutdown()`은 아직 안 내렸을 때만 내린다.
- **finally에서 정리**: `node.destroy_node()` → `rclpy.try_shutdown()` — 어느 경로로 끝나든 반드시.
- **sleep 중이면 바로 안 꺼진다**: 느린 콜백이 `time.sleep(2)` 중이면 그게 끝나야 종료가 처리된다(최대 2초).
- **답을 받으면 끝나는 노드**(서비스 클라이언트): spin 없이 destroy → try_shutdown. 클라이언트에 종료 골격이 없으면 Ctrl+C에 트레이스백이 뜨는 것은 정상.
- **콜백 안에서 shutdown 하지 않기**: 액션 클라이언트 완성형처럼 `self.done` 플래그만 세우고 main 한 곳에서 끝낸다.
- 이 골격은 한 번 익혀 퍼블리셔·서브스크라이버·서버 노드가 모두 글자까지 같이 쓴다.

## 원리·구조
```
rclpy.init() → node = X()
try:      rclpy.spin(node)              ← Ctrl+C
except:   (KeyboardInterrupt, ExternalShutdownException) → pass
finally:  node.destroy_node(); rclpy.try_shutdown()
```

## 코드 예시
```python
# shutdown 두 번 vs try_shutdown — 같은 상황을 순수 파이썬으로
class Context:
    def __init__(self): self.ok = True
    def shutdown(self):
        if not self.ok: raise RuntimeError("rcl_shutdown already called")
        self.ok = False
    def try_shutdown(self):
        if self.ok: self.ok = False
ctx = Context()
ctx.shutdown()                       # Ctrl+C 신호에 rclpy가 먼저 내림
try:
    ctx.shutdown()                   # main 끝의 rclpy.shutdown()
except RuntimeError as e:
    print("빨간 줄:", e)              # 빨간 줄: rcl_shutdown already called
ctx.try_shutdown(); print("try_shutdown: 조용히 통과")   # try_shutdown: 조용히 통과
```
```python
import rclpy
from rclpy.node import Node
from rclpy.executors import ExternalShutdownException

def main():
    rclpy.init()
    node = Node('clean_exit')
    try:
        rclpy.spin(node)
    except (KeyboardInterrupt, ExternalShutdownException):
        pass                          # Ctrl+C는 오류가 아니다
    finally:
        node.destroy_node()
        rclpy.try_shutdown()          # 이미 내려갔으면 조용히 넘어간다
```
