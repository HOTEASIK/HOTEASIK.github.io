# launch 네임스페이스·리맵·파라미터

## 정의·핵심
- **정의**: launch의 `Node(...)`에 `namespace=`, `remappings=`, `parameters=`를 적어 **코드를 고치지 않고 바깥에서** 이름과 값을 바꾸는 것. 명령줄 `--ros-args -r __ns:= / -r a:=b / -p x:=v`를 대본에 옮겨 적은 것 (입문 4·5차시).
- **namespace**: 노드 이름만이 아니라 그 노드의 (상대 이름) 토픽까지 통째로 한 칸 아래로 — `/chatter` → `/r2/chatter`. 로봇 열 대를 같은 코드로 띄울 때 한 줄로 끝난다.
- **remappings**: `[('/chatter', '/robot1/chatter')]` — 토픽 하나씩 갈아 끼운다(튜플 리스트).
- **parameters**: `[{'rate_hz': 2.0}]`(dict) 또는 `['config/params.yaml']`(파일 경로) — 여러 개 섞어도 되고 뒤의 것이 덮는다. 받는 쪽 노드에 `declare_parameter`가 있어야 한다.
- **같은 노드가 두 꼴로 보인다**: `ros2 node list`는 `/r1/my_publisher`(슬래시), 로그 줄은 `[r1.my_publisher]`(점).
- **칸막이와 이름 가르기는 다른 일**: `ROS_DOMAIN_ID` — 망 자체를 가르는 칸막이(서로를 발견조차 못 함) / 리매핑·namespace — 한 망 안에서 이름만 가르기(보이지만 섞이지 않음). 둘을 함께 쓰면 「어느 망인가」와 「그 안에서 누구인가」를 각각 정한다.

## 원리·구조
```text
Node(package='my_py_pkg', executable='my_publisher',
     name='pub', namespace='robot1',
     parameters=[{'rate_hz': 2.0}, '/path/params.yaml'],
     remappings=[('/chatter', '/robot1/chatter')])
```

## 코드 예시
```python
# launch 노드 설정 → 최종 노드·토픽 이름 계산 흉내 (namespace 후 remap 적용)
def final_names(node, ns="", remaps=(), topics=("chatter",)):
    pre = f"/{ns.strip('/')}" if ns else ""
    rm = dict(remaps)
    out = {"node": f"{pre}/{node}"}
    for t in topics:
        full = t if t.startswith("/") else f"{pre}/{t}"
        out[t] = rm.get(full, full)
    return out
print(final_names("my_publisher"))                    # {'node': '/my_publisher', 'chatter': '/chatter'}
print(final_names("my_publisher", ns="r2"))           # {'node': '/r2/my_publisher', 'chatter': '/r2/chatter'}
print(final_names("my_publisher", remaps=[("/chatter", "/robot1/chatter")]))
# {'node': '/my_publisher', 'chatter': '/robot1/chatter'}
```

# launch/multi.launch.py — 같은 코드 두 대
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(package='my_py_pkg', executable='param_demo', namespace=ns,
             parameters=[{'robot_name': ns, 'speed': spd}])
        for ns, spd in (('r1', 0.5), ('r2', 1.0))
    ])
