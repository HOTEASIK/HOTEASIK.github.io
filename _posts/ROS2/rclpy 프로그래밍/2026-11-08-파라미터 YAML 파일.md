# 파라미터 YAML 파일

## 정의·핵심
- **정의**: 파라미터 전체를 파일 하나로 저장·복원하는 YAML. 설정이 수십 개가 되면 하나씩 바꾸기 어렵다 — **파일이 설정의 정본** (입문 5차시).
- **꼴**: 맨 왼쪽 노드 이름 → 두 칸 `ros__parameters:`(**밑줄 두 개**, 손으로 적을 때 놓치기 쉽다) → 네 칸 값들. dump는 알파벳 순으로 정렬해 뽑는다. 노드 이름 자리에 `/**`를 쓰면 모든 노드에 적용.
- **세 명령**: `dump`(켜져 있는 노드 값을 파일로 — 좋은 값을 찾았을 때) / `load`(켜진 노드에 밀어 넣기 — 끄지 않고 되돌릴 때) / `--params-file`(그 값으로 켜기 — 초기값).
- **load의 빨간 줄 하나**: dump가 딸려 뽑은 `start_type_description_service`는 읽기 전용이라 `failed — read-only parameter`. 내가 선언한 것이 successful이면 된 것 — 거슬리면 그 줄을 지운다.
- **현장**: set으로 빠르게 맞춰 보고 → 좋은 값이 나오면 파일에 적어 고정. 기종별(burger/waffle)·로봇별로 파일을 나눈다. Nav2·SLAM도 YAML 한 벌로 설정한다.
- **launch에서**: `parameters=[os.path.join(pkg_share, 'config', 'params.yaml')]` — 파일은 setup.py data_files로 `share/패키지/config`에 설치해야 한다.
- YAML 주의: `off`·`on`·`yes`·`no`는 불(bool)로 읽힌다 → 문자열이면 따옴표.

## 원리·구조
```yaml
/param_demo:
  ros__parameters:
    robot_name: alpha
    speed: 2.0
    start_type_description_service: true
    use_sim_time: false
```

## 코드 예시
```python
# ros__parameters 구조를 손으로 읽는 작은 파서 (yaml 라이브러리 없이 들여쓰기 2/4칸 꼴만)
text = """/param_demo:
  ros__parameters:
    robot_name: alpha
    speed: 2.0
    use_sim_time: false
"""
def parse_params(t):
    out, node, ok = {}, None, False
    for line in t.splitlines():
        if not line.strip(): continue
        ind = len(line) - len(line.lstrip())
        key, _, val = line.strip().partition(":")
        if ind == 0: node = key; out[node] = {}
        elif ind == 2: ok = (key == "ros__parameters")
        elif ind == 4 and ok:
            v = val.strip()
            out[node][key] = {"true": True, "false": False}.get(v, float(v) if v.replace(".", "", 1).isdigit() else v)
    return out
print(parse_params(text))
# {'/param_demo': {'robot_name': 'alpha', 'speed': 2.0, 'use_sim_time': False}}
print(parse_params(text.replace("ros__parameters", "ros_parameters")))   # {'/param_demo': {}}  ← 밑줄 하나면 무시됨
```
```bash
ros2 param dump /param_demo > params.yaml
ros2 param load /param_demo params.yaml
ros2 run my_py_pkg param_demo --ros-args --params-file params.yaml
```
