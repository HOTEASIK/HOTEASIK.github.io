# rclpy 파라미터

## 정의·핵심
- **정의**: 노드 코드에서 파라미터를 **선언하고 읽는** 것. 코드에 박힌 숫자(값 하나 바꾸는 데 코드 수정→빌드→재실행 여섯 단계)를 바깥 손잡이로 꺼낸다 (입문 5차시).
- **선언 → 읽기**: `self.declare_parameter('speed', 1.0)` (보통 `__init__`에서 한 번) → `self.get_parameter('speed').value`.
- **기본값이 하는 일 둘**: 바깥에서 값을 안 줬을 때 쓸 값 + **자료형 결정**(1.0이면 실수형 — 이후 실수만 받는다). `1`로 선언해 놓고 `1.5`를 넣으려다 막히는 일이 흔하다.
- **가장 흔한 함정 — `.value` 누락**: `get_parameter`는 값을 감싼 객체를 돌려준다 → 계산에 넣으면 타입 오류, 로그에 객체 표현.
- **쓸 때마다 다시 읽는다**: 타이머 콜백 안에서 매번 읽으면 `ros2 param set`이 바로 반영되고, `__init__`에서 한 번 읽어 담아 두면 아무리 바꿔도 옛 값.
- **선언 안 하고 읽으면**: `ParameterNotDeclaredException: Invalid access to undeclared parameter(s): speed` — 읽는 줄이 타이머 콜백 안이면 뜬 뒤 1초에 죽고, `__init__` 안이면 뜨자마자 죽는다.
- **값을 넣는 세 길**: 명령줄 `-p speed:=2.0`(켤 때) / `--params-file params.yaml`(켤 때, 여럿) / `ros2 param set`(실행 중). set으로 바꾼 값은 껐다 켜면 사라진다 → 좋은 값은 파일로.
- **모든 노드가 기본으로 갖는 것**: `use_sim_time`, `start_type_description_service`.

## 원리·구조
| 자료형 | 선언 예 | 쓰는 자리 |
|---|---|---|
| 정수 | `declare_parameter('count', 10)` | 반복 횟수, 큐 크기 |
| 실수 | `declare_parameter('speed', 1.0)` | 속도, 주기, 임계값 |
| 불리언 | `declare_parameter('verbose', False)` | 기능 켬·끔 |
| 문자열 | `declare_parameter('frame_id', 'base_link')` | 좌표계 이름, 장치 경로 |
| 배열 | `declare_parameter('limits', [0.0, 2.0])` | 하한·상한 묶음 |

## 코드 예시
```python
import rclpy
from rclpy.node import Node

class ParamDemo(Node):
    def __init__(self):
        super().__init__('param_demo')
        self.declare_parameter('speed', 1.0)          # 실수
        self.declare_parameter('robot_name', 'alpha') # 문자열
        self.create_timer(1.0, self.tick)

    def tick(self):
        speed = self.get_parameter('speed').value     # .value 까지, 쓸 때마다 다시 읽기
        name = self.get_parameter('robot_name').value
        self.get_logger().info(f'{name} 속도={speed}')

def main():
    rclpy.init(); rclpy.spin(ParamDemo())
```
```bash
ros2 run my_py_pkg param_demo --ros-args -p speed:=2.0 -p robot_name:=beta   # beta 속도=2.0
ros2 param set /param_demo speed 2.0                                          # Set parameter successful
ros2 param describe /param_demo speed                                         # Type: double
```
