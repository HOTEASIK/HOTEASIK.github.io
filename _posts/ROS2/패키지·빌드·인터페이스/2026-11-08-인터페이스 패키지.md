# 인터페이스 패키지

## 정의·핵심
- **정의**: `.msg`·`.srv`·`.action` 양식만 모아 두는 **전용 ament_cmake 패키지** — 양식 공장. 예 `my_interfaces`, 실무 이름은 `프로젝트명_interfaces`·`_msgs` (입문 2차시).
- **왜 ament_cmake인가**: 양식에서 코드를 찍어내는 rosidl 생성이 **CMake 빌드 단계 안에서** 돈다. ament_python 노드 패키지에 `.msg`를 넣으면 빌드는 표면상 통과해도 타입이 생성되지 않는다 (`ros2 interface list | grep my_py_pkg`에 아무것도 없음).
- **왜 따로 두나**
  - **공용**: 파이썬 노드·C++ 노드·나중 패키지가 공장 하나만 바라본다. 양식을 노드 패키지에 묻으면 양식 한 장 필요한 쪽이 남의 노드 코드까지 끌어와야 한다.
  - **변경 범위**: 노드 로직은 매일 바뀌어도 데이터 모양은 오래간다 — 노드를 고쳐도 공장은 재빌드하지 않는다.
- **만드는 순서**: `pkg create --build-type ament_cmake` → `mkdir -p my_interfaces/{msg,srv}` (폴더 먼저!) → 양식 작성 → 마법의 여섯 줄 → 빌드 → source → `interface show`.
- **쓰는 쪽은 둘이 짝**: 노드 패키지 package.xml에 `<depend>my_interfaces</depend>`(신고) + 코드에 `from my_interfaces.msg import TurtleGoal`(가져오기). import만 하고 신고를 빼면 빌드는 통과하고 실행·남의 환경에서 무너진다.
- **빌드 순서가 드러난다**: 신고하면 colcon이 my_interfaces를 먼저, my_py_pkg를 나중에.
- **양식을 바꾸면** 그 양식에 기댄 노드를 전부 다시 빌드 — 칸 추가는 비교적 안전, 이름·타입 변경은 읽던 코드까지 손봐야 한다.

## 원리·구조
```
my_interfaces/          (ament_cmake)
 ├─ CMakeLists.txt  package.xml  LICENSE
 ├─ include/my_interfaces/   src/      ← C++용으로 생기지만 안 쓴다
 ├─ msg/TurtleGoal.msg
 └─ srv/AddThreeInts.srv  SetTurtleName.srv
```
| 증상 | 원인 → 해결 |
|---|---|
| `bash: msg/T.msg: No such file or directory` | 폴더보다 파일 먼저 → `mkdir -p` |
| 양식을 넣었는데 타입이 안 생김 | ament_python 패키지에 넣음 → 전용 ament_cmake로 |
| `Unknown package 'my_interfaces'` | 새 터미널에서 source 안 함 |

## 코드 예시
```python
# 빌드 후 파이썬에서 보이는 모양 흉내: 서비스는 _Request/_Response 둘로 갈라진다
def generated(pkg, kind, name, fields_req, fields_res=None):
    if kind == "msg":
        return [f"{pkg}.msg.{name}({fields_req})"]
    return [f"{pkg}.srv.{name}_Request({fields_req})", f"{pkg}.srv.{name}_Response({fields_res})"]
print(generated("my_interfaces", "msg", "TurtleGoal", "turtle_name='', x=0.0, y=0.0, speed=0.0"))
for l in generated("my_interfaces", "srv", "AddThreeInts", "a=0, b=0, c=0", "sum=0"): print(l)
# my_interfaces.srv.AddThreeInts_Request(a=0, b=0, c=0)
# my_interfaces.srv.AddThreeInts_Response(sum=0)
```
```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_cmake --license Apache-2.0 my_interfaces
mkdir -p my_interfaces/{msg,srv}
cd ~/ros2_ws && colcon build --packages-select my_interfaces && source install/setup.bash
ros2 interface list | grep my_interfaces
```
