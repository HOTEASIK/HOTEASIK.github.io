# msg 파일

## 정의·핵심
- **정의**: 토픽용 메시지 양식. `msg/` 폴더에 `이름.msg`로 두고, **한 줄에 `타입 이름`** 하나씩 적는다. 구분선이 없다 (입문 2차시).
- **필드 이름은 설계 문서**: `string s`는 몇 달 뒤 본인도 모른다 — `string turtle_name`처럼 뜻이 읽히게. 도메인이 바뀌면 단어가 바뀐다: 거북이판 `x` → 배달판 `dest_x`, `turtle_name` → `robot_id`.
- **이름 규칙**: 필드는 소문자+밑줄(snake_case), 상수는 대문자+밑줄·영문자 시작, 끝 밑줄·연속 밑줄 금지. 파일(타입) 이름은 CamelCase.
- **두껍게 쓰기**: 상수(`int8 STATE_ERROR=2` — 코드에 `2`보다 읽힌다), 기본값(`float64 speed 1.0`), 배열(`int32[]`, `float64[3]`, `int32[<=5]`).
- **다른 양식을 칸으로**: `geometry_msgs/Point goal_point` (복합·중첩 타입) — 이때는 CMakeLists의 `DEPENDENCIES geometry_msgs`와 package.xml `<depend>geometry_msgs</depend>` 두 곳에.
- **`interface show`** 는 주석·정렬까지 적은 그대로 보여 준다 — 주석을 성의 있게.

## 원리·구조
```
# my_interfaces/msg/TurtleGoal.msg
string turtle_name   # 거북이 이름
float64 x            # 목표 x 좌표
float64 y            # 목표 y 좌표
float64 speed        # 이동 속도

# my_interfaces/msg/RobotState.msg
int8 STATE_IDLE=0
int8 STATE_MOVING=1
int8 STATE_ERROR=2
int8 current_state
```
| 증상 | 원인 → 해결 |
|---|---|
| 양식 파싱 실패 | 콤마로 구분·한 토막만 → `타입 이름` |
| 대문자 필드 거부 | 필드는 snake_case |
| `float` 인식 안 됨 | 비트 수까지 — `float32`/`float64` |
| 상수가 필드로 처리 | 대문자 + `타입 NAME=값` |
| 글자 배열 기본값 빌드 실패 | 단순 타입에만 기본값 |

## 코드 예시
```python
# .msg 한 줄씩 해석하는 작은 파서 (필드/상수/기본값/배열)
import re
LINE = re.compile(r"^(?P<type>[\w/]+(?:\[(?:<=)?\d*\])?)\s+(?P<name>\w+)(?:\s*=\s*(?P<const>\S+)|\s+(?P<default>\S+))?$")
def parse_msg(text):
    out = []
    for raw in text.splitlines():
        line = raw.split("#")[0].strip()
        if not line: continue
        m = LINE.match(line)
        if not m: out.append(("ERROR", line)); continue
        kind = "const" if m["const"] else "field"
        if kind == "field" and not re.fullmatch(r"[a-z][a-z0-9_]*", m["name"]): kind = "ERROR(필드 이름)"
        out.append((kind, m["type"], m["name"], m["const"] or m["default"]))
    return out
src = """int8 STATE_ERROR=2   # 상수
int8 current_state
float64 speed 1.0
int32[<=5] ids
string Name
float64, x"""
for r in parse_msg(src): print(r)
# ('const', 'int8', 'STATE_ERROR', '2') / ('field', 'int8', 'current_state', None)
# ('field', 'float64', 'speed', '1.0') / ('field', 'int32[<=5]', 'ids', None)
# ('ERROR(필드 이름)', 'string', 'Name', None) / ('ERROR', 'float64, x')
```
