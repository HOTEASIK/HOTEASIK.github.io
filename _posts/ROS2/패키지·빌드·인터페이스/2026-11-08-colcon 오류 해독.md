# colcon 오류 해독

## 정의·핵심
- **원칙**: 오류 메시지는 적이 아니라 길 안내다. 맨 아래 `Failed <<< 패키지` 줄을 찾고 → 그 **바로 위 몇 줄**로 올라가 → 「무엇을 못 찾았다 · 어디서 충돌했다」는 **첫 영어 문장**을 읽는다. 뜻을 짐작해 찾지 말고 화면 문구를 그대로 집어 표에서 찾는다 (기초 5차시, 입문 1차시).
- **일부러 막혀 보기**: remap 빼기, `__ns` 밑줄 하나, src 안에서 빌드 — 한 번 깨뜨려 보면 다음에 같은 메시지가 떠도 당황하지 않는다.
- **colcon이 원인을 숨길 때**: setup.py 콤마 누락은 `Failed <<<`와 `CalledProcessError`까지만 보인다 → 패키지 폴더에서 `python3 setup.py --help` 처럼 파이썬에게 직접 물으면 `SyntaxWarning: 'tuple' object is not callable; perhaps you missed a comma?`.
- **빌드는 성공·실행에서 실패**: `ModuleNotFoundError`(의존성 미신고·import 경로 오타)는 colcon build가 통과한다.
- **「내 컴퓨터에선 됐는데」의 절반**은 source와 의존성 신고.

## 원리·구조
| 증상(화면 메시지) | 원인 → 해결 |
|---|---|
| `colcon: command not found` | 미설치 → `sudo apt install python3-colcon-common-extensions` |
| 빌드 후 `Package '…' not found` | overlay source 누락 → `source install/setup.bash` (새 터미널마다) |
| `src/` 안에 build·install·log | src 안에서 빌드 → 지우고 루트에서 재빌드 |
| 파이썬 import·버전 충돌 | conda (base) 켜짐 → `conda deactivate` 후 재빌드 |
| `SetuptoolsDeprecationWarning` | 경고는 무시 가능, 실패면 패키지명·setup.py 철자 확인 |
| 중간에 멈추고 `Aborted` / 꼬임 | 이전 산출물 꼬임 → `rm -rf build install log` 후 클린 빌드 |
| `No executable found` | entry_points 미등록·재빌드 안 함 → 등록 → 빌드 → source |
| `Failed <<<` + `CalledProcessError` | setup.py 항목 사이 콤마 누락 |
| 코드를 고쳤는데 반영 안 됨 | install 미갱신 → 재빌드 또는 `--symlink-install` |
| `Unknown CMake command "rosidl_generate_interfaces"` | find_package 순서·누락 |

## 코드 예시
```python
# 빌드 로그에서 Failed 줄 바로 위의 첫 영어 오류 문장 찾기
log = """Starting >>> my_py_pkg
--- stderr: my_py_pkg
Traceback (most recent call last):
  File "setup.py", line 20
SyntaxWarning: 'tuple' object is not callable; perhaps you missed a comma?
---
Failed   <<< my_py_pkg [0.52s, exited with code 1]
Summary: 0 packages finished [0.80s]"""
lines = log.splitlines()
i = next(k for k, l in enumerate(lines) if l.startswith("Failed"))
hint = next(l for l in reversed(lines[:i]) if any(w in l for w in ("Error", "Warning", "not found")))
print(lines[i].split("<<<")[1].split()[0], "→", hint)
# my_py_pkg → SyntaxWarning: 'tuple' object is not callable; perhaps you missed a comma?
```
