# setup.py

## 정의·핵심
- **정의**: ament_python 패키지의 **설치·실행 설명서**. 파이썬 표준 패키징 도구(setuptools)가 읽어 코드를 어디에 설치하고 어떤 실행 파일을 만들지 정한다. C++ 패키지에서는 CMakeLists.txt가 이 자리를 대신한다 (입문 1차시).
- **핵심 두 칸**
  - **entry_points**: `.py`의 함수를 `ros2 run` 실행 이름으로 등록 — 노드의 전화번호부.
  - **data_files**: 소스 밖 파일을 install 쪽 `share/패키지/`에 복사 — 기본으로 색인 마커와 package.xml, 나중에 launch·config·urdf 파일을 여기 더한다.
- **launch·YAML을 더할 때**: `(os.path.join('share', package_name, 'launch'), glob('launch/*.py'))` 같은 줄을 data_files에 추가하고 다시 빌드 — 안 하면 `ros2 launch`가 파일을 못 찾는다.
- **가장 흔한 오타**: 항목과 항목 사이 콤마 누락 → `Failed <<<` + `CalledProcessError`. 마지막 항목 뒤 콤마는 있어도 없어도 된다.
- **의존성은 여기 안 적는다**: package.xml에 적는다 (`install_requires=['setuptools']`만 둔다).

## 원리·구조
```text
from setuptools import find_packages, setup
package_name = 'my_py_pkg'
setup(
    name=package_name,
    version='0.0.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages', ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='student',
    description='TODO: Package description',
    license='Apache-2.0',
    entry_points={
        'console_scripts': [
            'my_publisher = my_py_pkg.my_publisher:main',
        ],
    },
)
```

## 코드 예시
```python
# 콤마를 빠뜨리면 두 튜플이 "호출"로 읽힌다 — 파이썬이 직접 일러 주는 경고
import warnings
src = "data_files = [('a', ['x'])  ('b', ['y'])]"
with warnings.catch_warnings(record=True) as w:
    warnings.simplefilter("always")
    code = compile(src, "setup.py", "exec")
print(w[0].message)     # 'tuple' object is not callable; perhaps you missed a comma?
try:
    exec(code)
except TypeError as e:
    print("TypeError:", e)   # TypeError: 'tuple' object is not callable
```
