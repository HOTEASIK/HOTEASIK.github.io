# 표준 메시지 패키지

## 정의·핵심
- **정의**: 자주 쓰는 데이터 양식을 미리 만들어 둔 묶음(common_interfaces). 좌표·자세·영상·센서값은 이미 있다 — **먼저 찾고, 없으면 만든다** (입문 2차시).
- **표준을 쓰면 생태계와 바로 연결된다**: RViz, Nav2, SLAM, rosbag 도구들이 표준 타입을 기대한다. `MyPosition.msg`를 새로 만들면 시중의 위치 처리 노드·시각화와 곧바로 이어지지 않는다.
- **외울 필요는 없다**: 분야 이름(std·geometry·sensor·nav)으로 묶여 있다는 것만 기억하고 `ros2 interface list`, `interface show`로 찾는다.
- **std_msgs 주의**: `String`, `Int32` 같은 기본형 감싸기는 실습에는 편하지만 의미가 없는 타입이라 실무에서는 뜻 있는 타입(또는 커스텀)을 권장.
- **헤더가 붙은 Stamped 판**: `PoseStamped`, `TwistStamped`처럼 `std_msgs/Header`(시각+좌표계 frame_id)가 붙은 판이 있다 — TF·시간 동기화가 필요할 때.
- **서비스 표준도 있다**: `std_srvs/srv/Trigger`(요청 없음, success+message), `std_srvs/srv/SetBool`, `example_interfaces/srv/AddTwoInts`.

## 원리·구조
| 패키지 | 담는 것 | 흔한 예 |
|---|---|---|
| std_msgs | 기본값 감싸기, Header | String, Int32, Float64, Bool, Header |
| geometry_msgs | 위치·자세·속도 | Point, Quaternion, Pose, PoseStamped, Twist, TwistStamped, TransformStamped |
| sensor_msgs | 센서 데이터 | Image, CompressedImage, CameraInfo, LaserScan, Imu, PointCloud2, JointState |
| nav_msgs | 이동·지도 | Odometry, Path, OccupancyGrid |
| std_srvs | 단순 서비스 | Trigger, SetBool, Empty |
| visualization_msgs | RViz 표시 | Marker, MarkerArray |

## 코드 예시
```python
# "먼저 찾고, 없으면 만든다": 필요한 칸으로 표준 타입 고르기
std = {
    "geometry_msgs/msg/Point": {"x", "y", "z"},
    "geometry_msgs/msg/Twist": {"linear", "angular"},
    "sensor_msgs/msg/LaserScan": {"ranges", "angle_min", "angle_max"},
    "nav_msgs/msg/Odometry": {"pose", "twist"},
}
def find_std(need):
    hits = [t for t, f in std.items() if need <= f]
    return hits or "표준 없음 → my_interfaces에 새로 만든다"
print(find_std({"x", "y"}))                      # ['geometry_msgs/msg/Point']
print(find_std({"turtle_name", "speed"}))        # 표준 없음 → my_interfaces에 새로 만든다
```
```bash
ros2 interface list | grep geometry_msgs
ros2 interface show geometry_msgs/msg/PoseStamped
ros2 interface package sensor_msgs
```
