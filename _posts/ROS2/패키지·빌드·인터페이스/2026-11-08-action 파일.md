# action 파일

## 정의·핵심
- **정의**: 액션용 양식. `action/` 폴더에 두고 **구분선 `---` 두 개**로 목표(Goal) / 결과(Result) / 피드백(Feedback) 세 묶음을 나눈다. 순서가 고정 — 위에서부터 goal, result, feedback (입문 2·5차시).
- **요령은 .srv와 같다**: 구분선 하나로 요청/응답을 가른 것을 한 칸 늘린 것.
- **예 CountUp**: 목표 「10까지 세라」 → 피드백 「지금 3까지 셌다」가 계속 → 결과 「센 숫자 전체」가 한 번.
- **추가 순서**: `mkdir action` → `.action` 작성 → CMakeLists의 `rosidl_generate_interfaces` 목록에 `"action/CountUp.action"` 한 줄 **추가**(기존 목록을 덮어써 지우지 않기) → 재빌드 → source.
- **의존**: 액션 양식을 만들면 package.xml에 `<depend>action_msgs</depend>`가 필요할 수 있다 (액션 내부의 goal_id·status 타입).
- **빌드 결과**: 이름_Goal, 이름_Result, 이름_Feedback (+ 내부용 SendGoal·GetResult 서비스, FeedbackMessage 토픽).

## 원리·구조
```
# my_interfaces/action/CountUp.action
int32 target          # Goal
---
int32[] sequence      # Result
---
int32 current         # Feedback

# turtlesim/action/RotateAbsolute.action
float32 theta
---
float32 delta
---
float32 remaining
```

## 코드 예시
```python
# .action 세 묶음 나누기 + 생성될 타입 이름
def parse_action(name, text):
    parts = text.split("\n---\n")
    if len(parts) != 3: return f"구분선이 {len(parts)-1}개 — action은 2개"
    return {f"{name}_{k}": p.split() [1::2] for k, p in zip(("Goal", "Result", "Feedback"), parts)}
print(parse_action("CountUp", "int32 target\n---\nint32[] sequence\n---\nint32 current"))
# {'CountUp_Goal': ['target'], 'CountUp_Result': ['sequence'], 'CountUp_Feedback': ['current']}
print(parse_action("Bad", "int32 a\n---\nint32 b"))   # 구분선이 1개 — action은 2개
```
```bash
ros2 interface show turtlesim/action/RotateAbsolute
ros2 interface show my_interfaces/action/CountUp
```
