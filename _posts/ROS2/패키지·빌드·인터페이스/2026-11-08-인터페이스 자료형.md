# 인터페이스 자료형

## 정의·핵심
- **정의**: `.msg`·`.srv`·`.action` 칸에 쓸 수 있는 ROS 공용 타입. 타입이 「5.0이 숫자인지 글자인지」 판단을 미리 끝내 둔다 (입문 2차시).
- **비트 수까지 적는다**: `float`는 인식 안 됨 → `float32`/`float64`. 입문에서는 정수 `int64`, 소수 `float64`를 기본으로.
- **배열 세 가지**: `타입[]` 무제한, `타입[N]` 정확히 N개, `타입[<=N]` N개 이하(상한을 두면 메모리·검증에 유리). 문자열 길이 상한 `string<=10`.
- **기본값과 상수**: `float64 speed 1.0`(기본값), `int8 STATE_IDLE=0`(상수). 기본값은 단순 타입에만 — 글자 배열·복합 타입은 안 된다.
- **복합 타입**: 다른 양식을 칸으로 — `geometry_msgs/Point goal_point`, `std_msgs/Header header`.
- **언어 매핑**: 빌드 후 파이썬에서는 int/float/str/bool/list(또는 numpy 배열·array), C++에서는 int64_t/double/std::string/std::vector.
- **타입 범위 주의**: `uint8`에 300을 넣으면 파이썬 메시지가 `AssertionError`로 거절한다(turtlesim SetPen의 r·g·b는 uint8 → 0~255).

## 원리·구조
| ROS 타입 | 파이썬 | C++ | 비고 |
|---|---|---|---|
| bool | bool | bool | |
| byte, uint8 / int8 | int | uint8_t / int8_t | 0~255 / -128~127 |
| int16·int32·int64 (u 포함) | int | int16_t… | |
| float32 / float64 | float | float / double | |
| string | str | std::string | `string<=N` 상한 |
| T[] / T[N] / T[<=N] | list·array | vector / array | |
| 패키지/타입 | 메시지 객체 | 구조체 | 중첩 |

## 코드 예시
```python
# 타입 범위 검사 흉내 (rosidl 파이썬 메시지가 하는 검사와 같은 생각)
RANGES = {"uint8": (0, 255), "int8": (-128, 127), "int32": (-2**31, 2**31 - 1),
          "uint16": (0, 65535)}
def check(t, v):
    if t.startswith("float"): return isinstance(v, float)
    lo, hi = RANGES[t]
    return isinstance(v, int) and lo <= v <= hi
print(check("uint8", 255), check("uint8", 300), check("int8", -5))   # True False True
print(check("float64", 1), check("float64", 1.0))                     # False True  ← 1이 아니라 1.0
def bounded(arr, n): return len(arr) <= n
print(bounded([1, 2, 3], 5), bounded(list(range(6)), 5))            # True False
```
