# 정의
ROS에서 기본적으로 제공하는 표준 메시지 패키지
글자 한 줄, 숫자 한 개처럼 **기본값을 감싼 단순 양식**을 담는다. 표준 양식 모음(common_interfaces)의 하나다.

| 표준 꾸러미 | 담는 것 | 예 |
|---|---|---|
| **std_msgs** | 기본값을 감싼 단순 양식 | String, Int32, Float64, Bool |
| [[geometry_msgs]] | 위치·자세·속도 | Point, Pose, Twist |
| [[sensor_msgs]] | 센서 데이터 | Image, LaserScan, Imu |
| nav_msgs | 이동·지도 | Path, OccupancyGrid, Odometry |

흔한 데이터에는 대개 표준이 있다 — **먼저 찾고, 없으면 만든다.**

# .msg
해당 패키지 안에 있는 메시지 정의(message definition) 모듈안에 있는 클래스를 가져다 쓴다.
`from std_msgs.msg import String` = 「`std_msgs` 패키지의 `msg` 안에 있는 `String`을 가져온다」

## String 
문자열 데이터를 주고받기 위한 클래스. 칸은 `data` 하나다.

```python
from std_msgs.msg import String

self.pub = self.create_publisher(String, '/chatter', 10)
msg = String()
msg.data = 'Hello ROS'
self.pub.publish(msg)
```

```bash
ros2 topic pub --once /guess std_msgs/msg/String "{data: 'h'}"
# publishing #1: std_msgs.msg.String(data='h')
```

# 의존성
패키지에서 쓰려면 의존성에 넣는다.
```bash
ros2 pkg create --build-type ament_python --dependencies rclpy std_msgs my_pkg
```
```xml
<depend>std_msgs</depend>   <!-- package.xml -->
```
- `import`가 빠지면 `create_subscription(String, …)` 줄에서 `NameError`로 멈춘다
