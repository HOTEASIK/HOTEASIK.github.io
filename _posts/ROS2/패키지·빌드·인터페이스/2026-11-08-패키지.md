# 패키지

## 정의·핵심
- **정의**: ROS2 코드를 담는 **배포·빌드의 최소 단위 상자**. 노드 코드, 설정, launch 파일, 인터페이스 정의를 담고, package.xml로 이름·버전·의존성을 신고한다 (기초 5차시, 입문 1차시).
- **노드와의 관계**: 패키지 하나에 노드 여럿이 들어갈 수 있다. `ros2 run <패키지> <실행 이름>` — 앞은 상자, 뒤는 상자 안의 실행 파일.
- **상자와 방**: `my_py_pkg/my_py_pkg/` — 바깥은 패키지 상자, 안쪽은 파이썬 모듈(방). 이름이 두 겹인 게 파이썬 패키징 표준이고 노드 `.py`는 늘 안쪽에.
- **ament_python 패키지의 일곱 칸**

| 항목 | 역할 |
|---|---|
| package.xml | 신고서 — 이름·버전·의존성 |
| LICENSE | `--license`로 정한 라이선스 전문 (옵션 없으면 안 생김) |
| setup.py | 빌드·설치 방식 — entry_points·data_files가 핵심 |
| setup.cfg | 실행 파일을 어느 폴더에 설치할지 |
| resource/ | 패키지 색인용 마커 파일(이름=패키지 이름) |
| test/ | 코드 스타일·자동 테스트 |
| my_py_pkg/ | 실제 노드 .py가 들어갈 파이썬 모듈 |

- **나누는 기준**: 노드 패키지와 인터페이스 패키지는 분리, 여러 노드를 띄우는 launch만 모은 `*_bringup` 패키지도 흔하다.
- **남이 만든 패키지 받기**: src에 둔다 → 루트에서 빌드 → 본체·워크스페이스 순 source → `ros2 pkg list`로 확인.

## 원리·구조
```
~/ros2_ws/src/my_py_pkg/
 ├─ package.xml   LICENSE   setup.py   setup.cfg
 ├─ resource/my_py_pkg
 ├─ test/  (test_copyright.py, test_flake8.py, test_pep257.py)
 └─ my_py_pkg/
     ├─ __init__.py
     └─ my_publisher.py     ← 노드
```

## 코드 예시
```python
# ros2 run <패키지> <실행 이름> → 패키지 안 실행 파일 찾기 흉내
installed = {"turtlesim": ["turtlesim_node", "turtle_teleop_key"], "my_py_pkg": ["my_publisher"]}
def ros2_run(pkg, exe):
    if pkg not in installed: return f"Package '{pkg}' not found"
    if exe not in installed[pkg]: return "No executable found"
    return f"실행: {pkg}/{exe}"
print(ros2_run("turtlesim", "turtlesim_node"))   # 실행: turtlesim/turtlesim_node
print(ros2_run("my_py_pkg", "my_subscriber"))    # No executable found
print(ros2_run("my_pkg", "x"))                   # Package 'my_pkg' not found
```

## 수업 메모

### 정의
패키지는 노드 코드, 설정, launch 파일, 메시지 정의 등을 묶은 빌드·배포 단위

### 특징
재사용하고 다른 사람과 공유(배포)하기 쉽습니다.  
의존성을 명시해 colcon으로 빌드·설치하고 ros2 run으로 실행할 수 있습니다.


### 빌드 

#### 파일 특징 
package.xml: 패키지 이름, 버전, 작성자, 라이선스, 의존성 같은 메타정보를 담습니다.

CMakeLists.txt: C++(ament_cmake) 패키지의 컴파일·설치 규칙을 정합니다.

setup.py: Python(ament_python) 패키지의 설치 정보를 담고, entry_points의 console_scripts에 실행 이름을 등록합니다.

실행 이름 등록을 빠뜨리면 ros2 run 했을 때 No executable found가 돌아옵니다.

### 패기지 종류
| c++,                                                        | python                                                                        |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 실시간 제어                                                      | 로직                                                                            |
| 하드 스펙과 저지연(Low-latency)이 중요한 부분                             | 빠른 알고리즘 구현이 중요한 부분에는 충분히 실용적(인공지능(AI), 머신러닝, 상위 레벨 로직, GUI, 데이터 로깅)           |
| 멀티스레딩(Multi-threading)과 콜백 그룹(Callback group)을 정교하게 제어하기 좋음 | 딥러닝 라이브러리(PyTorch, TensorFlow)나 데이터 분석 도구(NumPy, Pandas)를 ROS 노드와 연동하기가 매우 쉬움 |
### 기본 패키지

[[geometry_msgs]]: 로봇에 움직임을 제어하는 데이터를 주고 받는 패키지 
[[sensor_msgs]]: 특정 센서의 데이터 형식이 있는 패키지
