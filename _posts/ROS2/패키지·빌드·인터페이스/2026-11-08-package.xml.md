# package.xml

## 정의·핵심
- **정의**: 패키지의 **신고서**. 이름·버전·설명·관리자·라이선스, 그리고 「이 패키지가 돌려면 어떤 다른 패키지가 필요한가」(의존성)를 적는 XML. ROS 세계 전체(colcon, rosdep)가 읽는 공통 문서라 파이썬이든 C++이든 같은 형식 (입문 1·2차시).
- **의존성 신고가 하는 일 셋**
  - **빌드 순서**: colcon이 읽어 의존 대상을 먼저 빌드.
  - **설치**: rosdep이 읽어 받은 사람 환경에 필요한 것을 자동 설치.
  - **약속**: 나보다 이 패키지를 받아 쓸 다음 사람을 위한 것 — 내 컴퓨터에선 빠뜨려도 우연히 돈다.
- **빠뜨리면**: 빌드는 되더라도 실행 때 `ModuleNotFoundError` — 또는 남의 환경에서만 터진다.
- **자리표시자**: `<description>TODO…`, `<maintainer email="…@todo.todo">` — 남에게 넘길 패키지라면 고친다. `format="3"`.

## 원리·구조
| 태그 | 언제 필요한가 | 예 |
|---|---|---|
| `<depend>` | 빌드 때도 실행 때도 (아래 둘의 줄임) | rclpy, std_msgs, my_interfaces |
| `<buildtool_depend>` | 빌드할 때만 — 빌드 도구 자체 | ament_cmake, rosidl_default_generators |
| `<exec_depend>` | 실행할 때만 | rosidl_default_runtime |
| `<test_depend>` | 테스트할 때만 | ament_flake8, python3-pytest |
| `<member_of_group>` | 그룹 명찰 | rosidl_interface_packages |
| `<export><build_type>` | 빌드 타입 | ament_python / ament_cmake |

| 비교 | package.xml | setup.py |
|---|---|---|
| 비유 | 신고서 | 설치·실행 설명서 |
| 적는 것 | 이름·버전·의존성 | entry_points·data_files |
| 빠뜨리면 | 실행 때 「모듈 없음」 | `ros2 run`이 노드를 못 찾음 |
| 읽는 쪽 | colcon·rosdep (ROS 세계) | setuptools (파이썬 세계) |

## 코드 예시
```python
# package.xml을 실제로 파싱해 의존성 뽑기 (표준 라이브러리 xml)
import xml.etree.ElementTree as ET
xml = """<?xml version="1.0"?>
<package format="3">
  <name>my_py_pkg</name>
  <version>0.0.0</version>
  <license>Apache-2.0</license>
  <depend>rclpy</depend>
  <depend>std_msgs</depend>
  <depend>my_interfaces</depend>
  <test_depend>ament_flake8</test_depend>
  <export><build_type>ament_python</build_type></export>
</package>"""
root = ET.fromstring(xml.split("?>", 1)[1])
print(root.findtext("name"), root.findtext("export/build_type"))   # my_py_pkg ament_python
print([d.text for d in root.findall("depend")])                    # ['rclpy', 'std_msgs', 'my_interfaces']
```
