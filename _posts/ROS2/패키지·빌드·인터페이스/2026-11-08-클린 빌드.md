# 클린 빌드

## 정의·핵심
- **정의**: 산출물 `build install log` 세 폴더만 지우고 처음부터 다시 빌드하는 초기화 (기초 5차시, 입문 1차시).
- **안전한 이유**: 세 폴더에는 내 손으로 쓴 것이 하나도 없다 — 내 코드는 `src`에만 있다. 그래서 언제든 지우고 되살린다.
- **언제**: 빌드가 중간에 멈추고 `Aborted`, 이전 산출물이 꼬인 것 같을 때, 패키지 이름을 바꿨을 때, `--symlink-install`을 켜고 끄며 바꿀 때, 지운 파일이 install에 남아 계속 쓰일 때.
- **source 다시**: 지우고 다시 빌드한 뒤에는 `source install/setup.bash`를 다시 해야 패키지가 보인다. 지운 install을 가리키던 터미널은 새로 여는 게 깔끔하다.
- **한 패키지만**: `rm -rf build/my_py_pkg install/my_py_pkg` 후 `--packages-select`.
- **주의**: `rm -rf`는 되돌릴 수 없다 — 반드시 워크스페이스 루트에서, `src`를 지우지 않는지 확인하고.

## 원리·구조
```
cd ~/ros2_ws
rm -rf build install log     ← src는 절대 아님
colcon build
source install/setup.bash
```

## 코드 예시
```python
# 산출물만 지우는 클린 빌드를 임시 폴더에서 실제로 흉내
import tempfile, os, shutil
ws = tempfile.mkdtemp()
for d in ["src/my_py_pkg", "build/my_py_pkg", "install/my_py_pkg", "log/latest"]:
    os.makedirs(os.path.join(ws, d))
open(os.path.join(ws, "src/my_py_pkg/node.py"), "w").write("print('hi')\n")

for d in ("build", "install", "log"):                 # 지울 것은 셋뿐
    shutil.rmtree(os.path.join(ws, d))
print(sorted(os.listdir(ws)))                          # ['src']
print(os.path.exists(os.path.join(ws, "src/my_py_pkg/node.py")))   # True  ← 내 코드는 안전
```
