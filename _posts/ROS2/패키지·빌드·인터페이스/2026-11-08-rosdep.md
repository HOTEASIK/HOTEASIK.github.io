# rosdep

## 정의·핵심
- **정의**: package.xml에 적힌 의존성을 읽어 **apt 꾸러미 이름으로 바꿔 자동으로 깔아 주는 도구** (입문 1차시에서 이름, 실습 5차시에서 실제 사용).
- **흐름**: 만든 사람이 package.xml에 신고 → 받은 사람이 `rosdep install` → 필요한 것이 자동으로 깔림. 의존성 신고가 「다음 사람을 위한 약속」인 이유.
- **처음 한 번 초기화**: 처음 쓰면 `ERROR: your rosdep installation has not been initialized yet` 으로 멈춘다 → `sudo rosdep init` (컴퓨터당 한 번) · `rosdep update` (사용자, 가끔).
- **소스 빌드 리듬** (실습 5차시 TurtleBot3·두산 로봇): `git clone -b jazzy …` → `rosdep install --from-paths src --ignore-src -r -y` → `colcon build --symlink-install` → `source install/setup.bash`.
- **옵션 뜻**: `--from-paths src` src 아래 모든 package.xml을 읽는다 / `--ignore-src` 워크스페이스에 소스로 있는 패키지는 설치 대상에서 뺀다 / `-r` 일부 실패해도 계속 / `-y` 묻지 않고 설치.
- **자동화 흐름**: rosdep(의존성) + CI(올릴 때마다 빌드·테스트) + Docker(환경 통째로) — 그래도 실패했을 때 어디가 문제인지 짚는 건 절차를 직접 겪어 본 사람.

## 원리·구조
```
package.xml <depend>slam_toolbox</depend>
     │ rosdep 키
     ▼ rosdistro 규칙표 (rosdep update로 받음)
apt: ros-jazzy-slam-toolbox  → sudo apt install
(<depend>python3-numpy</depend> → apt: python3-numpy)
```

## 코드 예시
```python
# rosdep 키 → apt 이름 변환 + --ignore-src 흉내
rules = {"python3-numpy": "python3-numpy", "libopencv-dev": "libopencv-dev"}
def to_apt(key, distro="jazzy"):
    return rules.get(key, f"ros-{distro}-{key.replace('_', '-')}")
deps = ["rclpy", "slam_toolbox", "turtlebot3_msgs", "python3-numpy"]
in_src = {"turtlebot3_msgs"}                       # 워크스페이스에 소스로 있음
print([to_apt(d) for d in deps if d not in in_src])
# ['ros-jazzy-rclpy', 'ros-jazzy-slam-toolbox', 'python3-numpy']
```
```bash
sudo rosdep init          # 처음 한 번
rosdep update
cd ~/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
```
