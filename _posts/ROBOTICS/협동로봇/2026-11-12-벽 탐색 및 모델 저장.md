에뮬레이터 Docker 이미지(doosanrobot/dsr_emulator:3.0.1)는 이미 설치돼
  있습니다. 터미널 2개로 아래 순서대로 실행하면 됩니다.

  터미널 1: 가상 로봇 띄우기

  cd ~/ws_cobot_pjt/ws_dsr
  source install/setup.bash
  ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=virtual
  host:=127.0.0.1 port:=12345 model:=m0609
  - mode:=virtual이면 에뮬레이터 컨테이너가 자동으로 뜹니다.
  - model:=m0609는 꼭 넣어야 합니다. 빼면 기본값인 m1013으로 뜨는데, 코드는
    m0609 기준입니다.
  - RViz에 로봇이 보이고 로그가 잠잠해질 때까지 10~20초 정도 기다리세요.

  터미널 2: 벽 탐색 실행

  cd ~/ws_cobot_pjt/ws_dsr
  source install/setup.bash
  ros2 run rokey1 wall_navigation --ros-args -p mode:=virtual
  - mode의 기본값이 virtual이라 --ros-args ... 부분은 빼도 됩니다.
  - RViz에서 로봇이 격자 9곳을 차례로 찌르고, 두 줄을 따라 미끄러진 뒤 홈
    자세로 돌아갑니다.
  - 끝나면 터미널에 모델링 결과가 나오고 그림 창이 뜹니다. 그림을 닫아야
    프로그램이 끝납니다.

  옵션
  # 그림 창 없이 PNG 파일만 저장
  ros2 run rokey1 wall_navigation --ros-args -p mode:=virtual -p
  show_plot:=false

  # 탐색만 하고 모델링은 생략
  ros2 run rokey1 wall_navigation --ros-args -p mode:=virtual -p
  modeling:=false

  결과 확인 / 모델링만 다시 하기

  ls ~/wall_scan_data/          # scan_*.json, *_model.json, *_model.png
  ros2 run rokey1 wall_modeling # 가장 최근 데이터로 다시 모델링

  잘 안 될 때

  - 서비스 대기 중: ...이 계속 나올 때: bringup이 덜 떴거나 실패한 경우입니다.
    터미널 1 로그에서 에러를 확인하세요.
  - 접촉 없음이 나올 때: 가상 벽은 X=550 mm에 있습니다. WALL_GUESS_X(550)나
    VIRTUAL_WALL['x0']을 바꿨다면 두 값을 맞춰 주세요.
  - 이동 중 에러(관절 한계, 특이점 등)가 날 때: 탐색 영역이 작업 범위를 벗어난
    경우입니다. 파일 위쪽의 GRID_Y, GRID_Z, READY_J를 조금 줄여 보세요.

  에뮬레이터에서는 저도 아직 돌려보지 않았습니다. 실행하다 에러가 나면 로그를
  붙여 주세요.

  1. 세로 스캔 추가 (wall_navigation.py)

  - 기존 가로 스캔(높이 고정, Y 방향 이동)에 **세로 스캔(Y 고정, Z 방향
    이동)**을 더해, 가로 2줄과 세로 3줄이 격자 모양으로 벽을 덮습니다.
    - 설정값: SCAN_COLS_Y = [-100, 0, 100], SCAN_Z_RANGE = (300, 500)
    - 세로 줄은 열마다 방향을 바꿔(지그재그) 이동 거리를 줄였습니다.
  - 가로/세로 스캔을 하나의 함수 sliding_scan(plane, 시작(y,z), 끝(y,z), kind)로
    합쳤습니다. 실제 로봇 모드에서는 X 방향을 힘 제어가 맡기 때문에 세로로
    움직여도 벽 굴곡을 그대로 따라갑니다.
  - 점 종류를 scan_h(가로)와 scan_v(세로)로 나눠 저장합니다. 예전에 저장한 scan
    데이터도 그대로 읽힙니다.
  - 교차점 점검을 새로 넣었습니다. 가로 줄과 세로 줄이 만나는 지점에서 두 측정의
    X 값 차이를 로그로 출력하니, 실제 로봇에서 측정이 일관적인지 확인하는 데
    쓰세요.

  정확도가 나아진 점: 같은 데이터로 비교했을 때, 가로 스캔만 쓰면 위아래 방향
  휘어짐을 실제보다 약 1/3로 작게 잡았습니다(v² −2.9e-5, 같은 혹의 좌우 방향
  u²는 −9.3e-5). 세로 스캔을 더하면 v² −8.7e-5로 좌우 값과 비슷하게 맞습니다.
  다만 가상 모드는 스캔 데이터에 노이즈가 없어서, 평면 기울기(법선) 오차는 두
  경우 모두 이미 0°였습니다. 기울기 정확도 차이는 실제 로봇에서 확인해야 합니다.

  2. rviz 표시 (새 파일 wall_rviz.py)

  - 토픽은 /dsr01/wall_markers (MarkerArray)입니다. rviz에서 Fixed Frame을
    base_link로 두고, Add → By topic에서 이 토픽을 추가하면 됩니다.
  - 보이는 항목:

  ┌───────────────┬─────────────────────────────────────────────────────────┐
  │     이름      │                          내용                           │
  ├───────────────┼─────────────────────────────────────────────────────────┤
  │ probe         │ 프로빙 접촉점 (빨강)                                    │
  ├───────────────┼─────────────────────────────────────────────────────────┤
  │ scan_h /      │ 가로 스캔 점 (파랑) / 세로 스캔 점 (주황)               │
  │ scan_v        │                                                         │
  ├───────────────┼─────────────────────────────────────────────────────────┤
  │ plane /       │ 맞춘 벽 평면(반투명 초록) / 법선 화살표                 │
  │ normal        │                                                         │
  ├───────────────┼─────────────────────────────────────────────────────────┤
  │ surface       │ 휘어짐 모델 곡면. 색이 파랑이면 들어간 곳, 빨강이면     │
  │               │ 튀어나온 곳                                             │
  ├───────────────┼─────────────────────────────────────────────────────────┤
  │ outlier /     │ 이상치 점 / 평면식·평탄도 텍스트                        │
  │ info          │                                                         │
  └───────────────┴─────────────────────────────────────────────────────────┘

  - 탐색 중에는 점이 찍힐 때마다 갱신되고, 끝나면 최종 모델(곡면, 텍스트)까지
    표시됩니다. 끄려면 -p rviz:=false를 주면 됩니다.
  - 저장된 데이터를 다시 보려면 ros2 run rokey1 wall_modeling --rviz --no-show를
    실행하세요. Ctrl+C를 누를 때까지 계속 보냅니다.

  1. 가상 환경 (에뮬레이터)

  터미널 1: bringup (rviz가 같이 뜹니다)
  ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=virtual
  host:=127.0.0.1 port:=12345 model:=m0609

  rviz 설정 (탐색을 시작하기 전에 해 두세요)
  1. 왼쪽 아래 Add → By topic 탭 → /dsr01/wall_markers → MarkerArray → OK
  2. Global Options → Fixed Frame이 base_link인지 확인합니다.

  터미널 2: 탐색 실행
  ros2 run rokey1 wall_navigation --ros-args -p mode:=virtual
  - 프로빙 9점 → 가로 스캔 2줄 → 세로 스캔 3줄 순서로 진행되고, rviz에 점이
    실시간으로 찍힙니다.
  - 탐색이 끝나면 모델링을 하고, rviz에 평면, 법선 화살표, 곡면(편차 색),
    텍스트가 표시됩니다.
  - 동시에 matplotlib 그림 창도 뜹니다. 창을 닫아야 프로그램이 끝나며, 창을
    닫아도 rviz 표시는 남아 있습니다.

  2. 실제 로봇

  터미널 1: bringup
  ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=real
  host:=192.168.1.100 port:=12345 model:=m0609
  rviz 설정은 가상 환경과 똑같습니다.

  실행 전 체크 (wall_navigation.py 맨 위 설정값)
  - WALL_GUESS_X: 실제 벽보다 조금 앞으로, 줄자로 재서 맞춥니다.
  - GRID_Y, GRID_Z, SCAN_Y_RANGE, SCAN_COLS_Y, SCAN_Z_RANGE: 벽 안쪽이면서 로봇
    작업 영역 안이어야 합니다.
  - TOOL_NAME, TCP_NAME: 티칭 펜던트에 등록된 이름과 같아야 합니다.
  - 처음에는 PROBE_VEL과 FORCE_THRESHOLD를 작게 두세요.
  - 수정한 뒤에는 다시 빌드해야 합니다.

  터미널 2: 탐색 실행
  ros2 run rokey1 wall_navigation --ros-args -p mode:=real
  - [REAL] ... y 입력:이 나오면 로봇 주변을 확인하고 y를 누릅니다.
  - 멈추려면 Ctrl+C를 누릅니다. 그러면 정지 → 힘 제어 해제 → 데이터 저장 → 홈
    복귀 순서로 처리됩니다. 비상 시에는 티칭 펜던트의 비상정지를 쓰세요.

  3. 저장된 모델 다시 띄우기

  데이터는 ~/wall_scan_data/scan_날짜_시간.json에 저장되고, 결과는
  _model.json과 _model.png 파일로 나옵니다.

  # 가장 최근 데이터 → 그림 창
  ros2 run rokey1 wall_modeling

  # 가장 최근 데이터 → rviz에 표시 (Ctrl+C 할 때까지 계속 보냄)
  ros2 run rokey1 wall_modeling --rviz --no-show

  # 특정 파일 지정 + 그림 창 + rviz
  ros2 run rokey1 wall_modeling ~/wall_scan_data/scan_20261112_101010.json
  --rviz
  --rviz와 그림 창을 함께 쓰면 그림 창을 닫은 뒤부터 rviz로 보내기 시작합니다.
  rviz로 바로 보려면 --no-show를 붙이세요.

  자주 쓰는 옵션 (wall_navigation)

  ┌─────────────────────┬──────────────────────────────┐
  │        옵션         │             설명             │
  ├─────────────────────┼──────────────────────────────┤
  │ -p show_plot:=false │ 그림 창 없이 PNG 파일만 저장 │
  ├─────────────────────┼──────────────────────────────┤
  │ -p rviz:=false      │ rviz 표시 끄기               │
  ├─────────────────────┼──────────────────────────────┤
  │ -p modeling:=false  │ 탐색만 하고 모델링은 생략    │
  └─────────────────────┴──────────────────────────────┘

  예시:
  ros2 run rokey1 wall_navigation --ros-args -p mode:=virtual -p
  show_plot:=false

  rviz에 아무것도 안 보일 때

  - Fixed Frame이 base_link인지 확인하세요.
  - 탐색이 끝난 뒤에 rviz를 켰다면 MarkerArray Display → Topic → Durability 
    Policy를 Transient Local로 바꾸거나, wall_modeling --rviz로 다시 띄우세요.
  - 토픽이 실제로 나오는지는 ros2 topic echo /dsr01/wall_markers --once로
    확인할 수 있습니다.
  - MarkerArray 항목을 펼치면 Namespaces(probe, scan_h, scan_v, plane, surface
    등)를 체크박스로 하나씩 켜고 끌 수 있습니다.
