# 정의
두산 로봇틱스 랭귀지 
- 파이썬 기반
- ‘Custom Code’를 사용하여 DRL 명령어를 사용 가능

# 특징 
태스크 작성기(Task Writer)의 `Custom Code` 명령어를 통해 싱글 라인(한 줄 작성) 또는 스크립트(.txt) 파일을 불러와 정의하고 실행할 수 있습니다.

DRL (Doosan Robot Language) 개요

* **정의**: DRL은 Python 문법을 기반으로 제작된 두산 로봇 제어 전용 프로그래밍 언어 및 라이브러리입니다.
* **특징**: 
  * Python 기반 문법을 따르나, 일반 Python의 모든 제어 기능과 문법 구조를 100% 지원하지는 않는 로봇 전용 스크립트 언어입니다.
  * 직관적인 함수 호출 방식으로 모션, I/O, 좌표계 제어 및 대기/정지 처리가 가능합니다.
* **사용 방법**: 
  * 태스크 작성기(Task Writer)의 `Custom Code` 명령어를 통해 한 줄(Single Line) 코드를 직접 입력할 수 있습니다.
  * 별도의 스크립트 파일(`.txt` 등) 형태로 작성된 전체 프로세스 코드를 불러와 실행할 수 있습니다.

## 2. DRL 주요 제어 함수 및 명령어 분류

### 2.1 모션 및 이동 관련 함수

| 함수 명칭 | 주요 매개변수 | 설명 및 특징 |
| :--- | :--- | :--- |
| `movej()` / `amovej()` | `pos, v, a, t, radius` | 조인트 좌표 기반 최단 거리 이동 (a 접두어: 비동기/Async 실행) |
| `movel()` / `amovel()` | `pos, v, a, t, radius` | 직교 좌표(TCP) 기반 직선 이동 |
| `movec()` / `amovec()` | `pos1, pos2, v, a, t, radius` | 경유점(`pos1`) 및 목표점(`pos2`) 기반 원호 보간 이동 |
| `mwait()` | `time` | 선행 비동기 모션 완료 시까지 대기 (`mwait(0)` 적용 시 동기화 전환) |

### 2.2 I/O 및 환경 설정 함수 (Set Commands)

| 함수 명칭 | 주요 매개변수 | 설명 및 비고 |
| :--- | :--- | :--- |
| `set_digital_output()` | `index, val` | 컨트롤러 디지털 출력 접점(1~16번)의 ON/OFF(`1/0`) 제어 |
| `set_tool_digital_output()` | `index, val` | 툴 플랜지 디지털 출력 접점(1~6번)의 ON/OFF(`1/0`) 제어 |
| `set_tool()` / `set_tcp()` | `name` | 미리 등록된 툴 무게/TCP 명칭 지정 |
| `set_ref_coord()` | `coord` | 기준 좌표계 설정 (`DR_BASE`, `DR_WORLD`, `DR_TOOL`, 사용자 좌표계) |
| `change_operation_speed()` | `speed` | 작업 속도를 상대적 비율(10%~100%)로 실시간 감속 제어 |

### 2.3 대기 및 조건 처리 함수 (Wait Commands)

| 함수 명칭 | 주요 매개변수 | 설명 및 타임아웃 반환값 |
| :--- | :--- | :--- |
| `wait_digital_input()` | `index, val, timeout` | 컨트롤러 디지털 입력 조건 충족 시까지 대기 (성공: `0`, 타임아웃: `-1`) |
| `wait_tool_digital_input()` | `index, val, timeout` | 툴 플랜지 디지털 입력 조건 충족 시까지 대기 |
| `wait_analog_input()` | `ch, condition, val, timeout` | 아날로그(전압/전류) 신호 조건 충족 시까지 대기 |

### 2.4 감속 정지 및 상태 제어 함수 (Stop Commands)

| 정지 모드 (`st_mode`) | 정지 동작 및 특성 |
| :--- | :--- |
| `DR_QSTOP` | Quick Stop: 시스템 최대 감속도로 즉시 감속 정지 |
| `DR_SSTOP` | Soft Stop: 표준 감속 시간의 약 1.5배 속도로 부드럽게 감속 정지 |
| `DR_QSTOP_STO` | Safe Torque Off 없이 Quick Stop 감속 정지 수행 |

### 2.5 티치펜던트 사용자 인터페이스 함수

| 함수 명칭 | 주요 매개변수 | 설명 및 활용 예시 |
| :--- | :--- | :--- |
| `tp_popup()` | `msg, pop_type` | 티치펜던트 화면에 알림/경고 팝업 표시 (`.format()` 변수 바인딩 가능) |
| `tp_log()` | `msg` | 스크립트 실행 중 변수 데이터 및 로그 상태 기록 |

## 3. 로봇 모션(Move) 제어 종합 비교표

| 명령어 | 보간 방식 | 경로 특징 | 동기/비동기 | 블렌딩(Radius) | 주요 용도 및 특성 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Move J** | Joint (관절) | 각 관절 최단 거리 | Sync / Async | 지원 | - 원거리 빠른 이동 및 기본 자세 변경<br>- 빠름 (최대 $1\text{ m/s}$ 이상)<br>- 특이점(Singularity) 영향 없음 |
| **Move L** | Task (직교) | 직선 (TCP 유지) | Sync / Async | 지원 | - 근거리 접근/이탈 및 협소 지역 이동<br>- 상대적으로 느림 (최대 $1\text{ m/s}$)<br>- 특이점 영역 진입 시 주의 필요 |
| **Move C** | Task (직교) | 원호/원형 경로 | Sync / Async | 지원 | - 3점($P_0, P_1, P_2$) 구속 기반 원호 보간 이동<br>- 회전 각도 및 자세 구속 옵션 제공 |
| **Move Spiral** | Task (직교) | 나선형 궤적 | Sync / Async | 제한적 | - 중심에서 외곽으로 확장되는 나선 모션<br>- Hole Search, Air Blowing, 세척 등 |
| **Move Periodic**| Task (직교) | 주기적 왕복/회전 | Sync / Async | 제한적 | - 지정 축/방향 진폭과 주기로 왕복 모션<br>- Air Blowing, Shaking, 기어 조립 등 |
| **Move SX** | Task (직교) | 태스크 스플라인 | Sync / Async | 미지원 | - 직교 공간 경유점 연결 곡선 (최대 50 Segment)<br>- mwait 처리 필요 |
| **Move SJ** | Joint (관절) | 관절 스플라인 | Sync / Async | 미지원 | - 관절 공간 경유점 연결 곡선 (최대 50 Segment)<br>- mwait 처리 필요 |
| **Move B** | Task (직교) | 연속 등속 궤적 | Sync / Async | 자체 처리 | - 직선/원호 구간 자동 블렌딩 (최대 100 Segment)<br>- 글루잉(Gluing), 실링(Sealing) 작업용 |
| **Move JX** | Task-Joint | 특이점 회피 궤적 | Sync / Async | 지원 | - 직교 공간 이동 시 Joint 보간 적용<br>- 선형 이동 시 특이점 회피 및 자세 제어 |

## 4. 이동 옵션 및 동작 처리 메커니즘

### 4.1 동기(Sync) 및 비동기(Async) 실행 비교
* **동기 (Sync)**: 선행 모션 명령이 완전히 완료되어 목표 위치에 도달한 후 다음 스크립트 코드 라인을 순차적으로 실행합니다.
* **비동기 (Async)**: 모션 명령이 시작됨과 동시에 다음 코드 라인(신호 출력, 조건 검사 등)을 병렬적으로 즉시 실행합니다.

### 4.2 블렌딩 (Blending) 및 라운딩 반경 (Radius)
* **개념**: 정지 동작 없이 코너 구간을 부드럽게 라운딩하여 택타임(Cycle Time)을 단축시키는 기능입니다.
* **제약 조건**: 설정 가능한 최대 반경 값은 해당 구간 이동 거리의 $1/2$을 초과할 수 없습니다.
  $$\text{Radius}_{\text{max}} \le \frac{\text{Path Length}}{2}$$

### Exit 
태스크 프로그램을 종료
태스크 종료와 관련된 일반 출력 신호인 ‘Task Operating’을 활용하여 외부장비에서 태스크가 종료되었음을 확인 가능




### Thread 명령어
-  thread : thread 생성
- run thread : thread command로 선언된 thread  호출
- kill thread : run thread command 로 실행된 thread 종료
