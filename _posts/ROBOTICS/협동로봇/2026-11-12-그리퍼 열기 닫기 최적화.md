# RG2 그리퍼 설정법
웹브라우저를 띄워서 주소창에 192.168.1.1 을 입력한다

디바이스 탭에서 RG2를 선택한다.

우측 상단 언어설정 EN을 KR로 변경한다.

장치탭에서 그리퍼를 테스트 할수 있다, 너비와 포스값을 변경하면서 그리퍼의 동작을 테스트한다.


장치에서 그리퍼의 상태정보 그리퍼의 눌림버튼이 눌렸을때 어떤 스위치가 눌렸는지 확인이 가능하고 복구하는 전원사이클 버튼이 있다. 스위치 버튼이 눌려 그리퍼가 동작하지 않는경우 전원사이클 버튼을 눌러 빠져 나올수 있다.


아래의 네트워크 설정정보를 확인한다.

그리퍼는 입력 2핀, 출력 핀 총 4가지의 동작을 제어할수 있다.

이외에도 조건값 설정을 통해 그리퍼의 상태 정보에 따른 컨트롤러의 output값을 4가지로 입력받을수 있다.


그리퍼 설정이 완료되면 저장버튼을 눌러 설정을 저장한다.

그리고 우측상단의 작동버튼을 눌러 그리퍼가 실행할수 있도록 설정한다.

작동버튼이 정지 버튼으로 변경되면 그리퍼의 제어를 할수 있게 된다.

동작상태로 변경된 화면

그리퍼의 TCP설정값은 아래 TCP(툴중심점) 값을 이용하시기 바랍니다.

실제 무게와 두산로봇에서 체크한 값을 비교해 보세요.

**`grip == true`**

**사용자가 WebLogic에서 조건을 설정해서 만드는 값이 아니라, RG2 그리퍼 내부에서 자동으로 판단하는 상태값**입니다.

RG2는 다음과 같은 정보를 내부적으로 사용합니다.

- 모터의 위치(그리퍼가 얼마나 닫혔는지)
- 모터 전류(얼마나 큰 힘이 걸렸는지)
- 목표 폭(Target Width)과 실제 폭(Actual Width)
- 설정한 Grip Force

이 정보들을 이용하여 **"물체를 만나서 정상적으로 파지했다"**고 판단하면 `grip_detected`(`grip == true`)를 내부 펌웨어가 자동으로 설정합니다.

### 예를 들어

목표 폭을 50 mm로 명령했다고 가정하면

#### 물체가 없는 경우

```
명령 : 50 mm까지 닫아라
실제 : 50 mm까지 그대로 닫힘
모터 전류 : 낮음

→ 물체가 없음
→ grip = false
```

#### 물체가 있는 경우

```
명령 : 50 mm까지 닫아라
실제 : 63 mm에서 멈춤
모터 전류 : 증가

→ 중간에서 물체를 만남
→ grip = true
```

즉, **"목표 위치까지 가지 못하고 물체 때문에 멈췄으며 충분한 힘이 발생했다"**는 것을 내부 알고리즘이 감지하는 것입니다.

### WebLogic의 역할

정지후 설정 가능 

WebLogic에서 설정하는 것은 보통

- `grip == true`이면 다음 단계 실행
- `lost_grip == true`이면 알람 발생
- `width < xx`이면 분기

와 같은 **조건을 사용하는 것**이지,

```
width > 30 이면 grip=true
```

처럼 `grip` 값을 사용자가 정의하는 것은 아닙니다.

## 브라우저
상황별 여러가지 이름으로 설정값을 만듬

## 프로그램 에디터
세부 설정 값 조정

### 언제 false가 될 수 있나?

예를 들어 매우 얇은 종이나 스펀지처럼 물체를 잡았더라도

- 설정한 힘이 너무 낮거나
- 물체가 너무 부드러워 모터 부하가 충분히 증가하지 않거나
- 감지 임계값에 도달하지 못하면

실제로는 물체를 잡고 있어도 `grip == false`가 될 수 있습니다. 반대로 정상적인 강성을 가진 물체라면 내부 알고리즘이 자동으로 `true`를 반환합니다.

즉, **`grip == true`는 OnRobot RG2의 펌웨어가 센서와 모터 정보를 바탕으로 자동으로 계산하는 결과**이며, 사용자가 WebLogic에서 임계값을 직접 설정해서 만드는 값은 아닙니다.

다만 WebLogic에서는 이 결과를 조건으로 활용해 공정 흐름을 제어할 수 있습니다.

# **그리퍼 닫기**

- **set_digital_outputs([1,-2])**
        - **디지털 출력 (DO):** 로봇이 외부 장치로 보내는 **명령 신호**(ON/OFF 또는 1/0 값)
        - **`[1, -2]`의 의미:** 이 배열은 디지털 출력 포트의 번호와 값을 쌍으로 지정
            - **`1`**: `DO 1` 포트의 값을 **ON (High, 1)**으로 설정
            - **`-2`**: `DO 2` 포트의 값을 **OFF (Low, 0)** 으로 설정
        - **그리퍼와의 관계**
            - 이 코드의 경우, **`DO 1 = ON, DO 2 = OFF`** 조합이 '그리퍼 닫기'에 해당하도록 그리퍼가 배선 및 설정되어 있음을 의미
            - Weblogic의 설정에 의해서 결정됨.


# **그리퍼 열기**

   - **set_digital_outputs([-1,2])**
        - **디지털 출력 (DO):** 로봇이 외부 장치로 보내는 **명령 신호**(ON/OFF 또는 1/0 값)
        - **`[-1, 2]`의 의미:** 이 배열은 디지털 출력 포트의 번호와 값을 쌍으로 지정
            - **`-1`** : `DO 1` 포트의 값을 **OFF (Low, 0)** 으로 설정
            - **`2`**: `DO 2` 포트의 값을 **ON (High, 1)**으로 설정
        - **그리퍼와의 관계**
            - 이 코드의 경우, **`DO 1 = OFF, DO 2 = ON`** 조합이 '그리퍼 열기'에 해당하도록 그리퍼가 배선 및 설정되어 있음을 의미
            - Weblogic의 설정에 의해서 결정됨.

# **그리퍼 열고/ 닫을 때 기다리기**
- **wait_digital_input(index=1, val=ON, timeout=5):**
        - 로봇의 **디지털 입력(TDI)** 포트를 모니터링하여 그리퍼가 명령을 성공적으로 수행했는지 **피드백을 기다리는 역할**
            
            **디지털 입력 (TDI):** 외부 장치(그리퍼)가 로봇에게 보내는 **상태 피드백 신호**
            
        - **`index=1`**: **`DI 1`** 포트의 상태를 확인하라는 의미
            
            - 이 그리퍼는 **열림 상태**를 TDI1을 통해 보고하도록 연결되어 있음을 의미
        - **`val=ON`**: `DI 1` 포트의 값이 **ON (High, 1)**이 될 때까지 기다리라는 의미
            
            - 즉, 그리퍼가 완전히 열렸을 때 DI1 신호가ON이 된다는 뜻
        - **`timeout=2.5`**: 만약 2.5초 이내에 DI1 신호가 ON으로 바뀌지 않으면 **오류(에러)를 발생**시키고 대기를 중단하라는 의미

``` python
#그리퍼 닫기
set_digital_outputs([1,-2])
ret = wait_digital_input(index=1, val=ON, timeout=5)
tp_log("그리퍼 닫기:{}".format(ret==0))

#그리퍼 열기
set_digital_outputs([-1,2])
```

# 코드
```python
# pick and place in 1 method. from pos1 to pos2 @20241104
import rclpy
import DR_init
import time

# for single robot
ROBOT_ID   = "dsr01"
ROBOT_MODEL= "m0609"
VELOCITY, ACC = 30, 30

DR_init.__dsr__id   = ROBOT_ID
DR_init.__dsr__model= ROBOT_MODEL

ON, OFF = 1, 0
CYCLE = 3
CHECK_INTERVAL = 0.1


def main(args=None):
    rclpy.init(args=args)
    node = rclpy.create_node("rokey_grip_simple", namespace=ROBOT_ID)

    DR_init.__dsr__node = node

    try:
        from DSR_ROBOT2 import (
        # drl 명령어
            set_digital_output,
            get_digital_input,
            set_tool,
            set_tcp,
            movej,
            wait,
        )

        from DR_common2 import posj

    except ImportError as e:
        node.get_logger().info(f"Error importing DSR_ROBOT2 : {e}")
        return

    set_tool("Tool Weight_1")
    set_tcp("GripperDA_v1")


    def grip():
        node.get_logger().info("set for digital output 1 0 for grip")
        set_digital_output(1, OFF)
        set_digital_output(2, OFF)
        set_digital_output(1, ON)
        set_digital_output(2, OFF)
        #wait(1)
        time.sleep(1)

    def release():
        node.get_logger().info("set for digital output 0 1 for release")
        set_digital_output(1, OFF)
        set_digital_output(2, OFF)
        set_digital_output(1, OFF)
        set_digital_output(2, ON)
        wait(1)
     
    homej = posj([0, 0, 90, 0, 90, 0])

    node.get_logger().info(f"Moving to joint position: {homej}")
    movej(homej, vel=VELOCITY, acc=ACC)

    try:
        for i in range(CYCLE):
            node.get_logger().info(f"=== Cycle {i+1}/{CYCLE} ===")

            grip()
            release()
            wait(1)

        node.get_logger().info("Gripper Test Complete")

    except KeyboardInterrupt:
        node.get_logger().info("Program Stopped")
    except TimeoutError as e:
        node.get_logger().error(str(e))

    finally:
        try:
            movej(homej, vel=VELOCITY, acc=ACC)
        except Exception as e:
            node.get_logger().error(f"Failed to move home: {e}")

        node.destroy_node()
        rclpy.shutdown()


if __name__ == "__main__":
    main()


```
