# 테이프 끝단 탐색 (비전 없이 접촉 기반)

카메라 없이 **접촉 기반 탐색(Tactile Exploration)** 으로 양생 테이프 롤의 끝단을 찾아 떼어내는 작업.
관련: [[장비 및 제약 사항]], [[26_11_10]]

---

## 1. 작업 조건 (결정 사항)

| 항목 | 내용 |
|---|---|
| 로봇 / 그리퍼 | Doosan M0609 + OnRobot RG2 (DO1/DO2 로 열기·닫기) |
| Tool / TCP | `Tool Weight` / `GripperDA_v1` |
| 테이프 | 양생 테이프, 폭 **50mm** |
| 롤 치수 | 바깥지름 **40mm** (R=20mm), 심지 지름 **35mm** |
| 거치 방식 | 휴지걸이처럼 **축(지름 10mm)** 에 걸림, 축은 **BASE Y 축과 평행** |
| 롤 회전 | 빡빡해서 잘 안 도는 편 |
| 끝단 상태 | **1~2cm 정도 들떠 있음**, 위치는 둘레 어딘가 |
| 탐색 범위 | 로봇은 롤 윗부분(약 ±60°)만 훑을 수 있음 → **끝단을 윗부분에 오게 거치** |
| 도구 | RG2 손가락 끝으로 먼저 시도 → 안 걸리면 헤라 (잡기→들기→내려놓기→그립) |
| 범위 | 감지 → 그립 → 떼어내기 전체 |

---

## 2. 핵심 원리

- 테이프 끝단 높이 차이(0.05~0.15mm)는 **로봇 위치값만으로는 구분하기 어려움**
- 대신 끝단을 감긴 반대 방향으로 훑을 때 걸리면서 생기는 **진행 방향 힘 스파이크**를 감지

### 탐색 자세: 접선 자세

```
        진행 방향 ←
   ┌────┐  위 손가락 ═══╗
   │ RG2│               ║  ← 들뜬 끝단(flap)
   └────┘  아래손가락 ═══╝/
  ─────────────────────────── 롤 표면 (원호)
```

1. 그리퍼를 롤 **접선 방향**으로 눕히고 손가락을 벌림. 손가락 벌림 방향 = 롤 반지름 방향
2. 아래 손가락 끝은 표면에 거의 닿게 → 원호를 따라 진행하며 **Tool Z 반력** 감시
3. 들뜬 끝단 밑으로 아래 손가락이 들어가고, 뿌리에 닿으면 반력 증가 → **정지 → 그리퍼 닫기**
4. 진행 반대 방향(Tool -Z)으로 당겨 떼어내기

> 감지와 그립을 **한 자세**로 처리할 수 있어서 동작이 적다.

> [!warning] 롤이 작아서(R=20mm) 곡률이 큼
> 접선에서 5mm만 벗어나도 표면과 약 0.6mm 벌어진다 → 원호를 정확히 따라가야 하고, 그래서 **롤 중심 보정(probe)** 이 필요.

---

## 3. 전체 진행 순서

1. **모델링**: 롤을 URDF 로 만들어 RViz 에 표시 ✅
2. **위치 측정**: teach(티칭) / probe(접촉) 로 롤 중심 측정 ✅ (에뮬레이터 경로 확인까지)
3. **탐색**: 보정한 모델 기준으로 원호를 따라 훑으며 힘 로그 확인 → 임계값 결정
4. **감지 + 그립 + 떼어내기**

## 5. 테이프 모델 (URDF)

### 프레임
- `base_link`: 로봇 BASE (이름을 같게 해서 로봇 TF 트리에 붙음)
- `tape_holder`: **롤 폭 가운데의 축 중심**. 롤 회전축 = 로컬 Y, 위쪽 = 로컬 Z
- `tape_flap`: 들뜬 끝단 뿌리. 꼭대기(+Z)에서 Y 축 기준 `flap_angle` 만큼 회전한 위치

### launch 인자 (단위: **m, rad**)

| 인자 | 기본값 | 비고 |
|---|---|---|
| `x`, `y`, `z` | 0.5, 0.0, 0.2 | 축 중심 위치 |
| `yaw` | 0.0 | 0 = 축이 BASE Y 와 평행 (실측) |
| `outer_d` | 0.040 | 실측 |
| `core_d` | 0.035 | 실측 |
| `width` | 0.050 | 테이프 폭 |
| `shaft_d` | 0.010 | 실측 |
| `shaft_len` | 0.080 | |
| `flap_angle` | 0.0 | 끝단 위치 |
| `flap_len` | 0.015 | 들뜬 길이 |
| `flap_lift` | 0.3 | 들린 각도 |

### 띄우는 방법

```bash
cd ~/ws_cobot_pjt/ws_dsr
colcon build --packages-select rokey1
source install/setup.bash

# 터미널 1: 로봇
ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=real host:=192.168.1.100 model:=m0609

# 터미널 2: 테이프 모델
ros2 launch rokey1 tape_display.launch.py x:=0.45 y:=0.05 z:=0.18
```

RViz: **Add → RobotModel → Description Topic = `/tape/robot_description`**, Fixed Frame = `base_link`

## 6. 롤 중심 측정: `tape_locate`

결과는 둘 다 `~/tape_model/tape_roll.json` 에 저장되고, 그 값으로 띄우는 `tape_display` 명령이 출력된다.

### teach 모드
```bash
ros2 run rokey1 tape_locate teach                 # TCP 를 롤 폭 가운데의 축 중심에 맞춘 상태
ros2 run rokey1 tape_locate teach --y-offset 25   # 축 끝에 맞췄다면 Y 차이(mm)
```

### probe 모드
```bash
ros2 run rokey1 tape_locate probe                       # teach 로 저장한 값을 대략값으로
ros2 run rokey1 tape_locate probe --center 500 0 200    # 대략값 직접 입력 (mm)
```

- XZ 평면에서 **-90°, -45°, 0°, +45°** (0° = 꼭대기, 음수 = 로봇 쪽 -X) 방향으로 5mm/s 접근
- 힘 변화량 > **3N** 이면 접촉으로 보고 정지 → TCP 위치 기록
- 4점 **최소자승 원 피팅** → 중심 x, z 보정 (y 는 대략값 유지)
- 피팅 반지름 = 롤 반지름 + 손끝 두께 → **중심은 정확, 반지름은 확인용**
- 표면에서 30mm 밖에서 출발, 표면 안쪽 10mm 까지 가도 접촉 없으면 오류

| 파라미터 | 값 |
|---|---|
| `PROBE_ORI` | `[0, 180, 0]` ⚠ 임시값 |
| `START_GAP` / `MAX_DEPTH` | 30mm / 10mm |
| `SAFE_DZ` | 60mm (롤 꼭대기 위 여유 높이) |
| `PROBE_VEL` | 5 mm/s |
| `FORCE_THRESHOLD` | 3N |

원 피팅 검증: 위치 오차 0.1mm 노이즈를 넣은 가짜 점 → 중심 오차 약 0.3mm 이내.

## 7. 끝단 탐색: `tape_peel` (초안)

1. 홈 → 그리퍼 열기 → `P_START` 위 → `P_START`
2. 기준 Tool Fz 저장
3. `amovec(P_MID, P_END)` 10mm/s 로 원호 진행하며 `dF` 로그
4. `|dF| > FORCE_THRESHOLD` 이면 `move_stop` 으로 정지
5. 그리퍼 닫기 → Tool -Z 로 80mm 당기기
6. 못 찾으면 접근 위치로 후퇴

> [!note] 앞으로 바꿀 것
> 지금은 원호 3점(`P_START/MID/END`)을 티칭하는 방식이다. 롤 중심 보정이 끝나면 **모델에서 원호를 계산**하도록 바꿀 예정. 현재 3점 값은 0 이라 **그대로 실행하면 안 됨**.

## 8. 트러블슈팅

| # | 증상 | 원인 | 해결 |
|---|---|---|---|
| 1 | (잠재) 접촉 감지해도 안 멈춤 | `move_stop` 서비스 경로 오류: `/dsr01/motion/move_stop` | `dsr_controller2/motion/move_stop` 로 수정 (`tape_locate`, `tape_peel`) |
| 2 | probe 실행해도 로봇이 안 움직임 | 관절 전부 0 자세(특이점)에서 `movel` 실패, 반환값 무시 | 시작할 때 `movej(HOME)` 추가, `movel` 실패 시 예외 |
| 3 | 로그가 안 보이고 timeout 으로 끝남 | 강제 종료 시 출력 버퍼 유실 | `PYTHONUNBUFFERED=1 RCUTILS_LOGGING_BUFFERED_STREAM=0` |
| 4 | 1회 200초 timeout | 원인 미확인 (재실행 시 정상) | 재발하면 확인 |

> [!tip] DSR_ROBOT2 에는 `stop()` 함수가 없다
> `dsr_msgs2/srv/MoveStop` 서비스를 직접 호출 (`stop_mode = DR_QSTOP`).

> [!tip] 서비스 경로
> 컨트롤러 서비스는 `/dsr01/dsr_controller2/...` 아래에 있다.
> ```bash
> ros2 service call /dsr01/dsr_controller2/aux_control/get_current_posx dsr_msgs2/srv/GetCurrentPosx "{ref: 0}"
> ```

### 에뮬레이터 probe 결과
홈 → -90° 위 → 출발점 → 접근 (롤이 없으니 접촉 없음) → 10mm 들어간 뒤 후퇴 → "접촉 없음" 오류.
최종 위치 **(450, 0, 280)mm** = 계산한 위치와 일치 → **경로 정상**.
