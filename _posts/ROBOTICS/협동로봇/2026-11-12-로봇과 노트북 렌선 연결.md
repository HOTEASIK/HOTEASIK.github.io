## 1. 두산로봇 티칭펜던트에서 설정 확인

```
Settings → Network
설정    --> 네트워크
```

들어가서 컨트롤러 IP를 확인합니다.


```
ip 주소 : 192.168.1.100  ## 기본 설정
게이트웨이: 192.168.1.1
서브넷마스크: 255.255.255.0 
을 사용합니다. 
```

## 2. 랜선 연결 후 IP 확인

PC도 같은 대역으로 설정해야 합니다.

우분투 —> 프로그램표시 —> 설정 —> 네트워크

LAN 고정

유선 연결됨 —> ipv4(탭)


```
교육생 ip주소: 192.168.1.20
네트워크 마스크 : 255.255.255.0
게이트웨이 : 192.168.1.1
```

우분투 설정을 저장한다.

그리고 노트북 터미널에서:

```bash
ping 192.168.1.100
```

이 정상적으로 응답해야 합니다.


### 위의 명령이 반응이 없을경우 실행

ping 192.168.137.100

위에서 네트워크 설정이 192.168.137.100 으로 설정되어 있는 경우가 있을수 있습니다

이경우에는 TP 설정을 확인해서 192.168.1.100으로 수정해 보시기 바랍니다.

## 3. launch를 real로 변경

- Virtual에서 실행

```bash
source ~/ws_cobot_pjt/ws_dsr/install/setup.bash

### Virtual 모드 (시뮬레이션)
# 브링업 (두산로봇 m0609 + 그리퍼)
ros2 launch m0609_rg2_bringup bringup.launch.py
```

- 실제 로봇은 : mode:=real 사용, host:=실제로봇 컨트롤러의 ip설정값을 사용합니다.

현재는 192.168.1.100으로 설정되어 있습니다.

```bash

source ~/ws_cobot_pjt/ws_dsr/install/setup.bash

### Real 모드 (실제 로봇)

# 브링업 (두산로봇 m0609 + 그리퍼)
ros2 launch m0609_rg2_bringup bringup.launch.py mode:=real host:=192.168.1.100 model:=m0609
```

## 4. TP에서 제어권 확인

launch가 성공하면 티치펜던트에

```
제어권 강제회수
```

팝업이 뜨면서 제어권이 ROS2로 넘어갑니다. 이게 안 뜨면 실제 제어가 안 됩니다.

## ⚠️주의

Virtual에서 문제없이 동작했다고 해서 Real에서도 바로 안전한 것은 아닙니다.

특히 DRL에:

```
movej(...)
movel(...)
```

이 있으면 Real 모드에서는 실제 M0609가 즉시 움직입니다.

```python
set_velj(30)
set_accj(30)
```

처음에는 속도를 낮춰 실행하고, 동작에 문제가 없으면 원하는 속도로 올린다.
