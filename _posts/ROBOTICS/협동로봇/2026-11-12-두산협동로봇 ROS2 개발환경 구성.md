## 1. 댄스만 다시 실행 (bringup은 그대로)
```bash
source ~/.bashrc     # alias 로드 (새 터미널이면 생략 가능)
sod
ros2 run dsr_example dance
```

## 2. bringup부터 다시 실행
터미널 1
```bash
source ~/.bashrc
newgrp docker       # 도커 권한이 없을 때 permission denied 방지
sodvir              # virtual bringup (에뮬레이터 포함)
```
터미널 2
```bash
source ~/.bashrc
sod
ros2 run dsr_example dance
```

## 참고
- bringup이 돌고 있는데 `sodvir`를 다시 켜면 이전 에뮬레이터 컨테이너는 launch가 지워 주지만, 옛 노드가 남아 충돌할 수 있다. 기존 bringup을 끄고 다시 여는 게 낫다.
- `sodreal`은 실제 로봇용 (`host:=192.168.1.100`)
