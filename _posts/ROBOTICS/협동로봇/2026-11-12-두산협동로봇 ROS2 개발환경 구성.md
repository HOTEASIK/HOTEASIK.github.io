## 참고 자료
https://app.notion.com/p/1-389478936edf8075a4e6c218d6cebded?p=389478936edf801e9846dee3576a5eb2&pm=s

1) 댄스만 다시 실행 (가장 간단 — bringup은 그대로)
새 터미널에서:
source ~/.bashrc     # alias 로드 (새 터미널이면 생략 가능)
sod
ros2 run dsr_example dance
2) bringup부터 통째로 다시 실행
터미널 1:
source ~/.bashrc
newgrp docker       # 도커 권한이 없으면 permission denied 방지
sodvir              # virtual bringup (에뮬레이터 포함)
터미널 2:
source ~/.bashrc
sod
ros2 run dsr_example dance
참고
- 이미 돌고 있는 bringup이 있을 때 sodvir를 다시 켜면 이전 에뮬레이터 컨테이너는 launch가 자동으로 지우지만, 옛 노드가 남아 충돌할 수 있어서 되도록 기존 bringup을 끈 뒤 다시 여는 게 좋아요.
- sodreal은 실제 로봇용(host:=192.168.1.100).
- 지금 실행 중인 bringup와 dance는 제가 백그라운드로 띄워둔 것이라, 중단이 필요하면 말씀해 주세요.
