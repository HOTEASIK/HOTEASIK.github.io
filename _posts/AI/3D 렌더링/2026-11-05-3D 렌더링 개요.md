# 3D 렌더링 개요

## 정의·핵심
- **목표 (응용 9차시)**: **인간의 시각 체계를 모사하는 가상 세계**를 만드는 것
  - "**광원이 빛을 방출하고, 물체가 반사하고, 카메라가 이를 받아들이는 과정을 계산**"
- **가상 세계 구성 5단계 (강의)**
  1. **가상 카메라 배치**: 시점과 보는 방향 설정 → [[가상 카메라]]
  2. **픽셀 그리드 삽입**: 화면 평면 구성
  3. **오브젝트 배치**: 3D 물체 생성 → [[Polygon·Mesh]]
  4. **광원 추가**: 빛과 그림자 연산
  5. **최종 렌더링**: 이미지 생성 완료
- **2D vs 3D (강의)**

| 항목 | 2D | 3D |
|---|---|---|
| 좌표계 | X, Y 축만 | X, Y, **Z(깊이)** 축 |
| 특징 | 평면 (Flat Surface), 깊이 없음 | 입체 공간 (Volume) |
| 원근감 | 표현 한계 | 거리에 따른 원근감 발생 |
| 시점 | 고정 | **카메라 위치에 따라 모습 변화** |
| 비유 | 종이 위 점 (x, y) | 상자 속 점 (x, y, z) |

- **활용 분야 (강의)**: 게임 그래픽(실시간 렌더링, 물리 엔진) · 메타버스(아바타) · 영화/광고 CG(VFX, 오프라인 고품질) · AR/VR(몰입형) · 건축/설계(디지털 트윈) · **자율주행 시뮬레이션**(가상 환경 주행 학습)
- **AI 3D 복원 흐름**: 현실 세계 → 카메라 촬영 → **3D 복원(NeRF)** → 가상 세계 재현 → [[NeRF]]
- **기술 흐름 (강의 요약)**: 3D 좌표계 정의 → 카메라 모델 → 삼각형/메시(전통) → **Ray Casting**(광선 추적·충돌) → **NeRF**(신경망 볼륨 렌더링) → **Gaussian Splatting**(실시간 점 기반) → [[Ray Casting]], [[Gaussian Splatting]]
- **실습 팁 (강의)**: 작은 장면으로 Tiny NeRF부터 / **Camera Pose(위치·방향) 정확도**가 렌더링 품질을 결정짓는 가장 중요한 요소

## 수식·원리
```
렌더링:  3D 장면(물체, 재질, 광원) + 카메라  →  2D 이미지
원근 투영 (핀홀):  u = f · X / Z + c_x,    v = f · Y / Z + c_y
→ 같은 크기라도 Z(깊이)가 2배면 화면에서 1/2 크기
```

## 코드 예시
```python
import numpy as np

f, cx, cy = 100.0, 64.0, 64.0                              # 초점거리, 화면 중심 (128×128)
def project(P):                                            # 3D 점 → 2D 픽셀 (원근 투영)
    X, Y, Z = P.T
    return np.stack([f * X / Z + cx, f * Y / Z + cy], 1)

cube = np.array([[x, y, z] for x in (-1, 1) for y in (-1, 1) for z in (4, 6)], dtype=float)   # 정육면체 꼭짓점
uv = project(cube)
near, far = uv[cube[:, 2] == 4], uv[cube[:, 2] == 6]
print(np.ptp(near[:, 0]), round(float(np.ptp(far[:, 0])), 1))   # 50.0 33.3  가까운 면이 더 크게 (원근감)

img = np.zeros((128, 128), dtype=np.uint8)                 # 2D 화면에 점 찍기 (픽셀 그리드)
for u, v in uv.round().astype(int): img[v, u] = 255
print(int((img > 0).sum()))                                # 8  꼭짓점 8개가 화면에 투영됨

shifted = cube + np.array([1.0, 0, 0])                     # 카메라 기준으로 물체를 옮기면 모습이 바뀜
print(round(float(project(shifted)[:, 0].mean() - uv[:, 0].mean()), 1))   # 20.8  화면에서 오른쪽으로 이동
```
