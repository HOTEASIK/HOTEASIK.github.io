# Tiny NeRF 구현

## 정의·핵심
- **개요 (응용 9차시 01_tiny_nerf)**: **소형 MLP**로 NeRF의 전체 파이프라인을 가볍게 실습 — PyTorch 등으로 **약 100줄 내외**
  - 원 NeRF에서 **빠진 것**: 5D 입력 중 **보는 방향(view direction)**, **계층적 샘플링(Hierarchical Sampling)** → 위치 (x, y, z)만 입력
  - 데이터: `tiny_nerf_data.npz` — 레고 장면 **100×100 이미지 106장 + 카메라 포즈 + focal** (원본 노트북)
- **학습 파이프라인 4단계 (강의)**
  1. **데이터 준비**: Images + Camera Poses 로드
  2. **광선 생성**: 각 픽셀의 Ray Origin(o), Direction(d) 계산 (`get_rays`, 과제 문항 3) → [[Ray Casting]]
  3. **MLP 추론**: 광선 위 샘플 포인트 xyz → **Positional Encoding** → 색상 c, 밀도 σ (과제 문항 4: 입력 → **128 노드** 선형층 … → **RGB 3 + Density 1** 출력) → [[NeRF의 Positional Encoding]]
  4. **렌더링 & 학습**: 볼륨 렌더링으로 이미지 생성 → 실제 이미지와 **MSE Loss**로 역전파 (과제 문항 6) → [[Volume Rendering]]
- **하이퍼파라미터 (강의)**: **N_samples = 64** (광선당 샘플 수), **L_embed = 10** (PE 차수), near = 2, far = 6
- **Stratified Sampling (과제 문항 5)**: `z_vals = linspace(near, far, N_samples)` + **균일 간격 × 무작위 노이즈** → 학습 시 같은 위치만 보지 않게 (오버피팅 방지)
- **평가**: 일정 간격(예: 50 iter)마다 **홀드아웃 시점**을 렌더링하고 **PSNR** 표시 → 학습 후 **360° 영상** 렌더링
- **이 환경**: 레고 데이터 대신 **합성 장면(색 있는 구)** 을 만들어 같은 파이프라인으로 학습 (아래)

## 수식·원리
```
get_rays:  d = c2w[:3,:3] · ((i − W/2)/f, −(j − H/2)/f, −1),   o = c2w[:3, 3]
pts = o + d · z_vals,   z_vals = linspace(near, far, N) + U(0, 1) · (far − near)/N
loss = mean( (render(pts) − target)² )
PSNR = −10 · log10(MSE)
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn

torch.manual_seed(0); np.random.seed(0)
H = W = 24; focal = 30.0; near, far, N_samples, L_embed = 2.0, 6.0, 32, 6

def get_rays(c2w):
    i, j = torch.meshgrid(torch.arange(W, dtype=torch.float32), torch.arange(H, dtype=torch.float32), indexing="xy")
    dirs = torch.stack([(i - W * .5) / focal, -(j - H * .5) / focal, -torch.ones_like(i)], -1)
    return c2w[:3, -1].expand(H, W, 3), (dirs[..., None, :] * c2w[:3, :3]).sum(-1)

def pose(theta):                                              # 원점을 바라보며 y축 둘레를 도는 카메라 (반지름 4)
    c, s = np.cos(theta), np.sin(theta)
    m = np.array([[c, 0, s, 4 * s], [0, 1, 0, 0], [-s, 0, c, 4 * c], [0, 0, 0, 1]], dtype=np.float32)
    return torch.tensor(m)

def scene(pts):                                               # 정답 장면: 반지름 1 구, 위쪽 빨강·아래쪽 초록
    inside = (pts.norm(dim=-1) < 1.0).float()
    rgb = torch.stack([(pts[..., 1] > 0).float(), (pts[..., 1] <= 0).float(), torch.zeros_like(pts[..., 0])], -1)
    return rgb, 20.0 * inside

def posenc(x):
    return torch.cat([x] + [f(2.0 ** k * x) for k in range(L_embed) for f in (torch.sin, torch.cos)], -1)

def render(fn, rays_o, rays_d, rand=False):
    z = torch.linspace(near, far, N_samples).expand(*rays_o.shape[:-1], N_samples).clone()
    if rand: z = z + torch.rand_like(z) * (far - near) / N_samples        # stratified sampling (과제 문항 5)
    pts = rays_o[..., None, :] + rays_d[..., None, :] * z[..., None]
    rgb, sigma = fn(pts)
    delta = torch.cat([z[..., 1:] - z[..., :-1], torch.full_like(z[..., :1], 1e10)], -1)
    alpha = 1 - torch.exp(-sigma * delta)
    T = torch.cumprod(torch.cat([torch.ones_like(alpha[..., :1]), 1 - alpha + 1e-10], -1), -1)[..., :-1]
    return ((T * alpha)[..., None] * rgb).sum(-2)

poses = [pose(t) for t in np.linspace(0, 2 * np.pi, 9)[:-1]]
images = [render(scene, *get_rays(p)) for p in poses]         # "촬영한 사진" 8장
test_pose = pose(np.pi / 8)                                    # 학습에 없는 새 시점 (Novel View)
test_img = render(scene, *get_rays(test_pose))

in_dim = 3 + 3 * 2 * L_embed
mlp = nn.Sequential(nn.Linear(in_dim, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, 4))   # 과제 문항 4
def model_fn(pts):
    out = mlp(posenc(pts))
    return torch.sigmoid(out[..., :3]), torch.relu(out[..., 3])

opt = torch.optim.Adam(mlp.parameters(), lr=1e-3)
psnr = lambda a, b: (-10 * torch.log10(((a - b) ** 2).mean())).item()
start = psnr(render(model_fn, *get_rays(test_pose)).detach(), test_img)
for it in range(500):
    k = np.random.randint(len(poses))
    loss = ((render(model_fn, *get_rays(poses[k]), rand=True) - images[k]) ** 2).mean()   # 과제 문항 6: MSE
    opt.zero_grad(); loss.backward(); opt.step()
with torch.no_grad():
    end = psnr(render(model_fn, *get_rays(test_pose)), test_img)
print(len(images), tuple(images[0].shape), round(start, 1), round(end, 1))   # 8 (24, 24, 3) 7.0 30.7  학습에 없던 새 시점 PSNR(dB)이 크게 오름
```
