# 가상 카메라

## 정의·핵심
- **정의 (응용 9차시)**: 우리가 세상을 보는 방식(눈)을 그대로 **수학적으로 모델링**한 것 — "**가상 카메라는 사람 눈과 같다**" (Pinhole Camera 모델)
  - **위치 (Position)**: 월드 공간 어디에 있는가? (사람이 서 있는 위치)
  - **방향 (Direction)**: 어디를 바라보는가? (시선 방향)
  - **시야각 (FOV)**: 얼마나 넓게 보는가? (광각 vs 망원)
  - **초점거리**: 상(Image)이 맺히는 거리 (줌 인/아웃 효과)
  - 컴퓨터 그래픽스 = **인간 시각 시스템의 수학적 모방**: 눈/카메라 → 픽셀마다 광선 발사 → 물체와 충돌 → 반사광(색) 결정
- **카메라 파라미터 (강의)**
  - **내부 (Intrinsic)**: 렌즈 특성 — **초점 거리**(픽셀 단위 f), **주점**(Principal Point, 보통 이미지 중심) → 행렬 K
  - **외부 (Extrinsic)**: 월드 좌표계에서의 카메라 **위치와 회전 (Pose)** — 회전 행렬 R(3×3) + 이동 벡터 t
  - NeRF 데이터의 **c2w** (camera-to-world, 4×4) = 카메라 좌표 → 월드 좌표 변환 = 포즈
- **좌표계 (9차시 핵심이론)**
  - **월드 좌표계**: (0,0,0)이 절대 기준점 — 카메라가 움직여도 점의 (x,y,z)는 그대로
  - **로컬 좌표계**: 물체 자체의 중심이 (0,0,0)
  - **카메라 좌표계 (View space)**: 카메라를 원점으로 — 월드의 점에 **view matrix**를 적용해 변환
  - **구면 좌표**: 방위각(좌우), 고도각(상하), 거리 d로 카메라 기준 위치 → 월드 위치를 더해 월드 좌표로 (`x_world = xc + d·cos(고도각)·sin(방위각)`)
- **카메라 보정 (Calibration)**: 렌즈 왜곡·시야각·위치·방향을 알아내는 과정 → NeRF 입력은 **Calibrated images**(이 값들을 모두 아는 이미지) → [[NeRF]], [[SfM·Point Cloud]]
- **중요성 (강의)**: Camera Pose 정확도가 렌더링 품질을 결정짓는 **가장 중요한 요소**

## 수식·원리
```
K = [[f, 0, c_x], [0, f, c_y], [0, 0, 1]]
FOV = 2 · atan( W / (2f) )          (f ↑ → FOV ↓, 망원)
월드 → 카메라:  X_c = R X_w + t      (view matrix, w2c)
카메라 → 월드:  X_w = Rᵀ (X_c − t)   (c2w = w2c⁻¹)
픽셀:  [u, v, 1]ᵀ ∝ K X_c
```

## 코드 예시
```python
import numpy as np

def look_at(cam_pos, target, up=np.array([0, 1.0, 0])):      # c2w 포즈 만들기 (OpenGL식: 카메라는 −z를 봄)
    fwd = (target - cam_pos) / np.linalg.norm(target - cam_pos)
    right = np.cross(fwd, up); right /= np.linalg.norm(right)
    true_up = np.cross(right, fwd)
    c2w = np.eye(4)
    c2w[:3, :3] = np.stack([right, true_up, -fwd], 1)
    c2w[:3, 3] = cam_pos
    return c2w

c2w = look_at(np.array([0.0, 0.0, 4.0]), np.zeros(3))
w2c = np.linalg.inv(c2w)                                     # view matrix
P_world = np.array([0.5, 0.0, 0.0, 1.0])
P_cam = w2c @ P_world
print(P_cam[:3].round(3).tolist())                           # [0.5, 0.0, -4.0]  카메라 앞(−z) 4m

H = W = 100; f = 120.0
K = np.array([[f, 0, W / 2], [0, f, H / 2], [0, 0, 1]])
uvw = K @ np.array([P_cam[0], P_cam[1], -P_cam[2]])          # −z 방향을 깊이로
print((uvw[:2] / uvw[2]).round(1).tolist())                  # [65.0, 50.0]  중심에서 오른쪽
print(round(float(np.degrees(2 * np.arctan(W / (2 * f)))), 1), round(float(np.degrees(2 * np.arctan(W / (2 * 2 * f)))), 1))   # 45.2 23.5  초점거리 2배 → 시야각 좁아짐(줌 인)

az, el, d = np.radians(30), np.radians(10), 4.0              # 구면 좌표 (방위각, 고도각, 거리)
x = d * np.cos(el) * np.sin(az); y = d * np.sin(el); z = d * np.cos(el) * np.cos(az)
print(round(float(np.linalg.norm([x, y, z])), 3))           # 4.0  d = 원점(물체)까지 직선 거리
```
