# NeRF

## 정의·핵심
- **정의 (응용 9차시)**: Neural Radiance Fields (Mildenhall et al., 2020). **2D 이미지를 이용해 3D 공간을 복원**하고 **새로운 시점의 이미지를 생성**하는 기술
  - 한 문장으로: "**여러 장의 사진으로 3D 공간을 추측해, 찍지 않은 아무 각도에서나 이미지를 만들어 내는 AI**"
  - 비유: "친구 얼굴을 이리저리 보면 **옆모습도 상상**되죠?"
- **문제 정의 (강의)**
  - **입력**: **보정된 다중 시점 이미지 (Calibrated Images)** + 각 이미지의 **카메라 포즈**(위치, 방향) — 렌즈 왜곡·시야각·위치·방향을 모두 앎 → [[가상 카메라]]
  - **출력**: 학습에 쓰지 않은 **새로운 시점 (Novel View)** 의 이미지 — 마치 그 자리에 가서 찍은 것처럼
  - **핵심**: 공간상의 모든 점에 대해 **밀도(Density)와 색상(Radiance)** 을 정의하는 **연속 함수를 딥러닝으로 학습**
- **3가지 핵심 작동 원리 (강의)**
  1. **Neural Volumetric 3D Scene Representation**: 3D 장면을 메시/복셀로 직접 저장하는 대신 **MLP 함수**로 표현 — 위치 (x, y, z)와 보는 방향 (θ, φ)을 넣으면 **색상 c와 밀도 σ** 출력 (원 논문: **9개 레이어, 256채널 MLP**) → 9차시 과제 문항 2: 출력 = **색상(RGB), 부피 밀도(σ)**
  2. **Differentiable Volumetric Rendering**: 광선을 따라 예측값을 적분해 2D 이미지로 — **미분 가능**해서 딥러닝 학습 가능 → [[Volume Rendering]]
  3. **Optimization via Analysis-by-Synthesis ("합성을 통한 분석")**: 렌더링한 이미지와 실제 사진의 **MSE Loss**를 역전파해 MLP 업데이트
- **세부 설계**
  - **Positional Encoding**: 좌표를 고주파 sin/cos로 확장해 **선명한 디테일** 학습 → [[NeRF의 Positional Encoding]]
  - **시점 의존 효과 (View-Dependent)**: 보는 방향 d를 입력받아 **반사광(Specular)**·재질감 표현 — 밀도 σ는 위치만으로, 색 c는 위치+방향으로
  - **계층적 샘플링**: Coarse 네트워크로 대략 위치를 찾고 Fine 네트워크로 물체 근처를 촘촘히
- **장점 (강의)**: 실사와 구별하기 힘든 **매우 높은 품질**, 미분 가능한 **연속 볼륨**(끊김 없음), **메시 불필요**(토폴로지 관리 없음), 연기·반투명·털 표현
- **단점 (강의)**: **느린 학습·추론**(장면당 수 시간 학습, 렌더링 수 초), **많은 메모리**, **실시간 렌더링 어려움**(Ray Marching 비용), 느린 수렴 → **Gaussian Splatting**으로 해결 → [[Gaussian Splatting]]
- **확장된 Plenoptic Function**: 7D 빛의 지도를 **5D (x, y, z, θ, φ)** 로 단순화한 것 → [[Plenoptic Function]]

## 수식·원리
```
F_Θ : (x, d) → (c, σ),     x = (x, y, z),  d = (θ, φ)
σ = σ(γ(x)),   c = c(γ(x), γ(d))          (밀도는 위치만, 색은 방향까지)
Ĉ(r) = Σ_i T_i (1 − exp(−σ_i δ_i)) c_i,   T_i = exp(−Σ_{j<i} σ_j δ_j)
L = Σ_r ‖ Ĉ(r) − C_gt(r) ‖²
```

## 코드 예시
```python
import torch
import torch.nn as nn

class NeRF(nn.Module):                                   # 밀도는 위치만, 색은 위치+방향 (시점 의존)
    def __init__(self, L_x=10, L_d=4, W=128):
        super().__init__()
        self.L_x, self.L_d = L_x, L_d
        in_x, in_d = 3 + 3 * 2 * L_x, 3 + 3 * 2 * L_d
        self.trunk = nn.Sequential(nn.Linear(in_x, W), nn.ReLU(), nn.Linear(W, W), nn.ReLU())
        self.sigma = nn.Linear(W, 1)
        self.color = nn.Sequential(nn.Linear(W + in_d, W // 2), nn.ReLU(), nn.Linear(W // 2, 3), nn.Sigmoid())
    @staticmethod
    def pe(p, L):
        return torch.cat([p] + [f(2.0 ** k * p) for k in range(L) for f in (torch.sin, torch.cos)], -1)
    def forward(self, x, d):
        h = self.trunk(self.pe(x, self.L_x))
        sigma = torch.relu(self.sigma(h)).squeeze(-1)    # σ ≥ 0
        rgb = self.color(torch.cat([h, self.pe(d, self.L_d)], -1))
        return rgb, sigma

torch.manual_seed(0)
model = NeRF()
x = torch.rand(1024, 3) * 2 - 1                            # 공간의 점들
d = nn.functional.normalize(torch.randn(1024, 3), dim=-1)  # 보는 방향
rgb, sigma = model(x, d)
print(tuple(rgb.shape), tuple(sigma.shape), bool((rgb >= 0).all() & (rgb <= 1).all()), bool((sigma >= 0).all()))   # (1024, 3) (1024,) True True

x1 = torch.zeros(1, 3)
_, s_a = model(x1, torch.tensor([[0, 0, 1.0]])); _, s_b = model(x1, torch.tensor([[1.0, 0, 0]]))
c_a, _ = model(x1, torch.tensor([[0, 0, 1.0]])); c_b, _ = model(x1, torch.tensor([[1.0, 0, 0]]))
print(torch.allclose(s_a, s_b), torch.allclose(c_a, c_b))  # True False  밀도는 방향과 무관, 색은 방향에 따라 다름
print(sum(p.numel() for p in model.parameters()))          # 파라미터 수 (작은 MLP 하나가 장면 전체를 표현)
```
