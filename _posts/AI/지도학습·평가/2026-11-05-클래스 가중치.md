# 클래스 가중치

## 정의·핵심
- **정의**: 데이터는 그대로 두고, **손실을 계산할 때 소수 클래스의 오류에 더 큰 가중치**를 주는 방법. "적은 클래스를 틀리면 더 아프게"
- **가중치 계산법**
  - **역빈도 (balanced)**: `w_k = N / (K · N_k)` — sklearn `compute_class_weight('balanced', classes, y)`와 같음. 균형 데이터면 모두 1
  - 단순 역수 `1 / N_k`, 너무 극단적이면 **제곱근 역빈도** `1 / √N_k`로 완화
  - 이진: `pos_weight = N_neg / N_pos`
- **PyTorch에서 넣는 곳**
  - 다중분류: `nn.CrossEntropyLoss(weight=torch.tensor(w, dtype=torch.float32).to(device))` — **float, 길이 = 클래스 수, 모델과 같은 device**
  - 이진: `nn.BCEWithLogitsLoss(pos_weight=torch.tensor([N_neg / N_pos]))`
  - 손실 수식 자세히 → [[Weighted Cross Entropy]]
- **sklearn 모델**: `LogisticRegression(class_weight='balanced')`, `RandomForestClassifier(class_weight='balanced')`
- **WeightedRandomSampler와 비교**
  - 샘플러: 소수 샘플을 **더 자주 보여 줌** (배치 구성 변경)
  - 클래스 가중치: 보는 횟수는 같고 **손실 크기**만 키움
  - 둘을 동시에 강하게 쓰면 소수 클래스가 과하게 강조된다 → 보통 하나 먼저 쓰고, 부족하면 약하게 추가 (강의 조언)
- **효과**: 소수 클래스 재현율↑, 대신 정밀도↓ 경향 → 임계값 조정과 함께 점검

## 수식·원리
```
w_k = N / (K · N_k)
L = Σᵢ w_{yᵢ} · ℓᵢ / Σᵢ w_{yᵢ}          (CrossEntropyLoss mean)
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn
from sklearn.utils.class_weight import compute_class_weight

y = np.array([0] * 80 + [1] * 15 + [2] * 5)
w = compute_class_weight("balanced", classes=np.unique(y), y=y)
print(np.round(w, 3).tolist())                                   # [0.417, 2.222, 6.667]
print(np.round(len(y) / (3 * np.bincount(y)), 3).tolist())       # [0.417, 2.222, 6.667]  같은 공식

crit = nn.CrossEntropyLoss(weight=torch.tensor(w, dtype=torch.float32))
logits = torch.zeros(2, 3)                                       # 확신 없는 예측
print(round(crit(logits, torch.tensor([0, 2])).item(), 3))       # 1.099 (가중 평균이라 값은 ln3)
per = nn.CrossEntropyLoss(weight=torch.tensor(w, dtype=torch.float32), reduction="none")(logits, torch.tensor([0, 2]))
print([round(v, 3) for v in per.tolist()])                       # [0.458, 7.324]  ← 소수 클래스 오류가 16배 큼
```
