# 단순회귀·중회귀

## 정의·핵심
- **단순회귀 (Simple Regression)**: 입력 특징이 **1개**. `y = wx + b` — 2D 평면의 직선
  - 예: 신장 → 체중, 보스턴 데이터에서 **방 개수(RM) 하나**로 집값 예측 (7차시 첫 실습)
  - PyTorch: `nn.Linear(1, 1)`, 입력 모양 `(N, 1)` — 1차원 `(N,)`이면 `reshape(-1, 1)` 필요
- **중회귀 (Multiple Regression, 다중회귀)**: 입력 특징이 **여러 개**. `y = w₁x₁ + w₂x₂ + … + b` — 고차원 평면(초평면)
  - 예: 보스턴 데이터 **RM + LSTAT(저소득층 비율)** 2개, 또는 13개 전부
  - PyTorch: `nn.Linear(n_input, 1)`
  - 각 계수 wᵢ의 의미: **다른 특징이 고정되었을 때** xᵢ가 1 증가하면 y가 wᵢ만큼 변함
- **특징을 늘리면**
  - 보통 예측력(R²)이 오른다 (강의: RM만 쓸 때보다 RM+LSTAT가 손실이 낮다)
  - 하지만 쓸모없는 특징이 많으면 과적합, 특징끼리 상관이 높으면(다중공선성) 계수가 불안정 → 규제
  - **특징 스케일이 다르면** 경사하강법이 느리다 → 표준화 → [[표준화(StandardScaler)]]
- 다변량 회귀(Multivariate)는 **출력이** 여러 개인 경우로, 중회귀와 다른 말이다

## 수식·원리
```
단순:  ŷ = w·x + b                       nn.Linear(1, 1)
중회귀: ŷ = Σⱼ wⱼxⱼ + b = Xw + b          nn.Linear(n, 1)
```

## 코드 예시
```python
import numpy as np
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(0)
rm = rng.normal(6.3, 0.7, 300); lstat = rng.normal(12, 7, 300).clip(2)
price = 9 * rm - 0.6 * lstat - 28 + rng.normal(0, 3, 300)     # 가짜 보스턴 형태 데이터

simple = LinearRegression().fit(rm.reshape(-1, 1), price)
multi = LinearRegression().fit(np.c_[rm, lstat], price)
print(round(simple.score(rm.reshape(-1, 1), price), 2), round(multi.score(np.c_[rm, lstat], price), 2))   # 0.67 0.87  (R²)
print(np.round(multi.coef_, 1))                                # [ 9.2 -0.6]  각 특징의 효과
```
