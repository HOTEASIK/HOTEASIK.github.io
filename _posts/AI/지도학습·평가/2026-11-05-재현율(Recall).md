# 재현율(Recall)

## 정의·핵심
- **정의**: **실제 긍정 중 모델이 긍정으로 찾아낸 비율**. `TP / (TP + FN)` — "찾아야 할 것을 얼마나 놓치지 않았나"
- **다른 이름**: 민감도(Sensitivity), **TPR(True Positive Rate)** — ROC 곡선의 y축 → [[ROC 곡선]]
- **관점**: **실제 기준**(혼동행렬의 행). FN(놓침)이 늘면 떨어진다
- **중요한 상황 — FN의 비용이 클 때**
  - **질병 진단**: 환자를 정상으로 놓치면(FN) 치료 시기를 놓친다 (13차시 폐렴 X-ray)
  - **사기 거래·침입 탐지**(8차시 사기거래탐지 실습), 불량품 검사, 자율주행 보행자 검출
  - 이런 경우 재현율 목표(예: 95% 이상)를 정하고, 그 안에서 정밀도를 최대화
- **쉽게 올리는 법과 함정**: **모두 양성**이라고 하면 재현율 = 1이지만 정밀도가 바닥 → 재현율만 보면 안 된다 → [[Precision–Recall 트레이드오프]]
- **올리는 방법**: 임계값 낮추기, 클래스 가중치·pos_weight, 오버샘플링, Focal Loss → [[클래스 불균형 문제]]
- **특이도(Specificity)**: 실제 음성 중 음성으로 맞힌 비율 `TN/(TN+FP)` = 음성 클래스의 재현율. `1 − 특이도 = FPR`
- 다중분류에서는 클래스별 재현율 = 혼동행렬 행별 대각 비율

## 수식·원리
```
Recall = TPR = TP / (TP + FN)
Specificity = TN / (TN + FP),   FPR = 1 − Specificity
```

## 코드 예시
```python
from sklearn.metrics import recall_score

y_true = [1, 0, 1, 1, 0, 0, 1, 0]
y_pred = [1, 0, 0, 1, 0, 1, 1, 0]                      # TP=3, FN=1
print(recall_score(y_true, y_pred))                    # 0.75 = 3 / (3 + 1)
print(recall_score(y_true, [1] * 8))                   # 1.0  모두 양성이면 만점 (정밀도는 0.5)
print(recall_score(y_true, y_pred, pos_label=0))       # 0.75 특이도 = 음성 클래스의 재현율
```
