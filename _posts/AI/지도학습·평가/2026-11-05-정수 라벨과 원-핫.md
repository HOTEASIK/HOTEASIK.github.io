# 정수 라벨과 원-핫

## 정의·핵심
- **정수 라벨 (Label Encoding)**: 클래스를 **번호 하나**로 표현. 고양이=0, 강아지=1, 여우=2 → `[2, 0, 1]`, 모양 `(N,)`, dtype `long`
- **원-핫 (One-hot Encoding)**: 클래스 수 길이의 벡터에서 **정답 위치만 1, 나머지 0**. 여우 → `[0, 0, 1]`, 모양 `(N, K)`
- **PyTorch는 정수 라벨을 쓴다**
  - `nn.CrossEntropyLoss`의 정답은 **클래스 인덱스** — "원-핫 인코딩은 필요 없습니다! 클래스 인덱스만 전달하세요" (6차시)
  - torchvision 데이터셋·ImageFolder도 정수 라벨을 준다 (`class_to_idx`)
  - 메모리가 적고, 내부적으로 정답 위치의 로그 확률만 꺼내 쓰면 되므로 효율적
- **원-핫이 필요한 경우**
  - **BCE 기반 다중 라벨** 분류 (각 클래스 0/1 float)
  - Label Smoothing을 직접 구현할 때, Mixup처럼 라벨을 섞을 때 (부드러운 정답)
  - sklearn **다중분류 ROC**: `label_binarize(y, classes=[0,1,2])` → [[다중분류 ROC]]
  - Keras의 `categorical_crossentropy` (정수는 `sparse_categorical_crossentropy`)
- **변환**
  - 정수 → 원-핫: `F.one_hot(y, num_classes=K)` (결과는 long → 손실에 쓰려면 `.float()`)
  - 원-핫 → 정수: `onehot.argmax(1)`
- **입력 특징으로서의 원-핫**: 범주형 입력(색상, 지역)을 정수로만 넣으면 모델이 "2 > 1" 같은 **없는 순서**를 배운다 → 입력은 원-핫(또는 임베딩)으로 → [[원-핫 인코딩(텍스트)]], [[임베딩]]

## 수식·원리
```
정수:   y = 2
원-핫:  e₂ = [0, 0, 1]
CE(z, y) = −log softmax(z)[y] = −Σₖ e_y[k]·log softmax(z)[k]   (두 표현의 손실은 같다)
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

y = torch.tensor([2, 0, 1])
oh = F.one_hot(y, num_classes=3)
print(oh.tolist(), oh.dtype)                     # [[0, 0, 1], [1, 0, 0], [0, 1, 0]] torch.int64
print(oh.argmax(1).tolist())                     # [2, 0, 1]  되돌리기

z = torch.randn(3, 3)
a = nn.CrossEntropyLoss()(z, y)                  # 정수 라벨
b = nn.CrossEntropyLoss()(z, oh.float())         # 확률(원-핫) 라벨도 받음
print(torch.allclose(a, b))                      # True
```
