# 회귀와 분류의 차이

## 정의·핵심
- **회귀(Regression)**: **연속적인 숫자**를 예측. 예: 집값, 체중, 온도, 매출 / 박스 좌표(검출)
- **분류(Classification)**: 정해진 **범주(클래스) 중 하나**를 예측. 예: 스팸/정상(이진), 숫자 0~9(다중), 고양이·강아지·여우
  - 이진분류: 2개 → [[이진분류 출력과 임계값]] / 다중분류: 3개 이상 → [[다중분류]] / 다중 라벨: 여러 개 동시에 참 가능
- **딥러닝에서 무엇이 달라지나** (구조는 같고 **출력층·손실·지표**만 바뀐다)

| | 회귀 | 이진분류 | 다중분류 |
|---|---|---|---|
| 출력 뉴런 수 | 1 (또는 예측할 값 수) | 1 | 클래스 수 K |
| 출력층 활성화 | 없음(항등) | Sigmoid (손실에 내장) | Softmax (손실에 내장) |
| 손실 | MSE, MAE, Huber | BCEWithLogitsLoss | CrossEntropyLoss |
| 정답 형태 | 실수 float | 0./1. float | 클래스 인덱스 long |
| 평가 지표 | MSE, MAE, R² | 정확도, 정밀도, 재현율, F1, AUC | 정확도, 혼동행렬, macro F1 |
| 예측 값 읽기 | 출력 그대로 | `logit > 0` | `argmax` |

- **헷갈리는 이름**: **로지스틱 "회귀"는 분류 모델**이다 (확률을 회귀한 뒤 임계값으로 분류) → [[로지스틱 회귀]]
- 숫자 라벨(0~9)이라도 순서·크기 의미가 없으면 분류다. 반대로 "별점 1~5"처럼 순서가 있으면 둘 다 가능

## 수식·원리
```
회귀:     ŷ = f(x) ∈ ℝ               L = (1/n)Σ(y − ŷ)²
이진분류:  p = σ(f(x)) ∈ (0,1)        L = BCE
다중분류:  p = softmax(f(x)) ∈ Δᴷ     L = CE
```

## 코드 예시
```python
import torch
import torch.nn as nn

h = nn.Sequential(nn.Linear(4, 16), nn.ReLU())           # 몸통은 같다
reg = nn.Sequential(h, nn.Linear(16, 1));  bin_ = nn.Sequential(h, nn.Linear(16, 1));  multi = nn.Sequential(h, nn.Linear(16, 3))
x = torch.randn(5, 4)
print(nn.MSELoss()(reg(x), torch.randn(5, 1)).shape)                          # torch.Size([])
print(nn.BCEWithLogitsLoss()(bin_(x), torch.randint(0, 2, (5, 1)).float()) > 0)  # tensor(True)
print(nn.CrossEntropyLoss()(multi(x), torch.tensor([0, 2, 1, 1, 0])) > 0)        # tensor(True)
print(multi(x).argmax(1).shape)                                               # torch.Size([5])
```
