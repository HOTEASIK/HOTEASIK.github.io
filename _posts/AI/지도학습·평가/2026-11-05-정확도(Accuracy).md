# 정확도(Accuracy)

## 정의·핵심
- **정의**: 전체 예측 중 **맞힌 비율**. `(TP + TN) / 전체` — 가장 직관적인 분류 지표
- **PyTorch 계산** (강의 학습 루프)
  - 배치마다 `predicted = outputs.argmax(1)` → `n_correct += (predicted == labels).sum().item()`, `n_total += len(labels)`
  - 에폭 끝에 `acc = n_correct / n_total`
  - 배치별 정확도를 평균내면 마지막 배치 크기가 다를 때 약간 틀리므로 **개수로 누적**하는 편이 정확
- sklearn: `accuracy_score(y_true, y_pred)`
- **정확도의 함정 — 클래스 불균형**
  - 정상 990, 스팸 10일 때 **모두 정상이라고만 해도 99%** — 스팸은 하나도 못 잡는 쓸모없는 모델 (10차시)
  - 의료 진단(정상 99%, 질병 1%)도 같다
  - → 불균형 데이터에서는 **혼동행렬, 정밀도, 재현율, F1, AUC**를 함께 본다 → [[혼동행렬]], [[F1 Score]]
- **언제 적절한가**: 클래스 비율이 비슷하고, 두 종류의 오류(FP·FN) 비용이 비슷할 때 (MNIST, CIFAR10)
- 강의 수치: MNIST 2층 MLP **94.95%** → 은닉층 추가 **95.81%** (10차시), CIFAR10 CNN_v2 SGD 70% → Adam 76.56% (12차시)
- **Top-k 정확도**: 정답이 상위 k개 예측 안에 있으면 정답 처리 (ImageNet Top-5)

## 수식·원리
```
Accuracy = (TP + TN) / (TP + TN + FP + FN) = 맞힌 수 / 전체 수
다중분류: (1/N) Σ 1[ŷᵢ = yᵢ]
```

## 코드 예시
```python
import torch
from sklearn.metrics import accuracy_score

n_correct = n_total = 0
batches = [(torch.tensor([[2.0, 0.1], [0.3, 1.2]]), torch.tensor([0, 1])),
           (torch.tensor([[0.9, 0.2]]), torch.tensor([1]))]               # 마지막 배치 크기가 다름
for outputs, labels in batches:
    predicted = outputs.argmax(1)
    n_correct += (predicted == labels).sum().item(); n_total += len(labels)
print(round(n_correct / n_total, 3))                                      # 0.667

y = [0] * 990 + [1] * 10
print(accuracy_score(y, [0] * 1000))                                      # 0.99  ← 스팸을 하나도 못 잡아도 99%
```
