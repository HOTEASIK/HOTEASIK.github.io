# 이진분류 출력과 임계값

## 정의·핵심
- **이진분류 모델의 출력**: 마지막 `nn.Linear(?, 1)`이 내놓는 **로짓 1개** → Sigmoid를 거치면 **양성(1)일 확률** p → [[Sigmoid]]
- **임계값(Threshold)**: 확률을 0/1 라벨로 바꾸는 기준선. 기본은 **확률 0.5**
  - **확률 0.5 ⇔ 로짓 0.0** (σ(0) = 0.5) → 확률로 바꾸지 않고 `logits > 0`으로도 같은 판정 (8차시)
  - 코드: `pred = (torch.sigmoid(logits) > 0.5).long()` 또는 `(logits > 0).long()`
- **임계값을 바꾸면 성능 지표가 바뀐다**
  - **낮추면(0.3)**: 양성을 더 많이 예측 → **재현율↑, 정밀도↓** (놓치는 환자를 줄이고 싶을 때, 의료·사기 탐지)
  - **높이면(0.8)**: 확실한 것만 양성 → **정밀도↑, 재현율↓** (스팸 필터: 정상 메일을 스팸으로 버리면 안 될 때)
  - → [[Precision–Recall 트레이드오프]], 모든 임계값을 훑어 그린 것이 [[ROC 곡선]]
- **임계값 고르는 법**: 검증 데이터에서 F1이 최대인 값, 목표 재현율(예: 95%)을 만족하는 값, 비용(FN이 FP보다 10배 비싸다 등)을 반영. **테스트 데이터로 고르면 안 된다**
- **불균형 데이터**에서는 0.5가 최적이 아닌 경우가 많다 → [[클래스 불균형 문제]]
- 출력 모양 주의: 출력 `(N, 1)` vs 정답 `(N,)` → `squeeze(1)` 또는 정답 `reshape(-1, 1)`로 맞춘다

## 수식·원리
```
p = σ(z),   ŷ = 1  if p ≥ t  else 0
t = 0.5  ⇔  z ≥ 0
일반 t:   z ≥ log(t / (1 − t))
```

## 코드 예시
```python
import torch

logits = torch.tensor([-2.0, -0.2, 0.1, 0.9, 3.0])
y = torch.tensor([0, 1, 0, 1, 1])
p = torch.sigmoid(logits)
print(torch.equal((p > 0.5).long(), (logits > 0).long()))     # True  확률 0.5 = 로짓 0

for t in (0.3, 0.5, 0.7):
    pred = (p > t).long()
    tp = ((pred == 1) & (y == 1)).sum().item(); fp = ((pred == 1) & (y == 0)).sum().item()
    fn = ((pred == 0) & (y == 1)).sum().item()
    print(t, round(tp / (tp + fp), 2), round(tp / (tp + fn), 2))   # 임계값, 정밀도, 재현율
# 0.3 0.75 1.0
# 0.5 0.67 0.67
# 0.7 1.0 0.67
```
