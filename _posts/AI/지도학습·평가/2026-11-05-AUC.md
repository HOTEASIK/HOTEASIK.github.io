# AUC

## 정의·핵심
- **정의**: Area Under the (ROC) Curve. **ROC 곡선 아래 면적**으로 모델 성능을 **하나의 숫자**로 요약 (개론 10차시). `roc_auc_score(y_true, y_score)`
- **해석 기준 (강의)**
  - **1.0**: 완벽한 분류기
  - 0.9~1.0: 매우 우수 / 0.8~0.9: 우수 / 0.7~0.8: 괜찮음
  - **0.5**: 동전 던지기 수준 (대각선)
  - 0.5 미만: 예측이 거꾸로 (라벨을 뒤집으면 1 − AUC)
- **확률적 의미**: "**무작위로 고른 양성 샘플과 음성 샘플에서, 모델이 양성 샘플에 더 높은 점수를 줄 확률**" — AUC = 0.9면 90% (강의)
  - 그래서 **순위(ranking)** 만 본다: 점수를 모두 2배 하거나 Sigmoid를 씌워도 AUC는 그대로
- **장점**
  - **임계값과 무관**: 임계값을 정하기 전에 모델 자체의 분리 능력 비교
  - 클래스 비율에 덜 민감 (정확도처럼 "다 음성" 꼼수가 안 통함 → 0.5)
- **단점**
  - 극심한 불균형에서는 낙관적으로 나올 수 있음 → PR-AUC(Average Precision) 병행
  - 확률이 **잘 보정되었는지**는 알려주지 않는다 (순위만 봄) → [[Calibration]]
- 다중분류: `roc_auc_score(y, prob, multi_class='ovr', average='macro')` → [[다중분류 ROC]]

## 수식·원리
```
AUC = ∫₀¹ TPR d(FPR)
    = P(score(양성) > score(음성))   (동점은 0.5로)
```

## 코드 예시
```python
import numpy as np
from sklearn.metrics import roc_auc_score

y = np.array([0, 0, 1, 0, 1, 1, 0, 1])
s = np.array([0.1, 0.4, 0.35, 0.2, 0.8, 0.7, 0.6, 0.9])
print(roc_auc_score(y, s))                                     # 0.875

pos, neg = s[y == 1], s[y == 0]
pairs = (pos[:, None] > neg[None, :]).mean()                   # 양성 점수 > 음성 점수 인 쌍의 비율
print(pairs)                                                   # 0.875  ← 확률적 의미와 같음
print(roc_auc_score(y, s * 100) == roc_auc_score(y, s))        # True   순위만 본다
print(roc_auc_score(y, np.zeros(8)), roc_auc_score(y, 1 - s))  # 0.5 0.125
```
