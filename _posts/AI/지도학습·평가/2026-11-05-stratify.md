# stratify

## 정의·핵심
- **정의**: 층화 추출(Stratified Sampling). 데이터를 나눌 때 **각 부분의 클래스 비율이 원래 데이터와 같도록** 나누는 옵션. `train_test_split(..., stratify=y)`
- **왜 필요한가**: 무작위로 나누면 우연히 한쪽에 특정 클래스가 몰릴 수 있다
  - 특히 **클래스 불균형**(양성 1%) 데이터: 테스트셋에 양성이 0~2개만 들어가면 재현율·F1이 의미 없어지고, 실행할 때마다 결과가 크게 흔들린다
  - 데이터가 **적을 때**(iris 150개)도 비율이 쉽게 틀어진다
- **사용법**: `stratify`에 **라벨 배열**을 넘긴다 (`stratify=y`). `True`가 아님에 주의
- **교차 검증 버전**: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)` — 분류에서는 `cross_val_score`가 기본으로 사용
- **주의**: 어떤 클래스의 샘플이 1개뿐이면 오류 (최소 2개 필요). 회귀에서는 쓸 수 없다(연속값) → 구간으로 나눠서 사용하기도 함
- PyTorch `random_split`에는 이 기능이 없다 → 인덱스를 sklearn으로 나눈 뒤 `Subset` 사용

## 수식·원리
```
원본: 양성 50 / 음성 950 (5%)
stratify 분할 → train: 40 / 760 (5%),  test: 10 / 190 (5%)
```

## 코드 예시
```python
import numpy as np
from sklearn.model_selection import train_test_split

y = np.array([1] * 20 + [0] * 380)                     # 양성 5%
X = np.arange(400).reshape(-1, 1)
props = []
for seed in range(5):
    _, _, _, yt = train_test_split(X, y, test_size=0.1, random_state=seed)
    props.append(int(yt.sum()))
print(props)                                           # [2, 4, 2, 2, 4]  시드마다 양성 개수가 들쭉날쭉
_, _, _, yt = train_test_split(X, y, test_size=0.1, random_state=0, stratify=y)
print(int(yt.sum()), len(yt))                          # 2 40  ← 정확히 5%
```
