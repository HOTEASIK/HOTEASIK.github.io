# 지도·비지도·강화학습 구분

## 정의·핵심
- **구분 기준**: 학습할 때 **정답(레이블)을 어떻게 주는가**
- **지도학습 (Supervised)**
  - 입력 x와 정답 y가 **쌍으로** 주어진다 → x에서 y를 예측하는 함수 학습
  - **회귀**(연속값: 집값, 체중) / **분류**(범주: 스팸 여부, 숫자 0~9) → [[회귀와 분류의 차이]]
  - 강의 실습 대부분: 보스턴 집값(7차시), 이진분류(8차시), MNIST·CIFAR10(9~11차시), 객체 검출
  - 단점: 정답 만들기(라벨링)에 비용이 많이 든다
- **비지도학습 (Unsupervised)**
  - 정답 없이 데이터의 **구조·패턴**을 찾는다
  - 군집화(K-Means, 고객 그룹), 차원 축소(PCA, t-SNE 시각화), 이상 탐지, **AutoEncoder·VAE·GAN**(데이터 분포 학습) → [[AutoEncoder]]
- **자기지도학습 (Self-supervised)**: 정답을 데이터에서 **자동으로 만든다** (가린 단어 맞추기 — BERT, 다음 단어 예측 — GPT). 형식은 지도학습이지만 사람이 라벨을 달지 않음
- **강화학습 (Reinforcement)**
  - 정답 대신 **보상(Reward)** 만 주어진다. 에이전트가 환경과 상호작용하며 **누적 보상을 최대화**하는 행동(정책)을 학습
  - 상태·행동·보상, 시행착오, 보상이 **늦게** 올 수 있음 → [[강화학습 개요]]
  - 예: 게임, 로봇 제어, CartPole, LLM의 RLHF
- 준지도학습(Semi-supervised): 라벨 조금 + 라벨 없는 데이터 많이

## 수식·원리
```
지도:   D = {(xᵢ, yᵢ)}      → f(x) ≈ y
비지도: D = {xᵢ}            → p(x) 또는 군집·저차원 표현
강화:   (s, a, r, s')       → π(a|s) 로 Σ γᵗ rₜ 최대화
```

## 코드 예시
```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.linear_model import LogisticRegression
from sklearn.cluster import KMeans

X, y = load_iris(return_X_y=True)
sup = LogisticRegression(max_iter=300).fit(X, y)          # 지도: 정답 y 사용
print(round(sup.score(X, y), 2))                          # 0.97
km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(X)   # 비지도: y 없이 묶기
print(sorted(np.bincount(km.labels_).tolist()))           # [38, 50, 62]  묶음 크기 (이름은 모름)
```
