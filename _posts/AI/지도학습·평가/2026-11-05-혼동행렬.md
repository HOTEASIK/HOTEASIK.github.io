# 혼동행렬

## 정의·핵심
- **정의**: Confusion Matrix. 분류 모델의 예측 결과를 **실제 정답과 비교해 표로 정리**한 것. 모델이 **무엇을 무엇으로 헷갈리는지** 한눈에 보여 준다 (개론 8·10차시)
- **이진분류의 4칸** (Positive = 찾고 싶은 클래스: 질병, 스팸, 사기)
  - **TP (True Positive)**: 실제 긍정 → 긍정 예측 (정답)
  - **TN (True Negative)**: 실제 부정 → 부정 예측 (정답)
  - **FP (False Positive)**: 실제 부정 → 긍정으로 **잘못** 예측 — **1종 오류**, 오경보 (정상 메일을 스팸 처리)
  - **FN (False Negative)**: 실제 긍정 → 부정으로 **잘못** 예측 — **2종 오류**, 놓침 (환자를 정상으로)
  - 읽는 법: 두 번째 글자(P/N) = **예측**, 첫 글자(T/F) = 예측이 **맞았나**
- **sklearn 배치**: `confusion_matrix(y_true, y_pred)` → **행 = 실제, 열 = 예측**
  - 이진: `[[TN, FP], [FN, TP]]` → `tn, fp, fn, tp = cm.ravel()`
  - 대각선 = 맞힌 개수, 대각선 밖 = 오류
- **오류 유형별 대응 (강의)**: FN이 치명적(의료·보안) → 재현율 중시, 임계값 낮춤 / FP가 치명적(스팸 필터, 무고한 고객 차단) → 정밀도 중시, 임계값 높임
- **다중 클래스 혼동행렬** (10차시 예: 개·고양이·토끼 각 50마리)
  - K×K 표. `cm[i, j]` = 실제 i를 j로 예측한 수
  - 행 합 = 실제 클래스 개수, 행별 대각 비율 = 그 클래스의 재현율 / 열별 대각 비율 = 정밀도
  - 대각선 밖 큰 칸 = 자주 헷갈리는 쌍 (FashionMNIST: 셔츠 ↔ 티셔츠·코트)
- **시각화**: `seaborn.heatmap(cm, annot=True, fmt='d')` 또는 `ConfusionMatrixDisplay` → [[seaborn heatmap]], `normalize='true'`로 행 비율
- 여기서 정밀도·재현율·F1이 모두 계산된다 → [[정밀도(Precision)]], [[재현율(Recall)]]

## 수식·원리
```
               예측 Negative   예측 Positive
실제 Negative       TN             FP   (1종 오류)
실제 Positive       FN             TP
                 (2종 오류)
```

## 코드 예시
```python
import numpy as np
from sklearn.metrics import confusion_matrix

y_true = [1, 0, 1, 1, 0, 0, 1, 0]
y_pred = [1, 0, 0, 1, 0, 1, 1, 0]
cm = confusion_matrix(y_true, y_pred)
print(cm.tolist())                              # [[3, 1], [1, 3]]
tn, fp, fn, tp = cm.ravel()
print(tp, tn, fp, fn)                           # 3 3 1 1

yt = ["개"] * 5 + ["고양이"] * 5 + ["토끼"] * 5
yp = ["개"] * 4 + ["고양이"] + ["고양이"] * 3 + ["개"] * 2 + ["토끼"] * 5
cm3 = confusion_matrix(yt, yp, labels=["개", "고양이", "토끼"])
print(cm3.tolist())                             # [[4, 1, 0], [2, 3, 0], [0, 0, 5]]  개↔고양이 혼동
print(np.round(cm3.diagonal() / cm3.sum(1), 2).tolist())   # [0.8, 0.6, 1.0]  클래스별 재현율
```
