# 로지스틱 회귀

## 정의·핵심
- **정의**: 선형 모델 `z = Wx + b`의 출력에 **Sigmoid**를 씌워 **양성일 확률**로 바꾸는 **이진분류** 모델. 이름은 "회귀"지만 **분류 모델**이다 (개론 7·8차시, 대학원 02)
- **구조 = 선형회귀 + Sigmoid**
  - 선형 부분 z(로짓)는 −∞~∞ → Sigmoid로 0~1 확률 p → [[Sigmoid]]
  - p ≥ 0.5(= z ≥ 0)이면 1, 아니면 0 → [[이진분류 출력과 임계값]]
  - 결정 경계 `Wx + b = 0`은 **직선(평면)** → 선형 분류기 → [[결정 경계]]
- **손실**: MSE가 아니라 **BCE**(교차 엔트로피). PyTorch는 Sigmoid를 빼고 `nn.BCEWithLogitsLoss` → [[BCEWithLogitsLoss]]
- **왜 "회귀"인가**: 확률의 로그 오즈 `log(p/(1−p))`를 x의 **선형 회귀**로 모델링하기 때문 → [[로짓(Logit)]]
- **PyTorch 구현 (8차시, iris 2클래스)**
  - `nn.Linear(n_input, 1)` + `BCEWithLogitsLoss` (또는 `nn.Sigmoid` + `nn.BCELoss` — 강의 초반 방식)
  - 정답 `y`는 `(N, 1)` float
- **다중 클래스로 확장**: Softmax + CE → 다항 로지스틱 회귀(Softmax 회귀) → [[다중분류]]
- **sklearn**: `LogisticRegression()` — 기본 L2 규제 포함, 다중 클래스 자동 처리 (7차시 머신러닝 맛보기)
- 계수 해석: wⱼ가 1 늘면 **오즈가 e^wⱼ배**

## 수식·원리
```
z = w·x + b,   p = σ(z) = 1 / (1 + e^(−z))
BCE = −[y log p + (1−y) log(1−p)]
∂BCE/∂w = (p − y)·x     ← 선형회귀 MSE 기울기와 같은 모양
```

## 코드 예시
```python
import torch
import torch.nn as nn
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
X = torch.tensor(X[:100, :2], dtype=torch.float32)               # setosa vs versicolor, 꽃받침 2개 특징
y = torch.tensor(y[:100], dtype=torch.float32).reshape(-1, 1)
X = (X - X.mean(0)) / X.std(0)

net = nn.Linear(2, 1)
opt = torch.optim.SGD(net.parameters(), lr=0.1)
crit = nn.BCEWithLogitsLoss()
for _ in range(1000):
    opt.zero_grad(); loss = crit(net(X), y); loss.backward(); opt.step()
with torch.no_grad():
    prob = torch.sigmoid(net(X))
print(((prob > 0.5).float() == y).float().mean().item())        # 1.0  (선형 분리 가능)
print(round(prob[0].item(), 3) < 0.1, round(prob[-1].item(), 3) > 0.9)   # True True
```
