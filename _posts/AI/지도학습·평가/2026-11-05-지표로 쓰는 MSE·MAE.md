# 지표로 쓰는 MSE·MAE

## 정의·핵심
- **손실 vs 지표**: MSE·MAE는 **학습용 손실함수**로도, 사람이 성능을 판단하는 **평가 지표**로도 쓴다. 역할이 다르다
  - 손실: 미분 가능해야 하고, 학습을 잘 이끌어야 한다 → [[MSE]], [[MAE(L1Loss)]]
  - 지표: **해석하기 쉬워야** 하고, 실제 목적(비용)을 반영해야 한다
  - 예: MSE로 학습하고 MAE·RMSE·R²로 보고하는 경우가 흔하다
- **회귀 지표 정리**

| 지표 | 단위 | 해석 | 특징 |
|---|---|---|---|
| **MAE** | 원래 단위 | "평균 2.67만큼 틀린다" | 직관적, 이상치에 덜 민감 |
| **MSE** | 단위² | 해석 어려움 | 큰 오차 강조 |
| **RMSE** = √MSE | 원래 단위 | MAE와 비교 가능 | 큰 오차 강조. 항상 RMSE ≥ MAE |
| **R²** | 없음(비율) | 설명된 분산 비율 | 스케일 무관 → [[R² Score]] |
| MAPE | % | "평균 5% 틀린다" | 정답이 0 근처면 폭발 |

- **RMSE와 MAE의 차이가 크다** = 오차 분포에 **큰 오차(이상치)** 가 섞여 있다는 신호
- **표준화된 정답으로 학습했다면** 지표는 반드시 **원래 단위로 역변환한 뒤** 계산해야 해석이 된다
- sklearn: `mean_squared_error`, `mean_absolute_error`, `root_mean_squared_error`(최신), `r2_score`

## 수식·원리
```
MAE  = (1/n) Σ |y − ŷ|
RMSE = √((1/n) Σ (y − ŷ)²)  ≥ MAE
```

## 코드 예시
```python
import numpy as np
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

y = np.array([10.0, 20.0, 30.0]); p = np.array([12.0, 19.0, 35.0])
mae, mse = mean_absolute_error(y, p), mean_squared_error(y, p)
print(round(mae, 2), mse, round(np.sqrt(mse), 2), round(r2_score(y, p), 3))   # 2.67 10.0 3.16 0.85

p2 = np.array([11.0, 21.0, 22.0])                     # 큰 오차 하나
print(round(mean_absolute_error(y, p2), 2), round(np.sqrt(mean_squared_error(y, p2)), 2))   # 3.33 4.69  ← RMSE가 더 크게 반응
```
