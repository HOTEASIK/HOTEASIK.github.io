# R² Score

## 정의·핵심
- **정의**: 결정계수(Coefficient of Determination). 회귀 모델이 **정답의 변동(분산) 중 몇 %를 설명하는지** 나타내는 지표. `sklearn.metrics.r2_score(y_true, y_pred)` (개론 7차시)
- **구성**
  - **SS_tot (총 제곱합)**: `Σ(y − ȳ)²` — 그냥 **평균값으로만 예측**했을 때의 오차 (기준선)
  - **SS_res (잔차 제곱합)**: `Σ(y − ŷ)²` — 모델의 오차 (= SSE)
  - **R² = 1 − SS_res / SS_tot**: 평균 예측 대비 오차를 얼마나 줄였나
- **값 읽기**
  - **1**: 완벽한 예측
  - **0**: 평균으로 찍는 것과 같은 수준
  - **음수**: 평균보다도 못함 (잘못된 모델, 테스트 데이터에서 가능)
  - 예: R² = 0.75 → 집값 변동의 75%를 설명
- **장점**: MSE·MAE는 단위·스케일에 따라 값이 달라 "좋은지" 판단이 어렵지만, R²는 **스케일과 무관한 비율**이라 데이터셋 간 비교·해석이 쉽다
- **주의**
  - 특징을 추가하면 훈련 R²는 **거의 항상 오른다** → 과적합 판단은 검증·테스트 R²로. (보정 R²: 특징 수 반영)
  - R²가 높아도 오차가 실무에 허용되는지는 MAE·RMSE로 따로 확인
- sklearn 회귀 모델의 `.score(X, y)`가 R²

## 수식·원리
```
SS_res = Σ (yᵢ − ŷᵢ)²
SS_tot = Σ (yᵢ − ȳ)²
R² = 1 − SS_res / SS_tot = 1 − MSE / Var(y)
```

## 코드 예시
```python
import numpy as np
from sklearn.metrics import r2_score

y = np.array([3.0, 5.0, 7.0, 9.0])
pred = np.array([2.8, 5.3, 6.9, 9.4])
ss_res = ((y - pred) ** 2).sum(); ss_tot = ((y - y.mean()) ** 2).sum()
print(round(ss_res, 2), ss_tot, round(1 - ss_res / ss_tot, 4))      # 0.3 20.0 0.985
print(round(r2_score(y, pred), 4))                                   # 0.985
print(r2_score(y, np.full(4, y.mean())))                             # 0.0   평균 예측
print(r2_score(y, np.array([9.0, 7.0, 5.0, 3.0])))                   # -3.0  평균보다 못함
```
