# 오버샘플링·언더샘플링

## 정의·핵심
- **공통 목표**: 학습에 쓰는 데이터의 **클래스 비율을 맞춰서**(리샘플링) 모델이 소수 클래스도 충분히 보게 한다
- **오버샘플링 (Oversampling)**: **소수 클래스를 늘린다**
  - 단순 복제(무작위 중복 추출), 증강을 곁들인 복제, 합성(SMOTE) → [[SMOTE]]
  - 장점: 데이터를 버리지 않는다
  - 단점: 같은 샘플을 반복해서 보므로 **소수 클래스에 과적합** 위험, 학습 시간 증가
- **언더샘플링 (Undersampling)**: **다수 클래스를 줄인다**
  - 무작위로 일부만 사용
  - 장점: 빠르고 간단, 메모리 절약
  - 단점: **정보 손실** — 버린 다수 샘플에 중요한 패턴이 있을 수 있다. 데이터가 원래 적으면 쓰기 어렵다
- **PyTorch: `WeightedRandomSampler`** (강의 추천 "보통 이것 하나로 충분")
  - 데이터를 복제하지 않고 **뽑을 확률**을 샘플마다 다르게 → 미니배치 안의 클래스 비율이 균형
  - 샘플 가중치 = `1 / (그 샘플 클래스의 개수)`
  - `sampler = WeightedRandomSampler(weights, num_samples=len(weights), replacement=True)`
  - `DataLoader(ds, batch_size, sampler=sampler)` — **`shuffle=True`와 함께 쓰면 오류** (sampler가 섞기를 대신함)
  - `replacement=True`라 소수 샘플은 여러 번, 다수 샘플은 일부만 뽑힌다 → 오버+언더 효과
- **규칙**: **훈련 데이터에만** 적용. 분할을 먼저 하고 리샘플링 (먼저 복제하고 나누면 같은 샘플이 train·test에 → 누수) → [[데이터 누수(Data Leakage)]]

## 수식·원리
```
weightᵢ = 1 / N_{class(i)}
P(샘플 i 선택) = weightᵢ / Σ weight     → 클래스별 선택 확률이 같아짐
```

## 코드 예시
```python
import numpy as np
import torch
from torch.utils.data import DataLoader, TensorDataset, WeightedRandomSampler

y = torch.tensor([0] * 95 + [1] * 5)
ds = TensorDataset(torch.randn(100, 3), y)
class_count = torch.bincount(y)                          # [95, 5]
weights = (1.0 / class_count.float())[y]                 # 샘플별 가중치
sampler = WeightedRandomSampler(weights, num_samples=len(weights), replacement=True,
                                generator=torch.Generator().manual_seed(0))
loader = DataLoader(ds, batch_size=100, sampler=sampler)
_, yb = next(iter(loader))
print(class_count.tolist(), torch.bincount(yb).tolist())   # [95, 5] [53, 47]  ← 배치가 균형

rng = np.random.default_rng(0)                           # 단순 오버/언더샘플링 (인덱스)
idx0, idx1 = np.where(y.numpy() == 0)[0], np.where(y.numpy() == 1)[0]
over = np.r_[idx0, rng.choice(idx1, 95, replace=True)]
under = np.r_[rng.choice(idx0, 5, replace=False), idx1]
print(len(over), len(under))                             # 190 10
```
