# 실전 예측 함수

## 정의·핵심
- **정의**: 학습이 끝난 모델을 **저장 → 다시 불러와 → 새 데이터 한 건(또는 여러 건)을 예측**하는 함수. 실제 서비스에 넣는 마지막 단계 (개론 10·15차시)
- **저장 (학습 쪽)**: 가중치만 저장하는 `state_dict` 방식이 표준 → 자세한 내용은 [[state_dict 저장·불러오기]]
  - `torch.save(model.state_dict(), 'best.pt')` — Early Stopping의 best 시점
  - 함께 저장할 것: **클래스 이름 목록**(`class_names`), 전처리 설정(입력 크기, 평균·표준편차), 표준화 scaler, 임계값
- **예측 함수가 꼭 해야 할 일 (빠뜨리기 쉬운 순서대로)**
  1. **같은 모델 클래스로 객체 생성** 후 `load_state_dict(torch.load(path, map_location=device))` — GPU에서 저장한 것을 CPU에서 열려면 `map_location`
  2. **`model.eval()`** — Dropout·BN 추론 모드 → [[train()·eval() 모드]]
  3. **학습 때와 똑같은 전처리** — Resize, ToTensor, Normalize(같은 mean/std), 표형 데이터는 **저장한 scaler로 transform**
  4. **배치 차원 추가** — 한 장이면 `(3, 224, 224)` → `unsqueeze(0)` → `(1, 3, 224, 224)` → [[view·reshape·unsqueeze]]
  5. `.to(device)`, **`torch.no_grad()`** 안에서 순전파
  6. 로짓 → `softmax` 확률 → `argmax` → **클래스 이름**으로 변환 (이진은 sigmoid + 임계값)
  7. 결과를 `.item()`/`.cpu()`로 파이썬 값으로
- **흔한 실수**: eval() 누락, 정규화 누락·불일치, 채널 순서(OpenCV BGR → RGB), 흑백 이미지(1채널)를 3채널 모델에, `class_to_idx` 순서 착각 (ImageFolder는 폴더 이름 **알파벳순**)

## 수식·원리
```
img ─preprocess─▶ (3,H,W) ─unsqueeze(0)─▶ (1,3,H,W) ─model.eval()+no_grad─▶ logits
    ─softmax─▶ prob ─argmax─▶ idx ─class_names[idx]─▶ "고양이" (prob[idx])
```

## 코드 예시
```python
import os, tempfile
import numpy as np
import torch
import torch.nn as nn
from PIL import Image
from torchvision import transforms

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.body = nn.Sequential(nn.Flatten(), nn.Linear(3 * 32 * 32, 64), nn.ReLU(), nn.Dropout(0.5), nn.Linear(64, 3))
    def forward(self, x):
        return self.body(x)

path = os.path.join(tempfile.mkdtemp(), "best.pt")
torch.save({"state_dict": Net().state_dict(), "class_names": ["개", "고양이", "토끼"]}, path)   # 학습 쪽 저장

tf = transforms.Compose([transforms.Resize((32, 32)), transforms.ToTensor(), transforms.Normalize(0.5, 0.5)])

def predict(img, path, device="cpu"):
    ckpt = torch.load(path, map_location=device)
    model = Net().to(device)
    model.load_state_dict(ckpt["state_dict"])
    model.eval()                                          # 필수
    x = tf(img.convert("RGB")).unsqueeze(0).to(device)    # (1, 3, 32, 32)
    with torch.no_grad():
        prob = torch.softmax(model(x), dim=1)[0]
    idx = prob.argmax().item()
    return ckpt["class_names"][idx], round(prob[idx].item(), 3)

img = Image.fromarray((np.random.rand(50, 40, 3) * 255).astype(np.uint8))
name, p = predict(img, path)
print(name in ["개", "고양이", "토끼"], 0 < p <= 1)         # True True
print(predict(img, path) == (name, p))                    # True  eval 덕분에 매번 같은 결과
```
