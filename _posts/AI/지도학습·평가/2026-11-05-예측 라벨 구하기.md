# 예측 라벨 구하기

## 정의·핵심
- **목표**: 모델 출력 `(배치, 클래스 수)`에서 **샘플마다 가장 큰 값의 위치(클래스 번호)** 를 뽑는다
- **`torch.max(outputs, 1)`** (강의에서 자주 쓰는 방식, 9·10차시)
  - 두 값을 돌려준다: `(최댓값, 위치)` → `values, indices`
  - 예측 라벨은 **두 번째** → `predicted = torch.max(outputs, 1)[1]` 또는 `_, predicted = torch.max(outputs, 1)`
  - `1`은 **dim=1(클래스 축)**. 0을 주면 배치 축으로 계산되어 엉뚱한 결과
- **`outputs.argmax(dim=1)`**: 위치만 바로 → 더 간결
- **Softmax를 할 필요가 없다**: Softmax는 순서를 유지하므로 로짓의 argmax = 확률의 argmax. 확률 값 자체가 필요할 때만 Softmax → [[Softmax]]
- **정확도 계산까지**: `(predicted == labels).sum().item()` → 맞힌 개수, 배치마다 누적 후 전체 수로 나눔 → [[정확도(Accuracy)]]
- **이진분류는 다르다**: 출력이 1개이므로 argmax가 아니라 임계값 `(logits > 0)` → [[이진분류 출력과 임계값]]
- **Top-k**: `outputs.topk(5, dim=1).indices` → ImageNet Top-5 정확도
- 결과를 NumPy·리스트로: `predicted.cpu().numpy()` (sklearn 지표에 넣을 때) → [[item·numpy 변환]]

## 수식·원리
```
outputs: (N, K)
torch.max(outputs, 1) → (values: (N,), indices: (N,))
ŷ = indices = argmax over dim 1
```

## 코드 예시
```python
import torch

outputs = torch.tensor([[0.1, 2.5, -1.0], [3.0, 0.2, 0.1], [0.0, 0.3, 0.9]])
labels = torch.tensor([1, 0, 1])
values, predicted = torch.max(outputs, 1)
print([round(v, 1) for v in values.tolist()], predicted.tolist())   # [2.5, 3.0, 0.9] [1, 0, 2]
print(torch.equal(predicted, outputs.argmax(1)))      # True
print(torch.equal(predicted, torch.softmax(outputs, 1).argmax(1)))   # True  Softmax 불필요
print((predicted == labels).sum().item())             # 2  맞힌 개수
print(torch.max(outputs, 0)[1].tolist())              # [1, 0, 2]  ← dim=0은 클래스별 최고 샘플(의미 다름)
print(outputs.topk(2, dim=1).indices.tolist())        # [[1, 0], [0, 1], [2, 1]]
```
