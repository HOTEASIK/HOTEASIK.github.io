# 결정 경계

## 정의·핵심
- **정의**: Decision Boundary. 입력 공간에서 분류 모델의 **예측 클래스가 바뀌는 경계선(면)**. 경계 한쪽은 클래스 A, 반대쪽은 B로 예측
- **선형 모델의 결정 경계**: 로지스틱 회귀는 `w·x + b = 0` (확률 0.5, 로짓 0인 곳) → 2D에서는 **직선**, 3D에서는 평면 (개론 8차시에서 iris 2특징 산포도 위에 직선을 그려 확인)
  - w는 경계에 **수직인 방향**, b는 경계의 위치를 옮긴다
  - 직선의 식으로 바꾸면 `x₂ = −(w₁x₁ + b) / w₂`
- **임계값을 바꾸면** 경계가 평행 이동한다 (`w·x + b = log(t/(1−t))`)
- **비선형 결정 경계**: 은닉층 + 활성화 함수가 있는 신경망은 **곡선** 경계를 만든다 → XOR, 동심원, 나선 데이터도 분류 가능 → [[XOR 문제]], [[활성화 함수의 목적]]
- **다중분류**: 클래스마다 점수 `zₖ`가 있고, 두 클래스의 점수가 같아지는 곳(`zᵢ = zⱼ`)이 경계 → 공간이 여러 영역으로 나뉜다
- **시각화 방법**: 입력 공간을 촘촘한 격자로 만들어 모든 점을 예측하고, `plt.contourf`로 색칠 → 모델이 무엇을 배웠는지 직관적으로 확인 (과적합이면 경계가 구불구불)

## 수식·원리
```
로지스틱 회귀:  p = 0.5  ⇔  w₁x₁ + w₂x₂ + b = 0  ⇔  x₂ = −(w₁/w₂)x₁ − b/w₂
신경망:  f(x) = 0 인 곡선(면)
```

## 코드 예시
```python
import numpy as np
from sklearn.datasets import make_circles
from sklearn.linear_model import LogisticRegression
from sklearn.neural_network import MLPClassifier

X, y = make_circles(n_samples=300, noise=0.05, factor=0.4, random_state=0)   # 동심원
lin = LogisticRegression().fit(X, y)
mlp = MLPClassifier(hidden_layer_sizes=(16,), max_iter=3000, random_state=0).fit(X, y)
print(round(lin.score(X, y), 2), round(mlp.score(X, y), 2))   # 0.5 근처 1.0  ← 직선으론 불가, 곡선 경계로 해결

w, b = lin.coef_[0], lin.intercept_[0]
x1 = 0.5; x2 = -(w[0] * x1 + b) / w[1]                       # 직선 경계 위의 점
print(abs(lin.decision_function([[x1, x2]])[0]) < 1e-9)       # True  경계 위 = 로짓 0

xx, yy = np.meshgrid(np.linspace(-1.5, 1.5, 50), np.linspace(-1.5, 1.5, 50))
Z = mlp.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
print(Z.shape, Z[25, 25], Z[0, 0])                            # (50, 50) 1 0  가운데=안쪽 원, 모서리=바깥
# plt.contourf(xx, yy, Z, alpha=0.3); plt.scatter(X[:, 0], X[:, 1], c=y)
```
