# SMOTE

## 정의·핵심
- **정의**: Synthetic Minority Over-sampling Technique. 소수 클래스를 단순 복제하지 않고, **소수 샘플과 그 이웃 사이를 선으로 이어 그 위의 새 점을 합성**하는 오버샘플링 (개론 10차시 "리샘플링: 오버샘플링/언더샘플링·SMOTE")
- **알고리즘**
  1. 소수 클래스 샘플 x 하나를 고른다
  2. 같은 소수 클래스에서 **k개의 최근접 이웃**(보통 k=5)을 찾는다
  3. 그중 하나 x_nn을 무작위로 고른다
  4. 둘 사이의 무작위 지점 `x_new = x + λ·(x_nn − x)`, λ ~ U(0, 1) 을 새 샘플로 만든다
  5. 원하는 개수가 될 때까지 반복
- **장점**: 똑같은 점을 반복하는 단순 복제보다 **과적합이 덜하고** 소수 클래스 영역을 넓게 채운다
- **단점·주의**
  - 클래스가 겹치는 경계 근처에서 **잡음 샘플**을 만들 수 있다 (변형: Borderline-SMOTE, SMOTE-Tomek, ADASYN)
  - **표 형태(수치 특징)** 데이터용. **이미지·텍스트에는 맞지 않는다** — 두 이미지 픽셀을 섞으면 의미 없는 이미지 → 이미지는 증강 + WeightedRandomSampler
  - 범주형 특징은 SMOTENC 사용
  - **훈련 데이터에만**, 교차 검증에서는 폴드 안에서 적용 (`imblearn.pipeline`)
- **라이브러리**: `imbalanced-learn` (`from imblearn.over_sampling import SMOTE`, `SMOTE(k_neighbors=5).fit_resample(X, y)`) — 이 PC에는 미설치라 아래는 직접 구현

## 수식·원리
```
x_new = x + λ · (x_nn − x),   λ ~ Uniform(0, 1),  x_nn ∈ kNN(x) ∩ 소수 클래스
```

## 코드 예시
```python
import numpy as np
from sklearn.neighbors import NearestNeighbors

def smote(X_min, n_new, k=5, seed=0):
    rng = np.random.default_rng(seed)
    nn = NearestNeighbors(n_neighbors=k + 1).fit(X_min)
    _, idx = nn.kneighbors(X_min)                       # idx[:, 0]은 자기 자신
    out = []
    for _ in range(n_new):
        i = rng.integers(len(X_min)); j = idx[i, rng.integers(1, k + 1)]
        out.append(X_min[i] + rng.random() * (X_min[j] - X_min[i]))
    return np.array(out)

rng = np.random.default_rng(0)
X_min = rng.normal([5, 5], 0.5, (10, 2))                # 소수 클래스 10개
X_syn = smote(X_min, 90)
print(X_syn.shape)                                      # (90, 2)  → 소수 클래스 100개로
lo, hi = X_min.min(0), X_min.max(0)
print(bool(((X_syn >= lo) & (X_syn <= hi)).all()))      # True  기존 샘플들 사이에 생성
# from imblearn.over_sampling import SMOTE; X_res, y_res = SMOTE().fit_resample(X, y)
```
