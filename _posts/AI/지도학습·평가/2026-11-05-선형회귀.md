# 선형회귀

## 정의·핵심
- **정의**: 입력과 출력 사이의 관계를 **직선(평면)** `y = Wx + b`로 나타내고, 데이터를 가장 잘 설명하는 W(기울기·가중치)와 b(절편·편향)를 찾는 모델 (개론 4·7차시)
- **왜 선형회귀부터 배우나**: "가장 단순하지만 모든 신경망의 기본 블록", "CNN, Transformer도 결국 이 구조의 반복" — 예측 → 손실 → 경사 → 수정의 학습 사이클을 가장 작게 보여 준다
- **푸는 방법 두 가지**
  1. **최소제곱법(OLS)**: 수식으로 한 번에 정답을 구한다 → [[최소제곱법(OLS)]]
  2. **경사하강법**: 손실(MSE)을 조금씩 줄여 가며 찾는다 → 딥러닝과 같은 방식 → [[경사하강법(GD)]]
- **PyTorch 구현** (7차시)
  - 모델: `nn.Linear(n_input, 1)` 하나
  - 손실: `nn.MSELoss()`, 옵티마이저: `optim.SGD(net.parameters(), lr)`
  - 학습 후 `net.weight`, `net.bias`가 회귀 계수
- **강의 데이터**
  - 신장 → 체중 (5명, 4차시): W = 1.82, B = 0.37
  - **보스턴 집값** (7차시): 506개 지역, 13개 특징(방 개수 RM, 저소득층 비율 LSTAT 등) → 주택 가격(MEDV). sklearn에서 제거되어 `pd.read_csv(url, sep="\s+", skiprows=22, header=None)`로 읽는다
- **가정과 한계**: 관계가 선형이어야 한다, 이상치에 민감(MSE). 비선형 관계는 특징 변환(다항식) 또는 신경망 → [[선형 모델의 한계와 비선형성]]
- 특징 단위가 다르면(방 개수 vs 세금) 학습이 불안정 → **표준화** 후 학습 → [[표준화(StandardScaler)]]

## 수식·원리
```
단순:  ŷ = w·x + b
다중:  ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b = Xw + b
손실:  MSE = (1/n) Σ (yᵢ − ŷᵢ)²
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
X = torch.randn(200, 2)
y = X @ torch.tensor([[3.0], [-2.0]]) + 1.0 + 0.1 * torch.randn(200, 1)

net = nn.Linear(2, 1)
criterion = nn.MSELoss()
opt = torch.optim.SGD(net.parameters(), lr=0.1)
for epoch in range(200):
    opt.zero_grad()
    loss = criterion(net(X), y)
    loss.backward(); opt.step()
print([round(v, 1) for v in net.weight.flatten().tolist()], round(net.bias.item(), 1))   # [3.0, -2.0] 1.0
print(round(loss.item(), 3))                                                            # 0.01 근처 (잡음 크기)
```
