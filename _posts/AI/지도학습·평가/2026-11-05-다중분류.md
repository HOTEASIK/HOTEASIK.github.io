# 다중분류

## 정의·핵심
- **정의**: Multi-class Classification. **3개 이상의 클래스 중 하나**를 고르는 분류. 예: iris 3품종(9차시), MNIST 숫자 0~9·FashionMNIST 10종(10차시), CIFAR10(11차시)
- **모델 구조**
  - 출력층 뉴런 수 = **클래스 수 K** (`nn.Linear(n_hidden, K)`) → 클래스별 점수(로짓)
  - Softmax로 합이 1인 확률 → 가장 큰 클래스를 예측 → [[Softmax]]
  - 손실 `nn.CrossEntropyLoss` (Softmax 내장, 정답은 클래스 인덱스) → [[CrossEntropyLoss]]
- **1 대 N (One-vs-Rest, OvR)** 방식 (개론 9차시)
  - 이진분류기를 **클래스마다 하나씩** K개 만든다: "0인가 아닌가", "1인가 아닌가", …
  - 가장 높은 점수를 낸 분류기의 클래스를 선택
  - 신경망의 K개 출력 뉴런은 사실상 K개의 선형 분류기를 동시에 학습하는 것이고, Softmax가 이를 서로 경쟁시켜 확률로 묶는다
  - 다중분류 ROC를 그릴 때도 클래스별 OvR로 나눠 그린다 → [[다중분류 ROC]]
- **두 가지 모델 작성 패턴** (9차시): 로짓 출력 + CrossEntropyLoss / LogSoftmax 포함 + NLLLoss → [[LogSoftmax]]
- **예측 라벨**: `outputs.argmax(1)` 또는 `torch.max(outputs, 1)[1]` → [[예측 라벨 구하기]]
- **평가**: 정확도, 혼동행렬(어떤 클래스끼리 헷갈리나), 클래스별 정밀도·재현율과 macro/weighted 평균 → [[혼동행렬]], [[macro·micro·weighted 평균]]
- **다중 라벨(Multi-label)과 구분**: 한 샘플이 여러 클래스에 동시에 속할 수 있으면(사진에 개와 고양이) 클래스마다 **Sigmoid + BCE**

## 수식·원리
```
z = W h + b ∈ ℝᴷ
p = softmax(z),   ŷ = argmaxₖ pₖ = argmaxₖ zₖ
L = −log p_y
```

## 코드 예시
```python
import torch
import torch.nn as nn
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
X = torch.tensor((X - X.mean(0)) / X.std(0), dtype=torch.float32); y = torch.tensor(y)
torch.manual_seed(0)
net = nn.Sequential(nn.Linear(4, 16), nn.ReLU(), nn.Linear(16, 3))   # 출력 3 = 클래스 수
opt = torch.optim.Adam(net.parameters(), lr=0.01)
for _ in range(300):
    opt.zero_grad(); loss = nn.CrossEntropyLoss()(net(X), y); loss.backward(); opt.step()
with torch.no_grad():
    out = net(X)
print(out.shape, (out.argmax(1) == y).float().mean().item() > 0.95)   # torch.Size([150, 3]) True
print(torch.softmax(out[:1], 1).sum().item())                         # 1.0  (확률 합)
```
