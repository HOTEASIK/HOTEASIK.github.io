# ROC 곡선

## 정의·핵심
- **정의**: ROC(Receiver Operating Characteristic). **임계값을 1에서 0까지 바꿔 가며** 각 임계값의 (FPR, TPR)을 찍어 이은 곡선. 특정 임계값에 묶이지 않고 모델의 **분리 능력 전체**를 보여 준다 (개론 8·10차시)
- **두 축**
  - **X축 FPR (False Positive Rate)** = `FP / (FP + TN)` — 실제 음성 중 **잘못 양성**이라고 한 비율 (오경보율, 1 − 특이도)
  - **Y축 TPR (True Positive Rate)** = `TP / (TP + FN)` = **재현율**
- **곡선 읽기**
  - (0, 0): 임계값 1 — 모두 음성 / (1, 1): 임계값 0 — 모두 양성
  - **왼쪽 위 (0, 1)** 에 가까울수록 좋다: 오경보 없이 다 찾음
  - **대각선** = 무작위 추측(동전 던지기)
  - 곡선이 대각선 아래 = 예측을 거꾸로 하는 모델
  - 곡선 아래 면적 = **AUC** → [[AUC]]
- **입력은 점수(확률)**: `roc_curve(y_true, y_score)` — `y_score`는 0/1 예측이 아니라 **양성 확률(또는 로짓)**. 0/1을 넣으면 점 하나짜리 곡선이 된다
- **임계값 고르기**: Youden's J = TPR − FPR이 최대인 점, 또는 목표 TPR에서 FPR이 가장 낮은 점
- **ROC vs PR 곡선**: 음성이 압도적으로 많으면 FP가 늘어도 FPR은 작게 움직여 ROC가 좋아 보인다 → 불균형이 심하면 **PR 곡선도 함께** → [[Precision–Recall 트레이드오프]]
- 다중분류는 클래스별 OvR로 → [[다중분류 ROC]]

## 수식·원리
```
FPR(t) = FP(t) / (FP(t) + TN(t)),   TPR(t) = TP(t) / (TP(t) + FN(t))
t: 1 → 0  로 내리면서 (FPR, TPR)이 (0,0) → (1,1)로 이동
```

## 코드 예시
```python
import numpy as np
from sklearn.metrics import roc_curve

y = np.array([0, 0, 1, 0, 1, 1, 0, 1])
score = np.array([0.1, 0.4, 0.35, 0.2, 0.8, 0.7, 0.6, 0.9])
fpr, tpr, th = roc_curve(y, score)
for f, t, h in zip(fpr, tpr, th):
    print(round(f, 2), round(t, 2), h)       # 임계값이 내려갈수록 FPR·TPR 모두 증가
best = (tpr - fpr).argmax()
print("best threshold", th[best])            # Youden J 최대 지점
# plt.plot(fpr, tpr); plt.plot([0, 1], [0, 1], "--")  ← 대각선 = 무작위
```
