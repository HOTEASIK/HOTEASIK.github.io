# 최소제곱법(OLS)

## 정의·핵심
- **정의**: Ordinary Least Squares. 예측과 실제의 **오차 제곱합(SSE)이 가장 작아지는** 직선의 계수를 찾는 방법 (개론 7차시 "선형회귀 OLS")
- **SSE (Sum of Squared Errors)**: `Σ(yᵢ − ŷᵢ)²` — 잔차(residual, 실제 − 예측)를 제곱해 더한 값. 제곱하는 이유: 양·음 오차가 상쇄되지 않게, 큰 오차에 더 큰 벌점, 미분이 쉬움
  - SSE를 n으로 나누면 MSE → OLS = MSE를 최소화하는 것과 같다
- **해를 수식으로 바로 구한다 (정규방정식)**: SSE를 W로 미분해 0이 되는 점 → `W = (XᵀX)⁻¹Xᵀy`
  - 반복 학습이 필요 없고 **정확한 최적해**
  - 단순회귀에서는 `w = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²`, `b = ȳ − w·x̄`
- **경사하강법과 비교**

| | OLS (정규방정식) | 경사하강법 |
|---|---|---|
| 방법 | 행렬 계산 한 번 | 반복해서 조금씩 |
| 결과 | 정확한 최적해 | 근사 (충분히 반복하면 같음) |
| 한계 | 특징 수가 많으면 역행렬이 비쌈(O(n³)), 특징끼리 강한 상관이면 불안정 | 학습률 선택 필요 |
| 확장 | 선형 모델만 | 신경망 등 모든 모델 |

- sklearn `LinearRegression`, `np.linalg.lstsq`가 OLS. 강의는 OLS 결과와 PyTorch 경사하강법 결과가 같아지는 것을 확인한다
- 역행렬이 불안정하면 L2 규제를 더한 Ridge: `(XᵀX + λI)⁻¹Xᵀy` → [[L2 규제(Ridge, weight_decay)]]

## 수식·원리
```
SSE(W) = Σ (yᵢ − xᵢᵀW)² = ‖y − XW‖²
∂SSE/∂W = −2Xᵀ(y − XW) = 0  →  W = (XᵀX)⁻¹ Xᵀ y
(X에 1로 된 열을 붙이면 절편 b도 함께 구해짐)
```

## 코드 예시
```python
import numpy as np
from sklearn.linear_model import LinearRegression

x = np.array([166, 176, 171, 173, 169.0]); y = np.array([58.7, 75.7, 62.1, 70.4, 60.1])
w = ((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean()) ** 2).sum()
b = y.mean() - w * x.mean()
print(round(w, 3), round(b, 2))                              # 1.821 -245.94  ← 강의 경사하강법 결과 W=1.82와 같은 기울기

X = np.c_[np.ones(5), x]                                      # 절편용 1 열 추가
print(np.round(np.linalg.inv(X.T @ X) @ X.T @ y, 3))          # [-245.938    1.821]  정규방정식
lr = LinearRegression().fit(x[:, None], y)
print(round(lr.coef_[0], 3), round(lr.intercept_, 2))         # 1.821 -245.94
print(round(((y - (w * x + b)) ** 2).sum(), 2))               # 22.7  최소 SSE
```
