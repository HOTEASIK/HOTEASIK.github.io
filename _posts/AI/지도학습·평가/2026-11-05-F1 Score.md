# F1 Score

## 정의·핵심
- **정의**: 정밀도와 재현율의 **조화평균**. 두 지표의 **균형**을 하나의 숫자로 평가 (개론 10차시)
- **왜 산술평균이 아니라 조화평균인가**
  - 조화평균은 **작은 값에 크게 끌려간다** → 둘 중 하나라도 낮으면 F1이 낮다
  - 예: 정밀도 1.0, 재현율 0.1 → 산술평균 0.55(그럴듯해 보임) / **F1 = 0.18**(실제로 나쁨)
  - "모두 양성" 같은 꼼수로 한쪽만 올리면 F1이 잡아낸다
- **값의 범위**: 0~1, 정밀도 = 재현율이면 F1도 같은 값
- **언제 쓰나**
  - **클래스 불균형** 데이터에서 정확도 대신 (사기 탐지, 의료, 스팸)
  - FP와 FN을 비슷하게 중요하게 볼 때
  - 임계값 선택 기준 (F1 최대가 되는 임계값)
- **Fβ Score**: β > 1이면 재현율을, β < 1이면 정밀도를 더 중시 (F2: 재현율 2배 중요)
- **다중분류**: 클래스별 F1을 구해 평균 — macro(클래스 동등), weighted(개수 가중), micro → [[macro·micro·weighted 평균]]
- 단점: TN을 전혀 고려하지 않는다 (음성을 잘 맞히는 능력은 반영 안 됨)
- sklearn: `f1_score(y_true, y_pred, average='binary'|'macro'|...)`

## 수식·원리
```
F1 = 2 · P · R / (P + R) = 2TP / (2TP + FP + FN)
Fβ = (1 + β²) · P · R / (β²·P + R)
```

## 코드 예시
```python
from sklearn.metrics import f1_score, fbeta_score, precision_score, recall_score

y_true = [1, 0, 1, 1, 0, 0, 1, 0]
y_pred = [1, 0, 0, 1, 0, 1, 1, 0]
p, r = precision_score(y_true, y_pred), recall_score(y_true, y_pred)
print(p, r, f1_score(y_true, y_pred))                    # 0.75 0.75 0.75

P, R = 1.0, 0.1
print((P + R) / 2, round(2 * P * R / (P + R), 2))        # 0.55 0.18  ← 조화평균은 낮은 쪽에 끌림
print(round(fbeta_score(y_true, [1] * 8, beta=2), 3), round(f1_score(y_true, [1] * 8), 3))   # 0.833 0.667  F2는 재현율 중시
```
