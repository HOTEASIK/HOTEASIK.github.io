# XAI 개요

## 정의·핵심
- **정의 (응용 10차시)**: XAI(eXplainable AI, 설명 가능한 AI)는 복잡한 AI 모델의 **의사결정 과정을 시각화하고 설명**해, 인간이 **이해하고 검증**할 수 있게 만드는 기술
  - 핵심: **결과(What) + 이유(Why) = 신뢰(Trust)**
- **왜 필요한가 (강의)**: AI의 판단 근거를 모르면 신뢰할 수 없음
  - **의료 진단**: "왜 암이라고 판단했나요?" → 의사가 병변 위치를 확인해야 결과 신뢰
  - **대출 심사**: "왜 거절되었나요?" → 투명한 사유가 있어야 고객 이의 제기 가능
  - **자율 주행**: "왜 급정거했나요?" → 사고 시 원인 추적·책임 소재 규명
- **정확도-설명력 트레이드오프 (10차시 과제 문항 1)**: 딥러닝은 Decision Tree·선형 회귀보다 성능은 뛰어나지만 내부를 이해하기 어려움 → 모델이 복잡할수록 성능↑ 설명력↓ (**Accuracy-Interpretability Trade-off**). 내부를 알 수 없어 **블랙박스(Black-box) 모델**이라 부름
- **블랙박스 AI vs XAI (강의 비교표)**

| 항목 | 블랙박스 AI | 설명 가능한 AI |
|---|---|---|
| 이해도 | 입력과 출력만 확인 가능 | 근거(Feature Importance, Heatmap)를 시각적으로 제공 |
| 신뢰·책임 | 오작동 원인 파악 어려움, 책임 불분명 | 의사결정 경로 추적 → 오류 수정·책임 규명 용이 |
| 규제·감사 | 설명 요구에 대응 어려움 | 법적 규제 준수(GDPR 설명 요구권), 감사 보고서에 유리 |
| 사용자 수용성 | "AI가 그렇다니까 믿으세요" | "이 부분 때문에 암으로 진단했습니다" |

- **활용 사례 (강의)**: 의료(히트맵으로 판독 보조) · 금융(소득·연체 기록 등 결정 요인 제시) · 제조(결함·흠집 위치 표시) · 자율주행(보행자·신호등 등 중요 객체) · 추천("지난달 산 운동화와 비슷해서") · 공공·법률(공정성 검증) → [[의료영상에서 Grad-CAM 활용]]
- **4가지 주요 기법 (강의)**: **CAM / Grad-CAM**(어디를 봤나, 위치) · **Saliency Map**(픽셀 민감도) · **Integrated Gradients**(경로 누적 기여도, 신뢰성) → [[XAI 기법 비교·도구]]
- **흔한 오해 (강의)**: "설명이 그럴싸하면 정답이다?" → **No**. 모델이 **틀린 이유**를 설명할 수도 있음. XAI는 모델의 '생각'을 보여 줄 뿐 현실의 진실을 보장하지 않음
  - 예: 늑대 분류기가 늑대가 아니라 **배경의 눈(snow)** 을 보고 판단 → XAI로 데이터 편향(지름길 학습) 발견

## 수식·원리
```
기여도(Attribution):  입력 x의 각 특징 i에 점수 a_i 부여  →  "f(x)에 얼마나 기여했나"
기울기 기반:   a_i ∝ ∂f_c / ∂x_i                (Saliency, Grad-CAM, IG)
가중치 기반:   heatmap = Σ_k w_k^c A_k          (CAM)
설명 ≠ 정답:  설명은 모델 f의 근거일 뿐, 실제 정답 y와는 별개
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
# 지름길 학습 예: 라벨이 "배경 픽셀(마지막 특징)"과 함께 움직이는 데이터
N = 400
obj = torch.randn(N, 1)                              # 진짜 물체 특징 (라벨과 약한 관계)
y = (obj[:, 0] + 0.8 * torch.randn(N) > 0).float()
background = y + 0.05 * torch.randn(N)               # 배경이 라벨과 거의 일치 (데이터 편향)
X = torch.cat([obj, torch.randn(N, 3), background[:, None]], 1)   # 특징 5개

model = nn.Sequential(nn.Linear(5, 16), nn.ReLU(), nn.Linear(16, 1))
opt = torch.optim.Adam(model.parameters(), lr=0.05)
for _ in range(300):
    loss = nn.functional.binary_cross_entropy_with_logits(model(X).squeeze(1), y)
    opt.zero_grad(); loss.backward(); opt.step()
acc = ((model(X).squeeze(1) > 0).float() == y).float().mean().item()

x = X.clone().requires_grad_(True)                    # 가장 간단한 설명: 입력 기울기의 평균 크기
model(x).sum().backward()
importance = x.grad.abs().mean(0)
print(acc > 0.95, importance.argmax().item())         # True 4  정확도는 높지만 "배경(4번)"을 보고 판단
```
