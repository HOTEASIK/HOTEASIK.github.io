# CAM

## 정의·핵심
- **정의 (응용 10차시)**: Class Activation Mapping (Zhou et al., 2016). AI 모델이 **이미지의 어디를 보고** 이 정답을 선택했는지 **히트맵**으로 보여 주는 기법 — "**형광펜으로 중요한 부분 표시하기**"
  - 예: 고양이 사진 → "**얼굴이 중요하군!**" (붉을수록 중요한 영역)
- **필요 구조 (강의)**: **마지막 합성곱층 → GAP(Global Average Pooling) → FC layer** 순으로 연결된 CNN이어야 함
  - GAP 계층이 각 특징맵을 평균 → FC 가중치가 각 특징맵이 클래스에 기여한 정도
  - **GAP가 없으면 구조를 바꾸고 재학습**해야 함 → 이미 배포된 모델엔 쓰기 어려움 (한계) → [[Global Average Pooling(GAP)]]
- **작동 원리 4단계 (강의)**
  1. **입력 이미지**: 분석할 사진을 CNN에 입력 ("이 사진 좀 봐줘")
  2. **특징맵 추출**: 마지막 합성곱 층에서 여러 특징(귀, 눈, 털 등) 추출 → [[Feature Map]]
  3. **가중치 결합**: 각 특징이 정답(고양이)에 얼마나 중요한지(**FC 가중치**)를 곱해서 더함 — "점수 = 중요도 × 특징 세기"
  4. **히트맵 생성**: 결과를 **원본 크기로 확대(upsample)** 해 덮어씌움 (붉은색 = 중요)
- **핵심 포인트 (강의)**: CAM은 "어떤 특징(Feature)"이 "얼마나 중요(Weight)"한지를 결합해 **위치 정보를 복원**
- **왜 성립하나**: GAP와 FC가 모두 선형이라 `y_c = Σ_k w_k^c · mean(A_k) = mean(Σ_k w_k^c A_k)` → 클래스 점수가 CAM 맵의 **평균**과 정확히 같음 → 맵의 각 위치가 점수에 기여한 몫
- **한계**: GAP 구조 필수, 특징맵 해상도(예: 7×7)가 낮아 **경계가 흐림** → 구조 제약을 없앤 것이 **Grad-CAM** → [[Grad-CAM]]

## 수식·원리
```
A_k ∈ R^{h×w}:  마지막 conv의 k번째 특징맵
GAP:   F_k = (1/hw) Σ_{i,j} A_k(i,j)
점수:  y_c = Σ_k w_k^c F_k
CAM:   M_c(i,j) = Σ_k w_k^c A_k(i,j)       → upsample → 히트맵
       y_c = (1/hw) Σ_{i,j} M_c(i,j)
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CAMNet(nn.Module):                                  # conv → GAP → FC (CAM 필수 구조)
    def __init__(self, n_cls=2):
        super().__init__()
        self.features = nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
                                      nn.Conv2d(8, 16, 3, padding=1), nn.ReLU())
        self.fc = nn.Linear(16, n_cls)
    def forward(self, x):
        A = self.features(x)
        return self.fc(A.mean((2, 3))), A                 # GAP

torch.manual_seed(0)
def make(n):                                              # 클래스 1 = 오른쪽 아래에 밝은 사각형
    x = 0.1 * torch.randn(n, 1, 16, 16); y = torch.randint(0, 2, (n,))
    x[y == 1, :, 10:14, 10:14] += 1.0
    return x, y
X, Y = make(256)
net = CAMNet(); opt = torch.optim.Adam(net.parameters(), lr=0.01)
for _ in range(100):
    loss = F.cross_entropy(net(X)[0], Y); opt.zero_grad(); loss.backward(); opt.step()

x = make(64)[0][:1]; x[:, :, 10:14, 10:14] += 1.0          # 클래스 1 이미지
logits, A = net(x)
w = net.fc.weight[1]                                       # 클래스 1의 FC 가중치
cam = torch.einsum("k,khw->hw", w, A[0])                   # Σ_k w_k A_k
print(torch.allclose(cam.mean() + net.fc.bias[1], logits[0, 1], atol=1e-5))   # True  점수 = CAM 평균 (+bias)
heat = F.interpolate(cam[None, None], size=(16, 16), mode="bilinear", align_corners=False)[0, 0]
r, c = divmod(heat.argmax().item(), 16)
print(tuple(A.shape[2:]), (r >= 8 and c >= 8))             # (8, 8) True  히트맵 최댓값이 사각형 쪽(오른쪽 아래)
```
