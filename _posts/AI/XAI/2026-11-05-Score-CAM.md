# Score-CAM

## 정의·핵심
- **출처 (응용 13차시 의료영상)**: "**고급 Grad-CAM (ScoreCAM, GradCAM++)** — 기본 Grad-CAM 외에도 ScoreCAM, GradCAM++ 같은 개선된 XAI 기법을 적용해 더 정밀한 시각화" → [[의료영상에서 Grad-CAM 활용]]
- **정의**: Score-CAM (Wang et al., 2020). 특징맵의 중요도를 **기울기 대신 "그 특징맵만 보여 줬을 때의 점수"** 로 계산하는 CAM 계열 기법 (**gradient-free**)
- **계산 과정**
  1. 마지막 conv의 각 특징맵 A^k를 **입력 크기로 upsample**하고 **[0, 1]로 정규화** → 마스크 M^k
  2. **원본 이미지 × 마스크**(M^k가 켜진 영역만 남김)를 모델에 다시 넣어 클래스 점수 계산
  3. 기준(baseline) 대비 **점수 증가량**(보통 softmax 확률)을 그 특징맵의 가중치로 → softmax로 정규화
  4. `ReLU(Σ_k w_k A^k)` → 히트맵
- **Grad-CAM 대비 장점**
  - **기울기의 노이즈·포화(saturation)** 문제 없음 — 기울기가 0에 가까워도 실제 점수 변화를 봄 → [[Saliency Map]]
  - 시각적으로 더 깔끔하고 **물체 영역에 집중**하는 경향
- **단점**: 특징맵 개수(K)만큼 **forward를 반복** → 느림 (ResNet 마지막 층 K=2048이면 2048번, 배치로 묶어 처리)
- **GradCAM++**: 기울기의 고차 항으로 가중치를 계산 → 한 이미지에 **같은 클래스 물체가 여러 개**일 때 더 잘 잡음
- **도구**: `pytorch_grad_cam`의 `ScoreCAM`, `GradCAMPlusPlus` (사용법은 GradCAM과 동일) → [[captum·pytorch_grad_cam]]

## 수식·원리
```
M^k = normalize( upsample(A^k) ) ∈ [0, 1]^{H×W}
s_k = f_c( X ⊙ M^k ) − f_c( X_baseline )          (점수 증가량, Channel-wise Increase of Confidence)
w_k = softmax(s)_k
L^c_Score-CAM = ReLU( Σ_k w_k A^k )
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
feat = nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), nn.Conv2d(8, 16, 3, padding=1), nn.ReLU())
head = nn.Sequential(nn.Flatten(), nn.Linear(16 * 8 * 8, 2))
model = lambda x: head(feat(x))
X = 0.1 * torch.randn(256, 1, 16, 16); Y = torch.randint(0, 2, (256,))
X[Y == 1, :, 9:13, 3:7] += 1.0                               # 클래스 1 = 왼쪽 아래 사각형
opt = torch.optim.Adam(list(feat.parameters()) + list(head.parameters()), lr=0.01)
for _ in range(100):
    loss = F.cross_entropy(model(X), Y); opt.zero_grad(); loss.backward(); opt.step()

@torch.no_grad()                                             # 기울기 없이 forward만 사용
def score_cam(x, cls):
    A = feat(x)[0]                                           # (K, 8, 8)
    M = F.interpolate(A[:, None], size=x.shape[-2:], mode="bilinear", align_corners=False)   # (K, 1, H, W)
    mn, mx = M.amin((2, 3), keepdim=True), M.amax((2, 3), keepdim=True)
    M = (M - mn) / (mx - mn + 1e-8)                          # [0, 1] 마스크
    base = model(torch.zeros_like(x)).softmax(1)[0, cls]
    s = model(x * M).softmax(1)[:, cls] - base               # 마스크된 이미지 K장을 배치로 한 번에
    w = s.softmax(0)
    cam = F.relu((w[:, None, None] * A).sum(0))
    return F.interpolate(cam[None, None], size=x.shape[-2:], mode="bilinear", align_corners=False)[0, 0], len(s)

x = 0.1 * torch.randn(1, 1, 16, 16); x[:, :, 9:13, 3:7] += 1.0
heat, n_forward = score_cam(x, 1)
r, c = divmod(heat.argmax().item(), 16)
print(n_forward, r >= 8 and c < 8)                           # 16 True  특징맵 수만큼 forward, 히트맵은 왼쪽 아래
```
