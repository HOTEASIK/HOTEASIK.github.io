# Grad-CAM

## 정의·핵심
- **정의 (응용 10차시)**: Gradient-weighted Class Activation Mapping (Selvaraju et al., 2017). CAM의 구조적 제약(**GAP + FC**) 없이 **기존 CNN에 재학습 없이 바로 적용** 가능한 위치 시각화 기법 → [[CAM]]
- **계산 과정 (강의)**
  1. 특정 클래스 c의 출력 **y^c (softmax 직전 점수)** 를 기준으로
  2. 마지막 합성곱 층의 각 특징맵 **A^k에 대한 기울기** ∂y^c/∂A^k 계산 (역전파)
  3. 기울기를 **공간 축 전체에 평균(합산)** → 각 특징맵의 **중요도 가중치 α_k**
  4. α_k와 A^k의 **가중합** → **ReLU**로 **positive 영향 영역만** 강조 → upsample해 히트맵
- **CAM vs Grad-CAM (강의 비교표)**

| 항목 | CAM | Grad-CAM |
|---|---|---|
| 필요 조건 | CNN 끝단에 **GAP 필수** (재학습 필요) | 이미 학습된 대부분의 CNN에 즉시 적용 |
| 핵심 아이디어 | GAP 이후 **FC 가중치**로 특징맵 결합 | 역전파된 **기울기**로 중요도 계산 |
| 한계 | 구조를 바꿔야 해서 배포된 모델엔 어려움 | 픽셀 단위 세밀한 경계는 여전히 흐릿 |
| 구조 | Conv → GAP → Softmax | Conv → Gradient → FC (어떤 구조든 기울기만 있으면 OK) |

- **ReLU를 쓰는 이유**: 해당 클래스 점수를 **올리는** 영역만 관심 (음수 = 다른 클래스의 근거)
- **CAM과의 관계**: GAP+FC 구조에서는 α_k = w_k^c / (hw)로 **CAM과 같은 결과** → Grad-CAM은 CAM의 **일반화**
- **흔한 오해 (강의)**: "Grad-CAM이 항상 CAM보다 선명하다?" → **아님**. 장점은 **범용성**, 선명도는 주로 **마지막 특징맵의 크기**에 좌우
- **활용**: 의료(폐렴 병변 위치 확인), 제조(스크래치 위치 검증) → [[의료영상에서 Grad-CAM 활용]] / 라이브러리: `pytorch_grad_cam` → [[captum·pytorch_grad_cam]]
- **개선판**: Grad-CAM++(여러 객체), **Score-CAM**(기울기 없이 점수 변화로) → [[Score-CAM]]

## 수식·원리
```
α_k^c = (1/Z) Σ_{i,j} ∂y^c / ∂A^k(i,j)          (기울기의 GAP)
L^c_Grad-CAM = ReLU( Σ_k α_k^c A^k )
GAP+FC 모델:  ∂y^c/∂A^k(i,j) = w_k^c / Z   →  Grad-CAM ∝ CAM
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
net = nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),     # GAP 없는 일반 CNN
                    nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(),
                    nn.Flatten(), nn.Linear(16 * 8 * 8, 2))
X = 0.1 * torch.randn(256, 1, 16, 16); Y = torch.randint(0, 2, (256,))
X[Y == 1, :, 2:6, 2:6] += 1.0                               # 클래스 1 = 왼쪽 위 사각형
opt = torch.optim.Adam(net.parameters(), lr=0.01)
for _ in range(100):
    loss = F.cross_entropy(net(X), Y); opt.zero_grad(); loss.backward(); opt.step()

acts, grads = {}, {}
layer = net[4]                                               # 마지막 conv 블록(ReLU) 출력
layer.register_forward_hook(lambda m, i, o: acts.update(a=o))
layer.register_full_backward_hook(lambda m, gi, go: grads.update(g=go[0]))

def grad_cam(x, cls):
    net.zero_grad()
    net(x)[0, cls].backward()                                # y^c (softmax 직전)
    alpha = grads["g"].mean((2, 3), keepdim=True)            # 기울기의 공간 평균 = α_k
    cam = F.relu((alpha * acts["a"]).sum(1))[0]              # ReLU(Σ α_k A^k)
    return F.interpolate(cam[None, None], size=x.shape[-2:], mode="bilinear", align_corners=False)[0, 0]

x = 0.1 * torch.randn(1, 1, 16, 16); x[:, :, 2:6, 2:6] += 1.0
heat = grad_cam(x, 1)
r, c = divmod(heat.argmax().item(), 16)
print(tuple(heat.shape), r < 8 and c < 8, heat.min().item() >= 0)   # (16, 16) True True  왼쪽 위 + ReLU로 음수 없음
```
