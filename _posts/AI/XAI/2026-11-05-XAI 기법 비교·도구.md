# XAI 기법 비교·도구

## 정의·핵심
- **4가지 XAI 기법 종합 비교 (응용 10차시)**

| 기법 | 작동 원리 | 장점 | 단점 | 적합한 상황 | 속도 | 신뢰감 |
|---|---|---|---|---|---|---|
| **CAM** | 마지막 특징맵과 가중치의 선형 결합으로 위치 파악 | 매우 직관적, 위치 정보 정확 | **GAP 구조 필수**, 낮은 해상도 | 간단한 CNN, 대략적 위치 | 보통 | 보통 |
| **Grad-CAM** | 기울기로 특징맵 중요도 계산 | **구조 제약 없음**, 범용성 | 픽셀 단위 세밀함 부족 | 이미 학습된 다양한 모델, 일반 시각화 | 보통 | 보통 |
| **Saliency Map** | 입력에 대한 출력의 기울기(민감도) | **구현 가장 간단**, 픽셀 단위 | **노이즈 심함**, 난해 | 빠른 디버깅, 미세 변화 감지 | **빠름** | 낮음 |
| **Integrated Gradients** | Baseline부터 입력까지 기울기 적분 | **이론적으로 탄탄**, 포화 해결 | 계산 비용 높음, Baseline 필요 | **금융·의료 등 고신뢰**, 규제 대응 | 느림 | **높음** |

- **선택 가이드 (강의 흐름도)**
  - Q1. **이미지(CNN)** 데이터인가? → Yes면 Q3, No(정형·텍스트)면 Q2
  - Q3. **위치(관심 영역) 시각화**가 가장 중요한가? → Yes: 모델에 **GAP 구조**가 있거나 수정 가능하면 **CAM**, 아니면 **Grad-CAM** / No(정밀 분석)면 Q2
  - Q2. 실시간 처리가 필요할 만큼 **속도**가 중요한가? → Yes: **Saliency Map** / No: Q4
  - Q4. **법적 규제 대응·높은 신뢰**가 필수인가? → Yes: **Integrated Gradients**
  - 요약: 빠른 확인(Saliency)과 신뢰성(IG) 사이에서 **균형**
- **한 줄 정리 (강의)**: CAM/Grad-CAM = "이미지의 **어디**를 봤니?" / Saliency = "얼마나 **민감**하게 반응하니?" / IG = "과정 전체를 **누적**했니?"
- **도구 (라이브러리)** → [[captum·pytorch_grad_cam]]
  - **captum** (PyTorch 공식): `Saliency`, `IntegratedGradients`, **`DeepLift`**(활성화 값의 차이를 역전파, 10차시 과제 문항 5), `LayerGradCam`, `Occlusion`, `NoiseTunnel`(SmoothGrad) / `captum.attr.visualization.visualize_image_attr`로 원본 위 **오버레이**(과제 문항 6)
  - **pytorch_grad_cam**: `GradCAM`, `ScoreCAM`, `GradCAMPlusPlus` — `target_layers=[model.layer4[-1]]`, `ClassifierOutputTarget(c)`, `show_cam_on_image` → [[Score-CAM]]
- **평가 방법**: 정성(사람이 보기에 그럴듯한가)만으로는 부족 → **삭제(deletion) 테스트**: 중요하다고 한 픽셀부터 지웠을 때 점수가 빨리 떨어질수록 좋은 설명 / Sanity check(가중치를 무작위로 바꿔도 맵이 같으면 의심)
- 이 환경엔 captum·pytorch_grad_cam **미설치** → 아래는 사용법(미실행) + 순수 PyTorch로 삭제 테스트

## 수식·원리
```
captum 공통:  attr = Method(model).attribute(inputs, target=c, ...)
IG:      baselines=0, n_steps=50, return_convergence_delta=True
삭제 테스트:  중요도 순으로 픽셀 k%를 지움 → 점수 곡선의 면적(AUC)이 작을수록 좋은 설명
```

## 코드 예시
라이브러리 사용법 (captum·grad-cam 미설치 — 이 환경 미실행):
```
from captum.attr import Saliency, IntegratedGradients, DeepLift, visualization as viz
sal = Saliency(model).attribute(x, target=label)
ig, delta = IntegratedGradients(model).attribute(x, baselines=torch.zeros_like(x), target=label,
                                                 n_steps=50, return_convergence_delta=True)
dl = DeepLift(model).attribute(x, baselines=torch.zeros_like(x), target=label)
viz.visualize_image_attr(ig[0].permute(1, 2, 0).numpy(), img_np, method="blended_heat_map", sign="positive")

from pytorch_grad_cam import GradCAM, ScoreCAM
from pytorch_grad_cam.utils.model_targets import ClassifierOutputTarget
from pytorch_grad_cam.utils.image import show_cam_on_image
cam = GradCAM(model=model, target_layers=[model.layer4[-1]])
heat = cam(input_tensor=x, targets=[ClassifierOutputTarget(label)])[0]
overlay = show_cam_on_image(img_float, heat, use_rgb=True)
```

실행 가능한 비교 (Saliency vs IG vs 무작위 — 삭제 테스트):
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
net = nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), nn.Flatten(), nn.Linear(8 * 8 * 8, 2))
X = 0.1 * torch.randn(256, 1, 16, 16); Y = torch.randint(0, 2, (256,))
X[Y == 1, :, 4:12, 4:12] += 1.0
opt = torch.optim.Adam(net.parameters(), lr=0.01)
for _ in range(100):
    loss = F.cross_entropy(net(X), Y); opt.zero_grad(); loss.backward(); opt.step()

x = 0.1 * torch.randn(1, 1, 16, 16); x[:, :, 4:12, 4:12] += 1.0
def grad_at(z):
    z = z.clone().requires_grad_(True); net(z)[:, 1].sum().backward(); return z.grad
sal = grad_at(x).abs()[0, 0]
alphas = torch.linspace(0.02, 1, 50)[:, None, None, None]
ig = (x * grad_at(alphas * x).mean(0, keepdim=True))[0, 0]    # baseline = 0
rand = torch.rand(16, 16)

def deletion_auc(attr, steps=8):                               # 중요한 픽셀부터 지우며 확률 곡선 면적
    order = attr.flatten().argsort(descending=True)
    probs = []
    for k in range(steps + 1):
        z = x.clone().flatten(); z[order[: k * 256 // steps]] = 0
        probs.append(net(z.view(1, 1, 16, 16)).softmax(1)[0, 1].item())
    return sum(probs) / len(probs)

aucs = {name: round(deletion_auc(a), 3) for name, a in [("saliency", sal), ("ig", ig), ("random", rand)]}
print(aucs["ig"] < aucs["random"], aucs["saliency"] < aucs["random"])   # True True  설명 기반 삭제가 점수를 더 빨리 떨어뜨림
```
