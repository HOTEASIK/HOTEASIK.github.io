[[precision|정밀도]]와 [[recall|재현율]]의 **조화평균** (`2·P·R / (P + R)`). 불균형 데이터의 기본 지표다.

## 동작 원리

조화평균은 작은 값에 끌려간다. 그래서 한쪽만 높고 다른 쪽이 낮으면 크게 깎여서, 정밀도와 재현율의 균형을 한 숫자로 볼 수 있다.

## 예시

```python
def f1_score(tp, fp, fn):
    precision = tp / (tp + fp)
    recall = tp / (tp + fn)
    return 2 * precision * recall / (precision + recall)

print(round(f1_score(tp=8, fp=2, fn=8), 3))
```

정밀도 0.8, 재현율 0.5의 산술평균은 0.65이지만 F1은 약 `0.615`로 더 낮다.
