예측 영역과 정답 영역의 **겹친 넓이 ÷ 합친 넓이**. 1이면 완벽히 겹침, 0이면 전혀 안 겹침. 객체 검출·분할에서 "얼마나 정확히 위치를 맞췄나"를 잰다.

## 예시

상자를 `(x1, y1, x2, y2)`로 나타내면 다음과 같이 계산한다.

```python
def iou(a, b):
    width = max(0, min(a[2], b[2]) - max(a[0], b[0]))
    height = max(0, min(a[3], b[3]) - max(a[1], b[1]))
    inter = width * height
    area_a = (a[2] - a[0]) * (a[3] - a[1])
    area_b = (b[2] - b[0]) * (b[3] - b[1])
    return inter / (area_a + area_b - inter)

print(round(iou((0, 0, 10, 10), (5, 5, 15, 15)), 3))
```

두 상자의 겹친 넓이는 25, 합친 넓이는 175라서 IoU는 약 `0.143`이다.

## 판정 기준

보통 IoU ≥ 0.5 를 맞춘 것으로 친다.
