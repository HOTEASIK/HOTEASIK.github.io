`f(x) = max(0, x)`. 음수는 0으로 끊고 양수는 그대로 통과시키는 스위치. 계산이 싸고 기울기 소실이 덜해 깊은 망을 학습 가능하게 만든 대표 활성화 함수.

## 동작 원리

양수 구간의 기울기가 항상 1이라 여러 층을 지나도 기울기가 잘 줄지 않는다. 다만 입력이 계속 음수인 뉴런은 기울기가 0이 되어 학습이 멈출 수 있다.

## 예시

```python
def relu(x):
    return max(0, x)

print([relu(x) for x in [-2, -0.5, 0, 1.5, 3]])
```

음수 두 개는 `0`이 되고 나머지는 그대로 나온다.
