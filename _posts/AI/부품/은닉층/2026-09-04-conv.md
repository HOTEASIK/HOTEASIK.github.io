작은 필터(커널)를 이미지 위로 굴려가며 선·모서리·질감 같은 국소 특징을 뽑아내는 층. 같은 필터를 전체에 재사용하므로 파라미터가 적고 위치 이동에 강하다.

## 동작 원리

필터를 한 칸씩 옮기며, 겹친 칸끼리 곱해 모두 더한다. 패턴이 필터와 닮은 위치일수록 값이 커진다.

## 예시

왼쪽은 어둡고 오른쪽은 밝은 세로 경계를 찾는 필터다.

```python
import numpy as np

image = np.array([[0, 0, 1, 1]] * 4, dtype=float)
kernel = np.array([[-1, 1], [-1, 1]], dtype=float)

height, width = image.shape
output = np.zeros((height - 1, width - 1))

for y in range(height - 1):
    for x in range(width - 1):
        output[y, x] = (image[y:y + 2, x:x + 2] * kernel).sum()

print(output)
```

경계가 있는 가운데 열만 `2`가 되고 나머지는 `0`이다.
