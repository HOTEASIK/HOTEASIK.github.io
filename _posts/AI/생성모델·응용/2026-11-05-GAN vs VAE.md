# GAN vs VAE

## 정의·핵심
- **공통점**: 둘 다 **잠재변수 z → 디코더/생성자 → 이미지** 구조의 생성 모델, 학습 후 `z ~ N(0, I)`에서 샘플링해 새 이미지 생성
- **비교 (응용 7차시 표)**

| 항목 | VAE | GAN |
|---|---|---|
| 학습 안정성 | **안정적** — 손실이 명확, 수렴 잘 됨 | 불안정 — G·D 균형이 깨지면 실패 |
| 이미지 품질 | **흐릿함 (Blurry)** — 평균을 학습 | **선명함 (Sharp)** — 진짜와 구별 어렵게 |
| 수학적 기반 | **확률 (Likelihood)**, ELBO 최대화 | **게임 이론 (Nash 균형)**, minimax |
| 구현 난이도 | 중간 | 높음 — 하이퍼파라미터 민감 |

- **추가 비교**
  - **구조**: VAE = Encoder + Decoder / GAN = Generator + Discriminator (인코더 없음 → 실제 이미지의 z를 바로 못 구함)
  - **p(x)**: VAE는 **명시적**(하한 계산 가능) / GAN은 **암묵적**(샘플만) → [[생성 모델 vs 판별 모델]]
  - **다양성**: VAE는 모든 데이터를 복원해야 하므로 모드를 잘 덮음 / GAN은 **mode collapse** 위험 → [[Mode Collapse]]
  - **잠재 공간**: VAE는 KL로 정돈되어 **보간·해석이 쉬움** / GAN도 보간은 되지만 구조 보장이 없음
- **왜 VAE는 흐릿한가**: 픽셀 단위 재구성 손실(MSE/BCE)은 여러 그럴듯한 정답이 있을 때 그 **평균**을 최적해로 만듦 → 경계가 뭉개짐. GAN은 D가 "흐릿하면 가짜"라고 판별하므로 선명해짐
- **결합 모델**: VAE-GAN, **VQ-GAN**(VQ-VAE + 적대적 손실) → Stable Diffusion의 오토인코더가 이 계열
- **이후**: 확산 모델이 **안정적 학습 + 선명한 품질 + 다양성**을 함께 달성 → [[Diffusion 모델(언급)]]

## 수식·원리
```
VAE:  max  E_q[log p(x|z)] − KL(q(z|x) ‖ p(z))      (ELBO)
GAN:  min_G max_D  E[log D(x)] + E[log(1 − D(G(z)))]
흐릿함: 정답 후보 {a, b}에 MSE → 최적 예측 = (a + b)/2
```

## 코드 예시
```python
import torch

a, b = torch.zeros(8), torch.ones(8)                    # 같은 입력에 대한 그럴듯한 두 정답 (검은 선 / 흰 선)
pred = torch.full((8,), 0.3, requires_grad=True)
opt = torch.optim.SGD([pred], lr=0.5)
for _ in range(100):
    loss = ((pred - a) ** 2).mean() + ((pred - b) ** 2).mean()   # 픽셀 재구성 손실 (VAE식)
    opt.zero_grad(); loss.backward(); opt.step()
print(round(pred.mean().item(), 2))                     # 0.5  두 정답의 평균 = 회색(흐릿함)

def realness(x): return 1 - 4 * (x * (1 - x)).mean().item()   # 판별자 흉내: 0 또는 1에 가까울수록 '진짜'
print(round(realness(pred.detach()), 2), realness(b))  # 0.0 1.0  GAN의 D는 평균 이미지를 가짜로 판단
```
