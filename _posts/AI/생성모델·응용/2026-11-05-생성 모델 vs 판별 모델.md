# 생성 모델 vs 판별 모델

## 정의·핵심
- **판별 모델 (Discriminative)**: 샘플 x가 주어졌을 때 **레이블 y의 조건부 확률 p(y|x)** 를 학습 → **결정 경계** 학습, 단 하나의 적합한 출력 (보충 생성형 AI 1주차)
  - 예: 분류("이게 고양이인가?"), 검출("고양이가 어디에 있나?") — 이미지를 보고 **판단(Decision)** 에 집중 (응용 7차시)
- **생성 모델 (Generative)**: 데이터 x가 관측될 **확률분포 p(x)** 자체를 학습 → 그 분포에서 **샘플링**해 존재하지 않던 새 데이터 생성, **여러 개의 적합한 출력** 가능
  - 예: 생성("없는 고양이를 그려라"), 합성("사람 얼굴을 만화처럼") — 판단하지 않고 **창조(Creation)** 에 집중
  - **조건부 생성 모델**: 조건 c에 맞는 샘플 → **p(x|c)** (텍스트 → 이미지, 클래스 → 숫자)
- **확률 관점에서 본 이미지 생성 (응용 7차시)**
  - **정답이 하나가 아님**: 같은 숫자를 써도 사람마다 모양·굵기·기울기가 다름
  - **이미지는 분포(Distribution)**: 세상의 모든 고양이 사진은 어떤 확률 분포 안에 존재
  - 목표: 데이터가 만들어졌을 **가능성 공간(Latent Space)** 을 학습 → 그 공간에서 하나를 뽑으면(**Sampling**) 새로운 이미지
  - **저차원 잠재 공간**의 한 점 ↔ 이미지 하나 (압축·매핑)
- **생성 모델링의 도전과제 (보충 1주차)**
  - **정확도**: 생성 샘플의 확률이 실제 데이터와의 유사도에 비례해야
  - **생성 용이성**: 학습된 분포에서 샘플링이 쉬워야
  - **표현**: 학습된 분포로 데이터의 고수준 특성이 어떻게 표현되는지 이해할 수 있어야
- **생성 모델의 분류 (보충 2주차)**
  - **잠재변수 활용**: VAE, GAN, Diffusion, 에너지 기반, 플로우 기반
  - **잠재변수 미활용**: **자기회귀 모델**(체인룰로 p(x) 직접 추정, LLM) → [[Autoregressive 모델(언급)]]
  - **명시적(Explicit)** p(x) 정의: VAE·Diffusion·플로우 / **암묵적(Implicit)**: **GAN** (샘플만 생성)
- 베이즈로 연결: `p(y|x) = p(x|y)p(y) / p(x)` — 생성 모델로 분류도 가능(나이브 베이즈), 하지만 분류 성능은 보통 판별 모델이 좋음

## 수식·원리
```
판별:  p(y | x)            → 결정 경계
생성:  p(x)  또는  p(x, y) = p(x|y)p(y)
조건부 생성: p(x | c)
샘플링:  x ~ p_θ(x)   (잠재변수: z ~ p(z), x = G(z))
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)
x0 = rng.normal(-2, 1, 500); x1 = rng.normal(2, 1, 500)          # 클래스 0, 1의 1차원 데이터

# 생성 모델: 클래스별 p(x|y)를 가우시안으로 학습 → 새 샘플 생성 가능
mu, sd = [x0.mean(), x1.mean()], [x0.std(), x1.std()]
new = rng.normal(mu[1], sd[1], 5)
print(np.round(mu, 2).tolist(), np.round(new, 2).tolist())       # 학습한 분포에서 새 데이터 샘플링

# 판별 모델: 결정 경계만 학습 (로지스틱 회귀)
X = np.concatenate([x0, x1]); y = np.r_[np.zeros(500), np.ones(500)]
w = b = 0.0
for _ in range(500):
    p = 1 / (1 + np.exp(-(w * X + b)))
    w -= 0.1 * ((p - y) * X).mean(); b -= 0.1 * (p - y).mean()
print(round(-b / w, 2))                                          # 결정 경계 ≈ 0  (새 샘플은 못 만듦)

pdf = lambda x, m, s: np.exp(-(x - m) ** 2 / (2 * s * s)) / (s * np.sqrt(2 * np.pi))
x = 1.0                                                          # 생성 모델로 분류: 베이즈 정리
post1 = pdf(x, mu[1], sd[1]) / (pdf(x, mu[0], sd[0]) + pdf(x, mu[1], sd[1]))
print(round(post1, 3), round(1 / (1 + np.exp(-(w * x + b))), 3))   # 두 방식의 p(y=1|x=1) 비교
```
