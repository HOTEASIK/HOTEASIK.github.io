# VAE

## 정의·핵심
- **정의**: Variational AutoEncoder (Kingma & Welling, 2013). 입력을 잠재 공간의 **한 점이 아니라 확률 분포**로 매핑하는 오토인코더 → 그 분포에서 샘플링해 새 데이터를 생성 (응용 7차시, 과제 문항 2)
- **구조 (강의)**
  - **Encoder** `q_φ(z|x)`: 입력 x → **평균 μ, 표준편차 σ**(실무에선 log σ² 출력) — "x가 잠재 공간 어디쯤, 얼마나 퍼져 있는가"
  - **Sampling**: `z = μ + σ·ε, ε ~ N(0, 1)` — **Reparameterization Trick**으로 미분 가능하게 → [[Reparameterization Trick]]
  - **Decoder** `p_θ(x|z)`: z → x̂, 마지막 **sigmoid**(픽셀 0~1)
- **손실 = 재구성 손실 + KL 발산 (강의)**
  - **재구성(Reconstruction)**: 원본과 비슷하게 복원 — BCE 또는 MSE
  - **KL 발산**: 인코더 분포 q(z|x)를 **표준정규 N(0, I)** 에 가깝게 → 잠재 공간을 정돈
  - 두 항의 **균형** → **연속적인 잠재 공간** → 두 점 사이를 보간하면 이미지가 **부드럽게 변함** → [[VAE Loss]]
- **이론적 배경**: `p(x) = ∫p(x|z)p(z)dz` 를 직접 최대화할 수 없어 **근사 분포 q_φ(z|x)** 를 도입하고 **ELBO(증거 하한)** 를 최대화 (보충 2주차) → [[ELBO]], [[MLE(최대우도추정)]]
- **생성 (강의 MNIST 예)**: 학습 후 인코더는 버리고 `z = torch.randn(64, 20)` (잠재 차원 20) → 디코더 → 새 손글씨 64장
- **특징**: 학습 안정적, 잠재 공간 해석 쉬움 / 결과가 **흐릿함**(평균적인 복원) → [[GAN vs VAE]]
- **발전**: β-VAE(KL 가중 ↑ → 해석 가능한 축), VQ-VAE(이산 잠재), Stable Diffusion의 **이미지 압축기**로 쓰임

## 수식·원리
```
Encoder: x → (μ, log σ²)
z = μ + σ ⊙ ε,  ε ~ N(0, I)
Decoder: z → x̂ = sigmoid(...)
L = BCE(x̂, x) + KL( N(μ, σ²) ‖ N(0, I) )
  = BCE − ½ Σ (1 + log σ² − μ² − σ²)
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, x_dim=784, h=128, z_dim=20):
        super().__init__()
        self.enc = nn.Linear(x_dim, h)
        self.mu, self.logvar = nn.Linear(h, z_dim), nn.Linear(h, z_dim)
        self.dec = nn.Sequential(nn.Linear(z_dim, h), nn.ReLU(), nn.Linear(h, x_dim), nn.Sigmoid())
    def forward(self, x):
        h = F.relu(self.enc(x))
        mu, logvar = self.mu(h), self.logvar(h)
        z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)        # reparameterization
        return self.dec(z), mu, logvar

def vae_loss(recon, x, mu, logvar):
    bce = F.binary_cross_entropy(recon, x, reduction="sum")
    kld = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return bce + kld

torch.manual_seed(0)
model = VAE()
x = (torch.rand(32, 784) > 0.7).float()                                # 가짜 이진 이미지
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for step in range(100):
    recon, mu, logvar = model(x)
    loss = vae_loss(recon, x, mu, logvar)
    if step in (0, 99): print(step, round(loss.item() / 32, 1))        # 샘플당 손실 감소
    opt.zero_grad(); loss.backward(); opt.step()

with torch.no_grad():
    sample = model.dec(torch.randn(64, 20))                            # 강의: 인코더 없이 생성
print(tuple(sample.shape), bool(((sample >= 0) & (sample <= 1)).all()))   # (64, 784) True
```
