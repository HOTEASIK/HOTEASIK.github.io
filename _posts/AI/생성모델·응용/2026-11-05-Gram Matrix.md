# Gram Matrix

## 정의·핵심
- **정의 (강의)**: 주어진 행렬의 **특징 벡터들 간의 내적(dot product)** 으로 만든 **상관관계 행렬(correlation matrix)** — 스타일 전이에서는 **i번째 특징 맵과 j번째 특징 맵 사이의 내적 값** (응용 6차시)
- **표기 (강의)**
  - **F^l**: 레이어 l의 특징 맵, **F^l ∈ ℝ^(N_l × M_l)**
  - **N_l**: 필터(채널)의 개수
  - **M_l**: 공간적 크기 (가로 × 세로 픽셀 수)
  - `G^l = F^l · (F^l)ᵀ` → **N_l × N_l** 행렬
- **상관관계 해석 (강의)**: 두 특징 맵의 값이 **함께 클 때 내적이 커짐** → 그 특징들이 **동시에 활성화**됨 (예: "빨간색" 채널과 "소용돌이 무늬" 채널이 같이 켜짐 → 빨간 소용돌이 스타일)
- **핵심 의미 (강의)**: "이 이미지의 **어떤 시각적 특징들이 얼마나 자주 함께 나타나는가**?"를 수치로 표현
- **성질**
  - **대칭 행렬** (G_ij = G_ji), 대각 원소 G_ii = 채널 i의 에너지(제곱합)
  - 공간 위치에 대해 합산 → **위치 정보가 사라짐** → 배치와 무관한 질감 통계 → [[Style Loss]]
  - 크기가 이미지 해상도와 무관하게 N × N → 정규화(`/ (c·h·w)`)로 스케일 맞춤
- **과제 문항 1**: 스타일을 수치화하기 위해 특징 맵 간 상관관계를 계산 / **문항 3 구현**: `(b, c, h, w) → view(b, c, h·w)` → `bmm(F, Fᵀ)` → `(b, c, c)`
- 다른 쓰임: 커널 방법(SVM의 커널 행렬), 벡터 집합의 선형 독립 판정

## 수식·원리
```
F ∈ ℝ^{N×M}   (N 채널, M = H·W)
G = F Fᵀ ∈ ℝ^{N×N},   G_ij = Σ_k F_ik F_jk
정규화: G / (N·M)
```

## 코드 예시
```python
import torch

def gram_matrix(x):                                      # 과제 문항 3
    b, c, h, w = x.size()
    f = x.view(b, c, h * w)
    return torch.bmm(f, f.transpose(1, 2))

f = torch.tensor([[[[1., 0.], [2., 0.]],                 # 채널 0
                   [[2., 0.], [4., 0.]],                 # 채널 1 = 채널 0 × 2 (항상 같이 켜짐)
                   [[0., 3.], [0., 1.]]]])               # 채널 2 (다른 위치에서 켜짐)
G = gram_matrix(f)[0]
print(G.tolist())                                        # [[5.0, 10.0, 0.0], [10.0, 20.0, 0.0], [0.0, 0.0, 10.0]]
print(torch.equal(G, G.T), tuple(G.shape))               # True (3, 3)  대칭, 채널×채널
big = torch.rand(1, 64, 128, 128)
print(tuple(gram_matrix(big).shape))                     # (1, 64, 64)  해상도와 무관한 크기
```
