# Pix2Pix

## 정의·핵심
- **정의**: Isola et al. (2017). **짝지어진(paired) 이미지 쌍**으로 학습해 한 도메인의 이미지를 다른 도메인으로 바꾸는 **이미지-투-이미지 변환(Image-to-Image Translation)** 조건부 GAN (응용 7차시)
  - 예: 스케치 → 사진, 위성사진 → 지도, 흑백 → 컬러, 낮 → 밤, 라벨맵 → 건물 외관
  - 조건 = **입력 이미지 x** → G(x)가 목표 이미지 y처럼 보이도록 → [[Conditional GAN]]
- **Generator = U-Net (강의)**
  - **인코더**: Conv2D **8개 층** — 각 층 Conv → Norm → **LeakyReLU**, stride 2로 해상도 절반씩
  - **디코더**: Upsample(ConvTranspose) → Conv, 인코더 같은 해상도의 특징과 **Skip Connection(concat)**, 활성화 **ReLU**, 마지막 **tanh**
  - 출력 **256×256×3** (입력과 같은 크기)
  - Skip connection으로 **경계·윤곽 같은 저수준 정보**를 그대로 디코더에 전달 → [[U-Net]]
  - 노이즈 z 대신 **Dropout**으로 확률성 부여
- **Discriminator = PatchGAN**
  - 이미지 전체에 확률 1개가 아니라, **N×N 패치(예: 70×70) 단위로 진위 판정** → 출력이 30×30 같은 격자
  - 입력은 `concat(x, y)` 또는 `concat(x, G(x))` (6채널) → "이 입력에 맞는 진짜 출력인가?"
  - 국소 질감(고주파)을 잘 잡음, 파라미터 적음, 임의 크기 이미지에 적용 가능
- **손실**: **cGAN 손실 + λ·L1 손실**(λ=100)
  - L1만 쓰면 평균적인(흐릿한) 결과 → GAN 손실이 **선명함** 담당
  - GAN만 쓰면 입력과 무관한 결과 가능 → L1이 **정답과의 구조 일치** 담당
- **한계**: 짝지어진 데이터 필요 → 짝 없는 데이터는 **CycleGAN**(생성자 2개 + cycle consistency)

## 수식·원리
```
L_cGAN(G, D) = E_{x,y}[log D(x, y)] + E_x[log(1 − D(x, G(x)))]
L_L1(G)      = E_{x,y}[‖y − G(x)‖₁]
G* = arg min_G max_D  L_cGAN + λ·L_L1      (λ = 100)
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def down(i, o, norm=True):
    return nn.Sequential(nn.Conv2d(i, o, 4, 2, 1), nn.BatchNorm2d(o) if norm else nn.Identity(), nn.LeakyReLU(0.2))
def up(i, o):
    return nn.Sequential(nn.ConvTranspose2d(i, o, 4, 2, 1), nn.BatchNorm2d(o), nn.ReLU())

class UNetG(nn.Module):                       # 축소판 U-Net (강의: 인코더 8층, 256×256)
    def __init__(self):
        super().__init__()
        self.d1, self.d2, self.d3 = down(3, 32, False), down(32, 64), down(64, 128)
        self.u1, self.u2 = up(128, 64), up(128, 32)
        self.out = nn.Sequential(nn.ConvTranspose2d(64, 3, 4, 2, 1), nn.Tanh())
    def forward(self, x):
        e1 = self.d1(x); e2 = self.d2(e1); e3 = self.d3(e2)
        u = self.u1(e3); u = self.u2(torch.cat([u, e2], 1))      # skip connection
        return self.out(torch.cat([u, e1], 1))

patchD = nn.Sequential(down(6, 32, False), down(32, 64), nn.Conv2d(64, 1, 4, 1, 1), nn.Sigmoid())

torch.manual_seed(0)
G = UNetG()
x, y = torch.rand(2, 3, 64, 64) * 2 - 1, torch.rand(2, 3, 64, 64) * 2 - 1   # (입력, 정답) 쌍
fake = G(x)
print(tuple(fake.shape))                                     # (2, 3, 64, 64)  입력과 같은 크기
pred = patchD(torch.cat([x, fake], 1))
print(tuple(pred.shape))                                     # (2, 1, 15, 15)  패치별 진위
g_loss = F.binary_cross_entropy(pred, torch.ones_like(pred)) + 100 * F.l1_loss(fake, y)
print(g_loss.item() > 0)                                     # True  cGAN + λ·L1
```
