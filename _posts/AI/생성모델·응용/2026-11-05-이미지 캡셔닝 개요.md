# 이미지 캡셔닝 개요

## 정의·핵심
- **정의 (응용 8차시)**: 입력된 이미지의 내용을 분석해 **상황을 가장 잘 설명하는 자연어 문장을 자동 생성**하는 AI 기술
  - 예: "검은색 털을 가진 강아지가 나무 마루 위에 얌전히 앉아 있다."
- **CV + NLP 융합**: Computer Vision(**보는 능력**)과 NLP(**말하는 능력**)의 결합 → 시각 정보와 언어 표현이 동시에 필요한 **멀티모달(Multi-modal) AI**의 대표 기술
- **핵심 가치·활용 분야 (강의)**
  - **접근성(Accessibility)** — 시각장애인 보조: 화면을 볼 수 없는 사용자에게 주변 상황·웹 이미지를 음성으로 설명(**Alt Text**)
  - **검색성(Searchability)** — 사진 관리·스마트 검색: 자동 태깅·설명 생성 → 텍스트 검색만으로 장면 찾기
  - **자동화(Automation)** — 전자상거래: 상품 이미지의 기본 상세 설명·해시태그 자동 생성
  - **의료·산업**: X-ray/MRI **판독문 초안**, CCTV 이상 상황 **텍스트 요약**
- **전체 파이프라인 (강의)**
  - 입력 이미지 (3, H, W) → **CNN 특징 추출**(ResNet/VGG) → **특징 벡터**(Embedding, 압축) → **LSTM 디코딩**(Memory Cell) → 최종 문장
  - **학습**: 정답 캡션을 입력으로 주어, 예측 단어와의 오차(Loss)를 최소화하도록 가중치 업데이트 → [[Teacher Forcing]]
  - **추론**: 이미지만 입력, `<start>` 부터 `<end>` 가 나올 때까지 단어를 하나씩 생성 → [[Greedy Search·Beam Search]]
- **문장의 수치화 (강의)**: 문장 → 토큰화 + 특수 토큰 → **단어 사전(Vocabulary)** 에서 인덱스 조회 → 정수 시퀀스
  - 예: `<start> 강아지 가 공 을 문다 <end>` → `1 45 12 89 34 102 2`
  - 특수 토큰: `0 <pad>`(길이 맞춤), `1 <start>`, `2 <end>`, `3 <unk>`(모르는 단어)
- **실습 4단계 (강의)**: ① 전처리(이미지 224×224 리사이즈, 캡션 토큰화, 사전 생성) ② 모델 구현(ResNet 인코더 + LSTM 디코더 `CaptionModel`) ③ CrossEntropyLoss로 학습, Validation Loss 확인 ④ 테스트 이미지 5장 캡션 생성·시각화
- **데이터셋**: Flickr8k / Flickr30k, **MS COCO Captions**(이미지당 정답 캡션 5개)
- **발전**: Show and Tell(CNN+LSTM) → Show, Attend and Tell(Attention) → Transformer 기반(BLIP, 멀티모달 LLM)

## 수식·원리
```
v = CNN(I)                                  이미지 → 특징 벡터
p(S | I) = Π_t p(w_t | w_{<t}, v)          자기회귀 문장 생성
학습: min −Σ_t log p(w_t* | w_{<t}*, v)      (정답 단어의 Cross Entropy)
```

## 코드 예시
```python
caption = "강아지 가 공 을 문다"
vocab = {"<pad>": 0, "<start>": 1, "<end>": 2, "<unk>": 3, "가": 12, "을": 34, "강아지": 45, "공": 89, "문다": 102}
inv = {i: w for w, i in vocab.items()}

def encode(text, max_len=10):
    ids = [vocab["<start>"]] + [vocab.get(w, vocab["<unk>"]) for w in text.split()] + [vocab["<end>"]]
    return ids + [vocab["<pad>"]] * (max_len - len(ids))

ids = encode(caption)
print(ids)                                         # [1, 45, 12, 89, 34, 102, 2, 0, 0, 0]
print(encode("고양이 가 공 을 문다")[:3])           # [1, 3, 12]  사전에 없는 단어 → <unk>
print(" ".join(inv[i] for i in ids if i > 2))      # 강아지 가 공 을 문다
```
