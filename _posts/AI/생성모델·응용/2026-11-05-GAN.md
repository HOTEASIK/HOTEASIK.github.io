# GAN

## 정의·핵심
- **정의**: Generative Adversarial Network (Goodfellow, 2014). **생성자(Generator, G)** 와 **판별자(Discriminator, D)** 두 신경망이 **서로 경쟁**하며 학습하는 생성 모델 (응용 7차시)
- **비유 (강의)**: G = **위조지폐범**(진짜 같은 가짜를 만듦), D = **경찰**(진짜와 가짜를 구별) → 경찰이 똑똑해질수록 위조범도 정교해짐
- **구성 (과제 문항 1)**
  - **Generator**: 랜덤 노이즈 **z ~ N(0, I)** 를 입력받아 가짜 이미지 G(z) 생성 — 목표: D를 속이기
  - **Discriminator**: 이미지를 받아 **진짜일 확률(0~1)** 출력 (마지막 sigmoid) — 목표: 진짜 → 1, 가짜 → 0
- **게임 이론 관점 (강의)**
  - **Minimax 게임**: D는 V(D, G)를 **최대화**, G는 **최소화**
  - **Zero-sum**: 한쪽의 이득 = 다른 쪽의 손해
  - **Nash 균형**: 최적에서 `p_g = p_data`, `D(x) = ½` (어느 것도 구별 못 함)
  - **교대 최적화(Alternating Optimization)**: D 한 스텝 → G 한 스텝 반복 → [[GAN 학습]]
- **암묵적(Implicit) 생성 모델**: p(x)를 명시적으로 계산하지 않고 **샘플만** 생성 → 가능도 계산 불가, 대신 이미지가 **선명** → [[GAN vs VAE]]
- **문제점 (강의)**
  - **학습 불안정**: 두 손실이 진동, 한쪽이 너무 강하면 다른 쪽이 학습 못 함
  - **Mode Collapse**: G가 D를 잘 속이는 몇 가지 샘플만 반복 생성 → [[Mode Collapse]]
- **주요 변형 (강의)**
  - **DCGAN**: 합성곱 구조 → [[DCGAN]]
  - **Conditional GAN**: 조건(레이블) 입력 → [[Conditional GAN]]
  - **Pix2Pix**: 이미지 → 이미지 변환 → [[Pix2Pix]]
  - **SRGAN**: 저해상도 → 고해상도 (초해상도)
  - **CycleGAN**: **생성자 2개**, 짝이 없는 데이터로 도메인 변환(말 ↔ 얼룩말), cycle consistency loss
  - **LSGAN**: BCE 대신 **MSE(최소제곱)** 손실 → 기울기 소실 완화
  - (참고) WGAN(Wasserstein 거리), StyleGAN(고해상도 얼굴)

## 수식·원리
```
min_G max_D V(D, G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 − D(G(z)))]
최적 D*(x) = p_data(x) / (p_data(x) + p_g(x))
D* 대입 시 V = −log4 + 2·JSD(p_data ‖ p_g)  → p_g = p_data 에서 최소, D* = ½
```

## 코드 예시
```python
import torch
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, z_dim=16, out=2):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(z_dim, 32), nn.ReLU(), nn.Linear(32, out))
    def forward(self, z): return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, inp=2):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(inp, 32), nn.LeakyReLU(0.2), nn.Linear(32, 1), nn.Sigmoid())
    def forward(self, x): return self.net(x)

torch.manual_seed(0)
G, D = Generator(), Discriminator()
z = torch.randn(4, 16)                        # 노이즈
fake = G(z)
print(tuple(fake.shape), tuple(D(fake).shape))   # (4, 2) (4, 1)
print(bool(((D(fake) > 0) & (D(fake) < 1)).all()))   # True  D 출력 = 진짜일 확률

p_data, p_g = torch.tensor(0.3), torch.tensor(0.1)
print(round((p_data / (p_data + p_g)).item(), 2))     # 0.75  최적 판별자 D*(x)
p_g = p_data
print((p_data / (p_data + p_g)).item())               # 0.5  균형: 구별 불가
```
