# 캡셔닝 평가

## 정의·핵심
- **정의 (응용 8차시 "성능 평가 지표")**: 생성된 캡션이 **정답 문장(참조 캡션)과 얼마나 유사한지** 수치화하는 지표들
- **BLEU** (Bilingual Evaluation Understudy)
  - 기계 번역 분야의 표준 지표 — 생성 문장과 정답 문장 간 **n-gram 정밀도(Precision)** 측정
  - 연속된 단어(n-gram, 보통 1~4)가 얼마나 일치하는지 확인
  - 너무 짧은 문장에 **Brevity Penalty(BP)** 부여 (정밀도만 보면 짧게 쓸수록 유리하므로)
  - 한계: 단순 매칭 → **동의어·문맥 고려 부족**
- **METEOR** (Metric for Evaluation of Translation with Explicit ORdering)
  - BLEU의 단점 보완 — **정밀도와 재현율의 조화 평균**(재현율 가중), **유의어**까지 고려
  - 동의어 매칭, **어간 추출(Stemming)** 지원
  - **사람의 평가(Human Judgment)와 상관관계 높음**, 문법적 유창성 평가에 유리
- **CIDEr** (Consensus-based Image Description Evaluation)
  - **이미지 캡셔닝 특화** 지표 — **TF-IDF 가중치**로 중요 단어 일치 여부를 봄
  - **다수의 정답 캡션 집합(Consensus)** 과의 유사도 (COCO는 이미지당 5개)
  - 자주 등장하지 않는 **'핵심 단어'에 높은 가중치** ("a", "of"보다 "frisbee"가 중요)
  - 현재 캡셔닝 대회(COCO 등)의 **주요 평가 기준**
- (참고) **ROUGE-L**(최장 공통 부분열), **SPICE**(장면 그래프 의미 비교), CLIPScore(참조 없이 이미지-텍스트 유사도)
- **실습 팁 — 과적합 모니터링 (강의)**: Loss만 보지 말고 **검증 셋 CIDEr**를 주기적으로 확인. Loss는 줄어드는데 CIDEr가 정체·하락하면 **Early Stopping** → [[Early Stopping]]

## 수식·원리
```
p_n = Σ min(count_gen(ngram), max count_ref(ngram)) / Σ count_gen(ngram)   (clipped precision)
BP = 1  (c > r),   exp(1 − r/c)  (c ≤ r)      c = 생성 길이, r = 참조 길이
BLEU-N = BP · exp( Σ_{n=1..N} (1/N) log p_n )
METEOR F_mean = 10PR / (R + 9P)  (재현율 가중)
CIDEr: n-gram TF-IDF 벡터의 코사인 유사도를 참조 캡션들에 대해 평균
```

## 코드 예시
```python
import math
from collections import Counter

def ngrams(ws, n): return Counter(tuple(ws[i:i + n]) for i in range(len(ws) - n + 1))

def bleu(cand, refs, N=2):
    c = cand.split(); rs = [r.split() for r in refs]
    logs = []
    for n in range(1, N + 1):
        cg = ngrams(c, n)
        mx = Counter()
        for r in rs: mx |= ngrams(r, n)                     # 참조별 최대 개수로 clip
        clip = sum(min(v, mx[g]) for g, v in cg.items())
        logs.append(math.log(max(clip, 1e-9) / max(sum(cg.values()), 1)))
    r_len = min((abs(len(r) - len(c)), len(r)) for r in rs)[1]
    bp = 1 if len(c) > r_len else math.exp(1 - r_len / len(c))
    return round(bp * math.exp(sum(logs) / N), 3)

refs = ["a dog is sitting on the floor", "a black dog sits on a wooden floor"]
print(bleu("a dog is sitting on the floor", refs))         # 1.0  참조와 동일
print(bleu("a dog sits on the floor", refs))               # 0.846  부분 일치
print(bleu("a puppy rests on the ground", refs))           # 0.268  의미는 비슷해도 단어가 달라 낮음 (동의어 한계)
print(bleu("a dog", refs))                                 # 0.082  정밀도는 100%지만 짧아서 BP 페널티
```
