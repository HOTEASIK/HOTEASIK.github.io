# MLE(최대우도추정)

## 정의·핵심
- **가능도 (Likelihood, 보충 생성형 AI 1주차)**: `L(θ | x)` — 관측된 데이터 샘플 x가 주어졌을 때 **파라미터 θ의 타당성**을 측정하는 함수. 값은 점 x에서 θ를 파라미터로 갖는 **확률 밀도 함수의 값** `p_θ(x)`
  - 확률: θ 고정, x가 변수 / 가능도: **x 고정(관측됨), θ가 변수**
- **최대우도추정 (MLE)**: 관측된 데이터를 **가장 그럴듯하게 만드는 θ**를 찾음
  - `θ̂ = argmax_θ Π_i p_θ(x_i)` → 곱은 수치적으로 불안정 → **로그**를 취해 합으로: `θ̂ = argmax_θ Σ_i log p_θ(x_i)` (보충 2주차: `θ̂ = argmax_θ (log p_θ(x))`)
  - 최대화 대신 **음의 로그 가능도(NLL) 최소화**로 구현 → 딥러닝 손실 함수
- **딥러닝 손실과의 연결**
  - 분류: 출력이 범주 분포 → NLL = **Cross Entropy** → [[CrossEntropyLoss]]
  - 회귀: 출력이 고정 분산 가우시안 → NLL ∝ **MSE**
  - 이진: 베르누이 → **BCE**
  - MLE = 데이터 분포와 모델 분포의 **KL 발산 최소화**와 같음
- **생성 모델에서 (보충 2주차)**
  - 생성 모델 학습의 기본 원리 = 학습 데이터의 **로그 가능도 최대화**
  - **자기회귀 모델**: 체인룰로 p(x)를 정확히 계산 → MLE 직접 적용
  - **VAE**: `p_θ(x) = ∫ p_θ(x|z) p(z) dz` — z가 고차원 연속 변수라 **적분(모든 값 합)이 계산 불가능** → 계산 가능한 **하한(ELBO)** 을 최대화 → [[ELBO]]
  - **GAN**: p(x)를 명시하지 않는 **암묵적** 모델 → MLE 대신 적대적 학습
- **한계**: 데이터가 적으면 과적합(예: 동전 3번 다 앞면 → p = 1) → 사전분포를 더한 **MAP**(= 정규화)

## 수식·원리
```
L(θ | x_1..n) = Π_i p_θ(x_i)
θ̂_MLE = argmax_θ Σ_i log p_θ(x_i) = argmin_θ −Σ_i log p_θ(x_i)   (NLL)
가우시안: μ̂ = (1/n)Σx_i,  σ̂² = (1/n)Σ(x_i − μ̂)²
베르누이: p̂ = (앞면 수)/n
```

## 코드 예시
```python
import numpy as np
import torch

rng = np.random.default_rng(0)
x = rng.normal(3.0, 2.0, 1000)
print(round(x.mean(), 2), round(x.std(), 2))                 # 해석적 MLE: 표본 평균·표준편차

mu = torch.zeros(1, requires_grad=True); log_s = torch.zeros(1, requires_grad=True)
xt = torch.tensor(x, dtype=torch.float32)
opt = torch.optim.Adam([mu, log_s], lr=0.05)
for _ in range(1000):                                        # NLL 최소화 = 가능도 최대화
    nll = (log_s + (xt - mu) ** 2 / (2 * torch.exp(2 * log_s))).mean()
    opt.zero_grad(); nll.backward(); opt.step()
print(round(mu.item(), 2), round(log_s.exp().item(), 2))     # 경사하강으로 찾은 값이 해석해와 같음

coin = np.array([1, 1, 1])                                   # 앞면 3번
ps = np.linspace(0.01, 0.99, 99)
ll = coin.sum() * np.log(ps) + (len(coin) - coin.sum()) * np.log(1 - ps)
print(round(ps[ll.argmax()], 2))                             # 0.99  데이터가 적으면 극단적인 추정
```
