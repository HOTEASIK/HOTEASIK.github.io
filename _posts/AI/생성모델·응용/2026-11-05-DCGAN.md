# DCGAN

## 정의·핵심
- **정의**: Deep Convolutional GAN (Radford et al., 2015). GAN의 G·D를 **합성곱 신경망**으로 구성하고, 안정적으로 학습되는 **구조 규칙**을 제시한 모델 (응용 7차시)
- **강의 구조 — Generator** (노이즈 → 이미지, 해상도를 키움)
  - 입력 **z: 64차원** → **Linear** → **16×16×128** 로 reshape
  - **Upsample(×2) → 32×32** → Conv 3×3, 128채널 (+BN, ReLU)
  - **Upsample(×2) → 64×64** → Conv 3×3
  - 마지막 Conv → **64×64×3 (RGB)**, tanh
- **강의 구조 — Discriminator** (이미지 → 확률, 해상도를 줄임)
  - 입력 **64×64×3** → Conv 3×3, **stride 2**, 64채널 → 32×32
  - → 128채널 (32→**16**) → 256채널 (16→**8**) → 512채널 (8→**4**)
  - → **FC** → **Sigmoid** (진짜일 확률)
- **DCGAN 설계 규칙 (논문)**
  - **Pooling 제거**: D는 **strided conv**로, G는 **ConvTranspose2d(fractional-strided conv)** 또는 Upsample+Conv로 크기 조절 (과제 문항 3: 생성자는 ConvTranspose2d)
  - **BatchNorm**: G·D 모두 사용 (G 출력층, D 입력층 제외)
  - **FC 은닉층 제거**
  - 활성화: G는 **ReLU**, 출력 **tanh** / D는 **LeakyReLU(0.2)** (과제 문항 4: 음수 영역에서도 기울기 유지 → D가 G에게 기울기를 잘 전달)
  - 가중치 초기화 **N(0, 0.02)** (과제 문항 5), Adam lr=0.0002, β1=0.5
- **잠재 공간 산술**: `z(안경 쓴 남자) − z(남자) + z(여자) ≈ z(안경 쓴 여자)` → 잠재 공간이 의미 있게 구조화됨

## 수식·원리
```
ConvTranspose2d 출력 크기: (H − 1)·stride − 2·padding + kernel
  예) 4×4, k=4, s=2, p=1 → (4−1)·2 − 2 + 4 = 8
Conv2d (D): ⌊(H + 2p − k)/s⌋ + 1    예) 64, k=3, s=2, p=1 → 32
```

## 코드 예시
```python
import torch
import torch.nn as nn

class G(nn.Module):                                   # 강의 구조
    def __init__(self, nz=64):
        super().__init__()
        self.fc = nn.Linear(nz, 128 * 16 * 16)
        self.net = nn.Sequential(
            nn.BatchNorm2d(128),
            nn.Upsample(scale_factor=2), nn.Conv2d(128, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(),
            nn.Upsample(scale_factor=2), nn.Conv2d(128, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(),
            nn.Conv2d(64, 3, 3, padding=1), nn.Tanh())
    def forward(self, z): return self.net(self.fc(z).view(-1, 128, 16, 16))

def block(i, o): return [nn.Conv2d(i, o, 3, 2, 1), nn.BatchNorm2d(o), nn.LeakyReLU(0.2)]
D = nn.Sequential(nn.Conv2d(3, 64, 3, 2, 1), nn.LeakyReLU(0.2),   # 64→32 (입력층 BN 없음)
                  *block(64, 128), *block(128, 256), *block(256, 512),   # 32→16→8→4
                  nn.Flatten(), nn.Linear(512 * 4 * 4, 1), nn.Sigmoid())

def weights_init(m):                                  # 과제 문항 5
    if isinstance(m, (nn.Conv2d, nn.ConvTranspose2d)): nn.init.normal_(m.weight, 0.0, 0.02)
    elif isinstance(m, nn.BatchNorm2d): nn.init.normal_(m.weight, 1.0, 0.02); nn.init.zeros_(m.bias)

torch.manual_seed(0)
g = G(); g.apply(weights_init); D.apply(weights_init)
img = g(torch.randn(2, 64))
print(tuple(img.shape), img.min().item() >= -1, img.max().item() <= 1)   # (2, 3, 64, 64) True True
print(tuple(D(img).shape))                                               # (2, 1)
print(round(D[0].weight.std().item(), 2))                                # 0.02

up = nn.ConvTranspose2d(512, 256, 4, 2, 1)                               # 과제 문항 3 방식
print(tuple(up(torch.randn(1, 512, 4, 4)).shape))                        # (1, 256, 8, 8)
```
