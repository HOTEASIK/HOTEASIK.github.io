# ELBO

## 정의·핵심
- **정의**: Evidence Lower BOund (증거 하한). 계산할 수 없는 **로그 가능도 log p_θ(x)** (= evidence) 대신 최대화하는, 항상 그보다 작거나 같은 **계산 가능한 하한**
- **왜 필요한가 (보충 생성형 AI 2주차)**
  - 잠재변수 모델: `p_θ(x) = ∫ p_θ(x|z) p(z) dz`
  - z가 고차원 연속 변수 → **모든 z에 대한 적분이 불가능(intractable)** → MLE를 직접 할 수 없음 → [[MLE(최대우도추정)]]
  - 진짜 사후분포 `p_θ(z|x)` 도 같은 이유로 계산 불가
  - → 다루기 쉬운 **근사 분포 q_φ(z|x)** (인코더, 가우시안)를 도입 = **변분 추론(Variational Inference)**
- **유도 결과**
  - `log p(x) = ELBO + KL(q_φ(z|x) ‖ p_θ(z|x))`
  - KL ≥ 0 이므로 **log p(x) ≥ ELBO**
  - ELBO를 최대화하면 ① log p(x)를 밀어 올리고 ② q가 진짜 사후분포에 가까워짐 (둘을 동시에)
- **ELBO의 두 항 = VAE 손실**
  - `E_q[log p(x|z)]`: **재구성** 항 (디코더가 x를 잘 복원)
  - `−KL(q(z|x) ‖ p(z))`: **정규화** 항 (인코더 분포를 사전분포 N(0, I)에 가깝게)
  - VAE 손실 = **−ELBO** → [[VAE Loss]]
- 기대값 `E_q[·]`은 z를 샘플링해 추정 → 샘플링을 미분 가능하게 하는 것이 [[Reparameterization Trick]]
- 확산 모델의 학습 목표도 ELBO에서 유도됨 → [[Diffusion 모델(언급)]]

## 수식·원리
```
log p(x) = log ∫ p(x, z) dz = log E_q[ p(x, z) / q(z|x) ]
         ≥ E_q[ log p(x, z) − log q(z|x) ]                 (Jensen 부등식)
         = E_q[log p(x|z)] − KL(q(z|x) ‖ p(z))  =: ELBO
log p(x) − ELBO = KL(q(z|x) ‖ p(z|x)) ≥ 0
```

## 코드 예시
```python
import numpy as np

# 장난감 모델: z ~ N(0,1), x|z ~ N(z, 1)  →  p(x) = N(0, 2), 사후분포 p(z|x) = N(x/2, 1/2)
x = 1.5
log_px = -0.5 * np.log(2 * np.pi * 2) - x ** 2 / 4

def elbo(m, s, n=200000, seed=0):
    z = np.random.default_rng(seed).normal(m, s, n)           # q(z|x) = N(m, s²)에서 샘플
    log_pxz = -0.5 * np.log(2 * np.pi) - (x - z) ** 2 / 2
    log_pz = -0.5 * np.log(2 * np.pi) - z ** 2 / 2
    log_q = -0.5 * np.log(2 * np.pi * s * s) - (z - m) ** 2 / (2 * s * s)
    return (log_pxz + log_pz - log_q).mean()

print(round(log_px, 3))                                       # -1.828  진짜 log p(x)
print(round(elbo(0.0, 1.0), 3))                               # 나쁜 q → 하한이 낮음
print(round(elbo(x / 2, np.sqrt(0.5)), 3))                    # -1.828  q = 진짜 사후분포면 하한 = log p(x)
print(elbo(0.0, 1.0) <= log_px)                               # True  항상 하한
```
