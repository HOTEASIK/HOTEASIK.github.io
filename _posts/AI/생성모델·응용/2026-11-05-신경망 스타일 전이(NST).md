# 신경망 스타일 전이(NST)

## 정의·핵심
- **정의**: Neural Style Transfer (Gatys et al., 2015). **이미지 A(콘텐츠)의 객체·배치는 유지**하면서 **이미지 B(스타일)의 질감·색감·붓터치**를 입혀 **이미지 C**를 만드는 기법 — "이미지 B의 스타일을 이미지 A로 옮기는 것" (응용 6차시)
- **파이프라인 (강의 수업 목표 1)**
  1. **입력**: 콘텐츠 이미지, 스타일 이미지
  2. **특징 추출기**: ImageNet으로 사전학습된 **VGG19** — **가중치를 고정**(학습하지 않음)하고 중간 층의 특징 맵만 사용
  3. **최적화 대상**: 네트워크 가중치가 아니라 **생성 이미지의 픽셀 자체** (콘텐츠 복사본 또는 노이즈로 시작, `requires_grad=True`)
  4. **옵티마이저**: L-BFGS 또는 Adam으로 생성 이미지를 반복 갱신
- **손실 함수 (강의 수업 목표 2)**
  - **Content Loss**: 깊은 층(예: conv4_2) 특징 맵의 MSE → **객체와 배치** 보존 → [[Content Loss]]
  - **Style Loss**: 여러 층(conv1_1 ~ conv5_1)의 **Gram Matrix** MSE → **질감·색·패턴** → [[Style Loss]], [[Gram Matrix]]
  - **Total Loss = α·L_content + β·L_style** — 비율(보통 β/α가 매우 큼, 10³~10⁶)로 스타일 강도 조절
- **과제 문항 2 — VGG의 역할**: 가중치 업데이트 **안 함** (`requires_grad_(False)`, `eval()`) — 이유: 이미 학습된 **특징 추출 능력**(저층: 엣지·색, 고층: 형태·의미)만 빌려 쓰고, 바뀌어야 하는 것은 생성 이미지
- **하이퍼파라미터 (강의 수업 목표 3)**: content/style weight, 사용할 층, 반복 횟수, 학습률, 이미지 크기, 시작 이미지(콘텐츠 vs 노이즈)
- **입력 전처리**: ImageNet 평균·표준편차로 정규화 → 결과는 역정규화 후 0~1 clip → [[ImageNet 정규화 통계]]
- **한계와 발전**: 이미지마다 수백 번 최적화 → **느림** → **Fast Style Transfer**(Johnson 2016, 변환 네트워크를 학습해 한 번의 forward), **AdaIN**(임의 스타일 실시간), 확산 모델 기반 스타일 변환

## 수식·원리
```
L_total(p, a, x) = α·L_content(p, x) + β·L_style(a, x)
x* = argmin_x L_total      (VGG 가중치 고정, x = 생성 이미지 픽셀)
x ← x − η·∂L_total/∂x
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torchvision.models import vgg19

vgg = vgg19(weights=None).features[:21].eval()          # 실사용: weights="DEFAULT" (사전학습)
for p in vgg.parameters():
    p.requires_grad_(False)                             # VGG 고정
print(sum(p.requires_grad for p in vgg.parameters()))   # 0

layers = {"1": "relu1_1", "6": "relu2_1", "11": "relu3_1", "20": "relu4_1"}
def feats(x):
    out = {}
    for name, m in vgg._modules.items():
        x = m(x)
        if name in layers: out[layers[name]] = x
    return out
def gram(f):
    b, c, h, w = f.shape
    f = f.view(b, c, h * w)
    return f @ f.transpose(1, 2) / (c * h * w)

torch.manual_seed(0)
content, style = torch.rand(1, 3, 64, 64), torch.rand(1, 3, 64, 64)
fc, fs = feats(content), feats(style)
x = content.clone().requires_grad_(True)                # 최적화 대상 = 이미지 픽셀
opt = torch.optim.Adam([x], lr=0.02)
for step in range(30):
    fx = feats(x)
    lc = F.mse_loss(fx["relu4_1"], fc["relu4_1"])
    ls = sum(F.mse_loss(gram(fx[k]), gram(fs[k])) for k in fx)
    loss = 1 * lc + 1e4 * ls
    if step in (0, 29): print(step, f"{loss.item():.3e}")   # 손실 감소
    opt.zero_grad(); loss.backward(); opt.step()
print(x.grad is not None, vgg[0].weight.grad is None)   # True True  이미지만 갱신
```
