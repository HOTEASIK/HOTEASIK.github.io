# U-Net

## 정의·핵심
- **정의**: Ronneberger et al. (2015). **인코더(축소 경로) – 디코더(확장 경로)** 가 **U자 모양**으로 대칭이고, 같은 해상도의 인코더 특징을 디코더에 **Skip Connection(concat)** 으로 이어 붙이는 구조. 원래 **의료영상 분할**용 → 이후 Pix2Pix 생성자, 확산 모델의 노이즈 예측기로 널리 사용
- **인코더 (Contracting path)**: Conv-Conv-Pool 반복 → 해상도 ↓, 채널 ↑ → "**무엇**"(의미, 문맥)
- **디코더 (Expanding path)**: Up-Conv(ConvTranspose 또는 Upsample+Conv) → 해상도 ↑, 채널 ↓ → "**어디**"(위치 복원)
- **Skip Connection (핵심)**
  - 다운샘플링에서 잃은 **경계·윤곽 같은 공간 세부 정보**를 디코더에 직접 전달
  - ResNet의 덧셈(add)이 아니라 **채널 방향 이어붙이기(concat)** → 채널 수가 합쳐짐
  - 없으면 출력이 흐릿하고 경계가 뭉개짐
- **Pix2Pix에서 (응용 7차시)**: 인코더 Conv2D 8층(Conv–Norm–LeakyReLU), 디코더 Upsample–Conv + skip concat(ReLU, 마지막 tanh), 256×256×3 출력 → [[Pix2Pix]]
- **쓰임**
  - **의미 분할(Semantic Segmentation)**: 픽셀마다 클래스 → 의료영상(세포, 장기, 종양), Dice 손실과 함께 → [[Dice 계수(의료영상)]]
  - **이미지 변환**: Pix2Pix 생성자
  - **확산 모델**: 노이즈가 섞인 이미지 → 노이즈 예측 (입·출력 크기 동일) → [[Diffusion 모델(언급)]]
- **장점**: 적은 데이터로도 잘 학습(강한 데이터 증강과 함께), 입력·출력 해상도 동일

## 수식·원리
```
인코더 l단:  e_l = Conv(Pool(e_{l−1}))         해상도 H/2^l
디코더 l단:  d_l = Conv(concat(Up(d_{l+1}), e_l))
채널:  concat 후 = Up 출력 채널 + e_l 채널
```

## 코드 예시
```python
import torch
import torch.nn as nn

def conv2(i, o): return nn.Sequential(nn.Conv2d(i, o, 3, padding=1), nn.ReLU(), nn.Conv2d(o, o, 3, padding=1), nn.ReLU())

class UNet(nn.Module):
    def __init__(self, in_ch=1, n_cls=2):
        super().__init__()
        self.e1, self.e2, self.mid = conv2(in_ch, 16), conv2(16, 32), conv2(32, 64)
        self.pool = nn.MaxPool2d(2)
        self.up2, self.d2 = nn.ConvTranspose2d(64, 32, 2, 2), conv2(64, 32)    # 32(up) + 32(skip)
        self.up1, self.d1 = nn.ConvTranspose2d(32, 16, 2, 2), conv2(32, 16)    # 16(up) + 16(skip)
        self.head = nn.Conv2d(16, n_cls, 1)
    def forward(self, x):
        e1 = self.e1(x); e2 = self.e2(self.pool(e1)); m = self.mid(self.pool(e2))
        d2 = self.d2(torch.cat([self.up2(m), e2], 1))
        d1 = self.d1(torch.cat([self.up1(d2), e1], 1))
        return self.head(d1)

torch.manual_seed(0)
net = UNet()
x = torch.rand(2, 1, 64, 64)
out = net(x)
print(tuple(out.shape))                          # (2, 2, 64, 64)  픽셀마다 클래스 점수
print(tuple(out.argmax(1).shape))                # (2, 64, 64)  분할 마스크
print(tuple(torch.cat([net.up2(torch.rand(1, 64, 16, 16)), torch.rand(1, 32, 32, 32)], 1).shape))   # (1, 64, 32, 32)  concat으로 채널 합
```
