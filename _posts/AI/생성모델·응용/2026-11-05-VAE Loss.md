# VAE Loss

## 정의·핵심
- **정의**: VAE의 손실 = **재구성 손실(Reconstruction Loss) + KL 발산(KL Divergence)** — 음의 ELBO와 같음 (응용 7차시) → [[ELBO]]
- **1) 재구성 손실**: 디코더 출력 x̂가 원본 x와 얼마나 비슷한가
  - 픽셀이 0~1(이진·MNIST)이면 **BCE** (디코더 끝 sigmoid) → 베르누이 가정의 NLL
  - 실수값이면 **MSE** → 가우시안 가정의 NLL
  - 보통 `reduction="sum"` (픽셀 합) — 평균으로 하면 KL에 비해 너무 작아져 흐릿해짐
- **2) KL 발산**: 인코더가 낸 분포 `N(μ, σ²)` 가 **사전분포 N(0, I)** 에서 얼마나 떨어졌나
  - 닫힌 형태: `KL = −½ Σ (1 + log σ² − μ² − σ²)`
  - μ = 0, σ = 1 일 때 0
- **두 항의 줄다리기 (강의 "균형")**
  - **재구성만**: 각 입력이 잠재 공간의 **고립된 점**(σ → 0)이 됨 → 일반 오토인코더와 같아져 샘플링 불가
  - **KL만**: 모든 입력이 N(0, I)로 **똑같이** 인코딩 → 입력 정보가 사라짐 (posterior collapse)
  - **균형**: 비슷한 입력은 가까운 곳에 겹치게 배치 → **연속적인 잠재 공간**, 부드러운 보간
- **β-VAE**: `L = recon + β·KL` — β > 1이면 잠재 축이 더 독립적(해석 가능)이지만 흐릿함, β < 1이면 선명하지만 잠재 공간이 덜 정돈됨
- **KL annealing**: 학습 초반 β를 0에서 서서히 키워 posterior collapse 방지

## 수식·원리
```
L(x) = −E_{q(z|x)}[log p(x|z)] + KL(q(z|x) ‖ p(z))
     = BCE(x̂, x)            + (−½) Σ_j (1 + log σ_j² − μ_j² − σ_j²)
KL 항의 미분: ∂/∂μ = μ,  ∂/∂σ = σ − 1/σ   → μ = 0, σ = 1 에서 최소
```

## 코드 예시
```python
import torch
import torch.nn.functional as F

def kl(mu, logvar): return (-0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum()).item()

print(kl(torch.zeros(2), torch.zeros(2)))                    # -0.0 (= 0)  N(0,1)과 같음
print(round(kl(torch.tensor([2., 0.]), torch.zeros(2)), 2))  # 2.0  평균이 멀어짐
print(round(kl(torch.zeros(2), torch.log(torch.tensor([0.01, 0.01]))), 2))   # 3.62  σ가 0에 가까움(점처럼) → 벌점

# 닫힌 형태 KL = 몬테카를로 추정과 일치하는지 확인
torch.manual_seed(0)
mu, s = torch.tensor(1.0), torch.tensor(0.5)
z = mu + s * torch.randn(200000)
logq = -0.5 * ((z - mu) / s) ** 2 - torch.log(s)
logp = -0.5 * z ** 2
print(round((logq - logp).mean().item(), 2), round(kl(mu.view(1), torch.log(s ** 2).view(1)), 2))   # 0.82 0.82

x = torch.tensor([1., 0., 1.]); x_hat = torch.tensor([0.9, 0.2, 0.7])
recon = F.binary_cross_entropy(x_hat, x, reduction="sum")
print(round(recon.item(), 3))                                # 0.685  재구성 손실 (BCE 합)
```
