# GAN 학습

## 정의·핵심
- **정의**: 판별자 D와 생성자 G를 **번갈아(Alternating Optimization)** 업데이트하는 학습 절차 (응용 7차시)
- **1단계 — D 학습 (과제 문항 6)**
  1. 진짜 이미지 → D → **레이블 1**과 BCE (`real_loss`)
  2. 노이즈 z → G → 가짜 이미지를 **`detach()`** 해서 D → **레이블 0**과 BCE (`fake_loss`) — detach로 G까지 기울기가 흐르지 않게
  3. `d_loss = real_loss + fake_loss` → `d_loss.backward()` → `optimizerD.step()`
- **2단계 — G 학습**
  1. 새로(또는 같은) 가짜 이미지 → D → **레이블 1(진짜인 척)** 과 BCE
  2. `g_loss.backward()` → `optimizerG.step()` (D 파라미터는 이 옵티마이저에 없으므로 갱신 안 됨)
- **Non-saturating 손실**: 원래 식의 G 목표 `min log(1 − D(G(z)))`는 초반(D가 가짜를 쉽게 구별, D(G(z)) ≈ 0)에 **기울기가 거의 0** → 대신 `max log D(G(z))` = "가짜에 레이블 1을 붙인 BCE" 사용 (실무 표준)
- **가중치 초기화 (과제 문항 5)**: Conv·ConvTranspose 가중치를 **N(0, 0.02)**, BatchNorm 가중치는 N(1, 0.02)·bias 0 (DCGAN 논문 권장) → `model.apply(weights_init)`
- **안정화 팁**
  - Adam `lr=2e-4, betas=(0.5, 0.999)`
  - D에 **LeakyReLU**(0.2), G 출력 **tanh**(이미지를 [-1, 1]로 정규화)
  - **Label smoothing**(진짜 레이블 0.9), D·G 학습 비율 조절
  - 손실 값만 보고 판단하기 어려움 → 주기적으로 **고정 노이즈**로 샘플을 뽑아 눈으로 확인, FID 등 지표
- **학습 곡선 (강의)**: 손실이 수렴하지 않고 **진동** — D와 G가 서로 따라잡는 과정. D 손실이 0에 붙으면 G가 학습 못 하는 신호

## 수식·원리
```
D:  max  E[log D(x)] + E[log(1 − D(G(z)))]
    ⇔ min  BCE(D(x), 1) + BCE(D(G(z).detach()), 0)
G:  min  E[log(1 − D(G(z)))]          (원래 식, 초반 기울기 소실)
    → min  BCE(D(G(z)), 1) = −E[log D(G(z))]   (non-saturating)
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
real_data = lambda n: torch.randn(n, 1) * 0.5 + 3.0          # 목표 분포 N(3, 0.5)
G = nn.Sequential(nn.Linear(4, 16), nn.ReLU(), nn.Linear(16, 1))
D = nn.Sequential(nn.Linear(1, 16), nn.LeakyReLU(0.2), nn.Linear(16, 1), nn.Sigmoid())
criterion = nn.BCELoss()
optD = torch.optim.Adam(D.parameters(), lr=2e-3, betas=(0.5, 0.999))
optG = torch.optim.Adam(G.parameters(), lr=2e-3, betas=(0.5, 0.999))
ones, zeros = torch.ones(64, 1), torch.zeros(64, 1)

print(round(G(torch.randn(1000, 4)).mean().item(), 2))       # 학습 전 생성 평균 (목표 3과 멂)
for step in range(2000):
    real = real_data(64); fake = G(torch.randn(64, 4))
    d_loss = criterion(D(real), ones) + criterion(D(fake.detach()), zeros)   # 1단계: D
    optD.zero_grad(); d_loss.backward(); optD.step()
    g_loss = criterion(D(fake), ones)                         # 2단계: G (진짜인 척)
    optG.zero_grad(); g_loss.backward(); optG.step()
with torch.no_grad():
    s = G(torch.randn(1000, 4))
print(round(s.mean().item(), 1), round(D(real_data(1000)).mean().item(), 1))   # 평균이 3 근처, D는 0.5 근처

d = torch.tensor([0.01])                                       # 초반: D가 가짜를 쉽게 구별
d.requires_grad_(True); torch.log(1 - d).backward(); g1 = d.grad.abs().item()
d.grad = None; (-torch.log(d)).backward(); g2 = d.grad.abs().item()
print(round(g1, 2), round(g2, 1))                              # 1.01 100.0  non-saturating이 기울기 큼
```
