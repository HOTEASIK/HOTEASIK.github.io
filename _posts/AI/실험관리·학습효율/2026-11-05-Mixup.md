# Mixup

## 정의·핵심
- **정의 (보충 02 성능 향상 — 정규화)**: **두 이미지를 λ : 1−λ로 섞고, 라벨도 같은 비율로 섞는** 데이터 증강·정규화 기법 (Zhang et al., 2018)
  - Mixup: 두 이미지가 **반투명하게 겹쳐짐**
  - **CutMix**: 한 이미지의 **패치를 잘라 다른 이미지에 붙임** — 라벨은 패치 **면적 비율**로 섞음
- **효과 (강의)**: **결정경계를 부드럽게** → 강건성·일반화 ↑ / 주의: 너무 강하면 train 정확도 ↓ — 적당히
- **공통 원리 (강의)**: Label Smoothing·Mixup·CutMix 셋 다 "**정답을 너무 확신하지 말라**"(과신 억제) — Label Smoothing은 정답값을 살짝 낮추고, Mixup/CutMix는 애매한 혼합 샘플을 만들어 경계를 매끄럽게 → [[Label Smoothing]]
  - 대회에서 **마지막 몇 %** 를 짜낼 때 자주
- **언제 쓰나 (강의)**: 과적합 신호(train↑ val↓)가 보이면 정규화 손잡이를 하나씩 조임 — 보통 Dropout·Weight decay·증강을 먼저, 필요하면 **라벨 스무딩·Mixup**을 더함. 한꺼번에 켜지 말고 하나씩 효과 확인 → [[Dropout]], [[데이터 증강]]
- **구현 포인트**
  - λ ~ **Beta(α, α)** (보통 α = 0.2~0.4, 이미지 대회는 1.0도) — α가 작으면 대부분 한쪽에 가까운 λ
  - 배치 안에서 **순서를 섞은 짝**과 혼합 (`perm = randperm(B)`)
  - 손실: `λ·CE(out, y_a) + (1−λ)·CE(out, y_b)` (= 소프트 라벨 CE와 같음)
  - **학습 때만** 적용, 검증·추론엔 원본

## 수식·원리
```
λ ~ Beta(α, α)
x̃ = λ x_i + (1 − λ) x_j,     ỹ = λ y_i + (1 − λ) y_j     (y: 원-핫)
L = λ CE(f(x̃), y_i) + (1 − λ) CE(f(x̃), y_j)
CutMix:  x̃ = M ⊙ x_i + (1 − M) ⊙ x_j,   λ = 1 − (패치 면적 / 전체 면적)
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn.functional as F

def mixup(x, y, n_cls, alpha=0.4, rng=np.random.default_rng(0)):
    lam = float(rng.beta(alpha, alpha))
    perm = torch.randperm(x.size(0))
    x_mix = lam * x + (1 - lam) * x[perm]
    y_soft = lam * F.one_hot(y, n_cls).float() + (1 - lam) * F.one_hot(y[perm], n_cls).float()
    return x_mix, y, y[perm], lam, y_soft

torch.manual_seed(0)
x = torch.rand(8, 3, 32, 32); y = torch.randint(0, 10, (8,))
x_mix, ya, yb, lam, y_soft = mixup(x, y, 10)
print(tuple(x_mix.shape), 0 <= lam <= 1, torch.allclose(y_soft.sum(1), torch.ones(8)))   # (8, 3, 32, 32) True True

logits = torch.randn(8, 10)                                   # 두 가지 손실 계산은 같음
loss_a = lam * F.cross_entropy(logits, ya) + (1 - lam) * F.cross_entropy(logits, yb)
loss_b = -(y_soft * F.log_softmax(logits, 1)).sum(1).mean()
print(torch.allclose(loss_a, loss_b))                         # True

def cutmix(x, y, lam=0.75):                                   # 패치 붙이기, 라벨은 면적 비율
    H = W = x.size(-1); ph = pw = int(H * (1 - lam) ** 0.5)
    perm = torch.randperm(x.size(0)); out = x.clone()
    out[:, :, :ph, :pw] = x[perm, :, :ph, :pw]
    return out, 1 - ph * pw / (H * W)
xc, lam_c = cutmix(x, y)
print(round(lam_c, 3))                                        # 0.75  실제 남은 면적 비율로 라벨을 섞음

lams = np.random.default_rng(1).beta(0.2, 0.2, 10000)
print(round(float(np.mean((lams < 0.1) | (lams > 0.9))), 2))  # 0.67  α가 작으면 λ가 0이나 1에 몰림 (약한 혼합이 대부분)
```
