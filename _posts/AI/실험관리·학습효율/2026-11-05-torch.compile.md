# torch.compile

## 정의·핵심
- **정의 (보충 2_6 STEP 6)**: PyTorch 2.x의 **그래프 컴파일** — `torch.compile(model)` **한 줄**로 커널을 최적화해 더 빠르게 (미지원/CPU면 건너뜀)
  - 보충 02 "추가 가속 카드": 큰 모델에서 추가 가속, **Colab 버전·환경에 따라 효과 상이**
- **동작 원리**
  1. **TorchDynamo**: 파이썬 바이트코드를 가로채 연산을 **FX 그래프**로 캡처 (캡처 못 하는 부분은 **graph break** → 그 부분만 eager로)
  2. **AOTAutograd**: 역전파 그래프까지 미리 생성
  3. **백엔드(기본 Inductor)**: 연산 **융합(fusion)** 해 GPU는 **Triton** 커널, CPU는 **C++** 코드로 생성 → 메모리 왕복·커널 호출 횟수 감소
- **특징**
  - **첫 호출이 느림** (컴파일 시간 수십 초) → 이후 호출부터 빨라짐 — 짧은 실험엔 손해일 수 있음
  - 입력 shape이 바뀌면 **재컴파일** (`dynamic=True`로 완화)
  - 모드: `mode="reduce-overhead"`(CUDA Graph로 작은 배치 오버헤드 감소), `"max-autotune"`(커널 자동 튜닝, 컴파일 더 김)
  - 결과는 eager와 **수치적으로 거의 같음** (연산 순서 차이로 미세한 오차)
- **이 환경 (Windows)**: 기본 Inductor 백엔드는 **C++ 컴파일러(`cl`)가 없어 실패** (`BackendCompilerFailed: Compiler: cl is not found`) → 아래 예시는 컴파일러가 필요 없는 **`aot_eager`** 백엔드로 그래프 캡처 흐름만 확인 (가속 효과는 없음). Linux/Colab GPU에선 기본 백엔드로 실제 가속
- **다른 가속 카드와 함께 (강의)**: `cudnn.benchmark = True`(입력 크기 고정 시, 재현성과 상충), `zero_grad(set_to_none=True)`, 평가 시 `@torch.no_grad()`, `pin_memory + non_blocking`, 큰 배치 + AMP → [[AMP(혼합 정밀도)]], [[DataLoader 속도]]

## 수식·원리
```
eager:    y = relu(x @ W + b)  →  커널 3번 (matmul, add, relu), 중간 결과를 메모리에 쓰고 읽음
compiled: matmul + (add·relu 융합)  →  커널 수·메모리 왕복 감소
총 시간 = 컴파일 시간(1회) + N × 스텝 시간(compiled)  <  N × 스텝 시간(eager)  ⇔  N이 충분히 클 때
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
model = nn.Sequential(nn.Linear(64, 128), nn.ReLU(), nn.Linear(128, 10))
x = torch.randn(32, 64)

compiled = torch.compile(model, backend="aot_eager")      # 이 PC: 기본 inductor는 cl 컴파일러 없음 → aot_eager
y_eager, y_comp = model(x), compiled(x)
print(torch.allclose(y_eager, y_comp, atol=1e-6))         # True  결과는 eager와 같음

loss = nn.functional.cross_entropy(compiled(x), torch.randint(0, 10, (32,)))
loss.backward()                                            # 역전파도 컴파일된 그래프로 (AOTAutograd)
print(model[0].weight.grad is not None)                    # True

counts = {"graphs": 0}
def counting_backend(gm, example_inputs):                  # 캡처된 FX 그래프 확인용 백엔드
    counts["graphs"] += 1; counts["ops"] = len([n for n in gm.graph.nodes if n.op == "call_module" or n.op == "call_function"])
    return gm.forward
torch._dynamo.reset()
torch.compile(model, backend=counting_backend)(x)
print(counts["graphs"], counts["ops"] >= 3)                # 1 True  Linear·ReLU·Linear가 하나의 그래프로 캡처
```
