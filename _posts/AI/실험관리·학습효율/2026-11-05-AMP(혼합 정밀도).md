# AMP(혼합 정밀도)

## 정의·핵심
- **정의 (보충 2_6 STEP 3)**: Automatic Mixed Precision — 연산을 **16비트(float16)** 로 처리해 **더 빠르고 메모리도 적게**. `autocast` + `GradScaler` 한 쌍이면 끝 (GPU 전용 효과) → [[부동소수점]]
  - "계산은 16비트로 빠르게, 민감한 부분(누적·손실)은 32비트로 안전하게 — 두 정밀도를 섞는다"
- **두 부품 (보충 02)**
  - **autocast**: 어떤 연산을 16비트로 할지 **자동 결정** — 순전파·손실 계산을 감싸는 컨텍스트. 행렬곱·합성곱은 FP16(빠름), 합·정규화·softmax 등 민감한 연산은 FP32 유지(안전)
  - **GradScaler**: 작은 그래디언트가 0으로 사라지는 것(**underflow**) 방지 — ① 손실에 큰 수(예: ×1024)를 곱해 그래디언트를 키우고 ② 역전파 ③ `optimizer.step` 직전에 다시 나눠 원래 크기로. scale 값은 **동적으로 자동 조절** (inf/nan이 나오면 그 스텝을 건너뛰고 scale을 줄임)
- **기존 루프에 3가지만 추가 (강의 코드)**: ① `scaler = GradScaler()` (루프 밖 한 번) ② `with autocast():` 로 순전파·손실만 감싸기 ③ `scaler.scale(loss).backward()` → `scaler.step(optimizer)` → `scaler.update()`
  - 주의: **backward는 autocast 밖**에서 (2_6 연습 문제 2) / 최신 PyTorch: `torch.amp.autocast('cuda')`, `torch.amp.GradScaler('cuda')`
- **효과 (강의 예시, CIFAR급 CNN)**: 에폭당 시간 42s → 26s (**↓38%**), 최대 GPU 메모리 5.1GB → 3.0GB (**↓41%**), 검증 정확도 0.912 → 0.911 (≈ 동일)
  - "품질은 거의 그대로, 시간·메모리는 절감" → 대부분의 GPU 학습에서 **기본 옵션**, 효율 최적화의 **1순위 카드** (계산·메모리 병목 둘 다 도움)
- **주의점 (강의)**: MNIST처럼 작으면 이득이 작을 수 있음(오버헤드 비중) / NaN loss가 지속되면 lr 점검 / **BF16**(A100·L4)은 범위가 넓어 **GradScaler 불필요**
- **연습 문제 정답 (강의)**: AMP로 정확도가 그대로여도 쓸 이유 → 같은 결과를 더 값싸게 / GradScaler가 막는 것 → **언더플로**

## 수식·원리
```
scaled_loss = loss × S                      (S: 동적 scale, 예 2^16에서 시작)
grad_fp16 = ∇(scaled_loss) = S · ∇loss      → underflow 회피
step 직전:  grad ← grad / S   (inf/nan이면 skip, S ← S/2)
N번 연속 정상이면  S ← S × 2
```

## 코드 예시
```python
import torch
import torch.nn as nn

device = "cuda" if torch.cuda.is_available() else "cpu"
amp_dtype = torch.float16 if device == "cuda" else torch.bfloat16      # CPU autocast는 bf16
torch.manual_seed(0)
model = nn.Sequential(nn.Linear(256, 512), nn.ReLU(), nn.Linear(512, 10)).to(device)
opt = torch.optim.SGD(model.parameters(), lr=0.1)
scaler = torch.amp.GradScaler(device, enabled=(device == "cuda"))       # ① 스케일러 (bf16이면 불필요)
X = torch.randn(512, 256, device=device); y = torch.randint(0, 10, (512,), device=device)

for step in range(30):
    opt.zero_grad()
    with torch.autocast(device_type=device, dtype=amp_dtype):          # ② 순전파·손실만 감싸기
        out = model(X)
        loss = nn.functional.cross_entropy(out, y)
    scaler.scale(loss).backward()                                        # ③ autocast 밖에서 backward
    scaler.step(opt); scaler.update()
print(out.dtype == amp_dtype, loss.dtype, model[0].weight.dtype)        # True torch.float32 torch.float32  행렬곱은 16비트, 손실·가중치는 32비트
print(loss.item() < 2.3)                                                 # True  학습이 정상 진행

g = torch.tensor(1e-8)                                                   # GradScaler가 필요한 이유
print(g.half().item(), (g * 65536).half().item() > 0)                    # 0.0 True  스케일하면 FP16에서 살아남음
```
