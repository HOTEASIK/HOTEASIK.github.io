# 이상치(Outlier)

## 정의·핵심
- **정의**: 대부분의 데이터와 **동떨어진 값·샘플** — 측정 오류·입력 실수일 수도, 진짜 드문 사건(사기 거래, 고장)일 수도 있음
- **이미지 데이터의 이상치 (보충 02 데이터 정제)**: **깨진 파일 · 다른 밝기 · 과도한 편집 이미지** — 라벨 오류·중복 누수·분포 이동과 함께 정제 대상 → [[데이터 클렌징 기법]]
- **왜 문제인가**
  - 평균·분산·MSE 손실이 이상치에 크게 끌려감 (평균은 민감, **중앙값은 강건**)
  - 정규화 통계(평균·표준편차)를 왜곡 → 나머지 데이터의 스케일이 뭉개짐 → [[정규화(Normalize)]]
  - 양자화 scale도 이상치 하나에 폭증 → 블록 단위 양자화로 완화 → [[비트와 양자화]]
- **탐지 방법**
  - **Z-score**: `|x − μ| / σ > 3` — 정규분포 가정, 이상치 자체가 μ·σ를 오염시키는 약점
  - **IQR (사분위 범위)**: `Q1 − 1.5·IQR` 미만 또는 `Q3 + 1.5·IQR` 초과 — 박스플롯의 수염, 분포 가정 없이 강건
  - **Modified Z (MAD)**: 중앙값·중앙절대편차 기반 — `0.6745·|x − median| / MAD > 3.5`
  - **다변량 가우시안 / 마할라노비스 거리**: 확률 밀도가 낮은 데이터를 비정상으로 (9차시 "다변량 가우시안 활용 — 이상치 탐지") → [[Gaussian Splatting]]
  - **모델 기반**: Isolation Forest, LOF, 오토인코더 **재구성 오차** → [[AutoEncoder]]
  - **이미지**: 파일 열기 실패, 밝기·대비 통계(평균 픽셀값)의 극단, 임베딩 공간에서 클래스 centroid와 먼 샘플
- **처리**: 제거(명백한 오류) / 수정 / **클리핑(winsorize)** / 강건한 손실(Huber, MAE) / 로그 변환 / 그대로 두기(진짜 드문 사건이면 오히려 중요한 정보) → [[지표로 쓰는 MSE·MAE]]
- **주의**: 이상치 판정 기준은 **학습 데이터로만** 정하고 검증·테스트에 같은 기준 적용 (누수 방지)

## 수식·원리
```
Z = (x − μ) / σ,               |Z| > 3 → 이상치
IQR = Q3 − Q1,                 x < Q1 − 1.5·IQR  or  x > Q3 + 1.5·IQR
Modified Z = 0.6745 (x − median) / MAD,   MAD = median(|x − median|),   > 3.5
마할라노비스:  D² = (x − μ)ᵀ Σ⁻¹ (x − μ)  ~ χ²_d
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)
x = np.concatenate([rng.normal(50, 5, 200), [120, 130, -40]])   # 정상 200개 + 이상치 3개

z = (x - x.mean()) / x.std()
q1, q3 = np.percentile(x, [25, 75]); iqr = q3 - q1
iqr_out = (x < q1 - 1.5 * iqr) | (x > q3 + 1.5 * iqr)
med = np.median(x); mad = np.median(np.abs(x - med))
mz_out = np.abs(0.6745 * (x - med) / mad) > 3.5
print(int((np.abs(z) > 3).sum()), int(iqr_out.sum()) >= 3, set(np.flatnonzero(mz_out)) >= {200, 201, 202})   # 3 True True  이상치 탐지 (IQR·MAD는 3개 모두)

print(round(x.mean() - x[:200].mean(), 2), round(np.median(x) - np.median(x[:200]), 2))   # 0.29 0.0  평균은 끌려가고 중앙값은 거의 그대로

X2 = rng.multivariate_normal([0, 0], [[1, 0.9], [0.9, 1]], 300)   # 다변량: 각 축으로는 정상인데 상관관계를 깨는 점
X2 = np.vstack([X2, [[1.5, -1.5]]])
mu, S = X2.mean(0), np.cov(X2.T)
d2 = np.einsum("ni,ij,nj->n", X2 - mu, np.linalg.inv(S), X2 - mu)
print(int(np.argmax(d2)), bool(np.all(np.abs(X2[-1]) < 2)))     # 300 True  축별 |값|<2라 Z-score론 못 잡지만 마할라노비스로 탐지

imgs = rng.normal(0.5, 0.05, (50, 8, 8)).clip(0, 1); imgs[7] = 0.02   # 이미지: 거의 검은 깨진 이미지
bright = imgs.mean((1, 2)); bq1, bq3 = np.percentile(bright, [25, 75])
print(np.flatnonzero(bright < bq1 - 1.5 * (bq3 - bq1)).tolist())      # [7]  밝기 통계로 이상 이미지 발견
```
