# Optuna 실습

## 정의·핵심
- **실습 흐름 (보충 2_1 하이퍼파라미터 최적화 실습)**: MNIST + MLP로 HP를 **바꿔 가며 측정**하고 Grid·Random·Bayesian 탐색을 **직접 구현** → 마지막 STEP 5에서 **Optuna**로 Bayesian
  - STEP 0: **`run()` 한 줄 실험 함수** — HP를 인자로 받아 검증 정확도를 돌려줌 → 모든 실험을 한 줄로
  - STEP 1: 학습률 감각 (로그 스케일) / STEP 2: 배치·옵티마이저 / STEP 3: Grid / STEP 4: Random / **STEP 5: Bayesian(Optuna)**
  - 라이브러리 자체 설명(구성 요소·API)은 → [[Optuna]]
- **Optuna 코드 구조 (강의)**
  - `objective(trial)`: `trial.suggest_float('lr', 1e-4, 1e-1, log=True)`, `trial.suggest_categorical('batch', [32, 64, 128])` → `return run(...)` (검증 정확도)
  - `study = optuna.create_study(direction='maximize')` → `study.optimize(objective, n_trials=20)` → `study.best_params`, `study.best_value`
  - 내부적으로 **TPE** → [[Bayesian Optimization]]
  - "베이지안 최적화의 복잡한 수학은 전부 Optuna 안에 — 우리는 **무엇을 탐색하고(suggest) 무엇을 최적화할지(return)** 만 적으면 됨"
- **종합 문제 (2_1)**
  1. `objective`에 **weight_decay** `trial.suggest_float('wd', 1e-6, 1e-2, log=True)` 추가, `run()`이 받아 옵티마이저에 전달 → [[L2 규제(Ridge, weight_decay)]]
  2. `n_trials`를 25로 늘려 최고 성능 갱신
  3. 찾은 최적 설정으로 **전체 데이터(train_full)** 에서 한 번 더 학습해 확인
  - 핵심: **한 번에 하나씩** 바꾸며 효과 확인, 최종 설정만 전체 데이터로 검증
- **추가 기능**: **Pruning**(`trial.report` + `trial.should_prune()` — 가망 없는 시도 조기 중단, Hyperband·Median pruner) → [[Hyperband·BOHB]] / 시각화(`optuna.visualization.plot_optimization_history`, `plot_param_importances`)
- 이 환경엔 optuna **미설치** → 사용 코드는 미실행, 아래 실행 예시는 같은 `objective` 구조를 TPE 원리(좋은/나쁜 그룹 밀도 비)로 직접 구현

## 수식·원리
```
objective(trial) → score          (n_trials번 호출)
TPE: 관측을 상위 γ(≈25%) / 나머지로 나눔 → l(x), g(x) 커널 밀도 추정
     후보 여러 개를 l(x)에서 뽑아 l(x)/g(x)가 가장 큰 것을 다음 trial로
```

## 코드 예시
Optuna 사용 코드 (optuna 미설치 — 이 환경 미실행):
```
import optuna
def objective(trial):
    lr = trial.suggest_float("lr", 1e-4, 1e-1, log=True)
    wd = trial.suggest_float("wd", 1e-6, 1e-2, log=True)
    hidden = trial.suggest_categorical("hidden", [64, 128, 256])
    for epoch in range(3):
        acc = run_epoch(lr=lr, wd=wd, hidden=hidden, epoch=epoch)
        trial.report(acc, epoch)
        if trial.should_prune(): raise optuna.TrialPruned()     # 가망 없으면 조기 중단
    return acc
study = optuna.create_study(direction="maximize", pruner=optuna.pruners.MedianPruner())
study.optimize(objective, n_trials=25)
print(study.best_params, study.best_value)
```

실행 가능한 예시 (작은 데이터 + 같은 objective 구조, TPE 원리 직접 구현):
```python
import numpy as np
import torch
import torch.nn as nn

torch.manual_seed(0)
X = torch.randn(600, 20); w_true = torch.randn(20, 3)
y = (X @ w_true + 0.5 * torch.randn(600, 3)).argmax(1)
Xtr, ytr, Xva, yva = X[:400], y[:400], X[400:], y[400:]

def run(lr, wd, hidden, epochs=30):                       # 2_1의 한 줄 실험 함수
    torch.manual_seed(0)
    m = nn.Sequential(nn.Linear(20, hidden), nn.ReLU(), nn.Linear(hidden, 3))
    opt = torch.optim.Adam(m.parameters(), lr=lr, weight_decay=wd)
    for _ in range(epochs):
        loss = nn.functional.cross_entropy(m(Xtr), ytr); opt.zero_grad(); loss.backward(); opt.step()
    return (m(Xva).argmax(1) == yva).float().mean().item()

rng = np.random.default_rng(0)
def sample_prior():
    return {"log_lr": rng.uniform(-4, -1), "log_wd": rng.uniform(-6, -2), "hidden": int(rng.choice([16, 64, 128]))}
def objective(p): return run(10 ** p["log_lr"], 10 ** p["log_wd"], p["hidden"])

trials = []
for t in range(20):
    if t < 6:                                               # 웜업: 무작위
        p = sample_prior()
    else:                                                   # TPE: 좋은 그룹 근처 후보 중 l/g 최대
        trials.sort(key=lambda r: -r[1]); good = [r[0] for r in trials[: max(2, len(trials) // 4)]]; bad = [r[0] for r in trials[len(good):]]
        def dens(x, pts): return np.mean([np.exp(-((x - q["log_lr"]) / 0.4) ** 2) for q in pts]) + 1e-9
        cands = [dict(good[rng.integers(len(good))]) for _ in range(16)]
        for c in cands: c["log_lr"] = float(np.clip(c["log_lr"] + rng.normal(0, 0.3), -4, -1))
        p = max(cands, key=lambda c: dens(c["log_lr"], good) / dens(c["log_lr"], bad))
    trials.append((p, objective(p)))
best_p, best_v = max(trials, key=lambda r: r[1])
first6 = max(v for _, v in trials[:6])
print(round(best_v, 3) >= round(first6, 3), 10 ** best_p["log_lr"] > 1e-3)   # True True  탐색이 진행되며 웜업 최고 이상, 너무 작은 lr은 배제
```
