# 재현성

## 정의·핵심
- **정의**: 같은 코드·데이터·설정으로 다시 돌렸을 때 **같은 결과**가 나오는 성질
- **왜 중요한가 (보충 02)**
  - **공정 비교**: 시드가 다르면 A가 나은 건지 **운인지** 알 수 없음
  - **운 vs 실력**: 한 번의 좋은 결과가 우연일 수 있음 → **여러 시드**로 확인
  - **재현**: 찾은 최적 설정을 남이(미래의 나도) 재현할 수 있어야 함
  - "'한 번 좋은 값'을 믿지 말 것 — 시드를 바꿔도 좋아야 진짜다"
- **재현 체크리스트 (강의)**
  - **시드 고정**: `torch`·`numpy`·`random` 시드 고정 (+ `torch.cuda.manual_seed_all`)
  - **설정 기록**: 각 시도의 HP·결과를 전부 로깅 → [[WandB 실험 기록·Sweeps]]
  - **환경 기록**: 라이브러리·CUDA 버전, 하드웨어
  - **여러 시드**: 최종 후보는 **2~3개 시드**로 재확인
- **set_seed (보충 2_6 훈련 관리)**
  - `torch.backends.cudnn.deterministic = True`, `torch.backends.cudnn.benchmark = False`
  - 학습 시작 전에 **한 번** `set_seed(42)`
  - DataLoader worker에도 시드가 필요하면 **`worker_init_fn`**(+ `generator`) 전달
  - 주의: 시드를 고정해도 **GPU 연산 특성상 완벽히 같지 않을 수** 있음 (원자적 덧셈 순서 등) → 완전 결정성은 `torch.use_deterministic_algorithms(True)`
- **상충 관계**: `cudnn.benchmark = True`(입력 크기 고정 시 빠른 알고리즘 자동 선택)는 **속도↑ 재현성↓** → 목적에 맞게 선택 (강의 "추가 가속 카드")
- **체크포인트 (2_6 연습 문제 5)**: 학습 재개를 위해 **모델 + 옵티마이저 상태 + (스케줄러/에폭)** 함께 저장 → [[state_dict 저장·불러오기]]

## 수식·원리
```
같은 seed → 같은 난수열 → 같은 초기 가중치·셔플 순서·드롭아웃 마스크 → 같은 결과
결과 보고:  mean ± std  over seeds {0, 1, 2}
```

## 코드 예시
```python
import random
import numpy as np
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

def set_seed(seed=42):                                    # 2_6 실습
    random.seed(seed); np.random.seed(seed); torch.manual_seed(seed); torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False

def experiment(seed):
    set_seed(seed)
    X = torch.randn(200, 5); y = (X.sum(1) > 0).long()
    g = torch.Generator().manual_seed(seed)              # 셔플 순서도 고정
    loader = DataLoader(TensorDataset(X, y), batch_size=32, shuffle=True, generator=g)
    m = nn.Sequential(nn.Linear(5, 16), nn.ReLU(), nn.Dropout(0.3), nn.Linear(16, 2))
    opt = torch.optim.SGD(m.parameters(), lr=0.1)
    for _ in range(3):
        for xb, yb in loader:
            loss = nn.functional.cross_entropy(m(xb), yb); opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

print(experiment(42) == experiment(42))                  # True  같은 시드 → 완전히 같은 결과
runs = [experiment(s) for s in (0, 1, 2)]
print(len(set(runs)) == 3, round(float(np.std(runs)), 4) > 0)   # True True  시드마다 결과가 다름 → 여러 시드로 mean±std 보고

ckpt = {"model": nn.Linear(2, 2).state_dict(), "optimizer": None, "epoch": 3, "seed": 42}   # 재개용 체크포인트 구성
print(sorted(ckpt))                                      # ['epoch', 'model', 'optimizer', 'seed']
```
