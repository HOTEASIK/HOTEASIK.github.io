# PBT

## 정의·핵심
- **정의 (보충 02)**: Population-Based Training (DeepMind, 2017). **학습 중에 하이퍼파라미터를 진화**시키는 방법 — 진화(자연선택)처럼 '**좋은 걸 베끼고 조금 바꾸며**'
- **핵심 개념 (강의)**
  - **집단 (Population)**: 여러 모델(worker)을 서로 다른 HP로 **동시 학습**
  - **Exploit (복제)**: 주기적으로 성능 나쁜 worker가 좋은 worker의 **가중치 + HP를 복제**
  - **Explore (변형)**: 복제 후 HP를 약간 **흔들어(perturb, ×0.8 / ×1.2)** 다양성 유지
  - 차별점: 학습을 멈추지 않고 **HP가 시간에 따라 변함**
- **강의 예시 (5에폭 체크포인트)**: W1 lr 0.05 / 0.88 유지 · W2 0.01 / 0.82 → **W4 복제** 후 0.03 → 0.036(×1.2) · W3 0.10 / 0.79 → W4 복제 후 0.03 → 0.024(×0.8) · W4 0.03 / **0.90 최고** 유지
- **왜 특별한가 (강의)**
  - **정적 → 동적**: 기존 탐색은 'HP 고정 후 학습', PBT는 '학습 중 HP가 변함'
  - **스케줄 발견**: "처음엔 lr 높게, 나중엔 낮게" 같은 **스케줄**을 자동으로 찾음 — 결과가 값 하나가 아니라 **시간에 따른 변화**
  - **자원 공유**: 좋은 가중치·설정을 집단이 공유 → 탐색과 학습을 **한 번의 실행**으로 (벽시계 시간 절약)
- **단점 (강의)**: 여러 worker 병렬 자원(GPU 여러 개) 필요, 구현·관리 복잡(Ray Tune 필요)
- **쓰임새 (강의)**: **강화학습**·대형 모델 학습처럼 학습이 길고 HP 스케줄이 중요한 문제 → [[PPO]]

## 수식·원리
```
매 T 스텝마다 (worker i):
  if score_i ∈ 하위 q%:  θ_i ← θ_j,  λ_i ← λ_j     (j ∈ 상위 q%, exploit)
                         λ_i ← λ_i × U{0.8, 1.2}   (explore)
결과: λ_i(t)  — 시간에 따른 하이퍼파라미터 스케줄
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)
# 1차원 문제: w를 목표 3.0에 맞추기. 좋은 lr은 초반엔 크고 후반엔 작아야 함(노이즈가 있는 기울기)
def train_step(w, lr):
    grad = 2 * (w - 3.0) + rng.normal(0, 2.0)
    return w - lr * grad
def score(w): return -abs(w - 3.0)

workers = [{"w": 0.0, "lr": lr, "hist": []} for lr in (0.01, 0.05, 0.2, 0.4)]
for t in range(1, 201):
    for wk in workers:
        wk["w"] = train_step(wk["w"], wk["lr"])
    if t % 20 == 0:                                         # 체크포인트마다 exploit + explore
        evals = [np.mean([score(train_step(wk["w"], 0.0)) for _ in range(1)]) for wk in workers]
        order = np.argsort(evals)
        for bad, good in zip(order[:1], order[::-1][:1]):   # 하위 1개가 최고를 복제
            workers[bad]["w"] = workers[good]["w"]
            workers[bad]["lr"] = workers[good]["lr"] * rng.choice([0.8, 1.2])
        for wk in workers: wk["hist"].append(round(wk["lr"], 4))
best = max(workers, key=lambda wk: score(wk["w"]))
print(len(best["hist"]), round(abs(best["w"] - 3.0), 2) < 0.5)   # 10 True  학습과 탐색이 한 번의 실행에서
print(len({wk["lr"] for wk in workers}) >= 2)                    # True  explore로 다양성 유지
```
