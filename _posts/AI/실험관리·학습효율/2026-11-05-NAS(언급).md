# NAS(언급)

## 정의·핵심
- **정의 (보충 02)**: Neural Architecture Search — lr·batch가 아니라 **'층 종류·연결·깊이' 등 모델 구조 자체**를 탐색 ("하이퍼파라미터 탐색의 끝판")
  - **컨트롤러**: 신경망(RNN 등)이 구조를 '설계'하도록 학습
  - **보상**: 설계한 구조의 **검증 성능**을 보상으로 컨트롤러 개선
  - 결과: 사람이 안 떠올린 새 구조 발견 — **EfficientNet·MobileNetV3·NASNet** 등이 NAS로 탄생 → [[MobileNet(언급)]]
- **세 갈래 (강의)**
  1. **강화학습 기반 (RL)**: 컨트롤러(RNN)가 구조 생성 → 성능을 보상으로 정책 갱신 — 최초의 NAS, 비용 매우 큼 → [[REINFORCE]]
  2. **진화 알고리즘**: 구조 집단을 두고 좋은 것끼리 **교배·변이** (자연선택처럼 세대 거듭)
  3. **미분가능 (DARTS)**: 구조 선택을 **연속값(soft)으로 완화** → 경사하강법으로 구조 학습 → 훨씬 빠름
- **현실 (강의)**: 초기 RL-NAS는 **GPU 수천 일** (후보 구조마다 처음부터 학습) → **가중치 공유(ENAS)**, **DARTS**로 수천 배 빨라짐 → AutoML 도구로 대중화 중
- **강의 예시**: 탐색 공간 = 커널 {3×3, 5×5} × 활성화 {ReLU, Swish} × 깊이 {2, 3, 4} → 샘플 #2(5×5, Swish, 3) 0.91, #3(3×3, Swish, 4) 0.90 → 컨트롤러가 'Swish·깊은' 구조를 더 자주 뽑도록 갱신
- **입문자 결론 (강의)**: 직접 NAS를 돌릴 일은 드묾 — 하지만 우리가 쓰는 좋은 모델이 NAS로 만들어졌다는 사실, 구조 탐색도 자동화되는 흐름은 알아 둘 것. 그 성과는 **전이학습**으로 무료로 씀 → [[전이학습(Transfer Learning)]]

## 수식·원리
```
RL-NAS:  구조 a ~ π_θ(a),  보상 R(a) = val_acc(train(a)),   ∇J = E[∇ log π_θ(a) · (R − b)]
DARTS:   o(x) = Σ_k softmax(α)_k · op_k(x)    → α를 경사하강, 끝나면 argmax_k α_k 선택
```

## 코드 예시
```python
import numpy as np

space = {"kernel": [3, 5], "act": ["relu", "swish"], "depth": [2, 3, 4]}
def reward(k, act, d):                                    # 가짜 검증 정확도 (Swish·깊게가 좋음)
    return 0.84 + 0.02 * (k == 5) + 0.03 * (act == "swish") + 0.01 * (d - 2)

rng = np.random.default_rng(0)
logits = {key: np.zeros(len(v)) for key, v in space.items()}   # 컨트롤러: 선택지별 선호도
baseline, lr = 0.0, 2.0
for step in range(300):                                    # REINFORCE로 컨트롤러 학습
    probs = {k: np.exp(l) / np.exp(l).sum() for k, l in logits.items()}
    idx = {k: rng.choice(len(space[k]), p=probs[k]) for k in space}
    R = reward(*(space[k][idx[k]] for k in ("kernel", "act", "depth")))
    baseline = 0.9 * baseline + 0.1 * R
    for k in space:
        g = -probs[k]; g[idx[k]] += 1                      # ∇ log π
        logits[k] += lr * (R - baseline) * g
best = {k: space[k][int(np.argmax(l))] for k, l in logits.items()}
print(best, round(reward(*best.values()), 2))             # {'kernel': 5, 'act': 'swish', 'depth': 4} 0.91
print(np.prod([len(v) for v in space.values()]))          # 12  전체 구조 수 (실제 NAS는 10^10 이상)
```
