# 데이터 클렌징 기법

## 정의·핵심
- **데이터 정제가 먼저 (보충 02)**: 성능을 올리는 첫 번째 지렛대는 **데이터** — "어려운 모델링보다 '**틀린 라벨 고치기**'가 더 큰 향상을 줄 때가 잦다". 특히 **검증셋 라벨**이 틀리면 모든 판단이 흔들림 → 검증셋부터 깨끗이
  - 흔한 문제: **라벨 오류**(평균 3~4% 존재), **중복 누수**(train/test에 같은 이미지 → 성능 과대평가), **이상치**(깨진 파일·다른 밝기·과도한 편집), **분포 이동**(도메인 갭)
  - 정제 방법: 오답 점검('크게 확신하며 틀린' 예측), 중복 탐지(해시·임베딩 유사도), cleanlab, 데이터 버전 관리
- **객체검출 라벨 클렌징 6기법 (보충 데이터_클렌징_기법, KITTI·YOLO)**

| # | 기법 | 아이디어 | 장점 | 단점 |
|---|---|---|---|---|
| 0 | **Confidence 기반 (Missing/Extra)** | 예측과 GT를 다른 conf로 비교 — **Missing은 낮은 conf(0.1)** 에도 GT 클래스가 안 잡힘(라벨 소실), **Extra는 높은 conf(0.5)** 에 GT에 없는 클래스(라벨 교체), 둘이 같은 위치면 **Class Swap** | 간단, 추가 학습 불필요 | conf 임계값에 민감, **self-detection 함정**(자기가 학습한 데이터는 오염을 외워서 못 잡음) |
| 1 | **K-fold Cross-Validation** | 데이터를 K등분, 각 fold는 **그 샘플을 학습에 안 쓴 모델**(out-of-fold)이 검사. 불균형이면 **Stratified** 필수 | 신뢰도 최고, 전체 커버 | 학습 K배 비용, 파이프라인 복잡 |
| 2 | **Box-IoU Mismatch** | 같은 클래스끼리 GT-예측 1:1 매칭, IoU 낮으면 위치 오염 — **완전 누락**(IoU 0) / **위치 어긋남** / **크기 어긋남**(너비 비율 > 0.5) | 위치 오류 특화, `box_iou`로 빠름 | 클래스 오류는 못 잡음, 밀집 씬 매칭 애매 |
| 3 | **Cleanlab** | `cleanlab.object_detection`이 불일치를 통계적으로 점수화(confident learning) — **Overlooked / Swapped / Badloc** 자동 분류 | 한 번 호출로 점수+이슈 분류 | 외부 의존, self-prediction이면 신뢰↓ (K-fold OOF 예측을 넣는 게 정석) |
| 4 | **CLIP 의미 정렬** | crop을 CLIP으로 임베딩 — **Zero-shot**("a photo of a {class}") 또는 **Reference-set**(클래스별 정상 샘플 centroid)과 유사도 비교 | 파인튜닝 없이, '의미' 기준 | 작은 객체 부정확, 도메인 특화 클래스(자세 구분)에 약함 |
| 5 | **Loss 기반** | 이미지별 loss 기록 — **Box loss**(좌표 오염), **Cls loss**(클래스 오염), **DFL loss**(가려짐·블러 경계) 상위 샘플 | 학습 중 어려움 직접 반영, hard example도 발견 | 재학습 비용, batch=1이라 느림, 오염 vs hard example은 사람이 확인 |

- **실무 조합**: 0번으로 빠른 1차 스크리닝 → 2번으로 좌표 품질 → 최종 단계에서 1번(K-fold) 한 번 / 결과는 **낮은 점수 순으로 사람이 검토할 우선순위 리스트**로 → [[라벨 오류 찾기]]
- 수동 검토 비용·auto_detect 실습(클래스 교체·박스 누락·좌표 오류 주입)은 → [[라벨 오류 점검]]

## 수식·원리
```
Missing:  GT 클래스 c ∈ gt  and  c ∉ pred(conf ≥ 0.1)
Extra:    c ∈ pred(conf ≥ 0.5)  and  c ∉ gt
IoU mismatch:  best_IoU(gt_box, pred_boxes_c) < 0.5
  size_ratio = |w_gt − w_pred| / w_gt > 0.5 → 크기 어긋남,  아니면 위치 어긋남
```

## 코드 예시
```python
import torch
from torchvision.ops import box_iou

def find_missing_extra(gt, pred, low=0.1, high=0.5):       # 0번: Confidence 기반
    gt_cls = {c for c, *_ in gt}
    pred_low = {c for c, s, *_ in pred if s >= low}
    missing = sorted(c for c in gt_cls if c not in pred_low)
    extra = sorted({c for c, s, *_ in pred if s >= high and c not in gt_cls})
    return missing, extra

gt = [(0, 10, 10, 50, 50), (2, 60, 60, 90, 90)]             # (cls, x1, y1, x2, y2)
pred = [(0, 0.9, 12, 11, 51, 49), (1, 0.8, 61, 59, 90, 91)] # (cls, conf, box) — cls 2 자리에 cls 1이 강하게
missing, extra = find_missing_extra(gt, pred)
print(missing, extra)                                        # [2] [1]  같은 위치 → Class Swap 의심

def iou_mismatch(gt_box, pred_boxes, thr=0.5):               # 2번: Box-IoU Mismatch
    if len(pred_boxes) == 0: return "완전_누락", 0.0
    ious = box_iou(gt_box[None], pred_boxes)[0]
    best, idx = ious.max(0)
    if best >= thr: return "정상", round(best.item(), 2)
    p = pred_boxes[idx]
    size_ratio = abs((gt_box[2] - gt_box[0]) - (p[2] - p[0])) / (gt_box[2] - gt_box[0])
    return ("크기_어긋남" if size_ratio > 0.5 else "위치_어긋남"), round(best.item(), 2)

g = torch.tensor([10., 10., 50., 50.])
print(iou_mismatch(g, torch.tensor([[12., 11., 51., 49.]])))   # ('정상', 0.88)
print(iou_mismatch(g, torch.tensor([[35., 10., 75., 50.]])))   # ('위치_어긋남', 0.23)
print(iou_mismatch(g, torch.tensor([[10., 10., 110., 50.]])))  # ('크기_어긋남', 0.4)
print(iou_mismatch(g, torch.zeros((0, 4))))                     # ('완전_누락', 0.0)
```
