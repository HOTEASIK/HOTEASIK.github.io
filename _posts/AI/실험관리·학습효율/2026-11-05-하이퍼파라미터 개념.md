# 하이퍼파라미터 개념

## 정의·핵심
- **파라미터 vs 하이퍼파라미터 (보충 02 "가장 중요한 구분")**

| 구분 | 파라미터 (Parameter) | 하이퍼파라미터 (Hyperparameter) |
|---|---|---|
| 정의 | 모델이 학습으로 **'스스로'** 알아내는 값 | 사람이 학습 **'전에'** 정해 주는 설정값 |
| 예 | 가중치 W, 편향 b (fc1.weight 등) | 학습률, 배치 크기, 에폭 수, 층 수, 드롭아웃 비율 |
| 개수 | MNIST MLP만 해도 약 11만 개 | 보통 수 개~수십 개 |
| 결정 방법 | 경사하강법으로 자동 갱신 | 경험·실험·탐색으로 사람(또는 도구)이 선택 |

  - 비유: 파라미터 = '학생이 공부하며 얻는 지식', 하이퍼파라미터 = '**공부 시간·방법·교재 선택**' 같은 학습 환경 설정
  - 핵심: 하이퍼파라미터는 **학습되지 않는다** → 우리가 직접 좋은 값을 찾아야 함
- **주요 하이퍼파라미터와 중요도 (강의 표)**
  - **학습률 (lr)** ★★★ 최우선 — 1e-4 ~ 1e-1 (**로그 스케일**) → [[학습률]]
  - **배치 크기** ★★ — 16·32·64·128·256 → [[미니배치·배치 크기]]
  - **옵티마이저** ★★ — SGD·Adam·AdamW
  - **에폭·조기종료** ★★ — 조기종료로 자동 → [[Early Stopping]]
  - **정규화** ★★ — weight_decay·dropout → [[Dropout]]
  - **구조** ★ — 층 수·폭·활성화 (탐색 비용 큼, 나중에)
  - 탐색은 '**중요한 것부터**': 학습률 → 배치·옵티마이저·정규화 → 구조
- **목적 함수와 예산 (강의)**
  - **목적 함수**: 보통 **검증** 정확도·F1 최대화(또는 검증 손실 최소화). 불균형이면 정확도 대신 F1·AUC. 둘 이상이면 다목적 최적화
  - **예산**: 총 시도 수 × 시도당 비용 — 빠른 대리 탐색(적은 에폭·데이터 일부) 후 최종만 길게, 가망 없는 시도는 조기 종료
  - 핵심 트레이드오프: **탐색 정밀도 ↔ 예산**
- **탐색 방법 지도 (강의)**: 기본(수동·[[Grid Search]]·[[Random Search]]) → 모델 기반([[Bayesian Optimization]]·TPE) → 예산 스케줄링(Successive Halving·[[Hyperband·BOHB]]) → 딥러닝 기반([[PBT]]·[[NAS(언급)]]) — 아래로 갈수록 똑똑하지만 복잡
- **검증 전략 (강의)**: 학습셋 = 가중치 학습 / **검증셋 = 하이퍼파라미터 탐색·선택** / 테스트셋 = 최종 성능 **한 번만**. 테스트셋으로 튜닝하면 그 성능은 '거짓'
- **실전 워크플로우 (강의)**: ① 수동으로 범위 잡기 → ② 넓게 Random 20~30회 → ③ 구간 좁혀 재탐색 → ④ Bayesian 정밀화 → ⑤ (선택) Hyperband → ⑥ 최종 검증·재현(시드·설정 기록) — "**넓게 → 좁게**"
- **흔한 실수 (강의)**: lr을 선형 탐색 / 공간 과대 / 테스트셋 튜닝 / 한 시드 맹신 / 기록 안 함 / Grid 남용 → [[재현성]], [[WandB 실험 기록·Sweeps]]

## 수식·원리
```
θ* = argmin_θ L_train(θ; λ)              (파라미터: 경사하강법)
λ* = argmax_λ Score_val( θ*(λ) )          (하이퍼파라미터: 탐색)
로그 스케일 후보:  lr ∈ {10^-4, 10^-3, 10^-2, 10^-1}
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn

model = nn.Sequential(nn.Flatten(), nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10))   # MNIST MLP
n_params = sum(p.numel() for p in model.parameters())
hparams = {"lr": 1e-3, "batch_size": 64, "hidden": 128, "epochs": 3, "optimizer": "adam"}
print(n_params, len(hparams))                        # 101770 5  파라미터 약 10만 개 vs 하이퍼파라미터 5개

lrs = [10 ** e for e in range(-4, 0)]                # 2_1 실습 연습 문제 1: 로그 스케일
print(lrs, np.logspace(-4, -1, 4).tolist() == lrs)   # [0.0001, 0.001, 0.01, 0.1] True

torch.manual_seed(0)                                 # 학습률 감각: 같은 문제, lr만 다르게
X = torch.randn(256, 10); y = X @ torch.randn(10, 1)
def run(lr, steps=100):
    m = nn.Linear(10, 1); opt = torch.optim.SGD(m.parameters(), lr=lr)
    for _ in range(steps):
        loss = ((m(X) - y) ** 2).mean(); opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()
res = {lr: run(lr) for lr in [1e-4, 1e-2, 1e-1, 1.5]}
print(res[1e-1] < res[1e-2] < res[1e-4], res[1.5] != res[1.5])   # True True  작으면 느리고, 너무 크면 발산(nan)
```
