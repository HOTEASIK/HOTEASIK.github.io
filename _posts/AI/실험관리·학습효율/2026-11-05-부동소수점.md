# 부동소수점

## 정의·핵심
- **부동소수점**: 실수를 **부호 + 지수(exponent) + 가수(mantissa)** 로 저장하는 방식 — 지수는 **범위**(얼마나 크고 작은 수까지), 가수는 **정밀도**(유효 숫자 몇 자리)를 결정
- **FP32 vs FP16 vs BF16 (보충 02 성능 최적화)**

| 형식 | 비트 | 지수 / 가수 | 특징 |
|---|---|---|---|
| **FP32** (단정밀도) | 32 | 8 / 23 | 기본값. 넓은 범위 + 높은 정밀도 — 가장 안전하지만 느리고 메모리 2배 |
| **FP16** (반정밀도) | 16 | 5 / 10 | 범위 좁음 → **언더/오버플로 주의**. 빠르고 메모리 절반 (T4 Tensor Core) |
| **BF16** (brain float) | 16 | 8 / 7 | **FP32와 같은 범위**, 정밀도만 낮음. Ampere(A100)+ 지원, **스케일 불필요** |

  - 핵심 직관: '**지수(범위)** 와 **가수(정밀도)** 의 배분 차이'
  - FP16은 범위가 좁아 **스케일링(GradScaler)** 이 필요, BF16은 범위가 넓어 다루기 쉽지만 최신 GPU 필요 → "Colab T4는 FP16이 정답"
- **수치 한계**
  - FP16 최댓값 **65504**, 정규 최솟값 약 6.1e-5, 서브노멀 최솟값 약 **6e-8** → 1e-8 같은 작은 그래디언트는 **0으로 사라짐(underflow)**
  - BF16 최댓값 약 3.4e38 (FP32와 같음), 대신 유효 숫자 약 **2~3자리**
  - **machine epsilon**: FP32 약 1.2e-7, FP16 약 9.8e-4, BF16 약 7.8e-3 → 1 + 작은 수가 1로 뭉개짐
- **왜 16비트가 빠른가 (강의)**: GPU의 **Tensor Core**가 FP16 행렬곱 전용 → 처리량↑, 활성화 메모리 절반 → 더 큰 배치
- **혼합정밀도**: 계산은 16비트로 빠르게, 민감한 부분(누적·손실·가중치 마스터 사본)은 32비트로 안전하게 → [[AMP(혼합 정밀도)]]
- 메모리 계산(파라미터 × 바이트)과 int8/int4 양자화는 → [[비트와 양자화]]

## 수식·원리
```
값 = (−1)^s × 1.m × 2^(e − bias)
FP16: bias 15, 최대 (2 − 2^−10) × 2^15 = 65504
FP32/BF16: 지수 8비트 → 최대 ≈ 3.4 × 10^38
epsilon = 2^−(가수 비트):  FP32 2^−23,  FP16 2^−10,  BF16 2^−7
```

## 코드 예시
```python
import torch

for dt in (torch.float32, torch.float16, torch.bfloat16):
    fi = torch.finfo(dt)
    print(str(dt).split(".")[1], fi.bits, f"{fi.max:.3g}", f"{fi.eps:.2g}", f"{fi.tiny:.2g}")
# float32 32 3.4e+38 1.2e-07 1.2e-38 / float16 16 6.55e+04 0.00098 6.1e-05 / bfloat16 16 3.39e+38 0.0078 1.2e-38

g = torch.tensor([1e-3, 1e-6, 1e-8])                     # 작은 그래디언트
print(g.half().tolist()[2], g.bfloat16().float().tolist()[2] > 0)   # 0.0 True  FP16은 1e-8이 사라짐, BF16은 살아남음

big = torch.tensor([70000.0])
print(big.half().item(), big.bfloat16().item())          # inf 70144.0  FP16 오버플로, BF16은 범위 OK(정밀도↓)

print((torch.tensor(1.0, dtype=torch.float16) + 1e-4).item(), round((torch.tensor(1.0) + 1e-4).item(), 4))   # 1.0 1.0001  FP16은 작은 증분이 뭉개짐

scale = 1024.0                                           # GradScaler 아이디어: 키워서 FP16 범위 안으로
print((g * scale).half()[2].item() > 0, ((g * scale).half().float() / scale)[2].item() > 0)   # True True
```
