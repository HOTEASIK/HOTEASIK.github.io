# 아핀 변환

## 정의·핵심
- **정의**: Affine Transform. 2D 평면의 점을 **선형 변환(확대·축소, 회전, 전단) + 평행 이동**으로 매핑하는 변환 (응용 2차시)
- **성질 (강의)**
  - **직선 보존**: 직선은 변환 후에도 직선
  - **평행성 유지**: 평행선은 변환 후에도 평행 → **직사각형 → 평행사변형**
  - 길이 비율(한 직선 위), 무게중심 보존. 각도·길이는 바뀔 수 있음
  - 이동·회전·확대축소·기울임(Shear)을 모두 포함 — 앞서 배운 회전·이동·크기 변환이 모두 아핀의 특수한 경우
- **2×3 행렬**, 자유도 **6** → **점 3쌍**(변환 전 3점 ↔ 변환 후 3점)으로 결정
- **OpenCV (강의 코드)**
  ```
  pts1 = np.float32([[50,50], [200,50], [50,200]])
  pts2 = np.float32([[10,100], [200,50], [100,250]])
  M = cv2.getAffineTransform(pts1, pts2)      # 2×3
  dst = cv2.warpAffine(img, M, (w, h))
  ```
  - 점은 **float32**, 정확히 **3개**
  - 3개보다 많은 대응점(잡음 있음)이면 `cv2.estimateAffine2D(src, dst)` (RANSAC)
  - 역변환: `cv2.invertAffineTransform(M)`
- **목적 (강의)**: **정렬 및 기울기 보정** — 이미지 정렬, 단순 문서 스캔 보정, 객체 자세 보정, 얼굴 정렬(눈·코 3점), 데이터 증강(`RandomAffine`)
- 원근감(사다리꼴)까지 보정하려면 4점 투시 변환 → [[투시 변환]]

## 수식·원리
```
[x']   [a11 a12 tx] [x]
[y'] = [a21 a22 ty] [y]
                    [1]
6개 미지수 ← 3점 × (x, y) 2식 = 6개 방정식
전단(Shear): [[1, k, 0], [0, 1, 0]]
```

## 코드 예시
```python
import numpy as np
import cv2

pts1 = np.float32([[50, 50], [200, 50], [50, 200]])
pts2 = np.float32([[10, 100], [200, 50], [100, 250]])
M = cv2.getAffineTransform(pts1, pts2)
print(M.shape, np.allclose(cv2.transform(pts1[None], M)[0], pts2))   # (2, 3) True  3점이 정확히 대응

rect = np.float32([[[50, 50]], [[200, 50]], [[200, 200]], [[50, 200]]])   # 직사각형
q = cv2.transform(rect, M).reshape(-1, 2)
v_top, v_bottom = q[1] - q[0], q[2] - q[3]
print(np.allclose(v_top, v_bottom))                                 # True  평행 유지 → 평행사변형
Minv = cv2.invertAffineTransform(M)
print(np.allclose(cv2.transform(pts2[None], Minv)[0], pts1, atol=1e-3))   # True  역변환
shear = np.float32([[1, 0.5, 0], [0, 1, 0]])
print(cv2.transform(np.float32([[[0, 10]]]), shear).ravel().tolist())     # [5.0, 10.0]  아래로 갈수록 오른쪽으로 밀림
```
