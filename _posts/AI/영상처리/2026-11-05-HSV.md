# HSV

## 정의·핵심
- **정의**: **H**ue(색상)·**S**aturation(채도)·**V**alue(명도)로 색을 표현하는 색공간. 인간이 색을 인지하는 방식(색상·채도·명도)과 유사 (응용 1차시)
- **세 성분**
  - **H (색상)**: 색의 종류 — 색상환의 각도. 빨강 0°, 노랑 60°, 초록 120°, 시안 180°, 파랑 240°, 마젠타 300°
  - **S (채도)**: 색의 **진하기·순수함**. 0이면 무채색(회색), 최대면 원색
  - **V (명도)**: **밝기**. 0이면 검정
- **OpenCV의 범위 (8bit)**: **H 0~179** (360°를 2로 나눔, uint8에 넣으려고), **S 0~255**, **V 0~255**
  - 빨강 ≈ 0 또는 179 근처, 초록 ≈ 60, 파랑 ≈ 120
  - 다른 도구(그림판 0~360, 0~100%)의 값을 그대로 쓰면 안 된다
- **왜 비전에서 쓰나 (강의)**
  - **색상 정보(H)가 밝기(V)와 분리** → 조명이 바뀌어도 V만 변하고 H는 유지 → **조명 변화에 강함**
  - 활용: **객체 추적, 피부색 검출, 특정 색상 영역 분리**, CamShift의 Hue 히스토그램 → [[색상 검출]], [[CamShift 추적]]
  - "파란색 공을 찾으려면 RGB보다 HSV가 훨씬 쉽다"
- **주의점**
  - **빨강은 H 축의 양 끝**(0 근처, 179 근처)에 걸쳐 있다 → inRange를 **두 번** 하고 OR로 합친다
  - 채도·명도가 낮은 픽셀(회색·검정)은 H가 불안정 → S·V 하한을 함께 걸어 거른다
  - `COLOR_BGR2HSV_FULL`은 H를 0~255로 사용

## 수식·원리
```
V = max(R, G, B)
S = (V − min(R,G,B)) / V          (V = 0이면 0)
H = 60°·(G − B)/(V − min)          (V = R)
    60°·(2 + (B − R)/(V − min))    (V = G)
    60°·(4 + (R − G)/(V − min))    (V = B)
OpenCV:  H/2 → 0~179,  S·255,  V(그대로)
```

## 코드 예시
```python
import numpy as np
import cv2

colors = {"red": (0, 0, 255), "green": (0, 255, 0), "blue": (255, 0, 0), "yellow": (0, 255, 255), "gray": (128, 128, 128)}
for name, bgr in colors.items():
    h, s, v = cv2.cvtColor(np.uint8([[bgr]]), cv2.COLOR_BGR2HSV)[0, 0]
    print(f"{name:6s} H={h:3d} S={s:3d} V={v:3d}")
# red    H=  0 S=255 V=255
# green  H= 60 S=255 V=255
# blue   H=120 S=255 V=255
# yellow H= 30 S=255 V=255
# gray   H=  0 S=  0 V=128   ← 무채색은 S=0
pink_red = cv2.cvtColor(np.uint8([[(30, 0, 255)]]), cv2.COLOR_BGR2HSV)[0, 0, 0]
print(pink_red)                        # 176  빨강 계열인데 H가 179 쪽 끝 → 범위 두 개 필요
```
