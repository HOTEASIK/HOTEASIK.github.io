# RAFT

## 정의·핵심
- **정의**: RAFT (Recurrent All-Pairs Field Transforms, 2020 ECCV 최우수 논문). **딥러닝 기반 Dense Optical Flow** 모델 — 모든 픽셀 쌍의 유사도를 계산하고, **GRU로 flow를 반복 정제**해 고정밀 광류를 추정 (응용 4차시)
- **3단계 구조 (강의)**
  1. **Feature Encoder (CNN)**: 두 프레임에서 각각 **1/8 해상도 특징 맵** 추출 (+ 첫 프레임에서 context 특징)
  2. **4D Correlation Volume (All-Pairs)**: 프레임1의 **모든 픽셀**과 프레임2의 **모든 픽셀** 특징의 내적 → `(H, W, H, W)` 상관 볼륨, 여러 해상도로 풀링(피라미드)해 큰 움직임까지 커버
  3. **Iterative Update (GRU)**: 현재 flow 추정 위치 주변의 상관 값을 조회(lookup) → **ConvGRU가 flow 증분 Δf를 예측** → `f ← f + Δf`를 **수십 번 반복** (학습 12회, 추론 시 늘릴 수 있음)
  - 마지막에 학습된 업샘플링(convex upsampling)으로 원래 해상도 복원
- **고전 방법과 비교**

| | Lucas-Kanade / Farneback | RAFT |
|---|---|---|
| 방식 | 밝기 가정 + 수식 | 학습된 특징 + 전역 상관 |
| 큰 움직임 | 약함 (피라미드) | **강함** (all-pairs) |
| 가림(occlusion)·텍스처 부족 | 약함 | **강함 (강의)** |
| 비용 | CPU 실시간 | **GPU 필요 (강의)** |

- **torchvision 사용**
  - `from torchvision.models.optical_flow import raft_large, raft_small, Raft_Large_Weights`
  - `model = raft_large(weights=Raft_Large_Weights.DEFAULT).eval()` → 전처리 `weights.transforms()` (값을 [−1, 1]로)
  - 입력: `(B, 3, H, W)` 두 장, **H·W는 8의 배수이고 128 이상**(1/8 특징 맵이 상관 피라미드용으로 16 이상이어야 함) / 출력: **반복마다의 flow 리스트** → `flows[-1]`이 최종 `(B, 2, H, W)`
  - 시각화: `torchvision.utils.flow_to_image(flow)` (Dense와 같은 색상환 방식)
- 학습 데이터: FlyingChairs → FlyingThings3D → Sintel·KITTI (합성 데이터로 사전학습 후 미세조정), 평가 지표 **EPE**(End-Point Error, 예측·정답 벡터의 평균 거리)
- **활용**: 영상 보간·슬로모션, 비디오 편집(객체 제거), 행동 인식, 자율주행, 동영상 초해상도

## 수식·원리
```
C(i, j, k, l) = ⟨ g(I1)_ij , g(I2)_kl ⟩          (4D all-pairs 상관)
f_0 = 0,   f_{k+1} = f_k + ConvGRU(h_k, lookup(C, f_k), context)
EPE = mean ||f_pred − f_gt||₂
```

## 코드 예시
```python
import torch
from torchvision.models.optical_flow import raft_small
from torchvision.utils import flow_to_image

model = raft_small(weights=None).eval()            # 구조만 (실사용: weights=Raft_Small_Weights.DEFAULT)
print(round(sum(p.numel() for p in model.parameters()) / 1e6, 2), "M params")   # 0.99 M params
img1 = torch.rand(1, 3, 128, 128) * 2 - 1          # [-1, 1] 정규화, H·W는 8의 배수이고 128 이상
img2 = torch.roll(img1, shifts=4, dims=3)
with torch.no_grad():
    flows = model(img1, img2, num_flow_updates=6)  # GRU 반복 횟수
print(len(flows), tuple(flows[-1].shape))          # 6 (1, 2, 128, 128)  반복마다 정제된 flow
print(tuple(flow_to_image(flows[-1]).shape), flow_to_image(flows[-1]).dtype)   # (1, 3, 128, 128) torch.uint8

gt = torch.zeros_like(flows[-1]); gt[:, 0] = 4.0   # 정답 flow (오른쪽 4)
epe = (flows[-1] - gt).norm(dim=1).mean()
print(epe.item() > 0)                              # True  무작위 가중치라 오차 큼 → 사전학습 가중치 필요
```
