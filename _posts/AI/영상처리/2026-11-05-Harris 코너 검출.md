# Harris 코너 검출

## 정의·핵심
- **코너(모서리)란**: **두 방향 이상으로 밝기가 크게 변하는** 지점. 특징점(Keypoint)의 대표 — 추적·정합·인식의 기준점 (응용 3·4차시)
- **직관**: 작은 창을 여러 방향으로 조금 움직여 본다
  - **평탄한 영역**: 어느 방향으로 움직여도 변화 없음
  - **엣지**: 엣지를 **따라** 움직이면 변화 없음, 가로질러야 변화
  - **코너**: **모든 방향**으로 움직일 때 변화가 큼
- **Harris 방법 (1988)**
  - 창 안의 기울기로 **구조 텐서 M** = `Σ [[Ix², IxIy], [IxIy, Iy²]]` 계산
  - M의 고유값 λ₁, λ₂: 둘 다 작으면 평탄, 하나만 크면 엣지, **둘 다 크면 코너**
  - 고유값을 직접 구하지 않고 **응답 함수** `R = det(M) − k·(trace M)²` 사용 (k ≈ 0.04~0.06)
  - R > 0 크면 코너, R < 0이면 엣지, |R| 작으면 평탄
- **OpenCV: `cv2.cornerHarris(gray_float32, blockSize, ksize, k)`**
  - 입력은 **float32 흑백**, 결과는 픽셀별 R 값 맵
  - `blockSize`: 이웃 창 크기(2), `ksize`: Sobel 크기(3), `k`: 0.04
  - 코너 선택: `R > 0.01 * R.max()` 같은 임계값 + (선택) 팽창으로 극대점만
  - `cv2.cornerSubPix`로 서브픽셀 정밀화
- **성질**: **회전에 불변**(고유값은 회전해도 같음), 밝기 변화에 어느 정도 강함, **크기(scale) 변화에는 불변이 아님** → SIFT 등 스케일 공간 방법으로 확장
- 개선판: **Shi-Tomasi**(min(λ₁, λ₂) 사용, 추적용으로 더 안정) → [[Shi-Tomasi]]

## 수식·원리
```
M = Σ_{window} w(x,y) · [[Ix², Ix·Iy], [Ix·Iy, Iy²]]
R = det(M) − k · (trace M)² = λ₁λ₂ − k(λ₁ + λ₂)²
평탄: λ₁, λ₂ ≈ 0  /  엣지: λ₁ ≫ λ₂  /  코너: λ₁, λ₂ 둘 다 큼
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((60, 60), np.uint8)
cv2.rectangle(img, (15, 15), (45, 45), 255, -1)                 # 꼭짓점 4개
R = cv2.cornerHarris(np.float32(img), blockSize=2, ksize=3, k=0.04)
corners = np.argwhere(R > 0.1 * R.max())                        # (y, x)
centers = sorted({(int(round(y / 5) * 5), int(round(x / 5) * 5)) for y, x in corners})
print(centers)                                                  # [(15, 15), (15, 45), (45, 15), (45, 45)]  네 꼭짓점
print(R[30, 30] == 0, R[15, 30] < 0)                            # True True  내부는 평탄(0), 변(엣지)은 음수
print(R.dtype)                                                  # float32
```
