# 적응형 이진화

## 정의·핵심
- **정의**: 영상 전체에 하나의 임계값을 쓰지 않고, **픽셀마다 주변 영역(블록)의 통계로 임계값을 따로 계산**하는 이진화
- **왜 필요한가**: 조명이 **고르지 않은** 영상(한쪽에 그림자, 비스듬한 빛)에서는 전역 임계값(수동·Otsu)이 어두운 쪽 전체를 검게, 밝은 쪽 전체를 희게 만들어 버린다 → 지역별 기준이 필요
- **OpenCV: `cv2.adaptiveThreshold(src, maxValue, adaptiveMethod, thresholdType, blockSize, C)`**
  - `adaptiveMethod`
    - `ADAPTIVE_THRESH_MEAN_C`: 블록의 **평균** − C
    - `ADAPTIVE_THRESH_GAUSSIAN_C`: 블록의 **가우시안 가중 평균** − C (중심에 가까울수록 큰 가중치, 더 자연스러움)
  - `thresholdType`: `THRESH_BINARY` 또는 `THRESH_BINARY_INV`만
  - `blockSize`: 주변 영역 크기 — **홀수**(3, 5, 11…). 글자 획보다 충분히 커야 함
  - `C`: 평균에서 빼는 상수. 클수록 흰색이 늘어남(잡음 감소), 보통 2~10
  - 반환값이 **하나**(dst) — `threshold`와 달리 ret 없음
- **활용**: **문서 스캔·OCR**(그림자 진 종이 위 글씨), 칠판·화이트보드 사진, 번호판
- **단점**: 넓은 균일 영역(배경)에서 잡음이 생길 수 있음 → C를 키우거나 블러·모폴로지로 정리

## 수식·원리
```
T(x, y) = mean_{blockSize×blockSize}(x, y) − C       (MEAN_C)
T(x, y) = Gaussian-weighted mean(x, y) − C           (GAUSSIAN_C)
dst(x, y) = maxValue  if src(x, y) > T(x, y)  else 0
```

## 코드 예시
```python
import numpy as np
import cv2

h, w = 60, 120
light = np.tile(np.linspace(40, 230, w), (h, 1))               # 왼쪽 어둡고 오른쪽 밝은 조명
img = light.copy()
for x0 in (10, 50, 90):
    img[20:40, x0:x0 + 15] -= 35                               # 배경보다 35 어두운 글씨 3개
img = img.clip(0, 255).astype(np.uint8)

ret, glob = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
ada = cv2.adaptiveThreshold(img, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY_INV, 31, 10)
text = np.zeros_like(img); [cv2.rectangle(text, (x0, 20), (x0 + 14, 39), 255, -1) for x0 in (10, 50, 90)]
iou = lambda m: ((m > 0) & (text > 0)).sum() / ((m > 0) | (text > 0)).sum()
print(round(iou(glob), 2), round(iou(ada), 2))                 # 0.15 0.8  전역(Otsu)보다 적응형이 글씨를 훨씬 잘 찾음
```
