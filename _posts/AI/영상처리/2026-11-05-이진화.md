# 이진화

## 정의·핵심
- **정의**: 임계값(Threshold) 처리. 픽셀 값을 **기준값(T)과 비교해 두 값(0과 255)으로만** 나누는 것. 전경(물체)과 배경을 분리하는 가장 기본적인 분할 (응용 1·3차시 "이진화와 특징 검출")
- **OpenCV: `ret, dst = cv2.threshold(src, thresh, maxval, type)`**
  - 반환값이 **2개**: 사용된 임계값 `ret`, 결과 영상 `dst`
  - 입력은 보통 **흑백** (컬러면 채널별로 처리됨)
- **type 종류**
  - `THRESH_BINARY`: `src > T`이면 maxval, 아니면 0
  - `THRESH_BINARY_INV`: 반대 (어두운 물체를 흰색으로 — 흰 종이 위 검은 글씨)
  - `THRESH_TRUNC`: T보다 크면 T로 자름, 나머지 유지
  - `THRESH_TOZERO`: T 이하만 0으로 / `THRESH_TOZERO_INV`: T 초과만 0으로
  - `+ THRESH_OTSU`·`THRESH_TRIANGLE`: 임계값 자동 결정 → [[Otsu 이진화]]
- **주의**: 조건은 **`>` (초과)**. T와 같은 값은 0
- **T 고르기**: 히스토그램을 보고 두 봉우리 사이 골짜기 → 수동은 조명이 바뀌면 깨짐 → Otsu(전역 자동) 또는 적응형(지역별) → [[적응형 이진화]]
- **활용**: 문서 스캔·OCR 전처리, 윤곽선 검출 전 마스크 만들기, 모션 차분 결과 정리, 마스크 생성(강의 마스크 생성 도구: inRange·threshold)
- 이진 영상은 모폴로지로 다듬고 findContours로 물체를 찾는 것이 일반적 흐름 → [[모폴로지]], [[윤곽선]]

## 수식·원리
```
BINARY:     dst = maxval  if src > T  else 0
BINARY_INV: dst = 0       if src > T  else maxval
TRUNC:      dst = T       if src > T  else src
TOZERO:     dst = src     if src > T  else 0
```

## 코드 예시
```python
import numpy as np
import cv2

src = np.array([[0, 50, 100, 127, 128, 200, 255]], np.uint8)
for name in ("THRESH_BINARY", "THRESH_BINARY_INV", "THRESH_TRUNC", "THRESH_TOZERO"):
    ret, dst = cv2.threshold(src, 127, 255, getattr(cv2, name))
    print(f"{name:18s}", ret, dst.tolist())
# THRESH_BINARY      127.0 [[0, 0, 0, 0, 255, 255, 255]]   ← 127 자신은 0 (초과 조건)
# THRESH_BINARY_INV  127.0 [[255, 255, 255, 255, 0, 0, 0]]
# THRESH_TRUNC       127.0 [[0, 50, 100, 127, 127, 127, 127]]
# THRESH_TOZERO      127.0 [[0, 0, 0, 0, 128, 200, 255]]
```
