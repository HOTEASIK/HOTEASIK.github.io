# 덧셈·뺄셈

## 정의·핵심
- **픽셀 연산이란**: 0~255 범위의 픽셀 값에 수학적 연산을 해서 영상의 **밝기·대조·색상**을 조절하거나 효과를 적용하는 것. 산술·스칼라 연산, 논리 연산, 마스크 연산이 있다 (응용 1차시)
- **덧셈 `cv2.add(src1, src2)`** — Brightness Increase
  - 목적: 영상의 **밝기 증가**, 두 영상을 **겹쳐 합성**
  - **포화 연산(Saturation)**: 합이 255를 넘으면 **255(흰색)로 고정**
- **뺄셈 `cv2.subtract(src1, src2)`** — Difference Extraction
  - 목적: 영상의 **밝기 감소**, 두 영상 간 **차이** 구하기
  - **0으로 고정(Clamping)**: 결과가 음수면 **0(검은색)** 으로 고정해 데이터 형식 유지
- **NumPy 연산과의 차이 (강의)**: NumPy `uint8` 덧셈은 **256이 되면 0으로 순환**(modulo) → 밝게 하려다 오히려 검게 되는 버그. 뺄셈도 −1 → 255
  - 해결: OpenCV 함수를 쓰거나, `int`/`float`로 바꿔 계산 → `np.clip(…, 0, 255)` → `uint8`
- **스칼라 더하기 주의**: 숫자 하나(`cv2.add(img, 50)`)는 최근 버전에서 모든 채널에 더해지지만, **튜플 `(50,)`은 `(50, 0, 0, 0)`으로 해석돼 첫 채널(B)에만** 더해진다 (오래된 버전은 숫자도 B에만). 컬러 영상은 `cv2.add(img, (50, 50, 50, 0))` 또는 같은 크기의 배열을 쓰는 것이 안전
- 두 영상은 **크기·채널 수·dtype이 같아야** 한다 (또는 `mask` 인자로 영역 지정)
- 차이의 크기를 양수로 보존하려면 `absdiff` → [[절대값 차이]], 비율 합성은 `addWeighted` → [[가중합]]

## 수식·원리
```
cv2.add:      dst = min(src1 + src2, 255)
cv2.subtract: dst = max(src1 − src2, 0)
NumPy uint8:  dst = (src1 + src2) mod 256
```

## 코드 예시
```python
import numpy as np
import cv2

a = np.array([[100, 200, 250]], np.uint8)
b = np.array([[100, 100, 100]], np.uint8)
print(cv2.add(a, b).tolist(), (a + b).tolist())             # [[200, 255, 255]] [[200, 44, 94]]  포화 vs 순환
print(cv2.subtract(b, a).tolist(), (b - a).tolist())        # [[0, 0, 0]] [[0, 156, 106]]
print(np.clip(a.astype(int) + b, 0, 255).astype(np.uint8).tolist())   # [[200, 255, 255]]  NumPy로 안전하게

img = np.full((1, 1, 3), 100, np.uint8)
print(cv2.add(img, 50)[0, 0].tolist())                      # [150, 150, 150]  (OpenCV 4.13)
print(cv2.add(img, (50,))[0, 0].tolist())                   # [150, 100, 100]  튜플은 B 채널에만!
print(cv2.add(img, (50, 50, 50, 0))[0, 0].tolist())         # [150, 150, 150]
```
