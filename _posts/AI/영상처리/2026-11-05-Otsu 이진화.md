# Otsu 이진화

## 정의·핵심
- **정의**: 히스토그램을 분석해 **최적의 전역 임계값을 자동으로 찾는** 이진화 방법 (Nobuyuki Otsu, 1979)
- **아이디어**: 모든 후보 T(0~255)에 대해 픽셀을 두 그룹(배경·전경)으로 나눴을 때
  - **클래스 내 분산(within-class variance)이 최소**가 되는 T = **클래스 간 분산(between-class variance)이 최대**가 되는 T
  - 즉 두 그룹이 **각자 뭉쳐 있고 서로는 멀리 떨어지게** 나누는 값
- **잘 되는 경우**: 히스토그램이 **두 봉우리(쌍봉)** — 물체와 배경의 밝기가 뚜렷이 다를 때
- **안 되는 경우**: 봉우리가 하나뿐이거나, 물체가 매우 작아 봉우리가 안 보일 때, **조명이 고르지 않을 때**(그림자) → 적응형 이진화 → [[적응형 이진화]]
- **OpenCV**: `ret, dst = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)`
  - thresh 인자(0)는 **무시**되고, 찾은 임계값이 **ret**으로 반환
  - 8bit 단일 채널만
  - 잡음이 많으면 먼저 **가우시안 블러** → 봉우리가 매끄러워져 결과가 좋아진다
- 비슷한 자동 방법: `THRESH_TRIANGLE`(봉우리가 하나일 때 유리)

## 수식·원리
```
ω₀(T) = P(I ≤ T),  ω₁(T) = 1 − ω₀(T)
μ₀, μ₁: 각 그룹 평균
σ_B²(T) = ω₀ · ω₁ · (μ₀ − μ₁)²
T* = argmax_T  σ_B²(T)
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
img = np.clip(rng.normal(60, 12, (100, 100)), 0, 255)            # 배경 ~60
img[30:70, 30:70] = np.clip(rng.normal(180, 12, (40, 40)), 0, 255)   # 물체 ~180
img = img.astype(np.uint8)
ret, binary = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print(ret, cv2.countNonZero(binary))                              # 101.0 1600  (60과 180 사이, 물체 40×40)

p = np.bincount(img.ravel(), minlength=256) / img.size          # 직접 구현
k = np.arange(256)
w0, m = p.cumsum(), (p * k).cumsum()                              # 누적 비율, 누적 평균
sigma_b = (m[-1] * w0 - m) ** 2 / (w0 * (1 - w0) + 1e-12)          # 클래스 간 분산
best = sigma_b.argmax()
print(np.array_equal((img > best) * 255, binary))                 # True  같은 분할 결과
```
