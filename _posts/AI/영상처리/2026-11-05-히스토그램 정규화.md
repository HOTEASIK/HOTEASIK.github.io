# 히스토그램 정규화

## 정의·핵심
- **정의**: 좁은 범위에 몰려 있는 픽셀 값 분포를 **전체 범위(0~255)로 선형으로 늘려** 표현 범위를 확장하는 것. 명암 대비 스트레칭 (응용 1차시)
- **목적 (강의)**: **명암 대비 향상** — 흐릿한 영상의 대비를 높여 또렷하게, 또는 비전 알고리즘의 **전처리**
- **원리: Min-Max 변환 (강의)**: 현재 영상의 **최솟값을 0, 최댓값을 255**로 맞추고 나머지 값은 비율에 따라 선형 변환
  - `dst = (src − min) / (max − min) × 255`
- **OpenCV: `cv2.normalize(src, None, alpha, beta, norm_type)`**
  - `cv2.NORM_MINMAX`: 결과 범위를 **[alpha, beta]** 로 → `cv2.normalize(img, None, 0, 255, cv2.NORM_MINMAX)`
  - `cv2.NORM_L2`, `NORM_L1`, `NORM_INF`: 벡터 노름이 alpha가 되도록 스케일 (특징 벡터·히스토그램 정규화)
  - float 결과가 필요하면 `dtype=cv2.CV_32F`
- **z-score 정규화**: `(x − 평균) / 표준편차` — 강의 예시에서 중앙에 집중된 분포를 퍼뜨림. 딥러닝 입력 정규화와 같은 개념 → [[표준화(StandardScaler)]]
- **평활화와의 차이**
  - 정규화: **선형** 늘리기 — 분포의 모양은 그대로, 폭만 넓힘. 이상값(극단 픽셀 하나)이 있으면 효과가 거의 없다
  - 평활화: **비선형** 재배치 — 누적분포를 이용해 분포를 **균등**하게 → [[히스토그램 평활화(Equalization)]]
- 이상값 대책: 상·하위 1% 백분위수를 min/max로 쓰는 **percentile stretch**

## 수식·원리
```
NORM_MINMAX:  dst = (src − min) · (β − α) / (max − min) + α
z-score:      dst = (src − μ) / σ
```

## 코드 예시
```python
import numpy as np
import cv2

src = np.array([[100, 110, 120, 130, 150]], np.uint8)           # 100~150에 몰린 저대비 영상
dst = cv2.normalize(src, None, 0, 255, cv2.NORM_MINMAX)
print(dst.tolist())                                             # [[0, 51, 102, 153, 255]]
manual = (src.astype(float) - src.min()) / (src.max() - src.min()) * 255
print(np.round(manual).astype(int).tolist())                    # [[0, 51, 102, 153, 255]]  공식과 같음

outlier = np.array([[0, 110, 120, 130, 150]], np.uint8)         # 극단값 하나
print(cv2.normalize(outlier, None, 0, 255, cv2.NORM_MINMAX).tolist())   # [[0, 187, 204, 221, 255]]  효과 작음
v = np.array([3.0, 4.0], np.float32)
print([round(float(x), 3) for x in cv2.normalize(v, None, 1.0, 0, cv2.NORM_L2).ravel()])   # [0.6, 0.8]  길이 1
```
