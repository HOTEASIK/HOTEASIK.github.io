# 가중합

## 정의·핵심
- **정의**: `cv2.addWeighted(src1, α, src2, β, γ)` — 두 영상을 **비율(투명도)에 맞춰 섞는** 연산. Image Blending (응용 1차시)
- **목적 (강의)**: 두 영상을 비율에 맞춰 **합성(블렌딩)**, **장면 전환(Transition)** 효과
- **선형 결합**: `dst = src1 × α + src2 × β + γ`
  - 보통 **α + β = 1**로 설정해 **평균 밝기를 유지**
  - γ: 결과 전체에 더하는 밝기 보정값 (보통 0)
  - 결과는 포화 연산(0~255로 잘림)
- **활용**
  - 크로스 페이드(α를 1→0으로 바꾸며 프레임 생성)
  - **히트맵 오버레이**: Grad-CAM 컬러맵을 원본에 반투명하게 겹치기 `addWeighted(img, 0.6, heat, 0.4, 0)` → [[의료영상에서 Grad-CAM 활용]]
  - 분할 마스크 시각화, 워터마크
  - 샤프닝(언샤프 마스크): `addWeighted(img, 1.5, blur, -0.5, 0)` — 원본에서 흐린 영상을 빼서 경계 강조
- 단순 `cv2.add`는 둘 다 100% 더해 쉽게 255로 포화되지만, 가중합은 밝기를 유지한다
- 두 영상의 크기·채널이 같아야 한다 (다르면 `resize` 먼저)

## 수식·원리
```
dst(x, y) = saturate( α·src1(x, y) + β·src2(x, y) + γ )
α + β = 1  →  평균 밝기 유지
언샤프 마스크: dst = (1 + k)·img − k·blur(img)
```

## 코드 예시
```python
import numpy as np
import cv2

a = np.full((2, 2, 3), 200, np.uint8)
b = np.full((2, 2, 3), 50, np.uint8)
for alpha in (1.0, 0.7, 0.5, 0.0):
    print(alpha, cv2.addWeighted(a, alpha, b, 1 - alpha, 0)[0, 0, 0])
# 1.0 200
# 0.7 155
# 0.5 125
# 0.0 50
print(cv2.add(a, b)[0, 0, 0])                                # 250  단순 덧셈은 밝아짐

edge = np.array([[50, 50, 200, 200]], np.uint8)
blur = cv2.blur(edge, (3, 1))
print(cv2.addWeighted(edge, 1.5, blur, -0.5, 0).tolist())    # [[50, 25, 225, 200]]  경계가 더 뚜렷해짐
```
