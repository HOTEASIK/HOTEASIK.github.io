# 윤곽선

## 정의·핵심
- **정의**: Contour. 이진 영상에서 **같은 값을 가진 연결된 영역의 경계선**을 점들의 목록으로 표현한 것. 연결된 객체를 탐지해 **물체를 분할**하고 **형태를 수치로 표현**하는 도구 (응용 3차시 수업목표: 객체 연결·분할, 형태의 수치적 표현)
- **엣지와의 차이**: 엣지는 밝기 변화가 큰 **픽셀들**(끊길 수 있음), 윤곽선은 **닫힌 경계 곡선**(물체 단위)
- **`contours, hierarchy = cv2.findContours(binary, mode, method)`** (OpenCV 4 이상은 반환값 2개, 3.x는 3개)
  - 입력: **이진 영상** (threshold·Canny·inRange 결과). **흰색 = 물체**, 검은 배경
  - `mode`: `RETR_EXTERNAL`(가장 바깥 윤곽만), `RETR_LIST`(모두, 계층 없음), `RETR_TREE`(모든 계층 — 구멍 포함), `RETR_CCOMP`
  - `method`: `CHAIN_APPROX_SIMPLE`(직선 구간은 끝점만 → 사각형은 점 4개), `CHAIN_APPROX_NONE`(모든 점)
  - 각 윤곽 = `(N, 1, 2)` 배열의 (x, y) 점
- **형태 분석 함수**
  - `cv2.contourArea(c)`: **면적** → 작은 잡음 윤곽 걸러내기
  - `cv2.arcLength(c, closed=True)`: **둘레**
  - `cv2.boundingRect(c)` → `(x, y, w, h)` **바운딩 박스** / `cv2.minAreaRect(c)` → 회전된 최소 사각형
  - `cv2.minEnclosingCircle(c)`, `cv2.fitEllipse(c)`, `cv2.convexHull(c)`
  - **`cv2.moments(c)`**: 모멘트 → **무게중심** `cx = m10/m00, cy = m01/m00`
  - `cv2.approxPolyDP(c, ε, True)`: 다각형 근사 → 꼭짓점 수로 **삼각형·사각형 판별** (ε = 둘레의 1~2%)
  - 원형도 `4π·면적/둘레²` (원이면 1)
- **그리기**: `cv2.drawContours(img, contours, -1, (0,255,0), 2)` (−1 = 전부)
- **활용**: 물체 개수 세기, 도형 분류, 문서 테두리(사각형) 찾기 → 투시 변환, 색 추적 물체의 위치, 모션 영역 박스

## 수식·원리
```
모멘트  m_pq = Σ x^p · y^q · I(x, y)
중심   cx = m10 / m00,  cy = m01 / m00,   m00 = 면적
원형도 = 4π · Area / Perimeter²
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((100, 160), np.uint8)
cv2.rectangle(img, (10, 10), (50, 40), 255, -1)                      # 사각형
cv2.circle(img, (100, 50), 25, 255, -1)                              # 원
cv2.fillPoly(img, [np.array([[130, 90], [155, 90], [142, 65]])], 255)   # 삼각형
img[3, 3] = 255                                                      # 잡음 점
contours, hierarchy = cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print(len(contours))                                                 # 4  (잡음 포함)
for c in sorted(contours, key=cv2.contourArea, reverse=True):
    area = cv2.contourArea(c)
    if area < 10:
        continue                                                     # 잡음 제거
    peri = cv2.arcLength(c, True)
    n = len(cv2.approxPolyDP(c, 0.02 * peri, True))
    M = cv2.moments(c)
    cx, cy = int(M["m10"] / M["m00"]), int(M["m01"] / M["m00"])
    print(int(area), cv2.boundingRect(c), "꼭짓점", n, "중심", (cx, cy), "원형도", round(4 * np.pi * area / peri ** 2, 2))
# 1890 (75, 25, 51, 51) 꼭짓점 8 중심 (100, 50) 원형도 0.87   ← 원 (꼭짓점 많음, 원형도 1에 가까움)
# 1200 (10, 10, 41, 31) 꼭짓점 4 중심 (30, 25) 원형도 0.77    ← 사각형
# 312 (130, 65, 26, 26) 꼭짓점 3 중심 (142, 81) 원형도 0.54   ← 삼각형
```
