# 필터링·커널 개념

## 정의·핵심
- **정의**: 영상에서 각 픽셀의 **주변 값을 고려해** 수학적 연산으로 새 픽셀 값을 계산하는 과정 (응용 2차시)
- **작동 방식**: 작은 행렬인 **커널(Kernel)** 을 영상 위로 **슬라이딩**시키며 겹친 영역과 곱해 더한다 → `New Pixel = Σ(Kernel × Area)` (합성곱, Convolution)
- **주요 목적**: 영상의 특징(**Edge, Blur, Sharpening**)을 강조하거나 억제, **노이즈 제거**, 영상을 부드럽게
- **활용**: 딥러닝 객체 인식의 전처리, 코너 검출, 텍스처 분석 등 비전의 기초 단계. CNN의 합성곱층은 이 커널을 **학습**하는 것 → [[합성곱(Convolution)]]
- **필터 종류 (강의 표)**

| 분류 | 필터 | 특징 | 함수 |
|---|---|---|---|
| Smoothing | 평균 | 커널 내 평균으로 대체 | `blur` |
| | 가우시안 | 중심에 가까울수록 큰 가중치 | `GaussianBlur` |
| | 중간값 | 정렬 후 중앙값 (소금-후추 잡음) | `medianBlur` |
| | 양방향 | 가깝고 색 차이가 작은 픽셀만 평균 (엣지 보존) | `bilateralFilter` |
| Edge | 소벨 | 1차 미분, 수평/수직 방향 | `Sobel` |
| | 라플라시안 | 2차 미분, 방향 무관 | `Laplacian` |
| | 캐니 | 잡음 제거→그래디언트→히스테리시스 | `Canny` |
| 모폴로지 | 침식·팽창·열기·닫기 | 형태 다듬기 | `erode`, `dilate`, `morphologyEx` |
| 기타 | 임의의 커널 | 사용자 정의 커널로 합성곱 | `filter2D` |

- **`cv2.filter2D(src, ddepth, kernel)`**: 직접 만든 커널을 적용. `ddepth=-1`이면 입력과 같은 타입
  - 샤프닝 커널 `[[0,-1,0],[-1,5,-1],[0,-1,0]]`, 엠보싱, 평균 `np.ones((k,k))/k²`
  - 음수 결과가 필요하면 `ddepth=cv2.CV_32F`/`CV_64F` 후 절대값
  - OpenCV는 실제로 **상관(correlation)** 을 계산 (커널을 뒤집지 않음) — 대칭 커널이면 차이 없음
- **실무 Tips (강의)**: 커널 크기는 **홀수**(3, 5, 7…), **클수록 블러 효과가 강함**. 연산은 float로 하고 uint8로 복원
- **경계 처리 `borderType`**: 기본 `BORDER_REFLECT_101`(가장자리 거울 반사). `BORDER_CONSTANT`(0 채움) 등

## 수식·원리
```
dst(x, y) = Σ_i Σ_j K(i, j) · src(x + i − a, y + j − b)      (a, b: 커널 중심)
평균 3×3:  K = (1/9)·ones(3, 3)
샤프닝:    K = [[0,−1,0], [−1,5,−1], [0,−1,0]]   (원본 + 라플라시안 강조)
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.array([[10, 10, 10, 10],
                [10, 10, 90, 10],
                [10, 10, 10, 10]], np.uint8)
mean_k = np.ones((3, 3), np.float32) / 9
print(cv2.filter2D(img, -1, mean_k).tolist())               # [[10, 28, 28, 46], [10, 19, 19, 28], [10, 28, 28, 46]]  90이 퍼짐
print(np.array_equal(cv2.filter2D(img, -1, mean_k), cv2.blur(img, (3, 3))))   # True  blur와 같음
sharp = np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]], np.float32)
print(cv2.filter2D(img, -1, sharp)[1].tolist())             # [10, 0, 255, 0]  중심 강조, 주변 감소(포화)
print(cv2.filter2D(img, cv2.CV_32F, sharp)[1].tolist())     # [10.0, -70.0, 410.0, -150.0]  float로 실제 값(경계는 반사 처리)
```
