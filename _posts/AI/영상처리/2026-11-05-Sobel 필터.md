# Sobel 필터

## 정의·핵심
- **엣지(Edge)란 (응용 3차시)**: 영상에서 픽셀의 **밝기가 급격하게 변하는 지점** — 주로 객체의 윤곽선·경계. 수학적으로는 **기울기(Gradient)**, 즉 밝기 변화율이 가장 큰 지점 → 목표: **1차 미분값이 극대가 되는 위치** 찾기
- **Sobel 필터**: 미분 연산을 하면서 **잡음 영향을 줄이도록** 고안된 필터 (근사 미분)
  - 핵심 장점: **평활화 + 미분 결합** (Smoothing + Differentiation). 단순 차분은 잡음에 매우 민감하지만, Sobel은 **주변 픽셀을 함께 고려**해 안정적
  - **Gx (수평 방향 변화 → 세로 엣지)**: `[[-1,0,1],[-2,0,2],[-1,0,1]]`
  - **Gy (수직 방향 변화 → 가로 엣지)**: `[[-1,-2,-1],[0,0,0],[1,2,1]]`
  - 가운데 행·열에 가중치 2 → `[1,2,1]`(평활화) × `[-1,0,1]`(미분)
- **함수**: `cv2.Sobel(src, ddepth, dx, dy, ksize=3)`
  - `dx=1, dy=0` → x방향 미분(Gx), `dx=0, dy=1` → y방향(Gy)
  - **`ddepth=cv2.CV_64F`(또는 CV_16S)로 해야** 음수 기울기가 살아남는다. uint8로 하면 어두워지는 경계(음수)가 0으로 잘려 **한쪽 엣지가 사라짐**
  - 표시할 때 `cv2.convertScaleAbs`로 절대값 → uint8
  - ksize: 1, 3, 5, 7. `ksize=-1`이면 Scharr(3×3에서 더 정확)
- **기울기 크기와 방향**: `magnitude = √(Gx² + Gy²)` (`cv2.magnitude`), 근사 `|Gx| + |Gy|`, 방향 `θ = atan2(Gy, Gx)` (`cv2.phase`)
  - 방향 정보는 Canny의 비최대 억제, **HOG** 특징에 사용 → [[HOG(Histogram of Oriented Gradients)]]
- 엣지 검출은 "**밝기의 변화율을 보고 값이 큰 곳을 찾는 문제**" (강의)

## 수식·원리
```
Gx = [−1 0 1; −2 0 2; −1 0 1] ⊛ I,   Gy = [−1 −2 −1; 0 0 0; 1 2 1] ⊛ I
|G| = √(Gx² + Gy²),   θ = atan2(Gy, Gx)
Sobel = [1 2 1]ᵀ(평활화) × [−1 0 1](미분)
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((7, 7), np.uint8)
img[:, 4:] = 200                                         # 세로 엣지 (어둠 → 밝음)
img[5:, :] = 0                                           # 가로 엣지 (밝음 → 어둠, 아래쪽)
gx = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
gy = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)
print(gx[2].astype(int).tolist())                        # [0, 0, 0, 800, 800, 0, 0]  세로 엣지에 반응
print(int(gy[:, 5].min()), int(gx[2].min()))             # -800 0  음수 기울기(밝→어둠)도 보존 (CV_64F)
gy_u8 = cv2.Sobel(img, cv2.CV_8U, 0, 1)
print(int(gy_u8.max()))                                  # 0  uint8로 하면 음수 엣지가 사라짐!
mag = cv2.magnitude(gx, gy)
ang = cv2.phase(gx, gy, angleInDegrees=True)
print(int(mag[2, 3]), int(ang[2, 3]))                    # 800 0  크기, 방향(0° = 오른쪽으로 밝아짐)
edges = cv2.convertScaleAbs(mag)                         # 표시용 uint8
print(edges.dtype)                                       # uint8
```
