# 회전

## 정의·핵심
- **정의**: 영상을 **기준점(주로 영상 중심)을 중심으로 일정 각도만큼 돌려** 새 좌표로 변환. 필요하면 크기(scale)도 함께 조정 (응용 2차시)
- **목적 (강의)**: 물체의 방향 변화, **데이터 증강**, 기하학적 보정(기울어진 문서·수평선 바로잡기)
- **OpenCV**
  1. `M = cv2.getRotationMatrix2D(center, angle, scale)` → **2×3 변환 행렬** 생성
     - `center`: `(x, y)` 회전 중심 — 보통 `(w / 2, h / 2)`
     - `angle`: 도(degree) 단위, **반시계 방향이 양수(+)** (영상 좌표 기준)
     - `scale`: 1.0이면 크기 유지
  2. `dst = cv2.warpAffine(img, M, (w, h))`
- **잘리는 영역 (강의)**: 액자 크기를 그대로 두면 **모서리가 잘린다** → 잘리지 않게 하려면 새 크기를 계산하고 M의 이동 성분을 보정
  - `new_w = h·|sinθ| + w·|cosθ|`, `new_h = h·|cosθ| + w·|sinθ|`, `M[0, 2] += new_w/2 − cx`, `M[1, 2] += new_h/2 − cy`
- **90° 단위 회전**은 보간 없이 정확하고 빠른 `cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE | ROTATE_180 | ROTATE_90_COUNTERCLOCKWISE)` 또는 `np.rot90`
- **좌표도 함께 회전**: 바운딩 박스·키포인트 라벨이 있으면 같은 M으로 `cv2.transform` → 증강 시 라벨 일치

## 수식·원리
```
α = scale·cosθ,  β = scale·sinθ
M = [[ α, β, (1−α)·cx − β·cy],
     [−β, α, β·cx + (1−α)·cy]]
(영상 좌표에서 θ>0 → 화면상 반시계 회전)
```

## 코드 예시
```python
import numpy as np
import cv2

h, w = 100, 200
M = cv2.getRotationMatrix2D((w / 2, h / 2), 90, 1.0)
print(np.round(M, 2).tolist())                                    # [[0.0, 1.0, 50.0], [-1.0, 0.0, 150.0]]
pt = np.float32([[[150, 50]]])                                    # 중심에서 오른쪽 50
print(np.round(cv2.transform(pt, M)).reshape(-1).tolist())        # [100.0, 0.0]  위쪽으로 → 반시계 90°

img = np.full((h, w), 255, np.uint8)
rot = cv2.warpAffine(img, M, (w, h))
print(round((rot == 0).mean(), 2))                                # 0.5  액자 고정 → 절반이 잘리고 빈 곳은 검정

cos, sin = abs(M[0, 0]), abs(M[0, 1])
nw, nh = int(h * sin + w * cos), int(h * cos + w * sin)
M[0, 2] += nw / 2 - w / 2; M[1, 2] += nh / 2 - h / 2
full = cv2.warpAffine(img, M, (nw, nh))
print(full.shape, round((full > 0).mean(), 2))                    # (200, 100) 1.0  잘리지 않음
print(cv2.rotate(np.arange(6).reshape(2, 3), cv2.ROTATE_90_CLOCKWISE).tolist())   # [[3, 0], [4, 1], [5, 2]]
```
