# Hough 변환

## 정의·핵심
- **정의**: 엣지 픽셀들을 **파라미터 공간으로 매핑**해 **투표(Voting)** 하고, 누적값이 최대인 지점을 찾아 **직선·원 같은 도형을 검출**하는 수학적 기법 (응용 3차시)
- **아이디어 (강의)**: 직선·원 등은 **방정식으로 표현 가능한 객체** → 이미지 공간(image space)을 파라미터 공간(parameter space)으로 바꾸면, 도형을 정의하는 **'수학적 변수'를 찾아 도형의 존재**를 알아낼 수 있다
- **직선 검출**
  - 이미지 공간: `y = ax + b` — 직선 위의 점들이 하나의 선을 이룸
  - 기울기가 무한대(수직선)인 문제 때문에 **극좌표** 사용: `ρ = x·cosθ + y·sinθ`
  - 이미지의 점 하나 → (ρ, θ) 공간에서 **사인 곡선** 하나. 한 직선 위의 점들의 곡선은 **한 점(교차점)에서 만난다**
  - 누적 배열(Accumulator)에서 투표 수가 많은 (ρ, θ) = 직선
- **강건함 (강의)**: 직선이 **끊어져 있거나 노이즈가 있어도** 교차점의 누적값이 가장 큰 곳을 찾으므로 검출 성능이 우수
- **검출 흐름 (강의)**: 1. 엣지 추출(Canny/Sobel) → 2. 공간 변환(Image → Parameter) → 3. 변수 탐색(Accumulator Voting) → 4. 객체 판정(도형 존재 확인)
- **OpenCV**
  - `cv2.HoughLines(edges, rho=1, theta=np.pi/180, threshold)`: (ρ, θ) 무한 직선
  - **`cv2.HoughLinesP(edges, 1, np.pi/180, threshold, minLineLength, maxLineGap)`**: 확률적 허프 — 선분의 **양 끝점 (x1, y1, x2, y2)** 반환. 실무에서 주로 사용 (차선 검출)
  - **`cv2.HoughCircles(gray, cv2.HOUGH_GRADIENT, dp, minDist, param1, param2, minRadius, maxRadius)`**: 원 (x, y, r). 내부에서 Canny를 하므로 **흑백 원본**(블러 권장)을 넣는다. param1 = Canny 상한, param2 = 누적 임계값(작을수록 많이 검출)
- **활용**: 차선 검출, 문서·건물 직선, 동전·눈동자·원형 부품 검출

## 수식·원리
```
ρ = x·cosθ + y·sinθ,   θ ∈ [0, π),  ρ ∈ [−D, D]
원: (x − a)² + (y − b)² = r²  → 파라미터 (a, b, r)
점 (x₀, y₀) → 파라미터 공간의 곡선 ρ(θ) = x₀cosθ + y₀sinθ
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((100, 100), np.uint8)
cv2.line(img, (10, 80), (90, 80), 255, 1)                  # 가로선 (끊긴 부분 포함)
img[80, 40:45] = 0
cv2.circle(img, (50, 35), 15, 255, 2)
lines = cv2.HoughLinesP(img, 1, np.pi / 180, threshold=30, minLineLength=30, maxLineGap=10)
print(lines.reshape(-1, 4).tolist())                       # [[10, 80, 90, 80]]  끊긴 선도 하나의 선분으로 검출

lines_rt = cv2.HoughLines(img, 1, np.pi / 180, 60)
rho, theta = lines_rt[0, 0]
print(round(float(rho)), round(float(np.degrees(theta))))  # 80 90  (ρ=80, θ=90° → y=80)

gray = np.zeros((100, 100), np.uint8); cv2.circle(gray, (50, 50), 20, 200, -1)
circles = cv2.HoughCircles(cv2.GaussianBlur(gray, (5, 5), 1), cv2.HOUGH_GRADIENT, dp=1, minDist=20,
                           param1=100, param2=15, minRadius=10, maxRadius=30)
print(np.round(circles[0, 0]).astype(int).tolist())        # [50, 50, 20]  중심 (50, 50), 반지름 20
```
