# remap

## 정의·핵심
- **정의**: `cv2.remap(src, map_x, map_y, interpolation)` — **출력의 각 픽셀이 원본의 어느 좌표에서 값을 가져올지**를 담은 **좌표 맵**을 직접 주는 **가장 일반적인 기하 변환** (응용 2차시 기하학적 변환 응용)
- **동작**: `dst(y, x) = src(map_y[y, x], map_x[y, x])` — 역방향 매핑을 픽셀마다 자유롭게 지정
  - `map_x`, `map_y`: 출력과 같은 크기의 **float32** 배열 (원본의 x, y 좌표)
  - 소수 좌표는 `interpolation`(LINEAR 등)으로 보간, 범위 밖은 `borderMode`
- **행렬로 표현 못 하는 변환까지 가능**
  - 이동·회전·아핀·투시는 행렬 하나로 되지만, **물결·소용돌이·볼록렌즈·어안 효과**처럼 위치마다 다르게 움직이는 **비선형 왜곡**은 remap으로
  - 사실 `warpAffine`·`warpPerspective`도 내부적으로 좌표 맵을 만들어 remap하는 것과 같다
- **대표 활용**
  - **카메라 렌즈 왜곡 보정**: `cv2.initUndistortRectifyMap(K, dist, ...)`로 맵을 **한 번 계산** → 매 프레임 `remap` (빠름) — 스테레오 정렬도 같은 방식
  - Optical Flow로 프레임 **와핑(warp)**: `map = 격자 + flow` → 다음 프레임을 이전 프레임에 맞추기 → [[Dense Optical Flow]]
  - 특수 효과(물결, 거울, 렌즈)
- **좌표 격자 만들기**: `map_x, map_y = np.meshgrid(np.arange(w), np.arange(h))` → float32 → 수식으로 변형

## 수식·원리
```
dst(x, y) = src( map_x(x, y), map_y(x, y) )
좌우 반전:  map_x = W − 1 − x,  map_y = y
물결:       map_x = x + A·sin(2π·y / λ),  map_y = y
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.arange(12, dtype=np.uint8).reshape(3, 4) * 20
h, w = img.shape
map_x, map_y = np.meshgrid(np.arange(w, dtype=np.float32), np.arange(h, dtype=np.float32))
same = cv2.remap(img, map_x, map_y, cv2.INTER_LINEAR)
print(np.array_equal(same, img))                                  # True  항등 맵
flip = cv2.remap(img, (w - 1 - map_x), map_y, cv2.INTER_NEAREST)
print(np.array_equal(flip, cv2.flip(img, 1)))                     # True  좌우 반전을 맵으로

big = np.tile(np.arange(64, dtype=np.uint8) * 4, (64, 1))         # 가로 그라데이션
H, W = big.shape
mx, my = np.meshgrid(np.arange(W, dtype=np.float32), np.arange(H, dtype=np.float32))
wave = cv2.remap(big, mx + 3 * np.sin(2 * np.pi * my / 16), my, cv2.INTER_LINEAR, borderMode=cv2.BORDER_REFLECT)
print(int(wave[4, 32]) - int(big[4, 32]), int(wave[12, 32]) - int(big[12, 32]))   # 12 -12  행마다 좌우로 출렁
```
