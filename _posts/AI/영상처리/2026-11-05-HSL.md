# HSL

## 정의·핵심
- **정의**: **H**ue(색상)·**S**aturation(채도)·**L**ightness(밝기)로 색을 표현하는 색공간. 인간의 색 인지 방식과 유사하고 **직관적** (응용 1차시)
- **HSV와의 차이**
  - **H(색상)** 는 HSV와 같다
  - **L (Lightness)**: 최댓값과 최솟값의 **평균** `(max + min) / 2`
    - L = 0 → 검정, **L = 0.5 → 가장 순수한 원색**, L = 1 → **흰색**
    - HSV의 V는 원색일 때 이미 최대(1) → "V 최대 = 원색", HSL은 "L 최대 = 흰색"
  - S의 정의도 달라 같은 색이라도 S 값이 다르다
  - 모양: HSV는 원뿔(위가 밝은 면), HSL은 **양원뿔**(위 꼭짓점 흰색, 아래 검정)
- **용도**
  - 디자인·CSS(`hsl(120, 100%, 50%)`)에서 색 조절이 직관적 — 밝게/어둡게를 L 하나로
  - 밝기 조절, 하이라이트·그림자 보정
  - 비전의 색상 분할에는 보통 **HSV**를 더 많이 쓴다 (강의: HSV가 "조명 변화에 강하고 색상 기반 분할에 자주 활용")
- **OpenCV**: `cv2.COLOR_BGR2HLS` — 채널 순서가 **H, L, S** (HLS)임에 주의. 범위 H 0~179, L 0~255, S 0~255

## 수식·원리
```
max = max(R,G,B), min = min(R,G,B)
L = (max + min) / 2
S = (max − min) / (max + min)          (L ≤ 0.5)
    (max − min) / (2 − max − min)      (L > 0.5)
H: HSV와 동일
```

## 코드 예시
```python
import numpy as np
import cv2

for name, bgr in {"red": (0, 0, 255), "light red": (128, 128, 255), "white": (255, 255, 255)}.items():
    px = np.uint8([[bgr]])
    h, l, s = cv2.cvtColor(px, cv2.COLOR_BGR2HLS)[0, 0]      # 순서 H, L, S
    _, s2, v = cv2.cvtColor(px, cv2.COLOR_BGR2HSV)[0, 0]
    print(f"{name:9s} HLS(H={h}, L={l}, S={s})  HSV(S={s2}, V={v})")
# red       HLS(H=0, L=128, S=255)  HSV(S=255, V=255)   ← 원색: L은 중간, V는 최대
# light red HLS(H=0, L=192, S=255)  HSV(S=127, V=255)
# white     HLS(H=0, L=255, S=0)  HSV(S=0, V=255)
```
