# 템플릿 매칭

## 정의·핵심
- **정의**: Template Matching. 큰 이미지 안에서 **작은 템플릿 이미지와 가장 비슷한 위치**를 찾는 기법. 템플릿을 **한 픽셀씩 슬라이딩**하며 유사도를 계산 (응용 4차시)
- **OpenCV**
  1. `res = cv2.matchTemplate(img, templ, method)` → 유사도 맵, 크기 `(H − h + 1, W − w + 1)`
  2. `min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(res)` → 최댓값·최솟값 위치 = 매칭된 **좌상단 (x, y)**
  3. 박스: `(x, y) ~ (x + w, y + h)`
- **6가지 방법 (강의)**

| 방법 | 판정 | 특징 |
|---|---|---|
| `TM_SQDIFF` | **작을수록** 유사 (완벽 일치 = 0) | 제곱 차이 합 |
| `TM_SQDIFF_NORMED` | 작을수록 유사 (0~1) | 정규화 |
| `TM_CCORR` | 클수록 유사 | 상관 — 밝은 영역에 치우침 |
| `TM_CCORR_NORMED` | 클수록 유사 (0~1) | 정규화 |
| `TM_CCOEFF` | 클수록 유사 | 평균을 뺀 상관 |
| `TM_CCOEFF_NORMED` | 클수록 유사 (−1~1) | **가장 정확, 조명 변화에 강함 (권장)** |

  - 상관 계열(CCORR, CCOEFF)은 **max_loc**, 오차 계열(SQDIFF)은 **min_loc** 사용
- **여러 개 찾기**: `np.where(res >= 0.8)`로 임계값 이상 위치 전부 → 겹치는 것은 [[NMS(Non-Maximum Suppression)]]
- **한계 (강의)**: **회전·크기·밝기 변화에 취약** — 템플릿과 같은 크기·방향일 때만 잘 맞음
  - 크기 대응: 이미지 피라미드(여러 배율로 resize하며 반복)
  - 회전·크기에 강해야 하면 → [[특징점·디스크립터 매칭]]
- **활용**: 화면 UI 요소 찾기(게임·자동화), PCB 부품 위치, 고정된 로고·마크 검출

## 수식·원리
```
SQDIFF:        R(x,y) = Σ (T(x',y') − I(x+x', y+y'))²
CCORR:         R(x,y) = Σ T(x',y') · I(x+x', y+y')
CCOEFF_NORMED: R = Σ T'·I' / sqrt(Σ T'² · Σ I'²)   (T', I' = 평균을 뺀 값)
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
img = rng.integers(0, 256, (100, 120), dtype=np.uint8)
templ = img[40:55, 70:90].copy()                         # (x=70, y=40)에서 잘라낸 15×20 템플릿
res = cv2.matchTemplate(img, templ, cv2.TM_CCOEFF_NORMED)
print(res.shape)                                         # (86, 101) = (100−15+1, 120−20+1)
_, max_val, _, max_loc = cv2.minMaxLoc(res)
print(max_loc, round(max_val, 3))                        # (70, 40) 1.0  좌상단 (x, y)

res2 = cv2.matchTemplate(img, templ, cv2.TM_SQDIFF)
min_val, _, min_loc, _ = cv2.minMaxLoc(res2)
print(min_loc, min_val)                                  # (70, 40) 1.0  SQDIFF는 최솟값 (이론상 0, 부동소수 오차)

dark = (img * 0.5).astype(np.uint8)                      # 밝기 절반
r = cv2.matchTemplate(dark, templ, cv2.TM_CCOEFF_NORMED)
print(cv2.minMaxLoc(r)[3])                               # (70, 40)  정규화 상관은 밝기 변화에도 찾음
rot = cv2.rotate(templ, cv2.ROTATE_90_CLOCKWISE)
print(round(cv2.minMaxLoc(cv2.matchTemplate(img, rot, cv2.TM_CCOEFF_NORMED))[1], 2))   # 0.21  회전하면 점수 급락
```
