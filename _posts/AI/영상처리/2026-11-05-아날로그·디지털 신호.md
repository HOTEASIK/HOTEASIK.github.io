# 아날로그·디지털 신호

## 정의·핵심
- **아날로그 신호 (Analog)**: 자연계의 소리·빛처럼 **끊어지지 않고 연속적(Continuous)** 으로 변하는 신호. 예: LP판, 수은 온도계, 사람의 목소리 (응용 1차시)
- **디지털 신호 (Digital)**: 연속적인 아날로그 신호를 **0과 1 같은 숫자로 변환해 불연속적(Discrete)** 으로 끊어 표현한 신호. 아날로그 신호를 '디지털화'한 결과물. 예: MP3, JPG 이미지, 컴퓨터 데이터
- **디지털화 3단계 (강의)**: Sampler → Quantization → Encode
  1. **샘플링 (Sampling)**: 연속 신호를 **일정 간격(시간/공간)** 으로 쪼개어 표본 추출 — 격자 나누기, **픽셀화**
  2. **양자화 (Quantization)**: 추출한 샘플 값을 정해진 범위의 **대표값(정수)** 으로 근사 — **밝기값 할당(0~255)**
  3. **인코딩 (Encoding)**: 양자화된 값을 **이진수(0과 1)** 부호로 변환해 저장 — 이진수 변환, 압축
  - 자세히 → [[샘플링·양자화]]
- **영상에서의 의미**
  - 카메라 센서가 받은 빛(아날로그)이 → 공간 샘플링으로 **픽셀 격자**가 되고 → 양자화로 **0~255 정수**가 되고 → JPG/PNG로 **인코딩**된다
  - 디지털화 과정에서 정보가 **손실**될 수 있다 (해상도가 낮으면 세부 손실, 비트 수가 적으면 계단 현상)
- **디지털의 장점**: 복사·전송해도 품질 저하가 없고, 컴퓨터로 연산(필터·변환·딥러닝)이 가능하며, 압축·저장이 쉽다

## 수식·원리
```
아날로그:  f(t), t ∈ ℝ (연속)
샘플링:    f[n] = f(n·T)            (T: 샘플 간격)
양자화:    q[n] = round(f[n] / Δ) · Δ  (Δ: 양자화 간격)
인코딩:    q[n] → 이진수 (8bit면 0~255)
```

## 코드 예시
```python
import numpy as np

t = np.linspace(0, 1, 1000)                       # '연속' 신호 (촘촘한 근사)
analog = 0.5 + 0.5 * np.sin(2 * np.pi * 3 * t)    # 0~1 사이 아날로그 값
idx = np.arange(0, 1000, 50)                      # 샘플링: 50칸마다 하나
samples = analog[idx]
digital = np.round(samples * 255).astype(np.uint8)   # 양자화: 0~255 정수
print(len(samples), digital[:5].tolist())         # 20 [128, 231, 249, 167, 52]
print([format(v, "08b") for v in digital[:2]])    # 인코딩: ['10000000', '11100111']
print(np.abs(digital / 255 - samples).max() <= 0.5 / 255 + 1e-9)   # True  양자화 오차 ≤ 반 칸
```
