# 투시 변환

## 정의·핵심
- **정의**: Perspective Transform (호모그래피, Homography). **3차원 공간의 물체를 2차원 평면에 투영할 때 생기는 원근 효과**를 반영하는 변환 (응용 2차시)
- **성질 (강의)**
  - **직선은 직선**으로 남지만 **평행성이 깨진다** — 평행한 두 직선이 변환 후 **소실점(Vanishing Point)** 에서 만남
  - **직사각형 ↔ 사다리꼴(임의의 사각형)** 변환 가능
  - **3×3 행렬**, 자유도 **8** → **대응점 4쌍** 필요
- **OpenCV**
  ```
  M = cv2.getPerspectiveTransform(src_pts, dst_pts)   # 4점 → 3×3
  dst = cv2.warpPerspective(img, M, (w, h))
  ```
  - 점은 float32, 정확히 4개. 4개보다 많고 잡음이 있으면 `cv2.findHomography(src, dst, cv2.RANSAC)` (특징점 매칭 결과로 정합·스티칭)
  - 점 하나 변환: `cv2.perspectiveTransform(pts, M)`
- **Tip (강의)**: 입력 4개 점의 **순서(좌상, 우상, 우하, 좌하)** 가 출력 좌표 순서와 **일치해야** 이미지가 뒤집히지 않는다
- **대표 활용: 문서 스캔 보정 (#문서인식 #OCR전처리)**
  - 비스듬히 찍은 문서(사다리꼴) → **정면에서 본 것처럼** 직사각형으로 펴기
  - 흐름: 흑백 → 블러 → Canny → findContours → 가장 큰 4꼭짓점 윤곽(approxPolyDP) → 꼭짓점 정렬 → getPerspectiveTransform → warpPerspective → [[윤곽선]]
  - 점 정렬 요령: `x+y` 최소 = 좌상, 최대 = 우하 / `y−x` 최소 = 우상, 최대 = 좌하
- 그 밖: 차선 검출의 **조감도(Bird's-eye view)** 변환, 파노라마 스티칭, AR, 스포츠 경기장 좌표 변환

## 수식·원리
```
[x'w]   [h11 h12 h13] [x]
[y'w] = [h21 h22 h23] [y],    x' = x'w / w,  y' = y'w / w
[ w ]   [h31 h32  1 ] [1]
8개 미지수 ← 4점 × 2식 = 8개 방정식
아핀과 차이: h31, h32 ≠ 0 → 위치마다 다른 배율(원근)
```

## 코드 예시
```python
import numpy as np
import cv2

src = np.float32([[30, 20], [170, 40], [190, 150], [10, 130]])   # 비스듬한 문서 (좌상, 우상, 우하, 좌하)
W, H = 160, 120
dst = np.float32([[0, 0], [W - 1, 0], [W - 1, H - 1], [0, H - 1]])
M = cv2.getPerspectiveTransform(src, dst)
print(M.shape, round(float(M[2, 2]), 3))                           # (3, 3) 1.0
print(np.round(cv2.perspectiveTransform(src[None], M)[0]).tolist())   # [[0.0, -0.0], [159.0, 0.0], [159.0, 119.0], [0.0, 119.0]]  직사각형 모서리로

img = np.zeros((170, 200), np.uint8)
cv2.fillPoly(img, [src.astype(np.int32)], 255)                     # 사다리꼴 문서
flat = cv2.warpPerspective(img, M, (W, H))
print(flat.shape, round((flat > 0).mean(), 2))                     # (120, 160) 1.0  화면을 꽉 채운 직사각형

pts = np.float32([[170, 40], [10, 130], [30, 20], [190, 150]])     # 순서가 섞인 꼭짓점 정렬
s, d = pts.sum(1), np.diff(pts, axis=1).ravel()
ordered = np.float32([pts[s.argmin()], pts[d.argmin()], pts[s.argmax()], pts[d.argmax()]])
print(np.array_equal(ordered, src))                                # True
```
