# 색상 검출

## 정의·핵심
- **정의**: 특정 색 범위에 속하는 픽셀만 골라 **마스크**를 만들고 그 영역을 추출하는 기법. 응용 1차시 "색상의 검출", 3차시 "색상 tracking"
- **핵심 함수: `cv2.inRange(src, lowerb, upperb)`**
  - 각 픽셀이 **모든 채널에서 [lower, upper] 범위 안**이면 **255**, 아니면 **0**인 **마스크(uint8 단일 채널)** 반환
  - 마스크: 0이면 '무시', 0이 아니면 '적용' (응용 1차시 마스크 정의) → [[논리 연산]]
- **표준 절차**
  1. BGR → **HSV** 변환 (조명에 강함) → [[HSV]]
  2. 목표 색의 H 범위 + S·V 하한 설정 (예: 파랑 `[100, 100, 50]` ~ `[130, 255, 255]`)
  3. `mask = cv2.inRange(hsv, lower, upper)`
  4. (선택) **모폴로지 열기/닫기**로 작은 잡음 제거·구멍 메우기 → [[모폴로지]]
  5. `result = cv2.bitwise_and(img, img, mask=mask)` — 마스크 영역만 남김
  6. (추적) `findContours` → 가장 큰 윤곽의 중심·사각형 → [[윤곽선]]
- **빨강은 범위가 두 개**: H가 0 근처와 179 근처에 걸쳐 있음 → `mask = inRange(0~10) | inRange(170~179)`
- **범위 찾는 법**: 목표 색 픽셀을 HSV로 변환해 확인 → H ±10, S·V는 넉넉히. 트랙바로 실시간 조절하면 편하다 → [[마우스·트랙바]]
- **한계**: 배경에 비슷한 색이 있으면 오검출, 강한 조명·그림자·흰 반사광에서 실패 → 딥러닝 분할/검출로 보완
- 활용: 색 공 추적, 크로마키(초록 배경 제거), 피부 검출, 차선(흰·노랑) 검출

## 수식·원리
```
mask(x, y) = 255  if  lower_c ≤ src_c(x, y) ≤ upper_c  for all c
             0    otherwise
result = img AND img  (mask ≠ 0 인 곳만)
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.full((60, 90, 3), 200, np.uint8)               # 회색 배경
cv2.circle(img, (20, 30), 12, (255, 80, 0), -1)          # 파란 원 (BGR)
cv2.rectangle(img, (55, 15), (80, 45), (0, 0, 220), -1)  # 빨간 사각형
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

blue = cv2.inRange(hsv, np.array([100, 100, 50]), np.array([130, 255, 255]))
red = cv2.inRange(hsv, (0, 100, 50), (10, 255, 255)) | cv2.inRange(hsv, (170, 100, 50), (179, 255, 255))
print(blue.dtype, np.unique(blue).tolist())              # uint8 [0, 255]
print(cv2.countNonZero(blue), cv2.countNonZero(red))     # 441 806  (파란 원, 빨간 사각형 26×31)
only_blue = cv2.bitwise_and(img, img, mask=blue)
ys, xs = np.nonzero(blue)
print(round(xs.mean()), round(ys.mean()), only_blue[0, 0].tolist())   # 20 30 [0, 0, 0]  원 중심, 배경은 검정
```
