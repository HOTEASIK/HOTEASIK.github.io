# 샘플링·양자화

## 정의·핵심
- **샘플링 (Sampling)**: 연속 신호에서 **특정 시간·공간 지점의 값을 추출**해 이산 신호로 바꾸는 과정 (응용 1차시)
  - 영상: 공간을 격자로 나눔 → **해상도(픽셀 수)** 를 결정
- **양자화 (Quantization)**: 연속적인 값을 **제한된 개수의 이산 값**으로 근사하는 과정
  - 영상: 밝기를 몇 단계로 나눌지 → **bit depth** 결정 (8bit = 256단계)
  - 단계가 적으면 부드러운 그라데이션이 **계단(밴딩)** 처럼 보인다
- **신호를 '더 잘' 추출하는 두 기준 (강의)**
  - **Step 1. Quantity — Sampling Rate (Hz)**: 단위 시간당 추출하는 **샘플 수**. "더 촘촘하게 추출한다". 클수록 원본과 비슷(고해상도)하지만 **데이터 용량·처리 비용 증가**
  - **Step 2. Quality — Nyquist Rate**: 정보 손실 없이 원래 신호를 **완벽히 복원하기 위한 최소 샘플링 주파수**. "손실 없이 추출하는 최소 기준"
    - **Fs > 2 × Fmax** (샘플링 주파수 > 신호 최고 주파수의 2배)
- **에일리어싱 (Aliasing)**: 나이퀴스트 조건을 어기면 높은 주파수가 **낮은 주파수로 둔갑**
  - 영상: 고운 줄무늬를 축소하면 생기는 **모아레(물결무늬)**, 바퀴가 거꾸로 도는 것처럼 보이는 현상
  - 대책: 축소 전에 **블러(저역통과)** 를 하거나 `INTER_AREA` 보간 사용 → [[보간법]]
- **영상 크기 계산**: 가로 × 세로 × 채널 × (bit depth / 8) 바이트

## 수식·원리
```
Nyquist:  Fs > 2 · Fmax
양자화 단계 수 = 2^bits   (8bit → 256, 1bit → 2)
에일리어싱 겉보기 주파수 = |F − k·Fs|  (가장 가까운 정수 k)
```

## 코드 예시
```python
import numpy as np

f = 9                                                   # 신호 주파수 9Hz
for fs in (40, 10):                                     # 나이퀴스트 18Hz 기준: 40은 충분, 10은 부족
    t = np.arange(0, 1, 1 / fs)
    x = np.sin(2 * np.pi * f * t)
    peak = np.abs(np.fft.rfft(x)).argmax() * fs / len(x)
    print(fs, "Hz 샘플링 → 보이는 주파수", peak)
# 40 Hz 샘플링 → 보이는 주파수 9.0
# 10 Hz 샘플링 → 보이는 주파수 1.0   ← 에일리어싱(9Hz가 1Hz로 둔갑)

grad = np.linspace(0, 255, 8)                           # 부드러운 그라데이션
for bits in (8, 2):
    step = 256 // 2 ** bits
    print(bits, (grad // step * step).astype(int).tolist())
# 8 [0, 36, 72, 109, 145, 182, 218, 255]
# 2 [0, 0, 64, 64, 128, 128, 192, 192]   ← 4단계뿐이라 계단 현상
print(1920 * 1080 * 3)                                  # 6220800 바이트 (8bit 컬러 FHD 한 장)
```
