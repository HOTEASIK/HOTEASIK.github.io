# 동영상 처리

## 정의·핵심
- **정의**: 동영상은 **정지 영상(프레임)의 연속**. OpenCV는 `VideoCapture`로 프레임을 **한 장씩 읽어** 이미지처럼 처리하고, `VideoWriter`로 다시 저장한다 (응용 3차시)
- **읽기: `cap = cv2.VideoCapture(src)`**
  - `src`: 파일 경로(`"bird.mp4"`), **카메라 번호**(`0` = 기본 웹캠), RTSP·HTTP 스트림 URL
  - **열기 검증 (과제)**: `if not cap.isOpened(): ...` — 경로가 틀리거나 코덱 문제면 False
  - `ret, frame = cap.read()` — `ret`이 **False면 끝(또는 실패)** → 루프 종료
  - 다 쓰면 **자원 해제**: `cap.release()`, `cv2.destroyAllWindows()`
- **속성 (과제 문항 4)**: `cap.get(cv2.CAP_PROP_FPS)`, `CAP_PROP_FRAME_WIDTH`, `CAP_PROP_FRAME_HEIGHT`, `CAP_PROP_FRAME_COUNT`, `CAP_PROP_POS_FRAMES`(현재 위치) / `cap.set(...)`으로 위치 이동·카메라 해상도 설정
- **재생 속도**: `cv2.waitKey(delay)`의 delay = `int(1000 / fps)` ms → 원래 속도. 0이면 한 프레임에서 멈춤
- **저장: `cv2.VideoWriter(path, fourcc, fps, (w, h), isColor)`**
  - `fourcc = cv2.VideoWriter_fourcc(*"mp4v")`(mp4), `*"XVID"`(avi), `*"MJPG"`
  - 프레임 크기 `(w, h)`가 **정확히 일치**해야 함 (다르면 조용히 저장 실패), 흑백이면 `isColor=False`
- **표준 처리 루프**
  ```
  while True:
      ret, frame = cap.read()
      if not ret: break
      gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)   # 프레임별 처리
      cv2.imshow("v", gray)
      if cv2.waitKey(1) & 0xFF == ord('q'): break
  cap.release(); cv2.destroyAllWindows()
  ```
- **활용 (강의 흐름)**: 프레임별 [[색상 검출]]·[[이진화]] → 모멘트로 중심 추적(`cx = m10/m00`) → [[배경 제거]] → [[MeanShift 추적]]·[[Optical Flow 개념]]
- **실시간 성능**: 처리 시간이 1/fps보다 길면 프레임이 밀린다 → 프레임 축소, 매 N번째 프레임만 처리, GPU 모델 사용

## 수식·원리
```
동영상 = 프레임 시퀀스 I_1, I_2, ..., I_N   (N = FPS × 초)
재생 지연 delay(ms) = 1000 / FPS
프레임 i의 시간 t = i / FPS
```

## 코드 예시
```python
import os, tempfile
import numpy as np
import cv2

path = os.path.join(tempfile.mkdtemp(), "demo.avi")
w, h, fps = 64, 48, 10
out = cv2.VideoWriter(path, cv2.VideoWriter_fourcc(*"MJPG"), fps, (w, h))
for i in range(20):                                   # 오른쪽으로 움직이는 흰 사각형
    frame = np.zeros((h, w, 3), np.uint8)
    cv2.rectangle(frame, (2 * i, 20), (2 * i + 8, 28), (255, 255, 255), -1)
    out.write(frame)
out.release()

cap = cv2.VideoCapture(path)
print(cap.isOpened())                                 # True
print(cap.get(cv2.CAP_PROP_FPS), int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)),
      int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)), int(cap.get(cv2.CAP_PROP_FRAME_COUNT)))   # 10.0 64 48 20
cx_list = []
while True:
    ret, frame = cap.read()
    if not ret:
        break
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    _, b = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
    m = cv2.moments(b, binaryImage=True)
    cx_list.append(round(m["m10"] / m["m00"]))        # 중심 x = m10 / m00
cap.release()
print(len(cx_list), cx_list[:4], int(1000 / fps))     # 20 [4, 6, 8, 10] 100  프레임마다 2픽셀씩 이동
```
