# 마우스·트랙바

## 정의·핵심
- **정의**: OpenCV의 **사용자 입력 처리** 기능 — 키보드(`waitKey`), 마우스(`setMouseCallback`), 트랙바(`createTrackbar`)로 창(`imshow`)과 상호작용 (응용 1차시)
- **키보드: `cv2.waitKey(delay)`**
  - delay(ms) 동안 키 입력 대기, **0이면 무한 대기**. 반환값 = 눌린 키 코드, 입력이 없으면 **-1**
  - `imshow` 창을 실제로 그리려면 반드시 호출 필요 (이벤트 루프 역할)
  - 관용구: `if cv2.waitKey(1) & 0xFF == ord('q'): break` (동영상 루프 종료), ESC = 27
- **마우스: `cv2.setMouseCallback(windowName, onMouse, param=None)`**
  - 콜백 시그니처: `def onMouse(event, x, y, flags, param)`
  - `event`: `EVENT_LBUTTONDOWN`(왼쪽 클릭), `EVENT_LBUTTONUP`, `EVENT_MOUSEMOVE`(이동), `EVENT_RBUTTONDOWN`, `EVENT_LBUTTONDBLCLK` 등
  - `flags`: 드래그 중인지 등 부가 상태 (`EVENT_FLAG_LBUTTON`, `EVENT_FLAG_CTRLKEY`, `SHIFTKEY`)
  - 활용: 클릭한 점 좌표 수집(투시 변환 4점 선택), 드래그로 ROI 선택(추적 대상 지정), 그림판
  - ROI만 필요하면 `x, y, w, h = cv2.selectROI("win", img)`가 간편
- **트랙바: `cv2.createTrackbar(trackbarName, windowName, value, count, onChange)`**
  - 0 ~ count 범위 정수 슬라이더. 값이 바뀔 때마다 `onChange(pos)` 호출 (안 쓰면 `lambda x: None`)
  - 현재 값 읽기: `cv2.getTrackbarPos(name, win)`, 설정: `setTrackbarPos`
  - 활용: **임계값·Canny 상하한·HSV 범위**를 실시간으로 조절하며 최적값 찾기
- **Colab 주의 (강의)**: Colab은 GUI 창을 띄울 수 없어 `imshow`·`waitKey`·`setMouseCallback`·`createTrackbar`가 동작하지 않는다 → `cv2_imshow`(google.colab.patches), **ipywidgets 슬라이더**로 트랙바를 재현
- 핵심 설계: **콜백은 상태(전역 변수·param 딕셔너리)를 바꾸고**, 메인 루프가 그 상태로 다시 그린다

## 수식·원리
```
while True:
    cv2.imshow(win, draw(state))        # 상태로 그리기
    if cv2.waitKey(1) & 0xFF == 27: break
onMouse(event, x, y, flags, param) → state 갱신
onChange(pos) / getTrackbarPos → 파라미터 갱신
```

## 코드 예시
```python
import numpy as np
import cv2

state = {"pts": [], "drag": False, "roi": None}

def on_mouse(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:
        param["pts"].append((x, y)); param["drag"] = True
    elif event == cv2.EVENT_LBUTTONUP and param["drag"]:
        (x0, y0), param["drag"] = param["pts"][-1], False
        param["roi"] = (min(x0, x), min(y0, y), abs(x - x0), abs(y - y0))

# 실제 사용: cv2.namedWindow("win"); cv2.setMouseCallback("win", on_mouse, state)
on_mouse(cv2.EVENT_LBUTTONDOWN, 30, 20, 0, state)                   # 이벤트를 직접 흉내
on_mouse(cv2.EVENT_MOUSEMOVE, 50, 40, cv2.EVENT_FLAG_LBUTTON, state)
on_mouse(cv2.EVENT_LBUTTONUP, 80, 60, 0, state)
print(state["roi"])                                                 # (30, 20, 50, 40)  드래그한 ROI

img = np.tile(np.arange(256, dtype=np.uint8), (10, 1))
def on_change(pos):                                                 # 트랙바 콜백 (임계값)
    _, b = cv2.threshold(img, pos, 255, cv2.THRESH_BINARY)
    return int((b > 0).sum())
# 실제 사용: cv2.createTrackbar("T", "win", 128, 255, on_change); t = cv2.getTrackbarPos("T", "win")
print([on_change(t) for t in (64, 128, 192)])                       # [1910, 1270, 630]  값에 따라 결과가 바뀜
print(-1 & 0xFF == ord('q'), ord('q'))                              # False 113  waitKey 종료 판정
```
