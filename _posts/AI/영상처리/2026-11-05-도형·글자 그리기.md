# 도형·글자 그리기

## 정의·핵심
- **정의**: OpenCV 그리기 함수는 **영상(NumPy 배열) 위에 직접 선·도형·문자를 그려 넣는** 함수. 검출 결과(바운딩 박스, 라벨, 신뢰도) 시각화에 필수 (응용 1차시)
- **공통 규칙**
  - 원본 배열을 **직접 수정**(in-place) → 원본을 보존하려면 `img.copy()`에 그린다
  - 좌표는 **(x, y)** 정수 튜플, 색은 **BGR** 튜플 (`(0, 0, 255)` = 빨강), 흑백 영상이면 스칼라
  - `thickness`: 선 두께(기본 1), **`-1`(= `cv2.FILLED`)이면 내부 채움**
  - `lineType`: `cv2.LINE_4`, `LINE_8`(기본), **`LINE_AA`(안티에일리어싱, 부드러움)**
- **함수 정리 (강의)**

| 함수 | 용도 |
|---|---|
| `cv2.line(img, pt1, pt2, color, thickness)` | 직선 |
| `cv2.arrowedLine(..., tipLength=0.1)` | 화살표 직선 (머리 길이 비율) |
| `cv2.drawMarker(img, pt, color, markerType, markerSize)` | 마커(십자, 별, 다이아몬드 등) |
| `cv2.rectangle(img, pt1, pt2, color)` / `(img, (x, y, w, h), color)` | 사각형 — 두 꼭짓점 또는 위치+크기 |
| `cv2.circle(img, center, radius, color)` | 원 |
| `cv2.ellipse(img, center, axes, angle, startAngle, endAngle, color)` | 타원·호 |
| `cv2.polylines(img, [pts], isClosed, color)` / `cv2.fillPoly` | 다각형 (pts는 int32 배열의 리스트) |
| `cv2.putText(img, text, org, fontFace, fontScale, color, thickness)` | 문자열 (`org` = 글자 **좌하단** 기준점) |

- **폰트 (강의)**: `cv2.FONT_HERSHEY_SIMPLEX`(기본), `PLAIN`(얇음), `DUPLEX`(굵음), `COMPLEX`, `TRIPLEX`, `SCRIPT_SIMPLEX`(필기체), `| cv2.FONT_ITALIC`
  - `putText`는 **한글을 지원하지 않는다**(??로 표시) → 한글은 PIL `ImageDraw` + 한글 폰트로 그린 뒤 변환
  - 글자 크기 계산: `(w, h), baseline = cv2.getTextSize(text, font, scale, thickness)` → 라벨 배경 박스 크기 맞추기
- **검출 결과 시각화 패턴**: `rectangle`(박스) + `rectangle(-1)`(라벨 배경) + `putText`(클래스명·신뢰도)
- 반투명 박스: 복사본에 채운 도형 → `cv2.addWeighted`로 합성 → [[가중합]]

## 수식·원리
```
thickness > 0 : 외곽선만   /  thickness = -1 (FILLED) : 내부 채움
putText org = (x, y)  → 글자의 왼쪽 아래(baseline) 위치
라벨 배경 = (x, y − h − baseline) ~ (x + w, y)
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((100, 200, 3), np.uint8)
cv2.line(img, (0, 0), (199, 99), (255, 0, 0), 1)
cv2.rectangle(img, (10, 10), (50, 40), (0, 255, 0), 2)              # 외곽선
cv2.rectangle(img, (60, 10, 30, 30), (0, 0, 255), -1)                # (x, y, w, h), 채움
cv2.circle(img, (150, 50), 20, (0, 255, 255), -1, cv2.LINE_AA)
print(img[25, 75].tolist(), img[50, 150].tolist())                   # [0, 0, 255] [0, 255, 255]  BGR
print(img[25, 30].tolist())                                          # [0, 0, 0]  외곽선 사각형은 내부 비어 있음

pts = np.array([[100, 80], [130, 60], [160, 80]], np.int32)
cv2.polylines(img, [pts], True, (255, 255, 255), 1)
text, font = "person 0.92", cv2.FONT_HERSHEY_SIMPLEX
(w, h), base = cv2.getTextSize(text, font, 0.5, 1)
print(w, h, base)                                                    # 96 12 5  글자 영역 크기 → 라벨 배경 박스
x, y = 10, 95
cv2.rectangle(img, (x, y - h - base), (x + w, y), (0, 255, 0), -1)  # 라벨 배경
cv2.putText(img, text, (x, y - base), font, 0.5, (0, 0, 0), 1, cv2.LINE_AA)
print(img.shape, int((img > 0).any(axis=2).sum()) > 0)               # (100, 200, 3) True
```
