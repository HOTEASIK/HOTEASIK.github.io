# 이미지 파일 형식

## 정의·핵심
- **정의**: 픽셀 배열을 디스크에 저장하는 인코딩 방식. 확장자에 따라 압축 방식·지원 기능이 다르다 (응용 1차시 "파일형식변환 jpg·png" 실습)
- **JPG (JPEG)**
  - **손실 압축**: 사람 눈에 덜 띄는 고주파 정보를 버려 파일이 **작다** (8×8 블록 DCT + 양자화)
  - **품질(0~100)** 조절 가능: 낮을수록 작지만 **블록 노이즈·번짐** (아티팩트)
  - 투명도(알파) **미지원**, 저장할 때마다 화질 저하 누적
  - 용도: 사진, 웹, 대용량 데이터셋
- **PNG**
  - **무손실 압축**: 픽셀 값이 **그대로 복원** — 압축 레벨(0~9)은 크기·속도만 바꿈
  - **투명도(알파 채널)**, 16bit 지원
  - 파일이 크다 (사진은 JPG의 수 배)
  - 용도: **마스크·라벨(분할)**, 그래픽·스크린샷, 정확한 픽셀 값이 중요한 경우
- **그 밖**: BMP(무압축), TIFF(다중 페이지·16bit, 의료·위성), WebP(손실/무손실, 작음), DICOM(의료) → [[DICOM 형식]]
- **딥러닝에서의 주의**
  - **분할 마스크를 JPG로 저장하면 안 된다**: 손실 압축 때문에 클래스 값(0, 1, 2…)이 경계에서 깨진다
  - 데이터셋을 JPG로 변환하면 용량은 줄지만, 품질이 너무 낮으면 성능이 떨어진다
  - PNG의 알파 채널은 `IMREAD_UNCHANGED`로 읽어야 4채널로 나온다
- **OpenCV 저장 옵션**: `cv2.imwrite("a.jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 90])`, `cv2.imwrite("a.png", img, [cv2.IMWRITE_PNG_COMPRESSION, 3])`

## 수식·원리
```
압축률 = 원본 바이트(H·W·C) / 파일 바이트
JPG: 손실 (품질 ↓ → 크기 ↓, 오차 ↑)     PNG: 무손실 (오차 0)
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
y, x = np.mgrid[0:256, 0:256]
img = np.dstack([x, y, (x + y) // 2]).astype(np.uint8)          # 부드러운 그라데이션
img = cv2.add(img, rng.integers(0, 20, img.shape, dtype=np.uint8))

for q in (95, 30):
    ok, buf = cv2.imencode(".jpg", img, [cv2.IMWRITE_JPEG_QUALITY, q])
    dec = cv2.imdecode(buf, cv2.IMREAD_COLOR)
    print("jpg", q, buf.size < img.size, np.abs(dec.astype(int) - img).mean() > 0)   # 작아짐, 오차 있음
ok, buf = cv2.imencode(".png", img)
print("png", np.array_equal(cv2.imdecode(buf, cv2.IMREAD_COLOR), img))              # png True  무손실

mask = np.zeros((64, 64), np.uint8); cv2.circle(mask, (30, 33), 17, 2, -1)         # 분할 라벨 (0=배경, 2=물체)
ok, buf = cv2.imencode(".jpg", mask)
dec = cv2.imdecode(buf, cv2.IMREAD_GRAYSCALE)
print(np.unique(dec).tolist(), (dec != mask).sum())                                 # [0, 1, 2, 3] 115  없는 라벨이 생김
```
