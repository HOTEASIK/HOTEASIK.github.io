# 영상 = 행렬

## 정의·핵심
- **핵심**: OpenCV(Python)에서 영상은 **NumPy 배열(행렬)** 그 자체. 픽셀 = 배열의 원소 (응용 1차시)
- **차원 (강의)**
  - 1차원 = **높이**(세로, 위↔아래), 2차원 = **너비**(가로, 좌↔우), 3차원 = **채널**(색상 B·G·R)
  - 흑백 = 2차원 `[높이][너비]`, 컬러 = 3차원 `[높이][너비][3]`
  - 비유: 아파트 주소 — 호수(1차원) → 층·호수(2차원) → 동·층·호수(3차원)
- **uint8 (강의)**: **u**nsigned(음수 없음) + **8**bit → 2⁸ = 256가지 → **0~255**. 0 = 검정(어두움), 255 = 흰색(밝음)
- **좌표 주의**
  - 배열 인덱스는 **`img[y, x]` (행, 열)** 순서
  - OpenCV 함수의 점·크기 인자는 **`(x, y)`, `(width, height)`** 순서 — `cv2.circle(img, (x, y), ...)`, `cv2.resize(img, (w, h))`
  - `img.shape` = `(h, w, c)`
- **ROI (Region of Interest, 관심 영역)**: 슬라이싱으로 일부만 선택 `roi = img[y1:y2, x1:x2]`
  - 슬라이싱은 **뷰(view)** — roi를 바꾸면 원본도 바뀐다. 독립된 복사본이 필요하면 `.copy()` → [[얕은 복사·깊은 복사]]
  - ROI에만 처리(블러·모자이크·붙여넣기)하는 데 유용
- **자주 쓰는 연산**
  - 빈 영상: `np.zeros((h, w, 3), np.uint8)`, 흰 영상: `np.full((h, w, 3), 255, np.uint8)`
  - 채널 접근: `img[..., 0]`(B), `img[:, :, 2]`(R)
  - 픽셀 수정: `img[10, 20] = (0, 0, 255)` (빨강)
  - **연산 시 오버플로 주의**: NumPy uint8 덧셈은 256에서 0으로 **순환** → 계산은 float/int로 하고 `clip` 후 다시 uint8 (강의 Tips: "연산 시 float 변환 후 다시 uint8로 복원") → [[덧셈·뺄셈]]

## 수식·원리
```
img.shape = (H, W, C),  img[y, x] = [B, G, R]
ROI = img[y1:y2, x1:x2]   (뷰 — 원본 공유)
값 개수 = H · W · C
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((4, 6, 3), np.uint8)          # 높이 4, 너비 6
img[1, 4] = (0, 0, 255)                      # y=1, x=4 픽셀을 빨강(BGR)
print(img.shape, img.dtype, img[1, 4].tolist())   # (4, 6, 3) uint8 [0, 0, 255]
cv2.circle(img, (4, 1), 0, (0, 255, 0), -1)  # 함수 좌표는 (x, y)
print(img[1, 4].tolist())                    # [0, 255, 0]  같은 픽셀

roi = img[0:2, 3:6]                          # ROI (뷰)
roi[:] = 255
print(img[0, 5].tolist())                    # [255, 255, 255]  원본도 바뀜
safe = img[2:4, 0:2].copy(); safe[:] = 7
print(img[3, 1].tolist())                    # [0, 0, 0]  copy는 원본 그대로

a = np.array([250], np.uint8)
print((a + 10)[0], np.clip(a.astype(int) + 10, 0, 255).astype(np.uint8)[0])   # 4 255  순환 vs 포화
```
