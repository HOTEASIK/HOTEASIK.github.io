# 절대값 차이

## 정의·핵심
- **정의**: `cv2.absdiff(src1, src2)` — 두 영상의 **픽셀별 차이의 절대값** `|src1 − src2|`. Motion Detection (응용 1차시)
- **목적 (강의)**: **이전 프레임과 현재 프레임의 변화 감지**, CCTV 등에서 **움직이는 물체 검출**
- **왜 subtract가 아니라 absdiff인가**: 단순 뺄셈은 음수가 **0으로 잘려** 한쪽 방향의 변화만 남는다. 절대값 차이는 변화량 그 자체를 **양수로 보존** → 밝아진 곳·어두워진 곳 모두 검출
- **모션 검출 파이프라인 (시간적 차분)**
  1. 연속 프레임을 흑백으로 변환 (+ 가우시안 블러로 잡음 제거)
  2. `diff = cv2.absdiff(prev, curr)`
  3. `cv2.threshold(diff, 25, 255, THRESH_BINARY)` → 움직인 픽셀 마스크 → [[이진화]]
  4. 팽창(dilate)으로 조각 연결 → `findContours` → 일정 면적 이상이면 움직임 → [[윤곽선]]
- **3프레임 차분**: `absdiff(f1, f2) AND absdiff(f2, f3)` → 고스트(이전 위치 잔상) 감소
- 배경 영상을 따로 두고 차이를 구하면 **배경 차분** → 조명 변화에 대응하려면 MOG2 같은 배경 모델 → [[배경 제거]]
- 그 밖: 두 사진의 **다른 그림 찾기**, 제품 불량 검사(정상 기준 영상과 비교), 영상 압축 전후 비교
- 개념적으로 **차분(Differencing)** 의 시간 버전 → [[차분(Differencing)]]

## 수식·원리
```
diff(x, y) = | I_t(x, y) − I_{t−1}(x, y) |
motion(x, y) = 255  if diff > T  else 0
```

## 코드 예시
```python
import numpy as np
import cv2

prev = np.zeros((40, 60), np.uint8)
curr = prev.copy()
cv2.rectangle(prev, (5, 10), (15, 20), 200, -1)        # 이전 프레임: 물체가 왼쪽에
cv2.rectangle(curr, (25, 10), (35, 20), 200, -1)       # 현재 프레임: 오른쪽으로 이동
print(cv2.subtract(prev, curr).max(), cv2.subtract(curr, prev).max())   # 200 200  각각 한쪽만
diff = cv2.absdiff(prev, curr)
_, motion = cv2.threshold(diff, 25, 255, cv2.THRESH_BINARY)
print(cv2.countNonZero(motion))                         # 242  이전 위치 + 현재 위치 (11*11*2)
cnts, _ = cv2.findContours(motion, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print(sorted(cv2.boundingRect(c) for c in cnts))        # [(5, 10, 11, 11), (25, 10, 11, 11)]
```
