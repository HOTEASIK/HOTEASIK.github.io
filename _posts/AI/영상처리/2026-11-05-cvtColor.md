# cvtColor

## 정의·핵심
- **정의**: `cv2.cvtColor(src, code)` — 영상을 **다른 색공간으로 변환**하는 OpenCV 함수 (응용 1차시)
- **자주 쓰는 변환 코드**
  - `cv2.COLOR_BGR2GRAY`: 컬러 → **흑백** (3채널 → 1채널). 엣지·코너·이진화 등 대부분의 특징 검출 전처리
  - `cv2.COLOR_BGR2RGB`: matplotlib·PIL·딥러닝 모델 입력용 → [[RGB·BGR]]
  - `cv2.COLOR_BGR2HSV`: **색상 기반 검출·추적** → [[HSV]], [[색상 검출]]
  - `cv2.COLOR_BGR2HLS`, `COLOR_BGR2YCrCb`, `COLOR_BGR2Lab`
  - `cv2.COLOR_GRAY2BGR`: 흑백을 3채널로 (컬러 도형·글자를 위에 그리거나 3채널 모델에 넣을 때). 값은 세 채널 동일
  - 역방향: `COLOR_HSV2BGR`, `COLOR_RGB2BGR` 등
- **흑백 변환 공식**: `Y = 0.299R + 0.587G + 0.114B` — 사람 눈이 초록에 가장 민감해서 G의 가중치가 크다. 단순 평균과 다르다
- **주의**
  - 입력 채널 수가 코드와 맞아야 한다 (이미 흑백인 영상에 `BGR2GRAY` → 오류)
  - **입력이 RGB인데 `BGR2...` 코드를 쓰면** 결과가 틀린다 (특히 HSV의 H 값). PIL로 읽은 이미지는 RGB → `COLOR_RGB2HSV`
  - float32 입력이면 범위가 달라진다 (HSV의 H가 0~360, S·V 0~1)
  - `imread(path, cv2.IMREAD_GRAYSCALE)`로 읽으면 처음부터 흑백

## 수식·원리
```
GRAY = 0.299·R + 0.587·G + 0.114·B
GRAY2BGR: (H, W) → (H, W, 3),  B = G = R = GRAY
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((2, 3, 3), np.uint8)
img[0] = [(255, 0, 0), (0, 255, 0), (0, 0, 255)]               # 파랑, 초록, 빨강 (BGR)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(gray.shape, gray[0].tolist())                             # (2, 3) [29, 150, 76]  초록이 가장 밝게
print(img[0].mean(axis=1).astype(int).tolist())                 # [85, 85, 85]  단순 평균과 다름
back = cv2.cvtColor(gray, cv2.COLOR_GRAY2BGR)
print(back.shape, back[0, 1].tolist())                          # (2, 3, 3) [150, 150, 150]
hsv_ok = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)[0, 0, 0]
hsv_wrong = cv2.cvtColor(img, cv2.COLOR_RGB2HSV)[0, 0, 0]       # 순서를 잘못 지정하면
print(hsv_ok, hsv_wrong)                                        # 120 0  파랑이 빨강으로
try:
    cv2.cvtColor(gray, cv2.COLOR_BGR2GRAY)
except cv2.error:
    print("채널 수 불일치 오류")                                 # 채널 수 불일치 오류
```
