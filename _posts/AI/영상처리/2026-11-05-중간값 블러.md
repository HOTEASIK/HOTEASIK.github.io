# 중간값 블러

## 정의·핵심
- **정의**: Median Blur. 커널 영역의 픽셀들을 **정렬해서 중앙값**을 고르는 필터 (응용 2차시)
- **함수**: `cv2.medianBlur(img, ksize)` — ksize는 **1보다 큰 홀수 정수** 하나 (3, 5, 7…). 튜플이 아님
- **소금-후추 잡음(Salt-and-Pepper)에 탁월 (강의)**
  - 소금-후추 잡음: 픽셀이 무작위로 **0(검정)이나 255(흰색)** 로 튀는 잡음 (센서 결함, 전송 오류)
  - 평균 블러는 극단값이 평균에 섞여 **얼룩으로 번지지만**, 중간값은 극단값을 **정렬 양 끝으로 밀어내** 완전히 제거
- **엣지 보존**: 계단 모양 경계에서 중앙값은 한쪽 값을 그대로 고르므로 경계가 **덜 뭉개진다** (선형 필터가 아님)
- **단점**
  - 정렬이 필요해 평균·가우시안보다 느리다 (큰 커널일수록)
  - 커널이 크면 **가는 선·모서리 같은 디테일이 사라진다** (커널의 절반보다 얇은 구조 제거)
  - 가우시안 잡음(전체적으로 조금씩 흔들림)에는 가우시안 블러가 더 적합
- **활용**: 스캔 문서·오래된 사진 잡음, 이진 마스크의 작은 점 제거, 깊이 맵 잡음

## 수식·원리
```
dst(x, y) = median{ src(i, j) : (i, j) ∈ 영역(x, y) }
예: [10, 12, 255, 11, 13, 0, 12, 11, 10] → 정렬 → 중앙값 11
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
clean = np.full((60, 60), 120, np.uint8)
noisy = clean.copy()
r = rng.random(clean.shape)
noisy[r < 0.05] = 0; noisy[r > 0.95] = 255                 # 소금-후추 잡음 10%
err = lambda x: round(np.abs(x.astype(int) - clean).mean(), 2)
print(err(noisy), err(cv2.blur(noisy, (3, 3))), err(cv2.medianBlur(noisy, 3)))   # 13.12 9.42 0.0  원본, 평균(번짐), 중간값(완전 제거)

edge = np.array([[0, 0, 0, 200, 200, 200]] * 3, np.uint8)
print(cv2.medianBlur(edge, 3)[1].tolist(), cv2.blur(edge, (3, 3))[1].tolist())
# [0, 0, 0, 200, 200, 200] [0, 0, 67, 133, 200, 200]   ← 중간값은 엣지 보존
```
