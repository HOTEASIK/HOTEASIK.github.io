# 특징점·디스크립터 매칭

## 정의·핵심
- **정의**: 두 영상에서 **특징점(Keypoint)** 을 찾고, 각 점 주변을 숫자 벡터인 **디스크립터(Descriptor)** 로 표현한 뒤, **디스크립터 거리가 가까운 점끼리 짝지어** 같은 물체·장면을 찾는 기법 (응용 4차시)
- **3단계 (강의)**: **특징점 검출 → 디스크립터 계산 → 매칭**
  - 특징점: 코너처럼 **주변과 구별되고 반복 검출 가능한 점** → [[Harris 코너 검출]], [[Shi-Tomasi]]
  - 디스크립터: 점 주변 패치의 그래디언트·밝기 패턴을 요약한 벡터 → 같은 점이면 다른 영상에서도 비슷한 벡터
- **템플릿 매칭과 비교**: 템플릿은 픽셀 전체 비교라 회전·크기에 약함 ↔ 특징점 매칭은 **회전·크기·밝기 변화에 강함 (강의)**
- **대표 알고리즘**

| 알고리즘 | 디스크립터 | 거리 | 특징 |
|---|---|---|---|
| **SIFT** | 128차원 float (그래디언트 히스토그램) | L2 | 크기·회전 불변, 정확, 느림 (특허 만료 → `cv2.SIFT_create`) |
| **ORB** | 256bit 이진 (FAST + rotated BRIEF) | **Hamming** | **빠름, 무료**, 실시간용 |
| SURF | 64/128 float | L2 | contrib (특허) |

- **매칭기**
  - `cv2.BFMatcher(normType, crossCheck)`: **Brute-Force**(전부 비교). ORB → `NORM_HAMMING`, SIFT → `NORM_L2`
  - `crossCheck=True`: A→B와 B→A가 서로 최근접일 때만 인정
  - `FlannBasedMatcher`: 근사 최근접, 대용량에서 빠름
  - `knnMatch(k=2)` + **Lowe의 비율 테스트**: 1등 거리 < 0.75 × 2등 거리일 때만 채택 → 애매한 매칭 제거
- **후속**: 좋은 매칭점으로 `cv2.findHomography(src, dst, cv2.RANSAC)` → 물체 위치 사각형·파노라마 스티칭 → [[투시 변환]]
- 시각화: `cv2.drawKeypoints`, `cv2.drawMatches`
- **활용**: 물체 인식(책 표지·로고), 파노라마, 영상 정합, SLAM·Visual Odometry, AR 마커리스 추적

## 수식·원리
```
Hamming(a, b) = popcount(a XOR b)      (ORB 이진 디스크립터)
L2(a, b) = ||a − b||₂                   (SIFT)
비율 테스트: d1 / d2 < 0.75 → 좋은 매칭
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(1)
img1 = np.zeros((200, 200), np.uint8)
for _ in range(25):                                              # 무작위 도형으로 텍스처 생성
    x, y = rng.integers(10, 180, 2)
    cv2.rectangle(img1, (int(x), int(y)), (int(x) + 15, int(y) + 10), int(rng.integers(80, 256)), -1)
img1 = cv2.GaussianBlur(img1, (3, 3), 0)
M = cv2.getRotationMatrix2D((100, 100), 30, 1.0)                 # 30° 회전한 영상
img2 = cv2.warpAffine(img1, M, (200, 200))

orb = cv2.ORB_create(500)
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)
print(des1.shape[1], des1.dtype)                                 # 32 uint8  (32바이트 = 256bit)
bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = sorted(bf.match(des1, des2), key=lambda m: m.distance)
src = np.float32([kp1[m.queryIdx].pt for m in matches]).reshape(-1, 1, 2)
dst = np.float32([kp2[m.trainIdx].pt for m in matches]).reshape(-1, 1, 2)
H, inl = cv2.findHomography(src, dst, cv2.RANSAC, 3.0)
print(len(matches) > 20, inl.sum() > 20)                         # True True  회전에도 매칭 성공
p = cv2.perspectiveTransform(np.float32([[[150, 100]]]), H).ravel()
q = cv2.transform(np.float32([[[150, 100]]]), M).ravel()
print(np.allclose(p, q, atol=2))                                 # True  추정한 H ≈ 실제 회전
print(hasattr(cv2, "SIFT_create"))                               # True
```
