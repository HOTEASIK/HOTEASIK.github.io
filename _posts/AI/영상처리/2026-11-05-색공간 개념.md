# 색공간 개념

## 정의·핵심
- **정의**: 색공간(Color Space) = **색을 수치적으로 표현하기 위한 좌표계**. 작업 목적에 따라 색을 더 잘 추출·표현할 수 있는 색공간을 골라야 한다 (응용 1차시)
- **주요 색공간 (강의)**
  - **RGB (Red-Green-Blue)**: 빛의 삼원색을 섞는 **가산 혼합**. 모니터·카메라 등 **디스플레이 장치**의 기본. **조명 변화에 매우 민감** → [[RGB·BGR]]
  - **HSV (Hue-Saturation-Value)**: 색상·채도·명도. **색상 정보(H)가 밝기(V)와 분리** → 조명이 바뀌어도 H는 유지 → 컴퓨터 비전의 **색상 기반 분할**에 자주 사용 → [[HSV]]
  - **HSL (Hue-Saturation-Lightness)**: 색상·채도·밝기. **인간의 색 인지 방식과 유사**하고 직관적 → [[HSL]]
- **RGB vs HSV 비교 (강의)**
  - 표현: RGB는 세 색을 **섞어서** 결과를 만듦(기계적) / HSV는 '**어떤 색**인지', '**얼마나 진한지**', '**얼마나 밝은지**'로 구분(직관적)
  - 조명: RGB는 조명이 바뀌면 R·G·B **모두 변함** / HSV는 **V만 변하고 H는 유지**
  - 활용: RGB는 웹 디자인·이미지 표시·디스플레이 / HSV는 **객체 추적, 피부색 검출, 특정 색상 영역 분리**
  - Tip: "**파란색 공을 찾으려면 RGB보다 HSV가 훨씬 쉽다!**"
- **그 밖의 색공간**
  - **Grayscale**: 밝기 1채널 (엣지·특징 검출 전처리)
  - **YCrCb / YUV**: 밝기(Y) + 색차(Cr, Cb). JPEG·영상 압축, 피부색 검출
  - **Lab (CIELAB)**: 사람이 느끼는 색 차이와 거리가 비례 → 색 차이 측정, 색 보정
- **변환**: `cv2.cvtColor(img, cv2.COLOR_BGR2HSV)` 등 → [[cvtColor]]

## 수식·원리
```
Gray = 0.299·R + 0.587·G + 0.114·B          (사람 눈은 G에 가장 민감)
Y = 0.299R + 0.587G + 0.114B,  Cr = (R − Y)·0.713 + 128,  Cb = (B − Y)·0.564 + 128
```

## 코드 예시
```python
import numpy as np
import cv2

blue_bright = np.uint8([[[200, 50, 30]]])        # BGR: 밝은 파랑
blue_dark = (blue_bright * 0.5).astype(np.uint8) # 조명이 절반으로 어두워짐
for name, px in [("bright", blue_bright), ("dark", blue_dark)]:
    print(name, "BGR", px[0, 0].tolist(), "HSV", cv2.cvtColor(px, cv2.COLOR_BGR2HSV)[0, 0].tolist())
# bright BGR [200, 50, 30] HSV [116, 217, 200]
# dark BGR [100, 25, 15] HSV [116, 217, 100]   ← RGB는 셋 다 변했지만 H(116)·S는 그대로, V만 절반
print(cv2.cvtColor(blue_bright, cv2.COLOR_BGR2GRAY)[0, 0])   # 61
print(round(0.299 * 30 + 0.587 * 50 + 0.114 * 200))           # 61  공식으로 직접 계산(R=30, G=50, B=200)
```
