# Canny 엣지 검출

## 정의·핵심
- **정의**: John Canny(1986)의 다단계 엣지 검출 알고리즘. 목표: **노이즈 억제 + 정확한 엣지 검출 + 단일 엣지 응답(한 픽셀 두께)** (응용 3차시)
- **5단계 (강의)**
  1. **노이즈 제거 — Gaussian Blur**: 잡음을 부드럽게 만들어 오검출 방지 → [[가우시안 블러]]
  2. **그래디언트 계산 — Sobel**: 각 픽셀의 밝기 **변화량(강도)과 방향(각도)** 계산 → [[Sobel 필터]]
  3. **비최대 억제 (Non-Max Suppression)**: 엣지 **방향(그래디언트 방향)** 으로 이웃과 비교해 **로컬 최댓값만 남기고** 나머지 제거 → 엣지를 **얇게**(1픽셀)
  4. **이중 임계값 (Double Threshold)**: High/Low 임계값으로 **Strong Edge**(> High)와 **Weak Edge**(Low~High) 분류, Low 미만은 버림
  5. **엣지 추적 (Edge Tracking by Hysteresis)**: Strong Edge와 **연결된 Weak Edge만** 최종 엣지로 보존 → 끊긴 선은 잇고, 고립된 잡음은 제거
- **함수**: `edges = cv2.Canny(img, threshold1, threshold2)` — 강의 예 `cv2.Canny(img, 100, 200)`
  - threshold1 = Low, threshold2 = High. 결과는 0/255 이진 영상
  - **1:2 ~ 1:3 비율**이 흔한 권장 (Canny 원 논문)
  - `apertureSize`(Sobel 크기, 기본 3), `L2gradient=True`(정확한 크기 √ 사용)
  - 내부에 블러가 약하므로 잡음이 많으면 **먼저 GaussianBlur** 하는 것이 보통
- **임계값 자동 설정 요령**: 중앙값 m 기준 `low = 0.66·m`, `high = 1.33·m` 또는 Otsu 임계값의 0.5배/1배
- **활용**: 윤곽선 찾기 전처리, **허프 변환의 입력**, 차선 검출, 문서 테두리 검출 → [[Hough 변환]], [[윤곽선]]

## 수식·원리
```
1) I_s = G_σ ⊛ I
2) |G| = √(Gx² + Gy²),  θ = atan2(Gy, Gx)  (0°, 45°, 90°, 135°로 양자화)
3) |G|(p) < 방향상 이웃의 |G| 이면 0
4) strong: |G| > High,  weak: Low < |G| ≤ High
5) weak 중 strong과 8-연결된 것만 유지
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((60, 60), np.uint8)
cv2.rectangle(img, (15, 15), (45, 45), 200, -1)
rng = np.random.default_rng(0)
noisy = cv2.add(img, rng.integers(0, 40, img.shape, dtype=np.uint8))
e_raw = cv2.Canny(noisy, 100, 200)
e_blur = cv2.Canny(cv2.GaussianBlur(noisy, (5, 5), 1.4), 100, 200)
print(np.unique(e_blur).tolist())                          # [0, 255]  이진 결과
print(cv2.countNonZero(e_raw) >= cv2.countNonZero(e_blur))  # True  블러를 먼저 하면 잡음 엣지가 줄어듦
print(e_blur[30, 13:18].tolist())                          # [0, 0, 255, 0, 0]  경계에서 1픽셀 두께 엣지
m = np.median(noisy)
print(int(0.66 * m), int(1.33 * m))                        # 17 35  중앙값 기반 자동 임계값
```
