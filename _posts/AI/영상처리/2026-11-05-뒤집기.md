# 뒤집기

## 정의·핵심
- **정의**: Flip. 영상을 **좌우 또는 상하로 대칭(거울) 반전**하는 변환. 보간이 필요 없어 **정확하고 빠르다** (응용 2차시)
- **OpenCV: `cv2.flip(src, flipCode)`**
  - `flipCode = 1`: **좌우 반전** (y축 기준, 거울 모드)
  - `flipCode = 0`: **상하 반전** (x축 기준)
  - `flipCode = -1`: **좌우 + 상하** (= 180° 회전)
- **NumPy 대안**: `img[:, ::-1]`(좌우), `img[::-1]`(상하), `np.fliplr`, `np.flipud` — 뷰라서 빠르지만 음수 stride → 일부 함수에서 `.copy()` 필요
- **활용**
  - **웹캠 거울 모드**: `frame = cv2.flip(frame, 1)` — 사용자가 보기에 자연스럽게
  - **데이터 증강**: `RandomHorizontalFlip(p=0.5)` — 가장 흔한 증강 (강의 13차시 CIFAR 파인튜닝도 좌우 반전 p=0.5)
  - **주의**: 좌우 반전이 **의미를 바꾸는 데이터**에는 쓰면 안 된다 — 글자·숫자(OCR), 좌/우 구분이 있는 표지판, 흉부 X-ray(심장 위치) → 상하 반전도 대부분의 자연 사진에는 부적절
  - 라벨도 함께: 바운딩 박스 `x' = W − x − w`, 키포인트 좌우 이름 교환(왼눈↔오른눈)

## 수식·원리
```
좌우 (flipCode=1):  dst(x, y) = src(W − 1 − x, y)
상하 (flipCode=0):  dst(x, y) = src(x, H − 1 − y)
둘 다 (−1):         dst(x, y) = src(W − 1 − x, H − 1 − y)
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.arange(6).reshape(2, 3)
print(cv2.flip(img, 1).tolist())                         # [[2, 1, 0], [5, 4, 3]]  좌우
print(cv2.flip(img, 0).tolist())                         # [[3, 4, 5], [0, 1, 2]]  상하
print(cv2.flip(img, -1).tolist())                        # [[5, 4, 3], [2, 1, 0]]  둘 다
print(np.array_equal(cv2.flip(img, -1), cv2.rotate(img, cv2.ROTATE_180)))   # True  = 180° 회전
print(np.array_equal(cv2.flip(img, 1), img[:, ::-1]))    # True

W, (x, y, w, h) = 100, (10, 20, 30, 40)                  # 바운딩 박스도 같이 반전
print((W - x - w, y, w, h))                              # (60, 20, 30, 40)
```
