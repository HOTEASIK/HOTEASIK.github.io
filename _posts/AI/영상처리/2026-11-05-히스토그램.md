# 히스토그램

## 정의·핵심
- **정의**: 영상의 각 픽셀 값(0~255)이 **몇 개씩 있는지** 센 분포 그래프. 가로축 = 밝기 값, 세로축 = 픽셀 수 (응용 1차시 "히스토그램 분석: 영상의 밝기 분포를 분석")
- **읽는 법**
  - 왼쪽에 몰림 → **어두운** 영상 / 오른쪽에 몰림 → **밝은** 영상
  - 가운데 좁게 몰림 → **대비가 낮은**(뿌연) 영상 / 넓게 퍼짐 → 대비가 높음
  - 0이나 255에 막대가 솟음 → 노출 부족/과다로 **정보가 잘림**(clipping)
  - 봉우리 두 개(쌍봉) → 전경·배경이 뚜렷 → **Otsu 이진화**가 잘 동작 → [[Otsu 이진화]]
- **OpenCV: `cv2.calcHist(images, channels, mask, histSize, ranges)`**
  - 인자가 모두 **리스트**: `cv2.calcHist([img], [0], None, [256], [0, 256])`
  - 결과 `(256, 1)` float32 (OpenCV 5.0은 `(256,)`) → `hist.ravel()`로 쓰면 버전과 무관
  - `channels`: 컬러면 `[0]`(B), `[1]`(G), `[2]`(R) 각각 / HSV의 H만이면 `[0]` + `[180]`, `[0, 180]`
  - `mask`: 특정 영역만의 히스토그램
  - 2D 히스토그램(H-S)도 가능 → 역투영·추적에 사용 → [[역투영(Back Projection)]]
- NumPy: `np.histogram(img.ravel(), 256, [0, 256])`, `np.bincount(img.ravel(), minlength=256)`
- **활용**: 노출·대비 진단, 정규화·평활화, 임계값 결정, 색 기반 추적(MeanShift·CamShift), 영상 유사도 비교(`cv2.compareHist`)

## 수식·원리
```
h(k) = #{ (x, y) : I(x, y) = k },   k = 0 … 255
Σ_k h(k) = H · W
정규화 히스토그램 p(k) = h(k) / (H·W)   (확률 분포)
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
dark = np.clip(rng.normal(60, 15, (100, 100)), 0, 255).astype(np.uint8)    # 어두운 영상
hist = cv2.calcHist([dark], [0], None, [256], [0, 256])
hist = hist.ravel()                                         # 버전 차이 흡수
print(hist.shape, int(hist.sum()), int(hist.argmax()))      # (256,) 10000 56  최빈값 60 근처
print(int(hist[:128].sum()) / 10000)                        # 1.0  모두 왼쪽 절반(어두움)
print(np.array_equal(hist.astype(int), np.bincount(dark.ravel(), minlength=256)))   # True

img = np.zeros((10, 10, 3), np.uint8); img[:5] = (255, 0, 0)
for c, name in enumerate("BGR"):
    h = cv2.calcHist([img], [c], None, [256], [0, 256]).ravel()
    print(name, int(h[0]), int(h[255]))                     # B 50 50 / G 100 0 / R 100 0
mask = np.zeros((10, 10), np.uint8); mask[:5] = 255
print(int(cv2.calcHist([img], [0], mask, [256], [0, 256]).ravel()[255]))   # 50  마스크 영역만
```
