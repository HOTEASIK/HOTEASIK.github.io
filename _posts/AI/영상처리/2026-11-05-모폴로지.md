# 모폴로지

## 정의·핵심
- **정의**: Morphology(형태학) 연산. 주로 **이진 영상**에서 **구조 요소(커널)** 로 물체의 **모양을 깎거나 넓혀** 다듬는 연산 (응용 2차시)
- **구조 요소**: `cv2.getStructuringElement(cv2.MORPH_RECT | MORPH_ELLIPSE | MORPH_CROSS, (k, k))` 또는 `np.ones((k, k), np.uint8)`
- **기본 연산 (강의 표)**
  - **침식 (Erosion) `cv2.erode`**: 객체 외곽을 **깎아냄** → 작은 노이즈 제거, 붙은 영역 분리. 커널 안에 0이 하나라도 있으면 0 (영역 최솟값)
  - **팽창 (Dilation) `cv2.dilate`**: 객체 외곽을 **확장** → 구멍 메우기, 끊어진 영역 연결. 커널 안에 255가 하나라도 있으면 255 (영역 최댓값)
  - **열기 (Opening) = 침식 → 팽창** `morphologyEx(MORPH_OPEN)`: **배경의 작은 밝은 점(노이즈) 제거**, 얇은 돌출부 제거, 독립된 개체 분리. 큰 물체 크기는 거의 유지
  - **닫기 (Closing) = 팽창 → 침식** `morphologyEx(MORPH_CLOSE)`: **객체 내부의 작은 검은 구멍을 메움**, 끊어진 요소 연결
- **그 밖 (`morphologyEx`)**
  - `MORPH_GRADIENT` = 팽창 − 침식 → **외곽선**
  - `MORPH_TOPHAT` = 원본 − 열기 → 밝은 작은 디테일 / `MORPH_BLACKHAT` = 닫기 − 원본 → 어두운 작은 디테일
- `iterations=n`: 반복 횟수 (커널을 키우는 것과 비슷한 효과)
- **활용**: 이진화·inRange 마스크 정리(→ findContours 전 필수 단계), 문자 분리·연결, 모션 차분 조각 잇기, 분할 결과 후처리
- 흑백(그레이) 영상에도 적용 가능 — 침식 = 지역 최솟값, 팽창 = 지역 최댓값

## 수식·원리
```
erode(x)  = min_{(i,j)∈K} src(x + i, y + j)
dilate(x) = max_{(i,j)∈K} src(x + i, y + j)
open  = dilate(erode(src)),   close = erode(dilate(src))
gradient = dilate − erode
```

## 코드 예시
```python
import numpy as np
import cv2

k = np.ones((3, 3), np.uint8)
img = np.zeros((20, 20), np.uint8)
img[5:15, 5:15] = 255                              # 10x10 물체 (100픽셀)
img[1, 1] = 255                                    # 바깥 잡음 점
img[9, 9] = 0                                      # 안쪽 구멍
cnt = cv2.countNonZero
print(cnt(img), cnt(cv2.erode(img, k)), cnt(cv2.dilate(img, k)))   # 100 55 153  깎임 / 넓어짐
opened = cv2.morphologyEx(img, cv2.MORPH_OPEN, k)
closed = cv2.morphologyEx(img, cv2.MORPH_CLOSE, k)
print(opened[1, 1], closed[9, 9])                  # 0 255  열기: 잡음 점 제거, 닫기: 구멍 메움
grad = cv2.morphologyEx(img, cv2.MORPH_GRADIENT, k)
print(grad[12, 12], grad[5, 12])                   # 0 255  내부는 0, 경계만 남음
print(cv2.getStructuringElement(cv2.MORPH_CROSS, (3, 3)).tolist())   # [[0, 1, 0], [1, 1, 1], [0, 1, 0]]
```
