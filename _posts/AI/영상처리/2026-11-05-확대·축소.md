# 확대·축소

## 정의·핵심
- **정의**: Scaling. 영상의 좌표를 **일정 비율로 늘리거나 줄이는** 변환 (응용 2차시)
- **목적 (강의)**: **해상도 변화**, 데이터 증강, 객체 크기 보정 / 딥러닝 입력 크기 맞추기(224×224 등)
- **보간이 필수 (강의)**: 확대·축소 시 픽셀 값을 복사하는 것이므로 **'비는 공간(손실)'에 대한 보간**이 필요 → nearest, linear, cubic 등 → [[보간법]]
- **OpenCV: `cv2.resize(src, dsize, fx, fy, interpolation)`**
  - 절대 크기: `cv2.resize(img, (width, height))` — **(너비, 높이)** 순서
  - 비율: `cv2.resize(img, None, fx=0.5, fy=0.5)` (dsize=None)
  - `interpolation`: 기본 `INTER_LINEAR`
  - **권장 (강의 Tips)**: **확대는 CUBIC/LINEAR, 축소는 AREA**. 속도가 중요하면 LINEAR, 품질은 CUBIC
- **비율 유지 리사이즈**: 긴 변 기준 scale = `target / max(h, w)` → 남는 부분은 패딩(**letterbox**, YOLO 입력 방식)
- 아핀 행렬로도 가능: `M = [[sx, 0, 0], [0, sy, 0]]` + `warpAffine` (중심 기준 확대는 `getRotationMatrix2D(center, 0, scale)`)
- **주의**
  - 축소할 때 NEAREST/LINEAR로 크게 줄이면 **에일리어싱**(계단·모아레) → AREA 사용 → [[샘플링·양자화]]
  - 라벨(마스크)은 **NEAREST**로 리사이즈해야 클래스 값이 섞이지 않는다
  - 바운딩 박스 좌표도 같은 비율로 변환

## 수식·원리
```
x' = sx · x,   y' = sy · y
M = [[sx, 0, 0],
     [0, sy, 0]]
dsize = (round(w·fx), round(h·fy))
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.arange(16, dtype=np.uint8).reshape(4, 4) * 16
big = cv2.resize(img, (8, 8))                                    # (너비, 높이)
small = cv2.resize(img, None, fx=0.5, fy=0.5, interpolation=cv2.INTER_AREA)
print(big.shape, small.shape)                                    # (8, 8) (2, 2)
print(small.tolist())                                            # [[40, 72], [168, 200]]  2x2 영역 평균
print(cv2.resize(np.zeros((480, 640, 3), np.uint8), (224, 224)).shape)   # (224, 224, 3)

mask = np.zeros((4, 4), np.uint8); mask[:, 2:] = 3              # 라벨 0과 3
print(np.unique(cv2.resize(mask, (7, 7), interpolation=cv2.INTER_LINEAR)).tolist())    # [0, 1, 2, 3]  중간값이 생김
print(np.unique(cv2.resize(mask, (7, 7), interpolation=cv2.INTER_NEAREST)).tolist())   # [0, 3]  라벨 유지

h, w, target = 300, 500, 224                                     # 비율 유지 (letterbox)
s = target / max(h, w)
print(round(w * s), round(h * s))                                # 224 134  → 위아래 패딩
```
