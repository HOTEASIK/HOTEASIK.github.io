# 영상 입출력

## 정의·핵심
- **읽기: `cv2.imread(path, flag)`** → NumPy 배열 `(H, W, 3)` `uint8`, **BGR 순서** (응용 1차시)
  - `cv2.IMREAD_COLOR` (1, 기본): 3채널 컬러 (알파 제거)
  - `cv2.IMREAD_GRAYSCALE` (0): 흑백 1채널 `(H, W)`
  - `cv2.IMREAD_UNCHANGED` (−1): 알파 채널·16bit 그대로
  - **실패해도 오류를 내지 않고 `None`을 반환** → 반드시 `if img is None:` 확인 (경로 오타가 가장 흔한 버그)
  - **한글 경로를 못 읽는 경우**(Windows): `cv2.imdecode(np.fromfile(path, np.uint8), cv2.IMREAD_COLOR)`
- **쓰기: `cv2.imwrite(path, img, params)`** → 성공 여부 `True/False`. 확장자로 형식 결정
  - JPG 품질: `[cv2.IMWRITE_JPEG_QUALITY, 0~100]` (기본 95), PNG 압축: `[cv2.IMWRITE_PNG_COMPRESSION, 0~9]` → [[이미지 파일 형식]]
  - 한글 경로: `ok, buf = cv2.imencode(".jpg", img); buf.tofile(path)`
- **보기: `cv2.imshow(winname, img)` + `cv2.waitKey(ms)`**
  - `waitKey(0)`: 키 입력까지 무한 대기, `waitKey(1)`: 1ms (동영상 루프), 반환값 = 눌린 키 코드 (`& 0xFF == ord('q')`)
  - **waitKey가 없으면 창이 그려지지 않는다** (이벤트 처리를 waitKey가 함)
  - `cv2.destroyAllWindows()`로 창 닫기
  - **Colab·Jupyter에서는 imshow 불가** → `google.colab.patches.cv2_imshow` 또는 **matplotlib** 사용. 이때 **BGR → RGB 변환** 필수 (강의: "colab에서는 matplotlib에 이미지 표현을 맡김") → [[imshow]]
- **opencv-python의 특징 (강의)**: 픽셀 값을 **NumPy 배열로 표현** → 슬라이싱·연산을 그대로 사용 → [[영상 = 행렬]]

## 수식·원리
```
imread(color)     → (H, W, 3) uint8, BGR
imread(grayscale) → (H, W)    uint8
imread(실패)       → None
```

## 코드 예시
```python
import os, tempfile
import numpy as np
import cv2

img = np.zeros((100, 200, 3), np.uint8)
img[:, :100] = (255, 0, 0)                               # 왼쪽 절반 파랑 (BGR!)
path = os.path.join(tempfile.mkdtemp(), "test.png")
print(cv2.imwrite(path, img))                            # True
color = cv2.imread(path)                                 # 기본 IMREAD_COLOR
gray = cv2.imread(path, cv2.IMREAD_GRAYSCALE)
print(color.shape, color.dtype, gray.shape)              # (100, 200, 3) uint8 (100, 200)
print(color[0, 0].tolist(), gray[0, 0])                  # [255, 0, 0] 29  파랑의 밝기는 낮음
print(cv2.imread("없는파일.jpg") is None)                # True  오류 없이 None
ok, buf = cv2.imencode(".jpg", img); print(ok, buf.dtype)   # True uint8  (한글 경로 저장용: buf.tofile(path))
# cv2.imshow("win", img); key = cv2.waitKey(0); cv2.destroyAllWindows()   ← 로컬 GUI에서만
```
