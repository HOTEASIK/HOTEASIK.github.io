# 밝기·대비 조절

## 정의·핵심
- **밝기(Brightness)**: 모든 픽셀에 **같은 값을 더하거나 빼서** 전체를 밝게/어둡게 → 히스토그램이 좌우로 **이동**
- **대비(Contrast)**: 밝은 곳과 어두운 곳의 **차이**. 픽셀 값에 **곱해서** 조절 → 히스토그램이 **넓어지거나 좁아짐**
  - α > 1: 대비 증가(또렷), 0 < α < 1: 대비 감소(뿌옇게)
- **선형 변환**: `dst = α·src + β` (α: 대비 gain, β: 밝기 bias)
- **OpenCV 함수**
  - `cv2.convertScaleAbs(src, alpha=α, beta=β)`: `|α·src + β|`를 계산해 **uint8로 포화** → 밝기·대비를 한 번에 (가장 간단)
  - `cv2.multiply(src, scale)`: 곱셈 (포화 연산). 스칼라 사용 시 `cv2.add`처럼 채널 주의 → [[덧셈·뺄셈]]
  - `src.astype(np.float32) * α + β` → `np.clip` → `uint8` (강의 Tips: "연산 시 float 변환 후 다시 uint8로 복원")
- **중심 기준 대비**: `dst = src + (src − 128)·k` — 중간 밝기는 유지하고 대비만 바꿈
- **감마 보정 (비선형)**: `dst = 255·(src/255)^γ` — γ < 1이면 어두운 영역이 밝아짐(디테일 살리기), γ > 1이면 어두워짐. LUT(`cv2.LUT`)로 빠르게
- **자동 대비**: 히스토그램 정규화(min-max 늘리기)·평활화 → [[히스토그램 정규화]], [[히스토그램 평활화(Equalization)]]
- 딥러닝 데이터 증강의 ColorJitter(brightness, contrast)와 같은 원리 → [[데이터 증강]]

## 수식·원리
```
dst = saturate(α · src + β)
중심 기준: dst = saturate(src + (src − 128)·k)
감마:      dst = 255 · (src / 255)^γ
```

## 코드 예시
```python
import numpy as np
import cv2

src = np.array([[0, 64, 128, 192, 255]], np.uint8)
print(cv2.convertScaleAbs(src, alpha=1.0, beta=50).tolist())   # [[50, 114, 178, 242, 255]]  밝기 +50
print(cv2.convertScaleAbs(src, alpha=1.5, beta=0).tolist())    # [[0, 96, 192, 255, 255]]   대비 1.5배
print(cv2.multiply(src, 2).tolist())                           # [[0, 128, 255, 255, 255]]
k = 0.5
print(np.clip(src + (src.astype(int) - 128) * k, 0, 255).astype(np.uint8).tolist())   # [[0, 32, 128, 224, 255]]
lut = np.array([255 * (i / 255) ** 0.5 for i in range(256)]).astype(np.uint8)
print(cv2.LUT(src, lut).tolist())                              # [[0, 127, 180, 221, 255]]  감마 0.5: 어두운 곳 밝게
```
