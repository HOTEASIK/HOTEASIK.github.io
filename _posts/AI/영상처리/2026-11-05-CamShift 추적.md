# CamShift 추적

## 정의·핵심
- **정의**: CamShift (Continuously Adaptive Mean Shift). MeanShift로 위치를 찾은 뒤 **창의 크기와 회전 각도까지 매 프레임 적응적으로 갱신**하는 추적 알고리즘 (응용 4차시)
- **동작 5단계 (강의)**
  1. **HSV 변환 + Hue 히스토그램**: ROI의 색상(Hue) 분포 모델
  2. **역투영**: 확률 맵 생성 → [[역투영(Back Projection)]]
  3. **MeanShift**: 창을 질량 중심으로 이동해 수렴 → [[MeanShift 추적]]
  4. **크기·각도 갱신**: 창 안 확률 분포의 **2차 모멘트**로 물체의 크기·방향(타원)을 계산해 창을 재조정
  5. **반복**: 다음 프레임에서 갱신된 창으로 다시 시작
- **OpenCV**
  ```
  rot_rect, track_window = cv2.CamShift(dst, track_window, term)
  pts = cv2.boxPoints(rot_rect)          # ((cx, cy), (w, h), angle) → 4꼭짓점
  cv2.polylines(frame, [np.int32(pts)], True, (0, 255, 0), 2)
  ```
  - 반환 `rot_rect`: **회전된 사각형** (중심, 크기, 각도) / `track_window`: 다음 탐색용 축 정렬 창
- **MeanShift와 비교**

| | MeanShift | CamShift |
|---|---|---|
| 창 크기 | 고정 | **물체 크기에 맞게 변화** |
| 회전 | 반영 안 함 | **각도 추정** |
| 출력 | `(x, y, w, h)` | 회전 사각형 + 창 |

- **장점 (강의)**: 물체가 **다가오거나 멀어지거나 회전**해도 따라감
- **한계 (강의)**: **배경 색이 물체와 비슷하면 실패**(창이 배경으로 퍼짐), 색 정보만 사용, 가림(occlusion)에 약함 → 딥러닝 추적기(SORT·DeepSORT, ByteTrack)로 발전

## 수식·원리
```
창 안 확률 맵 B에서
m00, m10, m01, m20, m02, m11 (0~2차 모멘트)
중심: cx = m10/m00, cy = m01/m00
a = m20/m00 − cx²,  b = 2(m11/m00 − cx·cy),  c = m02/m00 − cy²
각도 θ = ½·atan2(b, a − c),  창 크기 ∝ sqrt(m00)
```

## 코드 예시
```python
import numpy as np
import cv2

def frame_at(cx, r):                                           # 이동하면서 커지는 빨간 원
    f = np.full((160, 240, 3), (255, 0, 0), np.uint8)
    cv2.circle(f, (cx, 80), r, (0, 0, 255), -1)
    return cv2.cvtColor(f, cv2.COLOR_BGR2HSV)

hsv0 = frame_at(60, 12)
win = (48, 68, 24, 24)
x, y, w, h = win
roi = hsv0[y:y + h, x:x + w]
roi_hist = cv2.calcHist([roi], [0], cv2.inRange(roi, (0, 60, 32), (180, 255, 255)), [180], [0, 180])
cv2.normalize(roi_hist, roi_hist, 0, 255, cv2.NORM_MINMAX)
term = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 1)
for cx, r in ((66, 16), (72, 20), (78, 24), (84, 28)):
    dst = cv2.calcBackProject([frame_at(cx, r)], [0], roi_hist, [0, 180], 1)
    rot_rect, win = cv2.CamShift(dst, win, term)
    (rx, ry), (rw, rh), ang = rot_rect
    print(cx, round(rx), "지름", 2 * r, "추정", round(max(rw, rh)))   # 66 64 지름 32 추정 44 → … → 84 83 지름 56 추정 108  창이 커짐
print(cv2.boxPoints(rot_rect).shape)                           # (4, 2)  회전 사각형 꼭짓점
```
