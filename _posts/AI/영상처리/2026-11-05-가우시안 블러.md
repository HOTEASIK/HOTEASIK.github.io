# 가우시안 블러

## 정의·핵심
- **정의**: **가우시안(정규) 분포** 모양의 가중치 커널로 평균을 내는 블러. **중심에 가까울수록 큰 가중치**, 멀수록 작은 가중치 (응용 2차시)
- **함수**: `cv2.GaussianBlur(img, (k, k), sigmaX, sigmaY=0)`
  - 커널 크기는 **양의 홀수** (`(5, 5)`)
  - `sigmaX=0`이면 커널 크기로부터 σ를 자동 계산 (`σ = 0.3·((k−1)·0.5 − 1) + 0.8`)
  - 커널 크기를 `(0, 0)`으로 주고 σ만 지정해도 됨
  - σ가 클수록 넓게 흐려진다
- **평균 블러보다 나은 점**
  - 가중치가 부드럽게 줄어 **자연스러운 블러** (박스 모양 아티팩트 없음)
  - 가까운 픽셀을 더 중시 → 같은 잡음 감소에서 엣지 손실이 상대적으로 적다
  - **분리 가능(separable)**: 2D 가우시안 = 가로 1D × 세로 1D → 빠름
- **어디에 쓰나**
  - **Canny 엣지 검출의 1단계**(잡음 제거) → [[Canny 엣지 검출]]
  - 미분(Sobel·Laplacian) 전 잡음 억제, Otsu·적응형 이진화 전처리
  - 언샤프 마스킹(샤프닝), 이미지 피라미드, 배경 흐림
  - 데이터 증강 `transforms.GaussianBlur`
- `cv2.getGaussianKernel(k, σ)`: 1D 커널 확인 (합 = 1)

## 수식·원리
```
G(x, y) = (1 / 2πσ²) · exp(−(x² + y²) / 2σ²)
분리:  G(x, y) = g(x) · g(y)
```

## 코드 예시
```python
import numpy as np
import cv2

g = cv2.getGaussianKernel(5, 1.0).ravel()
print([round(float(v), 3) for v in g], round(float(g.sum()), 3))        # [0.054, 0.244, 0.403, 0.244, 0.054] 1.0  중심이 가장 큼
k2d = np.outer(g, g)                                       # 분리 가능: 1D × 1D
img = np.zeros((9, 9), np.float32); img[4, 4] = 1.0        # 점 하나 (임펄스)
out = cv2.GaussianBlur(img, (5, 5), 1.0)
print(np.allclose(out[2:7, 2:7], k2d, atol=1e-6))          # True  결과 = 커널 모양
for s in (0.5, 2.0):
    print(s, round(cv2.GaussianBlur(img, (0, 0), s)[4, 4], 3))   # σ가 클수록 중심값 낮음(넓게 퍼짐)
# 0.5 0.619
# 2.0 0.04
```
