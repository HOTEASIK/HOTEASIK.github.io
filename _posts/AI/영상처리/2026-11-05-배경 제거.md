# 배경 제거 (MOG, MOG2)

## 정의·핵심
- **정의**: Background Subtraction. 고정된 카메라 영상에서 **배경을 학습해 제거하고 움직이는 객체(전경)만 추출**하는 기법 (응용 3·4차시)
- **MOG (Mixture of Gaussians) 개념 (강의)**
  - **각 픽셀의 색상 변화를 가우시안 분포(정규분포)로 모델링**
  - **배경(bg)**: 고정되어 있거나 **오래 머무는 색상** → 배경으로 학습
  - **전경(fg)**: **갑자기 툭 나타난 색상** → 움직이는 물체로 판단
  - 한 픽셀에 **여러 개의 가우시안을 혼합**(GMM) → 흔들리는 나뭇잎·물결처럼 값이 몇 가지로 오가는 배경도 표현
- **MOG2**: MOG 개선판. 픽셀마다 **가우시안 개수를 자동 선택**, 조명 변화에 더 잘 적응, **그림자 검출** 지원
  - `fgbg = cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=16, detectShadows=True)`
  - `mask = fgbg.apply(frame)` → **255 = 전경, 127 = 그림자, 0 = 배경**
  - `history`: 배경 학습에 쓰는 과거 프레임 수, `varThreshold`: 배경 판정 거리(클수록 둔감)
  - `learningRate`(apply 인자): -1 자동, 0 = 배경 갱신 안 함, 1 = 매 프레임 새로 학습
  - 배경 영상 확인: `fgbg.getBackgroundImage()`
- **기타**: `createBackgroundSubtractorKNN()`(KNN 기반), 원조 MOG는 `cv2.bgsegm.createBackgroundSubtractorMOG()` (**opencv-contrib** 필요)
- **후처리**: 마스크에 [[모폴로지]] (열림으로 잡음 제거) → 그림자 제거(`mask == 255`) → [[윤곽선]]·`boundingRect`로 객체 박스
- **가장 단순한 방법과 비교**: 고정 배경과의 [[절대값 차이]](`absdiff`) + 이진화 → 조명 변화·흔들림에 약함 → MOG는 **배경을 계속 갱신**해 이를 보완
- **한계**: **카메라가 움직이면** 전체가 전경으로 나옴, 오래 멈춘 물체는 배경으로 흡수, 배경과 색이 비슷한 물체 놓침
- **활용**: CCTV 침입 감지, 교통량 계수, 추적 전처리

## 수식·원리
```
픽셀 x의 확률 P(x) = Σ_k w_k · N(x | μ_k, σ_k²)    (K개 가우시안 혼합)
|x − μ_k| < λ·σ_k  이고 가중치 큰 분포 → 배경
아니면 → 전경 (255)
매 프레임 w, μ, σ를 학습률 α로 갱신 → 배경 적응
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
bg = rng.integers(90, 110, (60, 80, 3), dtype=np.uint8)           # 약간 잡음 있는 고정 배경
fgbg = cv2.createBackgroundSubtractorMOG2(history=50, varThreshold=16, detectShadows=True)
for _ in range(30):                                                # 배경 학습
    frame = np.clip(bg.astype(int) + rng.integers(-3, 4, bg.shape), 0, 255).astype(np.uint8)
    fgbg.apply(frame)

frame = bg.copy()
cv2.rectangle(frame, (30, 20), (50, 40), (0, 0, 255), -1)          # 갑자기 나타난 빨간 물체
mask = fgbg.apply(frame)
print(np.unique(mask).tolist())                                    # [0, 255]  전경 255 (그림자가 있으면 127)
fg = cv2.morphologyEx((mask == 255).astype(np.uint8) * 255, cv2.MORPH_OPEN, np.ones((3, 3), np.uint8))
cnts, _ = cv2.findContours(fg, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print(len(cnts), cv2.boundingRect(max(cnts, key=cv2.contourArea)))   # 1 (30, 20, 21, 21)  물체 박스
print(fgbg.getBackgroundImage().shape)                             # (60, 80, 3)  학습된 배경
print(hasattr(cv2, "createBackgroundSubtractorKNN"))               # True
```
