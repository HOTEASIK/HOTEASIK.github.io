# 논리 연산

## 정의·핵심
- **정의**: 픽셀 값의 **비트 단위 논리 연산**(AND·OR·XOR·NOT)으로 두 영상을 합성하거나 특정 영역을 추출·반전 (응용 1차시)
- **네 가지 연산 (강의)**
  - **AND `cv2.bitwise_and`** (교집합, Masking): 두 값이 **모두 0이 아닐 때만** 유지 → 마스크 기반 **영역 추출**, 교집합 확인
  - **OR `cv2.bitwise_or`** (합집합, Merging): **하나라도** 0이 아니면 켜짐 → 두 영상·마스크 합치기
  - **XOR `cv2.bitwise_xor`** (차이): 두 값이 **서로 다를 때만** 켜짐 → 변화 감지, 서로 다른 영역 강조
  - **NOT `cv2.bitwise_not`** (반전): 0 → 255, 255 → 0 → 색 반전(네거티브 필름), **마스크 뒤집기**
  - 실제로는 8비트 각각에 적용 (예: 200 AND 100 = 64)
- **마스크 (강의)**
  - `uint8` 단일 채널 흑백 이미지. **0이면 '무시', 0이 아니면 '적용'**. 입력 영상과 **크기가 같아야** 함
  - **생성**: `cv2.inRange()`(색 범위), `cv2.threshold()`(임계값), 빈 마스크(0) 위에 **흰색(255) 도형을 그려** ROI 직접 지정(`rectangle`, `circle`)
  - **적용**: `cv2.bitwise_and(img, img, mask=mask)` → 마스크 영역만 남기고 나머지 제거
  - **활용**: `cv2.inpaint()`(마스크 영역을 주변 색으로 복원 — 워터마크 제거), 모폴로지·블러로 마스크 정리
- **대표 활용**
  - 원형·다각형 ROI만 잘라내기
  - **로고 합성**: 배경 영역은 `bitwise_and(roi, roi, mask=mask_inv)`, 로고 영역은 `bitwise_and(logo, logo, mask=mask)` → 둘을 `add`
  - 배경/전경 분리 후 배경만 흐리게
- `mask=` 인자는 add·subtract·copyTo 등 많은 함수에서 지원

## 수식·원리
```
AND: dst = src1 & src2   (mask가 있으면 mask≠0 인 곳만, 나머지 0)
OR:  dst = src1 | src2
XOR: dst = src1 ^ src2
NOT: dst = 255 − src   (= ~src, uint8)
```

## 코드 예시
```python
import numpy as np
import cv2

a = np.zeros((5, 5), np.uint8); a[:, :3] = 255           # 왼쪽 3열
b = np.zeros((5, 5), np.uint8); b[:, 2:] = 255           # 오른쪽 3열
for name, f in [("and", cv2.bitwise_and), ("or", cv2.bitwise_or), ("xor", cv2.bitwise_xor)]:
    print(name, (f(a, b)[0] // 255).tolist())
# and [0, 0, 1, 0, 0]
# or [1, 1, 1, 1, 1]
# xor [1, 1, 0, 1, 1]
print((cv2.bitwise_not(a)[0] // 255).tolist(), cv2.bitwise_and(np.uint8([200]), np.uint8([100]))[0])   # [0, 0, 0, 1, 1] [64]

img = np.full((50, 50, 3), 120, np.uint8)
mask = np.zeros((50, 50), np.uint8)
cv2.circle(mask, (25, 25), 10, 255, -1)                 # 흰 원으로 ROI 지정
out = cv2.bitwise_and(img, img, mask=mask)
print(out[25, 25].tolist(), out[0, 0].tolist(), cv2.countNonZero(mask))   # [120, 120, 120] [0, 0, 0] 317
```
