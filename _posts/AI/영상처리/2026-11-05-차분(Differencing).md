# 차분(Differencing)

## 정의·핵심
- **정의**: **두 픽셀 값의 차이를 계산해 변화를 감지**하는 연산. 변화 지점을 찾아내는 영상 처리의 기초 (응용 3차시)
- **두 종류 (강의)**
  - **공간적 차분 (Spatial Difference)**: **같은 이미지 안에서 인접한 픽셀** 간 차이 → 위치에 따른 변화 → **Edge(경계선) 검출**
  - **시간적 차분 (Temporal Difference)**: **연속된 프레임** 간 같은 위치의 차이 → 시간에 따른 변화 → **움직임(Motion) 검출** → [[절대값 차이]]
- **왜 중요한가 (강의)**: **특징(Feature)이란 다른 부분과 구별되는 '변화 지점'** 이다. 변화를 수학적으로 표현하면 **차분**이 된다
- **미분과의 관계**: 연속 함수의 미분 `df/dx`를 디지털 영상에서는 이웃 픽셀 차이로 근사
  - 전방 차분 `f(x+1) − f(x)`, 중앙 차분 `(f(x+1) − f(x−1)) / 2`
  - 커널로 쓰면 `[−1, 1]`, `[−1, 0, 1]` → 이것을 평활화와 결합한 것이 **Sobel** → [[Sobel 필터]]
  - 2차 차분 `f(x+1) − 2f(x) + f(x−1)` → **Laplacian** → [[Laplacian 필터]]
- **약점**: 단순 차분은 **잡음에 매우 민감**(잡음도 '변화'라서) → 블러 후 차분하거나 Sobel처럼 평활화를 섞는다
- **특징의 수준 (강의)**
  - **저수준**: 색상, 밝기·강도, **엣지·코너**, 블롭
  - **중간 수준**: **윤곽선**, 형태 기술자, 질감
  - **고수준**: 지역적 특징(SIFT, SURF, ORB), 객체 인식, **딥러닝 CNN 특징**
  - 단순 픽셀 정보(저수준) → 의미 있는 형태(중간) → 객체 식별 정보(고수준)로 발전

## 수식·원리
```
공간 차분:  Dx(x, y) = I(x+1, y) − I(x, y),   Dy(x, y) = I(x, y+1) − I(x, y)
시간 차분:  Dt(x, y) = I_t(x, y) − I_{t−1}(x, y)
2차 차분:   I(x+1) − 2·I(x) + I(x−1)
```

## 코드 예시
```python
import numpy as np

row = np.array([10, 10, 10, 80, 150, 150, 150], dtype=int)      # 밝기가 바뀌는 경계
print(np.diff(row).tolist())                                    # [0, 0, 70, 70, 0, 0]  변화 지점에서만 큼
print(np.diff(row, n=2).tolist())                               # [0, 70, 0, -70, 0]   2차 차분: 시작·끝에서 부호
img = np.zeros((5, 5), int); img[:, 3:] = 100
dx = img[:, 1:] - img[:, :-1]                                   # 가로 방향 공간 차분
print(dx[0].tolist())                                           # [0, 0, 100, 0]  세로 엣지 위치
f1 = np.zeros((3, 3), int); f2 = f1.copy(); f2[1, 1] = 50       # 다음 프레임에서 한 점이 밝아짐
print(np.argwhere(np.abs(f2 - f1) > 0).tolist())                # [[1, 1]]  시간 차분 = 움직임
noisy = row + np.random.default_rng(0).integers(-5, 6, row.size)
print(np.diff(noisy).tolist())                                  # [-2, -2, 67, 71, -3, 0]  평평한 곳도 0이 아님 → 잡음에 민감
```
