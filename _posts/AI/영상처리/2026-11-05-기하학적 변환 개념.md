# 기하학적 변환 개념

## 정의·핵심
- **정의**: 이미지의 **좌표 (x, y)를 새로운 좌표 (x', y')로 매핑**하는 과정. 픽셀 값이 아니라 **픽셀의 위치**를 바꾼다 (응용 2차시)
- **주요 변환 유형 (강의)**
  - **이동 (Translation)**: 위치만 변경 (크기·각도 유지) → [[이동(Translation)]]
  - **회전 (Rotation)**: 중심점 기준 각도 변경 → [[회전]]
  - **확대/축소 (Scaling)**: 크기 비율 변경 (해상도 변화) → [[확대·축소]]
  - **아핀 (Affine)**: **평행선 유지** (직사각형 → 평행사변형) → [[아핀 변환]]
  - **투시 (Perspective)**: 원근감 반영, **평행성이 깨지며 소실점에서 만남** (직사각형 → 사다리꼴) → [[투시 변환]]
- **기본 원리 (강의)**: 모든 기하학적 변환은 픽셀 좌표를 **행렬 연산**으로 새 좌표로 옮기는 것 — `dst(x, y) = src(M · [x, y, 1]ᵀ)`
  - **동차 좌표** `[x, y, 1]`을 쓰면 이동까지 행렬 곱 하나로 표현
  - 아핀: **2×3 행렬** (`warpAffine`), 투시: **3×3 행렬** (`warpPerspective`)
- **OpenCV의 관점 (강의)**: **"액자(Canvas)"는 고정**하고, 그 안에 끼운 **"그림(Content)"을 조작**하는 방식 → 출력 크기 `dsize`를 따로 지정하며, 밖으로 나간 부분은 **잘리고** 빈 곳은 **검정(borderValue)** 으로 채워짐
- **역방향 매핑**: 실제 구현은 출력 픽셀 하나하나에 대해 **원본의 어느 위치에서 값을 가져올지** 계산(역행렬) → 원본 위치가 정수가 아니므로 **보간** 필요 → [[보간법]]
- **변환의 계층** (자유도 ↑)
  - 강체(Euclidean, 이동+회전) 3 → 유사(Similarity, +크기) 4 → **아핀 6** → **투시(호모그래피) 8**
- **활용**: 데이터 증강(회전·이동·크기·원근), 문서 스캔 보정, 영상 정렬·스티칭, 객체 자세 보정, 검출 전처리
- 함수 정리: `warpAffine`, `warpPerspective`, `getRotationMatrix2D`, `getAffineTransform`, `getPerspectiveTransform`, `resize`, `flip`, `remap`

## 수식·원리
```
[x']   [a b tx] [x]
[y'] = [c d ty] [y]        (아핀, 2×3)
                [1]
[x'w]   [h11 h12 h13] [x]
[y'w] = [h21 h22 h23] [y]   (투시, 3×3) → x' = x'w / w
[ w ]   [h31 h32  1 ] [1]
```

## 코드 예시
```python
import numpy as np
import cv2

M = np.float32([[1, 0, 10], [0, 1, 5]])                 # 이동 행렬 (2×3)
pt = np.array([3, 4, 1])                                # 동차 좌표 [x, y, 1]
print((M @ pt).tolist())                                # [13.0, 9.0]  행렬 곱으로 좌표 이동
pts = np.float32([[[3, 4]], [[0, 0]]])
print(cv2.transform(pts, M).reshape(-1, 2).tolist())    # [[13.0, 9.0], [10.0, 5.0]]

img = np.zeros((20, 30), np.uint8); img[2:6, 2:6] = 255
out = cv2.warpAffine(img, M, (30, 20))                  # 액자 크기 (w, h) 고정
ys, xs = np.nonzero(out)
print(xs.min(), ys.min(), out.shape)                    # 12 7 (20, 30)  그림만 이동
print(cv2.warpAffine(img, np.float32([[1, 0, 26], [0, 1, 0]]), (30, 20)).sum() // 255)   # 8  밖으로 나간 부분은 잘림
```
