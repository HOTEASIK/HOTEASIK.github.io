# 양방향 필터

## 정의·핵심
- **정의**: Bilateral Filter. **거리가 가깝고, 색(밝기) 차이도 작은** 픽셀만 크게 반영해 평균하는 **엣지 보존 스무딩** 필터 (응용 2차시)
- **두 가지 가중치의 곱**
  - **공간 가중치** (가우시안): 중심에서 **가까울수록** 큼 — 일반 가우시안 블러와 같음
  - **색 가중치** (가우시안): 중심 픽셀과 **값이 비슷할수록** 큼
  - 경계 건너편 픽셀은 색 차이가 커서 가중치가 거의 0 → **엣지를 넘어 섞이지 않는다**
- **함수**: `cv2.bilateralFilter(src, d, sigmaColor, sigmaSpace)`
  - `d`: 이웃 지름 (−1이면 sigmaSpace로 자동). 5 정도가 실시간, 9 이상은 느림
  - `sigmaColor`: 클수록 색 차이가 커도 섞임 (너무 크면 그냥 가우시안)
  - `sigmaSpace`: 클수록 멀리 있는 픽셀도 섞임
  - 보통 `bilateralFilter(img, 9, 75, 75)`
- **장단점**
  - 장점: 평평한 영역의 잡음은 지우면서 **윤곽은 또렷하게** 유지
  - 단점: 픽셀마다 가중치를 새로 계산해 **매우 느리다**. 강하게 반복하면 **만화(카툰) 같은** 평면 영역
- **활용**: 피부 보정(뷰티 필터), 카툰화(양방향 필터 + 엣지 검출 합성), HDR 톤 매핑, 엣지 검출 전처리

## 수식·원리
```
dst(p) = (1/W) Σ_q  G_s(‖p − q‖) · G_r(|I(p) − I(q)|) · I(q)
W = Σ_q G_s(‖p − q‖) · G_r(|I(p) − I(q)|)
```

## 코드 예시
```python
import numpy as np
import cv2

rng = np.random.default_rng(0)
img = np.zeros((40, 40), np.uint8); img[:, 20:] = 200            # 세로 엣지
noisy = np.clip(img + rng.normal(0, 10, img.shape), 0, 255).astype(np.uint8)
gauss = cv2.GaussianBlur(noisy, (9, 9), 3)
bila = cv2.bilateralFilter(noisy, 9, 75, 75)
flat_noise = lambda x: round(x[:, :15].std(), 1)                  # 평평한 영역의 잡음
edge_jump = lambda x: int(x[:, 21].mean()) - int(x[:, 18].mean())  # 경계 양쪽 차이
print(flat_noise(noisy), flat_noise(gauss), flat_noise(bila))     # 5.7 0.9 1.0  둘 다 잡음 감소
print(edge_jump(noisy), edge_jump(gauss), edge_jump(bila))        # 194 87 189  양방향은 경계 차이 유지, 가우시안은 크게 감소
```
