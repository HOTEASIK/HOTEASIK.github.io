# 보간법

## 정의·핵심
- **정의**: Interpolation. 이미지 크기 변경·회전 등에서 **원본 격자에 없는 위치의 픽셀 값을 주변 픽셀로부터 추정**해 빈 픽셀을 채우거나 픽셀을 합치는 과정. 기하학적 변환에 **필수** (응용 2차시)
- **왜 필요한가**: 출력 픽셀을 원본 좌표로 역매핑하면 (12.3, 7.8) 같은 **소수 좌표**가 나온다 → 그 위치의 값을 주변 정수 픽셀로 계산
- **OpenCV 보간 플래그 (강의 표)**

| 상수 | 특징 | 속도 |
|---|---|---|
| `INTER_NEAREST` | **가장 가까운 이웃** 픽셀 값 그대로 (계단 현상) | 매우 빠름 |
| `INTER_LINEAR` | **양선형 보간** (주변 2×2, **기본값**, 부드러움) | 빠름 |
| `INTER_CUBIC` | **3차 보간** (주변 4×4, 선명함, **확대용**) | 보통 |
| `INTER_AREA` | **픽셀 영역 재샘플링** (**축소용**, 모아레 방지) | 빠름 |
| `INTER_LANCZOS4` | Lanczos (주변 8×8, 가장 선명) | 느림 |

- **선택 가이드 (강의)**: 확대 → **CUBIC/LINEAR**, 축소 → **AREA**, 속도 우선 → LINEAR, 품질 우선 → CUBIC
- **NEAREST가 필요한 경우**: **분할 마스크·라벨 맵**(값이 클래스 번호라 섞이면 안 됨), 픽셀 아트
- CUBIC·LANCZOS는 경계에서 **오버슈트**(원래 범위를 넘는 값, 링잉)가 생길 수 있다 → uint8은 자동으로 0~255로 잘림
- torchvision `transforms.Resize`의 `interpolation=InterpolationMode.BILINEAR`(기본)도 같은 개념

## 수식·원리
```
양선형: 위치 (x + a, y + b), 0 ≤ a, b < 1
f = (1−a)(1−b)·I(x,y) + a(1−b)·I(x+1,y) + (1−a)b·I(x,y+1) + ab·I(x+1,y+1)
최근접: f = I(round(x + a), round(y + b))
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.array([[0, 100], [100, 200]], np.uint8)
for name in ("INTER_NEAREST", "INTER_LINEAR", "INTER_CUBIC"):
    out = cv2.resize(img, (4, 4), interpolation=getattr(cv2, name))
    print(f"{name:14s}", out[1].tolist())             # NEAREST [0, 0, 100, 100] / LINEAR [25, 50, 100, 125] / CUBIC [12, 45, 100, 133]
a, b = 0.5, 0.5                                       # 네 픽셀의 정중앙
f = (1 - a) * (1 - b) * 0 + a * (1 - b) * 100 + (1 - a) * b * 100 + a * b * 200
print(f)                                              # 100.0  양선형 보간 공식

edge = np.zeros((1, 8), np.uint8); edge[0, 4:] = 255
up = cv2.resize(edge.astype(np.float32), (16, 1), interpolation=cv2.INTER_CUBIC)
print(round(float(up.min()), 1) < 0, round(float(up.max()), 1) > 255)   # True True  cubic의 오버슈트
```
