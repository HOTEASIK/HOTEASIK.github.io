# torchviz

## 정의·핵심
- **정의**: PyTorch의 **계산 그래프**(Autograd가 만든 연산 기록)를 그림으로 그려 주는 도구. `pip install torchviz` + 시스템에 **Graphviz** 프로그램 설치 필요.
- **핵심 함수**: `make_dot(출력텐서, params=dict(model.named_parameters()))` → 그래프 객체, `.render("파일명", format="png")`로 저장. 노트북에서는 마지막 줄에 두면 바로 표시된다.
- **그림 읽는 법**
  - 파란 상자: 학습할 파라미터(`weight`, `bias`) — 잎(leaf) 텐서
  - 회색 상자: 연산 노드 `AddmmBackward0`, `ReluBackward0` 등 = 역전파 때 실행될 미분 함수
  - 아래쪽 초록 상자: 출력(손실)
- **왜 보나**: `loss.backward()`가 **어떤 길을 따라 기울기를 전달하는지** 눈으로 확인 → 역전파·연쇄법칙 이해용. 연결이 끊긴 곳(`detach`, `no_grad`)도 보인다. (강의: "make_dot과 같은 유틸리티 함수를 사용하면…")
- **도구 없이 보기**: `y.grad_fn`, `y.grad_fn.next_functions`로 그래프를 직접 따라갈 수 있다.

## 수식·원리
```
x, W, b ─▶ Addmm(x·Wᵀ+b) ─▶ Relu ─▶ Sum ─▶ loss
backward:  loss → SumBackward0 → ReluBackward0 → AddmmBackward0 → W.grad, b.grad
```

## 코드 예시
```python
import torch
import torch.nn as nn

model = nn.Sequential(nn.Linear(3, 2), nn.ReLU())
y = model(torch.randn(4, 3)).sum()
print(y.grad_fn)                                         # <SumBackward0 ...>
print([f[0].__class__.__name__ for f in y.grad_fn.next_functions])   # ['ReluBackward0']

from torchviz import make_dot
dot = make_dot(y, params=dict(model.named_parameters()))
# dot.render("graph", format="png")   # Graphviz 설치 필요
```
