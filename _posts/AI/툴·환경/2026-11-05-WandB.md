# WandB

## 정의·핵심
- **정의**: Weights & Biases. 학습 중 **손실·정확도·하이퍼파라미터·이미지를 웹 대시보드에 자동 기록**하고 실험끼리 비교하는 실험 관리 도구. (보충 02·2_2) `pip install wandb` (Colab 기본 미설치)
- **왜 쓰나**: print와 엑셀로 기록하면 "어떤 설정에서 이 결과가 나왔는지" 잃어버린다 → 설정(config)과 결과를 **Run 단위로 묶어 영구 저장**
- **준비**: wandb.ai 무료 가입 → `wandb.ai/authorize`에서 API 키 복사 → `wandb.login()` 입력창에 붙여넣기 (**키를 코드에 직접 쓰지 않는다**, 환경변수 `WANDB_API_KEY` 사용 가능)
- **용어**
  - **Project**: 실험 폴더. 같은 이름으로 여러 번 실행하면 Run이 한곳에 모여 비교된다
  - **Run**: 실험 한 번. `wandb.init()`마다 새 Run 생성
  - **config**: 그 Run의 하이퍼파라미터 딕셔너리. `cfg = wandb.config` → `cfg.lr`처럼 접근 — 설정을 한곳에 모아 두면 config만 바꿔 다른 실험 가능
- **핵심 함수 흐름**
  1. `wandb.init(project="mnist-wandb", name="mlp-baseline", config=config)`
  2. `wandb.watch(model)`: 가중치·기울기 **분포**까지 자동 기록 (기울기 소실·폭주 확인)
  3. `wandb.log({"train_loss": l, "val_acc": a, "epoch": e})`: 호출마다 한 step 쌓임 → 차트 x축
  4. `wandb.Image(img, caption=...)`: 예측 샘플 이미지, `wandb.plot.confusion_matrix(...)`: 혼동행렬
  5. `wandb.finish()`: Run 종료
  - GPU 사용률·메모리 같은 시스템 지표는 `init`만 해도 자동 수집
- **Sweeps** (하이퍼파라미터 자동 탐색): 탐색 설정을 딕셔너리로 정의 → `sweep_id = wandb.sweep(sweep_config, project=...)` → `wandb.agent(sweep_id, function=train, count=N)`
  - `method`: `grid`, `random`, `bayes` (베이지안) → [[하이퍼파라미터 탐색 방법]]
  - `metric`: `{"name": "val_acc", "goal": "maximize"}`, `parameters`: 값 목록(`values`) 또는 범위(`min`, `max`)
  - `early_terminate`: Hyperband로 성능 나쁜 Run 조기 종료
- **Artifacts**: 데이터셋·모델 파일 버전 관리 ("추적 + 튜닝(Sweeps) + 버전관리"가 한 곳에)

## 수식·원리
```
init(config) ─▶ watch(model) ─▶ [epoch마다] log({...}) ─▶ finish()
sweep(config) ─▶ agent(train, count=N)  ← train 안에서 init·wandb.config 사용
```

## 코드 예시
```python
import wandb

config = {"lr": 1e-3, "batch_size": 64, "epochs": 3, "optimizer": "adam"}
run = wandb.init(project="mnist-wandb", name="mlp-baseline", config=config, mode="offline")
cfg = wandb.config
for epoch in range(cfg.epochs):
    train_loss = 1.0 / (epoch + 1)          # 실제로는 학습 루프 결과
    wandb.log({"epoch": epoch, "train_loss": train_loss})
wandb.finish()

sweep_config = {
    "method": "bayes",
    "metric": {"name": "val_acc", "goal": "maximize"},
    "parameters": {"lr": {"min": 1e-4, "max": 1e-1}, "batch_size": {"values": [32, 64, 128]}},
}

# wandb.agent(sweep_id, function=train, count=10)
```
