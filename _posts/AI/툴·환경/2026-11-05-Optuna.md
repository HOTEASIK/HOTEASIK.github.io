# Optuna

## 정의·핵심
- **정의**: 하이퍼파라미터 **자동 탐색** 라이브러리. `pip install optuna`. 기본 탐색 알고리즘이 **TPE**(베이지안 최적화의 실무 대표 구현)라서, 과거 결과를 보고 다음 후보를 똑똑하게 고른다. (보충 02)
  - 강의 요약: "베이지안 최적화 = 과거 결과로 다음을 똑똑하게 고르기", "Optuna를 쓰면 TPE로 이걸 자동으로 해준다"
- **구성 요소 3개**
  - `objective(trial)`: 한 번의 시도. 하이퍼파라미터를 뽑아 학습하고 **점수를 return**
  - `trial.suggest_*`: 탐색할 하이퍼파라미터와 범위 선언
    - `suggest_float('lr', 1e-4, 1e-1, log=True)` — `log=True`면 로그 스케일로 고르게 (학습률처럼 자릿수가 바뀌는 값)
    - `suggest_int('layers', 1, 4)`, `suggest_categorical('batch', [32, 64, 128])`
  - `study = optuna.create_study(direction='maximize')` → `study.optimize(objective, n_trials=20)` → `study.best_params`, `study.best_value`
- **Pruning(가지치기)**: 학습 중간 점수를 `trial.report(val, epoch)`로 알리고 `trial.should_prune()`이면 `raise optuna.TrialPruned()` — 가망 없는 시도를 일찍 끊어 시간 절약 (Hyperband 아이디어)
- **TPE가 강한 곳**: 연속·이산·범주·조건부 하이퍼파라미터가 섞여 있어도 잘 다룬다. 실험이 비싸고 예산이 빠듯할 때 Grid/Random보다 **적은 시도로 좋은 값**
- 시각화: `optuna.visualization.plot_optimization_history(study)`, `plot_param_importances(study)`

## 수식·원리
```
for t in 1..n_trials:
    θ_t = TPE(지금까지 (θ, 점수) 기록)   ← 좋았던 구간 근처를 더 자주 뽑음
    점수_t = objective(θ_t)
best = argmax 점수
```

## 코드 예시
```python
import optuna
optuna.logging.set_verbosity(optuna.logging.WARNING)

def objective(trial):
    lr = trial.suggest_float("lr", 1e-4, 1e-1, log=True)
    b = trial.suggest_categorical("batch", [32, 64, 128])
    # 실제로는 lr, b로 학습 후 검증 정확도를 반환. 여기서는 lr=0.01, b=64가 최적인 가짜 점수
    import math
    return -abs(math.log10(lr) + 2) - (0 if b == 64 else 0.3)

study = optuna.create_study(direction="maximize", sampler=optuna.samplers.TPESampler(seed=0))
study.optimize(objective, n_trials=40)
print(study.best_params["batch"])              # 64
print(round(study.best_params["lr"], 2))       # 0.01 근처
```
