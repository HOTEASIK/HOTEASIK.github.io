# 라벨링 도구

## 정의·핵심
- **정의**: 이미지에 **정답(박스·클래스·마스크)을 표시해 라벨 파일을 만드는 도구**. 직접 모은 데이터로 객체 검출(YOLO)을 학습하려면 꼭 필요하다. (보충 3_1 탐지 데이터 다루기, 응용 12차시)
- **labelImg**
  - 내 PC에서 쓰는 무료 프로그램(`pip install labelImg` → `labelImg` 실행)
  - 박스를 그리고 클래스 이름을 고르면 저장 형식을 **YOLO(.txt)** 또는 **Pascal VOC(.xml)** 로 고를 수 있다
  - 단축키: `W` 박스 그리기, `D`/`A` 다음/이전 이미지, `Ctrl+S` 저장
- **Roboflow**
  - 웹 서비스. 업로드 → 라벨링 → **증강·분할(train/valid/test)** → YOLO·COCO·VOC 등 원하는 형식으로 내보내기까지 한 번에
  - 형식 변환에 유용: "'담는 정보'는 같고 표기 방식만 다르다 → Roboflow·변환 스크립트로 서로 바꿀 수 있다"
  - 내보낼 때 `data.yaml`까지 만들어 줘서 ultralytics에 바로 쓸 수 있다
- **YOLO 라벨 형식**: 이미지마다 같은 이름의 `.txt`, 한 줄에 객체 하나 → `class x_center y_center width height` (모두 **0~1로 정규화**)
- (그 밖) CVAT, Label Studio — 세그멘테이션·팀 작업용
- **좋은 라벨 규칙**: 물체를 빈틈없이 꼭 맞게, 가려진 물체도 보이는 만큼 일관되게, 클래스 이름 순서(번호)를 data.yaml과 일치

## 수식·원리
```
픽셀 박스 (x1, y1, x2, y2), 이미지 W×H
→ YOLO: xc = (x1+x2)/2/W, yc = (y1+y2)/2/H, w = (x2-x1)/W, h = (y2-y1)/H
```

## 코드 예시
```python
def voc_to_yolo(box, W, H, cls):
    x1, y1, x2, y2 = box
    return f"{cls} {(x1+x2)/2/W:.4f} {(y1+y2)/2/H:.4f} {(x2-x1)/W:.4f} {(y2-y1)/H:.4f}"

print(voc_to_yolo((100, 50, 300, 250), 640, 480, 0))   # 0 0.3125 0.3125 0.3125 0.4167
```
