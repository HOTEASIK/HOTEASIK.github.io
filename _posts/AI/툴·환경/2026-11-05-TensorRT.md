# TensorRT

## 정의·핵심
- **정의**: NVIDIA의 **GPU 추론 가속 엔진**. 학습된 모델(보통 ONNX)을 **특정 GPU에 맞춰 최적화한 엔진 파일(`.engine`)** 로 바꿔 추론 속도를 크게 높인다. (응용 12차시)
- **강의 비유**: PyTorch가 여러 길을 다닐 수 있는 승용차라면, TensorRT는 특정 서킷(GPU)에 맞춰 불필요한 부품을 떼어 낸 **F1 머신** — 오직 추론만을 위해 최적화
- **속도 비교 (강의)**: PyTorch ~150ms → ONNX Runtime ~75ms → **TensorRT ~20ms (7.5배)** — "추론 지연을 한 자릿수 ms대까지"
- **어떻게 빨라지나**
  - **층 합치기(Layer Fusion)**: Conv + BN + ReLU를 커널 하나로
  - **정밀도 낮추기**: FP32 → **FP16 / INT8** (INT8은 보정용 데이터 필요) — 속도·메모리 이득, 정확도 약간 손해
  - GPU 구조에 맞는 가장 빠른 커널 자동 선택
- **주의할 점**
  - 엔진은 **만든 GPU·TensorRT 버전에 묶인다** → 다른 PC에서 다시 빌드
  - 학습은 못 한다(추론 전용), NVIDIA GPU에서만 동작
  - YOLO의 NMS 같은 후처리는 플러그인이 필요해 배포가 까다롭다 → NMS-Free인 YOLOv10이 유리
  - Jetson(엣지 로봇) 배포에서 주로 사용
- **만드는 방법**: ultralytics `model.export(format='engine', half=True)` / `trtexec --onnx=model.onnx --saveEngine=model.engine --fp16`

## 수식·원리
```
PyTorch(.pt) ─export─▶ ONNX ─TensorRT 빌드(fusion, FP16/INT8, 커널 선택)─▶ .engine ─▶ 고속 추론
```

## 코드 예시
```
# ultralytics (NVIDIA GPU + TensorRT 설치 필요)
yolo export model=best.pt format=engine half=True
yolo predict model=best.engine source=bus.jpg

# ONNX에서 직접
trtexec --onnx=model.onnx --saveEngine=model.engine --fp16
```
