# VSCode

## 정의·핵심
- **정의**: Microsoft의 무료 코드 편집기(Visual Studio Code). 강의에서는 Colab 대신 **내 PC에서 실습할 때** "VSCode + Conda" 조합을 안내한다. (개론 1차시)
- **딥러닝 실습에 필요한 확장(Extension)**
  - **Python**: 실행·디버깅·자동완성
  - **Jupyter**: `.ipynb`를 VSCode 안에서 열고 셀 실행
  - (선택) Pylance: 타입 힌트·오류 표시
- **인터프리터·커널 고르기가 핵심**: 오른쪽 위 `커널 선택` 또는 `Ctrl+Shift+P → Python: Select Interpreter`에서 **Conda 가상환경의 python**을 골라야 그 환경에 설치한 torch가 잡힌다 → [[Conda 가상환경]]
  - "No module named torch"가 나면 대부분 다른 인터프리터가 선택된 것
- **Colab과 비교**

| | Colab | VSCode(로컬) |
|---|---|---|
| 설치 | 없음 | Python·Conda·라이브러리 직접 |
| GPU | 무료 T4 | 내 PC GPU(NVIDIA + CUDA 필요) |
| 파일 | 세션 끝나면 삭제 | 내 디스크에 그대로 |
| 웹캠·GUI 창 | 불가 | `cv2.imshow`, 웹캠 가능 |

- **좋은 점**: 여러 `.py` 파일로 된 프로젝트 관리, 디버거(중단점), Git 연동, 원격 서버 접속(Remote-SSH)

## 수식·원리
```
VSCode ─(Python 확장)─▶ 인터프리터 선택 ─▶ conda env의 python.exe ─▶ torch, numpy ...
```

## 코드 예시
```python
import sys
print(sys.executable)   # 지금 쓰는 인터프리터 경로 → conda env 경로인지 확인
print(sys.version.split()[0])
```
