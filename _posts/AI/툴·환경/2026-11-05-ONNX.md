# ONNX

## 정의·핵심
- **정의**: Open Neural Network Exchange. 딥러닝 모델을 **프레임워크와 상관없이 저장하는 공통 형식**(`.onnx`). "여러 런타임에서 통용되는 대표 포맷" (응용 12차시)
- **왜 변환하나**: 학습은 PyTorch로 해도, 서비스(웹 서버·C++·모바일·다른 언어)에서는 PyTorch를 통째로 설치하기 어렵다 → 계산 그래프와 가중치만 담은 ONNX로 내보내 **ONNX Runtime** 등으로 실행
  - 강의 비교: PyTorch(Native) ~150ms → **ONNX Runtime ~75ms (2배)** → TensorRT ~20ms
- **배포 흐름**: PyTorch → **ONNX(중간 표현)** → TensorRT·OpenVINO·모바일 런타임
- **내보내기 방법**
  - PyTorch: `torch.onnx.export(model, 예시입력, "model.onnx", input_names, output_names, dynamic_axes)`
    - 예시 입력을 한 번 흘려서 그래프를 기록하므로 **모양이 맞는 더미 입력** 필요
    - `dynamic_axes={"input": {0: "batch"}}`: 배치 크기를 바꿀 수 있게
    - 내보내기 전에 `model.eval()` (Dropout·BatchNorm을 추론 모드로)
  - ultralytics: `model.export(format='onnx')` 한 줄 → weights 폴더에 `best.onnx`
- **실행**: `onnxruntime.InferenceSession("model.onnx")` → `sess.run(None, {"input": numpy배열})` — 입력·출력이 **NumPy**
- export 형식 고르기: onnx(범용), engine(TensorRT, NVIDIA 고속), tflite(모바일·엣지)

## 수식·원리
```
model.eval() + dummy(1,3,224,224) ─torch.onnx.export─▶ model.onnx (그래프+가중치)
                                                        └─ onnxruntime.run(numpy) → 같은 출력
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn

model = nn.Sequential(nn.Flatten(), nn.Linear(3 * 8 * 8, 10)).eval()
dummy = torch.randn(1, 3, 8, 8)
torch.onnx.export(model, dummy, "model.onnx", input_names=["input"], output_names=["logits"],
                  dynamic_axes={"input": {0: "batch"}, "logits": {0: "batch"}})

import onnxruntime as ort
sess = ort.InferenceSession("model.onnx")
x = np.random.randn(4, 3, 8, 8).astype(np.float32)
out = sess.run(None, {"input": x})[0]
print(out.shape)                                                     # (4, 10)
print(np.allclose(out, model(torch.from_numpy(x)).detach().numpy(), atol=1e-5))   # True
```
