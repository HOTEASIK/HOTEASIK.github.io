# Conda 가상환경

## 정의·핵심
- **가상환경이란**: 프로젝트마다 **독립된 파이썬과 라이브러리 묶음**을 만드는 것. A 프로젝트는 torch 2.1, B는 torch 2.4처럼 버전이 달라도 서로 부딪히지 않는다.
- **Conda**: Anaconda/Miniconda에 들어 있는 패키지·환경 관리 도구. 강의의 로컬 환경 안내가 "VSCode + Conda"이다.
- **pip와 차이**

| | pip | conda |
|---|---|---|
| 설치 대상 | 파이썬 패키지만 (PyPI) | 파이썬 + 파이썬 아닌 것(CUDA 런타임, C 라이브러리)까지 |
| 환경 관리 | 없음 (`venv`를 따로 써야 함) | `conda create`로 환경 생성·전환 |
| 파이썬 버전 | 바꿀 수 없음 | 환경마다 지정 (`python=3.11`) |

- **실무 흐름**: conda로 환경과 파이썬 버전을 만들고, 그 안에서 `pip install`로 라이브러리 설치 (PyTorch도 공식 사이트 안내 명령을 그대로 사용)
- **주의**
  - 설치 전에 `conda activate 환경이름`으로 들어갔는지 확인 (프롬프트 앞 `(env)` 표시)
  - 한 환경에서 conda와 pip를 섞으면 충돌할 수 있으니 순서를 지킨다
  - `pip freeze > requirements.txt` / `conda env export > environment.yml`로 환경을 기록하면 다른 PC에서 똑같이 재현 가능
- VSCode·Jupyter에서는 이 환경의 python을 **인터프리터/커널로 선택**해야 한다 → [[VSCode]]

## 수식·원리
```
base ─┬─ env_dl  (python 3.11, torch 2.4 + CUDA)
      └─ env_ros (python 3.10, 다른 버전들)   ← 서로 독립
```

## 코드 예시
```
conda create -n dl python=3.11 -y
conda activate dl
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install numpy matplotlib scikit-learn jupyter
conda env list                 # 환경 목록 (* = 현재)
pip freeze > requirements.txt  # 설치 목록 저장
```
```python
import sys, os
print("가상환경:", sys.prefix != sys.base_prefix or "CONDA_DEFAULT_ENV" in os.environ)
```
