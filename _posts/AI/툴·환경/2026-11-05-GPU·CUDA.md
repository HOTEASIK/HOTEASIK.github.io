# GPU·CUDA

## 정의·핵심
- **GPU**: 수천 개의 작은 코어로 **같은 계산을 동시에** 처리하는 장치. 딥러닝은 대부분 행렬 곱이라 GPU에서 수십 배 빨라진다.
- **CPU와 차이**
  - CPU: 강한 코어 몇 개 → 복잡한 순차 작업(데이터 읽기·전처리·제어)
  - GPU: 약한 코어 수천 개 → 단순 병렬 계산(행렬 곱, 합성곱)
  - 그래서 데이터 준비는 CPU(DataLoader), 모델 계산은 GPU가 맡는다
- **CUDA**: NVIDIA GPU에서 범용 계산을 하게 해 주는 병렬 컴퓨팅 플랫폼. PyTorch는 CUDA 버전에 맞춰 빌드되어 있다(`cu121` 등). 그래픽 드라이버가 그 버전 이상을 지원해야 한다.
  - `torch.cuda.is_available()`: CUDA를 쓸 수 있는지
  - `torch.version.cuda`: PyTorch가 쓰는 CUDA 버전
- **`nvidia-smi`**: GPU 이름, 메모리 사용량(MiB), 사용률, 드라이버·CUDA 버전 확인
- **GPU 메모리에 올라가는 것**: 모델 파라미터 + **활성화(중간 결과, 역전파용)** + 기울기 + 옵티마이저 상태(Adam은 파라미터의 2배)
- **OOM (Out Of Memory)**: `CUDA out of memory` 오류. 해결 순서
  1. **배치 크기 줄이기** (16 → 8 → 4)
  2. 입력 크기 줄이기 (imgsz 640 → 416)
  3. AMP(FP16)로 메모리 절반 → [[AMP(혼합 정밀도)]]
  4. Gradient Accumulation으로 유효 배치 유지 → [[Gradient Accumulation]]
  5. 평가 때 `torch.no_grad()` (활성화 저장 안 함)
  6. 노트북이면 남은 변수 `del` 후 `torch.cuda.empty_cache()`
- **시간 측정 주의**: GPU는 비동기로 실행되므로 시간을 잴 때 `torch.cuda.synchronize()`를 먼저 부른다 (보충 2_6)

## 수식·원리
```
메모리 ≈ 파라미터 + 기울기 + 옵티마이저 상태 + 활성화(배치 크기에 비례)
                                                  └ OOM의 주범 → 배치 줄이기
```

## 코드 예시
```python
import torch, time

print(torch.cuda.is_available(), torch.version.cuda)
if torch.cuda.is_available():
    print(torch.cuda.get_device_name(0))
    x = torch.randn(4096, 4096, device="cuda")
    torch.cuda.synchronize(); t = time.time()
    y = x @ x
    torch.cuda.synchronize()                 # GPU 작업이 끝날 때까지 기다린 뒤 측정
    print(f"GPU {time.time()-t:.4f}s")
    print(torch.cuda.memory_allocated() // 2**20, "MiB")   # 128 MiB 정도 (x, y 두 개)
    del x, y; torch.cuda.empty_cache()
    print(torch.cuda.memory_allocated() // 2**20, "MiB")   # 8 MiB 정도 (cuBLAS 작업 공간만 남음)
```
