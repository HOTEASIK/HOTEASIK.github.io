# Kaggle

## 정의·핵심
- **정의**: 데이터 과학 대회·공개 데이터셋·노트북 공유 플랫폼(kaggle.com). 강의 실습 데이터 일부를 여기서 받는다 (예: 응용 13차시 **Chest X-Ray 폐렴** 데이터, 개·고양이 분류 등).
- **데이터 받는 방법 두 가지**
  1. 웹에서 `Download` → zip을 Colab에 업로드하거나 드라이브에 저장
  2. **Kaggle API** (`pip install kaggle`) — 큰 데이터를 Colab 서버로 바로 받기
- **API 준비**
  - kaggle.com → `Settings → API → Create New Token` → `kaggle.json`(사용자 이름 + 키) 다운로드
  - `~/.kaggle/kaggle.json`에 두고 권한 `chmod 600` (Colab: 업로드 후 복사) — **키 파일을 공유·커밋하지 않는다**
  - 또는 환경변수 `KAGGLE_USERNAME`, `KAGGLE_KEY`
- **명령**
  - 데이터셋: `kaggle datasets download -d <작성자>/<데이터셋이름> --unzip -p data/`
  - 대회: `kaggle competitions download -c <대회이름>` (대회 규칙 동의 먼저)
- **받은 뒤**: 폴더 구조(`train/NORMAL`, `train/PNEUMONIA` …)를 확인하고 [[ImageFolder]]로 읽거나 Custom Dataset 작성
- 데이터셋 페이지의 **라이선스·설명(클래스 불균형, 분할 방식)** 을 꼭 읽는다

## 수식·원리
```
kaggle.json ─▶ kaggle datasets download -d user/name --unzip ─▶ data/train/<클래스>/*.jpg ─▶ ImageFolder
```

## 코드 예시
```
pip install kaggle
mkdir -p ~/.kaggle && cp kaggle.json ~/.kaggle/ && chmod 600 ~/.kaggle/kaggle.json
kaggle datasets download -d paultimothymooney/chest-xray-pneumonia --unzip -p data/
ls data/chest_xray/train        # NORMAL  PNEUMONIA
```
