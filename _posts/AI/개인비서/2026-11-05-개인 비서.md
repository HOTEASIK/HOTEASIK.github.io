방법 1. Ollama에 내 파인 튜닝 모델 등록 후 연동하기 (가장 추천)

파인 튜닝된 가중치 파일(GGUF 형식 등)이 있다면, Ollama의 Modelfile을 이용해 나만의 로컬 모델로 커스텀 등록한 뒤 시메지 앱과 연결할 수 있습니다.

1단계: Ollama에 내 모델 등록하기

1. 메모장을 열고 파일명을 Modelfile (확장자 없음)로 생성합니다.
2. 아래 내용을 입력하고 저장합니다. (파인 튜닝한 GGUF 파일 경로와 펫의 기본 세계관/성격을 지정)dockerfile
FROM /path/to/your/fine-tuned-model.gguf

# 펫의 페르소나 설정
SYSTEM "너는 주인을 보좌하는 귀여운 AI 데스크톱 펫 '모모'야. 짧고 친절하게 대답해줘."

# 창의성 조절 (필요시)
PARAMETER temperature 0.7
코드를 사용할 때는 주의가 필요합니다.
3. 터미널(명령 프롬프트)을 열고 아래 명령어를 입력해 Ollama에 모델을 빌드합니다.bash
ollama create my-desktop-pet -f ./Modelfile
코드를 사용할 때는 주의가 필요합니다.
4. 등록이 완료되면 잘 작동하는지 확인합니다.bash
ollama run my-desktop-pet
코드를 사용할 때는 주의가 필요합니다.

2단계: 데스크톱 펫 프로그램과 연결하기

Ollama는 실행 시 로컬에서 OpenAI와 호환되는 API 서버(http://localhost:11434/v1)를 자동으로 띄워줍니다.
시메지 AI 프로그램의 환경설정 파일(config.json 또는 .env)에서 주소를 로컬로 돌려주면 끝납니다.
json
{
  "OPENAI_API_BASE": "http://localhost:11434/v1",
  "OPENAI_API_KEY": "ollama", 
  "MODEL": "my-desktop-pet" 
}
코드를 사용할 때는 주의가 필요합니다.
• Tip: API Key 칸에는 아무 글자나 입력해도 로컬에서 정상 작동합니다. 모델명(MODEL) 구문에는 방금 내가 Ollama에 등록한 이름(my-desktop-pet)을 적어줍니다.

방법 2. 파인 튜닝 모델을 Python 코드로 직접 구동하여 연동하기

만약 Hugging Face 형식(safetensors 등)으로 파인 튜닝을 진행했고, Ollama로 변환하기 번거롭다면 시메지 프로그램의 백엔드(Python 코드)에서 모델을 직접 로드하는 방식을 씁니다.
GitHub에서 다운로드한 시메지 AI 프로그램의 메인 대화 로직 소스코드(예: agent.py 또는 llm.py)를 직접 수정합니다.
python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# 1. 내가 파인 튜닝한 로컬 모델 폴더 경로 지정
model_path = "./my_finetuned_pet_model"
tokenizer = AutoTokenizer.from_pretrained(model_path)
model = AutoModelForCausalLM.from_pretrained(model_path, torch_dtype=torch.float16, device_map="auto")

# 2. 시메지 대화창에서 입력이 들어왔을 때 실행되는 함수 수정
def generate_pet_response(user_input):
    messages = [
        {"role": "system", "content": "너는 귀여운 데스크톱 펫 비서야."},
        {"role": "user", "content": user_input}
    ]
    
    # 모델 포맷에 맞게 토큰화 및 답변 생성
    input_ids = tokenizer.apply_chat_template(messages, return_tensors="pt").to("cuda")
    outputs = model.generate(input_ids, max_new_tokens=150, temperature=0.7)
    
    response = tokenizer.decode(outputs[0][input_ids.shape[-1]:], skip_special_tokens=True)
    return response
코드를 사용할 때는 주의가 필요합니다.
• 이 방식은 내 그래픽카드(VRAM)의 성능이 좋아야 데스크톱 펫이 버벅이지 않고 부드럽게 화면을 돌아다니며 답변할 수 있습니다.
