# 경사하강법(GD)

## 정의·핵심
- **정의**: 손실 함수의 **기울기(Gradient)의 반대 방향으로 파라미터를 조금씩 이동**시켜 손실을 최소화하는 최적화 방법. "틀린 부분을 조금씩 고쳐 나가며 정답에 가까워지는 것" — 모든 딥러닝 학습의 심장 (개론 4·5차시)
- **비유: 안갯속에서 산 내려오기**
  - **현재 고도 = 손실(Loss)**: 가장 낮은 지점(Global Minimum)이 목표
  - **발밑의 기울기 = 그라디언트**: 어느 방향으로 갈지 (가파를수록 크게 이동)
  - **보폭 = 학습률(Learning Rate)**: 한 번에 얼마나 이동할지 (너무 크면 지나치고, 작으면 느림)
  - 전체 지도를 몰라도 **현재 위치의 기울기(지역 정보)만으로** 전진할 수 있다
- **왜 기울기의 반대 방향인가**: 기울기 ∇L은 손실이 **가장 빠르게 증가하는 방향**이다. 그 반대로 가면 가장 빠르게 감소한다
- **경사하강법의 4단계**: 예측 계산 → 손실 계산 → 경사 계산 → 파라미터 수정 (반복) → [[학습 루프 4단계]]
- **데이터 전처리 팁**: 입력 값이 크면(신장 170 등) 기울기가 커서 불안정 → 평균을 빼서 0 근처로 (강의: `X = x - x.mean()`) → [[표준화(StandardScaler)]]
- **기울기를 몇 개 데이터로 계산하나**에 따라 세 종류 → [[배치 경사하강법(Full Batch)]], [[확률적 경사하강법(SGD)]], [[미니배치·배치 크기]]
- **한계**: 국소 최솟값·안장점에 갇힘, 학습률 선택에 민감 → Momentum, Adam 같은 개선 옵티마이저

## 수식·원리
```
W ← W − η · ∂L/∂W
B ← B − η · ∂L/∂B          (η = 학습률)
강의 결과(신장→체중, lr=0.001, 500 에폭): W=1.82, B=0.37, 손실 13.35 → 4.67
```

## 코드 예시
```python
import numpy as np
import torch

data = np.array([[166, 58.7], [176.0, 75.7], [171.0, 62.1], [173.0, 70.4], [169.0, 60.1]])
x, y = data[:, 0], data[:, 1]
X = torch.tensor(x - x.mean()).float(); Y = torch.tensor(y - y.mean()).float()

W = torch.tensor(1.0, requires_grad=True)
B = torch.tensor(1.0, requires_grad=True)
lr = 0.001
for epoch in range(500):
    loss = ((W * X + B - Y) ** 2).mean()
    loss.backward()
    with torch.no_grad():          # 그냥 W -= ... 하면 RuntimeError (leaf in-place)
        W -= lr * W.grad
        B -= lr * B.grad
        W.grad.zero_(); B.grad.zero_()
print(round(W.item(), 2), round(B.item(), 2), round(loss.item(), 2))   # 1.82 0.37 4.67
```
