# Adagrad

## 정의·핵심
- **정의**: Adaptive Gradient. 파라미터마다 **지금까지의 기울기 제곱을 모두 더한 값**으로 학습률을 나눠, 자주·크게 업데이트된 파라미터는 학습률을 줄이고 드물게 업데이트된 파라미터는 크게 유지하는 최초의 적응형 옵티마이저
- **장점**: **희소한 특징**(가끔만 등장하는 단어 임베딩 등)에 강하다 — 드물게 나오는 특징은 누적값이 작아 큰 보폭으로 학습
- **치명적 단점**: 기울기 제곱 누적 G가 **계속 커지기만** 해서 학습률 `η/√G`가 점점 0에 가까워진다 → 긴 학습에서 **학습이 멈춘다**
- **후속 개선**: 누적 대신 지수 이동 평균을 쓰는 **RMSprop**, 여기에 모멘텀을 더한 **Adam** → [[RMSprop]], [[Adam]]
- PyTorch: `optim.Adagrad(params, lr=0.01)`

## 수식·원리
```
G ← G + g²                 (계속 누적)
W ← W − η · g / (√G + ε)
→ t가 커질수록 유효 학습률 η/√G ↓
```

## 코드 예시
```python
import torch

w = torch.tensor([5.0], requires_grad=True)
opt = torch.optim.Adagrad([w], lr=1.0)
moves = []
for _ in range(100):
    opt.zero_grad()
    loss = (w - 100) ** 2 / 2                 # 목표 100, 기울기 크기가 거의 일정
    loss.backward()
    before = w.item(); opt.step(); moves.append(w.item() - before)
print(round(moves[0], 2), round(moves[-1], 2))   # 1.0 0.09  ← 보폭이 약 1/√t로 줄어듦
print(w.item() < 30)                             # True  목표(100)에 한참 못 미침
```
