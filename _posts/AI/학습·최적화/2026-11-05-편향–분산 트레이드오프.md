# 편향–분산 트레이드오프

## 정의·핵심
- **정의**: 모델의 예측 오차는 **편향(Bias)²+ 분산(Variance) + 줄일 수 없는 잡음**으로 나뉘며, 모델 복잡도를 바꾸면 **하나가 줄 때 다른 하나가 늘어나는** 관계 (개론 4차시 실습 "편향–분산 관찰, 데이터 분할 누수 방지")
- **편향(Bias)**: 모델이 **너무 단순해서** 진짜 패턴을 표현하지 못해 생기는 **체계적인 오차**
  - 예: 곡선 데이터에 직선 → 데이터를 바꿔 다시 학습해도 늘 같은 방향으로 틀림
  - 높으면 **과소적합** (훈련 오차도 큼)
- **분산(Variance)**: 모델이 **너무 복잡해서** 훈련 데이터의 잡음까지 맞춰, **데이터가 조금만 달라져도 예측이 크게 흔들리는** 오차
  - 높으면 **과적합** (훈련 오차 작음, 검증 오차 큼)
- **과녁 비유**: 편향 = 화살이 중심에서 **한쪽으로 치우침**, 분산 = 화살이 **넓게 흩어짐**
- **진단표**

| 훈련 오차 | 검증 오차 | 상태 | 대응 |
|---|---|---|---|
| 높음 | 높음 | 고편향 (과소적합) | 모델 키우기, 특징 추가, 더 학습, 규제 줄이기 |
| 낮음 | 높음 | 고분산 (과적합) | 데이터·증강, 규제, Dropout, 모델 줄이기 |
| 낮음 | 낮음 | 적당 | — |

- **딥러닝에서는**: 큰 모델 + 충분한 데이터 + 규제 조합으로 둘 다 낮추는 경우가 많다 (매우 큰 모델은 오히려 일반화가 다시 좋아지는 "double descent"도 관찰됨)

## 수식·원리
```
E[(y − f̂(x))²] = Bias[f̂(x)]² + Var[f̂(x)] + σ²(잡음)
복잡도 ↑ → Bias ↓, Variance ↑
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)
x0 = 0.25; truth = np.sin(2 * np.pi * x0)
for deg in (1, 9):
    preds = []
    for _ in range(200):                                     # 데이터셋을 200번 새로 뽑아 학습
        x = rng.uniform(0, 1, 15); y = np.sin(2 * np.pi * x) + rng.normal(0, 0.3, 15)
        preds.append(np.polyval(np.polyfit(x, y, deg), x0))
    preds = np.array(preds)
    print(deg, round((preds.mean() - truth) ** 2, 3), round(preds.var(), 3))
# 1 0.25 0.04      편향² 큼, 분산 작음
# 9 0.002 15.817   편향² 거의 0, 분산 매우 큼
```
