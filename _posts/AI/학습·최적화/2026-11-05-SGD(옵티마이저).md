# SGD(옵티마이저)

## 정의·핵심
- **정의**: PyTorch의 `torch.optim.SGD`. 가장 기본적인 최적화 함수로, 받은 기울기에 학습률을 곱해 빼 준다. `W ← W − η·∇W` (개론 12차시)
- **최적화 함수의 역할**: "손실 함수라는 내비게이션이 알려주는 '가장 낮은 손실 값'이라는 목적지를 향해, 경사 정보를 보고 파라미터를 조작하여 나아가는" 학습의 주체
- **사용법**: `optim.SGD(model.parameters(), lr=0.01, momentum=0, weight_decay=0, nesterov=False)`
  - `momentum=0.9`를 주면 Momentum SGD → [[Momentum]]
  - `weight_decay`: L2 규제 → [[L2 규제(Ridge, weight_decay)]]
  - `nesterov=True`: 한 발 앞의 위치에서 기울기를 보는 Nesterov 모멘텀
- **특징**
  - 직관적이고 계산·메모리가 가장 적다 (추가 상태 없음)
  - 단점: 모든 파라미터에 **같은 학습률** → 수렴이 느리고, 지역 최솟값에 갇히거나 협곡에서 지그재그
  - 강의 비교(12차시, CNN_v2): SGD 50 에폭 **70%**, 초반 3 에폭은 10%에 정체 / Momentum·Adam 20 에폭 76.56%
- **그래도 쓰이는 이유**: 잘 튜닝한 **SGD + Momentum + 스케줄러**는 이미지 분류(ResNet 등)에서 Adam보다 일반화가 좋은 경우가 많다
- **직접 구현과 같다**: 강의의 `W.data -= lr * W.grad.data`를 `optimizer.step()` 한 줄로 대신하고, `zero_grad()`로 기울기 초기화도 대신해 준다

## 수식·원리
```
W ← W − η · g                  (g = ∇L, 이번 배치 기울기)
weight_decay λ:  g ← g + λW
```

## 코드 예시
```python
import torch

W = torch.tensor([1.0, -2.0], requires_grad=True)
opt = torch.optim.SGD([W], lr=0.1)
loss = (W ** 2).sum()            # ∇ = 2W = [2, -4]
loss.backward()
opt.step()
print([round(v, 2) for v in W.tolist()])   # [0.8, -1.6]  = W − 0.1 × [2, −4]

# 직접 구현과 비교 (강의 방식)
V = torch.tensor([1.0, -2.0], requires_grad=True)
(V ** 2).sum().backward()
V.data -= 0.1 * V.grad.data
print(torch.allclose(W, V))      # True
```
