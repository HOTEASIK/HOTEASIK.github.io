# NLLLoss

## 정의·핵심
- **정의**: Negative Log Likelihood Loss, 음의 로그 우도. **이미 로그 확률이 된 입력**에서 **정답 클래스 위치의 값만 골라 −를 붙여** 평균내는 손실 (개론 9차시 "초간단 NLLLoss, KL Divergence 정리")
- **스스로는 log도 softmax도 하지 않는다**: 입력이 로그 확률이라고 믿고 인덱싱만 한다 → 반드시 앞에 `LogSoftmax`가 있어야 의미가 있다
  - `nn.LogSoftmax(dim=1)` + `nn.NLLLoss()` = `nn.CrossEntropyLoss()` → [[LogSoftmax]]
- **이름의 의미**
  - **Likelihood(우도)**: 모델이 정답에 준 확률 p(y|x)
  - **Log**: 곱을 합으로, 작은 확률도 다루기 쉽게
  - **Negative**: 우도는 **최대화**하고 싶지만 손실은 **최소화** → − 붙임
  - 즉 NLL 최소화 = **최대우도추정(MLE)** → [[MLE(최대우도추정)]]
- **언제 직접 쓰나**: 모델 클래스 안에 LogSoftmax를 넣는 **패턴2** 설계(출력이 바로 로그 확률), 시퀀스 모델의 토큰별 손실
- 정답은 클래스 인덱스(`long`), `weight`·`ignore_index` 옵션은 CrossEntropyLoss와 같다

## 수식·원리
```
NLL(logp, y) = −(1/N) Σᵢ logpᵢ[yᵢ]
logp = log_softmax(z) 이면  NLL = CrossEntropy
```

## 코드 예시
```python
import torch
import torch.nn as nn

logp = torch.log(torch.tensor([[0.7, 0.2, 0.1], [0.1, 0.8, 0.1]]))
y = torch.tensor([0, 1])
print(round(nn.NLLLoss()(logp, y).item(), 4))                       # 0.2899
print(round(-(logp[0, 0] + logp[1, 1]).item() / 2, 4))              # 0.2899  ← 정답 위치만 골라 − 평균

z = torch.randn(4, 5); t = torch.tensor([0, 3, 1, 4])
print(torch.allclose(nn.NLLLoss()(torch.log_softmax(z, 1), t), nn.CrossEntropyLoss()(z, t)))   # True
print(nn.NLLLoss()(torch.tensor([[2.0, 5.0]]), torch.tensor([1])).item())   # -5.0  ← 로그 확률이 아니면 의미 없는 값
```
