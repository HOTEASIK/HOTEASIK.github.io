# Momentum

## 정의·핵심
- **정의**: SGD에 **관성(속도)** 개념을 더한 방법. **과거 기울기를 기억해 현재 기울기와 합쳐서** 이동한다. (개론 12차시: "관성 개념을 도입하여 SGD를 개선")
- **비유**: 언덕을 굴러 내려가는 공. 같은 방향으로 계속 내려가면 점점 빨라지고, 방향이 자꾸 바뀌는 곳(진동)에서는 서로 상쇄되어 흔들림이 줄어든다
- **효과**
  - **빠른 수렴**: 일관된 방향으로는 가속
  - **진동 감소**: 좁은 협곡에서 좌우로 튀는 성분은 상쇄
  - **지역 최솟값 탈출**: 관성으로 작은 웅덩이나 평지를 지나쳐 감 → [[국소 최솟값(Local Minimum)]]
- **β(모멘텀 계수)**: 보통 **0.9** — 과거 속도를 90% 유지. `optim.SGD(params, lr=0.01, momentum=0.9)`
- **Nesterov Momentum** (`nesterov=True`): 관성으로 갈 위치를 먼저 보고 거기서 기울기를 계산 → 지나치는 것을 덜 함
- 강의 결과(12차시): Momentum **20 에폭 76.56%** — SGD(50 에폭 70%)보다 빠르고 높다
- Adam의 1차 모멘트(m)가 바로 이 아이디어 → [[Adam]]

## 수식·원리
```
v ← β·v + g            (PyTorch 방식, g = 현재 기울기)
W ← W − η·v
β = 0.9 이면 최근 약 10스텝 기울기의 (가중) 누적
```

## 코드 예시
```python
import torch

def steps_to_converge(momentum):
    w = torch.tensor([3.0, 3.0], requires_grad=True)
    opt = torch.optim.SGD([w], lr=0.01, momentum=momentum)
    for i in range(1, 2001):
        opt.zero_grad()
        loss = 0.5 * w[0] ** 2 + 10 * w[1] ** 2      # 한쪽만 가파른 협곡
        loss.backward(); opt.step()
        if loss.item() < 1e-6:
            return i
    return None

print(steps_to_converge(0.0), steps_to_converge(0.9))    # 764 134  ← 모멘텀이 약 6배 빠름
```
