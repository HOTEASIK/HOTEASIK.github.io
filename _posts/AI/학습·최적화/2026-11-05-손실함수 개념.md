# 손실함수 개념

## 정의·핵심
- **정의**: 모델의 **예측값과 실제 정답 사이의 차이를 하나의 숫자로 나타내는** 함수. 값이 작을수록 더 정확하게 예측하고 있다는 뜻 (개론 6차시)
- **Loss vs Cost**
  - **Loss(손실)**: 데이터 **한 개**에 대한 오차
  - **Cost(비용)**: 데이터 **전체(또는 배치)** 의 손실 평균 — 실제로 최소화하는 값
  - 실무에서는 둘을 섞어 쓴다 (PyTorch는 기본 `reduction='mean'`으로 배치 평균을 돌려줌)
- **주요 목적**
  1. 모델의 오류 정도 **측정**
  2. **학습 방향 결정** — 손실의 기울기가 파라미터를 어느 쪽으로 바꿀지 알려준다
  3. 최적화 알고리즘의 **가이드** ("내비게이션")
- **좋은 손실함수의 조건**: 미분 가능(역전파), 문제의 목표와 일치, 수치적으로 안정
- **문제별 선택 가이드**

| 문제 | 출력층 | 손실함수 |
|---|---|---|
| 회귀 | 항등(없음) | MSE, MAE, Huber |
| 이진분류 | 로짓 1개 | **BCEWithLogitsLoss** (Sigmoid 내장) |
| 다중분류 | 로짓 K개 | **CrossEntropyLoss** (Softmax 내장) |
| 불균형 분류 | 로짓 | Weighted CE, Focal Loss |
| 검출 박스 회귀 | 좌표 | Smooth L1, IoU 계열 Loss |
| 분포 비교 | 확률 | KL Divergence |

- **손실 ≠ 평가 지표**: 손실은 학습용(미분 가능), 정확도·F1은 사람이 보는 평가용(미분 불가) → [[정확도(Accuracy)]]
- `reduction`: `'mean'`(평균, 기본), `'sum'`(합), `'none'`(샘플별 값 그대로 — 가중치를 직접 곱할 때)

## 수식·원리
```
Loss  ℓ(ŷᵢ, yᵢ)                    한 샘플
Cost  J(θ) = (1/N) Σᵢ ℓ(f_θ(xᵢ), yᵢ)  평균
학습 목표: θ* = argmin J(θ)
```

## 코드 예시
```python
import torch
import torch.nn as nn

pred = torch.tensor([12.0, 19.0, 35.0]); true = torch.tensor([10.0, 20.0, 30.0])
print(nn.MSELoss(reduction="none")(pred, true).tolist())   # [4.0, 1.0, 25.0]  샘플별 Loss
print(nn.MSELoss()(pred, true).item())                      # 10.0  평균 = Cost
print(nn.MSELoss(reduction="sum")(pred, true).item())       # 30.0
```
