# 데이터 증강

## 정의·핵심
- **정의**: Data Augmentation. 가지고 있는 데이터를 **뒤집기·회전·자르기·밝기 조절** 등으로 인위적으로 변형해 데이터의 양과 다양성을 늘리는 방법. 모델이 **매번 조금씩 다른 데이터**를 학습하게 되어 과적합을 줄인다 (개론 1·12차시)
- **원리**: "고양이 사진을 좌우로 뒤집어도 고양이" — **라벨이 바뀌지 않는 변형**을 가르쳐 모델이 위치·방향·조명에 흔들리지 않게(불변성) 한다
- **강의에서 쓴 증강 (1차시 intro)**
  - `RandomHorizontalFlip(p=0.5)`: 50% 확률로 좌우 반전 → 데이터 2배 효과, 동물처럼 좌우 대칭인 대상에 유용
  - `RandomErasing(p=0.5, scale=(0.02, 0.33), ratio=(0.3, 3.3), value=0)`: 50% 확률로 이미지 일부(전체의 2~33%, 가로세로비 0.3~3.3)를 지움 → 모델이 특정 부분에만 의존하지 못하게 강제, 일반화 향상
    - **ToTensor 뒤에** 둬야 한다 (텐서에 동작)
  - 그 밖에 `RandomResizedCrop`, `RandomRotation`, `ColorJitter`(밝기·대비·채도), `RandomAffine`
- **중요 규칙**
  - **학습 데이터에만** 적용. 검증·테스트는 Resize·CenterCrop·Normalize만 → 일관된 성능 평가 보장
  - **라벨을 바꾸는 변형은 금지**: 숫자 6을 180° 회전하면 9, 좌우 반전된 글자, 의료영상의 좌우(심장 위치)
  - 증강은 **에폭마다 무작위로 새로** 적용된다 (데이터를 미리 늘려 저장하는 것이 아님)
- **고급 증강**: Mixup·CutMix(두 이미지·라벨을 섞음) → [[Mixup]], Mosaic(검출용, 4장 합치기) → [[검출용 데이터 증강]], AutoAugment·RandAugment

## 수식·원리
```
train_tf = Compose([RandomHorizontalFlip(0.5), Resize(224), CenterCrop(224),
                    ToTensor(), Normalize(0.5, 0.5), RandomErasing(0.5)])
test_tf  = Compose([Resize(224), CenterCrop(224), ToTensor(), Normalize(0.5, 0.5)])
```

## 코드 예시
```python
import torch
from torchvision import transforms
from PIL import Image
import numpy as np

img = Image.fromarray(np.arange(64 * 64 * 3, dtype=np.uint8).reshape(64, 64, 3))
train_tf = transforms.Compose([
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.ToTensor(),
    transforms.Normalize(0.5, 0.5),
    transforms.RandomErasing(p=1.0, scale=(0.02, 0.33), ratio=(0.3, 3.3), value=0),
])
torch.manual_seed(0)
a, b = train_tf(img), train_tf(img)
print(a.shape, torch.equal(a, b))         # torch.Size([3, 64, 64]) False  ← 호출할 때마다 다른 결과
print((a == 0).float().mean().item() > 0)  # True  지워진 영역 존재
```
