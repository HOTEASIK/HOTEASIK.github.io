# MAE(L1Loss)

## 정의·핵심
- **정의**: Mean Absolute Error, 평균 절대 오차. 오차의 **절댓값을 평균**낸 값. PyTorch는 `nn.L1Loss`
- **강의 예시 (6차시)**: 실제 [10, 20, 30], 예측 [12, 19, 35] → 절댓값 [2, 1, 5] → **MAE = 2.67**
- **특징**
  - **강건성(Robust)**: 모든 오차를 같은 비율로 취급 → **이상치의 영향을 덜 받는다** (MSE처럼 제곱으로 키우지 않음)
  - **직관적 해석**: "평균적으로 2.67만큼 틀림" — 원래 단위 그대로
  - **단점**: 0 근처에서 **미분 불가능**(꺾인 점), 기울기가 항상 ±1로 일정 → 최솟값 근처에서도 보폭이 줄지 않아 **진동**하기 쉽다 (학습률 감소가 필요)
- **사용 권장 (강의)**: 이상치가 많은 데이터, 해석 가능성이 중요할 때, 모든 오차를 공평하게 평가할 때
- **MSE vs MAE 예측값의 의미**: MSE를 최소화하면 **평균**, MAE를 최소화하면 **중앙값**을 예측하는 경향
- 둘의 장점을 합친 것 → [[Huber Loss]]

## 수식·원리
```
MAE = (1/n) Σ |yᵢ − ŷᵢ|
∂MAE/∂ŷᵢ = sign(ŷᵢ − yᵢ) / n       (크기 일정, 0에서 정의 안 됨)
```

## 코드 예시
```python
import torch
import torch.nn as nn

y = torch.tensor([10.0, 20.0, 30.0]); p = torch.tensor([12.0, 19.0, 35.0])
print(round(nn.L1Loss()(p, y).item(), 2))                    # 2.67

y2 = torch.tensor([10.0, 20.0, 30.0, 40.0]); p2 = torch.tensor([11.0, 21.0, 31.0, 140.0])
print(nn.L1Loss()(p2, y2).item(), nn.MSELoss()(p2, y2).item())   # 25.75 2500.75  ← 이상치 영향 비교

data = torch.tensor([1.0, 2.0, 3.0, 100.0])
c = torch.tensor(0.0, requires_grad=True)
opt = torch.optim.SGD([c], lr=0.5)
for _ in range(2000):
    opt.zero_grad(); nn.L1Loss()(c.expand(4), data).backward(); opt.step()
print(2 <= c.item() <= 3, data.mean().item())                # True 26.5  ← MAE는 중앙값 쪽
```
