# L1 규제(Lasso)

## 정의·핵심
- **정의**: 손실에 **가중치 절댓값 합 × λ**를 더하는 규제. 선형회귀에 적용하면 **Lasso 회귀** (Least Absolute Shrinkage and Selection Operator)
- **가장 큰 특징 — 희소성(Sparsity)**: 중요하지 않은 특징의 가중치를 **정확히 0**으로 만든다 → **자동 특징 선택**
  - 이유: L1의 기울기는 가중치 크기와 상관없이 **항상 ±λ로 일정**하다. 작은 가중치도 같은 힘으로 0까지 밀어 버린다 (L2는 기울기가 2λw라 0에 가까워질수록 힘이 약해져 0에 도달하지 못함)
  - 기하학적으로: L1 제약 영역은 **마름모**(꼭짓점이 축 위)라 최적점이 꼭짓점(일부 좌표 = 0)에 걸리기 쉽다. L2는 원
- **언제 쓰나**: 특징이 많고 그중 일부만 중요할 것으로 예상될 때, 해석 가능한 모델(어떤 특징이 중요한지)이 필요할 때
- **단점**: 상관이 높은 특징 묶음에서는 **하나만 고르고 나머지를 0**으로 → 불안정. 0에서 미분 불가 → 해결: **ElasticNet** → [[ElasticNet]]
- **PyTorch**: 옵티마이저 옵션이 없어 손실에 직접 더한다 `loss = loss + λ * sum(p.abs().sum() for p in model.parameters())`
- **sklearn**: `Lasso(alpha=λ)`

## 수식·원리
```
L_total = L_data + λ Σ |wᵢ|
∂/∂w (λ|w|) = λ·sign(w)        (크기 무관 일정한 힘)
```

## 코드 예시
```python
import numpy as np
from sklearn.linear_model import Lasso, Ridge

rng = np.random.default_rng(0)
X = rng.normal(size=(100, 6))
y = 4 * X[:, 0] - 2 * X[:, 1] + rng.normal(0, 0.5, 100)    # 실제로는 특징 0, 1만 중요
print(np.round(Lasso(alpha=0.1).fit(X, y).coef_, 2))        # [ 3.89 -1.86  0.  0.  0.  0. ] ← 정확히 0
print(np.round(Ridge(alpha=10).fit(X, y).coef_, 2))         # [ 3.62 -1.77  0.01  0.07  0.06  0.13] 0은 아니고 작은 값들
print((Lasso(alpha=0.1).fit(X, y).coef_ == 0).sum())        # 4  ← 특징 4개 자동 제거
```
