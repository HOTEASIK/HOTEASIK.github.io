# Warm-up

## 정의·핵심
- **정의**: 학습 **처음 몇 스텝(또는 에폭) 동안 학습률을 0 근처에서 목표값까지 서서히 올리는** 기법. 6차시 "좋은 손실 곡면 만드는 방법"의 학습 안정성 항목: "**Warm-up: 초반 안전한 탐색**"
- **왜 필요한가**
  - 학습 초기의 가중치는 무작위라 **기울기가 크고 방향도 불안정**하다 → 처음부터 큰 학습률이면 크게 튀어 발산하거나 나쁜 영역으로 가 버린다
  - **Adam의 초반 문제**: 2차 모멘트 v의 추정이 아직 부정확해 업데이트가 과하게 커질 수 있다
  - **큰 배치 학습**: 배치를 키우며 학습률도 키우면 초반이 특히 불안정
  - **Transformer**(BERT, GPT, ViT)는 warm-up 없이는 잘 학습되지 않는 경우가 많다
- **보통의 조합**: Warm-up(선형 증가) → Cosine 또는 Linear 감소
  - Hugging Face: `get_linear_schedule_with_warmup`, `TrainingArguments(warmup_ratio=0.1)`
  - ultralytics YOLO: `warmup_epochs=3`
  - PyTorch: `LinearLR(start_factor=0.01, total_iters=N)` + `SequentialLR`
  - OneCycleLR은 warm-up이 내장된 스케줄 → [[OneCycleLR]]
- **warm-up 길이**: 전체 스텝의 5~10% 정도가 흔하다

## 수식·원리
```
t < T_w:   η_t = η_max · t / T_w          (선형 warm-up)
t ≥ T_w:   감소 스케줄 (cosine 등)
```

## 코드 예시
```python
import torch
from torch.optim.lr_scheduler import LinearLR, CosineAnnealingLR, SequentialLR

w = torch.zeros(1, requires_grad=True)
opt = torch.optim.AdamW([w], lr=1e-3)
warm = LinearLR(opt, start_factor=0.25, total_iters=3)      # 3스텝 동안 0.25배 → 1배
cos = CosineAnnealingLR(opt, T_max=5)
sched = SequentialLR(opt, schedulers=[warm, cos], milestones=[3])
lrs = []
for step in range(8):
    lrs.append(round(opt.param_groups[0]["lr"] * 1e4, 2)); opt.step(); sched.step()
print(lrs)    # [2.5, 5.0, 7.5, 10.0, 9.05, 6.55, 3.45, 0.95]  (×1e-4)  증가 후 감소
```
