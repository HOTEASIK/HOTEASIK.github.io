# 학습률

## 정의·핵심
- **정의**: Learning Rate(η, lr). 경사하강법에서 기울기 방향으로 **한 번에 얼마나 이동할지(보폭)** 정하는 값. 가장 중요한 하이퍼파라미터
- **너무 크면**: 최솟값을 **지나쳐 버린다** → 손실이 진동하거나 점점 커지다가 **발산**, 결국 `inf`·**`NaN`** 이 된다
  - NaN이 한 번 생기면 모든 파라미터로 퍼져서 복구 불가 → 학습 재시작
- **너무 작으면**: 수렴이 **매우 느리고**, 국소 최솟값·평평한 구간에 갇히기 쉽다
- **적당하면**: 초반 빠르게 감소 → 완만하게 수렴
- **흔한 시작값**
  - SGD: 0.1 ~ 0.01 (Momentum 0.9와 함께)
  - Adam: **1e-3** (기본값), 전이학습 미세조정: 1e-4 ~ 1e-5
- **찾는 방법**: 로그 스케일로 여러 값 시도(1e-1, 1e-2, 1e-3, 1e-4) → `suggest_float(..., log=True)` → [[Optuna]]
- **학습 중 바꾸기**: 처음엔 크게, 나중엔 작게 → [[학습률 스케줄러 개념]], 처음 몇 스텝은 작게 시작 → [[Warm-up]]
- 현재 값 확인: `optimizer.param_groups[0]['lr']`

## 수식·원리
```
W ← W − η·∇L
예) L = w²,  ∇L = 2w:   w ← w(1 − 2η)
   η < 1   → |1−2η| < 1 → 수렴
   η > 1   → |1−2η| > 1 → 발산 (진동하며 커짐)
```

## 코드 예시
```python
import torch

def run(lr, steps=50):
    w = torch.tensor(5.0, requires_grad=True)
    for _ in range(steps):
        loss = w ** 2
        loss.backward()
        with torch.no_grad():
            w -= lr * w.grad; w.grad.zero_()
    return w.item()

print(round(run(0.001), 2))      # 4.52   너무 작음 → 거의 안 움직임
print(round(run(0.1), 4))        # 0.0001 적당 → 0에 수렴
print(run(1.5, 2000))            # nan    너무 큼 → 발산(inf → nan)
```
