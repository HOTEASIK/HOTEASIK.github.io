# 로짓(Logit)

## 정의·핵심
- **정의**: 분류 모델의 마지막 Linear 층이 내놓는 **Sigmoid·Softmax를 거치기 전의 원시 점수**. 범위 제한이 없는 실수(−∞ ~ ∞)
- **원래 수학적 의미**: 확률 p의 **로그 오즈(log-odds)** `logit(p) = log(p / (1−p))` — Sigmoid의 역함수
  - p = 0.5 → 로짓 0, p = 0.9 → 2.197, p = 0.1 → −2.197
  - 로짓이 1 커지면 오즈(p/(1−p))가 e배
- **딥러닝에서 로짓을 그대로 다루는 이유**
  - 손실함수 `BCEWithLogitsLoss`, `CrossEntropyLoss`가 **로짓을 받아 내부에서 안정적으로** Sigmoid/Softmax + log를 계산 → [[log-sum-exp trick]]
  - 확률로 바꾼 뒤 log를 하면 0으로 반올림되어 `−inf`가 생길 수 있다
- **예측할 때**
  - 이진: `logits > 0` ⇔ `sigmoid(logits) > 0.5`
  - 다중: `logits.argmax(1)` = `softmax(logits).argmax(1)` (확률 변환 없이 라벨만 구할 수 있음) → [[예측 라벨 구하기]]
- **로짓의 크기 = 확신 정도**: 차이가 클수록 확신. 과신을 줄이려면 Label Smoothing, Temperature Scaling(`logits / T`) → [[Temperature Scaling]]
- 변수 이름으로 `outputs`, `logits`를 쓰면 "아직 확률이 아님"을 기억하기 쉽다

## 수식·원리
```
logit(p) = log(p / (1 − p)) = σ⁻¹(p)
σ(logit(p)) = p
다중분류: zₖ = wₖ·h + bₖ,  p = softmax(z)
```

## 코드 예시
```python
import torch

p = torch.tensor([0.1, 0.5, 0.9])
z = torch.logit(p)
print([round(v, 3) for v in z.tolist()])                  # [-2.197, 0.0, 2.197]
print(torch.allclose(torch.sigmoid(z), p))                # True  Sigmoid의 역함수

logits = torch.tensor([[1.2, -0.3, 3.1], [0.0, 2.0, 1.0]])
print(logits.argmax(1).tolist(), torch.softmax(logits, 1).argmax(1).tolist())   # [2, 1] [2, 1]
```
