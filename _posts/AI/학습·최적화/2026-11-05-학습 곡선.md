# 학습 곡선

## 정의·핵심
- **정의**: 에폭(또는 이터레이션)에 따라 **훈련·검증 손실과 정확도가 어떻게 변하는지** 그린 그래프. 학습이 잘 되고 있는지 진단하는 가장 기본 도구 (개론 4·12차시)
- **기록 방법**: 에폭마다 `history`에 `[epoch, train_loss, train_acc, val_loss, val_acc]`를 쌓아 두고 matplotlib으로 그린다 → [[학습 곡선 그리기]]
- **곡선 읽는 법**

| 모양 | 진단 | 대응 |
|---|---|---|
| 초반 급감 → 완만하게 수렴 | 정상 ("아름다운 곡선") | — |
| 훈련·검증 모두 높게 정체 | **과소적합** | 모델 키우기, 학습 더, 학습률 조정 |
| 훈련↓ 계속, **검증은 최소 후 다시 ↑** | **과적합** | Dropout, 증강, 규제, Early Stopping |
| 손실이 위아래로 크게 출렁 | 학습률이 큼 / 배치 작음 | lr 낮추기, 스케줄러 |
| 손실이 `nan`·폭증 | 발산 | lr 크게 낮추기, 기울기 클리핑 |
| 초반 몇 에폭 정확도 10%에 머묾 | 깊은 망 + SGD의 느린 시작 | Momentum·Adam, BN (12차시 CNN_v2 사례) |

- **훈련 vs 검증 차이(gap)**: 두 곡선 사이가 벌어질수록 일반화가 안 되는 것
- 강의 예: 12차시 CNN_v2는 **40 에폭 근처에서 검증 손실이 반등** → 과학습 조짐
- 실험 관리 도구(WandB, TensorBoard)는 이 곡선을 자동으로 그려 준다 → [[WandB]]

## 수식·원리
```
history = [[epoch, train_loss, train_acc, val_loss, val_acc], ...]
최적 에폭 ≈ argmin(val_loss)
```

## 코드 예시
```python
import numpy as np

# 가짜 학습 기록: 훈련 손실은 계속 감소, 검증 손실은 U자
ep = np.arange(1, 51)
train_loss = 1.5 * np.exp(-ep / 10)
val_loss = 1.5 * np.exp(-ep / 10) + 0.0004 * (ep - 5) ** 2
best = ep[np.argmin(val_loss)]
print(best)                                         # 23  ← 이후는 과적합 구간
print(train_loss[-1] < train_loss[best - 1], val_loss[-1] > val_loss[best - 1])   # True True
```
