# 에폭·이터레이션

## 정의·핵심
- **에폭(Epoch)**: 학습 데이터 **전체를 한 번 다 본 것**. `num_epochs = 50`이면 전체 데이터를 50번 반복해서 학습
- **배치(Batch)**: 한 번에 모델에 넣는 데이터 묶음. 크기 = `batch_size` → [[미니배치·배치 크기]]
- **이터레이션(Iteration, Step)**: **파라미터를 한 번 업데이트**하는 것 = 배치 하나 처리 (`optimizer.step()` 1회)
- **관계**: 1 에폭의 이터레이션 수 = `ceil(데이터 수 / 배치 크기)` = `len(train_loader)`
  - 예: 데이터 60,000개(MNIST), 배치 100 → 1 에폭 = 600 이터레이션
  - 마지막 배치가 나머지 개수로 작아질 수 있다 (`drop_last=True`로 버리기 가능)
- **에폭 수 정하기**
  - 너무 적으면 **과소적합**(아직 덜 배움), 너무 많으면 **과적합**(훈련 데이터 암기)
  - 학습 곡선에서 검증 손실이 다시 오르기 시작하는 지점 근처가 적당 → [[학습 곡선]], [[Early Stopping]]
- **스케줄러 단위 주의**: `StepLR`, `ReduceLROnPlateau`는 보통 **에폭마다** `scheduler.step()`, `OneCycleLR`는 **이터레이션마다** 호출 → [[학습률 스케줄러 개념]]
- 매 에폭 `shuffle=True`로 순서를 섞어 배치 구성이 달라지게 한다

## 수식·원리
```
iterations_per_epoch = ceil(N / batch_size)
total_steps          = epochs × iterations_per_epoch
```

## 코드 예시
```python
import math
import torch
from torch.utils.data import DataLoader, TensorDataset

ds = TensorDataset(torch.randn(1050, 3))
loader = DataLoader(ds, batch_size=100, shuffle=True)
print(len(loader), math.ceil(1050 / 100))          # 11 11
print([b[0].shape[0] for b in loader][-1])         # 50  ← 마지막 배치는 나머지
print(len(DataLoader(ds, batch_size=100, drop_last=True)))   # 10
epochs = 5
print(epochs * len(loader))                         # 55  총 업데이트 횟수
```
