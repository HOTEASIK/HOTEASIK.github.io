# 확률적 경사하강법(SGD)

## 정의·핵심
- **정의**: Stochastic Gradient Descent. 원래 의미는 **데이터 1개(또는 무작위로 뽑은 일부)** 로 기울기를 계산해 바로 업데이트하는 방식. "확률적"은 **무작위로 뽑은 샘플**을 쓴다는 뜻
- **장점**
  - 업데이트가 **매우 자주** 일어나 빠르게 진행
  - 메모리가 적게 든다
  - 기울기에 **잡음(noise)** 이 섞여 있어 오히려 **국소 최솟값·안장점을 빠져나오는** 데 도움, 넓고 평평한 최솟값을 찾는 경향 → 일반화에 유리
- **단점**
  - 한 샘플의 기울기는 전체 방향과 많이 달라 **손실이 심하게 출렁인다**
  - GPU 병렬 계산을 활용하지 못해 실제로는 비효율적
- **실무에서의 의미**: 요즘 "SGD"라고 하면 보통 **미니배치 SGD**(배치 32~256개의 평균 기울기)를 말한다. PyTorch의 `optim.SGD`도 넘겨받은 배치의 기울기로 업데이트할 뿐이다 → [[미니배치·배치 크기]], [[SGD(옵티마이저)]]
- 잡음을 줄이면서 빠르게 가려고 **Momentum**, 학습률을 점점 줄이는 **스케줄러**를 함께 쓴다

## 수식·원리
```
매 스텝 무작위 i 선택:  W ← W − η · ∇L(xᵢ, yᵢ)
E[∇L(xᵢ)] = 전체 평균 기울기   ← 평균적으로는 올바른 방향
```

## 코드 예시
```python
import torch

torch.manual_seed(0)
X = torch.randn(500, 1); Y = 3 * X + 2
W = torch.zeros(1, requires_grad=True); B = torch.zeros(1, requires_grad=True)
losses = []
for step in range(1000):
    i = torch.randint(0, 500, (1,))            # 샘플 1개 무작위
    loss = ((X[i] * W + B - Y[i]) ** 2).mean()
    loss.backward()
    with torch.no_grad():
        W -= 0.01 * W.grad; B -= 0.01 * B.grad
        W.grad.zero_(); B.grad.zero_()
    losses.append(loss.item())
print(round(W.item(), 1), round(B.item(), 1))  # 3.0 2.0
print(max(losses[:50]) > 1)                    # True  초반 손실이 크게 출렁임
```
