# 국소 최솟값(Local Minimum)

## 정의·핵심
- **정의**: 주변보다는 낮지만 **전체에서 가장 낮은 곳은 아닌** 지점. 경사하강법이 여기에 빠지면 사방이 오르막이라 기울기가 0이 되어 **더 이상 움직이지 않는다** (개론 4차시 "학습이 잘 안 되는 이유: 국소 최적해")
- **비유 (강의)**
  - **전역 최적해(Global Minimum)**: 산 전체에서 가장 낮은 계곡 — 진짜 최고의 답
  - **국소 최적해(Local Minimum)**: 산 중턱의 움푹 파인 작은 쉼터 — 꽤 괜찮지만 최고는 아님. 그 안에서는 사방이 오르막이라 가장 낮은 지점이라고 착각
- **비슷한 함정**
  - **안장점(Saddle Point)**: 한 방향으로는 최소, 다른 방향으로는 최대인 말안장 모양. 기울기 0. **고차원 딥러닝에서는 국소 최솟값보다 안장점이 훨씬 흔한 문제**
  - **평탄 구간(Plateau)**: 기울기가 거의 0인 넓은 평지 → 학습이 멈춘 것처럼 보임
- **실제 딥러닝에서는**: 파라미터가 수백만 개인 고차원에서는 대부분의 국소 최솟값의 손실이 전역 최솟값과 **비슷하게 낮다**고 알려져 있어 큰 문제가 아닌 경우가 많다. 오히려 **넓고 평평한 최솟값**을 찾는 것이 일반화에 중요
- **빠져나오는 방법**
  - **Momentum**: 관성으로 작은 웅덩이를 넘어감 → [[Momentum]]
  - **SGD의 잡음**: 작은 배치의 무작위성이 흔들어 줌
  - **Adam** 등 적응형 옵티마이저, 학습률 스케줄(주기적으로 키우기)
  - 좋은 **초기화**, 여러 번 다른 시드로 학습

## 수식·원리
```
국소 최솟값: ∇L = 0 이고 주변 모든 방향으로 L 증가
안장점:     ∇L = 0 이지만 어떤 방향은 증가, 어떤 방향은 감소
예: f(x) = x⁴ − 3x² + x  → x≈−1.30(전역), x≈1.13(국소)
```

## 코드 예시
```python
import torch

def descend(x0, momentum=0.0, lr=0.01, steps=500):
    x = torch.tensor(x0, requires_grad=True)
    opt = torch.optim.SGD([x], lr=lr, momentum=momentum)
    for _ in range(steps):
        opt.zero_grad()
        f = x ** 4 - 3 * x ** 2 + x
        f.backward(); opt.step()
    return round(x.item(), 2)

print(descend(2.0))                  # 1.13   국소 최솟값에 갇힘
print(descend(2.0, momentum=0.9))    # -1.3   관성으로 넘어가 전역 최솟값
```
