# RMSprop

## 정의·핵심
- **정의**: Root Mean Square Propagation. 기울기 **제곱의 지수 이동 평균**으로 파라미터마다 학습률을 나눠 주는 적응형 옵티마이저 (힌튼이 강의에서 제안)
- **아이디어**: 최근 기울기가 **크게 요동친 파라미터는 보폭을 줄이고**, 기울기가 작은 파라미터는 보폭을 키운다 → 협곡 모양 손실면에서 진동 감소
- **Adagrad의 개선판**: Adagrad는 기울기 제곱을 **계속 누적**해서 학습률이 0으로 줄어들어 학습이 멈춘다 → RMSprop은 **지수 이동 평균(최근 값 위주)** 으로 바꿔 이 문제를 해결 → [[Adagrad]]
- **하이퍼파라미터**: `lr=0.01`(PyTorch 기본), `alpha=0.99`(감쇠율, 보통 ρ로 표기), `eps=1e-8`, `momentum` 옵션
- **쓰이는 곳**: RNN 학습, 강화학습(DQN 원 논문)에서 많이 썼다. 지금은 대부분 Adam(= RMSprop + Momentum)으로 대체

## 수식·원리
```
v ← ρ·v + (1−ρ)·g²
W ← W − η · g / (√v + ε)
```

## 코드 예시
```python
import torch

w = torch.tensor([1.0, 1.0], requires_grad=True)
opt = torch.optim.RMSprop([w], lr=0.01, alpha=0.99)
loss = 100 * w[0] ** 2 + 0.01 * w[1] ** 2
loss.backward(); opt.step()
# 첫 스텝: v = 0.01 g² → g/√v = 10·sign(g) → 이동량 = lr × 10 = 0.1 (기울기 크기 무관)
print([round(v, 4) for v in w.tolist()])     # [0.9, 0.9]
```
