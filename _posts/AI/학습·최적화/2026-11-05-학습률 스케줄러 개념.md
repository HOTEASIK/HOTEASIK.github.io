# 학습률 스케줄러 개념

## 정의·핵심
- **정의**: 학습 도중 **학습률을 정해진 규칙에 따라 바꿔 주는** 도구 (`torch.optim.lr_scheduler`). 개론 5차시 "Grad 분포와 Scheduler" 실습
- **왜 필요한가**
  - **초반**: 큰 학습률로 빠르게 좋은 영역으로 이동
  - **후반**: 최솟값 근처에서 큰 학습률은 주변을 맴돌며 진동 → **작은 학습률로 세밀하게 수렴**
  - 고정 학습률로는 두 가지를 동시에 만족하기 어렵다
- **대표 스케줄러**

| 스케줄러 | 규칙 | step 호출 |
|---|---|---|
| `StepLR(step_size=30, gamma=0.1)` | 30 에폭마다 ×0.1 | 에폭마다 |
| `MultiStepLR(milestones=[30, 60])` | 지정 에폭마다 ×gamma | 에폭마다 |
| `ExponentialLR(gamma=0.95)` | 매 에폭 ×0.95 | 에폭마다 |
| `CosineAnnealingLR(T_max)` | 코사인 곡선으로 부드럽게 0까지 | 에폭(또는 스텝)마다 |
| `ReduceLROnPlateau` | **검증 손실이 정체**되면 줄임 | `step(val_loss)` → [[ReduceLROnPlateau]] |
| `OneCycleLR` | 올렸다가 내림 | **배치마다** → [[OneCycleLR]] |
| Warm-up | 처음 몇 스텝 0에서 서서히 증가 | 스텝마다 → [[Warm-up]] |

- **사용 순서**: `optimizer.step()` **다음에** `scheduler.step()` (반대로 하면 경고, 첫 학습률을 건너뜀)
- 현재 학습률: `scheduler.get_last_lr()` 또는 `optimizer.param_groups[0]['lr']`
- 체크포인트에 **scheduler.state_dict()도 함께 저장**해야 이어서 학습할 때 같은 학습률로 재개

## 수식·원리
```
StepLR:   ηₑ = η₀ · γ^⌊e / step_size⌋
Cosine:   ηₜ = η_min + ½(η₀ − η_min)(1 + cos(πt / T_max))
```

## 코드 예시
```python
import torch

w = torch.zeros(1, requires_grad=True)
opt = torch.optim.SGD([w], lr=0.1)
sched = torch.optim.lr_scheduler.StepLR(opt, step_size=3, gamma=0.1)
lrs = []
for epoch in range(7):
    opt.step()                 # (학습 생략)
    lrs.append(round(opt.param_groups[0]["lr"], 4))
    sched.step()
print(lrs)                     # [0.1, 0.1, 0.1, 0.01, 0.01, 0.01, 0.001]

opt2 = torch.optim.SGD([w], lr=0.1)
cos = torch.optim.lr_scheduler.CosineAnnealingLR(opt2, T_max=4)
out = []
for _ in range(5):
    out.append(round(cos.get_last_lr()[0], 4)); opt2.step(); cos.step()
print(out)                     # [0.1, 0.0854, 0.05, 0.0146, 0.0]
```
