# Dropout

## 정의·핵심
- **정의**: 학습 중 매 반복마다 신경망의 뉴런 일부를 **무작위로 비활성화(출력 0)** 하는 규제 기법. 네트워크가 **특정 뉴런에 과도하게 의존하는 것을 막아** 더 강건하고 일반화가 좋은 모델을 만든다 (개론 12차시)
- **직관**: 매번 다른 "작은 네트워크"를 학습하는 셈 → 여러 모델을 **앙상블**한 효과. 뉴런들이 서로에게 기대지 못하고(공적응 방지) 각자 쓸모 있는 특징을 배운다
- **훈련 모드 vs 평가 모드 (강의 실습)**
  - **훈련(`train()`)**: 확률 p(예: 0.5)로 요소를 0으로, **살아남은 요소는 1/(1−p)배**(p=0.5면 **2배**) → 출력 기댓값이 그대로 유지 (Inverted Dropout)
  - **평가(`eval()`)**: 드롭아웃 **적용 안 함**, 입력 = 출력. 예측 시에는 모든 뉴런을 써야 일관된 결과
  - → 추론 전에 `model.eval()` 필수 → [[train()·eval() 모드]]
- **배치 전략 (강의)**
  - "정보가 집약되는 길목"에: **풀링 레이어 직후**, **분류기 선형 레이어 사이**
  - **점진적 비율 증가**: 깊어질수록 0.2 → 0.3 → 0.4 (CNN_v3)
  - 보통 FC층 0.5, Conv층 0.1~0.3. 출력층 바로 뒤에는 넣지 않는다
- **주의**: 너무 크면 과소적합, 학습이 느려진다. BatchNorm과 같이 쓸 때는 BN 뒤·FC 쪽에 두는 편이 안정적
- 변형: `nn.Dropout2d`(채널 전체를 끔, Conv 특징맵), DropPath/Stochastic Depth(Residual 블록을 통째로 끔, ViT·ConvNeXt)

## 수식·원리
```
훈련: mᵢ ~ Bernoulli(1−p),   yᵢ = xᵢ · mᵢ / (1−p)
평가: y = x
E[y_train] = x  (기댓값 보존)
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
drop = nn.Dropout(p=0.5)
x = torch.ones(10)
drop.train()
y = drop(x)
print(y.tolist())                         # 0.0과 2.0만 섞여 나옴 ← 살아남은 값은 2배
print(set(y.tolist()) <= {0.0, 2.0})      # True
drop.eval()
print(torch.equal(drop(x), x))            # True  평가 모드는 그대로

big = drop.train()(torch.ones(100000))
print(round(big.mean().item(), 1))        # 1.0  기댓값 보존

class CNN_v3_head(nn.Module):             # 강의 CNN_v3처럼 점진적 비율
    def __init__(self):
        super().__init__()
        self.dropout1, self.dropout2, self.dropout3 = nn.Dropout(0.2), nn.Dropout(0.3), nn.Dropout(0.4)
```
