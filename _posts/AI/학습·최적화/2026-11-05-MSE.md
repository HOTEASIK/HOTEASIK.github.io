# MSE

## 정의·핵심
- **정의**: Mean Squared Error, 평균 제곱 오차. 예측과 정답의 차이를 **제곱해서 평균**낸 값. 가장 널리 쓰는 **회귀 손실함수** (`nn.MSELoss`)
- **특징**
  - 제곱 때문에 **큰 오차에 훨씬 큰 패널티** (오차 5 → 25, 오차 1 → 1)
  - **이상치(outlier)에 민감**: 하나의 큰 오차가 손실을 지배해 모델이 이상치 쪽으로 끌려간다
  - 모든 곳에서 미분 가능하고 매끄럽다 → 최적화가 쉽다. 기울기가 오차에 비례(`2(ŷ−y)`)해서 최솟값에 가까워질수록 자연스럽게 작아진다
  - 단위가 제곱이 된다 → 해석할 때는 **RMSE = √MSE** (원래 단위)
- **강의 예시 (6차시)**: 실제 [10, 20, 30], 예측 [12, 19, 35] → 오차 [2, 1, 5] → 제곱 [4, 1, 25] → **MSE = 10**
- **이진분류에 MSE?** Sigmoid + MSE는 기울기가 작아 학습이 느리고 손실면이 볼록하지 않다 → 분류는 BCE 사용 (6차시 실습 "MSE vs BCEWithLogits 비교")
- **확률적 의미**: 오차가 정규분포라고 가정했을 때의 최대우도추정과 같다
- 평가 지표로 쓰는 MSE와는 역할이 다르다 → [[지표로 쓰는 MSE·MAE]]

## 수식·원리
```
MSE = (1/n) Σ (yᵢ − ŷᵢ)²
∂MSE/∂ŷᵢ = (2/n)(ŷᵢ − yᵢ)
RMSE = √MSE
```

## 코드 예시
```python
import torch
import torch.nn as nn

y = torch.tensor([10.0, 20.0, 30.0]); p = torch.tensor([12.0, 19.0, 35.0])
print(nn.MSELoss()(p, y).item(), ((p - y) ** 2).mean().item())   # 10.0 10.0

y2 = torch.tensor([10.0, 20.0, 30.0, 40.0]); p2 = torch.tensor([11.0, 21.0, 31.0, 140.0])  # 마지막이 이상치
print(nn.MSELoss()(p2, y2).item())                                # 2500.75  ← 이상치 하나가 지배
print(round(nn.MSELoss()(p2, y2).sqrt().item(), 2))               # 50.01   RMSE
```
