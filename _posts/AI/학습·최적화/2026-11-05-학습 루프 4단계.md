# 학습 루프 4단계

## 정의·핵심
- **정의**: 모델을 학습시키는 반복 과정의 기본 틀. PyTorch에서는 `for epoch in range(...)` 루프 안에서 **예측 → 손실 → 경사 → 수정** 4단계를 순서대로 실행한다. (개론 4·5차시)
- **학습의 3대 핵심 함수** ("이 세 가지 요소가 없으면 AI 학습은 시작되지 않는다")
  - **예측 함수 `net`**: 입력 → 예측값 (모델 자체)
  - **손실 함수 `criterion`**: 예측과 정답을 비교해 오차 계산 → [[손실함수 개념]]
  - **최적화 함수 `optimizer`**: 손실을 바탕으로 파라미터 수정 → [[SGD(옵티마이저)]], [[Adam]]
- **4단계**
  1. **예측 계산 (Forward)**: `outputs = net(inputs)`
  2. **손실 계산**: `loss = criterion(outputs, labels)`
  3. **경사 계산 (Backward)**: `loss.backward()` → 각 파라미터 `.grad`에 기울기 저장
  4. **파라미터 수정**: `optimizer.step()` → `W ← W − lr·grad`
  - 그리고 **`optimizer.zero_grad()`**: 기울기는 누적되므로 매 반복 시작(또는 step 후)에 0으로 초기화. 빠뜨리면 이전 배치의 기울기가 계속 더해져 학습이 망가진다
- **실전 루프에 추가되는 것**
  - `model.train()` / 검증 때 `model.eval()` + `torch.no_grad()` → [[train()·eval() 모드]]
  - 데이터와 모델을 같은 device로 `.to(device)`
  - 에폭마다 손실·정확도를 history에 기록 → [[학습 곡선]]
  - 검증 성능이 가장 좋을 때 저장 → [[Early Stopping]], [[state_dict 저장·불러오기]]
- 강의에서는 이 루프를 `fit()` 공통 함수로 만들어 재사용한다 (12차시 "공통 함수의 라이브러리화")

## 수식·원리
```
for epoch:
    for inputs, labels in train_loader:
        optimizer.zero_grad()          # 0. 기울기 초기화
        outputs = net(inputs)          # 1. 예측
        loss = criterion(outputs, labels)  # 2. 손실
        loss.backward()                # 3. 경사
        optimizer.step()               # 4. 수정
```

## 코드 예시
```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(0)
X = torch.randn(200, 2); y = (X[:, 0] + X[:, 1] > 0).long()
loader = DataLoader(TensorDataset(X, y), batch_size=32, shuffle=True)

net = nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2))
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(net.parameters(), lr=0.1)

for epoch in range(20):
    net.train()
    for inputs, labels in loader:
        optimizer.zero_grad()
        loss = criterion(net(inputs), labels)
        loss.backward()
        optimizer.step()

net.eval()
with torch.no_grad():
    acc = (net(X).argmax(1) == y).float().mean().item()
print(acc > 0.95)        # True
```
