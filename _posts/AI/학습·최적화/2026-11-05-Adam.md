# Adam

## 정의·핵심
- **정의**: Adaptive Moment Estimation. **Momentum(1차 모멘트) + RMSprop(2차 모멘트)** 를 결합한 옵티마이저. "현재 가장 널리 사용되는 최적화 함수" — 특징: **자동 학습률 조절, 안정적 성능** (개론 12차시)
- **두 가지 기억**
  - **m (1차 모멘트)**: 기울기의 지수 이동 평균 → **방향** (Momentum처럼 관성)
  - **v (2차 모멘트)**: 기울기 **제곱**의 지수 이동 평균 → **크기**. 기울기가 큰 파라미터는 보폭을 줄이고, 작은 파라미터는 키운다 → **파라미터마다 학습률이 자동 조절**
- **편향 보정(Bias Correction)**: m, v를 0으로 시작하므로 초반에는 값이 0 쪽으로 치우친다 → `1 − βᵗ`로 나눠 보정
- **기본 하이퍼파라미터**: `lr=1e-3`, `betas=(0.9, 0.999)`, `eps=1e-8` — 거의 이대로 써도 잘 된다
  - 사용: `optim.Adam(model.parameters())` (강의: lr 생략, 기본값)
- **장점**: 튜닝을 덜 해도 빠르고 안정적으로 수렴. 희소한 기울기(NLP 임베딩)에 강함. 강의 결과: **20 에폭 76.56%, 가장 빠른 초기 학습**
- **단점·주의**
  - 메모리: 파라미터마다 m, v 저장 → 파라미터 수의 **2배** 추가
  - 이미지 분류에서 SGD+Momentum보다 일반화가 약간 떨어질 때가 있다
  - `weight_decay`가 적응형 학습률과 섞여 의도대로 동작하지 않음 → **AdamW** 사용 권장 → [[AdamW]]

## 수식·원리
```
m ← β₁m + (1−β₁)g            v ← β₂v + (1−β₂)g²
m̂ = m / (1−β₁ᵗ)              v̂ = v / (1−β₂ᵗ)
W ← W − η · m̂ / (√v̂ + ε)
첫 스텝: m̂ = g, v̂ = g² → 이동량 ≈ η·sign(g)  (기울기 크기와 무관하게 lr만큼)
```

## 코드 예시
```python
import torch

w = torch.tensor([1.0, 1.0], requires_grad=True)
opt = torch.optim.Adam([w], lr=0.1)
loss = 100 * w[0] ** 2 + 0.01 * w[1] ** 2     # 기울기 크기가 1만 배 차이
loss.backward(); opt.step()
print([round(v, 4) for v in w.tolist()])      # [0.9, 0.9]  ← 둘 다 lr만큼 이동 (크기 자동 조절)

# 수식으로 직접 계산
g = torch.tensor([200.0, 0.02]); m = 0.1 * g; v = 0.001 * g ** 2
m_hat, v_hat = m / (1 - 0.9), v / (1 - 0.999)
print([round(x, 4) for x in (1 - 0.1 * m_hat / (v_hat.sqrt() + 1e-8)).tolist()])   # [0.9, 0.9]
print(len(opt.state[w]), list(opt.state[w].keys()))   # 3 ['step', 'exp_avg', 'exp_avg_sq']  ← m, v를 따로 저장
```
