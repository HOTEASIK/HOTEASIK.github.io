# AdamW

## 정의·핵심
- **정의**: Adam with decoupled **W**eight decay. Adam에서 **가중치 감쇠(weight decay)를 기울기와 분리해서** 직접 적용하는 수정판. Transformer(BERT·GPT·ViT) 학습과 Hugging Face `Trainer`의 **기본 옵티마이저**
- **Adam의 문제**: `optim.Adam(..., weight_decay=λ)`는 L2 항 `λW`를 **기울기에 더한 뒤** 적응형 학습률(÷√v)로 나눈다 → 기울기가 큰 파라미터는 규제가 약해지고, 작은 파라미터는 강해지는 등 **규제 강도가 파라미터마다 들쭉날쭉**
- **AdamW의 해결**: Adam 업데이트는 그대로 하고, 따로 `W ← W − η·λ·W`로 **모든 파라미터를 같은 비율로 줄인다** → 의도한 규제 효과, 일반화 향상
- **사용법**: `optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)` (PyTorch 기본 weight_decay = 0.01, Adam은 0)
  - 보통 **bias와 LayerNorm/BatchNorm 가중치는 weight decay에서 제외** (param_groups로 분리)
- **권장**: Adam에 weight decay를 쓰고 싶으면 Adam 대신 AdamW

## 수식·원리
```
Adam + L2:  g ← g + λW  →  W ← W − η·m̂/(√v̂+ε)            (규제가 √v̂로 나눠짐)
AdamW:      W ← W − η·m̂/(√v̂+ε) − η·λ·W                  (규제를 따로, 일정하게)
```

## 코드 예시
```python
import torch
import torch.nn as nn

def one_step(opt_cls):
    w = torch.tensor([100.0], requires_grad=True)
    opt = opt_cls([w], lr=0.1, weight_decay=0.1)
    opt.zero_grad()
    (0 * w).sum().backward()              # 손실 기울기 0 → 순수 weight decay 효과만
    opt.step()
    return round(w.item(), 4)

print(one_step(torch.optim.Adam), one_step(torch.optim.AdamW))   # 99.9 99.0
# Adam: λW=10이 √v로 나눠져 lr(0.1)만큼만 줄어듦 / AdamW: η·λ·W = 1.0만큼 그대로 줄어듦
model = nn.Linear(4, 2)
decay = [p for n, p in model.named_parameters() if n.endswith("weight")]
no_decay = [p for n, p in model.named_parameters() if n.endswith("bias")]
opt = torch.optim.AdamW([{"params": decay, "weight_decay": 0.01},
                         {"params": no_decay, "weight_decay": 0.0}], lr=1e-3)
print([g["weight_decay"] for g in opt.param_groups])            # [0.01, 0.0]
```
