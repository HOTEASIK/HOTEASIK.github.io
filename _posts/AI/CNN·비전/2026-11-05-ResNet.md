# ResNet

## 정의·핵심
- **정의**: Microsoft Research(Kaiming He 등)의 **Residual Network** (2015). **잔차 연결(skip connection)** 로 아주 깊은 망을 학습 가능하게 만든 모델 (대학원 09)
- **성적**: **152층**(VGG의 8배 깊이)으로 ILSVRC 2015 분류 **Top-5 오류 3.57%로 우승** — 사람의 오류율(5~10%)보다 낮음. ImageNet 검출·위치, COCO 검출·분할도 1위
- **Degradation 문제 (대학원 09)**
  - 일반 망(plain)에서 20층보다 **56층이 train error와 test error 모두 더 높다**
  - 과적합이라면 train error는 낮아야 하는데 **train error도 높다** → 과적합이 아니라 **최적화 자체가 어려운 문제**
  - 이론상 깊은 망은 추가 층을 항등함수로 만들면 얕은 망만큼은 해야 하는데, 비선형 층 여러 개로 **항등 함수를 배우기가 어렵다**
- **해결: 잔차 학습 (Residual Learning)**
  - 원하는 함수 H(x)를 직접 배우지 말고 **F(x) = H(x) − x (잔차)** 를 배우게 하고 출력은 **F(x) + x**
  - 항등 함수가 최적이면 F(x)를 **0으로 밀기만** 하면 된다 → 훨씬 쉬움
  - shortcut 덧셈은 **추가 파라미터·연산이 없다** (identity)
  - 역전파 때 기울기가 shortcut으로 바로 흘러 **기울기 소실 완화**
  - 자세한 블록 구조 → [[Residual Block]]
- **구성**
  - ResNet-18/34: **Basic block** (3×3 두 개) / ResNet-50/101/152: **Bottleneck** (1×1 → 3×3 → 1×1)
  - 첫 층 7×7 conv stride 2 + MaxPool, 이후 4개 stage(64·128·256·512 채널, Bottleneck은 ×4), 끝은 **GAP + FC 하나**
  - 크기를 줄일 때 풀링 대신 **stride 2 conv**, 크기가 절반이면 채널 2배
- **CIFAR-10 실험 (대학원 09)**: ResNet은 층을 늘릴수록 성능↑, plain은 오히려↓. 1202층은 과적합으로 다시 나빠짐
- **torchvision (개론 13차시)**: `models.resnet18` Top-1 30.24 / Top-5 10.92, `resnet152` 21.69 / 5.94. 분류부는 **`net.fc`** (`Linear(512, 1000)`) → 교체가 간단

## 수식·원리
```
y = F(x, {Wᵢ}) + x            (identity shortcut)
y = F(x, {Wᵢ}) + W_s·x        (projection shortcut: 1×1 conv로 채널·크기 맞춤)
∂L/∂x = ∂L/∂y · (∂F/∂x + 1)   ← "+1" 덕분에 기울기가 사라지지 않음
```

## 코드 예시
```python
import torch
import torch.nn as nn
from torchvision import models

net = models.resnet18(weights=None)
print(net.fc)                                            # Linear(in_features=512, out_features=1000, bias=True)
print([name for name, _ in net.named_children()])        # conv1 bn1 relu maxpool layer1~4 avgpool fc
print(type(net.layer1[0]).__name__, type(models.resnet50(weights=None).layer1[0]).__name__)   # BasicBlock Bottleneck
x = net.maxpool(net.relu(net.bn1(net.conv1(torch.randn(1, 3, 224, 224)))))   # stem: 224 → 56
for name in ["layer1", "layer2", "layer3", "layer4"]:
    x = getattr(net, name)(x)
    print(name, tuple(x.shape))                          # 채널 2배, 크기 절반
# layer1 (1, 64, 56, 56)
# layer2 (1, 128, 28, 28)
# layer3 (1, 256, 14, 14)
# layer4 (1, 512, 7, 7)
net.fc = nn.Linear(net.fc.in_features, 10)
print(net(torch.randn(2, 3, 112, 112)).shape)            # torch.Size([2, 10])
```
