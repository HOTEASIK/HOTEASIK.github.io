# AlexNet

## 정의·핵심
- **정의**: 2012년 Krizhevsky·Sutskever·Hinton의 CNN. **ILSVRC 2012 우승**(분류·위치 1위), Top-5 오류 **16.4%**로 2위(약 26%)를 크게 앞섬 → "딥러닝 돌파의 해", **CNN을 처음 대중화** (대학원 01·06)
- **구조**: 합성곱 5층 + FC 3층 = **8층**, 파라미터 약 **6,000만 개**
  - 입력 227×227×3 (논문 224) → Conv1 **11×11, stride 4**, 96채널 → 55×55 (대학원 05 계산 예)
  - Conv 5×5, 3×3 ×3 + MaxPool(3×3, stride 2, 겹치는 풀링)
  - FC 4096 → 4096 → 1000
  - GPU 메모리 한계로 **GPU 2개에 나눠** 학습 (그룹 합성곱)
- **성공 요인 (대학원 06 "기울기 소실·과적합" 해결)**
  - **ReLU**: Sigmoid·Tanh의 **기울기 소실** 해결 — 미분값 0 또는 1, 계산이 싸고 희소 활성. tanh보다 학습 6배 빠름 → [[ReLU]]
  - **Dropout(0.5)**: FC층 과적합 방지 → [[Dropout]]
  - **데이터 증강**: 무작위 crop·좌우 반전, PCA 색상 변화 → [[데이터 증강]]
  - **GPU 학습**: GTX 580 두 장으로 대규모 학습이 가능해짐
  - LRN(Local Response Normalization): 이후 VGG 실험에서 효과가 거의 없다고 밝혀져 지금은 BN으로 대체
- **torchvision**: `models.alexnet(weights=...)` — Top-1 에러 43.45 / Top-5 20.91 (개론 13차시 표). 분류부 마지막은 `classifier[6]`

## 수식·원리
```
(227 − 11) / 4 + 1 = 55    → Conv1 출력 55×55×96
Conv5 → 6×6×256 = 9216 → FC 4096 → FC 4096 → FC 1000
```

## 코드 예시
```python
import torch
from torchvision import models

net = models.alexnet(weights=None)                       # 구조만 (weights="IMAGENET1K_V1"이면 사전학습)
print(net.features[0])                                   # Conv2d(3, 64, kernel_size=(11, 11), stride=(4, 4), padding=(2, 2))
print(round(sum(p.numel() for p in net.parameters()) / 1e6, 1))   # 61.1  (백만 개)
print(net.classifier[6])                                 # Linear(in_features=4096, out_features=1000, bias=True)
print([type(m).__name__ for m in net.classifier])        # Dropout이 FC 사이에
print(net(torch.randn(2, 3, 224, 224)).shape)            # torch.Size([2, 1000])
```
