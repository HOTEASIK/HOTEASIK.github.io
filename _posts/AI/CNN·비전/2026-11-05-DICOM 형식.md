# DICOM 형식

## 정의·핵심
- **정의**: **D**igital **I**maging and **CO**mmunications in **M**edicine. 의료 영상과 관련 정보를 **함께 저장**하는 국제 표준 파일 형식 (`.dcm`) (응용 13차시)
- **일반 이미지와의 차이 (강의)**
  - JPG/PNG: **사진 픽셀 정보만**
  - DICOM: **이미지 + 환자 정보 + 촬영 정보 + 장비 정보**
- **파일 구조 (강의)**
  - **Header**: 파일 식별자, 버전 정보 (128바이트 preamble + "DICM")
  - **Meta Data**: 환자명, 나이, 성별, 촬영 날짜, 병원명, 장비 모델 등 — **태그 (그룹, 요소)** 로 저장 (예: `(0010,0010)` PatientName, `(0008,0060)` Modality)
  - **Pixel Data**: 실제 영상 픽셀 (그레이스케일 또는 컬러, 보통 12~16bit)
- **딥러닝에 쓸 때 처리할 것**
  - 읽기: `pydicom.dcmread(path)` → `ds.pixel_array` (NumPy) → [[pydicom]]
  - **Rescale**: CT는 `HU = pixel × RescaleSlope + RescaleIntercept` 로 Hounsfield 단위로 변환
  - **Windowing**: 보고 싶은 조직 범위(Window Center/Width)만 0~255로 잘라내 대비를 높임 (폐창, 뼈창 등)
  - **PhotometricInterpretation**: `MONOCHROME1`이면 흑백이 반전 → 뒤집어야 함
  - 정규화 후 PNG/JPEG로 변환하거나 바로 텐서로 (강의의 Chest X-ray 데이터셋은 **이미 JPEG로 변환**된 것)
  - 3D(CT·MRI)는 슬라이스 여러 장 → `SliceLocation`/`InstanceNumber`로 정렬
- **개인정보**: 헤더에 환자 식별 정보가 있으므로 공개·공유 전 **비식별화(anonymization)** 필수
- 표준 덕분에 병원 PACS(영상 저장 전송 시스템)와 장비 간 호환이 된다

## 수식·원리
```
HU = pixel · RescaleSlope + RescaleIntercept
windowing: lo = WC − WW/2,  hi = WC + WW/2,  img = clip((HU − lo)/(hi − lo), 0, 1) · 255
```

## 코드 예시
```python
import numpy as np

raw = np.array([[0, 1000, 2000], [3000, 1024, 40]], dtype=np.int16)    # 저장된 픽셀(예시)
slope, intercept = 1.0, -1024.0
hu = raw * slope + intercept                                           # CT → Hounsfield 단위
print(hu.tolist())                                                     # [[-1024.0, -24.0, 976.0], [1976.0, 0.0, -984.0]]

def window(hu, wc, ww):
    lo, hi = wc - ww / 2, wc + ww / 2
    return (np.clip((hu - lo) / (hi - lo), 0, 1) * 255).astype(np.uint8)
print(window(hu, wc=40, ww=400).tolist())                              # 연부조직 창: 범위 밖은 0/255
# [[0, 86, 255], [255, 102, 0]]
mono1 = window(hu, 40, 400); print((255 - mono1)[0].tolist())          # MONOCHROME1이면 반전 [255, 169, 0]
# import pydicom; ds = pydicom.dcmread("a.dcm"); arr = ds.pixel_array; ds.PatientAge, ds.Modality
```
