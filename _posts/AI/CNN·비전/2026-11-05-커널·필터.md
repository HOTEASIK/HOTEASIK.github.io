# 커널·필터

## 정의·핵심
- **정의**: 합성곱에서 이미지 위를 이동하며 곱하고 더하는 **작은 가중치 행렬** (3×3, 5×5 등). "특징을 찾아내는 틀" (개론 11차시 레고 비유: 수많은 블록 속에서 '1×2 빨간 블록' 같은 특정 부품을 찾는 틀)
- **커널 vs 필터 용어**
  - **커널**: 2차원 가중치 하나 (k×k)
  - **필터**: 입력 채널 수만큼 커널을 쌓은 3차원 묶음 (C_in × k × k) → 출력 채널 1개를 만든다
  - 실무에서는 섞어 쓴다. `Conv2d`의 `out_channels` = 필터 개수
- **고전 비전 vs CNN**
  - 고전: 사람이 설계한 필터 — Sobel(모서리), 가우시안(블러), 샤프닝, HOG(방향 기울기, 대학원 04)
  - CNN: 필터 값을 **데이터로부터 학습** (특징 추출기와 분류기가 모두 trainable, 대학원 05)
  - 학습된 첫 층 필터를 시각화하면 실제로 **모서리·색 검출기**처럼 생긴다
- **크기 선택**
  - **3×3이 표준**: 작은 커널을 여러 번 쌓으면 같은 수용 영역을 더 적은 파라미터 + 더 많은 비선형성으로 얻는다 (VGG) → [[VGG]]
  - 1×1: 채널 섞기·차원 축소 → [[1x1 Convolution]]
  - 큰 커널(7×7, 11×11): 초기 모델 첫 층 (AlexNet 11×11, ResNet 첫 층 7×7)
  - 홀수 크기를 쓰는 이유: **중심 픽셀**이 있고 `padding=k//2`로 크기 유지가 쉽다
- 강의 실습: 대각선에만 가중치를 둔 커널로 MNIST 숫자에 3번 합성곱 → 대각선 방향 특징이 강조됨

## 수식·원리
```
Sobel-x = [[-1, 0, 1],
           [-2, 0, 2],
           [-1, 0, 1]]     → 세로 모서리(가로 방향 밝기 변화)에 반응
필터 1개의 가중치 수 = C_in × k × k (+1 bias)
```

## 코드 예시
```python
import torch
import torch.nn.functional as F

img = torch.zeros(1, 1, 5, 5)
img[..., 2:] = 1.0                                   # 왼쪽 어둡고 오른쪽 밝은 세로 경계
sobel_x = torch.tensor([[-1., 0, 1], [-2, 0, 2], [-1, 0, 1]]).view(1, 1, 3, 3)
sobel_y = sobel_x.transpose(2, 3)
print(F.conv2d(img, sobel_x)[0, 0])                  # 경계 근처에서 큰 값
# tensor([[4., 4., 0.],
#         [4., 4., 0.],
#         [4., 4., 0.]])
print(F.conv2d(img, sobel_y).abs().sum().item())     # 0.0  가로 경계 필터는 반응 없음
diag = torch.eye(3).view(1, 1, 3, 3) / 3              # 강의의 대각선 커널
print([round(v, 3) for v in F.conv2d(img, diag)[0, 0, 0].tolist()])   # [0.333, 0.667, 1.0]
```
