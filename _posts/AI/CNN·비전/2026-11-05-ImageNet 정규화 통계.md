# ImageNet 정규화 통계

## 정의·핵심
- **정의**: ImageNet 학습 이미지 전체에서 구한 **채널별 평균과 표준편차**
  - **mean = [0.485, 0.456, 0.406]**, **std = [0.229, 0.224, 0.225]** (R, G, B 순, [0, 1] 스케일 기준)
  - `transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])`
- **왜 써야 하나**
  - 사전학습 모델은 **이 통계로 정규화된 입력**을 보며 가중치를 학습했다 → 같은 분포로 넣어야 학습된 특징이 제대로 동작
  - 다른 정규화(예: 0.5/0.5)를 쓰면 입력 분포가 달라져 초기 성능이 떨어진다 (학습으로 어느 정도 회복은 됨)
  - 의료영상 강의(응용 13차시)도 Resize 224 → ToTensor → **ImageNet 통계로 Normalize**
- **정규화 방식 비교**
  - `Normalize(0.5, 0.5)`: [0, 1] → **[−1, 1]** (개론 11·15차시, 스크래치 모델)
  - 내 데이터셋 통계: 스크래치 학습이면 직접 계산한 mean/std가 가장 정확 (예: CIFAR-10 [0.4914, 0.4822, 0.4465])
  - **ImageNet 통계**: 사전학습 모델을 쓸 때 기본
- **주의**
  - Normalize는 **ToTensor 뒤에** (텐서에만 적용)
  - **흑백 이미지**를 3채널 모델에 넣으려면 `Grayscale(num_output_channels=3)` 후 정규화
  - 시각화할 때는 **역정규화** `x * std + mean` 후 `clamp(0, 1)` → [[imshow]]
  - torchvision 신버전은 `Weights.transforms()`가 이 값을 포함한 전처리를 돌려준다

## 수식·원리
```
x_norm[c] = (x[c] − mean[c]) / std[c]
역정규화:  x = x_norm[c] · std[c] + mean[c]
```

## 코드 예시
```python
import torch
from torchvision import transforms, models

mean, std = [0.485, 0.456, 0.406], [0.229, 0.224, 0.225]
norm = transforms.Normalize(mean, std)
x = torch.rand(3, 224, 224)
z = norm(x)
back = z * torch.tensor(std).view(3, 1, 1) + torch.tensor(mean).view(3, 1, 1)
print(torch.allclose(back, x, atol=1e-6))                    # True  역정규화로 원래대로
gray = torch.full((3, 1, 1), 0.5)
print([round(v, 3) for v in norm(gray).flatten().tolist()])  # [0.066, 0.196, 0.418]
print(models.ResNet18_Weights.IMAGENET1K_V1.transforms().mean)   # [0.485, 0.456, 0.406]
```
