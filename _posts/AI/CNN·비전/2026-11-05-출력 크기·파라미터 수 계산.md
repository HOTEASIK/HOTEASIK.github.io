# 출력 크기·파라미터 수 계산

## 정의·핵심
- **왜 중요한가**: "CNN 설계 시 어려운 부분은 features를 통과한 데이터가 classifier의 첫 Linear에 들어갈 때 **그 크기가 얼마인지 계산하는 것**" (개론 11차시). 틀리면 `mat1 and mat2 shapes cannot be multiplied` 오류
- **출력 크기 공식 (대학원 05)**: `(W − F + 2P) / S + 1` — W 입력 크기, F 커널, P 패딩, S stride
  - 3×3, P=0, S=1: 크기 **2 감소** (32 → 30)
  - 3×3, P=1, S=1: **유지**
  - MaxPool 2×2 (S=2): **절반** (28 → 14)
  - ReLU·BatchNorm·Dropout: 모양 변화 없음 (값만 바뀜)
- **강의 예 (개론 11차시 CIFAR-10 CNN)**
  - `[3, 32, 32]` → Conv(3→32, 3) `[32, 30, 30]` → Conv(32→32, 3) `[32, 28, 28]` → MaxPool `[32, 14, 14]` → Flatten **32 × 14 × 14 = 6272** → `nn.Linear(6272, n_hidden)`
- **파라미터 수**
  - **Conv2d**: `C_out × (C_in × kH × kW) + C_out(bias)` — **입력 이미지 크기와 무관** (가중치 공유)
  - **Linear**: `in × out + out`
  - **BatchNorm2d**: `2 × C` (γ, β) — running mean/var는 버퍼라 파라미터 아님
  - 예: `Conv2d(3, 32, 3)` = 32×27 + 32 = **896**, `Conv2d(32, 32, 3)` = 9,248, `Linear(6272, 128)` = 802,944 → **파라미터 대부분이 FC층**에 있다 (VGG16 1.38억 개 중 약 1.2억이 FC)
- **크기를 계산하지 않는 방법**
  - **더미 입력**을 features에 통과시켜 shape 확인 (강의 방식)
  - `nn.LazyLinear(out)`: 첫 입력에서 in_features 자동 결정
  - `AdaptiveAvgPool2d((1, 1))`/GAP로 크기를 고정 → [[Global Average Pooling(GAP)]]
  - `torchinfo.summary`로 층별 출력·파라미터 표 → [[torchinfo·torchsummary]]

## 수식·원리
```
H_out = ⌊(H + 2P − D·(F − 1) − 1) / S⌋ + 1     (PyTorch 공식, D: dilation=1이면 위 공식과 같음)
Params(Conv) = C_out · C_in · kH · kW + C_out
FLOPs(Conv) ≈ H_out · W_out · C_out · C_in · kH · kW
```

## 코드 예시
```python
import torch
import torch.nn as nn

def out_size(w, f, p=0, s=1):
    return (w - f + 2 * p) // s + 1

print(out_size(32, 3), out_size(30, 3), out_size(28, 2, s=2))   # 30 28 14
features = nn.Sequential(nn.Conv2d(3, 32, 3), nn.ReLU(), nn.Conv2d(32, 32, 3), nn.ReLU(), nn.MaxPool2d(2))
n = features(torch.zeros(1, 3, 32, 32)).flatten(1).shape[1]       # 더미 입력으로 확인
print(n, 32 * 14 * 14)                                            # 6272 6272

count = lambda m: sum(p.numel() for p in m.parameters())
print(count(nn.Conv2d(3, 32, 3)), 32 * 3 * 3 * 3 + 32)            # 896 896
print(count(nn.Conv2d(32, 32, 3)), count(nn.Linear(6272, 128)))   # 9248 802944  FC가 압도적
print(count(nn.BatchNorm2d(64)))                                  # 128
lazy = nn.LazyLinear(10); lazy(torch.zeros(2, 6272)); print(lazy.in_features)   # 6272
```
