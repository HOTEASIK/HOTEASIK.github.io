# 풀링

## 정의·핵심
- **정의**: Pooling. 특징 맵을 작은 구역(예: 2×2)으로 나눠 **구역마다 대표값 하나만 남겨** 크기를 줄이는 층. 학습할 파라미터가 **없다** (개론 11차시)
- **역할 (강의)**
  - **크기 축소**: 특징 맵 크기를 줄여 **계산량 감소** (2×2 → 가로·세로 절반, 값 개수 1/4)
  - **강인함 확보**: 특징의 **위치가 약간 바뀌어도** 같은 결과 → 이동(translation)에 대한 robustness
  - 핵심 정보는 유지하면서 정보량을 줄인다 (대학원 05)
  - 뒤층의 수용 영역을 빠르게 넓힌다
- **Max Pooling** — `nn.MaxPool2d(2)`
  - 구역에서 **가장 큰 값**(가장 두드러진 특징)만 남기고 나머지는 버린다
  - "이 구역에 이 특징이 **있는가**"를 잘 보존 → CNN 중간층의 기본 선택
  - 레고 비유: 각 구역에서 가장 대표적인 부품 하나씩만 뽑아 요약
- **Average Pooling** — `nn.AvgPool2d(2)`
  - 구역의 **평균** → 부드럽게 요약, 배경 정보까지 반영
  - 주로 마지막에 **전역 평균 풀링(GAP)** 형태로 쓴다 → [[Global Average Pooling(GAP)]]
- **기본 설정**: `MaxPool2d(kernel_size=2)`이면 stride도 2 (겹치지 않게)
- **역전파**: Max는 **최댓값 위치로만** 기울기 전달, Average는 균등 분배
- **요즘 경향**: 풀링 대신 stride 2 합성곱으로 다운샘플링하는 경우가 많다 (ResNet 중간) → [[Stride]]
- `AdaptiveAvgPool2d(출력크기)`: 커널 크기 대신 **원하는 출력 크기**를 지정 → 입력 크기와 무관하게 같은 출력 (개론 13차시)

## 수식·원리
```
MaxPool: y[i, j] = max_{(m,n) ∈ 구역(i,j)} x[m, n]
AvgPool: y[i, j] = mean_{(m,n) ∈ 구역(i,j)} x[m, n]
출력 = (W − k) / s + 1   (k=2, s=2 → W/2)
```

## 코드 예시
```python
import torch
import torch.nn as nn

x = torch.tensor([[1., 3, 2, 0], [4, 2, 1, 5], [0, 1, 7, 2], [2, 2, 3, 1]]).view(1, 1, 4, 4)
print(nn.MaxPool2d(2)(x)[0, 0])        # tensor([[4., 5.], [2., 7.]])
print(nn.AvgPool2d(2)(x)[0, 0])        # tensor([[2.5000, 2.0000], [1.2500, 3.2500]])

a = torch.zeros(1, 1, 4, 4); a[0, 0, 0, 0] = 9
b = torch.zeros(1, 1, 4, 4); b[0, 0, 1, 1] = 9          # 특징이 한 칸 이동
print(torch.equal(nn.MaxPool2d(2)(a), nn.MaxPool2d(2)(b)))   # True  작은 이동에 강인
print(sum(p.numel() for p in nn.MaxPool2d(2).parameters()))  # 0  파라미터 없음
print(nn.AdaptiveAvgPool2d((1, 1))(torch.randn(100, 32, 16, 16)).shape)   # torch.Size([100, 32, 1, 1])
```
