# 레이어 동결

## 정의·핵심
- **정의**: Freezing. 특정 층의 파라미터를 **학습 중에 바뀌지 않게 고정**하는 것. PyTorch에서는 `param.requires_grad = False` (개론 13·14차시)
- **효과**
  - 그 파라미터의 **기울기를 계산하지 않음** → 역전파 메모리·시간 절약
  - 사전학습된 특징을 **그대로 보존** → 적은 데이터에서 과적합 방지
- **방법**
  - 전체 동결 후 일부 해제: `for p in net.parameters(): p.requires_grad = False` → 새로 만든 `net.fc`는 기본값 `True`
  - 이름으로 선택: `for n, p in net.named_parameters(): p.requires_grad = n.startswith("layer4")`
  - 모듈 단위: `net.layer1.requires_grad_(False)`
  - Keras: `model.trainable = False` (대학원 07 실습 `VGG.trainable = False`, `include_top=False`)
- **옵티마이저에는 학습할 것만**: `optim.SGD(filter(lambda p: p.requires_grad, net.parameters()), ...)` — 전부 넘겨도 grad가 None이면 건너뛰지만, 명시하는 편이 명확하고 weight decay 등이 섞이지 않는다
- **주의: BatchNorm**
  - `requires_grad=False`는 γ·β만 고정한다. **running_mean/var는 `train()` 모드에서 계속 갱신**된다
  - 완전히 고정하려면 동결한 BN 층을 `eval()` 모드로 두거나, 작은 배치에서는 특히 주의
- **확인**: 학습 가능한 파라미터 수를 출력 (`sum(p.numel() for p in net.parameters() if p.requires_grad)`), torchinfo의 Trainable params → [[torchinfo·torchsummary]]
- 점진적으로 동결을 푸는 방법(Gradual Unfreezing) → [[Feature Extraction vs Fine-tuning]]

## 수식·원리
```
requires_grad=False  →  backward에서 ∂L/∂θ 계산 생략  →  optimizer.step()에서 θ 그대로
BN: γ, β (파라미터, requires_grad로 제어)  /  running_mean, running_var (버퍼, train/eval로 제어)
```

## 코드 예시
```python
import torch
import torch.nn as nn
from torchvision import models

net = models.resnet18(weights=None)
for p in net.parameters():
    p.requires_grad = False
net.fc = nn.Linear(512, 3)                                       # 새 층은 requires_grad=True
net.layer4.requires_grad_(True)                                  # layer4만 다시 해제
trainable = [n for n, p in net.named_parameters() if p.requires_grad]
print(trainable[0], trainable[-1], len(trainable))               # layer4.0.conv1.weight fc.bias 17

bn = net.bn1
before = bn.running_mean.clone()
net.train(); net(torch.randn(4, 3, 64, 64))
print(torch.equal(before, bn.running_mean))                      # False  동결했어도 BN 통계는 바뀜
net.bn1.eval(); before = bn.running_mean.clone(); net(torch.randn(4, 3, 64, 64))
print(torch.equal(before, bn.running_mean))                      # True   eval로 두면 고정
```
