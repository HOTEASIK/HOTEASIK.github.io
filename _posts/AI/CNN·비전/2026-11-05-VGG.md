# VGG

## 정의·핵심
- **정의**: Oxford **Visual Geometry Group**의 CNN (2014). **3×3 합성곱만 깊게 쌓은** 단순한 구조로 **깊이가 성능에 중요하다는 것을 실험으로 증명** (대학원 07)
- **성적**: ILSVRC 2014 **2위**(1위 GoogLeNet), Top-5 오류 **7.3%** (AlexNet 16.4%). 1위보다 구조가 훨씬 간단해서 **더 널리 사용**됨
- **설계 규칙 (대학원 07)**
  - 모든 합성곱 **3×3, stride 1, same padding** / 모든 풀링 **2×2 MaxPool, stride 2**
  - 채널: 64 → 128 → 256 → 512 → 512 (풀링 때마다 2배)
  - FC 4096 → 4096 → 1000 → Softmax, 입력 224×224 RGB
  - **VGG16**: 합성곱 13 + FC 3 = **가중치 층 16개** (MaxPool 5개 포함 21층), 약 **1.38억** 파라미터
  - A·A-LRN·B·C·D·E 6가지 실험 → **깊을수록 성능↑**, LRN은 효과 없음
- **왜 3×3을 쌓는가 (대학원 07)**
  - 3×3 세 번 = 7×7 한 번과 **같은 수용 영역**
  - 가중치: **27개 vs 49개** → 파라미터 감소
  - ReLU가 3번 → **비선형성 증가**, 같은 영역에 더 추상적인 정보
- **단점**: 파라미터·메모리가 매우 크다 (대부분 FC). 개론 13차시: VGG-19-BN은 ResNet-18보다 에폭당 시간이 훨씬 길다(약 8분)
- **torchvision (개론 13차시)**
  - `models.vgg19_bn` — BN 추가판, Top-1 25.76 / Top-5 8.15
  - 분류기가 `classifier` Sequential → 마지막 FC는 **`classifier[6]`** (`Linear(4096, 1000)`)
  - 교체: `net.classifier[6] = nn.Linear(net.classifier[6].in_features, n_output)`
  - 강의 결과: CIFAR-10 파인튜닝 5에폭, 초기 93.67% → **최종 95.76%** (ResNet-18보다 높음)

## 수식·원리
```
블록: [Conv3×3 → ReLU] × (2 또는 3) → MaxPool 2×2
224 → 112 → 56 → 28 → 14 → 7,   7×7×512 = 25088 → 4096 → 4096 → 1000
```

## 코드 예시
```python
import torch
import torch.nn as nn
from torchvision import models

vgg = models.vgg16(weights=None)
convs = [m for m in vgg.features if isinstance(m, nn.Conv2d)]
print(len(convs), {m.kernel_size for m in convs})        # 13 {(3, 3)}  전부 3x3
print(round(sum(p.numel() for p in vgg.parameters()) / 1e6, 1))        # 138.4
print(round(sum(p.numel() for p in vgg.classifier.parameters()) / 1e6, 1))   # 123.6  FC가 대부분
print(vgg.classifier[6])                                 # Linear(in_features=4096, out_features=1000, bias=True)

net = models.vgg19_bn(weights=None)
net.classifier[6] = nn.Linear(net.classifier[6].in_features, 10)      # CIFAR-10용 교체
print(net(torch.randn(1, 3, 112, 112)).shape)            # torch.Size([1, 10])  (avgpool이 7x7로 맞춰 줌)
```
