# CNN 아키텍처 진화 정리

## 정의·핵심
- **흐름 한 줄**: 손글씨용 작은 CNN(LeNet) → GPU·ReLU로 대규모화(AlexNet) → **깊게**(VGG) → **효율적으로 넓게**(GoogLeNet) → **아주 깊어도 학습되게**(ResNet) → **가볍게**(MobileNet) → 어텐션(ViT)
- **비교표**

| 모델 | 연도 | 깊이 | 파라미터 | 핵심 아이디어 | ImageNet Top-5 |
|---|---|---|---|---|---|
| [[LeNet-5]] | 1998 | 5~7 | 6만 | Conv·Pool·FC 원형, 가중치 공유 | (MNIST) |
| [[AlexNet]] | 2012 | 8 | 6,100만 | ReLU, Dropout, 증강, GPU | 16.4% (1위) |
| [[VGG]] | 2014 | 16/19 | 1.38억 | 3×3만 깊게, 깊이가 중요 | 7.3% (2위) |
| [[GoogLeNet]] | 2014 | 22 | 700만 | Inception, 1×1 축소, GAP, 보조 분류기 | 6.7% (1위) |
| [[ResNet]] | 2015 | 18~152 | 1,170만(18) | 잔차 연결, BN, degradation 해결 | 3.57% (1위) |
| [[MobileNet(언급)]] | 2017 | - | 350만(V2) | Depthwise separable, 경량 | - |

- **반복되는 설계 원칙**
  - 깊을수록 좋다 — 단, **최적화가 가능해야** (ReLU → BN → 잔차 연결)
  - 큰 커널 대신 **작은 커널(3×3) 여러 개** → [[수용 영역(Receptive Field)]]
  - **1×1 conv로 채널 조절**해 연산량 절약 → [[1x1 Convolution]]
  - 무거운 FC 대신 **GAP** → [[Global Average Pooling(GAP)]]
  - 공간은 줄이고(Pool/stride 2) 채널은 늘린다 (64 → 512)
- **개론 13차시 torchvision 표 (Top-1/Top-5 에러)**: AlexNet 43.45/20.91, VGG-19-BN 25.76/8.15, ResNet-18 30.24/10.92, ResNet-152 21.69/5.94
- **고르는 기준**
  - 빠르고 가벼운 기본값: **ResNet-18/50** (교체도 `fc` 하나라 쉬움)
  - 정확도 우선, 자원 여유: VGG-BN, ResNet-152, EfficientNet
  - 모바일·엣지: MobileNet
  - 대규모 데이터·사전학습이 충분: ViT → [[ViT]]

## 수식·원리
```
plain:     x → F₁ → F₂ → … → y              (깊어지면 degradation)
residual:  x → [F₁ + I] → [F₂ + I] → … → y   (항등 경로로 기울기 전달)
```

## 코드 예시
```python
from torchvision import models

names = ["alexnet", "vgg16", "googlenet", "resnet18", "resnet152", "mobilenet_v2"]
for n in names:
    kw = {"aux_logits": False, "init_weights": False} if n == "googlenet" else {}
    m = getattr(models, n)(weights=None, **kw)
    print(f"{n:12s} {sum(p.numel() for p in m.parameters()) / 1e6:7.1f}M")
# alexnet         61.1M
# vgg16          138.4M
# googlenet        6.6M
# resnet18        11.7M
# resnet152       60.2M
# mobilenet_v2     3.5M
```
