# Flatten

## 정의·핵심
- **정의**: 다차원 텐서를 **1차원으로 쭉 펼치는** 층. CNN의 **특징 추출부와 분류부를 잇는 다리** (개론 11차시)
- **왜 필요한가 (강의)**: 합성곱·풀링을 거친 데이터는 여전히 채널·가로·세로를 가진 다차원 텐서. 그런데 최종 분류를 맡는 `nn.Linear`는 **1차원 벡터**를 입력으로 받는다
- **`nn.Flatten()`의 동작**
  - 기본값 `start_dim=1`: **배치 차원(0번)은 남기고** 나머지를 곱해 하나로 합친다
  - 강의 예: `[100, 32, 14, 14]` → **`[100, 6272]`** (32 × 14 × 14 = 6272) → `nn.Linear(in_features=6272, ...)`
- **같은 일을 하는 다른 방법**
  - `x.view(x.size(0), -1)` / `x.reshape(x.size(0), -1)` / `torch.flatten(x, 1)` → [[view·reshape·unsqueeze]]
  - 주의: `x.view(-1)`은 **배치까지 합쳐** 버린다 (모델 안에서 쓰면 안 됨). 강의의 MLP용 `transforms.Lambda(lambda x: x.view(-1))`는 **샘플 한 장 단위** 변환이라 괜찮다
- **MLP에서의 Flatten 문제**: 이미지를 처음부터 펼치면(MLP) 픽셀 간 공간 관계가 사라진다 → 개론 11차시 CIFAR-10: MLP 최대 53% vs CNN 66%. CNN은 **특징을 다 뽑은 뒤에** 펼치므로 공간 정보는 이미 특징에 담겨 있다
- 현대 모델은 Flatten 전에 **GAP**를 넣어 펼칠 크기를 채널 수로 줄인다 → [[Global Average Pooling(GAP)]]

## 수식·원리
```
(N, C, H, W) ─Flatten(start_dim=1)─▶ (N, C·H·W)
[100, 32, 14, 14] → [100, 6272]
```

## 코드 예시
```python
import torch
import torch.nn as nn

x = torch.randn(100, 32, 14, 14)
f = nn.Flatten()(x)
print(f.shape)                                         # torch.Size([100, 6272])
print(torch.equal(f, x.view(100, -1)), torch.equal(f, torch.flatten(x, 1)))   # True True
print(x.view(-1).shape)                                # torch.Size([627200])  ← 배치까지 합쳐짐(모델 안에선 금지)
print(torch.equal(f[3], x[3].reshape(-1)))             # True  샘플별로 C→H→W 순서로 펼침
print(nn.Linear(6272, 10)(f).shape)                    # torch.Size([100, 10])
```
