# 출력층 교체

## 정의·핵심
- **정의**: 사전학습 모델의 마지막 분류층(ImageNet **1000개 클래스**용)을 **우리 과제의 클래스 수에 맞는 새 층으로 바꾸는 것**. 전이학습의 첫 단계 (개론 13차시)
- **모델마다 위치가 다르다** — `print(net)`으로 마지막 층 이름부터 확인
  - **ResNet**: `net.fc` — 바로 접근 가능해 교체가 간단 (기본 `Linear(512, 1000)`)
    - `net.fc = nn.Linear(net.fc.in_features, n_output)`
  - **VGG·AlexNet**: `classifier`라는 Sequential의 **6번째 요소** `classifier[6]` (`Linear(4096, 1000)`)
    - `net.classifier[6] = nn.Linear(net.classifier[6].in_features, n_output)`
  - **MobileNetV2/V3, EfficientNet**: `classifier[-1]`
  - **DenseNet**: `classifier` (Linear 하나) / **ViT(torchvision)**: `heads.head`
  - **GoogLeNet**: `fc` (+ 보조 분류기 `aux1.fc2`, `aux2.fc2`)
- **`in_features`를 직접 숫자로 쓰지 말고 기존 층에서 읽어 쓰기** → 모델을 바꿔도 안전
- 이진 분류: `Linear(in, 2)` + CrossEntropyLoss 또는 `Linear(in, 1)` + BCEWithLogitsLoss
- **확장**: 하나의 Linear 대신 작은 head를 둘 수도 있다 — `nn.Sequential(nn.Dropout(0.5), nn.Linear(in, 256), nn.ReLU(), nn.Linear(256, n))`
- 새 층은 **무작위 초기화** 상태 → 동결된 백본보다 큰 학습률이 필요할 수 있다 → [[Feature Extraction vs Fine-tuning]]
- 교체 후 `.to(device)`를 다시 해야 한다 (교체 전 이미 GPU로 옮겼다면 새 층은 CPU에 있음)

## 수식·원리
```
ResNet-18:     ... → GAP → [fc: 512 → 1000]        ⇒  [fc: 512 → K]
VGG-19-BN:     ... → classifier[0..5] → [classifier[6]: 4096 → 1000]  ⇒  4096 → K
```

## 코드 예시
```python
import torch
import torch.nn as nn
from torchvision import models

n_output = 10
r = models.resnet18(weights=None)
r.fc = nn.Linear(r.fc.in_features, n_output)
v = models.vgg19_bn(weights=None)
v.classifier[6] = nn.Linear(v.classifier[6].in_features, n_output)
m = models.mobilenet_v2(weights=None)
m.classifier[-1] = nn.Linear(m.classifier[-1].in_features, n_output)
vit = models.vit_b_16(weights=None)
vit.heads.head = nn.Linear(vit.heads.head.in_features, n_output)

x = torch.randn(1, 3, 224, 224)
for name, net in [("resnet18", r), ("vgg19_bn", v), ("mobilenet_v2", m), ("vit_b_16", vit)]:
    net.eval()
    print(name, net(x).shape)                            # 모두 torch.Size([1, 10])
```
