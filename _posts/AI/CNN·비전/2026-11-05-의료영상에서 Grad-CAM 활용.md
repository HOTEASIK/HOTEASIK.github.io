# 의료영상에서 Grad-CAM 활용

## 정의·핵심
- **정의**: 의료영상 분류 모델이 **이미지의 어느 영역을 근거로** 판단했는지 히트맵으로 보여 주는 것. Grad-CAM = **Grad**ient-weighted **C**lass **A**ctivation **M**apping (응용 13차시 "AI의 시선 추적기"). 원리 자세히는 → [[Grad-CAM]]
- **왜 의료에서 특히 중요한가 (강의)**
  - 블랙박스처럼 작동하던 AI의 **판단 근거를 의료진이 직접 검토** → 임상 현장 도입에 큰 도움
  - 신뢰: 의사가 "왜 폐렴이라고 했는지" 확인할 수 있어야 보조 도구로 쓸 수 있다
  - 규제·책임: 설명 가능성은 의료기기 인허가와 법적 책임에서도 요구된다
- **강의의 5단계**
  1. **입력 이미지**: 흉부 X-ray 원본
  2. **모델 추론**: ResNet18이 NORMAL 또는 PNEUMONIA로 분류
  3. **기울기 계산**: 예측 클래스 점수에 대한 **특정 레이어(마지막 합성곱 층, ResNet은 `layer4[-1]`)** 의 기울기
  4. **히트맵 생성**: 중요 영역을 **빨간색(높음)~파란색(낮음)**
  5. **원본 오버레이**: 히트맵을 X-ray 위에 겹쳐 시각화
- **무엇을 확인하나**
  - 폐렴 예측 시 **폐 실질의 혼탁(음영) 부위**가 강조되는가
  - **지름길 학습(shortcut learning)** 검출: 병원 표식·글자·튜브·촬영 자세 표시 등을 보고 맞히는 모델은 다른 병원 데이터에서 실패 → Grad-CAM으로 발견
  - 틀린 예측(FN·FP)의 히트맵을 모아 오류 원인 분석
- **도구**: `pytorch-grad-cam` (`pip install grad-cam`) — `GradCAM(model, target_layers=[model.layer4[-1]])`, `show_cam_on_image` → [[captum·pytorch_grad_cam]] (이 PC에는 미설치라 아래는 hook으로 직접 구현)
- **한계**: 해상도가 낮다(ResNet18 마지막 특징 맵 7×7 → 224로 확대) → 작은 병변 위치는 거칠게만 표시. 히트맵이 "인과"를 보장하지는 않는다

## 수식·원리
```
α_k = (1/Z) Σ_i Σ_j ∂y_c / ∂A^k_ij          (채널 k 중요도 = 기울기의 GAP)
L_Grad-CAM = ReLU( Σ_k α_k · A^k )           → 입력 크기로 upsample → 0~1 정규화 → 컬러맵 오버레이
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torchvision import models

torch.manual_seed(0)
net = models.resnet18(weights=None)
net.fc = nn.Linear(512, 2)
net.eval()
store = {}
layer = net.layer4[-1]
h1 = layer.register_forward_hook(lambda m, i, o: store.__setitem__("A", o))
h2 = layer.register_full_backward_hook(lambda m, gi, go: store.__setitem__("G", go[0]))

x = torch.randn(1, 3, 224, 224)                      # 전처리된 X-ray라고 가정
logits = net(x)
cls = logits.argmax(1).item()
net.zero_grad(); logits[0, cls].backward()           # 예측 클래스 점수의 기울기
A, G = store["A"], store["G"]                        # (1, 512, 7, 7)
alpha = G.mean(dim=(2, 3), keepdim=True)             # 채널 중요도
cam = F.relu((alpha * A).sum(1, keepdim=True))
cam = F.interpolate(cam, size=(224, 224), mode="bilinear", align_corners=False)
cam = (cam - cam.min()) / (cam.max() - cam.min() + 1e-8)
print(A.shape[-2:], cam.shape, round(cam.min().item(), 2), round(cam.max().item(), 2))   # torch.Size([7, 7]) torch.Size([1, 1, 224, 224]) 0.0 1.0
h1.remove(); h2.remove()
# 오버레이: plt.imshow(xray, cmap="gray"); plt.imshow(cam[0, 0], cmap="jet", alpha=0.4)
```
