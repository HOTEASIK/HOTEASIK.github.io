# Stride

## 정의·핵심
- **정의**: 커널이 한 번에 **몇 칸씩 이동**하는지(가로·세로 간격). `nn.Conv2d(..., stride=S)` (대학원 05)
- **효과 (대학원 05)**
  - **stride 1**: 한 칸씩 이동 → 이웃한 수용 영역이 **넓게 겹치고** 출력이 크다
  - **stride가 크면**: 수용 영역끼리 좁게만 겹치고 **출력 크기가 작아진다** (stride 2 → 약 절반)
- **다운샘플링 수단**
  - 풀링 대신 **stride 2 합성곱**으로 특징 맵을 줄일 수 있다 — 줄이는 방식까지 **학습** 가능
  - ResNet 구현 팁 (대학원 09): 특징 맵을 줄일 때 **풀링을 거의 쓰지 않고 stride 2 합성곱** 사용, 크기가 절반이 되면 **채널 수는 2배**
- **계산량**: 출력이 1/S² 로 줄어 연산량도 크게 감소
- **주의**: `(W − F + 2P)`가 S로 나누어떨어지지 않으면 나머지 가장자리는 버려진다(내림) → 정수가 되도록 크기 설계 (대학원 05 "정수가 되도록 조정")
- 풀링의 stride는 기본값이 **kernel_size와 같다** (`MaxPool2d(2)` = stride 2)

## 수식·원리
```
출력 = ⌊(W − F + 2P) / S⌋ + 1
AlexNet 첫 층: (227 − 11 + 0) / 4 + 1 = 55
```

## 코드 예시
```python
import torch
import torch.nn as nn

x = torch.randn(1, 3, 32, 32)
for s in (1, 2, 4):
    print(s, nn.Conv2d(3, 8, 3, stride=s, padding=1)(x).shape[-2:])
# 1 torch.Size([32, 32])
# 2 torch.Size([16, 16])
# 4 torch.Size([8, 8])
print(nn.Conv2d(3, 96, 11, stride=4)(torch.randn(1, 3, 227, 227)).shape)   # torch.Size([1, 96, 55, 55])  AlexNet
print(nn.Conv2d(3, 1, 3, stride=2)(torch.randn(1, 3, 8, 8)).shape[-1])      # 3  (8-3)/2+1 = 3.5 → 내림
```
