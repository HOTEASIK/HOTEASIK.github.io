# LeNet-5

## 정의·핵심
- **정의**: Yann LeCun이 1998년 발표한 **최초의 실용적 CNN**. 손글씨 숫자(우편번호·수표) 인식용. 현대 CNN의 원형 (대학원 05)
- **배경 (대학원 05)**: 당시 분류기는 저차원·쉽게 분리되는 공간에서만 잘 동작 → 사람이 특징 추출기를 설계해야 했다. LeNet은 특징 추출까지 **학습**으로 해결
- **세 가지 핵심 아이디어** — 이동·크기·왜곡에 어느 정도 불변
  1. **Local receptive fields**: 각 노드를 입력의 로컬 영역에만 연결
  2. **Shared weights (weight replication)**: 하나의 커널을 이미지 전체에 동일하게 적용 — 커널 값 자체는 위치마다 바뀌지 않음
  3. **Spatial sub-sampling (Pooling)**: 해상도를 줄여 위치 변화·왜곡에 강인
- **구조** (입력 32×32 흑백)
  - C1: Conv 5×5, 6채널 → 28×28×6
  - S2: 평균 풀링 2×2 → 14×14×6
  - C3: Conv 5×5, 16채널 → 10×10×16
  - S4: 풀링 → 5×5×16
  - C5: FC 120 (원 논문은 5×5 conv) → F6: FC 84 → 출력 10
  - 활성화: tanh/sigmoid (ReLU 이전 시대), 파라미터 약 **6만 개**
- **MNIST**: 28×28 흑백 손글씨 0~9, 학습 60,000 / 테스트 10,000 → 28×28이면 첫 conv에 `padding=2`를 주어 32×32와 같게 만든다
- Conv → Pool → Conv → Pool → FC 패턴은 이후 AlexNet·VGG로 그대로 이어진다

## 수식·원리
```
32×32×1 ─C1 5×5─▶ 28×28×6 ─S2─▶ 14×14×6 ─C3 5×5─▶ 10×10×16 ─S4─▶ 5×5×16
        ─Flatten 400─▶ FC 120 ─▶ FC 84 ─▶ 10
```

## 코드 예시
```python
import torch
import torch.nn as nn

class LeNet5(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, 5, padding=2), nn.Tanh(), nn.AvgPool2d(2),   # MNIST 28x28 → padding 2
            nn.Conv2d(6, 16, 5), nn.Tanh(), nn.AvgPool2d(2))
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Linear(16 * 5 * 5, 120), nn.Tanh(), nn.Linear(120, 84), nn.Tanh(), nn.Linear(84, n_classes))
    def forward(self, x):
        return self.classifier(self.features(x))

net = LeNet5()
x = torch.randn(8, 1, 28, 28)
print(net.features(x).shape, net(x).shape)               # torch.Size([8, 16, 5, 5]) torch.Size([8, 10])
print(sum(p.numel() for p in net.parameters()))          # 61706  약 6만 개
```
