# ResNet18 스크래치 구현

## 정의·핵심
- **목표**: torchvision을 쓰지 않고 **Residual Block부터 직접 조립**해 ResNet-18을 만들고, CIFAR-10·SVHN 같은 작은 이미지로 학습 (개론 16차시 "CNN 스크래치 구현: Residual block·ResNet18")
- **ResNet-18 구성** — 가중치 층 18개 = 첫 conv 1 + BasicBlock 8개 × conv 2 + FC 1
  - stem: Conv → BN → ReLU (→ MaxPool)
  - **layer1**: BasicBlock(64) × 2
  - **layer2**: BasicBlock(128, stride 2) + BasicBlock(128)
  - **layer3**: 256 × 2 (첫 블록 stride 2)
  - **layer4**: 512 × 2 (첫 블록 stride 2)
  - AdaptiveAvgPool(1) → Flatten → FC(512, num_classes)
  - 각 stage의 **첫 블록만** 크기 절반·채널 2배 → **projection shortcut** 필요
- **32×32 작은 이미지용 수정 (CIFAR 버전)**
  - ImageNet stem(7×7 stride 2 + MaxPool)을 쓰면 32 → 8로 너무 빨리 작아진다
  - stem을 **3×3, stride 1, MaxPool 없음**으로 바꾸는 것이 관례 → 32 → 32 → 16 → 8 → 4
- **`_make_layer` 패턴**: `strides = [stride] + [1] * (num_blocks − 1)`로 블록 리스트를 만들고 `nn.Sequential(*layers)`
- **데이터 (개론 16차시)**
  - CIFAR-10: 60,000장(학습 50K, 테스트 10K), 32×32 컬러, 10클래스(각 6,000장). 저해상도라 빠른 실험 가능, 실제 사진이라 라벨 노이즈, cat vs dog·automobile vs truck처럼 **클래스가 비슷**
  - SVHN: 실제 거리 번지수 숫자 사진 (`datasets.SVHN(split='train')`)
- **확인 순서**: 더미 입력으로 출력 shape → 파라미터 수(약 1,117만) → 작은 배치에서 손실이 떨어지는지(과적합 테스트) → 전체 학습

## 수식·원리
```
32×32×3 ─stem 3×3─▶ 32×32×64 ─layer1─▶ 32×32×64 ─layer2─▶ 16×16×128
        ─layer3─▶ 8×8×256 ─layer4─▶ 4×4×512 ─GAP─▶ 512 ─FC─▶ 10
층 수: 1 + 2·(2+2+2+2) + 1 = 18
```

## 코드 예시
```python
import torch
import torch.nn as nn

class BasicBlock(nn.Module):
    def __init__(self, c_in, c_out, stride=1):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(c_in, c_out, 3, stride, 1, bias=False), nn.BatchNorm2d(c_out), nn.ReLU(inplace=True),
            nn.Conv2d(c_out, c_out, 3, 1, 1, bias=False), nn.BatchNorm2d(c_out))
        self.shortcut = nn.Sequential()
        if stride != 1 or c_in != c_out:
            self.shortcut = nn.Sequential(nn.Conv2d(c_in, c_out, 1, stride, bias=False), nn.BatchNorm2d(c_out))
    def forward(self, x):
        return torch.relu(self.body(x) + self.shortcut(x))

class ResNet18(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.c = 64
        self.stem = nn.Sequential(nn.Conv2d(3, 64, 3, 1, 1, bias=False), nn.BatchNorm2d(64), nn.ReLU(inplace=True))
        self.layer1 = self._make_layer(64, 2, 1)
        self.layer2 = self._make_layer(128, 2, 2)
        self.layer3 = self._make_layer(256, 2, 2)
        self.layer4 = self._make_layer(512, 2, 2)
        self.head = nn.Sequential(nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(512, num_classes))
    def _make_layer(self, c_out, n, stride):
        layers = []
        for s in [stride] + [1] * (n - 1):
            layers.append(BasicBlock(self.c, c_out, s)); self.c = c_out
        return nn.Sequential(*layers)
    def forward(self, x):
        x = self.stem(x)
        x = self.layer4(self.layer3(self.layer2(self.layer1(x))))
        return self.head(x)

torch.manual_seed(0)
net = ResNet18()
print(net(torch.randn(2, 3, 32, 32)).shape)                       # torch.Size([2, 10])
print(round(sum(p.numel() for p in net.parameters()) / 1e6, 2))   # 11.17
convs = sum(isinstance(m, nn.Conv2d) and m.kernel_size == (3, 3) for m in net.modules())
print(convs + 1)                                                  # 18  (3x3 conv 17 + FC 1)

x, y = torch.randn(8, 3, 32, 32), torch.randint(0, 10, (8,))      # 작은 배치 과적합 테스트
opt = torch.optim.Adam(net.parameters(), 1e-3)
for step in range(30):
    loss = nn.functional.cross_entropy(net(x), y); opt.zero_grad(); loss.backward(); opt.step()
print(loss.item() < 0.1)                                          # True  손실이 거의 0까지
```
