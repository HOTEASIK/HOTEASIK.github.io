# 이미지 데이터의 특성

## 정의·핵심
- **컴퓨터 비전**: 디지털 시스템이 이미지·영상을 **픽셀 수준에서 처리·분석·이해**하게 만드는 분야. 사람은 사진에서 사람·사물을 보지만, 컴퓨터에게 이미지는 **R·G·B 밝기를 나타내는 숫자 배열**일 뿐이다 (대학원 01)
- **이미지를 이루는 요소 (대학원 01)**
  - **Matrix**: 숫자로 이루어진 2차원 배열. 행·열 수가 이미지 크기(해상도). 클수록 저장공간·처리 비용이 비례해서 증가
  - **Pixel**: 행렬의 각 숫자 = 밝기. 픽셀이 많을수록 **공간 해상도(spatial resolution)** 가 좋다
  - **Bit depth**: 픽셀 값의 범위. 8bit면 0~255. 클수록 밝기 표현이 다양하지만 저장공간↑ (의료영상은 12~16bit도 흔함)
  - **Channel**: 픽셀 하나가 가진 값의 개수. 흑백 1채널, 컬러 **RGB 3채널**. Red 채널 = 이미지 전체의 빨강 밝기만 모은 행렬
- **텐서 모양 규칙**
  - PIL·OpenCV·matplotlib: **HWC** `(높이, 너비, 채널)`, 값 0~255 `uint8`. OpenCV는 **BGR** 순서
  - PyTorch: **CHW** `(채널, 높이, 너비)`, 배치까지 **NCHW** `(N, C, H, W)`, `float32`
  - `transforms.ToTensor()`가 HWC uint8 → CHW float [0, 1]로 바꿔 준다 → [[transforms]]
- **비전이 어려운 이유 (대학원 01)**: 가려짐(Occlusion), 크기(Scale), 변형(Deformation), 배경 혼잡(Clutter), 시점(View point), 조명(Illumination), 자세(Object pose) — 같은 물체도 픽셀 값은 완전히 달라진다
- **이미지 데이터의 성질 → CNN이 필요한 이유**
  - **공간 구조**: 이웃 픽셀끼리 강하게 관련 → 1차원으로 펼치면(MLP) 이 정보가 사라진다 (개론 11차시: CIFAR-10에서 MLP 53% vs CNN 66%)
  - **고차원**: 224×224×3 = 150,528개 값 → 완전연결이면 파라미터 폭증
  - **위치 불변성**: 고양이가 어디 있든 고양이 → 같은 필터를 전체에 공유(합성곱)
- 응용: 자율주행, OCR, 얼굴 인식, 모션 캡처, 의료영상. 주요 학회: CVPR, ICCV, ECCV

## 수식·원리
```
흑백: (H, W)          컬러: (H, W, 3)  →  PyTorch (3, H, W)  →  배치 (N, 3, H, W)
값의 개수 = H × W × C,   8bit 저장 크기 = H × W × C 바이트
```

## 코드 예시
```python
import numpy as np
import torch
from PIL import Image
from torchvision import transforms

arr = np.zeros((4, 6, 3), dtype=np.uint8)          # HWC: 높이 4, 너비 6, RGB
arr[..., 0] = 255                                  # Red 채널만 최대 → 빨간 이미지
img = Image.fromarray(arr)
print(img.size, img.mode)                          # (6, 4) RGB   PIL은 (너비, 높이)
x = transforms.ToTensor()(img)
print(x.shape, x.dtype, x[0].max().item(), x[1].max().item())   # torch.Size([3, 4, 6]) torch.float32 1.0 0.0
print(x.unsqueeze(0).shape, 224 * 224 * 3)         # torch.Size([1, 3, 4, 6]) 150528
bgr = arr[..., ::-1]                               # OpenCV식 BGR로 바꾸면 빨강이 Blue 자리로
print(bgr[0, 0].tolist())                          # [0, 0, 255]
```
