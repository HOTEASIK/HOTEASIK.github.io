# BiLSTM

## 정의·핵심
- **정의 (응용 8차시)**: 순방향 LSTM에 **역방향으로 입력을 참고하는 LSTM을 추가**해 양방향으로 만든 구조 (Bidirectional LSTM)
  - **이점**: 앞의 문맥뿐 아니라 **뒤의 문맥까지** 참고 — 강의 빈칸 예: "Exercise is very effective at [ ] belly fat." → 뒤의 "belly fat"을 봐야 reducing / building / boosting 중 **reducing** 을 고를 수 있음
- **Deep / Bidirectional (강의)**
  - **Deep RNN**: 은닉층을 여러 층 쌓음 (`num_layers`)
  - **Bidirectional RNN**: 정방향 + 역방향
  - **Deep Bidirectional RNN**: 양방향 RNN의 은닉층을 여러 층으로
- **BiLSTM 텍스트 분류 (강의 "구조는?")**
  - 분류는 결국 **many-to-one** → 문장 전체를 대표하는 벡터 하나가 필요
  - 순방향 LSTM의 **마지막 시점** hidden + 역방향 LSTM의 **첫 시점**(= 역방향 입장에서 마지막) hidden을 **concatenate**
  - 강의 주의: 두 방향 모두 **같은 끝(마지막 시점)의 output만** 쓰면 역방향은 한 단어만 본 상태 → "**양방향으로 구현한 의미가 없음**"
- **PyTorch 구현 (개론 17차시 과제 문제 5)**
  - `nn.LSTM(..., bidirectional=True)` → `output: (B, L, 2H)`, `h_n: (2·layers, B, H)`
  - `h_n[-2]`(순방향 마지막) 와 `h_n[-1]`(역방향 마지막) 을 `torch.cat(..., dim=1)` → `(B, 2H)` → `fc = Linear(2H, num_classes)`
- **개론 17차시 실습**: IMDb, `Embedding → BiLSTM → Linear` 감성 분류 → [[텍스트 분류 실습]]
- **쓰임**: 분류, **개체명 인식(NER)** 같은 시퀀스 레이블링(+CRF), ELMo의 기반 → [[ELMo]]
- **한계**: 생성(다음 단어 예측)에는 미래를 볼 수 없으므로 사용 불가

## 수식·원리
```
→h_t = LSTM_fwd(x_t, →h_{t−1})
←h_t = LSTM_bwd(x_t, ←h_{t+1})
output_t = [→h_t ; ←h_t]          (2H)
문장 표현 = [→h_L ; ←h_1] = cat(h_n[-2], h_n[-1])
```

## 코드 예시
```python
import torch
import torch.nn as nn

class BiLSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embed=32, hidden=64, num_classes=2):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed, padding_idx=0)
        self.lstm = nn.LSTM(embed, hidden, batch_first=True, bidirectional=True)
        self.fc = nn.Linear(hidden * 2, num_classes)
    def forward(self, x):
        out, (hn, cn) = self.lstm(self.embedding(x))
        h = torch.cat((hn[-2], hn[-1]), dim=1)            # 과제 문제 5: 순방향 + 역방향 마지막 은닉
        return self.fc(h), out, hn

torch.manual_seed(0)
m = BiLSTMClassifier(1000)
logits, out, hn = m(torch.randint(1, 1000, (3, 12)))
print(tuple(out.shape), tuple(hn.shape), tuple(logits.shape))   # (3, 12, 128) (2, 3, 64) (3, 2)
H = 64
print(torch.allclose(out[:, -1, :H], hn[0]))              # True   순방향 마지막 = output 마지막 시점 앞쪽 절반
print(torch.allclose(out[:, 0, H:], hn[1]))               # True   역방향 마지막 = output 첫 시점 뒤쪽 절반
print(torch.allclose(out[:, -1, H:], hn[1]))              # False  output[:, -1] 만 쓰면 역방향은 한 단어만 본 상태
```
