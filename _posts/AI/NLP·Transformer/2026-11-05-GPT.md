# GPT

## 정의·핵심
- **정의 (응용 14차시 GPT)**: Generative Pre-trained Transformer (OpenAI, 2018~). Transformer의 **Decoder만** 쌓아, **이전 단어들로부터 다음 단어를 예측**(Auto-Regressive)하도록 대용량 텍스트로 사전학습한 언어 모델
- **구조**: Masked Self-Attention만 있는 Decoder 블록 (Cross-Attention 없음) → 각 토큰은 **왼쪽(과거)만** 봄 → [[Transformer Decoder]]
  - 사전학습 목표: `p(x_t | x_<t)` 최대화 — 레이블 없이 모든 텍스트가 학습 데이터 → [[Autoregressive 모델(언급)]]
  - 생성(추론): 디코더가 단어를 **1개씩** 생성해 다시 입력 (강의 Transformer Inference 슬라이드: `<sos>` → je → suis → étudiant → `<eos>`)
- **BERT vs GPT (강의)**: BERT는 양방향 문맥 → NLU에 강하지만 **NLG 사용 불가** / GPT는 단방향 → **NLG(생성)에 강함** → [[NLU vs NLG]]
- **GPT의 발전 (강의)**: GPT-1 → GPT-2 → GPT-3는 **아키텍처 면에서 큰 차이가 없음** — 차이는 **학습 데이터의 양과 모델 크기**
  - GPT-1 (117M): 사전학습 + 태스크별 파인튜닝
  - GPT-2 (1.5B): 파인튜닝 없이 zero-shot 가능성 제시, Pre-LN
  - GPT-3 (175B): **In-context Learning** — 예시 몇 개만으로 문제 해결 → [[In-context Learning]]
- **활용 (강의)**
  - **번역**: 사이즈가 크면 인코더 없이 "영어 문장 → 프랑스어 문장"을 하나의 시퀀스로 학습해 번역 가능
  - **요약**: 위키피디아 본문 + 요약문을 이어 붙인 학습셋 → 본문 뒤에 요약 생성
- **현재 LLM**: 대부분 **GPT 계열 디코더 모델** (ChatGPT, LLaMA 등) → [[LLM·ChatGPT]]
- **디코딩 전략**: greedy, beam, **temperature / top-k / top-p 샘플링** → [[Greedy Search·Beam Search]]

## 수식·원리
```
L(θ) = −Σ_t log p_θ(x_t | x_1, ..., x_{t−1})
h = DecoderBlocks^{N}(Emb(x) + Pos),   p(x_{t+1} | x_≤t) = softmax(h_t W_eᵀ)   (임베딩 가중치 공유)
temperature: p_i ∝ exp(z_i / T)
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
text = "hello world hello there hello world "
chars = sorted(set(text)); stoi = {c: i for i, c in enumerate(chars)}
data = torch.tensor([stoi[c] for c in text])
V, D, L = len(chars), 32, 8

class TinyGPT(nn.Module):
    def __init__(self):
        super().__init__()
        self.tok, self.pos = nn.Embedding(V, D), nn.Embedding(L, D)
        self.blocks = nn.TransformerEncoder(nn.TransformerEncoderLayer(D, 4, 64, batch_first=True, dropout=0.0), 2)
        self.head = nn.Linear(D, V)
    def forward(self, x):
        n = x.size(1)
        causal = nn.Transformer.generate_square_subsequent_mask(n)           # 과거만 보기 → 디코더처럼 동작
        return self.head(self.blocks(self.tok(x) + self.pos(torch.arange(n)), mask=causal))

m = TinyGPT(); opt = torch.optim.Adam(m.parameters(), lr=3e-3)
X = torch.stack([data[i:i + L] for i in range(len(data) - L)]); Y = torch.stack([data[i + 1:i + L + 1] for i in range(len(data) - L)])
for _ in range(300):                                                          # 다음 글자 예측 (입력 한 칸 밀기)
    loss = nn.functional.cross_entropy(m(X).reshape(-1, V), Y.reshape(-1)); opt.zero_grad(); loss.backward(); opt.step()
print(loss.item() < 0.3)                                                      # True

m.eval(); ctx = [stoi[c] for c in "hello w"]
with torch.no_grad():
    for _ in range(5):                                                        # Auto-regressive 생성
        ctx.append(m(torch.tensor([ctx[-L:]]))[0, -1].argmax().item())
print("".join(chars[i] for i in ctx))                                         # hello world   학습한 패턴대로 이어서 생성
```
