# 임베딩

## 정의·핵심
- **정의**: 단어(토큰)를 **저차원의 밀집 실수 벡터(Dense Vector)** 로 표현하는 것. 의미가 비슷한 단어일수록 벡터 공간에서 가깝게 위치 (개론 17차시 "단어 임베딩의 이해")
  - 원-핫(희소, V차원, 유사도 없음) → 임베딩(밀집, 수십~수천 차원, **유사도 표현**) → [[원-핫 인코딩(텍스트)]]
- **`nn.Embedding` (17차시 과제 문제 2)**: **토큰 인덱스(정수)** 를 입력받아 학습 가능한 가중치 행렬(V × D)에서 그 행을 꺼내 **벡터**로 변환하는 **룩업 테이블** — NLP 모델의 첫 번째 계층
  - 입력 `(B, L)` 정수 → 출력 `(B, L, D)` 실수
  - 처음엔 랜덤 초기화 → 과제(분류 등)의 손실로 **함께 학습**되어 그 과제에 맞는 의미를 갖게 됨
  - `padding_idx`: 패딩 토큰 벡터를 0으로 고정
- **임베딩을 얻는 방법**
  - **과제와 함께 학습**: `nn.Embedding` 을 모델 일부로
  - **사전학습 정적 임베딩**: Word2Vec, GloVe, FastText — 대용량 말뭉치의 **동시 등장 통계**로 학습, 단어당 벡터 1개 → [[Word2Vec]]
  - **문맥 임베딩(Contextual)**: ELMo, BERT, GPT — 같은 단어라도 문맥에 따라 다른 벡터 ("배"를 먹다 / 배를 타다) → [[ELMo]], [[BERT]]
  - **API 임베딩**: 강의 보강 실습 — OpenAI `text-embedding-3-small` 로 문장 → 1536차원 벡터 (모델마다 차원이 다름). API 키는 코드에 쓰지 않고 환경변수/보안 저장소에서 읽음
- **유사도 측정**: **코사인 유사도** `A·B / (‖A‖‖B‖)` (방향), 유클리드 거리 — 개론 17차시 NLP SPECIAL 실습
- **활용**: 검색(의미 기반), 추천, 군집, RAG의 문서 검색, 분류 모델 입력

## 수식·원리
```
E ∈ ℝ^{V×D},   embed(i) = E[i, :] = onehot(i)^T E
cos(A, B) = A·B / (‖A‖ ‖B‖)   ∈ [−1, 1]
dist(A, B) = √Σ (A_k − B_k)²
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn

emb = nn.Embedding(num_embeddings=10, embedding_dim=4, padding_idx=0)
ids = torch.tensor([[5, 2, 0], [7, 7, 1]])            # (B=2, L=3) 토큰 인덱스
out = emb(ids)
print(tuple(emb.weight.shape), tuple(out.shape))     # (10, 4) (2, 3, 4)
print(torch.equal(out[1, 0], out[1, 1]))             # True  같은 인덱스 → 같은 벡터
print(emb.weight.requires_grad)                      # True  모델과 함께 학습

def cos_sim(A, B): return A @ B / (np.linalg.norm(A) * np.linalg.norm(B))
doc1, doc2, doc3 = np.array([0, 1, 1, 1]), np.array([1, 0, 1, 1]), np.array([2, 0, 2, 2])
print(round(cos_sim(doc1, doc2), 3), round(cos_sim(doc2, doc3), 3))   # 0.667 1.0  (강의 예제) 방향이 같으면 1
docQ = np.array((1, 1, 0, 1))
for d in (np.array((2, 3, 0, 1)), np.array((1, 2, 3, 1)), np.array((2, 1, 2, 2))):
    print(round(float(np.sqrt(((d - docQ) ** 2).sum())), 3), end=" ")  # 2.236 3.162 2.449  유클리드 거리
```
