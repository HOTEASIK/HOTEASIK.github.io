# NNLM

## 정의·핵심
- **정의 (응용 8차시)**: Neural Network Language Model (Bengio, 2003). **피드 포워드 신경망으로 구현한 언어 모델** — 이전 **n개 단어로 n+1번째 단어를 예측**
  - 언어 모델(Language Model): 이전 단어들로부터 다음 단어를 예측 (문장의 확률을 계산)
- **강의 예시**: "what will the fat cat sit on", n = 4 → **will, the, fat, cat** 으로 **sit** 예측. 입력은 원-핫 벡터
- **구조 (강의)**
  1. **Input layer**: n개 단어의 원-핫 벡터 (V차원)
  2. **Projection layer (linear, 활성화 없음)**: 각 원-핫 × **W(V×M)** = W의 해당 행 → **lookup table**. n개의 M차원 벡터를 **concatenate** (n·M)
  3. **Hidden layer** (tanh) → **Output layer** (softmax, V차원)
  4. 정답 다음 단어 원-핫과 **Cross Entropy** 로 학습 → 이 과정에서 **Projection layer의 embedding table이 학습**됨
- **의의 (강의)**
  - 투사층 W의 각 행 = 단어의 **밀집 벡터(Dense Vector)** — **임베딩의 시초**, Word2Vec으로 이어짐 → [[Word2Vec]]
  - 유사한 용도의 단어는 유사한 벡터 → "a cute dog"를 학습했다면 훈련 데이터에 없는 "a cute cat"도 생성 가능 (n-gram의 희소성 문제 완화)
- **한계 (강의)**: **고정된 n개 입력만** 받음 (N-gram LM과 같음) → 문장이 길고 앞부분에 중요한 정보가 있으면 반영 불가 → 입력 길이가 고정되지 않는 **RNN 언어 모델**로 발전 → [[RNN]]

## 수식·원리
```
e_i = x_i^T W              (V → M, lookup)
p = concat(e_{t−n}, ..., e_{t−1})         ∈ ℝ^{n·M}
h = tanh(W_h p + b_h)
ŷ = softmax(W_y h + b_y)  ∈ ℝ^V
L = −log ŷ[w_t]
```

## 코드 예시
```python
import torch
import torch.nn as nn

class NNLM(nn.Module):
    def __init__(self, V, M=8, n=4, H=32):
        super().__init__()
        self.proj = nn.Embedding(V, M)                   # Projection layer = lookup table
        self.hidden = nn.Linear(n * M, H)
        self.out = nn.Linear(H, V)
    def forward(self, x):                                # x: (B, n)
        p = self.proj(x).flatten(1)                      # concatenate → (B, n*M)
        return self.out(torch.tanh(self.hidden(p)))

words = "what will the fat cat sit on".split()
idx = {w: i for i, w in enumerate(words)}
X = torch.tensor([[idx[w] for w in words[i:i + 4]] for i in range(3)])   # 4단어씩
y = torch.tensor([idx[words[i + 4]] for i in range(3)])                 # 다음 단어
print([[words[j] for j in r] for r in X.tolist()][1], words[y[1]])      # ['will', 'the', 'fat', 'cat'] sit

torch.manual_seed(0)
m = NNLM(len(words))
opt = torch.optim.Adam(m.parameters(), lr=0.05)
for _ in range(100):
    loss = nn.functional.cross_entropy(m(X), y); opt.zero_grad(); loss.backward(); opt.step()
pred = m(torch.tensor([[idx[w] for w in ["will", "the", "fat", "cat"]]])).argmax(-1).item()
print(words[pred], tuple(m.proj.weight.shape))           # sit (7, 8)  투사층 = 학습된 임베딩 테이블
```
