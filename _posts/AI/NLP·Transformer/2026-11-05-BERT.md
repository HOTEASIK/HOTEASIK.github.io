# BERT

## 정의·핵심
- **정의 (응용 14차시)**: Bidirectional Encoder Representations from Transformers (Google, 2018). Transformer의 **Encoder 부분만** 사용해 문장의 **앞뒤 문맥을 동시에** 파악하는 **양방향(Bidirectional)** 사전학습 모델 (GPT는 단방향 Decoder)
- **입력 (강의)**: `[CLS] My dog is cute [SEP]` — 특수 토큰 포함
  - **세 가지 임베딩의 합**: **Token** + **Segment**(문장 A/B 구분) + **Position**(학습형)
  - **[CLS]**: 맨 앞 분류용 토큰 → 최종 출력 **C**를 문장 전체 표현으로 분류에 사용 / **[SEP]**: 문장 구분·끝
  - 출력: C(분류용 CLS), T₁…Tₙ(토큰별 표현)
  - 토크나이저: WordPiece (`playing` → `play`, `##ing`) → [[토큰화(Tokenizer)]]
- **사전학습 태스크 2가지 (강의)**
  - **Task 1 — MLM (Masked Language Model)**: 문장의 빈칸(**15%**)을 뚫고 문맥으로 해당 단어를 맞추며 언어 이해력 학습. 예: "I [MASK] you." → love
    - 15% 중 80%는 `[MASK]`, 10%는 랜덤 단어, 10%는 그대로 (파인튜닝 때 [MASK]가 없는 불일치 완화)
    - 양방향으로 보면 "자기 자신을 보는" 문제가 생기므로 **가리고 맞추는** 방식으로 해결
  - **Task 2 — NSP (Next Sentence Prediction)**: 두 문장이 이어지는 문장인지(IsNext) 판단 → 문장 간 관계 학습. 예: A "I love you." / B "He flies." → NotNext
- **모델 크기 (강의 표)**

| 모델 | Layers | Hidden | Heads | Parameters |
|---|---|---|---|---|
| BERT-Base | 12 | 768 | 12 | **110M** |
| BERT-Large | 24 | 1024 | 16 | **340M** |

- **파인튜닝 (강의)**: 사전학습 BERT + 태스크별 추가 신경망 → 태스크 오차로 학습. 문장 분류는 **[CLS] 출력 → Linear**, NER은 토큰별 출력 → Linear, 질의응답은 시작·끝 위치 예측 → [[PLM·Pre-training·Fine-tuning]]
- **BERT vs GPT (강의)**: BERT는 양방향 문맥 반영 → **NLU에 강함, 그러나 NLG(생성)에 사용 불가** / GPT는 이전 단어로 다음 단어 예측 → 생성 → [[NLU vs NLG]]
- **후속**: RoBERTa(학습 방식 개선), DistilBERT(경량화), ALBERT, ELECTRA, 한국어 KoBERT·KLUE-BERT → [[RoBERTa]], [[DistilBERT]]

## 수식·원리
```
입력 = TokenEmb + SegmentEmb + PositionEmb
H = TransformerEncoder^{12}(입력)              (양방향 self-attention, 마스크 없음)
MLM:  L = −Σ_{i∈Masked} log p(x_i | x_{\Masked})
NSP:  L = BCE(σ(w·H_[CLS]), IsNext)
분류 파인튜닝:  ŷ = softmax(W · H_[CLS])
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
V, D, L = 100, 64, 12
CLS, SEP, MASK = 1, 2, 3

class TinyBERT(nn.Module):
    def __init__(self):
        super().__init__()
        self.tok, self.seg, self.pos = nn.Embedding(V, D), nn.Embedding(2, D), nn.Embedding(L, D)
        self.enc = nn.TransformerEncoder(nn.TransformerEncoderLayer(D, 4, 128, batch_first=True), 2)
        self.mlm, self.nsp = nn.Linear(D, V), nn.Linear(D, 2)
    def forward(self, ids, seg):
        x = self.tok(ids) + self.seg(seg) + self.pos(torch.arange(ids.size(1)))   # 세 임베딩의 합
        h = self.enc(x)
        return self.mlm(h), self.nsp(h[:, 0])                                     # 토큰별 MLM, [CLS]로 NSP

ids = torch.tensor([[CLS, 10, 11, 12, SEP, 20, 21, SEP]])     # [CLS] A문장 [SEP] B문장 [SEP]
seg = torch.tensor([[0, 0, 0, 0, 0, 1, 1, 1]])
m = TinyBERT()
mlm_logits, nsp_logits = m(ids, seg)
print(tuple(mlm_logits.shape), tuple(nsp_logits.shape))      # (1, 8, 100) (1, 2)

x = torch.randint(4, V, (10000,))                             # MLM 마스킹 규칙 15% (80/10/10)
sel = torch.rand(10000) < 0.15
r = torch.rand(10000)
masked = x.clone(); masked[sel & (r < 0.8)] = MASK
masked[sel & (r >= 0.8) & (r < 0.9)] = torch.randint(4, V, ((sel & (r >= 0.8) & (r < 0.9)).sum(),))
print(round(sel.float().mean().item(), 2), round((masked == MASK).float().mean().item(), 2))   # 0.15 0.12
```
