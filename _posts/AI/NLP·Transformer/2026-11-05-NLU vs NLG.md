# NLU vs NLG

## 정의·핵심
- **NLU (Natural Language Understanding, 자연어 이해)**: 텍스트를 읽고 **의미를 파악**해 판단 — 분류, 감성 분석, 개체명 인식(NER), 기계 독해(MRC), 문장 유사도, 자연어 추론(NLI)
- **NLG (Natural Language Generation, 자연어 생성)**: 새로운 **텍스트를 만들어 냄** — 번역, 요약, 대화(챗봇), 질문 생성, 캡셔닝
- **구조별 강점 (응용 14차시 BART 슬라이드)**
  - **인코더 (BERT)**: MLM으로 가운데 단어 예측 → 양방향 문맥 → **NLU에 강함**, 그러나 **NLG에 사용 불가** (다음 단어를 순서대로 만드는 학습을 하지 않음) → [[BERT]]
  - **디코더 (GPT)**: 이전 단어로 다음 단어 예측 → **NLG에 강함** (NLU도 프롬프트로 가능하지만 같은 크기 인코더보다 약했음) → [[GPT]]
  - **인코더-디코더 (BART, T5)**: 이해 + 생성 모두 — BART는 NLU에서 RoBERTa와 비슷, 요약에 강함 / T5는 모든 NLU 태스크를 NLG로 변환 → [[BART]], [[T5]]
- **표로 정리**

| 구조 | 대표 모델 | Attention | 강점 |
|---|---|---|---|
| Encoder-only | BERT, RoBERTa, DistilBERT | 양방향 | NLU (분류·NER·MRC) |
| Decoder-only | GPT 계열, 현재 LLM | 단방향(causal) | NLG (생성·대화) |
| Encoder-Decoder | 원 Transformer, BART, T5 | 인코더 양방향 + 디코더 단방향 | 번역·요약 (입력 → 다른 출력) |

- **현재 추세**: 모델이 충분히 커지면 **Decoder-only LLM이 NLU까지** 프롬프트로 처리 → 범용 모델로 수렴 → [[LLM·ChatGPT]]
- 그래도 실무에서 분류·NER은 작은 인코더 모델이 **빠르고 저렴**하며 정확 (강의 "NLP 엔지니어로서의 방향성")

## 수식·원리
```
NLU:  ŷ = f(Encoder(x))                      → 레이블·위치·점수
NLG:  y_t ~ p(y_t | y_<t, x)                  → 토큰 시퀀스
Encoder mask: 없음 (모든 위치)   Decoder mask: j ≤ i 만
```

## 코드 예시
```python
import torch

n = 5
enc_mask = torch.ones(n, n)                                # 인코더(BERT): 모든 위치 참조 → 이해
dec_mask = torch.tril(torch.ones(n, n))                    # 디코더(GPT): 과거만 참조 → 생성
print(int(enc_mask[1].sum()), int(dec_mask[1].sum()))      # 5 2  두 번째 토큰이 볼 수 있는 위치 수

sentence = ["I", "[MASK]", "you", "so", "much"]
print("BERT는 오른쪽 문맥", sentence[2:], "도 활용")          # NLU: 빈칸 양쪽을 다 봄
print("GPT는", sentence[:1], "만 보고 다음 단어 생성")        # NLG: 왼쪽만 보고 다음 단어

tasks = {"감성 분석": "NLU", "NER": "NLU", "번역": "NLG", "요약": "NLG", "챗봇": "NLG", "MRC": "NLU"}
print(sorted(k for k, v in tasks.items() if v == "NLG"))  # ['번역', '요약', '챗봇']
```
