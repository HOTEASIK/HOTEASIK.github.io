# Text CNN

## 정의·핵심
- **정의 (응용 8차시 "CNN for Text Classification")**: Yoon Kim (2014). **합성곱 층을 단 하나만** 사용한 매우 단순한 구조임에도 준수한 성능을 보인 텍스트 분류 모델
- **입력 (강의)**: 문장의 각 단어를 임베딩한 **문장 테이블 n × k 행렬** — n = 문장 길이, k = 임베딩 차원
  - 예: "wait for the video and don't rent it" → 토큰화 / 패딩 / 임베딩 → 9 × k
  - **패딩**: n보다 짧은 문장은 제로 패딩, 긴 문장은 잘라냄
- **1D 합성곱**: 커널 크기 **(h × k)** — 폭이 임베딩 차원 전체라 **세로(단어 방향)로만** 슬라이딩
  - h = 한 번에 보는 단어 수 → **n-gram 특징** 검출 (h = 2, 3, 4, 5 여러 크기를 동시에)
  - 커널 크기별로 여러 개 필터 → 각각 길이 `n − h + 1` 특징 맵
- **Max-over-time Pooling**: 각 특징 맵에서 **최댓값 하나** → 문장 길이와 무관하게 고정 크기, "그 n-gram이 문장 어딘가에 있는가"
  - 이미지의 Max-pooling(강의 복습): 커널 영역 최댓값으로 다운샘플링, **가장 중요한 특징** 추출
- 모든 필터의 최댓값을 **concat** → Dropout → FC → softmax
- **Character-level CNN** (Zhang et al., 2015): 단어가 아니라 **문자**를 원-핫/임베딩해 입력 → 어휘집·형태소 분석 없이 오탈자·신조어에 강함, 대신 깊은 CNN과 많은 데이터 필요
- **RNN과 비교**: **병렬 계산**으로 빠름, 지역 패턴(n-gram, "not good")에 강함 / 긴 거리 의존성은 약함

## 수식·원리
```
X ∈ ℝ^{n×k},  커널 W ∈ ℝ^{h×k}
c_i = f(W · X[i:i+h] + b),   i = 1..n−h+1
ĉ = max_i c_i                  (max-over-time)
z = [ĉ_1 ; ... ; ĉ_m]  →  softmax(W_o z)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class TextCNN(nn.Module):
    def __init__(self, vocab, k=50, sizes=(2, 3, 4), n_filters=10, n_cls=2):
        super().__init__()
        self.emb = nn.Embedding(vocab, k, padding_idx=0)
        self.convs = nn.ModuleList([nn.Conv1d(k, n_filters, h) for h in sizes])   # (h × k) 커널
        self.fc = nn.Linear(n_filters * len(sizes), n_cls)
    def forward(self, x):
        e = self.emb(x).transpose(1, 2)                         # (B, k, n)  Conv1d는 채널 = 임베딩 차원
        feats = [torch.relu(c(e)) for c in self.convs]          # (B, F, n−h+1)
        self.shapes = [tuple(f.shape) for f in feats]
        pooled = [f.max(dim=2).values for f in feats]           # max-over-time
        return self.fc(torch.cat(pooled, 1))

torch.manual_seed(0)
m = TextCNN(vocab=100)
x = torch.randint(1, 100, (4, 9))                               # 문장 길이 9 ("wait for the video ...")
print(tuple(m(x).shape), m.shapes)                              # (4, 2) [(4, 10, 8), (4, 10, 7), (4, 10, 6)]
print(tuple(m(torch.randint(1, 100, (4, 30))).shape))           # (4, 2)  길이가 달라도 같은 출력 크기

chars = sorted(set("wait for the video"))                       # character-level 입력
print(len(chars), [chars.index(c) for c in "video"])            # 12 [10, 6, 2, 3, 7]
```
