# Word2Vec

## 정의·핵심
- **정의**: Mikolov et al. (2013). "**비슷한 문맥에 나오는 단어는 비슷한 의미를 가진다**"(분포 가설)에 따라, 주변 단어와 중심 단어의 관계를 예측하는 얕은 신경망으로 **단어 임베딩을 학습**하는 방법 (응용 8차시 Word Embedding, 개론 17차시 보강 실습)
- **두 가지 구조**
  - **CBOW(Continuous Bag of Words)**: **주변 단어들 → 중심 단어** 예측. 강의 보강 코드: 문맥 단어 임베딩의 **평균** → Linear(embed → vocab) → log_softmax
  - **Skip-gram**: **중심 단어 → 주변 단어들** 예측. 희귀 단어에 강하고 일반적으로 성능이 좋음
  - 윈도우 크기(예: 앞뒤 2개)로 문맥 범위 결정
- **구조의 핵심**: 은닉층이 **활성화 함수 없는 선형 투사층**(= 임베딩 룩업) 하나 → 학습 후 **투사층 가중치 행렬 W(V×D)의 각 행이 단어 벡터** (NNLM의 Projection layer와 같은 아이디어) → [[NNLM]]
- **효율화**: 출력층 softmax가 V(수십만)개 → 비쌈 → **Negative Sampling**(정답 1 + 무작위 오답 k개로 이진 분류), Hierarchical Softmax
- **성질 — 벡터 산술**: `vec(king) − vec(man) + vec(woman) ≈ vec(queen)`, 의미·문법 관계가 방향으로 표현됨
- **도구**: gensim `Word2Vec(sentences, vector_size, window, min_count, sg=1)` (강의: gensim 사전학습 모델 불러오기 / 직접 학습)
- **한계**: 단어당 벡터 **하나** → 동음이의어 구분 불가(정적 임베딩), OOV 단어 처리 불가(→ **FastText**: 문자 n-gram 합으로 해결), 문맥 반영 X → [[ELMo]]
- **관련**: **GloVe**(전역 동시등장 행렬 분해), **FastText**(서브워드)

## 수식·원리
```
CBOW:      p(w_t | w_{t−c..t+c}) = softmax(W_out · mean(E[w_{t±j}]))
Skip-gram: max Σ_t Σ_{−c≤j≤c, j≠0} log p(w_{t+j} | w_t)
p(o | c) = exp(u_o·v_c) / Σ_w exp(u_w·v_c)
Negative Sampling: log σ(u_o·v_c) + Σ_{k} log σ(−u_k·v_c)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class CBOW(nn.Module):                                   # 강의 보강 코드 구조
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.linear = nn.Linear(embed_dim, vocab_size)
    def forward(self, context_idxs):                     # (B, 2c)
        context_vec = self.embedding(context_idxs).mean(1)
        return torch.log_softmax(self.linear(context_vec), -1)

corpus = ("i like playing football . i like playing soccer . i enjoy watching football . "
          "i enjoy watching soccer . cats drink milk . dogs drink milk .").split()
vocab = sorted(set(corpus)); idx = {w: i for i, w in enumerate(vocab)}
data = [([idx[corpus[i - 2]], idx[corpus[i - 1]], idx[corpus[i + 1]], idx[corpus[i + 2]]], idx[corpus[i]])
        for i in range(2, len(corpus) - 2)]
X = torch.tensor([c for c, _ in data]); y = torch.tensor([t for _, t in data])

torch.manual_seed(0)
model = CBOW(len(vocab), 16)
opt = torch.optim.Adam(model.parameters(), lr=0.05)
for epoch in range(300):
    loss = nn.functional.nll_loss(model(X), y)
    opt.zero_grad(); loss.backward(); opt.step()
print(round(loss.item(), 2) < 0.5)                       # True

E = model.embedding.weight.detach()
def sim(a, b): return torch.cosine_similarity(E[idx[a]], E[idx[b]], 0).item()
print(sim("football", "soccer") > sim("football", "milk"))   # True  같은 문맥에 나온 단어끼리 가까움
```
