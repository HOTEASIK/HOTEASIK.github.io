# ViT

## 정의·핵심
- **정의 (응용 14차시 "Vision Transformer: 이미지를 시퀀스로")**: Dosovitskiy et al. (Google, 2020). 이미지를 **16×16 패치**로 잘라 **단어(Token)처럼** 처리하고, **CNN 없이 순수 Transformer Encoder(Attention)만으로** 이미지를 분류하는 모델
  - 논문 제목: "**An Image is Worth 16x16 Words**" (이미지는 16×16 크기의 단어들과 같다)
- **핵심 아이디어 (강의)**
  - **이미지 = 패치 시퀀스**: 16×16 패치로 잘라 토큰처럼
  - **Inductive Bias 제거**: CNN의 Locality(지역성)와 Translation Equivariance 가정 없이 데이터 간의 관계를 스스로 학습 → [[Inductive Bias]]
  - **데이터 규모의 승리**: 소규모 데이터에서는 CNN보다 낮지만, 대규모(ImageNet-21K, **JFT-300M**)로 사전학습하면 CNN을 능가
- **입력 처리 5단계 (강의)** → [[Patch Embedding·CLS 토큰]]
  1. 224×224×3 이미지를 16×16 패치로 분할 → **14×14 = 196개**
  2. 각 패치를 Flatten → 16×16×3 = **768** → `[196, 768]`
  3. **Linear Projection** (768 → 768)
  4. **Position Embedding** 더하기 (`+ Pos[196, 768]`)
  5. 맨 앞에 학습 가능한 **[CLS] Token** 추가 → 총 **197 tokens**
- **아키텍처 (강의)**: Embedded Patches → **Transformer Encoder × 12 Layers** → [CLS] 토큰 추출 → **MLP Head** → Softmax/Classification
  - **ViT-Base**: Patch 16×16, Hidden **768**, Layers **12**, Heads **12**, MLP **3072**, Params **86M** — BERT-Base와 거의 동일한 하이퍼파라미터로 "NLP의 성공 방정식을 Vision에 그대로 적용"

| Model | Patch | Layers | Hidden | Heads | Params |
|---|---|---|---|---|---|
| ViT-Base | 16×16 | 12 | 768 | 12 | 86M |
| ViT-Large | 16×16 | 24 | 1024 | 16 | 307M |
| ViT-Huge | 14×14 | 32 | 1280 | 16 | 632M |

- **응용 확장 (강의 학습 정리)**: DETR(객체 검출), **Swin**(계층적 구조, 윈도우 attention), **CLIP**(이미지+텍스트), Flamingo(Vision-Language)
- 실습: Beans 콩잎 질병 3클래스 분류, `google/vit-base-patch16-224` 파인튜닝 (강의 목표 97% 정확도) → [[ViT 파인튜닝 실습]]

## 수식·원리
```
x ∈ ℝ^{H×W×C} → x_p ∈ ℝ^{N×(P²·C)},  N = HW / P² = 224²/16² = 196
z_0 = [x_cls ; x_p¹E ; ... ; x_pᴺE] + E_pos,   E ∈ ℝ^{(P²C)×D},  E_pos ∈ ℝ^{(N+1)×D}
z_l = TransformerEncoderBlock(z_{l−1}),  l = 1..12
y = MLPHead(LN(z_12⁰))      ([CLS] 위치 출력)
```

## 코드 예시
```python
import torch
from torchvision.models import vit_b_16

torch.manual_seed(0)
model = vit_b_16(weights=None).eval()                      # ViT-Base/16 구조 (실사용: weights="DEFAULT")
print(round(sum(p.numel() for p in model.parameters()) / 1e6, 1))   # 86.6  약 86M
print(model.patch_size, model.hidden_dim, len(model.encoder.layers), model.encoder.layers[0].self_attention.num_heads)   # 16 768 12 12

x = torch.rand(1, 3, 224, 224)
with torch.no_grad():
    tokens = model._process_input(x)                       # 패치 분할 + Linear Projection
    print(tuple(tokens.shape))                             # (1, 196, 768)
    cls = model.class_token.expand(1, -1, -1)
    seq = torch.cat([cls, tokens], 1)
    print(tuple(seq.shape), tuple(model.encoder.pos_embedding.shape))   # (1, 197, 768) (1, 197, 768)
    print(tuple(model(x).shape))                           # (1, 1000)
```
