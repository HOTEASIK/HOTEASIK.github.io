# ELMo

## 정의·핵심
- **정의**: Embeddings from Language Models (Peters et al., 2018). **사전학습된 양방향 LSTM 언어 모델**의 은닉 상태들을 조합해, **문맥에 따라 달라지는 단어 표현(Contextual Representation)** 을 만드는 방법 (응용 14차시 GPT 슬라이드 "History of Contextual Representations")
- **배경 (강의)**
  - 사전 훈련된 임베딩(Word2Vec, GloVe)은 대용량 텍스트의 **동시 등장 통계**로 단어당 벡터 **하나**를 학습
  - **문제점**: 단어는 문맥에 따라 뜻이 달라짐 — 동음이의어 "배"(먹는 배 / 타는 배 / 신체), "사과"(과일 / 사죄)
  - **해결**: **언어 모델을 사전 훈련**시켜 문맥에 따른 표현을 얻음 → ELMo → GPT → BERT로 이어지는 흐름
- **구조**
  - **순방향 LM**: 왼쪽 → 오른쪽으로 다음 단어 예측 (LSTM 2층)
  - **역방향 LM**: 오른쪽 → 왼쪽으로 이전 단어 예측 (별도 LSTM 2층)
  - 입력: **문자 CNN** 기반 토큰 표현 → OOV 문제 완화
  - 각 층의 순방향·역방향 은닉 상태를 **concat**, 층별 가중합 `ELMo_k = γ Σ_j s_j h_{k,j}` (s_j는 과제별 학습 가중치)
- **사용법 (Feature-based)**: 사전학습 ELMo는 고정하고, 출력 벡터를 기존 과제 모델(BiLSTM 분류기 등)의 **입력 임베딩에 붙여** 사용 → 파인튜닝 방식인 GPT·BERT와 대비 → [[PLM·Pre-training·Fine-tuning]]
- **BERT와 차이**: ELMo는 두 단방향 LM을 **따로 학습해 이어 붙인 얕은 양방향**, BERT는 MLM으로 모든 층에서 **깊은 양방향** → [[BERT]]

## 수식·원리
```
순방향:  p(t_1..t_N) = Π_k p(t_k | t_1..t_{k−1})
역방향:  p(t_1..t_N) = Π_k p(t_k | t_{k+1}..t_N)
학습:   max Σ_k [ log p(t_k | 앞) + log p(t_k | 뒤) ]
ELMo_k = γ · Σ_{j=0..L} s_j · [→h_{k,j} ; ←h_{k,j}]
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
V, E, H = 20, 8, 16
emb = nn.Embedding(V, E)
fwd = nn.LSTM(E, H, batch_first=True)                       # 순방향 LM
bwd = nn.LSTM(E, H, batch_first=True)                       # 역방향 LM (뒤집어 입력)

def elmo(ids):
    x = emb(ids)
    hf, _ = fwd(x)
    hb, _ = bwd(torch.flip(x, [1])); hb = torch.flip(hb, [1])
    return torch.cat([hf, hb], -1)                          # 위치별 [→h ; ←h]

BAE = 5                                                     # 토큰 "배"
s1 = torch.tensor([[1, 2, BAE, 3]])                         # "맛있는 ... 배 를 먹다"
s2 = torch.tensor([[7, 8, BAE, 9]])                         # "바다 ... 배 를 타다"
print(torch.equal(emb(s1)[0, 2], emb(s2)[0, 2]))            # True   정적 임베딩: 같은 벡터
print(torch.allclose(elmo(s1)[0, 2], elmo(s2)[0, 2]))       # False  문맥 임베딩: 문맥 따라 다름
print(tuple(elmo(s1).shape))                                # (1, 4, 32)
```
