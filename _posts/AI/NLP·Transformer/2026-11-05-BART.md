# BART

## 정의·핵심
- **정의 (응용 14차시 GPT 슬라이드)**: Bidirectional and Auto-Regressive Transformer (Facebook AI, Lewis et al., 2019). 트랜스포머 **인코더-디코더를 모두 사용**해 사전학습 — 입력 문장에 **노이즈를 추가**하고, 인코더 정보를 받아 디코더가 **원래 문장을 복원** (Denoising Autoencoder)
- **등장 배경 (강의)**
  - 트랜스포머 **인코더** → MLM으로 가운데 단어 예측 → **BERT** → **NLU에 강함**
  - 트랜스포머 **디코더** → 이전 단어로 다음 단어 예측 → **GPT** → **NLG에 강함**
  - 원래 트랜스포머는 인코더-디코더 구조였음 → "그렇다면 **인코더-디코더 구조 자체를 다시 활용**해 보자"
  - = BERT(양방향 인코더) + GPT(자기회귀 디코더)
- **Pre-training (강의)**
  - 인코더-디코더 구조는 **입·출력 길이가 달라도 되므로 유연한 Masking** 가능 — 예: 여러 토큰을 [MASK] 하나로 바꾸기(0개·2개 분량 span)
  - 다양한 노이즈: **Token Masking**, **Token Deletion**(어디가 지워졌는지도 맞춰야), **Text Infilling**(span을 마스크 1개로 — 가장 효과적), **Sentence Permutation**(문장 순서 섞기), **Document Rotation**(시작점 회전)
- **성능 (강의)**
  - 다양한 Pre-training으로 **NLU 성능도 향상** — BERT는 당연히 이기고 **RoBERTa와 유사**
  - BERT와 달리 **디코더가 있어 NLG도 가능**
- **텍스트 요약 (강의)**: 번역용 트랜스포머와 다를 바 없는 인코더-디코더 — **인코더 입력(본문), 디코더 입력, 디코더 레이블(요약문)** 로 학습 후 요약. 요약(CNN/DailyMail, XSum) 대표 모델, 한국어 **KoBART**

## 수식·원리
```
x̃ = noise(x)                        (masking, deletion, infilling, permutation, rotation)
h = Encoder(x̃)                      (양방향)
L = −Σ_t log p(x_t | x_<t, h)       (디코더가 원문 x를 자기회귀로 복원)
```

## 코드 예시
```python
import random

random.seed(0)
x = "the cat sat on the mat today".split()

def token_mask(t):    return [w if random.random() > 0.3 else "[MASK]" for w in t]
def token_delete(t):  return [w for w in t if random.random() > 0.3]
def text_infill(t, i=2, n=3): return t[:i] + ["[MASK]"] + t[i + n:]          # span 3개 → 마스크 1개
def sent_permute(s):  s = s[:]; random.shuffle(s); return s

print(token_mask(x))
print(token_delete(x))
print(text_infill(x), len(text_infill(x)), len(x))   # 입력 5 토큰 → 출력 7 토큰: 길이가 달라도 됨 (인코더-디코더)
print(sent_permute(["I came.", "I saw.", "I won."]))

src = " ".join(text_infill(x))                       # 학습 쌍: (노이즈 입력, 원문)
dec_in, label = ["<s>"] + x, x + ["</s>"]            # 디코더 입력은 한 칸 밀린 원문
print(src, "→", " ".join(label))
```
