# RoBERTa

## 정의·핵심
- **정의**: Robustly optimized BERT approach (Facebook AI, Liu et al., 2019). **구조는 BERT와 같고 학습 방법만 개선**해 성능을 끌어올린 모델 — 강의: "RoBERTa(BERT의 개선 버전)" — BART가 NLU에서 RoBERTa와 비슷한 성능 (응용 14차시 GPT 슬라이드)
- **BERT 대비 변경점**
  1. **NSP 제거**: 다음 문장 예측이 오히려 도움이 안 됨 → MLM만 사용, 긴 연속 문장(최대 512 토큰)으로 학습
  2. **동적 마스킹(Dynamic Masking)**: BERT는 전처리 때 마스크 위치를 **한 번 고정** → RoBERTa는 **매 epoch마다 새로** 마스킹 → 같은 문장에서 다양한 빈칸 학습
  3. **더 많은 데이터**: 16GB → **160GB** 텍스트
  4. **더 오래, 더 큰 배치**: 배치 8K, 학습 스텝 증가
  5. **Byte-level BPE** 토크나이저 (어휘 50K) — GPT-2와 같은 방식, `<unk>` 거의 없음
- **의의**: "BERT는 덜 학습되었다(undertrained)" — 모델 구조를 바꾸지 않아도 **학습 레시피**만으로 큰 향상 → 하이퍼파라미터·데이터 규모의 중요성
- **강의 "NLP 엔지니어로서의 방향성"**: 대부분의 기업에서 LLM을 자체 운용하기 어려움 → **BERT, RoBERTa, GPT-2, BART, T5를 다룰 수 있는 것이 여전히 경쟁력**. 텍스트 분류·NER·MRC는 BERT·RoBERTa·T5가 여전히 강력
- 한국어: **KLUE-RoBERTa**, XLM-RoBERTa(다국어)

## 수식·원리
```
BERT:     마스크 m 고정 → 모든 epoch에서 같은 위치 예측
RoBERTa:  epoch e마다 m_e ~ Bernoulli(0.15) 새로 샘플
L = −Σ_{i∈m_e} log p(x_i | x_{\m_e})      (NSP 항 없음)
```

## 코드 예시
```python
import torch

torch.manual_seed(0)
sentence = torch.arange(10, 30)                      # 토큰 20개
MASK = 1

static_mask = torch.rand(20) < 0.15                  # BERT: 전처리 때 한 번
seen_static, seen_dynamic = set(), set()
for epoch in range(10):
    seen_static |= set(static_mask.nonzero().flatten().tolist())
    dyn = torch.rand(20) < 0.15                      # RoBERTa: 매 epoch 새로
    seen_dynamic |= set(dyn.nonzero().flatten().tolist())
print(len(seen_static), len(seen_dynamic))           # 3 17  동적 마스킹은 훨씬 많은 위치를 예측 대상으로 학습

def mask_tokens(x, m): y = x.clone(); y[m] = MASK; return y
print(mask_tokens(sentence, dyn)[:8].tolist())       # [10, 11, 1, 13, 14, 15, 16, 17]  epoch마다 다른 빈칸
```
