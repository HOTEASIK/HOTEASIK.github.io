# LoRA

## 정의·핵심
- **정의 (응용 14차시 "LLM의 튜닝 방법 (LoRA 학습)")**: Low-Rank Adaptation (Microsoft, Hu et al., 2021). **사전훈련된 가중치는 그대로 두고**, 각 층에 **별도로 추가한 작은 행렬만** 새 데이터로 학습하는 효율적 파인튜닝(PEFT) 방법
- **필요성 (강의)**
  - 일반적으로 LLM = **10B(100억) 이상** 파라미터 모델 → 이를 fine-tuning하기란 쉽지 않음
  - GPT-3 같은 거대 모델을 fine-tuning하면 **엄청난 parameter를 다 재학습**해야 함 (메모리·저장 공간·시간)
- **방식 (강의)**
  - Transformer의 **각 layer마다 학습 가능한 행렬을 별도로 추가** (기존 파라미터는 **고정**)
  - 레이어 중간중간 hidden states h에 **값을 더해 줄 수 있는 파라미터**를 추가
  - **PLM의 파라미터는 건드리지 않으므로 여러 버전의 LoRA를 만드는 것이 가능** (태스크별 작은 어댑터 파일만 교체)
  - 강의 예: KoAlpaca(Beomi) — LLaMA 계열을 한국어 지시 데이터로 LoRA 학습
- **Low-Rank 분해**: 가중치 변화량 ΔW(d×k)를 **B(d×r) · A(r×k)** 로 표현, **r ≪ d** (보통 4~64)
  - 학습 파라미터: d·k → **r·(d + k)** (예: 4096×4096, r=8 → 1,677만 → 6.5만, 약 **0.4%**)
  - 초기화: A는 랜덤, **B = 0** → 학습 시작 시 원래 모델과 정확히 같음
  - 스케일 `α/r` 곱함
  - 주로 attention의 **W_Q, W_V** 에 적용
- **장점**: 메모리·저장 절감, **추론 지연 없음**(학습 후 `W + BA`로 합칠 수 있음), 태스크별 어댑터 교체 / **QLoRA**: 기반 모델을 4bit 양자화 + LoRA → 단일 GPU로 수십 B 모델 튜닝

## 수식·원리
```
h = W₀ x + ΔW x = W₀ x + (α/r) · B A x
W₀ ∈ ℝ^{d×k} (고정),  B ∈ ℝ^{d×r},  A ∈ ℝ^{r×k},  r ≪ min(d, k)
학습 파라미터 비율 = r(d + k) / (d·k)
병합: W' = W₀ + (α/r) B A
```

## 코드 예시
```python
import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    def __init__(self, base: nn.Linear, r=8, alpha=16):
        super().__init__()
        self.base = base
        for p in self.base.parameters(): p.requires_grad_(False)       # 사전학습 가중치 고정
        self.A = nn.Parameter(torch.randn(r, base.in_features) * 0.01)
        self.B = nn.Parameter(torch.zeros(base.out_features, r))        # B=0 → 시작 시 원래 모델과 동일
        self.scale = alpha / r
    def forward(self, x):
        return self.base(x) + self.scale * (x @ self.A.T @ self.B.T)

torch.manual_seed(0)
base = nn.Linear(4096, 4096)
lora = LoRALinear(base)
x = torch.randn(2, 4096)
print(torch.allclose(lora(x), base(x)))                                # True  초기엔 출력이 같음
trainable = sum(p.numel() for p in lora.parameters() if p.requires_grad)
print(trainable, base.weight.numel(), round(100 * trainable / base.weight.numel(), 2))   # 65536 16777216 0.39 (%)

opt = torch.optim.Adam([lora.A, lora.B], lr=1e-2)
target = torch.randn(2, 4096)
for _ in range(20):
    loss = ((lora(x) - target) ** 2).mean(); opt.zero_grad(); loss.backward(); opt.step()
merged = base.weight + lora.scale * lora.B @ lora.A                     # 학습 후 병합 → 추론 지연 없음
print(torch.allclose(x @ merged.T + base.bias, lora(x), atol=1e-4), base.weight.grad is None)   # True True
```
