# ViT 파인튜닝 실습

## 정의·핵심
- **목표 (응용 14차시)**: ImageNet 사전학습 ViT(`google/vit-base-patch16-224`)를 **Beans 데이터셋**(콩잎 질병, 3클래스)으로 파인튜닝 — 강의 목표 정확도 약 **97%**
- **데이터**: `load_dataset("AI-Lab-Makerere/beans")` — train / validation / test, 레이블 `angular_leaf_spot`, `bean_rust`, `healthy` (레이블 키가 `labels` 또는 `label`인지 확인 후 사용)
- **절차 (강의 노트북)**
  1. **Processor 로드**: `AutoImageProcessor.from_pretrained(MODEL)` — resize·정규화·텐서 변환 담당 (과제 문제 3은 `vit-base-patch16-224-in21k`)
  2. **모델 로드 (과제 문제 5)**: `ViTForImageClassification.from_pretrained(MODEL, num_labels=3, id2label=..., label2id=..., ignore_mismatched_sizes=True)`
     - 원래 1000클래스 헤드를 **3클래스 새 헤드로 교체** → `ignore_mismatched_sizes=True` 필요
     - id2label/label2id를 주면 예측 결과를 이름으로 확인 가능 (`model.classifier.out_features` = 3)
  3. **전처리 (과제 문제 4)**: `transform(ex)` → `processor(images=ex["image"], return_tensors="pt")["pixel_values"]` (b, c, h, w) → `beans.map(transform, batched=True, remove_columns=["image"])` (원본 이미지 컬럼 제거로 메모리 절약) → `set_format("torch")`
  4. **필요 컬럼만 유지**: `pixel_values` + 레이블
  5. **학습 (과제 문제 6)**: `TrainingArguments(output_dir, eval_strategy="epoch", save_strategy="epoch", per_device_train_batch_size=16, per_device_eval_batch_size=32, num_train_epochs=3, learning_rate=2e-5, fp16=GPU, report_to="none", remove_unused_columns=False)` + `Trainer(model, args, train_dataset, eval_dataset, data_collator=DefaultDataCollator(), compute_metrics)`
     - `remove_unused_columns=False`: 이미지 데이터셋 컬럼(pixel_values)이 지워지지 않게
  6. **평가**: `compute_metrics`에서 `argmax` → accuracy, test 셋으로 최종 확인
- **실습 포인트**
  - 작은 학습률(2e-5)과 짧은 epoch — 사전학습 지식을 크게 망가뜨리지 않게 → [[PLM·Pre-training·Fine-tuning]]
  - 데이터가 작으면 **헤드만 학습**(백본 동결)도 비교해 볼 것
  - ViT는 데이터 요구량이 크지만 **사전학습 모델을 쓰면** 작은 데이터에서도 높은 성능 → [[Inductive Bias]]

```
# Hugging Face 실습 코드 요약 (transformers·datasets·evaluate 필요)
from transformers import AutoImageProcessor, ViTForImageClassification, TrainingArguments, Trainer, DefaultDataCollator
processor = AutoImageProcessor.from_pretrained("google/vit-base-patch16-224")
model = ViTForImageClassification.from_pretrained("google/vit-base-patch16-224", num_labels=3,
            id2label=id2label, label2id=label2id, ignore_mismatched_sizes=True)
args = TrainingArguments(output_dir="./results", eval_strategy="epoch", num_train_epochs=3,
            learning_rate=2e-5, remove_unused_columns=False)
```

## 수식·원리
```
θ_backbone ← 사전학습 ViT,  W_head ∈ ℝ^{768×3} 새로 초기화

```

## 코드 예시
```python
import torch
import torch.nn as nn
from torchvision.models import vit_b_16

torch.manual_seed(0)
names = ["angular_leaf_spot", "bean_rust", "healthy"]
id2label = {i: n for i, n in enumerate(names)}; label2id = {n: i for i, n in id2label.items()}

model = vit_b_16(weights=None)                                # 실사용: weights="DEFAULT" (사전학습)
print(model.heads.head.out_features)                          # 1000  ImageNet 헤드
model.heads.head = nn.Linear(model.hidden_dim, len(names))    # 3클래스 헤드로 교체 (ignore_mismatched_sizes와 같은 역할)
print(model.heads.head.out_features)                          # 3

for n, p in model.named_parameters():                         # 비교 실험: 백본 동결, 헤드만 학습
    p.requires_grad = n.startswith("heads")
print(sum(p.numel() for p in model.parameters() if p.requires_grad))   # 2307  = 768×3 + 3

x, y = torch.rand(4, 3, 224, 224), torch.tensor([0, 1, 2, 2])
opt = torch.optim.AdamW([p for p in model.parameters() if p.requires_grad], lr=2e-5)
logits = model(x); loss = nn.functional.cross_entropy(logits, y)
opt.zero_grad(); loss.backward(); opt.step()
pred = logits.argmax(-1)
print([id2label[i] for i in pred.tolist()][:1], round((pred == y).float().mean().item(), 2) >= 0)   # 예측 이름, accuracy 계산
```
