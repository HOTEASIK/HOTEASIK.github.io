# 원-핫 인코딩(텍스트)

## 정의·핵심
- **정의**: 어휘집 크기 V의 벡터에서 **해당 단어 인덱스만 1, 나머지는 0**으로 단어를 표현하는 방법 (응용 8차시 NNLM 슬라이드)
  - 예문 "what will the fat cat sit on" (V = 7): `what = [1,0,0,0,0,0,0]`, `will = [0,1,0,0,0,0,0]`, …, `on = [0,0,0,0,0,0,1]`
- **문서 벡터화로 확장 — BoW / DTM (강의 Text Classification using MLP)**
  - **Bag of Words**: 문서 안 단어들의 원-핫을 **합산** → 단어 등장 횟수 벡터 (순서 무시)
  - **DTM(Document-Term Matrix)**: 문서 × 어휘 행렬. 예) 문서1 "me free lottery", 문서2 "free get free you" … → 각 행이 고정 길이(Vocabulary size) 문서 벡터 → MLP 입력층 뉴런 수 = vocab_size
  - **TF-IDF**: 많은 문서에 흔히 나오는 단어의 가중치를 낮춤 — `tf(t,d)·log(N/(df(t)+1))` (개론 17차시 NLP SPECIAL)
- **한계**
  - **차원 = 어휘 크기**(수만~수십만) → 메모리 낭비, **희소(Sparse)**
  - 모든 단어 쌍의 내적이 0 → **단어 간 유사도를 표현 못 함** ("cat"과 "dog"도 "cat"과 "car"도 똑같이 멂)
  - → **밀집 벡터(Dense) 임베딩**으로 해결 → [[임베딩]], [[Word2Vec]]
- **원-핫 × 가중치 행렬 = Lookup (강의)**: i번째가 1인 원-핫 벡터와 W(V×M)를 곱하면 **W의 i번째 행을 그대로 읽어오는 것**과 같음 → 실제로는 곱셈 없이 인덱싱(`nn.Embedding`)으로 구현

## 수식·원리
```
onehot(w_i) = e_i ∈ {0,1}^V
e_i · e_j = 0  (i ≠ j)          → 유사도 정보 없음
BoW(d) = Σ_{w∈d} onehot(w)
e_i^T W = W[i, :]                → lookup table
TF-IDF(t, d) = tf(t, d) · log(N / (df(t) + 1))
```

## 코드 예시
```python
import numpy as np
import torch

words = "what will the fat cat sit on".split()
idx = {w: i for i, w in enumerate(words)}
onehot = np.eye(len(words), dtype=int)
print(onehot[idx["fat"]].tolist())                        # [0, 0, 0, 1, 0, 0, 0]
print(onehot[idx["cat"]] @ onehot[idx["fat"]])            # 0  어떤 두 단어든 내적 0

W = torch.randn(7, 5)                                     # V × M 투사 행렬
print(torch.allclose(torch.tensor(onehot[idx["fat"]], dtype=torch.float) @ W, W[idx["fat"]]))   # True  lookup과 동일

docs = ["me free lottery", "free get free you", "you free scholarship", "free to contact me"]
vocab = sorted({w for d in docs for w in d.split()})
dtm = np.array([[d.split().count(w) for w in vocab] for d in docs])
print(vocab)                                              # ['contact', 'free', 'get', 'lottery', 'me', 'scholarship', 'to', 'you']
print(dtm[1].tolist())                                    # [0, 2, 1, 0, 0, 0, 0, 1]  문서2 BoW
df = (dtm > 0).sum(0)
tfidf = dtm * np.log(len(docs) / (df + 1))
print(round(tfidf[1, vocab.index("free")], 3), round(tfidf[1, vocab.index("get")], 3))   # -0.446 0.693  흔한 free는 가중치 낮음
```
