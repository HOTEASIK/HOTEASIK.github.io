# 텍스트 분류 실습

## 정의·핵심
- **텍스트 분류 (응용 8차시)**: 주어진 텍스트가 **이미 정의된 카테고리 중 어디로** 분류되는지 예측 — NLP에서 **가장 수요가 높고 기본적인** 태스크
  - 예: 뉴스 카테고리(IT·정치·문화), **스팸** 메일·문자, 종목 뉴스 게시판 분류, 리뷰 **감성(긍정/부정)**, 챗봇 질의 의도(환불·주문·건의)
- **과정 (강의)**: 문서 → **Vectorization** → **Model** → **Predicted Output**
  - 벡터화: ① DTM, TF-IDF ② Word Embedding ③ Document Embedding → [[원-핫 인코딩(텍스트)]], [[임베딩]]
  - 모델: ① MLP ② RNN, CNN ③ BERT → [[LSTM]], [[Text CNN]], [[BERT]]
  - 출력: **이진 분류**(클래스 2개) — 스칼라(sigmoid) 또는 2차원(softmax) / **다중 클래스**(3개 이상) — N차원(softmax)
- **대표 데이터셋**
  - **NSMC** (네이버 영화 리뷰): 한국어 감성, 학습 15만 / 테스트 5만, label 0·1 (개론 17차시 보강: Korpora 또는 GitHub 원본으로 로드, 문장 길이 분포 확인)
  - **SST-2** (Stanford Sentiment Treebank, GLUE): 영어 문장 감성 이진 분류 (응용 14차시 DistilBERT 실습)
  - **IMDb**: 영어 영화 리뷰 2.5만/2.5만 (개론 17차시 BiLSTM·DistilBERT 실습)
- **개론 17차시 실습 흐름 — 모델 비교**
  1. 텍스트 전처리: 토큰화 → 어휘집 → 패딩 → [[토큰화(Tokenizer)]], [[어휘집(Vocabulary)·패딩]]
  2. **LSTM/BiLSTM** 감성 분류 직접 구현 → [[BiLSTM]]
  3. **DistilBERT 파인튜닝** (사전학습 Transformer) → [[DistilBERT]]
  4. 비교: 사전학습 모델이 적은 epoch로 훨씬 높은 정확도, 대신 모델이 크고 느림
- **평가**: accuracy, precision, recall, **F1** (불균형이면 F1 중심) → [[F1 Score]]
- **실전 팁**: 학습 데이터로만 어휘집 구축, 문장 길이 분포로 max_len 결정, 검증 셋으로 조기 종료, 오분류 사례를 직접 읽어 보기

## 수식·원리
```
이진:   p = σ(w·h + b),     L = BCE(p, y)
다중:   p = softmax(W h + b), L = −log p_y
F1 = 2PR / (P + R)
```

## 코드 예시
```python
import torch
import torch.nn as nn
from collections import Counter

train = [("this movie is great", 1), ("what a great film", 1), ("i love this movie", 1),
         ("this movie is boring", 0), ("worst film ever", 0), ("i hate this film", 0)]
cnt = Counter(w for s, _ in train for w in s.split())
vocab = {"<pad>": 0, "<unk>": 1, **{w: i + 2 for i, w in enumerate(cnt)}}
def enc(s, L=5):
    ids = [vocab.get(w, 1) for w in s.split()][:L]
    return ids + [0] * (L - len(ids))
X = torch.tensor([enc(s) for s, _ in train]); y = torch.tensor([l for _, l in train])

class Clf(nn.Module):
    def __init__(self, V):
        super().__init__()
        self.emb = nn.Embedding(V, 16, padding_idx=0)
        self.lstm = nn.LSTM(16, 32, batch_first=True, bidirectional=True)
        self.fc = nn.Linear(64, 2)
    def forward(self, x):
        _, (hn, _) = self.lstm(self.emb(x))
        return self.fc(torch.cat([hn[-2], hn[-1]], 1))

torch.manual_seed(0)
m = Clf(len(vocab)); opt = torch.optim.Adam(m.parameters(), lr=0.01)
for _ in range(100):
    loss = nn.functional.cross_entropy(m(X), y); opt.zero_grad(); loss.backward(); opt.step()
test = torch.tensor([enc("great movie"), enc("boring film")])
print(m(test).argmax(1).tolist())                         # [1, 0]  긍정 / 부정

pred, gold = torch.tensor([1, 1, 0, 1, 0]), torch.tensor([1, 0, 0, 1, 1])
tp = ((pred == 1) & (gold == 1)).sum().item(); P = tp / (pred == 1).sum().item(); R = tp / (gold == 1).sum().item()
print(round(P, 3), round(R, 3), round(2 * P * R / (P + R), 3))   # 0.667 0.667 0.667
```
