# LSTM

## 정의·핵심
- **정의 (응용 8차시)**: Long Short-Term Memory (Hochreiter & Schmidhuber, 1997). 바닐라 RNN의 **장기 의존성 문제를 개선해 기억력을 높인 RNN**. 강의: "앞으로 RNN을 사용한다고 하면 기본적으로 LSTM(또는 GRU)을 사용한다고 가정"
- **핵심 = Cell State (강의)**: RNN에 없던 **셀 상태 C_t** (장기 상태). 이전 시점 셀 상태가 다음 시점 셀 상태의 입력이 되고, **게이트(gate)** 로 정보를 더하거나 빼며 통제
  - 셀 상태는 **덧셈**으로 갱신 → 기울기가 곱셈으로 사라지지 않고 잘 흐름 (기울기 고속도로)
- **게이트 3개 (강의)** — 모두 시그모이드(0~1)로 "얼마나 통과시킬지" 결정
  - **삭제 게이트(Forget Gate) f_t**: 기억을 삭제 — **0에 가까울수록 많이 삭제, 1에 가까울수록 온전히 기억**. "이전 시점의 입력을 얼마나 반영할지"
  - **입력 게이트(Input Gate) i_t, g_t**: 현재 정보를 기억 — 시그모이드(0~1) `i_t`와 tanh(−1~1) `g_t` 두 값으로 이번에 기억할 값 결정. "현재 시점의 입력을 얼마나 반영할지"
  - **출력 게이트(Output Gate) o_t**: Hidden State 계산에 사용 — `h_t = o_t ⊙ tanh(C_t)`. Hidden State는 Cell State와 비교해 **단기 상태**
- **셀 상태 갱신 (강의)**: 삭제 게이트로 일부 기억 소실 + 입력 게이트의 `i_t ⊙ g_t`(이번에 기억할 값) → 두 값을 더함
  - `f_t = 0`: 이전 셀 상태가 0 → **입력 게이트만** 현재 셀 상태 결정 (삭제 게이트 닫힘)
  - `i_t = 0`: **이전 셀 상태로만** 현재 셀 상태 결정 (입력 게이트 닫힘)
- **PyTorch `nn.LSTM`**: 반환 `output, (h_n, c_n)` — hidden과 cell 둘 다. 파라미터 수는 RNN의 **4배** (게이트 4개 분량)
- **감성 분류 (개론 17차시 과제 문제 3)**: `Embedding → LSTM(batch_first=True) → Linear(hidden, num_classes)`, **마지막 시점 hidden state**를 Linear에 입력 → [[many-to-one·many-to-many]]

## 수식·원리
```
f_t = σ(W_f [h_{t−1}, x_t] + b_f)          삭제
i_t = σ(W_i [h_{t−1}, x_t] + b_i)          입력
g_t = tanh(W_g [h_{t−1}, x_t] + b_g)       후보 값
o_t = σ(W_o [h_{t−1}, x_t] + b_o)          출력
C_t = f_t ⊙ C_{t−1} + i_t ⊙ g_t            (장기 상태)
h_t = o_t ⊙ tanh(C_t)                      (단기 상태)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class BasicLSTM(nn.Module):                              # 개론 17차시 과제 문제 3
    def __init__(self, vocab_size, embed_size, hidden_size, num_classes=2):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        self.lstm = nn.LSTM(embed_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, num_classes)
    def forward(self, x):
        out, (h_n, c_n) = self.lstm(self.embedding(x))
        return self.fc(out[:, -1, :])                     # 마지막 시점 hidden state

torch.manual_seed(0)
m = BasicLSTM(100, 16, 32)
x = torch.randint(1, 100, (4, 10))
print(tuple(m(x).shape))                                  # (4, 2)
rnn_p = sum(p.numel() for p in nn.RNN(16, 32).parameters())
lstm_p = sum(p.numel() for p in nn.LSTM(16, 32).parameters())
print(rnn_p, lstm_p, lstm_p // rnn_p)                     # 1600 6400 4  게이트 4개 분량

C_prev, g = torch.tensor([2.0]), torch.tensor([0.5])      # 게이트 동작 (강의)
for f, i in ((1.0, 0.0), (0.0, 1.0), (0.5, 0.5)):
    print(f, i, (f * C_prev + i * g).item())              # 1.0 0.0 2.0 (기억 유지) / 0.0 1.0 0.5 (새 입력만) / 0.5 0.5 1.25
```
