# T5

## 정의·핵심
- **정의 (응용 14차시 GPT 슬라이드)**: Text-to-Text Transfer Transformer (Google, Raffel et al., 2019). **모든 NLP 태스크를 "텍스트 입력 → 텍스트 출력"** 하나의 형식으로 통일한 인코더-디코더 모델
- **Text-to-Text Framework (강의)**
  - Google T5에서 새로운 Fine-tuning 방식 사용 — **BART와 같이 enc-dec 방식**
  - 모든 downstream task를 **하나의 방식(NLG)** 으로 처리 → 텍스트 분류에서도 **클래스 인덱스 예측 방식 No**, 클래스 이름을 **텍스트로 생성**
  - **별도의 새로운 layer 추가 없이** 기존 모델 그대로 fine-tuning 가능 (BERT는 태스크마다 헤드를 붙임)
  - 원래 NLU 문제(분류·유사도)도 생성 문제로 풀림
- **태스크 접두어(prefix)로 구분**
  - `translate English to German: That is good.` → `Das ist gut.`
  - `cola sentence: The course is jumping well.` → `not acceptable`
  - `stsb sentence1: ... sentence2: ...` → `3.8` (회귀도 숫자 문자열로)
  - `summarize: ...` → 요약문
- **사전학습**: **C4**(Colossal Clean Crawled Corpus, 750GB) + **Span Corruption** — 연속 span을 sentinel 토큰(`<extra_id_0>`, `<extra_id_1>` …)으로 바꾸고, 디코더는 **가려진 부분만** 생성 (BART는 원문 전체 복원)
- **크기**: Small 60M ~ **11B**, 후속 mT5(다국어), Flan-T5(지시 튜닝)
- **강의 방향성**: 텍스트 분류·NER·MRC는 BERT·RoBERTa·**T5**가 여전히 강력
- SentencePiece 토크나이저 → [[토큰화(Tokenizer)]]

## 수식·원리
```
모든 태스크:  y_text = Decoder(Encoder("prefix: " + x_text))
L = −Σ_t log p(y_t | y_<t, x)          (태스크 무관하게 같은 손실)
Span Corruption:
  입력  "Thank you <X> me to your party <Y> week."
  출력  "<X> for inviting <Y> last <Z>"
```

## 코드 예시
```python
import random

def to_text2text(task, **kw):                                   # 모든 태스크 → (입력 텍스트, 출력 텍스트)
    if task == "translate": return f"translate English to German: {kw['src']}", kw["tgt"]
    if task == "cola": return f"cola sentence: {kw['s']}", ["not acceptable", "acceptable"][kw["label"]]
    if task == "stsb": return f"stsb sentence1: {kw['a']} sentence2: {kw['b']}", f"{kw['score']:.1f}"
    if task == "summarize": return f"summarize: {kw['doc']}", kw["summary"]

print(to_text2text("cola", s="The course is jumping well.", label=0))   # 분류도 텍스트로: 'not acceptable'
print(to_text2text("stsb", a="A cat sits.", b="A cat is sitting.", score=3.8)[1])   # 3.8  회귀도 문자열

def span_corrupt(words, spans):                                  # T5 사전학습
    inp, out, k, i = [], [], 0, 0
    for s, e in spans:
        inp += words[i:s] + [f"<extra_id_{k}>"]; out += [f"<extra_id_{k}>"] + words[s:e]; k += 1; i = e
    return " ".join(inp + words[i:]), " ".join(out + [f"<extra_id_{k}>"])

w = "Thank you for inviting me to your party last week .".split()
src, tgt = span_corrupt(w, [(2, 4), (8, 9)])
print(src)                                                       # Thank you <extra_id_0> me to your party <extra_id_1> week .
print(tgt)                                                       # <extra_id_0> for inviting <extra_id_1> last <extra_id_2>
```
