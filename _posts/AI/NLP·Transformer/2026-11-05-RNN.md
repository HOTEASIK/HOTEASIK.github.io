# RNN

## 정의·핵심
- **정의 (응용 8차시)**: Recurrent Neural Network. **연속적인 시퀀스를 처리하기 위한 신경망** — 사람이 이전 단어들의 이해를 바탕으로 다음 단어를 이해하듯, 내부에 **정보를 지속하는 루프**로 구성
- **기본 개념 (강의)**
  - **시점(time step)**: 입력을 받는 각 순간. `x_t`는 t시점 입력 (x₂ = 두 번째 시점)
  - **펼침(unrolled)**: 입력 길이만큼 같은 신경망이 펼쳐짐 → "피드 포워드 신경망에 시점 개념을 도입한 것"
  - **셀(cell)**: 은닉층의 RNN 처리 단위, 셀의 출력 = **은닉 상태(hidden state)**
  - 현재 `h_t` 계산에 **직전 `h_{t−1}`** 을 입력받음 → **과거 정보를 기억하는 비결**
  - **모든 시점이 같은 가중치(W_x, W_h, b) 공유** → 길이가 달라도 처리 가능 (NNLM의 고정 길이 한계 해결 → [[NNLM]])
- **행렬 크기 (강의)**: `x_t: d×1`, `W_x: D_h×d`, `W_h: D_h×D_h`, `h_t: D_h×1` — d = 단어 벡터 차원, **D_h = hidden size(주요 하이퍼파라미터)**
- **tanh (강의)**: −1~1 범위, 시그모이드보다 범위가 커서 은닉층에서 더 잘 동작
- **두 가지 그림 주의 (강의)**: (a) 입력·은닉·출력층까지 그린 그림 vs (b) 은닉층까지만 그린 그림 — 출력이 다름
- **장기 의존성 문제 (Long-Term Dependency)**: 시점이 길어질수록 **앞쪽 정보가 소실** — 역전파 시 같은 W_h가 반복 곱해져 **기울기 소실/폭주** → RNN의 고질적 문제 → [[LSTM]], [[GRU]]
- **RNN 언어 모델 (강의)**: Embedding → Hidden(RNN) → Output(Vocab size 다중 분류). 학습 시엔 실제값을 입력(**Teacher Forcing**) → [[Teacher Forcing]]
- **PyTorch `nn.RNN`**: 입력 `(B, L, d)`(batch_first=True) → `output (B, L, D_h)`(모든 시점 h), `h_n (layers, B, D_h)`(마지막 시점)
- **유형**: one-to-many(캡셔닝), many-to-one(분류), many-to-many(NER, 번역) → [[many-to-one·many-to-many]]

## 수식·원리
```
은닉층:  h_t = tanh(W_x x_t + W_h h_{t−1} + b)
출력층:  y_t = f(W_y h_t + b_y)          (분류면 softmax)
BPTT:   ∂h_t/∂h_k = Π_{i=k+1..t} diag(1 − h_i²) W_h   → |W_h| < 1 이면 소실, > 1 이면 폭주
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
d, Dh = 5, 4
rnn = nn.RNN(d, Dh, batch_first=True)
x = torch.randn(2, 6, d)                                    # (B=2, L=6, d=5)
out, h_n = rnn(x)
print(tuple(out.shape), tuple(h_n.shape))                   # (2, 6, 4) (1, 2, 4)
print(torch.allclose(out[:, -1], h_n[0]))                   # True  output 마지막 시점 = h_n

Wx, Wh = rnn.weight_ih_l0, rnn.weight_hh_l0                 # 직접 계산 (강의 수식)
b = rnn.bias_ih_l0 + rnn.bias_hh_l0
h = torch.zeros(2, Dh)
for t in range(6):
    h = torch.tanh(x[:, t] @ Wx.T + h @ Wh.T + b)
print(torch.allclose(h, h_n[0], atol=1e-6), tuple(Wx.shape), tuple(Wh.shape))   # True (4, 5) (4, 4)

g = torch.ones(1)                                           # 장기 의존성: 기울기가 반복 곱해짐
for w in (0.5, 1.5):
    print(w, f"{(w ** 30):.2e}")                            # 0.5 9.31e-10 (소실) / 1.5 1.92e+05 (폭주)
```
