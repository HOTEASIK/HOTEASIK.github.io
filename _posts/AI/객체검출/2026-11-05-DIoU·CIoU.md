# DIoU·CIoU

## 정의·핵심
- **배경**: GIoU는 박스가 포함 관계일 때 IoU와 같아지고, 먼저 박스를 키워 C를 채운 뒤에야 줄어들어 **수렴이 느림** → 중심 거리와 모양을 직접 넣은 손실 등장 (2020)
- **DIoU (Distance IoU)**
  - IoU에 **두 박스 중심점 사이 거리**를 벌점으로 추가 — `DIoU = IoU − ρ²(b, b_gt) / c²`
  - ρ = 중심점 간 유클리드 거리, c = **C box(감싸는 최소 박스)의 대각선 길이** → 정규화로 스케일 불변
  - **중심을 직접 당기므로** 수렴이 빠름, 포함 관계에서도 위치 구분 가능
  - **DIoU-NMS**: NMS 판단에 DIoU 사용 → 가까이 붙은 다른 객체 박스를 덜 지움
- **CIoU (Complete IoU)**
  - DIoU에 **종횡비(aspect ratio) 일치도**까지 추가 — `CIoU = IoU − ρ²/c² − α·v`
  - `v = (4/π²)·(arctan(w_gt/h_gt) − arctan(w/h))²`: 종횡비 차이, `α = v / ((1 − IoU) + v)`: 가중치
  - **좋은 박스의 3요소 = 겹침(IoU) + 중심 거리 + 종횡비**를 모두 고려
  - **YOLO v4·v5·v8의 기본 Box Loss** (강의 12차시: "CIoU — 겹치는 영역뿐 아니라 **중심점 거리와 종횡비까지** 고려하는 가장 정교한 손실, **YOLOv8의 기본 Box Loss**" / "두 박스가 절반만 겹치더라도 **중심이 가까우면 더 나은 예측**으로 평가")
- **비교**

| 지표 | 고려 요소 |
|---|---|
| IoU | 겹침 |
| GIoU | 겹침 + 감싸는 박스의 빈 공간 |
| DIoU | 겹침 + **중심 거리** |
| CIoU | 겹침 + 중심 거리 + **종횡비** |

- 손실: `L = 1 − DIoU` / `1 − CIoU` / torchvision: `distance_box_iou_loss`, `complete_box_iou_loss`

## 수식·원리
```
DIoU = IoU − ρ²(b, b_gt) / c²
CIoU = IoU − ρ²/c² − α·v
v = (4/π²)·(arctan(w_gt/h_gt) − arctan(w/h))²,   α = v / ((1 − IoU) + v)
```

## 코드 예시
```python
import torch
from torchvision.ops import box_iou, generalized_box_iou, distance_box_iou, complete_box_iou

gt = torch.tensor([[0., 0., 10., 10.]])
a = torch.tensor([[2., 2., 6., 6.]])                     # GT 안쪽, 중심에서 벗어남
b = torch.tensor([[3., 3., 7., 7.]])                     # GT 안쪽, 중심 일치
for name, f in (("IoU", box_iou), ("GIoU", generalized_box_iou), ("DIoU", distance_box_iou)):
    print(name, round(f(gt, a).item(), 3), round(f(gt, b).item(), 3))
# IoU 0.16 0.16 / GIoU 0.16 0.16 / DIoU 0.15 0.16  DIoU만 중심이 맞은 b를 더 좋게 평가

sq = torch.tensor([[0., 0., 10., 10.]]) + torch.tensor([[1., 0., 1., 0.]])   # 같은 크기, 정사각형
wide = torch.tensor([[-4., 2.5, 16., 7.5]])                                  # 같은 넓이 100, 납작
for b in (sq, wide):                                     # 벌점 = IoU − CIoU
    print(round(box_iou(gt, b).item(), 3), round((box_iou(gt, b) - complete_box_iou(gt, b)).item(), 3))
# 0.818 0.005 / 0.333 0.02  종횡비가 다르면 CIoU 벌점 ↑
```
