# Mask R-CNN

## 정의·핵심
- **정의**: Mask R-CNN (2017, He et al.). **Faster R-CNN에 객체별 마스크(픽셀 영역)를 예측하는 브랜치를 추가**한 **Instance Segmentation** 모델 (응용 12차시 Two-Stage 대표로 언급)
- **구조**: Faster R-CNN(Backbone + FPN + RPN) + RoI Head에 **3개 브랜치를 병렬로**
  1. 분류 (클래스)
  2. 박스 회귀
  3. **마스크 브랜치**: 작은 FCN → RoI마다 **클래스별 m×m(28×28) 이진 마스크**
- **핵심 개선: RoI Align**
  - RoI Pooling은 좌표를 **정수로 반올림(양자화)** 두 번 → 픽셀 단위 마스크에서 **어긋남(misalignment)**
  - RoI Align은 반올림 없이 **양선형 보간**으로 정확한 위치의 값을 샘플링 → 마스크 정확도 크게 향상 → [[Fast R-CNN]]
- **마스크 손실**: 정답 클래스 채널의 마스크에만 **픽셀별 Binary Cross Entropy** → 클래스 간 경쟁 없이 모양만 학습 (분류는 분류 브랜치가 담당)
- 전체 손실: `L = L_cls + L_box + L_mask`
- **확장**: 키포인트 브랜치(Keypoint R-CNN, 자세 추정)
- **활용**: 객체별 영역 분리(로봇 집기, 의료 병변 분할, 이미지 편집) → [[Instance Segmentation]]
- 실시간이 필요하면 One-Stage 분할(YOLO-seg) → [[YOLO Segmentation]]
- torchvision: `maskrcnn_resnet50_fpn` → 출력에 `masks` (N, 1, H, W) 확률

## 수식·원리
```
L = L_cls + L_box + L_mask
L_mask = BCE(sigmoid(m_k), M_gt)   (k = 정답 클래스 채널만)
RoI Pooling: 좌표 round → 오차   /   RoI Align: 양선형 보간 → 오차 없음
```

## 코드 예시
```python
import torch
from torchvision.models.detection import maskrcnn_resnet50_fpn

torch.manual_seed(0)
model = maskrcnn_resnet50_fpn(weights=None, weights_backbone=None, num_classes=3, min_size=128, max_size=128)
print(type(model.roi_heads.mask_predictor).__name__)            # MaskRCNNPredictor
model.train()
img = [torch.rand(3, 128, 128)]
mask = torch.zeros(1, 128, 128, dtype=torch.uint8); mask[0, 30:80, 40:90] = 1
tgt = [{"boxes": torch.tensor([[40., 30., 90., 80.]]), "labels": torch.tensor([1]), "masks": mask}]
print(sorted(model(img, tgt).keys()))                            # Faster R-CNN 손실 + loss_mask

model.eval()
with torch.no_grad():
    out = model(img)[0]
print(sorted(out.keys()))                                        # ['boxes', 'labels', 'masks', 'scores']
```
