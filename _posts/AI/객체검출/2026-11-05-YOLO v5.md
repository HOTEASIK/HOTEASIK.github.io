# YOLO v5

## 정의·핵심
- **정의**: YOLO v5 (2020.06, Ultralytics). **PyTorch 기반**으로 쉬운 사용성과 배포(Export) 편의성을 극대화해 **산업 표준**으로 자리 잡은 버전 — "**실전 엔지니어링 완성**" (응용 12차시)
- **KEY TECH (강의)**: **CSPDarknet 백본**, **Mosaic Augmentation**, **Auto Anchor**
- **아키텍처**
  - **Backbone: CSPDarknet53** — CSP(Cross Stage Partial)로 **연산량은 줄이고 학습 능력(Gradient Flow)은 강화** → [[CSP 구조]]
    - **Split & Merge**: 입력 특징을 두 파트로 나눠 하나만 conv, 다른 하나는 우회 후 합침 / 역전파 시 **중복 기울기 정보 감소**
    - 강의 비유: **고속도로 분기 차선** — 본선(연산)과 추월차선(우회)으로 나눠 달린 뒤 합류
  - **Neck: PANet** — Top-down(FPN) + Bottom-up(PAN) **양방향** → "의미는 내리고, 위치는 올린다" → [[FPN·PANet]]
  - **다중 스케일 (강의)**: **P3** 80×80 소형 / **P4** 40×40 중형 / **P5** 20×20 대형 (640 입력)
  - Head: **Coupled**, **Anchor-Based**, NMS 필수, 손실 GIoU/CIoU
- **학습 데이터 최적화 (강의)**
  - **Auto Anchor**: 학습 시작 전 데이터셋 모든 GT 박스 크기 분포를 분석 → **K-means**로 내 데이터에 맞는 앵커 세트 자동 생성 (사람이 설정할 필요 없음)
  - **Mosaic**: 서로 다른 **4장을 무작위로 크롭·배치해 1장**으로 합성 → **소형 객체 검출력 ↑**, **배치 크기 의존도 ↓**, 다양한 배경·맥락으로 일반화 ↑ (적은 데이터로도 높은 성능) → [[검출용 데이터 증강]]
- **모델 크기 라인업 n/s/m/l/x (강의, COCO val, 640)**

| 모델 | mAP 0.5:0.95 | CPU (ms) | Params (M) | FLOPs (B) |
|---|---|---|---|---|
| v5n | 28.0 | — | 1.9 | 4.5 |
| v5s | 37.4 | — | 7.2 | 16.5 |
| v5m | 45.4 | 224 | 21.2 | 49.0 |
| v5l | 49.0 | 430 | 46.5 | 109.1 |
| v5x | 50.7 | 766 | 86.7 | 205.7 |

  - n → x: 정확도 ↑, 속도 ↓ / 같은 구조에서 **depth_multiple·width_multiple**(층 수·채널 배율)만 바꿔 크기 조절
- **선택 가이드 (강의)**: 모바일·엣지(라즈베리파이, 드론) → **v5n/v5s** / 범용 서버·PC → **v5m/v5l** / 고정밀·연구(의료, 정밀 제조) → **v5x**
- 추천 용도(비교표): **레거시 호환, 튜닝 자유도**, 배포 안정성이 높아 보안 CCTV 등 기존 시스템 통합에 유리

## 수식·원리
```
채널 = round(base_ch × width_multiple),  반복 수 = round(base_n × depth_multiple)
n: (0.33, 0.25)  s: (0.33, 0.50)  m: (0.67, 0.75)  l: (1.0, 1.0)  x: (1.33, 1.25)
P3/P4/P5 = 640/8, 640/16, 640/32 = 80, 40, 20
```

## 코드 예시
```python
import numpy as np

scales = {"n": (0.33, 0.25), "s": (0.33, 0.50), "m": (0.67, 0.75), "l": (1.0, 1.0), "x": (1.33, 1.25)}
base_ch, base_n = [64, 128, 256, 512, 1024], 9
for k, (d, w) in scales.items():
    print(k, [int(c * w) for c in base_ch], max(round(base_n * d), 1))   # n [16, 32, 64, 128, 256] 3 … x [80, 160, 320, 640, 1280] 12

params = {"n": 1.9, "s": 7.2, "m": 21.2, "l": 46.5, "x": 86.7}
mAP = {"n": 28.0, "s": 37.4, "m": 45.4, "l": 49.0, "x": 50.7}
budget = 10                                                    # 엣지: 파라미터 10M 이하
best = max((k for k in params if params[k] <= budget), key=mAP.get)
print(best, mAP[best])                                         # s 37.4
```
