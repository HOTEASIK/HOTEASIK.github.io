# YOLO v8

## 정의·핵심
- **정의**: YOLO v8 (2023.01, Ultralytics). 복잡한 앵커 설정을 제거하고(Anchor-Free) 헤드를 분리(Decoupled)해 **유연성과 정확도를 동시에 확보**한 버전 — "**Anchor-Free 혁신**", 현재 **고성능 표준·범용** (응용 12차시)
- **KEY TECH (강의)**: **Anchor-Free Base**, **Decoupled Head**, **Task-Aligned Assigner**
- **3가지 핵심 혁신**
  1. **Anchor-Free**: 앵커 없이 **객체의 중심점과 중심에서 네 변까지의 거리(Top, Bottom, Left, Right)** 를 직접 예측 → 앵커 튜닝 비용 0, 비정형 비율·극소형 물체에 유연 → [[Anchor-Based vs Anchor-Free]]
     - 강의 비유: 지도 격자("가장 가까운 칸을 찾아라") → **GPS 좌표**("정확한 위도·경도 직송") / 기성복 S·M·L → **맞춤복**
  2. **C2f 모듈**: CSP의 **부분 분기(Split) + 재합류(Concat)** — 각 단계 결과를 **모두 concat** → 더 풍부한 Gradient Flow, 계산 ↓ 표현력 유지 → [[CSP 구조]]
     - 기존 Residual(v5 C3): `y = x + F(x)` / C2f: `y = Concat(x₁, Block(x₂), …)`
  3. **Decoupled Head**: 분류 브랜치와 회귀 브랜치를 **물리적으로 분리** → **Task Misalignment(과제 충돌)** 해소, 학습 안정·수렴 가속, mAP ↑
     - 강의 비유: 판사가 측량까지 겸업(1인 2역) → **판사와 측량사 분업**
- **Neck: PAN-FPN** — FPN(의미를 아래로) + PAN(위치를 위로) + C2f / **P3**(stride 8, 80×80, 8~32px 객체), **P4**(16, 40×40, 32~96px), **P5**(32, 20×20, 96px+) → [[FPN·PANet]]
- **손실 함수 (강의)**
  - **Box Loss: CIoU** (겹침 + 중심 거리 + 종횡비) + **DFL** → [[DIoU·CIoU]], [[DFL(Distribution Focal Loss)]]
  - **Classification Loss**: BCE / 강의는 **Focal Loss** 개념으로 설명 — `FL = −α(1 − p)^γ log p`, 쉬운 샘플(배경) 기여도 ↓, 어려운 샘플에 집중 ("쉬운 문제는 배점 낮게")
  - **할당: Task-Aligned Assigner** — 정렬 점수 `t = s^α × u^β` (s 분류 점수, u IoU, α=0.5, β=6.0)로 좋은 후보를 동적 선택 → [[Task-Aligned Assignment]]
- **통합 프레임워크**: 검출·**분할(Segmentation)**·분류·**자세 추정(Pose)** 을 하나로 (`yolov8n-seg.pt`, `-pose`, `-cls`)
- **라인업 (강의)**: n 3.2M(모바일·IoT) / s 11.2M(엣지) / m 25.9M(서버·PC) / l 43.7M(고성능) / x 68.2M(정밀 분석)
- 비교표(v8s): **mAP 44.9, Params 11.1M**, C2f + PAN-FPN, Anchor-Free, Decoupled, **NMS 필수**, CIoU + Focal + DFL

## 수식·원리
```
박스: 앵커 점 (cx, cy)에서 (l, t, r, b) 거리 예측 → x1 = cx − l, y1 = cy − t, x2 = cx + r, y2 = cy + b
정렬 점수: t = s^0.5 · u^6
Focal: FL(p_t) = −α_t (1 − p_t)^γ log(p_t)
출력(640): 80² + 40² + 20² = 8400 앵커 점 × (4·reg_max + nc)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class C2f(nn.Module):                                       # Split → Block 연속 → 전부 Concat
    def __init__(self, c, n=2):
        super().__init__()
        self.cv1 = nn.Conv2d(c, c, 1)
        self.m = nn.ModuleList(nn.Sequential(nn.Conv2d(c // 2, c // 2, 3, 1, 1), nn.SiLU()) for _ in range(n))
        self.cv2 = nn.Conv2d(c // 2 * (2 + n), c, 1)
    def forward(self, x):
        y = list(self.cv1(x).chunk(2, 1))                   # Split
        for m in self.m:
            y.append(m(y[-1]))                              # 각 단계 결과를 모두 보관
        return self.cv2(torch.cat(y, 1))                    # Concat

print(tuple(C2f(64)(torch.randn(1, 64, 40, 40)).shape))     # (1, 64, 40, 40)

ax, ay = 100., 80.                                          # Anchor-Free 디코딩
l, t, r, b = 30., 20., 50., 40.                             # 중심에서 네 변까지 거리
print([ax - l, ay - t, ax + r, ay + b])                     # [70.0, 60.0, 150.0, 120.0]

p = torch.tensor([0.95, 0.6, 0.1])                          # Focal Loss: 쉬운 샘플 가중 ↓
ce = -torch.log(p)
fl = (1 - p) ** 2 * ce
print([round(v, 4) for v in (fl / ce).tolist()])            # [0.0025, 0.16, 0.81]  잘 맞춘 샘플은 거의 무시
```
