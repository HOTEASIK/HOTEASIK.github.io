# 라벨 형식

## 정의·핵심
- 검출 라벨은 **"어떤 클래스가 어디에 있나"** 를 박스 좌표로 기록한 어노테이션. 형식마다 **좌표 의미가 달라** 변환 실수가 가장 흔한 버그 (보충교안 03·3_1)
- **3대 형식 (보충 3_1 표)**

| 형식 | 표현 | 단위 | 파일 |
|---|---|---|---|
| **YOLO** | `class cx cy w h` (중심 + 크기) | **0~1 정규화** | 이미지마다 `.txt`, 한 줄 = 한 객체 |
| **COCO** | `[x, y, w, h]` (좌상단 + 크기) | 픽셀 | 데이터셋 전체 하나의 `.json` |
| **VOC** | `xmin ymin xmax ymax` (모서리) | 픽셀 | 이미지마다 `.xml` |

- 예 (보충 3_1): YOLO `0.5 0.5 0.3 0.4` / COCO `120 80 90 130` / VOC `120 80 210 210`
- **YOLO 폴더 규약 (보충 3_1)**: `images`와 `labels`가 **거울처럼 대칭** — `coco8/images/train/000000000009.jpg` ↔ `coco8/labels/train/000000000009.txt`(확장자만 다른 같은 이름). 학습기는 경로의 `images`를 `labels`로 바꿔 라벨을 찾음
  - 객체가 없는 이미지는 **빈 txt**(또는 파일 없음) → 배경 샘플
- **변환식 (보충 3_1 연습 문제 2)**
  - YOLO → 픽셀 xyxy: `x1 = (cx − w/2)·W`, `x2 = (cx + w/2)·W` (y는 H)
  - 픽셀 xyxy → YOLO: `cx = ((x1 + x2)/2)/W`, `w = (x2 − x1)/W` (y도 동일)
- **VOC XML → YOLO txt (응용 12차시 Safety Helmet)**: `<object><name>`을 클래스 번호로, `<bndbox>`의 xmin·ymin·xmax·ymax를 정규화 중심 형식으로, `<size>`의 width·height 사용
- **라벨링 도구**: LabelImg(VOC·YOLO), CVAT, Label Studio, Roboflow(형식 변환·증강)
- **검수 (보충 3_1 STEP 4)**: 라벨이 정말 물체를 가리키는지 **박스를 이미지 위에 그려 눈으로 확인**하는 것이 데이터 검수의 핵심 → [[라벨 오류 점검]]

## 수식·원리
```
YOLO → xyxy:  x1 = (cx − w/2)·W,  y1 = (cy − h/2)·H,  x2 = (cx + w/2)·W,  y2 = (cy + h/2)·H
xyxy → YOLO:  cx = (x1 + x2)/(2W),  cy = (y1 + y2)/(2H),  w = (x2 − x1)/W,  h = (y2 − y1)/H
COCO → xyxy:  x2 = x + w,  y2 = y + h
```

## 코드 예시
```python
import xml.etree.ElementTree as ET

xml = """<annotation><size><width>640</width><height>480</height></size>
<object><name>helmet</name><bndbox><xmin>120</xmin><ymin>80</ymin><xmax>210</xmax><ymax>210</ymax></bndbox></object>
<object><name>person</name><bndbox><xmin>300</xmin><ymin>40</ymin><xmax>500</xmax><ymax>470</ymax></bndbox></object>
</annotation>"""
classes = ["head", "helmet", "person"]

def voc_to_yolo(xml_text):
    root = ET.fromstring(xml_text)
    W, H = int(root.find("size/width").text), int(root.find("size/height").text)
    lines = []
    for o in root.iter("object"):
        b = [float(o.find(f"bndbox/{k}").text) for k in ("xmin", "ymin", "xmax", "ymax")]
        cx, cy, w, h = (b[0] + b[2]) / 2 / W, (b[1] + b[3]) / 2 / H, (b[2] - b[0]) / W, (b[3] - b[1]) / H
        lines.append(f"{classes.index(o.find('name').text)} {cx:.6f} {cy:.6f} {w:.6f} {h:.6f}")
    return lines, W, H

lines, W, H = voc_to_yolo(xml)
print(lines)                                          # ['1 0.257812 0.302083 0.140625 0.270833', '2 0.625000 0.531250 0.312500 0.895833']

c, cx, cy, w, h = lines[0].split(); cx, cy, w, h = map(float, (cx, cy, w, h))
back = [round((cx - w / 2) * W), round((cy - h / 2) * H), round((cx + w / 2) * W), round((cy + h / 2) * H)]
print(int(c), back)                                   # 1 [120, 80, 210, 210]  왕복 변환 일치
x, y = back[0], back[1]
print([x, y, back[2] - x, back[3] - y])               # [120, 80, 90, 130]  COCO 형식
```
