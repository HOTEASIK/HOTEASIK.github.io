# 모델 배포

## 정의·핵심
- **정의**: 학습된 모델을 실제 서비스·기기에서 **빠르고 안정적으로 추론**하도록 변환·최적화하는 과정. 실서비스에서는 PyTorch 모델을 그대로 쓰지 않고 **중간 표현(ONNX)** 을 거쳐 **하드웨어 가속 엔진(TensorRT)** 으로 변환 (응용 12차시 "모델 배포 최적화")
- **PyTorch → ONNX → TensorRT (강의)**
  - **ONNX** (Open Neural Network Exchange): 프레임워크와 무관한 **표준 그래프 형식** — PyTorch에서 내보내 ONNX Runtime·TensorRT·OpenVINO·모바일 엔진 등 어디서나 실행
  - **TensorRT** (NVIDIA): 특정 GPU에 맞춰 **레이어 융합, 커널 자동 선택, FP16/INT8 정밀도 축소**로 최적화한 엔진(`.engine`)
- **추론 지연 비교 (강의)**

| 실행 방식 | Latency | 배속 |
|---|---|---|
| PyTorch (Native) | ~150ms | 기준 |
| ONNX Runtime | ~75ms | 2배 |
| TensorRT (NVIDIA) | ~20ms | **7.5배** |

  - 강의: "형식 변환과 하드웨어 가속으로 추론 지연을 **한 자릿수 ms대까지** 압축"
  - 강의 비유: PyTorch는 다양한 길을 갈 수 있는 **승용차**, TensorRT는 특정 서킷(GPU)에 맞춰 불필요한 부품을 떼어낸 **F1 머신** — 오직 추론만을 위해 최적화
- **ultralytics 내보내기**
  ```
  model = YOLO("best.pt")
  model.export(format="onnx", imgsz=640, dynamic=False, simplify=True)
  model.export(format="engine", half=True)     # TensorRT (GPU 환경)
  YOLO("best.onnx").predict("img.jpg")          # 내보낸 모델로 바로 추론
  ```
  - 그 밖의 형식: `openvino`(Intel CPU), `tflite`/`coreml`(모바일), `ncnn`(엣지)
- **PyTorch 직접 내보내기**: `torch.onnx.export(model.eval(), dummy_input, "m.onnx", input_names=..., output_names=..., dynamic_axes=..., opset_version=17)`
- **주의**
  - `model.eval()` 후 내보내기 (Dropout·BN 고정)
  - **NMS**는 그래프 밖에서 처리하거나 플러그인 필요 → TensorRT 배포가 까다로운 이유 → **v10 NMS-Free** 장점 → [[YOLO v10]]
  - **전처리(letterbox, 정규화)와 후처리를 배포 코드에서 학습 때와 똑같이** 구현
  - FP16·INT8은 속도 ↑ 정확도 약간 ↓ → **변환 후 mAP 재검증** / INT8은 보정(calibration) 데이터 필요
  - TensorRT 엔진은 **GPU 모델·TensorRT 버전에 종속** → 배포 장비에서 빌드
- 속도 측정 시 **워밍업** 후 여러 번 평균, 배치 1 기준 Latency와 처리량(FPS)을 구분

## 수식·원리
```
배포 흐름:  학습(.pt) → export(.onnx) → 최적화 엔진(.engine) → 서비스
속도 향상:  150ms → 75ms (ONNX, 2×) → 20ms (TensorRT, 7.5×)
FPS = 1000 / latency(ms)    → 150ms ≈ 6.7 FPS,  20ms = 50 FPS
```

## 코드 예시
```python
import time
import torch
import torch.nn as nn

model = nn.Sequential(nn.Conv2d(3, 16, 3, 2, 1), nn.ReLU(), nn.Conv2d(16, 32, 3, 2, 1), nn.ReLU(),
                      nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(32, 4)).eval()   # eval 필수
x = torch.rand(1, 3, 320, 320)

def latency(fn, n=20):
    with torch.no_grad():
        for _ in range(3): fn(x)                                  # 워밍업
        t = time.perf_counter()
        for _ in range(n): fn(x)
    return (time.perf_counter() - t) / n * 1000

traced = torch.jit.trace(model, x)                                # 그래프 고정 (ONNX 내보내기도 같은 원리)
print(torch.allclose(model(x), traced(x), atol=1e-6))             # True  변환 전후 출력 일치 확인
print(latency(model) > 0, latency(traced) > 0)                    # True True  워밍업 후 평균으로 측정
for ms in (150, 75, 20):
    print(ms, "ms →", round(1000 / ms, 1), "FPS")                # 6.7 / 13.3 / 50.0
```
