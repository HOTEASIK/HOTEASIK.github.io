# YOLO v10

## 정의·핵심
- **정의**: YOLO v10 (2024.05, 칭화대). 휴리스틱 후처리인 **NMS를 학습 과정에 내재화**해 **완전한 End-to-End 검출**을 실현 — "**NMS-Free & E2E**", 초저지연 (응용 12차시)
- **KEY TECH (강의)**: **NMS-Free Training**, **Dual Label Assignment**, **Efficiency-Accuracy 설계**(대커널 DWConv, CIB)
- **기존 NMS의 한계 (강의)**
  - **민감한 하이퍼파라미터**: IoU 임계값에 따라 결과가 크게 달라짐
  - **추론 지연 증가**: GPU 병렬 연산 후 **별도의 순차 연산** 필요
  - **배포 복잡성**: TensorRT 등 최적화 시 NMS 플러그인 구현이 까다로움
  - 강의 비유: **경매장 낙찰** — 중복 응찰자 중 최고가 1명을 사람이 정한 규칙(IoU)으로 수작업 선별
  - 기존(v5/v8): 예측 → **NMS** → 결과 / v10: 예측 → **결과(즉시)**
- **Dual Label Assignment (강의)**: 학습 시 **두 헤드**를 동시에 사용
  1. **One-to-Many Head (예선)**: 하나의 GT에 **여러 예측**을 할당 → 풍부한 학습 신호 (**Recall 강화**) — v8과 같은 방식
  2. **One-to-One Head (본선)**: 하나의 GT에 **오직 하나의 예측**만 매칭 → **중복 억제** (NMS 불필요)
  - 두 헤드가 같은 정렬 점수(Consistent Matching Metric)를 써서 최적 방향이 일치
  - **추론에는 One-to-One 헤드만** 사용 → 후처리 없이 top-k만 고름
  - 강의 비유: **오디션** — 예선에선 많이 뽑아 훈련(학습 효율 ↑), 본선에선 우승자 1명만 무대에 (추론 깔끔)
- **아키텍처 효율화 (강의)**
  - **Large-kernel DWConv**: 3×3을 여러 번 쌓는 대신 **7×7 Depthwise** → 넓은 수용 영역, 파라미터 ↓
    - 왜 기존 CNN은 3×3? ① 연산량 절약(49 vs 9) ② 비선형성 증가(3×3+ReLU 반복) ③ 쌓으면 7×7 효과 / v10이 7×7을 쓰는 이유 = **Depthwise라 채널별로 따로 계산해 싸다** → 적은 비용으로 넓은 문맥(context) → [[Depthwise Convolution]]
  - **CIB (Compact Inverted Block)**: **1×1 Conv(확장) → DWConv → 1×1 Conv(축소)** — 정보 손실 최소화, 연산량 감소
  - Partial Self-Attention(PSA), 공간-채널 분리 다운샘플링
  - 결과: **후처리 시간 단축 + 모델 추론 시간 단축 = 전체 Latency 극소화** → 모바일·드론 등 제한된 환경에 최적
- 비교표(v10s): **mAP 46.3, Params 8.0M**, CIB + Partial SA, Anchor-Free, Decoupled, **NMS-Free**

## 수식·원리
```
학습:  L = L_one-to-many + L_one-to-one
매칭 점수: m(α, β) = s · p^α · IoU(b̂, b)^β   (두 헤드 동일 α, β)
추론:  one-to-one head → score top-k → 결과 (NMS 없음)
DWConv 7×7 파라미터: C·49  vs  일반 7×7: C²·49
```

## 코드 예시
```python
import torch
import torch.nn as nn

C = 128
dw7 = nn.Conv2d(C, C, 7, padding=3, groups=C, bias=False)       # 대커널 Depthwise
full7 = nn.Conv2d(C, C, 7, padding=3, bias=False)
three3 = nn.Sequential(*[nn.Conv2d(C, C, 3, padding=1, bias=False) for _ in range(3)])   # 3x3 3개 = RF 7
n = lambda m: sum(p.numel() for p in m.parameters())
print(n(dw7), n(full7), n(three3))                               # 6272 802816 442368

class CIB(nn.Module):                                            # 1x1 확장 → DW → 1x1 축소
    def __init__(self, c, e=2):
        super().__init__()
        self.f = nn.Sequential(nn.Conv2d(c, c * e, 1), nn.SiLU(),
                               nn.Conv2d(c * e, c * e, 7, padding=3, groups=c * e), nn.SiLU(),
                               nn.Conv2d(c * e, c, 1))
    def forward(self, x):
        return x + self.f(x)
print(tuple(CIB(64)(torch.randn(1, 64, 20, 20)).shape))          # (1, 64, 20, 20)

# One-to-One: GT마다 정렬 점수가 가장 높은 예측 1개만 양성
score = torch.tensor([[0.9, 0.8, 0.85, 0.1], [0.1, 0.2, 0.1, 0.7]])   # (GT 2, 예측 4)
print((score > 0.5).sum(1).tolist(), score.argmax(1).tolist())   # [3, 1] [0, 3]  one-to-many vs one-to-one
```
