# YOLO 학습 실습

## 정의·핵심
- **목표 (응용 12차시)**: "**3줄 실습 코드로** 학습부터 추론, 평가까지 파이프라인 구축" — ultralytics로 커스텀 데이터셋 학습
- **실전 데이터셋 예 (강의: Safety Helmet)**
  - Kaggle Safety Helmet 데이터 **5000장**, 클래스 3개 **head, helmet, person**
  - 원본 **XML(VOC) 라벨 → YOLO .txt**로 변환 → [[라벨 형식]]
  - 분할: **Train 3693 / Validation 1175 / Test 537** — Train으로 학습, Val로 모니터링, Test로 최종 평가 (강의 수치 그대로, 합계는 5405)
- **폴더 구조**
  ```
  dataset/
    images/train/*.jpg   images/val/*.jpg
    labels/train/*.txt   labels/val/*.txt     (이미지와 같은 이름)
  ```
  - txt 한 줄 = `class cx cy w h` (0~1 정규화)
- **data.yaml**
  ```
  path: dataset
  train: images/train
  val: images/val
  names: {0: head, 1: helmet, 2: person}
  ```
- **3줄 파이프라인 (강의 Python SDK)**
  ```
  model = YOLO("yolov8n.pt")                                  # 사전학습 가중치
  model.train(data="data.yaml", epochs=100, imgsz=640, batch=16)
  metrics = model.val()                                       # mAP50, mAP50-95
  model.predict("test.jpg", conf=0.4)
  ```
  - CLI: `yolo detect train data=data.yaml model=yolov8n.pt epochs=100 imgsz=640`
- **결과물 (`runs/detect/train/`)**
  - `weights/best.pt`(검증 **mAP 최고** 가중치), `last.pt`(마지막 — 이어서 학습 `resume=True`)
  - `results.csv/png`(손실·mAP 곡선), `confusion_matrix.png`, `PR_curve.png`, `F1_curve.png`
  - 손실 3개: `box_loss`(CIoU), `cls_loss`, `dfl_loss` → 점점 감소해야 함
- **증강 파라미터 (강의 Strong Augmentation)**: `hsv_h, hsv_s, hsv_v`(색), `translate, scale, degrees`(기하), `mosaic`(4장 합성), `mixup`, `copy_paste` → [[검출용 데이터 증강]]
- **주요 학습 인자**: `epochs`, `imgsz`, `batch`(-1이면 자동), `lr0`, `optimizer`, `patience`(조기 종료), `freeze`(백본 동결 층 수), `device`, `workers`
- 장점 (강의): 한 줄로 실험 가능, CLI·Python SDK 통일, **재현성 높은 실험 환경**

## 수식·원리
```
YOLO 라벨:  class cx/W cy/H w/W h/H
fitness = 0.1·mAP50 + 0.9·mAP50-95  → 가장 높은 epoch를 best.pt로 저장
총 손실 = 7.5·box(CIoU) + 0.5·cls(BCE) + 1.5·dfl   (v8 기본 가중치)
```

## 코드 예시
```python
import os, tempfile, random

root = tempfile.mkdtemp()                                         # 데이터셋 폴더·data.yaml 준비 (실행 가능 부분)
names = ["head", "helmet", "person"]
files = [f"img{i:04d}" for i in range(3693 + 1175 + 537)]
random.seed(0); random.shuffle(files)
split = {"train": files[:3693], "val": files[3693:4868], "test": files[4868:]}
print({k: len(v) for k, v in split.items()})                      # {'train': 3693, 'val': 1175, 'test': 537}
for sub in ("images/train", "images/val", "labels/train", "labels/val"):
    os.makedirs(os.path.join(root, sub), exist_ok=True)
yaml_path = os.path.join(root, "data.yaml")
with open(yaml_path, "w", encoding="utf-8") as f:
    f.write(f"path: {root}\ntrain: images/train\nval: images/val\nnames:\n")
    f.writelines(f"  {i}: {n}\n" for i, n in enumerate(names))
print(open(yaml_path, encoding="utf-8").read().splitlines()[-3:])  # ['  0: head', '  1: helmet', '  2: person']
fitness = lambda m50, m5095: 0.1 * m50 + 0.9 * m5095
print(round(fitness(0.82, 0.55), 3))                              # 0.577  best.pt 선정 기준
```

```python
# ultralytics 미설치 → --stub로 흐름만 확인 (실제 출력은 미검증)
from ultralytics import YOLO

model = YOLO("yolov8n.pt")
model.train(data="data.yaml", epochs=100, imgsz=640, batch=16, patience=20)
metrics = model.val()
print(metrics.box.map50, metrics.box.map)
best = YOLO("runs/detect/train/weights/best.pt")
best.predict("test.jpg", conf=0.4, save=True)
```
