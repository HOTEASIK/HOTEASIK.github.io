# SSD Loss

## 정의·핵심
- **Multi-task Loss (응용 13차시)**: **분류(Confidence Loss) + 위치 회귀(Localization Loss)** 의 가중합을 매칭된 양성 수 N으로 나눔 — `L = (1/N)(L_conf + α·L_loc)`, α = 1 (N = 0이면 손실 0)
- **Localization Loss (강의)**
  - **Positive로 매칭된 Default Box에 대해서만** 계산
  - 예측값은 절대 좌표가 아니라 Default Box 기준 **오프셋** (cx, cy, w, h)
  - **좌표 파라미터화 (강의)**
    - 중심: `ĝcx = (gcx − dcx) / dw`, `ĝcy = (gcy − dcy) / dh` → Default Box 크기로 정규화된 상대 거리 → **위치 불변성(Translation Invariance)**
    - 크기: `ĝw = log(gw / dw)`, `ĝh = log(gh / dh)` → **로그**로 작은 박스·큰 박스의 오차 스케일을 맞춤 → **스케일 불변성**
    - (구현에서는 분산 0.1, 0.2로 한 번 더 나눔)
  - **Smooth L1 Loss (강의)**: Fast R-CNN에서 그대로 채택
    - **|x| < 1**: `0.5x²` — **L2처럼** 동작, 0 근처에서 부드러운 미분
    - **|x| ≥ 1**: `|x| − 0.5` — **L1처럼** 동작, **Gradient 폭주 방지**
    - L2(MSE)는 **Outlier에 민감**·기울기 폭주 가능 / L1(MAE)은 강건하지만 **0에서 미분 불가·진동** → 둘의 장점 결합
    - 초기 학습의 불안정한 예측(Outlier)에 덜 민감 → 학습 안정
- **Confidence Loss (강의)**
  - 박스마다 **C+1개(클래스 + 배경)** 점수 → **Softmax + Cross Entropy**
  - **Positive**(IoU > 0.5로 매칭): 해당 클래스 확률 최대화 / **Negative**(매칭 안 됨): **배경(c = 0)** 으로 분류
  - **Class Imbalance**: 배경이 압도적 → 모든 Negative를 쓰면 배경만 예측 → **Hard Negative Mining(3:1)** 필수 → [[Hard Negative Mining]]
- **학습 파이프라인 5단계 (강의)**: ① Forward(8,732개 예측) → ② Box Matching(IoU > 0.5) → ③ Hard Negative Mining(3:1) → ④ Loss 계산(L_conf + L_loc) → ⑤ Backprop

## 수식·원리
```
L(x, c, l, g) = (1/N) [ L_conf(x, c) + α·L_loc(x, l, g) ]
L_loc  = Σ_{i∈Pos} Σ_{m∈{cx,cy,w,h}} smoothL1(l_i^m − ĝ_j^m)
L_conf = −Σ_{i∈Pos} log ĉ_i^p − Σ_{i∈Neg} log ĉ_i^0       (ĉ = softmax)
smoothL1(x) = 0.5x² (|x|<1),  |x| − 0.5 (그 외)
```

## 코드 예시
```python
import torch
import torch.nn.functional as F

def encode(g, d):                                         # (cx, cy, w, h)
    return torch.cat([(g[:, :2] - d[:, :2]) / d[:, 2:], torch.log(g[:, 2:] / d[:, 2:])], 1)

d = torch.tensor([[0.5, 0.5, 0.2, 0.2], [0.3, 0.3, 0.4, 0.2]])
g = torch.tensor([[0.52, 0.49, 0.25, 0.2], [0.3, 0.35, 0.4, 0.3]])
t = encode(g, d)
print([[round(v, 3) for v in r] for r in t.tolist()])   # [[0.1, -0.05, 0.223, 0.0], [0.0, 0.25, 0.0, 0.405]]

x = torch.tensor([0.5, 3.0])                              # 작은 오차 / 큰 오차 (outlier)
print(F.smooth_l1_loss(x, torch.zeros(2), reduction="none").tolist(),   # [0.125, 2.5]
      F.mse_loss(x, torch.zeros(2), reduction="none").tolist())         # [0.25, 9.0]  L2는 outlier에 과민
xg = torch.tensor([3.0], requires_grad=True)
F.smooth_l1_loss(xg, torch.zeros(1)).backward()
print(xg.grad.item())                                     # 1.0  큰 오차에도 기울기 일정 (L2면 6.0)

torch.manual_seed(0)
loc_p, conf_p = torch.randn(5, 4), torch.randn(5, 3)      # 박스 5개, 클래스 2 + 배경
labels = torch.tensor([1, 2, 0, 0, 0]); pos = labels > 0
N = pos.sum()
L = (F.cross_entropy(conf_p, labels, reduction="sum") +
     F.smooth_l1_loss(loc_p[pos], torch.zeros(int(N), 4), reduction="sum")) / N
print(round(L.item(), 3) > 0)                             # True  (1/N)(L_conf + L_loc)
```
