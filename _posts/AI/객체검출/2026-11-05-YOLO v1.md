# YOLO v1

## 정의·핵심
- **정의**: YOLO (You Only Look Once, 2016, Redmon). 객체 검출을 **하나의 회귀 문제(Single Regression Problem)** 로 보고, 이미지 → **박스 좌표 + 클래스 확률**을 **한 번의 feedforward**로 바로 예측하는 **One-Stage 검출기** (대학원교안 14·15, 응용 12차시)
- **기존 방식과 차이 (강의)**: DPM·Sliding Window·R-CNN은 분류기를 검출에 재활용 — ① 후보 박스 생성 → ② 후보마다 분류 → ③ 후처리(정제·제거·재점수) / YOLO는 **통합(Unified)**
- **Unified Detection (강의)**
  1. 이미지를 **S × S 격자(grid)** 로 나눔 (VOC: **S = 7**)
  2. 객체의 **중심이 속한 grid cell이 그 객체를 담당**
  3. 각 cell은 **B개(= 2) 박스**마다 **5개 값 `(x, y, w, h, confidence)`** 예측 — x, y는 cell 기준 상대 위치, w, h는 이미지 기준
  4. 각 cell은 박스 수와 무관하게 **클래스 확률 C개** 1세트: `Pr(Class_i | Object)`
  - **출력 텐서: S × S × (B·5 + C) = 7 × 7 × 30** (VOC, C = 20)
  - confidence = `Pr(Object) × IoU(pred, truth)` / 테스트 시 클래스별 점수 = 클래스 확률 × 박스 confidence → [[Confidence Score]]
- **과제 문항 2 — grid cell이 예측하는 3요소 (= 손실의 3요소)**: ① **박스 좌표**(x, y, w, h) ② **객체 confidence**(객체 존재 여부) ③ **클래스 확률**
- **네트워크 (강의)**: **GoogLeNet 변형**(Inception 대신 1×1 reduction + 3×3), **24 conv + 2 FC** / Fast YOLO(tiny)는 9 conv
- **학습 (강의)**: ImageNet으로 앞 20 conv 사전학습(224) → 4 conv + 2 FC 추가, **입력 448×448**로 검출 학습 / epochs 135, batch 64, momentum 0.9, decay 0.0005, dropout 0.5, 증강(scaling, translation, exposure, saturation)
- **손실 (sum-squared error)**: 좌표 오차(λ_coord = 5, **w·h는 제곱근**으로 — 작은 박스 오차를 더 크게) + 객체 있는 박스 confidence + 객체 없는 박스 confidence(λ_noobj = 0.5) + 클래스 확률 / 셀 i의 j번째 박스 중 **IoU가 가장 큰 박스가 "responsible"**
- **장점 (강의)**: **매우 빠름**(45 FPS, Fast YOLO 155 FPS), 이미지 전체를 보므로 **배경 오검출이 적음**(Global context), **일반화 성능**(예술 작품 속 사람 검출)
- **한계 (강의)**: **작은 객체 무리**(cell당 1클래스·2박스), **특이한 종횡비**, 거친(coarse) 특징, **위치 오차**가 큼 → v2·v3에서 개선 → [[YOLO v2·v3]]

## 수식·원리
```
출력: S×S×(B·5 + C) = 7×7×(2·5 + 20) = 7×7×30
L = λ_coord Σ 1^obj [(x−x̂)² + (y−ŷ)² + (√w−√ŵ)² + (√h−√ĥ)²]
  + Σ 1^obj (C−Ĉ)² + λ_noobj Σ 1^noobj (C−Ĉ)²
  + Σ_cell 1^obj Σ_c (p(c) − p̂(c))²          (λ_coord=5, λ_noobj=0.5)
```

## 코드 예시
```python
import torch

S, B, C = 7, 2, 20
out = torch.rand(1, S, S, B * 5 + C)                       # 네트워크 출력
print(tuple(out.shape))                                    # (1, 7, 7, 30)

img_w = img_h = 448
cx, cy = 300, 130                                          # 객체 중심 → 담당 셀
col, row = int(cx / img_w * S), int(cy / img_h * S)
print(row, col)                                            # 2 4
x_cell, y_cell = cx / img_w * S - col, cy / img_h * S - row
print(round(x_cell, 3), round(y_cell, 3))                  # 0.688 0.031  셀 안 상대 좌표

cell = out[0, row, col]
boxes = cell[:B * 5].reshape(B, 5)                         # (x, y, w, h, conf) × 2
cls_prob = cell[B * 5:]                                    # 클래스 확률 20개 (셀당 1세트)
score = boxes[:, 4:5] * cls_prob                           # 박스별 클래스 점수
print(tuple(score.shape))                                  # (2, 20)
print((S * S * B))                                         # 98  이미지당 최대 박스 수
```
