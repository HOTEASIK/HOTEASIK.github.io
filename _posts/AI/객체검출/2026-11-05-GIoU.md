# GIoU

## 정의·핵심
- **정의**: GIoU (Generalized IoU, 2019). 두 박스 간 **교집합이 없으면 IoU가 0**이 되어 **얼마나 떨어져 있는지(오차)** 를 알기 어려운 점을 보완한 지표 (응용 11차시)
- **C box (강의)**: GT와 예측을 **모두 포괄하는 가장 작은 박스** (enclosing box) → `Enclose_left_up = min(좌상단)`, `Enclose_right_down = max(우하단)`
- **정의식**: `GIoU = IoU − |C − (A ∪ B)| / |C|`
  - C 안에서 **두 박스가 차지하지 않는 빈 공간의 비율**을 벌점으로 뺌
  - 범위 **−1 ~ 1**: 완전 일치 1, 겹치면 IoU에 가까움, **멀리 떨어질수록 −1에 가까워짐**
- **손실**: `L_GIoU = 1 − GIoU` (0 ~ 2)
  - 안 겹친 상태에서도 **기울기가 있어** 예측 박스를 GT 쪽으로 끌어당김
  - IoU는 **스케일 불변** → 큰 박스·작은 박스를 공평하게 평가 (L1/L2 좌표 손실은 큰 박스에 치우침)
- **한계**: 한 박스가 다른 박스를 **완전히 포함**하면 C = 큰 박스 → 벌점 0 → **GIoU = IoU**가 되어 위치 차이를 구분 못 함, 수렴이 느림 → **DIoU·CIoU** → [[DIoU·CIoU]]
- torchvision: `torchvision.ops.generalized_box_iou`, `generalized_box_iou_loss` / DETR이 L1과 함께 GIoU 손실 사용

## 수식·원리
```
C = 두 박스를 감싸는 최소 박스
GIoU = IoU − (|C| − |A ∪ B|) / |C|        (−1 < GIoU ≤ 1)
L_GIoU = 1 − GIoU
포함 관계: C = 큰 박스 = A ∪ B → GIoU = IoU
```

## 코드 예시
```python
import torch
from torchvision.ops import box_iou, generalized_box_iou, generalized_box_iou_loss

gt = torch.tensor([[0., 0., 10., 10.]])
for dx in (5, 20, 50):                                    # 점점 멀어지는 예측
    p = torch.tensor([[dx, 0., dx + 10., 10.]])
    print(dx, round(box_iou(gt, p).item(), 3), round(generalized_box_iou(gt, p).item(), 3))
# 5 0.333 0.333 / 20 0.0 -0.333 / 50 0.0 -0.667  IoU는 0으로 같지만 GIoU는 멀수록 작아짐

p = torch.tensor([[30., 0., 40., 10.]], requires_grad=True)
loss = generalized_box_iou_loss(p, gt)
loss.backward()
print(round(loss.item(), 3), p.grad[0, 0].item() > 0)    # 1.5 True  기울기 존재 → 왼쪽(GT 쪽)으로 이동

inner = torch.tensor([[2., 2., 6., 6.]]); inner2 = torch.tensor([[4., 4., 8., 8.]])
print([round(generalized_box_iou(gt, b).item(), 3) for b in (inner, inner2)])   # [0.16, 0.16]  포함되면 GIoU = IoU, 위치 구분 못 함
```
