# AP·mAP

## 정의·핵심
- **mAP (mean Average Precision)**: 실제 객체가 검출된 **재현율(Recall)의 변화에 따른 정밀도(Precision)** 를 평균한 성능 지표 — **객체 검출의 대표 종합 평가 지표** (응용 11차시)
- **검출에서의 Precision·Recall (강의)**
  - **Precision = TP / (TP + FP)**: 검출 예측한 결과가 실제 객체와 **얼마나 일치**하는가
  - **Recall = TP / (TP + FN)**: 실제 객체를 **빠뜨리지 않고** 얼마나 검출하는가
  - 예: 새 두 마리 중 하나를 정확히 Bird로 예측 → Precision 100%, Recall 50%
  - **TP 판정**: 같은 클래스 + **IoU ≥ 임계값(0.5)** + 그 GT에 처음 매칭된 예측 (중복 예측은 FP) → [[IoU]]
- **AP (Average Precision)**: **한 클래스**에 대한 성능 = **PR 곡선 아래 면적** → [[Precision-Recall 곡선(검출)]]
  - 계산 절차: 그 클래스의 모든 예측을 **confidence 내림차순** 정렬 → 하나씩 내려가며 누적 TP·FP로 P·R 계산 → 곡선
  - **보간 (강의 "오른쪽 최대 Precision 값을 연결")**: 각 recall에서 **그 이후(오른쪽)의 최대 precision**으로 지그재그를 평평하게 → 면적 계산
  - VOC2007: 11점(0, 0.1, …, 1) 보간 / VOC2010+·COCO: 모든 점(또는 101점) 보간
- **mAP**: **여러 클래스의 AP를 평균**한 값
- **VOC vs COCO (강의)**
  - **VOC**: IoU **0.5 고정** → **mAP@0.5** (= mAP50)
  - **COCO**: IoU를 **0.5 ~ 0.95 (0.05 간격, 10개)** 다양하게 → 평균 = **mAP@0.5:0.95** (= mAP50-95, 위치 정확도까지 엄격) + **크기별(Small/Medium/Large) mAP**
  - YOLO 결과표의 `mAP50`, `mAP50-95`가 바로 이것

## 수식·원리
```
AP = ∫₀¹ p_interp(r) dr,   p_interp(r) = max_{r' ≥ r} p(r')
mAP = (1/C) Σ_c AP_c
mAP@0.5:0.95 = (1/10) Σ_{t ∈ {0.5, 0.55, …, 0.95}} mAP@t
```

## 코드 예시
```python
import numpy as np

def average_precision(conf, is_tp, n_gt):
    order = np.argsort(-conf)
    tp = np.cumsum(is_tp[order]); fp = np.cumsum(1 - is_tp[order])
    rec, prec = tp / n_gt, tp / (tp + fp)
    r = np.concatenate([[0], rec, [1]]); p = np.concatenate([[1], prec, [0]])
    p = np.maximum.accumulate(p[::-1])[::-1]                  # 오른쪽 최대 precision으로 보간
    i = np.where(r[1:] != r[:-1])[0]
    return float(np.sum((r[i + 1] - r[i]) * p[i + 1])), rec, prec

conf = np.array([0.95, 0.9, 0.8, 0.7, 0.6, 0.5])
is_tp = np.array([1, 1, 0, 1, 0, 1])                          # IoU ≥ 0.5로 판정한 결과
ap, rec, prec = average_precision(conf, is_tp, n_gt=5)
print(np.round(rec, 2).tolist())                              # [0.2, 0.4, 0.4, 0.6, 0.6, 0.8]
print(np.round(prec, 2).tolist())                             # [1.0, 1.0, 0.67, 0.75, 0.6, 0.67]
print(round(ap, 3))                                           # 0.683  AP (클래스 1개)

aps = {"cat": ap, "dog": 0.6, "car": 0.8}
print(round(np.mean(list(aps.values())), 3))                  # 0.694  mAP = 클래스 AP 평균
print(np.round(np.arange(0.5, 0.96, 0.05), 2).tolist())       # COCO IoU 기준 10개
```
