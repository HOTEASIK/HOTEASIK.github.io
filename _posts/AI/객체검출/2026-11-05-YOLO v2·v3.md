# YOLO v2·v3

## 정의·핵심
- **YOLO v2 (2017, YOLO9000)**: v1의 정확도·위치 오차 문제를 여러 기법으로 개선 (대학원교안 14)
  - **Batch Normalization**: 모든 conv에 BN → mAP +2%
  - **High Resolution Classifier**: 224로 학습 후 **448로 ImageNet 10 epoch 미세조정** → mAP +4%
  - **FC 제거 + Anchor Box 도입**: 풀링 하나 제거, 입력 416 → **13×13** 출력(32배 다운샘플) / 앵커 없이 mAP 69.5%·recall 81% → 앵커로 **69.2%·recall 88%** (mAP 약간 ↓, **recall 크게 ↑**)
  - **Dimension Clusters**: 학습 데이터 GT 박스를 **K-means**로 클러스터링해 앵커 크기·비율 결정 — 유클리드 거리는 큰 박스가 오차를 더 만들어 부적합 → **거리 = 1 − IoU** / **k = 5**가 복잡도와 recall의 균형 (IoU 기반 5개(61.0%) ≈ Faster R-CNN 9개(60.9%))
  - **Direct location prediction**: 중심 = `σ(tx) + cx` → 셀 안에 묶어 학습 안정
  - **Fine-Grained Features (passthrough)**: 26×26×512 특징을 13×13×2048로 재배치해 concat → 작은 객체 mAP +1%
  - **Multi-Scale Training**: **10 배치마다** 입력 크기를 **{320, 352, …, 608}** 중 무작위 선택
  - **Darknet-19**: 19 conv + 5 maxpool, 1×1 conv 많이 사용 → ResNet-50급 정확도에 연산 적음
  - 출력(VOC): 앵커 5 × (5 + 20) = **125** 채널 → **13×13×125** (클래스 확률이 **박스마다** 존재)
- **YOLO v3 (2018)**
  - **3개 스케일에서 검출**: stride **32·16·8** → 416 입력 기준 **13×13, 26×26, 52×52** — 업샘플 후 앞 층(61, 36번째) 특징과 **concat**(FPN 개념) → [[FPN·PANet]]
  - 검출 커널 **1×1×(B×(5+C))**, COCO B = 3, C = 80 → **255**
  - **13×13은 큰 객체, 26×26은 중간, 52×52는 작은 객체** 담당 → v2의 작은 객체 문제 개선
  - 스케일마다 앵커 3개 → **총 9개**, 박스 수 416 기준 **10,647개** (v2 845개의 10배+)
  - **Softmax 대신 클래스별 logistic(sigmoid)** → 다중 라벨 가능 (Woman ⊂ Person)
  - **Darknet-53**: shortcut(잔차) 연결, ResNet-101보다 좋고 1.5배 빠름 / 검출용 53층을 더해 **106층**
  - 성능: YOLOv3-608 33.0% mAP·51ms vs RetinaNet 32.5%·73ms
- **v1·v2·v3 비교 (강의 표)**

| | v1 | v2 | v3 |
|---|---|---|---|
| Backbone | GoogLeNet 변형 | Darknet-19 | Darknet-53 |
| 앵커 | 없음 (셀당 박스 2) | 5개 (K-means) | 스케일당 3, 총 9 (K-means) |
| 출력 | 7×7 | 13×13 | 13·26·52 (FPN) |
| 출력 벡터 | 7×7×(5B + C) | 13×13×B(5+C) | 3스케일 × B(5+C) |
| 평가 | 빠르지만 정확도 낮음 | 속도·성능 모두 개선 | 약간 느려졌지만 성능 대폭 개선 |

## 수식·원리
```
v2 박스 디코딩:  bx = σ(tx) + cx,  by = σ(ty) + cy,  bw = pw·e^tw,  bh = ph·e^th
K-means 거리:    d = 1 − IoU(box, centroid)
v3 박스 수:      (13² + 26² + 52²) × 3 = 10,647
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)                                   # GT 박스 (w, h) — 세 가지 형태 군집
wh = np.concatenate([rng.normal([30, 60], 4, (100, 2)), rng.normal([120, 80], 8, (100, 2)), rng.normal([60, 30], 4, (100, 2))])

def iou_wh(a, b):                                                # 중심을 맞춘 IoU (w, h만)
    inter = np.minimum(a[:, None, 0], b[None, :, 0]) * np.minimum(a[:, None, 1], b[None, :, 1])
    return inter / (a[:, None].prod(2) + b[None].prod(2) - inter)

k = 3
cent = wh[rng.choice(len(wh), k, replace=False)]
for _ in range(20):                                              # K-means, 거리 = 1 − IoU
    assign = (1 - iou_wh(wh, cent)).argmin(1)
    cent = np.array([wh[assign == i].mean(0) for i in range(k)])
print(np.round(cent[np.argsort(cent[:, 0])]).astype(int).tolist())   # [[30, 60], [60, 30], [119, 80]]  세 군집 중심 = 앵커 크기

print([s // st for s in (416,) for st in (32, 16, 8)])           # [13, 26, 52]
print(sum((416 // st) ** 2 * 3 for st in (32, 16, 8)), 3 * (5 + 80))   # 10647 255
sig = lambda t: 1 / (1 + np.exp(-t))
print(round(sig(0.5) + 4, 3))                                    # 4.622  셀(4) 안으로 묶인 중심
```
