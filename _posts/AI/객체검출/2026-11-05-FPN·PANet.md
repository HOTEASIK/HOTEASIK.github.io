# FPN·PANet

## 정의·핵심
- **핵심 문제 (응용 12차시)**: 깊은 신경망은 **추상적인 의미(Semantic) 정보는 강하지만, 작은 객체의 위치(Spatial) 정보는 손실** / 얕은 층은 위치는 정확하지만 의미가 약함 → 여러 층의 특징을 **융합**해야 모든 크기의 객체를 잘 검출
- **FPN (Feature Pyramid Network, 2017)**
  - CNN의 여러 레벨 특징을 종합하는 **multi-layer feature fusion** 기법 (대학원교안 YOLOv3)
  - **Top-down**: 상위(깊은, 작은) 특징을 **업샘플링**해 하위 레벨 크기로 키운 뒤 **lateral(1×1 conv) 특징과 더함** → 저수준 맵에서도 객체 종류를 정확히 파악
  - 각 레벨(P3~P5 등)에서 **따로 예측** → 작은 객체는 큰 맵, 큰 객체는 작은 맵
  - YOLO v3: 업샘플 후 앞 층 특징과 **concat**해 13·26·52 세 스케일 검출 → [[YOLO v2·v3]]
- **PAN (Path Aggregation Network, 2018)**
  - FPN에 **역방향 Bottom-up 경로**를 추가 → 하위 계층의 **정교한 위치 정보를 상위 계층에 다시 전달** (경로가 짧아져 위치 정보가 덜 소실)
  - YOLO v4는 덧셈 대신 **concat**으로 바꾼 PAN 사용
- **PAN-FPN (YOLO v5·v8의 Neck, 강의)**: **양방향 융합** — 강의 비유 "**의미는 내리고(FPN ↓), 위치는 올린다(PAN ↑)**", 양방향 정보 고속도로
- **레벨별 담당 (강의, 640 입력)**

| 레벨 | 크기 | stride | 담당 객체 |
|---|---|---|---|
| **P3** | 80×80 | 8 | **작은 객체** (8~32px, 멀리 있는 사물, 고해상도 특징) |
| **P4** | 40×40 | 16 | **중간 객체** (32~96px) |
| **P5** | 20×20 | 32 | **큰 객체** (96px+, 저해상도, 강한 의미 정보) |

- 변형: BiFPN(EfficientDet, 가중 양방향), NAS-FPN / Faster R-CNN + FPN(RPN을 각 레벨에서) → [[Faster R-CNN]]

## 수식·원리
```
FPN (top-down):  P5 = L5(C5),  P4 = L4(C4) + Up(P5),  P3 = L3(C3) + Up(P4)
PAN (bottom-up): N3 = P3,  N4 = P4 + Down(N3),  N5 = P5 + Down(N4)
L = 1×1 conv (lateral),  Up = 2× 업샘플,  Down = stride 2 conv
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PANFPN(nn.Module):
    def __init__(self, chs=(64, 128, 256), c=64):
        super().__init__()
        self.lat = nn.ModuleList(nn.Conv2d(ch, c, 1) for ch in chs)
        self.down = nn.ModuleList(nn.Conv2d(c, c, 3, 2, 1) for _ in range(2))
    def forward(self, c3, c4, c5):
        p5 = self.lat[2](c5)
        p4 = self.lat[1](c4) + F.interpolate(p5, scale_factor=2)   # FPN: 의미를 아래로
        p3 = self.lat[0](c3) + F.interpolate(p4, scale_factor=2)
        n3 = p3
        n4 = p4 + self.down[0](n3)                                # PAN: 위치를 위로
        n5 = p5 + self.down[1](n4)
        return n3, n4, n5

c3, c4, c5 = torch.randn(1, 64, 80, 80), torch.randn(1, 128, 40, 40), torch.randn(1, 256, 20, 20)
outs = PANFPN()(c3, c4, c5)
print([tuple(o.shape[1:]) for o in outs])     # [(64, 80, 80), (64, 40, 40), (64, 20, 20)]  P3·P4·P5
for st, o in zip((8, 16, 32), outs):
    print(f"P{st.bit_length() - 1}: stride {st}, 셀 하나 = {st}px")
```
