# Default Box 스케일·종횡비

## 정의·핵심
- **Default Box**: SSD에서 각 특징 맵의 **셀마다 미리 정의한 고정 크기·비율의 박스** (= Anchor). 네트워크는 이 박스들의 **오프셋과 클래스 점수**를 예측 (응용 13차시) → [[Anchor Box(Default Box)]]
- **스케일 공식 (강의)**: `s_k = s_min + (s_max − s_min) / (m − 1) × (k − 1)`
  - **s_min = 0.2**: 최하위 레이어(Conv4_3) 스케일 — **이미지의 20%** 크기 박스 → 작은 객체
  - **s_max = 0.9**: 최상위 레이어(Conv11_2) 스케일 — **이미지의 90%** → 큰 객체
  - **m**: 특징 맵 총 개수 (**SSD300 = 6**), **k**: 현재 맵 인덱스 (1 ~ m)
  - → 낮은 레이어는 작은 객체, 높은 레이어는 큰 객체를 담당하도록 **등간격**으로 배분
- **종횡비 (Aspect Ratio, 강의)**: 셀마다 다양한 비율의 박스 → 여러 형태의 객체 대응 (기본 4~6개)
  - **1:1**(정사각형), **2:1**(가로로 긴), **3:1**(아주 가로로 긴), **1:2**(세로로 긴), **1:3**(아주 세로로 긴)
  - **추가 1:1**: 스케일 `s'_k = √(s_k · s_{k+1})`인 조금 더 큰 정사각형
  - 크기: `w = s_k × √ar`, `h = s_k / √ar` (넓이 유지)
  - **6개 맵 중 4개는 6박스**(1, 2, 3, 1/2, 1/3, 1'), **Conv4_3·Conv10_2·Conv11_2는 4박스**(3:1, 1:3 제외)
- **SSD300 박스 분포 — 총 8,732개 (강의 표)**

| 특징 맵 | 해상도 | 셀당 박스 | 총 박스 |
|---|---|---|---|
| Conv4_3 | 38×38 | 4 | **5,776** |
| Conv7 | 19×19 | 6 | 2,166 |
| Conv8_2 | 10×10 | 6 | 600 |
| Conv9_2 | 5×5 | 6 | 150 |
| Conv10_2 | 3×3 | 4 | 36 |
| Conv11_2 | 1×1 | 4 | 4 |
| **합계** | | | **8,732** |

- **중심 위치**: 셀 (i, j)의 중심 `((i + 0.5)/f_k, (j + 0.5)/f_k)` (0~1 정규화)
- **주의 (강의 한계)**: 스케일·비율 설정이 **데이터셋 특성에 크게 의존** → K-means로 데이터에 맞는 비율 분석 권장

## 수식·원리
```
s_k = 0.2 + (0.9 − 0.2)/(6 − 1) · (k − 1) = 0.2, 0.34, 0.48, 0.62, 0.76, 0.9
w = s_k·√ar,  h = s_k/√ar,   ar ∈ {1, 2, 3, 1/2, 1/3}
추가: s'_k = √(s_k·s_{k+1}),  ar = 1
```

## 코드 예시
```python
import math

m, s_min, s_max = 6, 0.2, 0.9
s = [s_min + (s_max - s_min) / (m - 1) * (k - 1) for k in range(1, m + 1)]
print([round(v, 2) for v in s])                             # [0.2, 0.34, 0.48, 0.62, 0.76, 0.9]

def boxes_for(k, ratios):                                   # k: 0부터
    out = [(s[k] * math.sqrt(r), s[k] / math.sqrt(r)) for r in ratios]
    s_next = s[k + 1] if k + 1 < m else 1.0
    out.append((math.sqrt(s[k] * s_next),) * 2)             # 추가 1:1
    return out

b = boxes_for(1, [1, 2, 3, 1 / 2, 1 / 3])                   # Conv7: 6개
print(len(b), [tuple(round(v * 300) for v in wh) for wh in b])   # 6 [(102, 102), (144, 72), (177, 59), (72, 144), (59, 177), (121, 121)]

fmap = [38, 19, 10, 5, 3, 1]
per = [4, 6, 6, 6, 4, 4]
print([f * f * k for f, k in zip(fmap, per)], sum(f * f * k for f, k in zip(fmap, per)))   # [5776, 2166, 600, 150, 36, 4] 8732
```
