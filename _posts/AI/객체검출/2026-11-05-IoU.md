# IoU

## 정의·핵심
- **정의**: IoU (Intersection over Union). 모델이 **예측한 박스와 Ground Truth 박스가 얼마나 겹치는지**를 나타내는 지표 = **교집합 넓이 / 합집합 넓이** (응용 11차시 "검출 정확도 평가 핵심")
  - 범위 **0 ~ 1**: 0 = 전혀 안 겹침, 1 = 완전히 일치
- **쓰임 (강의)**
  - **검출 성공 판단**: 개별 객체 검출이 성공했는지를 IoU로 판단 — **PASCAL VOC는 IoU ≥ 0.5**면 성공(TP) → [[AP·mAP]]
  - COCO는 0.5~0.95(0.05 간격) 여러 기준의 평균 → mAP@0.5:0.95
  - **NMS**: 같은 객체에 대한 중복 박스 판정 (IoU > 임계값이면 제거) → [[NMS(Non-Maximum Suppression)]]
  - **앵커 매칭**: 앵커·Default Box와 GT의 IoU로 양성/음성 결정 → [[Default Box Matching]]
  - **손실 함수**: `1 − IoU` → [[GIoU]], [[DIoU·CIoU]]
- **계산 (강의 코드 방식)**: 중심 형식 `(x, y, w, h)` → 좌상단 `(x − 0.5w, y − 0.5h)`, 우하단 `(x + 0.5w, y + 0.5h)`로 변환 → 교집합 좌상단 = 두 좌상단의 **max**, 우하단 = 두 우하단의 **min** → 폭·높이가 음수면 0 (안 겹침)
- **한계**: **안 겹치면 거리와 상관없이 항상 0** → 얼마나 틀렸는지 알 수 없고 손실로 쓰면 기울기 0 → **GIoU**가 보완 (강의)
- **작은 객체에 엄격**: 몇 픽셀만 어긋나도 IoU가 크게 떨어짐
- torchvision: `torchvision.ops.box_iou(boxes1, boxes2)` → (N, M) 행렬 (xyxy 형식)

## 수식·원리
```
IoU = |A ∩ B| / |A ∪ B| = I / (|A| + |B| − I)
교집합:  x1 = max(ax1, bx1),  y1 = max(ay1, by1)
         x2 = min(ax2, bx2),  y2 = min(ay2, by2)
I = max(0, x2 − x1) · max(0, y2 − y1)
```

## 코드 예시
```python
import torch
from torchvision.ops import box_iou

def iou_cxcywh(a, b):                                     # 강의 방식: 중심 형식 입력
    a1, a2 = a[:2] - a[2:] / 2, a[:2] + a[2:] / 2         # left_up, right_down
    b1, b2 = b[:2] - b[2:] / 2, b[:2] + b[2:] / 2
    lu, rd = torch.maximum(a1, b1), torch.minimum(a2, b2)
    wh = (rd - lu).clamp(min=0)                           # 안 겹치면 0
    inter = wh[0] * wh[1]
    return inter / (a[2] * a[3] + b[2] * b[3] - inter)

gt = torch.tensor([50., 50., 40., 40.])
pred = torch.tensor([60., 50., 40., 40.])                 # 오른쪽으로 10 어긋남
print(round(iou_cxcywh(gt, pred).item(), 3))              # 0.6  → VOC 기준(≥0.5) 성공
far = torch.tensor([200., 50., 40., 40.])
print(iou_cxcywh(gt, far).item())                         # 0.0  거리와 상관없이 0

A = torch.tensor([[0., 0., 10., 10.], [5., 5., 15., 15.]])  # xyxy
B = torch.tensor([[0., 0., 10., 10.], [20., 20., 30., 30.]])
print([[round(v, 3) for v in r] for r in box_iou(A, B).tolist()])   # [[1.0, 0.0], [0.143, 0.0]]  (N, M) 행렬
```
