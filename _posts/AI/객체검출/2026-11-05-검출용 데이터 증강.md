# 검출용 데이터 증강

## 정의·핵심
- **분류 증강과의 차이 (보충 3_1)**: 검출에서는 이미지를 바꾸면 **박스도 함께** 바꿔야 한다
  - **기하 변환**(뒤집기·이동·확대·회전·크롭): 이미지와 박스 **둘 다** 변환
  - **색 변환**(밝기·대비·HSV): 이미지만 변하고 **박스는 그대로**
  - 좌우 반전 시 정규화 좌표: **`cx → 1 − cx`**, cy·w·h는 그대로 (연습 문제 4)
- **YOLO v8의 증강 (응용 12차시 "Strong Augmentation")**
  - **HSV**: `hsv_h, hsv_s, hsv_v` (색상·채도·명도 변형)
  - 기하: `translate`(이동), `scale`(크기), `degrees`(회전), `fliplr`
  - 강하게 적용해 **강인함(Robustness)** 확보
- **Mosaic (강의)**: **4장의 이미지를 모자이크처럼 이어 붙여** 새 이미지 생성
  - 다양한 크기(Scale)의 객체·배경·맥락을 한 번에 학습 → 일반화 ↑
  - **소형 객체 검출력 ↑**, 한 장에 4장의 객체가 들어가 **배치 크기 의존도 ↓** (YOLO v4·v5부터) → [[YOLO v5]]
  - 마지막 몇 epoch는 끔(`close_mosaic=10`) → 실제 분포에 맞춰 마무리
- **MixUp (강의)**: **두 이미지를 섞어(Blend)** 새 이미지 → 박스는 둘 다 유지 → 더 부드러운 결정 경계
- **Copy-Paste (강의)**: 이미지 내 **객체를 복사해 다른 곳에 붙여** Hard Sample을 인위적으로 생성 → 작은 객체·가려진 객체 검출 능력 ↑ (분할 마스크가 필요)
- 그 밖: **CutMix**, Random Crop·Zoom In/Out(SSD에서 성능에 결정적, 13차시), Letterbox(비율 유지 리사이즈 + 패딩)
- **주의**
  - 증강 후 **이미지 밖으로 나간 박스는 clip**, 너무 작아진 박스는 제거
  - 회전은 축 정렬 박스를 키우는 경향 → 작은 각도만
  - 증강은 **학습 데이터에만**, 검증·테스트에는 적용하지 않음
- 도구: ultralytics 내장, **Albumentations**(`bbox_params`로 박스 자동 변환), torchvision `transforms.v2`(`BoundingBoxes` 지원)

## 수식·원리
```
좌우 반전 (정규화): cx' = 1 − cx           (픽셀: x1' = W − x2, x2' = W − x1)
상하 반전:          cy' = 1 − cy
크기 s배 + 이동 (tx, ty):  x' = s·x + tx  (박스 모서리 모두)
MixUp:  I = λ·I₁ + (1 − λ)·I₂,  박스 = B₁ ∪ B₂
```

## 코드 예시
```python
import numpy as np

def hflip(img, boxes):                                   # boxes: YOLO (cls, cx, cy, w, h)
    b = boxes.copy(); b[:, 1] = 1 - b[:, 1]
    return img[:, ::-1], b

def mosaic(imgs, boxes_list, S=320):                     # 4장 → 1장 (각 사분면에 축소 배치)
    out = np.zeros((2 * S, 2 * S, 3), np.uint8); new = []
    for k, (im, bx) in enumerate(zip(imgs, boxes_list)):
        oy, ox = (k // 2) * S, (k % 2) * S
        ys = np.linspace(0, im.shape[0] - 1, S).astype(int); xs = np.linspace(0, im.shape[1] - 1, S).astype(int)
        out[oy:oy + S, ox:ox + S] = im[ys][:, xs]        # 최근접 리사이즈
        for c, cx, cy, w, h in bx:
            new.append([c, (ox + cx * S) / (2 * S), (oy + cy * S) / (2 * S), w / 2, h / 2])
    return out, np.array(new)

img = np.zeros((100, 200, 3), np.uint8)
boxes = np.array([[0, 0.2, 0.5, 0.1, 0.2]])
_, fb = hflip(img, boxes)
print(fb.tolist())                                       # [[0.0, 0.8, 0.5, 0.1, 0.2]]  cx → 1 − cx

m, mb = mosaic([img] * 4, [boxes] * 4)
print(m.shape, len(mb), np.round(mb[3], 3).tolist())     # (640, 640, 3) 4 [0.0, 0.6, 0.75, 0.05, 0.1]

a, b = np.full((4, 4), 200.), np.full((4, 4), 100.)
lam = 0.7
print((lam * a + (1 - lam) * b)[0, 0])                   # 170.0  MixUp 픽셀
```
