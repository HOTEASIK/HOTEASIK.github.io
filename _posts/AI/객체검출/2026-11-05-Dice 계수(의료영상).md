# Dice 계수(의료영상)

## 정의·핵심
- **정의**: Dice 계수(Dice Similarity Coefficient, DSC, = F1 Score의 집합 버전). 예측 마스크와 정답 마스크의 **겹침 정도**를 `2·|A∩B| / (|A| + |B|)`로 나타낸 지표. 범위 0~1, 1 = 완전 일치 — **의료영상 분할의 표준 평가 지표** (응용 13차시 의료영상 분석 맥락)
- **IoU(Jaccard)와 관계**
  - `Dice = 2·IoU / (1 + IoU)`, `IoU = Dice / (2 − Dice)` → **단조 관계**(순위는 같음)
  - 같은 결과에서 **Dice ≥ IoU** (예: IoU 0.5 → Dice 0.667) → 논문 비교 시 어떤 지표인지 확인
  - 혼동행렬로: `Dice = 2TP / (2TP + FP + FN)` = **픽셀 단위 F1** → [[F1 Score]]
- **왜 의료영상에서 많이 쓰나**
  - 병변(종양·결절)은 **영상 전체에서 아주 작은 비율** → 픽셀 정확도(accuracy)는 "전부 정상"이라고 해도 99% → 의미 없음
  - Dice는 **배경(TN)을 계산에서 빼므로** 작은 대상의 분할 품질을 제대로 반영
- **Dice Loss**: `L = 1 − Dice` (확률 마스크로 계산하는 **Soft Dice**, 분모에 ε) → **클래스 불균형에 강함** → 흔히 **BCE + Dice**를 합쳐 사용 (BCE는 픽셀별 안정적 기울기, Dice는 영역 겹침)
- **주의**
  - 예측·정답이 **모두 비어 있으면** 0/0 → ε 처리 또는 1로 정의
  - 작은 병변은 몇 픽셀 차이로 Dice가 크게 변함 → **경계 지표(Hausdorff Distance, HD95)** 를 함께 보고
  - 다중 클래스는 클래스별 Dice 평균(배경 제외)
- 검출에서의 대응: 박스는 **IoU**, 마스크는 **mask IoU / Dice** → [[IoU]], [[Instance Segmentation]]

## 수식·원리
```
Dice = 2|A ∩ B| / (|A| + |B|) = 2TP / (2TP + FP + FN)
IoU  = |A ∩ B| / |A ∪ B|       = TP / (TP + FP + FN)
Dice = 2·IoU / (1 + IoU)
Soft Dice Loss = 1 − (2 Σ p·g + ε) / (Σ p + Σ g + ε)
```

## 코드 예시
```python
import numpy as np
import torch

def dice(a, b, eps=1e-7):
    inter = (a & b).sum()
    return (2 * inter + eps) / (a.sum() + b.sum() + eps)
def iou(a, b, eps=1e-7):
    return ((a & b).sum() + eps) / ((a | b).sum() + eps)

gt = np.zeros((100, 100), bool); gt[40:50, 40:50] = True       # 작은 병변 100px
pred = np.zeros_like(gt); pred[42:52, 42:52] = True            # 2px 어긋난 예측
d, j = dice(pred, gt), iou(pred, gt)
print(round(float(d), 3), round(float(j), 3), round(float(2 * j / (1 + j)), 3))   # 0.64 0.471 0.64  Dice = 2IoU/(1+IoU)
empty = np.zeros_like(gt)
print(round(float((empty == gt).mean()), 2), round(float(dice(empty, gt)), 3))   # 0.99 0.0  정확도 99%지만 Dice 0

def soft_dice_loss(p, g, eps=1.0):
    return 1 - (2 * (p * g).sum() + eps) / (p.sum() + g.sum() + eps)
g = torch.from_numpy(gt).float()
p = torch.full_like(g, 0.01, requires_grad=True)
loss = soft_dice_loss(p, g) + torch.nn.functional.binary_cross_entropy(p, g)   # BCE + Dice
loss.backward()
print(round(soft_dice_loss(p, g).item(), 3), p.grad[45, 45].item() < 0)       # 0.985 True  병변 픽셀 확률을 올리는 방향
```
