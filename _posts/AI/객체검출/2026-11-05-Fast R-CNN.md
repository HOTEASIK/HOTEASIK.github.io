# Fast R-CNN

## 정의·핵심
- **정의**: Fast R-CNN (2015, Girshick). R-CNN의 가장 큰 비효율(2000개 영역마다 CNN 실행)을 없앤 개선판 — **핵심 개선: 전체 이미지를 CNN에 1회만 통과** (응용 11차시)
- **동작 (강의)**
  1. **전체 이미지 → CNN(VGG16) 1회** → 공유 **feature map**
  2. Selective Search 후보(RoI)를 feature map 좌표로 **투영(RoI projection)** (stride로 나눔)
  3. **RoI Pooling**으로 각 RoI 영역을 **고정 크기(7×7×d)** 특징으로 변환
  4. FC 층 → 두 갈래: **Softmax 분류**(K+1 클래스, 배경 포함) + **Bounding Box Regression**
- **RoI Pooling (강의)**: Feature map의 RoI를 **미리 정해 놓은 H×W 격자로 나누고 각 칸에서 max pooling** → **크기에 상관없이 고정된 벡터**로 표현 → FC에 넣을 수 있음
  - 강의 예: 채널마다 독립적으로, 격자 칸의 최댓값만 추출 (3×4 = 12칸이면 출력 12개 × 채널 수)
  - 크기가 다른 영역을 warp 없이 처리 → 왜곡 문제 해결
- **Multi-task Loss**: `L = L_cls + λ·[u ≥ 1]·L_loc` — 분류(CE) + 박스(**Smooth L1**)를 **하나의 네트워크로 함께 학습** (배경 RoI는 박스 손실 제외) → SVM·별도 회귀 제거
- **R-CNN 대비**: 학습 약 9배, 추론 약 200배 빨라짐, 정확도도 상승
- **남은 병목**: 후보 생성인 **Selective Search가 CPU에서 이미지당 ~2초** → 전체 속도의 병목 → **Faster R-CNN의 RPN** → [[Faster R-CNN]]
- 후속: **RoI Align**(Mask R-CNN) — RoI Pooling의 좌표 반올림(양자화) 오차를 **양선형 보간**으로 제거 → [[Mask R-CNN(언급)]]

## 수식·원리
```
RoI (h × w) → H×W 격자, 각 칸 크기 ≈ (h/H) × (w/W) → 칸별 max
L = CE(p, u) + λ·[u ≥ 1]·Σ smoothL1(t^u_i − v_i)
CNN 비용: R-CNN 2000회 → Fast R-CNN 1회
```

## 코드 예시
```python
import torch
from torchvision.ops import roi_pool, roi_align

fmap = torch.arange(1, 1 + 1 * 2 * 8 * 8, dtype=torch.float32).reshape(1, 2, 8, 8)   # 채널 2, 8x8
rois = torch.tensor([[0, 0., 0., 63., 31.],                 # (batch_idx, x1, y1, x2, y2) — 원본 좌표
                     [0, 16., 16., 63., 63.]])
out = roi_pool(fmap, rois, output_size=(2, 2), spatial_scale=1 / 8)   # stride 8로 투영
print(tuple(out.shape))                                      # (2, 2, 2, 2)  RoI 크기와 무관하게 2x2
print(out[0, 0].tolist())                                    # [[21.0, 24.0], [37.0, 40.0]]  격자 칸별 최댓값
ra = roi_align(fmap, rois, output_size=(7, 7), spatial_scale=1 / 8, sampling_ratio=2)
print(tuple(ra.shape))                                       # (2, 2, 7, 7)  RoI Align (보간, 양자화 없음)
flat = out.flatten(1)
print(tuple(flat.shape))                                     # (2, 8)  → FC → 분류 + 박스 회귀
```
