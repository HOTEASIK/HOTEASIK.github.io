# CSP 구조

## 정의·핵심
- **정의**: CSP (Cross Stage Partial Network, CSPNet 2019). 특징 맵을 **채널 방향으로 두 파트로 나눠(Split)**, **한 파트만 무거운 블록(Dense/Residual)을 통과**시키고 **다른 파트는 우회**시킨 뒤 **합치는(Merge)** 구조 (응용 12차시)
- **핵심 원리 (강의)**
  - **Split & Merge (분할과 병합)**: 입력 특징을 두 파트로 → 하나는 연산(Conv), 다른 하나는 우회 → 나중에 concat
  - **Gradient 중복 방지**: DenseNet 등에서 같은 기울기 정보가 여러 층에 **중복 복사**되는 문제 → 경로를 나눠 **역전파 시 중복 기울기 감소**, 학습 효율 ↑
  - **연산량 감소**: 절반 채널만 블록을 통과 → FLOPs·메모리 ↓ (정확도는 유지 또는 ↑)
  - 강의 비유: **고속도로 분기 차선** — 꽉 막힌 1차선 대신 본선(연산)과 추월차선(우회)으로 나눠 달린 후 합류하면 흐름(학습)이 원활
- **YOLO에서의 사용**
  - **v4·v5: CSPDarknet53** 백본 → [[YOLO v4]], [[YOLO v5]]
  - v5의 **C3 모듈**: 한 갈래는 1×1 conv → Bottleneck n개, 다른 갈래는 1×1 conv만 → concat → 1×1 conv
  - **v8의 C2f**: Split 후 Bottleneck을 거친 **각 단계 출력을 모두 concat** → 더 풍부한 Gradient Flow (`y = Concat(x₁, Block(x₂), …)`) → [[YOLO v8]]
  - YOLO11의 C3k2도 같은 계열
- **Residual과 차이**: Residual은 `x + F(x)`(같은 채널 전체를 더함) / CSP는 **채널 일부만 변환하고 나머지는 그대로 이어붙임**(concat)
- **효과**: 같은 정확도에서 연산량 약 10~20% 절감(CSPNet 논문), 경량 모델에서 특히 유리

## 수식·원리
```
x → [x₁ | x₂]  (채널 절반씩)
CSP:  y = Transition( Concat( x₁, Block(x₂) ) )
C2f:  y = Conv( Concat( x₁, x₂, B₁(x₂), B₂(B₁(x₂)), … ) )
연산량 ≈ Block(C/2 채널)  vs  Block(C 채널)
```

## 코드 예시
```python
import torch
import torch.nn as nn

def blk(c):
    return nn.Sequential(nn.Conv2d(c, c, 3, 1, 1, bias=False), nn.BatchNorm2d(c), nn.SiLU())

class Plain(nn.Module):                                 # 전체 채널이 블록 통과
    def __init__(self, c, n=3):
        super().__init__(); self.m = nn.Sequential(*[blk(c) for _ in range(n)])
    def forward(self, x): return self.m(x)

class CSP(nn.Module):                                   # 절반만 블록, 절반은 우회 → concat
    def __init__(self, c, n=3):
        super().__init__()
        self.m = nn.Sequential(*[blk(c // 2) for _ in range(n)])
        self.t = nn.Conv2d(c, c, 1)
    def forward(self, x):
        x1, x2 = x.chunk(2, 1)                          # Split
        return self.t(torch.cat([x1, self.m(x2)], 1))   # Merge

n = lambda m: sum(p.numel() for p in m.parameters())
x = torch.randn(1, 128, 40, 40)
print(tuple(Plain(128)(x).shape), tuple(CSP(128)(x).shape))   # (1, 128, 40, 40) (1, 128, 40, 40)  같은 출력 크기
print(n(Plain(128)), n(CSP(128)))                       # 443136 127488  CSP가 파라미터 훨씬 적음
```
