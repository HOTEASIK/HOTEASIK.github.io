# 검출 데이터셋

## 정의·핵심
- 객체 검출 데이터셋 = **이미지 + 객체별 (클래스, 바운딩 박스) 라벨**. 대표 벤치마크는 **Pascal VOC**와 **MS COCO** (응용 11차시 "주요 데이터셋 비교")
- **Pascal VOC (강의)**
  - 클래스 **20개** (person, car, dog, aeroplane …)
  - 이미지(train + val) **약 20k장**, 이미지당 평균 객체 **2.4개**
  - 라벨: 이미지마다 **XML** 파일 (`xmin ymin xmax ymax`, 픽셀) → [[라벨 형식]]
  - 평가: **mAP@0.5** (IoU 0.5 고정)
- **MS COCO (강의)**
  - 클래스 **80개**
  - 이미지(train + val) **약 120k장**, 이미지당 평균 객체 **7.2개** (작고 밀집된 객체가 많아 더 어려움)
  - 라벨: 하나의 **JSON**(`images`, `annotations`, `categories`), 박스는 `[x, y, w, h]`(좌상단 + 크기, 픽셀). 분할 마스크(polygon/RLE)와 키포인트도 포함
  - 평가: **mAP@0.5:0.95**(IoU 0.5~0.95 평균) + 크기별 AP(Small < 32², Medium, Large > 96²) → [[AP·mAP]]
- **과제(11차시) 문항 2**: VOC는 IoU 0.5 이상을 정답으로 보고, COCO는 **IoU 0.5부터 0.95까지 0.05 간격 10개 임계값의 mAP를 평균**
- **실습·커스텀 데이터 예 (강의)**
  - Racoon 데이터셋(단일 클래스)
  - **Safety Helmet**(Kaggle, head·helmet·person 3클래스, XML → YOLO txt 변환)
  - **coco8**(이미지 8장짜리 실습용 미니 COCO, ultralytics 자동 다운로드)
- 그 밖: Open Images(600클래스), Objects365, KITTI·nuScenes(자율주행), VisDrone(드론·소형 객체)
- **COCO 클래스 번호 주의**: COCO 원본 id는 1~90(중간 빈 번호 있음, 91 슬롯) → torchvision 검출 모델 `num_classes=91` / YOLO는 0~79로 재번호

## 수식·원리
```
VOC:  20 클래스,  ~20k장,  2.4 객체/장,  mAP@0.5
COCO: 80 클래스, ~120k장,  7.2 객체/장,  mAP@[.5:.95] + AP_S/M/L
COCO 크기 기준:  small < 32²,  medium 32²~96²,  large > 96²  (픽셀 넓이)
```

## 코드 예시
```python
import json

coco = {                                                    # COCO JSON 최소 구조
    "images": [{"id": 1, "file_name": "a.jpg", "width": 640, "height": 480}],
    "annotations": [{"id": 10, "image_id": 1, "category_id": 18, "bbox": [100, 120, 50, 40], "area": 2000, "iscrowd": 0},
                    {"id": 11, "image_id": 1, "category_id": 1, "bbox": [300, 50, 120, 300], "area": 36000, "iscrowd": 0}],
    "categories": [{"id": 1, "name": "person"}, {"id": 18, "name": "dog"}],
}
s = json.dumps(coco)
d = json.loads(s)
names = {c["id"]: c["name"] for c in d["categories"]}
def size_group(a):
    return "small" if a < 32 ** 2 else "medium" if a < 96 ** 2 else "large"
for a in d["annotations"]:
    x, y, w, h = a["bbox"]
    print(names[a["category_id"]], [x, y, x + w, y + h], size_group(w * h))
# dog [100, 120, 150, 160] medium / person [300, 50, 420, 350] large
print(round(2.4 * 20000), round(7.2 * 120000))              # 48000 864000  대략적인 전체 객체 수
```
