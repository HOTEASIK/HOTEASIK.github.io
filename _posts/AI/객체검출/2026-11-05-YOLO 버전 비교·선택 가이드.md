# YOLO 버전 비교·선택 가이드

## 정의·핵심
- **진화 흐름 (응용 12차시 핵심 정리)**: '속도 유지'라는 대원칙 아래 **정확도(v5) → 구조적 유연함(v8) → 효율적 종단학습(v10)** — **Anchor(v5) → Anchor-Free(v8) → NMS-Free(v10)**
- **타임라인 (강의)**: 2016~18 v1/v2/v3 (Darknet, Multi-scale) → 2020.04 **v4** (CSPNet, Bag of Freebies) → 2020.06 **v5** → 2022 v6/v7 (RepVGG, E-ELAN) → 2023.01 **v8** → 2024.05 **v10** (→ 2024.09 YOLO11)
- **v5 / v8 / v10 비교표 (강의)**

| 항목 | YOLO v5 (안정성) | YOLO v8 (표준·범용) | YOLO v10 (초고속·효율) |
|---|---|---|---|
| 아키텍처 | CSP + PANet | C2f + PAN-FPN | CIB + Partial SA |
| 앵커 | **Anchor-Based** | **Anchor-Free** | Anchor-Free |
| 헤드 | Coupled | Decoupled | Decoupled |
| 후처리 | NMS 필수 | NMS 필수 | **NMS-Free** |
| 손실 | GIoU / CIoU | CIoU + Focal + DFL | Dual Assignment |
| mAP (s) | 37.4 | 44.9 | 46.3 |
| Params (s) | 7.2M | 11.1M | 8.0M |
| 추천 | 레거시 호환, 튜닝 자유도 | 고성능, 쉬운 학습·배포 | 엣지, 최소 지연 |

- **산업별 선택 가이드 (강의)** — "현장의 제약(리스크·연산·전력)에 맞춘 선택이 성능의 50%"
  - **자율주행**: **v8 / v10 (L/M)** — 앵커프리·NMS-Free가 밀집 객체에 유리, v10은 후처리 제거로 지연 극소화
  - **의료 영상**: **v8 (L/X)** — 정확도 최우선, **미검출(FN) 방지**가 핵심, Focal Loss가 불균형(정상 vs 질병)에 효과적
  - **보안 CCTV**: **v5 (M) 또는 v8 (S)** — 24시간 서버 부하 고려한 중소형, v5는 배포 안정성이 높아 레거시 통합에 유리
  - **모바일·엣지**: **v5n / v8n / v10n (Nano)** — 배터리·발열·메모리 제약, v10n은 CIB로 적은 연산 대비 높은 mAP
- **크기 선택 일반 원칙**: 먼저 **지연(ms)·메모리 예산**을 정하고 그 안에서 mAP가 가장 높은 것 → 작은 모델부터 시작해 부족하면 키움
- **주의**: 표의 mAP는 COCO 기준 — **내 데이터에서 직접 검증**해야 함, 배포 형식(ONNX·TensorRT)까지 포함해 속도 측정 → [[모델 배포]]

## 수식·원리
```
선택 = argmax_model mAP(model)  s.t.  latency(model, HW) ≤ 예산,  memory ≤ 예산
진화:  Anchor-Based (v2~v5) → Anchor-Free (v8) → NMS-Free (v10)
```

## 코드 예시
```python
table = {                      # (mAP, Params M, NMS 필요, Anchor-Free)
    "v5s": (37.4, 7.2, True, False),
    "v8s": (44.9, 11.1, True, True),
    "v10s": (46.3, 8.0, False, True),
}
def pick(max_params=None, need_nms_free=False):
    c = {k: v for k, v in table.items()
         if (max_params is None or v[1] <= max_params) and (not need_nms_free or not v[2])}
    return max(c, key=lambda k: c[k][0]) if c else None

print(pick())                                    # v10s  제약 없으면 최고 mAP
print(pick(max_params=8))                        # v10s
print(pick(max_params=7.5))                      # v5s   파라미터 예산이 작으면
print(pick(need_nms_free=True))                  # v10s  배포 시 NMS 플러그인 회피
for k, (m, p, *_ ) in table.items():
    print(k, round(m / p, 2))                    # v5s 5.19 / v8s 4.05 / v10s 5.79  파라미터당 mAP
```
