# 라벨 오류 점검

## 정의·핵심
- **문제 (보충 09 auto_detect)**: 라벨이 오염되면 모델이 틀린 것을 배운다. 하지만 **수동 검토는 한계** — 952장 약 8시간, 10,000장 약 83시간(약 2주), 100,000장 약 833시간(약 20주)
- **한눈에 안 보이는 오염 3종 (강의)**
  1. **클래스 교체**: boat → aeroplane
  2. **박스 삭제**: 있어야 할 boat 박스가 없음
  3. **허위 박스 추가**: 없는 cow 박스
- **Confidence 기반 자동 탐지 (강의)**: 학습된 모델의 예측과 라벨을 대조해 **불일치**를 찾음
  - **Missing 탐지 (conf 0.1, 낮게)**: 라벨에 클래스 X가 있는데 모델이 X를 **못 찾음** → **라벨 소실·허위 박스 의심**
  - **Extra 탐지 (conf 0.5, 높게)**: 라벨에 클래스 Y가 없는데 모델이 Y를 **강하게 예측** → **라벨 삭제·교체 의심**
  - 둘 다 걸리면 **Class Swap** 의심 (예: 라벨 cat·chair ↔ 예측 dog·sofa)
  - **self-detection 함정**: 오염된 데이터로 학습한 모델은 오염을 그대로 외워 못 잡음 → **Clean 기준 탐지기**(깨끗한 데이터로 학습한 모델) 사용
- **Triage → Fix → Re-train (강의)**
  - **Triage**: 사람이 **후보만** 보고 진짜 오염을 확정 (예: aeroplane → bird, cat → dog, motorbike 삭제)
  - **제거 vs 교정 실험** (오염 112장, clean val mAP@0.5)
    - ① Baseline(그대로 학습): **0.366**
    - ③a **제거**(의심 이미지 폐기, 112 → 70장): **0.247 (−0.119)** — 오염과 함께 학습 기회도 소실, 작은 데이터일수록 치명적
    - ③b **교정**(의심 라벨 고침, 112장 유지): **0.559 (+0.194)**
  - 결론: **"버리지 말고 고쳐라"** — 단, 교정 품질은 탐지기 정확도에 의존하므로 **최종 결정은 사람이 직접**
- **반복 루프 (강의)**: Detect(의심 자동 선별) → Triage(사람 확정) → Fix(라벨 수정·분포 재조정) → Re-train(같은 모델 재학습) → Iterate(좋아진 모델로 다시 탐지)
- **정답 라벨이 없을 때**: Self-training(모델 예측을 새 라벨로), **Foundation Model**(YOLO-World 등으로 라벨 재생성)
- **다음 단계 탐지 신호 5종 (강의)**: **K-fold Cross-Val**(그 샘플로 학습 안 한 모델이 검사), **Box-IoU Mismatch**(라벨·예측 1:1 매칭 후 IoU 낮으면 위치 오염), **Cleanlab**(라벨 X인데 모델이 Y라 확신하는 비율 통계), **CLIP 의미 정렬**(박스 crop과 라벨 텍스트 임베딩 유사도), **Loss 기반**(끝까지 loss가 높은 샘플)

## 수식·원리
```
Missing(X) = X ∈ labels  ∧  X ∉ preds(conf ≥ 0.1)
Extra(Y)   = Y ∉ labels  ∧  Y ∈ preds(conf ≥ 0.5)
Swap       = Missing ∧ Extra   (같은 이미지)
Box 오염   = IoU(label_box, matched_pred_box) < τ
```

## 코드 예시
```python
def audit(labels, preds, lo=0.1, hi=0.5):                  # labels: 클래스 집합, preds: [(cls, conf)]
    weak = {c for c, p in preds if p >= lo}
    strong = {c for c, p in preds if p >= hi}
    missing = labels - weak                                # 라벨엔 있는데 낮은 기준으로도 못 찾음
    extra = strong - labels                                # 라벨엔 없는데 강하게 예측
    kind = "swap" if missing and extra else "missing" if missing else "extra" if extra else "ok"
    return kind, sorted(missing), sorted(extra)

data = {
    "img1": ({"cat", "chair"}, [("dog", 0.91), ("sofa", 0.72)]),
    "img2": ({"bicycle", "car", "chair"}, [("train", 0.8), ("car", 0.3), ("bicycle", 0.15), ("chair", 0.2)]),
    "img3": ({"person"}, [("person", 0.88)]),
    "img4": ({"dog", "cow"}, [("dog", 0.9)]),
}
for k, (lab, pr) in data.items():
    print(k, audit(lab, pr))
# img1 swap / img2 extra(train) / img3 ok / img4 missing(cow) → 사람이 후보만 Triage

base, removed, fixed = 0.366, 0.247, 0.559                  # 강의 실험 결과 (mAP@0.5)
print(round(removed - base, 3), round(fixed - base, 3))     # -0.119 0.193  제거보다 교정
```
