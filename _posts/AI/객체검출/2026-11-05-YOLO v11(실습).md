# YOLO v11(실습)

## 정의·핵심
- **정의**: YOLO11 (2024.09, Ultralytics). v8 계열을 개선한 최신 Ultralytics 모델 — **C3k2 블록**, **C2PSA(공간 어텐션)** 추가로 **v8보다 적은 파라미터로 더 높은 mAP** (응용 12차시 실습 "YOLO_v11")
  - 예: YOLO11m은 YOLOv8m 대비 파라미터 약 22% 적으면서 COCO mAP ↑
  - 검출·분할·분류·자세·**OBB(회전 박스)** 모두 지원, 이름은 `yolo11n.pt` (v 없음)
- **ultralytics 공통 사용법 (v8·v11 동일, 과제 12차시)**
  ```
  from ultralytics import YOLO               # 과제 3: 임포트
  model = YOLO("yolo11n.pt")                 # 사전학습 가중치 로드 (자동 다운로드)
  results = model.predict(source=IMAGE_URL, conf=0.4)     # 과제 4: conf 0.4로 추론
  for box in results[0].boxes:               # 과제 5: 박스 순회
      name = model.names[int(box.cls)]
      conf = float(box.conf)
  batch_results = model.predict([URL1, URL2], conf=0.5, save=True)   # 과제 6: 배치 추론
  ```
- **결과 해석 (응용 12차시 실습 노트)** — `results[0].boxes`
  - `xywh`: **중심점 (x, y)** 과 너비·높이 (픽셀) — 주의: COCO의 xywh(좌상단)와 다름
  - `xywhn`: 이미지 크기 대비 **정규화**된 중심 형식
  - `xyxy`: 좌상단·우하단 (픽셀) / `xyxyn`: 정규화된 모서리 형식
  - `cls`(클래스 번호), `conf`(신뢰도), `model.names`(번호 → 이름)
  - `results[0].plot()`: 박스를 그린 BGR 이미지, `save=True`: `runs/detect/predict/`에 저장
- **주요 predict 인자**: `conf`(기본 0.25), `iou`(NMS, 0.7), `imgsz`(640), `classes=[0]`(특정 클래스만), `device`, `stream=True`(동영상·대용량 메모리 절약)
- **CLI**: `yolo detect predict model=yolo11n.pt source=img.jpg conf=0.4`

## 수식·원리
```
model.predict(source, conf, iou, imgsz) → List[Results]
Results.boxes: xyxy (N,4), xywh (N,4: 중심), conf (N,), cls (N,)
xywhn = xywh / [W, H, W, H]
```

## 코드 예시
```python
# ultralytics 미설치 → --stub로 흐름만 확인 (실제 출력은 미검증)
from ultralytics import YOLO

model = YOLO("yolo11n.pt")
results = model.predict(source="https://ultralytics.com/images/bus.jpg", conf=0.4)
for box in results[0].boxes:
    name = model.names[int(box.cls[0])]
    conf = float(box.conf[0])
    x1, y1, x2, y2 = box.xyxy[0].tolist()
    print(name, round(conf, 2), [round(v) for v in (x1, y1, x2, y2)])
batch_results = model.predict(["img1.jpg", "img2.jpg"], conf=0.5, save=True)
print(len(batch_results))
```
