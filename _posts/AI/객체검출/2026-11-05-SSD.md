# SSD

## 정의·핵심
- **정의**: SSD (Single Shot MultiBox Detector, 2016, Liu et al.). Region Proposal 없이 **이미지를 한 번만 통과(Single Shot)** 시켜 **여러 해상도의 특징 맵(Multi-scale)** 에서 **Default Box 기준으로** 위치와 클래스를 동시에 예측하는 **One-Stage 검출기** (응용 13차시)
- **설계 목표 (강의)**: **YOLO의 속도 + Faster R-CNN의 정확도**를 결합 / 멀티스케일 구조로 다양한 크기의 객체 검출 극대화
- **3가지 핵심 특징 (강의)**
  1. **One Forward Pass**: 제안 단계 없이 한 번에 위치(Localization)와 클래스(Classification) 예측
  2. **Multi-scale Feature Maps**: 고해상도는 작은 객체, 저해상도는 큰 객체 담당 → [[Multi-scale Feature Map]]
  3. **Default Boxes (Anchors)**: 각 셀마다 고정 크기·비율의 박스 → 오프셋과 클래스 점수 예측 → [[Default Box 스케일·종횡비]]
- **아키텍처 (강의)**
  - **VGG-16 백본**: FC 층을 **Conv(fc6, fc7)** 로 변환 + 추가 conv 층
  - **6개 예측 특징 맵**: **Conv4_3 (38×38)**, Conv7 (19×19), Conv8_2 (10×10), Conv9_2 (5×5), Conv10_2 (3×3), Conv11_2 (1×1)
  - 각 맵에 **3×3 conv**로 박스마다 **(C+1) 클래스 점수 + 4 오프셋** 예측
  - SSD300 기준 **총 8,732개 Default Box** (YOLO v1 98개 대비 훨씬 조밀한 Dense 예측)
- **예측 (강의)**
  - 분류: **C+1 클래스**(배경 포함) **Softmax**
  - 위치: Default Box 대비 **4개 오프셋 (Δcx, Δcy, Δw, Δh)**
  - 후처리: **NMS** → 객체당 박스 하나
  - 흐름: 8,732개 박스 → 분류·오프셋 동시 예측 → NMS → 최종 결과
- **학습**: [[Default Box Matching]](2단계) → [[Hard Negative Mining]](3:1) → [[SSD Loss]](Smooth L1 + CE)
- **성능 (강의)**: **SSD300 ≈ 59 FPS**(실시간), **SSD512 ≈ 22 FPS**(느리지만 더 정확) — 입력 해상도로 속도·정확도 조절
- **강점·한계 (강의 핵심 정리)**
  - 강점: 속도와 정확도의 균형, 다양한 크기 대응(6개 레이어), **End-to-End 학습**
  - 한계: **매우 작은 객체**는 여전히 어려움(저해상도 맵 정보 부족), Default Box 스케일·비율의 **하이퍼파라미터 의존성**, **Class Imbalance**(Hard Negative Mining 필수)
  - 실무 팁: **Zoom In/Out·Crop 등 강한 증강이 결정적**, K-means로 Custom Anchor 설계, 밀집 환경에서는 **NMS IoU threshold 신중히 조정**
- torchvision: `ssd300_vgg16`, `ssdlite320_mobilenet_v3_large`

## 수식·원리
```
SSD300 Default Box 수 = 38²·4 + 19²·6 + 10²·6 + 5²·6 + 3²·4 + 1²·4
                     = 5776 + 2166 + 600 + 150 + 36 + 4 = 8732
각 맵 출력 채널 = k·(C + 1 + 4)
L = (1/N)(L_conf + α·L_loc)
```

## 코드 예시
```python
import torch
from torchvision.models.detection import ssd300_vgg16

torch.manual_seed(0)
model = ssd300_vgg16(weights=None, weights_backbone=None, num_classes=21)   # VOC 20 + 배경
ab = model.anchor_generator
print(ab.num_anchors_per_location())                   # [4, 6, 6, 6, 4, 4]  맵별 셀당 박스 수
sizes = [38, 19, 10, 5, 3, 1]
print(sum(s * s * k for s, k in zip(sizes, ab.num_anchors_per_location())))   # 8732

model.eval()
with torch.no_grad():
    out = model([torch.rand(3, 300, 300)])
print(sorted(out[0].keys()))                           # ['boxes', 'labels', 'scores']  NMS까지 끝난 결과
```
