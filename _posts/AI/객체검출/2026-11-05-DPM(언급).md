# DPM(언급)

## 정의·핵심
- **정의**: DPM (Deformable Part Models, 2008~2010, Felzenszwalb et al.). 딥러닝 이전 **고전 객체 검출의 대표** — 객체를 **전체 형태(root) + 여러 부분(part) + 부분 간의 변형 허용**으로 모델링하고 **HOG 특징 + Sliding Window**로 검출 (대학원교안 YOLO v1: "기존 방식 — **Deformable Parts Models (DPM)**, Sliding window, R-CNN based methods")
- **구성**
  - **Root filter**: 객체 전체 모양을 표현하는 거친 HOG 템플릿 → [[HOG(Histogram of Oriented Gradients)]]
  - **Part filters**: 2배 해상도의 부분(머리·팔·다리) 템플릿
  - **Deformation cost**: 각 부분이 기준 위치에서 **얼마나 벗어났는지에 대한 벌점** (2차 함수) → 자세 변화 허용 ("deformable")
  - **Mixture**: 보는 각도(정면·측면)별로 여러 컴포넌트
  - **Latent SVM**으로 학습 (부분 위치를 잠재 변수로)
- **검출**: HOG 피라미드 위에서 **Sliding Window**로 각 위치 점수 = root 점수 + Σ(part 점수 − 변형 벌점) → NMS → [[Sliding Window]]
- **의의와 한계**
  - PASCAL VOC 2007~2010 챔피언급, 2010년 PASCAL "평생 공로상"
  - 하지만 손으로 설계한 특징(HOG), 다단계 파이프라인, **느린 속도** → **R-CNN(2014)** 이 mAP를 크게 넘어서며 딥러닝 시대로 전환 → [[R-CNN]]
  - YOLO 논문 비교: DPM은 실시간 버전도 정확도가 크게 낮음 (VOC07 30.4 mAP / 100Hz 버전 16.0)
- 개념적 유산: 부분 + 변형 아이디어 → Deformable Convolution, 키포인트 기반 검출

## 수식·원리
```
score(p_0, …, p_n) = F_0·φ(H, p_0) + Σ_i [ F_i·φ(H, p_i) − d_i·(dx_i, dy_i, dx_i², dy_i²) ]
F_0 = root filter, F_i = part filter, d_i = 변형 비용 계수, φ = HOG 특징
```

## 코드 예시
```python
import numpy as np

def part_score(response, anchor, d=(0, 0, 0.1, 0.1)):     # 부분 위치를 옮겨가며 (응답 − 변형 벌점) 최대화
    best = -np.inf
    for (y, x), r in np.ndenumerate(response):
        dy, dx = y - anchor[0], x - anchor[1]
        best = max(best, r - (d[0] * dx + d[1] * dy + d[2] * dx * dx + d[3] * dy * dy))
    return best

resp = np.zeros((9, 9)); resp[5, 6] = 3.0                  # 부분 필터 응답: 기준(4, 4)에서 조금 벗어난 곳이 최대
root = 2.0
total = root + part_score(resp, (4, 4))
print(round(total, 2))                                    # 4.5  = 2 + (3 − 0.1·4 − 0.1·1)
stiff = root + part_score(resp, (4, 4), d=(0, 0, 1, 1))
print(round(stiff, 2))                                    # 2.0  변형 비용이 크면 부분을 기준 위치에 둠
```
