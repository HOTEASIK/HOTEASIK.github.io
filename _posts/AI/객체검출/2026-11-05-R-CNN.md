# R-CNN

## 정의·핵심
- **정의**: R-CNN (Regions with CNN features, 2014, Girshick). **Region Proposal + CNN 특징 + 분류기**를 결합한 **Two-Stage 검출기의 시작점** — 딥러닝을 검출에 처음 성공적으로 적용 (응용 11차시)
- **파이프라인 (강의)**
  1. **Selective Search**로 이미지당 **약 2000개** 후보 영역(Region) 추출 → [[Selective Search·Region Proposal]]
  2. 각 영역을 **고정 크기(227×227)로 crop & warp** (휘게 늘림)
  3. **AlexNet(CNN)** 에 각각 넣어 **특징 벡터(4096차원)** 추출
  4. **클래스별 SVM**으로 분류
  5. **클래스별 Bounding Box Regression**(선형 회귀)으로 위치 보정 → [[Bounding Box Regression]]
- **학습 단계 (강의)**: ① ImageNet으로 분류 모델(AlexNet) 학습 → ② 검출 데이터로 **Fine-tuning** → ③ 특징 추출(디스크에 캐시) → ④ SVM 학습 → ⑤ 박스 회귀 학습 — **여러 단계를 따로** 학습
- **박스 회귀 (강의)**: "slightly wrong" 후보를 GT로 옮기는 **오프셋**을 클래스별 선형 회귀로 학습 (L2 손실 + **L2 정규화**)
  - 강의 보충: L1 Norm = 원소 차 절댓값 합, L2 Norm = 유클리드 거리, Regularization = 가중치가 과도하게 커지지 않도록 비용 함수에 가중치 제곱합을 더함
- **한계 (강의)**
  - **이미지마다 2000개 영역 각각 CNN 실행** → 매우 느림 (이미지당 수십 초)
  - **Crop·Warp로 형태 왜곡** → 성능 저하
  - 다단계 학습, SVM·회귀가 CNN과 따로 → end-to-end 아님, 특징 캐시로 디스크 사용 큼
  - → **Fast R-CNN**: 전체 이미지 CNN 1회 + RoI Pooling → [[Fast R-CNN]]

## 수식·원리
```
for each proposal r (~2000):
    f = CNN(warp(crop(I, r)))          # 2000번 CNN
    score_c = w_c · f   (SVM)
    box = r + regress_c(f)
비용 ∝ 2000 × CNN forward
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
cnn = nn.Sequential(nn.Conv2d(3, 8, 3, 2, 1), nn.ReLU(), nn.AdaptiveAvgPool2d(1), nn.Flatten())   # AlexNet 대신
svm = nn.Linear(8, 3)                                       # 클래스별 선형 분류기 (배경 + 2)
reg = nn.Linear(8, 4)                                       # 박스 오프셋

img = torch.rand(1, 3, 200, 300)
props = torch.tensor([[10, 20, 80, 120], [100, 50, 260, 150], [30, 30, 60, 50]])   # 후보 (x1, y1, x2, y2)
feats = []
for x1, y1, x2, y2 in props.tolist():
    crop = img[:, :, y1:y2, x1:x2]
    warp = F.interpolate(crop, size=(227, 227), mode="bilinear")   # 비율 무시하고 늘림 → 왜곡
    feats.append(cnn(warp))                                        # 영역마다 CNN 1회
feats = torch.cat(feats)
print(tuple(feats.shape), tuple(svm(feats).shape), tuple(reg(feats).shape))   # (3, 8) (3, 3) (3, 4)
print(len(props), "번 CNN 실행 → 실제로는 이미지당 ~2000번")   # 3 번 CNN 실행 …
```
