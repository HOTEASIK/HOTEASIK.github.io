# 컴퓨터 비전 주요 Task

## 정의·핵심
- **4가지 주요 Task (응용 11차시)**
  - **분류 (Classification)**: 이미지 내 객체의 **클래스**를 판별 — "이 사진은 고양이" (이미지 전체에 라벨 1개)
  - **위치 파악 (Localization)**: 이미지 내 **한 객체의 위치**를 **Bounding Box**로 찾음
  - **객체 검출 (Object Detection)**: **두 개 이상의 객체** 각각에 대해 **Classification + Localization** — "92% 확률로 이 위치에 버스"
  - **인스턴스 분할 (Instance Segmentation)**: 검출한 객체의 **형상(픽셀 영역)** 을 객체별로 표시 — 픽셀 단위 분류
- 그 밖: **Semantic Segmentation**(픽셀마다 클래스, 같은 클래스 객체는 구분 안 함), Panoptic Segmentation(semantic + instance), Pose Estimation(관절 키포인트), Tracking(프레임 간 같은 객체 연결)
- **Classification + Localization 구조 (강의)**: CNN(특징 추출) → FC 두 갈래
  - **분류 헤드**: 클래스 확률 (Dog = 0.9, Cat = 0.1) → Cross Entropy
  - **회귀 헤드**: 박스 `(x, y, w, h)` 4개 값 → **Bounding Box Regression** (L2·Smooth L1)
  - **분류와 회귀를 동시에** 학습 (multi-task loss)
- **검출로 확장할 때의 문제**: 객체 수가 **이미지마다 다름** → 출력 크기가 고정된 FC 하나로는 불가 → **후보 영역 기반**(Two-Stage) 또는 **격자·앵커 기반 밀집 예측**(One-Stage)으로 해결 → [[Two-Stage vs One-Stage]]
- 출력 비교

| Task | 출력 |
|---|---|
| 분류 | 클래스 1개 (확률 벡터) |
| 위치 파악 | 클래스 1개 + 박스 1개 |
| 검출 | (클래스, 박스, 신뢰도) × N개 |
| 인스턴스 분할 | 검출 + 객체별 마스크 |
| 의미 분할 | (H, W) 클래스 맵 |

## 수식·원리
```
Classification + Localization:
L = L_cls(p, y) + λ · L_box(b̂, b)
p = softmax(FC_cls(f)),  b̂ = FC_box(f) = (x, y, w, h)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class ClsLoc(nn.Module):                                  # 분류 + 위치 파악 (객체 1개)
    def __init__(self, n_cls=2):
        super().__init__()
        self.feat = nn.Sequential(nn.Conv2d(3, 8, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(4), nn.Flatten())
        self.cls = nn.Linear(8 * 16, n_cls)               # 무엇
        self.box = nn.Linear(8 * 16, 4)                   # 어디 (x, y, w, h)
    def forward(self, x):
        f = self.feat(x)
        return self.cls(f), self.box(f)

torch.manual_seed(0)
m = ClsLoc()
x = torch.randn(2, 3, 32, 32)
logits, box = m(x)
print(tuple(logits.shape), tuple(box.shape))              # (2, 2) (2, 4)
y, b = torch.tensor([0, 1]), torch.rand(2, 4)
loss = nn.functional.cross_entropy(logits, y) + nn.functional.smooth_l1_loss(box, b)
loss.backward()
print(loss.item() > 0)                                    # True  두 손실을 함께 학습
```
