# 벡터화

## 정의·핵심
- **정의**: for문으로 요소를 하나씩 계산하지 않고, **배열 전체를 한 번의 연산으로** 처리하는 방식. (Vectorization)
- **왜 빠른가**
  1. 계산이 최적화된 C 코드에서 실행된다 (파이썬 인터프리터 오버헤드 없음)
  2. 연속 메모리 덕분에 CPU 캐시를 잘 쓴다
  3. CPU의 SIMD 명령으로 여러 값을 동시에 계산한다
- **확장성**: for문은 데이터가 늘수록 시간이 그대로 늘어 수백만 개 데이터를 다루는 딥러닝에 맞지 않는다. 벡터화는 데이터가 커져도 빠르게 유지된다. GPU 텐서 연산은 이것을 수천 개 코어로 확장한 것이다.
- **"배열 단위로 생각하기"**: 2차시 핵심 메시지. 데이터 전체를 하나의 덩어리로 보고 반복문 없이 처리하는 습관.
- **예**
  - `[x * 2 for x in data]` (느림) → `data * 2` (빠름)
  - 손실 계산 `np.mean((y - y_pred) ** 2)` → 반복문 없는 MSE
  - 행렬 곱 `X @ W` → 배치 전체의 예측을 한 번에

## 수식·원리
- 선형 모델 예측을 샘플마다 계산하면 $\hat y_i = w x_i + b$ 를 $N$번 반복하지만,
  벡터화하면 $\hat{\mathbf y} = X W + b$ 한 줄이다.

## 코드 예시
```python
import time
import numpy as np

data = np.random.rand(1_000_000)

t = time.perf_counter()
out1 = [x * 2 for x in data]          # 반복문
t_loop = time.perf_counter() - t

t = time.perf_counter()
out2 = data * 2                       # 벡터화
t_vec = time.perf_counter() - t

print(np.allclose(out1, out2))        # True
print(t_loop > t_vec)                 # True (보통 수십 배 차이)

# 반복문 없는 MSE
y = np.array([10, 20, 30]); y_pred = np.array([12, 19, 35])
print(np.mean((y - y_pred) ** 2))     # 10.0
```
