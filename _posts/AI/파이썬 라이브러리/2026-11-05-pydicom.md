# pydicom

## 정의·핵심
- **정의**: 의료영상 표준 형식 **DICOM(.dcm)** 파일을 읽고 쓰는 라이브러리. `pip install pydicom`, `import pydicom` (응용 13차시 의료영상분석)
- **DICOM 파일 = 영상 + 메타데이터**: 픽셀 데이터와 함께 환자 ID, 촬영 장비(Modality: CT·MR·CR·DX), 촬영 날짜, 픽셀 간격 같은 정보가 **태그**로 들어 있다. → [[DICOM 형식]]
- **주요 사용법**
  - 읽기: `ds = pydicom.dcmread('file.dcm')`
  - 메타데이터: `ds.PatientID`, `ds.Modality`, `ds.Rows`, `ds.Columns`, `ds.PixelSpacing`
  - 픽셀: `ds.pixel_array` → NumPy 배열 (보통 `uint16`, 12~16비트)
- **딥러닝에 넣기 전 처리**
  - 값 범위가 0~255가 아니므로 **정규화** 필요: `(x - min) / (max - min)` → 0~1 또는 0~255 `uint8`
  - CT는 `RescaleSlope`·`RescaleIntercept`로 HU(하운스필드 단위) 변환 후, 보고 싶은 조직에 맞게 **윈도잉**(값 범위 자르기)
  - 흑백 1채널이라 사전학습 모델(3채널)에 넣을 때는 채널을 3번 복사
- **개인정보**: 환자 정보가 들어 있어 공유 전 익명화(태그 삭제)가 필요하다.
- 강의 실습의 Kaggle Chest X-Ray(폐렴) 데이터는 이미 **JPEG로 변환**된 것이라 pydicom 없이 ImageFolder로 읽는다.

## 수식·원리
```
.dcm ─dcmread─▶ ds ─┬─ ds.Modality, ds.PatientID ... (메타데이터)
                    └─ ds.pixel_array (uint16) ─정규화─▶ 0~1 ─3채널─▶ CNN
CT: HU = pixel × RescaleSlope + RescaleIntercept
```

## 코드 예시
```python
import numpy as np
from pydicom.data import get_testdata_file
import pydicom

path = get_testdata_file("CT_small.dcm")       # pydicom에 들어 있는 예제 파일
ds = pydicom.dcmread(path)
print(ds.Modality, ds.Rows, ds.Columns)        # CT 128 128
img = ds.pixel_array
print(img.dtype, img.shape)                    # int16 (128, 128)

hu = img * float(ds.RescaleSlope) + float(ds.RescaleIntercept)
norm = (hu - hu.min()) / (hu.max() - hu.min())
x3 = np.repeat(norm[None], 3, axis=0)          # (3, 128, 128)
print(round(norm.min(), 2), round(norm.max(), 2), x3.shape)   # 0.0 1.0 (3, 128, 128)
```
