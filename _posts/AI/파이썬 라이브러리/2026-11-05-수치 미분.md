# 수치 미분

## 정의·핵심
- **정의**: 미분 공식을 쓰지 않고, 아주 작은 간격 $h$로 함수값의 변화를 계산해 **기울기를 근사**하는 방법.
- **미분이 왜 필요한가**: 미분(기울기)은 학습의 나침반이다.
  - 방향: 손실을 줄이려면 가중치를 키울지 줄일지
  - 민감도: 입력이 조금 변할 때 손실이 얼마나 변하는지
  - 최적점: 기울기가 0인 곳이 손실이 가장 낮은 후보
- **중앙 차분(Central Difference)**: $x$ 양쪽의 $x+h$, $x-h$를 써서 전진 차분($x$, $x+h$)보다 오차가 작다.
- **고차 함수로 구현**: 함수를 받아 도함수를 돌려주는 `fdiff(f)`를 만든다. (1차시)
- **실무에서는**: 수치 미분은 파라미터마다 함수를 두 번씩 계산해야 해서 느리고 오차도 있다. 실제 딥러닝은 PyTorch **Autograd(자동 미분)** 를 쓴다. 수치 미분은 원리 이해와 기울기 검증(gradient check)에 쓴다. → [[Autograd]]

## 수식·원리
- 전진 차분: $f'(x) \approx \dfrac{f(x+h)-f(x)}{h}$ (오차 $O(h)$)
- 중앙 차분: $f'(x) \approx \dfrac{f(x+h)-f(x-h)}{2h}$ (오차 $O(h^2)$)
- 예: $f(x)=2x^2+2 \Rightarrow f'(x)=4x,\ f'(3)=12$

## 코드 예시
```python
import torch

def fdiff(f):
    h = 1e-6
    def diff(x):
        return (f(x + h) - f(x - h)) / (2 * h)   # 중앙 차분
    return diff

f = lambda x: 2 * x**2 + 2
f_prime = fdiff(f)
print(round(f_prime(3.0), 4))       # 12.0

# 같은 계산을 Autograd로
x = torch.tensor(3.0, requires_grad=True)
y = 2 * x**2 + 2
y.backward()
print(x.grad)                       # tensor(12.)
```
