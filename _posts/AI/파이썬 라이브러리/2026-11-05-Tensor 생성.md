# Tensor 생성

## 정의·핵심
- **텐서(Tensor)**: PyTorch의 기본 데이터 컨테이너. 고객 정보, 이미지 픽셀, 문장의 단어 등 모든 데이터는 모델에 넣기 전에 텐서에 담아야 한다. (3차시)
- **ndarray와 차이**: 문법은 NumPy와 거의 같지만 두 가지가 더 있다.
  1. **자동 미분**: `requires_grad=True`면 연산 기록을 남겨 `backward()`로 기울기를 계산 → [[Autograd]]
  2. **GPU 가속**: `.to('cuda')` 한 줄로 GPU에서 계산 → [[device와 GPU]]
- **생성 함수**

| 함수 | 만드는 것 | 주 용도 |
|---|---|---|
| `torch.tensor(data)` | 리스트·배열을 **복사**해서 | 데이터 변환 |
| `torch.from_numpy(arr)` | 배열과 **메모리 공유** | 빠른 변환 |
| `torch.zeros/ones(shape)` | 0/1로 채움 | 초기화, 마스크, 더미 정답 |
| `torch.randn(shape)` | 표준정규분포 난수 | 더미 입력 `torch.randn(100, 784)` |
| `torch.rand(shape)` | 0~1 균등분포 | 확률·노이즈 |
| `torch.arange/linspace` | 수열 | 그래프 x축 |
| `torch.zeros_like(t)` | t와 같은 모양·타입 | 기울기 버퍼 |

- **강의 관례**: NumPy 데이터를 텐서로 바꿀 때 `torch.tensor(x_np).float()` — NumPy 기본 float64를 모델이 쓰는 float32로 바꾸기 위해서다. 분류 정답은 `.long()`. → [[텐서 dtype]]
- 대문자 `torch.Tensor(...)`는 타입을 항상 float32로 만들고 동작이 헷갈리므로 소문자 `torch.tensor`를 쓴다.

## 수식·원리
```
Python list ──torch.tensor──▶ Tensor (복사)
ndarray     ──torch.from_numpy──▶ Tensor (메모리 공유)
Tensor      ──.numpy()──▶ ndarray (CPU 텐서만)
```

## 코드 예시
```python
import numpy as np
import torch

r0 = torch.tensor(1.0).float()           # 0차원(스칼라)
r1 = torch.tensor([1, 2, 3])
x_np = np.arange(-2.0, 2.1, 1.0)         # float64
x = torch.tensor(x_np).float()           # float32로
print(r0.shape, r1.dtype, x.dtype)       # torch.Size([]) torch.int64 torch.float32

print(torch.zeros(2, 3).shape)           # torch.Size([2, 3])
torch.manual_seed(123)
print(torch.randn(100, 784).shape)       # torch.Size([100, 784])

a = np.array([1.0, 2.0])
t = torch.from_numpy(a)
a[0] = 99
print(t)                                 # tensor([99.,  2.], dtype=torch.float64) ← 공유
```
