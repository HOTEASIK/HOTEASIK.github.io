# 한글 폰트 설정

## 정의·핵심
- **문제**: Matplotlib 기본 폰트(DejaVu Sans)에는 한글이 없어 제목·축 이름의 한글이 **네모(□)로 깨진다.**
- **해결 순서** (강의 노트북 맨 앞 셀에 항상 나오는 코드)
  1. 한글 폰트 설치 — Colab: `!apt-get install fonts-nanum` (나눔고딕)
  2. 폰트 파일을 Matplotlib에 등록 — `fm.fontManager.addfont(경로)`
  3. 기본 폰트로 지정 — `plt.rcParams['font.family'] = 'NanumGothic'`
  4. **마이너스 기호 깨짐 방지** — `plt.rcParams['axes.unicode_minus'] = False`
     (한글 폰트에 유니코드 마이너스 `−`가 없어 음수 눈금이 네모로 나오는 문제)
- **Windows 로컬**: 이미 있는 '맑은 고딕'을 쓰면 설치가 필요 없다. `font.family = 'Malgun Gothic'`
- **강의 노트북의 공통 설정 셀**에 함께 들어 있는 것
  - 기본 폰트 크기 `plt.rcParams['font.size'] = 14`
  - 기본 그래프 크기 `plt.rcParams['figure.figsize'] = (6, 6)`
  - 기본 격자 `plt.rcParams['axes.grid'] = True`
  - 넘파이 소수점 자릿수 `np.set_printoptions(suppress=True, precision=4)`
- Colab은 폰트 설치 뒤 **런타임 다시 시작**이 필요할 때가 있다. (`나눔고딕 폰트 설치.docx`)

## 수식·원리
```
한글 깨짐  → font.family를 한글 폰트로
음수 깨짐  → axes.unicode_minus = False
```

## 코드 예시
```python
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm

# Colab: !apt-get -qq install fonts-nanum 후
path = "/usr/share/fonts/truetype/nanum/NanumGothic.ttf"
try:
    fm.fontManager.addfont(path)
    plt.rcParams["font.family"] = "NanumGothic"
except FileNotFoundError:
    plt.rcParams["font.family"] = "Malgun Gothic"   # Windows 대체

plt.rcParams["axes.unicode_minus"] = False
plt.rcParams["font.size"] = 14
np.set_printoptions(suppress=True, precision=4)

plt.plot([-2, -1, 0, 1], [1, 0, -1, -2])
plt.title("손실 곡선")
plt.savefig("font.png")
```
