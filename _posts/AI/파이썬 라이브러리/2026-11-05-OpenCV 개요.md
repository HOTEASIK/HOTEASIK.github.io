# OpenCV 개요

## 정의·핵심
- **정의**: 컴퓨터 비전·영상 처리 라이브러리(Open Source Computer Vision). 파이썬에서는 `import cv2` (설치: `pip install opencv-python`)
- **할 수 있는 일** (응용 1~4차시) — 자세한 개념은 [[07_영상처리]] 폴더
  - 영상 읽기·쓰기·보기: `imread`, `imwrite`, `imshow`, 동영상 `VideoCapture`
  - 색공간 변환: `cvtColor` (BGR↔RGB·GRAY·HSV)
  - 픽셀·논리 연산, 히스토그램, 이진화
  - 필터링(블러·엣지), 모폴로지
  - 기하학적 변환(회전·확대·아핀·투시)
  - 특징 검출(코너·윤곽선·Hough), 추적(MeanShift·Optical Flow)
  - 그리기: `rectangle`, `circle`, `putText` — 검출 박스 표시에 사용
- **이미지 = NumPy 배열**: `cv2.imread` 결과는 `(H, W, 3)` `uint8` ndarray. NumPy 연산을 그대로 쓸 수 있다.
- **꼭 기억할 차이 두 가지**
  1. **BGR 순서**: OpenCV는 파랑·초록·빨강 순서. Matplotlib(RGB)으로 보거나 모델(RGB 학습)에 넣기 전에 `cv2.COLOR_BGR2RGB` 변환 → [[RGB·BGR]]
  2. **HWC 모양**: PyTorch는 CHW → `ToTensor()` 또는 `permute(2, 0, 1)`
- **좌표 순서**: 배열 인덱스는 `img[y, x]`(행, 열), 그리기 함수의 점은 `(x, y)` — 헷갈리기 쉽다.
- Colab에서는 `cv2.imshow` 대신 `from google.colab.patches import cv2_imshow` 또는 Matplotlib을 쓴다.
- 읽기 실패 시 오류 없이 `None`을 돌려주므로 경로가 맞는지 확인한다 (한글 경로 문제 → `cv2.imdecode(np.fromfile(path, np.uint8), cv2.IMREAD_COLOR)`).

## 수식·원리
```
cv2.imread → ndarray (H, W, 3) uint8, BGR
   ├─ cvtColor(BGR2RGB) → Matplotlib·모델
   └─ img[y, x] = [B, G, R]
```

## 코드 예시
```python
import numpy as np
import cv2

img = np.zeros((100, 200, 3), dtype=np.uint8)            # 검은 캔버스 (H=100, W=200)
cv2.rectangle(img, (20, 10), (120, 60), (0, 0, 255), 2)  # 빨간 박스 (BGR)
cv2.putText(img, "cat 0.92", (20, 85), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 1)
print(img[10, 20])                                       # [  0   0 255]  ← img[y, x], BGR

rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
print(rgb[10, 20])                                       # [255   0   0]
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(img.shape, gray.shape)                             # (100, 200, 3) (100, 200)
```
