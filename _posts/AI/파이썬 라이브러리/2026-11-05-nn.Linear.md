# nn.Linear

## 정의·핵심
- **정의**: 선형 변환 $y = xW^T + b$를 하는 레이어(완전연결층, Fully Connected, Dense). `nn.Linear(in_features, out_features, bias=True)`
- **파라미터 두 개** (7차시)
  - `weight`: 모양 **`(out, in)`** — 입력·출력 순서가 뒤집혀 있는 점에 주의. 그래서 식이 $W^T$
  - `bias`: 모양 `(out,)`
  - 둘 다 `requires_grad=True`로 만들어지고 무작위 초기화된다 (`manual_seed`로 고정 가능)
- **입력·출력 모양**: 입력 `(N, in)` → 출력 `(N, out)`. 마지막 축만 바뀌고 앞의 배치 축은 그대로
- **강의 예시**
  - `nn.Linear(1, 1)`: $y = w_1x_1 + b$ — 단순 선형회귀
  - `nn.Linear(2, 1)`: $y = w_1x_1 + w_2x_2 + b$ — 중회귀, 로지스틱 회귀(이진분류, 8차시)
  - `nn.Linear(2, 3)`: 출력 3개 — 다중분류(iris 3클래스, 9차시)
  - `nn.Linear(784, 128)`: MNIST 이미지 784 → 은닉 128
- **파라미터 수** = in × out + out. `Linear(784, 128)` → 100,480
- **초깃값 직접 넣기**: `nn.init.constant_(l.weight, 2.0)` 또는 `l.weight.data.fill_(1.0)` → [[nn.init]]
- Linear만 여러 겹 쌓으면 결국 하나의 선형 함수라서 **비선형 활성화 함수**를 사이에 넣어야 한다. → [[활성화 함수의 목적]]

## 수식·원리
$$y = xW^T + b,\quad x\in\mathbb R^{N\times in},\ W\in\mathbb R^{out\times in},\ b\in\mathbb R^{out}$$
(bias는 [[브로드캐스팅]]으로 N개 행에 더해짐)

## 코드 예시
```python
import torch
import torch.nn as nn

l3 = nn.Linear(2, 3)
print(l3.weight.shape, l3.bias.shape)     # torch.Size([3, 2]) torch.Size([3])

# 7차시: 출력마다 다른 가중치, bias 2
nn.init.constant_(l3.weight[0, :], 1.0)
nn.init.constant_(l3.weight[1, :], 2.0)
nn.init.constant_(l3.weight[2, :], 3.0)
nn.init.constant_(l3.bias, 2.0)
x2 = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
print(l3(x2))        # [[2,2,2],[3,4,5],[3,4,5],[4,6,8]]

print(torch.allclose(l3(x2), x2 @ l3.weight.T + l3.bias))   # True
print(sum(p.numel() for p in nn.Linear(784, 128).parameters()))   # 100480
```
