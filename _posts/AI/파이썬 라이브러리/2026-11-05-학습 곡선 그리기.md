# 학습 곡선 그리기

## 정의·핵심
- **학습 곡선**: 에폭(또는 반복 횟수)에 따른 **손실·정확도 변화**를 그린 그래프. 학습이 잘 되고 있는지 진단하는 가장 기본 도구. → 개념 설명은 [[학습 곡선]]
- **history 배열**: 학습 루프에서 값을 모아 둔다. 강의 방식은 NumPy 배열에 한 줄씩 붙이기
  - `history = np.zeros((0, 5))` → 매 에폭 `[epoch, train_loss, train_acc, val_loss, val_acc]`를 `np.vstack`으로 추가 (8~12차시)
  - 리스트에 `append`하는 방법도 많이 쓴다.
- **그리는 법**: 훈련(Train)과 검증(Validation) 곡선을 **한 그래프에 겹쳐** 그린다. (2차시 Tip)
- **읽는 법**
  - 둘 다 내려간다 → 정상 학습
  - Train은 내려가는데 Val은 올라간다 → **과적합** (그 지점이 Early Stopping 시점) → [[과적합(Overfitting)]]
  - 둘 다 높게 머문다 → 과소적합 (모델이 너무 작거나 학습률 문제)
  - 들쭉날쭉·NaN → 학습률이 너무 크다
- 첫 값이 너무 크면 나머지가 안 보이므로 `history[1:]`처럼 처음 요소를 빼고 그리기도 한다. (7차시)
- `loss.item()`으로 숫자만 꺼내 저장해야 그래프 그릴 때 텐서·그래프가 메모리에 쌓이지 않는다.

## 수식·원리
```
history[:, 0] = epoch
history[:, 1] = train loss     history[:, 3] = val loss
history[:, 2] = train acc      history[:, 4] = val acc
```

## 코드 예시
```python
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

history = np.zeros((0, 5))
for epoch in range(1, 21):
    tr_loss = 1 / epoch
    va_loss = 1 / epoch + max(0, epoch - 12) * 0.03   # 12에폭 뒤 과적합 흉내
    item = np.array([epoch, tr_loss, 1 - tr_loss / 2, va_loss, 1 - va_loss / 2])
    history = np.vstack((history, item))

print(history.shape)                                  # (20, 5)
print(int(history[np.argmin(history[:, 3]), 0]))      # 검증 손실 최소 에폭 = 12

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].plot(history[:, 0], history[:, 1], "b", label="train")
axes[0].plot(history[:, 0], history[:, 3], "k--", label="val")
axes[0].set_title("loss"); axes[0].legend()
axes[1].plot(history[:, 0], history[:, 2], "b", label="train")
axes[1].plot(history[:, 0], history[:, 4], "k--", label="val")
axes[1].set_title("accuracy"); axes[1].legend()
plt.savefig("curve.png")
```
