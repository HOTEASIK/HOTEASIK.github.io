# NLP 도구

## 정의·핵심
- **왜 필요한가**: 모델은 문자를 모른다. 문장을 **토큰(단어·형태소·서브워드)으로 자르고 번호로 바꾸는** 전처리가 먼저다. (개론 17차시, [보강] w2v·tokenizer) → [[토큰화(Tokenizer)]]
- **nltk** (영어 중심)
  - `nltk.download('punkt')`: 토큰화 규칙 데이터 내려받기 (최신 버전은 `punkt_tab`)
  - `nltk.tokenize.word_tokenize(문장)`: 단어·문장부호 단위로 자르기 — 단순 `split()`과 달리 `"movie!"` → `['movie', '!']`
  - 불용어(stopwords), 어간 추출(stemming)도 제공
- **soynlp** (한국어, 비지도 학습 방식)
  - 한국어는 조사·어미가 붙어서(교착어) 띄어쓰기만으로는 단어가 안 나뉜다: "영화가", "영화를", "영화는"이 다 다른 토큰이 됨
  - 형태소 분석기(KoNLPy) 대신 **말뭉치에서 단어 점수를 학습**해 자른다 — 사전 없이 신조어에도 대응
  - `WordExtractor`: 단어 경계 점수(응집 확률) 학습
  - `LTokenizer(scores)`: 어절을 **L(단어) + R(조사·어미)** 로 나눔 — "영화가" → "영화" + "가"
  - `LRNounExtractor_v2`: 명사 추출
- **서브워드 토크나이저**: BERT·GPT는 WordPiece·BPE 토크나이저를 쓴다 → [[Hugging Face]]의 `AutoTokenizer` (한국어 KcBERT 등)
- 실습 데이터: NSMC(네이버 영화 리뷰 감성, `pd.read_table`로 읽음)

## 수식·원리
```
"I loved this movie!" ─word_tokenize─▶ ['I', 'loved', 'this', 'movie', '!']
"영화가 정말 재밌다" ─LTokenizer─▶ ['영화', '가', '정말', '재밌', '다'] (점수에 따라)
토큰 ─vocab─▶ 정수 id ─nn.Embedding─▶ 벡터
```

## 코드 예시
```python
import nltk
nltk.download("punkt", quiet=True); nltk.download("punkt_tab", quiet=True)
from nltk.tokenize import word_tokenize
print(word_tokenize("I loved this movie!"))   # ['I', 'loved', 'this', 'movie', '!']

from soynlp.word import WordExtractor
from soynlp.tokenizer import LTokenizer
corpus = ["영화가 정말 재밌다", "영화를 또 보고 싶다", "영화는 별로였다", "배우가 좋다", "배우를 좋아한다"] * 20
we = WordExtractor(); we.train(corpus)
scores = {w: s.cohesion_forward for w, s in we.extract().items()}
tok = LTokenizer(scores=scores)
print(tok.tokenize("영화가 재밌다"))           # ['영화', '가', ...] 형태
```
