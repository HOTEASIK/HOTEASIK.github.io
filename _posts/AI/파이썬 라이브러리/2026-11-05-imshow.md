# imshow

## 정의·핵심
- **정의**: 2차원(흑백)·3차원(컬러) 배열을 이미지로 그리는 Matplotlib 함수. `plt.imshow(배열)`
- **입력 모양**
  - 흑백: `(H, W)` → `cmap='gray'`를 줘야 회색으로 보인다 (안 주면 기본 컬러맵 viridis로 초록·보라색)
  - 컬러: `(H, W, 3)` — **채널이 마지막**이어야 한다
- **값 범위**: 정수면 0~255, 실수면 0~1로 해석한다. 정규화(`Normalize(0.5, 0.5)`)로 -1~1이 된 이미지는 `(x + 1) / 2`로 되돌려서 그린다.
- **자주 하는 실수 두 가지**
  1. **PyTorch 텐서는 `(C, H, W)`** → `img.permute(1, 2, 0)` 또는 `np.transpose(img, (1, 2, 0))`로 `(H, W, C)`로 바꾼다. (12차시: 원래 이미지 [3,32,32] CHW)
  2. **OpenCV는 BGR 순서**로 읽는다 → `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`로 바꾸지 않으면 빨강·파랑이 뒤바뀌어 보인다. (응용 1차시) → [[RGB·BGR]]
- GPU 텐서는 `.cpu().numpy()`로 옮긴 뒤 그린다. → [[item·numpy 변환]]

## 수식·원리
```
PyTorch  (C, H, W) ──permute(1,2,0)──▶ (H, W, C)  Matplotlib
OpenCV   (H, W, C) BGR ──cvtColor──▶ (H, W, C) RGB
정규화 복원: x_show = x * std + mean   (Normalize(0.5,0.5)면 (x+1)/2)
```

## 코드 예시
```python
import numpy as np
import torch
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

img_t = torch.rand(3, 32, 32) * 2 - 1        # 정규화된 CIFAR 이미지 흉내 (-1~1, CHW)
img = img_t.permute(1, 2, 0).numpy()          # (32, 32, 3)
img = (img + 1) / 2                           # 0~1로 복원
print(img.shape, img.min() >= 0)              # (32, 32, 3) True

bgr = np.zeros((10, 10, 3), dtype=np.uint8); bgr[..., 0] = 255   # OpenCV 기준 파랑
rgb = bgr[..., ::-1]                          # BGR→RGB (cv2.cvtColor와 같은 효과)

fig, axes = plt.subplots(1, 2)
axes[0].imshow(img); axes[1].imshow(rgb)
plt.savefig("imshow.png")
```
