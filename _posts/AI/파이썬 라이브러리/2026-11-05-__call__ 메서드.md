# __call__ 메서드

## 정의·핵심
- **정의**: 클래스에 `__call__`을 정의하면 **인스턴스를 함수처럼 호출**할 수 있다. `h(3)` → 내부적으로 `h.__call__(3)` 실행.
- **왜 중요한가**: PyTorch에서 `net(inputs)`라고 쓰면 `nn.Module.__call__`이 실행되고, 그 안에서 우리가 만든 `forward()`가 호출된다. 그래서 모델은 `net.forward(x)`가 아니라 `net(x)`로 부른다.
- **`net(x)`를 쓰는 이유**: `__call__`은 `forward` 앞뒤로 **Hook** 같은 부가 처리를 함께 실행한다. `forward`를 직접 부르면 이 처리가 빠진다. (7차시)
- 이렇게 함수처럼 부를 수 있는 객체를 **callable**이라고 하며 `callable(obj)`로 확인한다.
- 손실 함수 `criterion(outputs, labels)`, 레이어 `l1(x)`, 활성화 `relu(x)`도 모두 같은 원리다.

## 수식·원리
```
net(x)
 └─ nn.Module.__call__(x)
     ├─ forward pre-hook 실행
     ├─ self.forward(x)   ← 우리가 정의한 부분
     └─ forward hook 실행
```

## 코드 예시
```python
class H:
    def __call__(self, x):
        return 2 * x

h = H()
print(h(3))            # 6  (h.__call__(3)과 같음)
print(callable(h))     # True

# PyTorch: net(x) → __call__ → forward
import torch
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.l1 = nn.Linear(1, 1)
    def forward(self, x):
        return self.l1(x)

net = Net()
x = torch.ones(2, 1)
print(torch.equal(net(x), net.forward(x)))   # True
```
