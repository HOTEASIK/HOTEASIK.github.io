# ndarray

## 정의·핵심
- **정의**: NumPy의 N차원 배열 객체. 같은 타입의 숫자를 **연속된 메모리**에 저장하는 고성능 수치 컨테이너.
- **"텐서 = 기울기가 추가된 ndarray"**: PyTorch Tensor는 ndarray의 설계를 그대로 이어받고 자동 미분·GPU를 더했다. ndarray를 알면 Tensor 문법 대부분을 알게 된다.
- **리스트와 차이**

| 항목 | Python list | ndarray |
|---|---|---|
| 데이터 타입 | 섞어 담기 가능 (이질적) | 한 가지만 (동질적) |
| 메모리 | 객체 주소를 흩어서 저장 | 값을 연속 블록에 저장 |
| 연산 | for문 순차 처리 | 벡터화(C 코드, SIMD) |
| 속도 | 느림 | 빠름 |

- **핵심 속성**
  - `shape`: 각 축의 크기. 28x28 흑백 이미지 → `(28, 28)`
  - `ndim`: 차원 수(축의 개수)
  - `dtype`: 요소 타입. `float32`(딥러닝 기본), `float64`(NumPy 기본), `int64`
  - `size`: 전체 요소 수
- **생성 방법**: `np.array(리스트)`, `np.zeros()`·`np.ones()`(초기화, 마스크), `np.arange()`·`np.linspace()`(수열), `np.random.randn()`(난수)
- **주의**: NumPy 기본 실수 타입은 `float64`인데 PyTorch 모델은 `float32`를 쓴다. 텐서로 바꿀 때 `.float()`를 붙이는 이유다. → [[텐서 dtype]]

## 수식·원리
- 데이터 차원 예
  - 벡터(1D): 특징 하나 `(D,)`
  - 행렬(2D): 배치 데이터 `(N, D)`
  - 3D: 컬러 이미지 `(H, W, C)` (OpenCV·PIL 순서)
  - 4D: 이미지 배치 `(N, C, H, W)` (PyTorch 순서)

## 코드 예시
```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.shape, a.ndim, a.dtype, a.size)   # (2, 3) 2 int64 6  (Windows 일부 환경은 int32)

b = np.array([1.5, 2.0], dtype="float32")
print(b.dtype)                            # float32

z = np.zeros((2, 2))
print(z.dtype)                            # float64 ← NumPy 기본 실수형

img = np.zeros((28, 28), dtype=np.uint8)  # 흑백 이미지 (0~255)
print(img.shape, img.max())               # (28, 28) 0
```
