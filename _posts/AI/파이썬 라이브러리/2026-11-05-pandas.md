# pandas

## 정의·핵심
- **정의**: 표 형태(행·열) 데이터를 다루는 라이브러리. `import pandas as pd`. 핵심 자료형은 **DataFrame**(표)과 **Series**(열 하나).
- **강의에서의 쓰임**
  - `pd.read_csv`: 파일·URL에서 표 읽기. 7차시 보스턴 집값은 sklearn에서 빠져서 **웹 URL에서 직접** 읽는다: `pd.read_csv(url, sep="\s+", skiprows=22, header=None)` — 공백 구분, 앞 22줄 설명 건너뛰기, 열 이름 없음
  - `pd.read_table`: 탭 구분 파일 (NSMC 영화 리뷰 감성 데이터, 17차시)
  - `pd.DataFrame(...)`: 결과 정리표 (모델별 성능 비교, 클래스 분포)
- **자주 쓰는 기능**
  - 확인: `df.head()`, `df.shape`, `df.info()`, `df.describe()`
  - 열 선택: `df['col']`, 여러 열 `df[['a', 'b']]`, 조건 `df[df.label == 1]`
  - 결측치: `df.isnull().sum()`, `df.dropna()`, `df.fillna(값)`
  - 분포: `df['label'].value_counts()`, 고유값 개수 `nunique()`
  - NumPy로: `df.values` 또는 `df.to_numpy()` → 텐서로 변환
- **딥러닝에 넣기 전**: DataFrame → NumPy → `torch.tensor(...).float()`

## 수식·원리
```
CSV ─read_csv─▶ DataFrame ─values─▶ ndarray ─torch.tensor─▶ Tensor
```

## 코드 예시
```python
import io
import numpy as np
import pandas as pd

csv = io.StringIO("RM,LSTAT,PRICE\n6.5,4.9,24.0\n7.1,9.1,21.6\n,5.3,34.7\n")
df = pd.read_csv(csv)
print(df.shape)                       # (3, 3)
print(df.isnull().sum()["RM"])        # 1
df = df.fillna(df["RM"].mean())
print(df["RM"].round(2).tolist())     # [6.5, 7.1, 6.8]

x = df[["RM", "LSTAT"]].values.astype(np.float32)
print(x.shape, x.dtype)               # (3, 2) float32
print(pd.Series([0, 0, 1]).value_counts().to_dict())   # {0: 2, 1: 1}
```
