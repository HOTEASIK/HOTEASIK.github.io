# nn.Sequential

## 정의·핵심
- **정의**: 레이어를 **넣은 순서대로** 이어서 실행하는 컨테이너. 여러 레이어를 하나의 합성 함수로 묶는다. (5차시 코드 4-3)
- `nn.Sequential(l1, relu, l2)(x)` = `l2(relu(l1(x)))`
- **장점**: forward를 따로 쓸 필요가 없어 짧다. 단순히 일렬로 이어지는 구조에 좋다.
- **한계**: 입력이 여러 개이거나, 중간에 갈라졌다 합쳐지는 구조(ResNet의 skip connection, Inception)는 Sequential만으로 안 된다 → `nn.Module`의 forward에 직접 쓴다.
- **CNN에서의 관례** (11·12차시)
  - `self.features = nn.Sequential(conv1, relu, conv2, relu, maxpool, ...)` — 특징 추출부
  - `self.classifier = nn.Sequential(l1, relu, dropout, l2)` — 분류부
  - forward: `features → flatten → classifier`
  - torchvision 사전학습 모델도 `features`·`classifier`로 나뉘어 있어 `net.classifier[6]`처럼 인덱스로 교체한다. → [[출력층 교체]]
- **인덱스·이름**: `seq[0]`으로 꺼낼 수 있다. 이름을 붙이려면 `OrderedDict`를 넘긴다.
- **주의 (12차시)**: Sequential에 **같은 BN 인스턴스를 여러 번** 넣으면 한 BN이 서로 다른 층의 통계를 섞어 학습이 망가진다. 층마다 새 인스턴스를 만든다. ReLU처럼 파라미터 없는 것은 재사용해도 된다.

## 수식·원리
```
nn.Sequential(f1, f2, f3)(x) = f3(f2(f1(x)))     ← 합성 함수
```

## 코드 예시
```python
import torch
import torch.nn as nn

l1 = nn.Linear(784, 128); relu = nn.ReLU(inplace=True); l2 = nn.Linear(128, 10)
inputs = torch.randn(100, 784)
out1 = l2(relu(l1(inputs)))
net2 = nn.Sequential(l1, relu, l2)
print(torch.equal(out1, net2(inputs)))     # True
print(net2[0])                             # Linear(in_features=784, out_features=128, bias=True)

features = nn.Sequential(
    nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2),
)
print(features(torch.randn(2, 3, 32, 32)).shape)   # torch.Size([2, 32, 16, 16])
```
