# torch.optim 사용법

## 정의·핵심
- **torch.optim**: 파라미터 업데이트 규칙(옵티마이저)을 모아 둔 모듈. SGD, Adam, AdamW, RMSprop 등
- **만들기**: `optimizer = optim.SGD(net.parameters(), lr=0.01)` — 무엇을(파라미터) 얼마만큼(학습률) 조정할지 알려 준다.
  - 옵션: `momentum=0.9`, `weight_decay=1e-2`(L2 규제) 등
- **두 메서드**
  - `optimizer.zero_grad()`: 모든 파라미터의 `.grad`를 0으로 비운다. **기울기가 누적되기 때문에** 매 반복마다 필요
  - `optimizer.step()`: 계산된 `.grad`로 파라미터를 한 번 업데이트한다. SGD면 $W \leftarrow W - lr\cdot\nabla W$
- **학습 루프에서의 위치**: `zero_grad → 예측 → 손실 → backward → step` (7차시 4단계 + 초기화) → [[학습 루프 4단계]]
- **손으로 하던 것을 대신해 준다** (4차시 3.12): 수동 업데이트 `with torch.no_grad(): W -= lr * W.grad; W.grad.zero_()`를 `step()`·`zero_grad()` 두 줄로 바꾼 것이다. 결과는 같다. (4차시 과제 "결과는 문제 3과 동일해야 함")
- **옵티마이저 바꾸기는 한 줄**: `optim.SGD` → `optim.Adam(net.parameters())` (12차시) — 각 알고리즘 설명은 04의 [[SGD(옵티마이저)]], [[Momentum]], [[Adam]]
- **학습률 스케줄러**와 함께: `scheduler.step()`은 보통 에폭마다 → [[학습률 스케줄러 개념]]
- `optimizer.param_groups[0]['lr']`로 현재 학습률을 확인·변경할 수 있다.

## 수식·원리
```
optimizer.zero_grad()      # grad = 0
outputs = net(inputs)      # 순전파
loss = criterion(outputs, labels)
loss.backward()            # grad 계산
optimizer.step()           # W ← W − lr·grad
```

## 코드 예시
```python
import torch
import torch.optim as optim

# 수동 업데이트
W = torch.tensor(1.0, requires_grad=True)
loss = (3 * W - 6) ** 2
loss.backward()
with torch.no_grad():
    W -= 0.01 * W.grad
    W.grad.zero_()
manual = W.item()

# optimizer로 같은 일
W2 = torch.tensor(1.0, requires_grad=True)
opt = optim.SGD([W2], lr=0.01)
opt.zero_grad()
loss2 = (3 * W2 - 6) ** 2
loss2.backward()
opt.step()
print(round(manual, 4), round(W2.item(), 4))   # 1.18 1.18 (같음)
print(opt.param_groups[0]["lr"])               # 0.01
```
