# Keras

## 정의·핵심
- **정의**: 고수준 딥러닝 API. 원래 TensorFlow용이었고 Keras 3부터는 TensorFlow·PyTorch·JAX를 백엔드로 고를 수 있다. **대학원 강의안**(선형·로지스틱 회귀, AlexNet 등) 예제가 Keras로 되어 있어, PyTorch와 비교해 읽을 수 있으면 된다.
- **대학원 강의안의 함수형(Functional) 모델 작성법**
  - `inputs = keras.Input(shape=(1,))`
  - `x = layers.Dense(4, activation='sigmoid')(inputs)` — Dense = PyTorch의 `nn.Linear` + 활성화
  - `model = keras.Model(inputs=inputs, outputs=outputs, name='Linear Regression')`
  - `model.compile(loss='mse', optimizer='sgd', metrics=['accuracy'])` — 손실·옵티마이저·지표를 미리 지정
  - `model.fit(x, y, epochs=...)` — **학습 루프를 직접 쓰지 않는다**
- **PyTorch와 대응표**

| 하는 일 | Keras | PyTorch |
|---|---|---|
| 완전연결층 | `layers.Dense(units, activation)` | `nn.Linear(in, out)` + 활성화 |
| 입력 크기 | `Input(shape)`로 지정, in은 자동 | in_features 직접 지정 |
| 모델 정의 | `Sequential` / 함수형 / 서브클래스 | `nn.Sequential` / `nn.Module` |
| 학습 설정 | `compile(loss, optimizer, metrics)` | `criterion`, `optimizer` 객체 |
| 학습 | `fit()` 한 줄 | for문 + zero_grad·backward·step |
| 평가·예측 | `evaluate()`, `predict()` | `eval()` + `no_grad()` |

- **차이의 핵심**: Keras는 학습 루프를 숨겨 짧고, PyTorch는 루프를 직접 써서 세밀하게 제어할 수 있다 (연구·실험에 유리).
- 강의안의 `metrics=['accuracy']`를 회귀(mse)에 쓴 예는 의미가 없다. 회귀는 MAE·R² 같은 지표를 본다.

## 수식·원리
```
Keras:   compile(loss, optimizer) → fit(x, y, epochs)
PyTorch: for epoch: zero_grad → forward → loss → backward → step
```

## 코드 예시
```python
import numpy as np
import keras
from keras import layers

x = np.linspace(-1, 1, 64).reshape(-1, 1).astype("float32")
y = 2 * x + 1

inputs = keras.Input(shape=(1,))
outputs = layers.Dense(1)(inputs)
model = keras.Model(inputs=inputs, outputs=outputs, name="LinearRegression")
model.compile(loss="mse", optimizer=keras.optimizers.SGD(learning_rate=0.1))
model.fit(x, y, epochs=200, verbose=0)

w, b = model.layers[1].get_weights()
print(round(float(w[0, 0]), 1), round(float(b[0]), 1))   # 2.0 1.0
```
