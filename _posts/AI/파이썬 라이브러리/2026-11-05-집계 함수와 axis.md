# 집계 함수와 axis

## 정의·핵심
- **집계(Aggregation)**: 배열을 하나의 값(스칼라)이나 더 작은 차원으로 **압축**하는 연산. `sum`, `mean`, `max`, `min`, `std`, `var`
- **딥러닝과 연결**: 손실 함수는 결국 예측과 정답의 차이를 **배치 전체에 대해 하나의 숫자로 집계**한 것이다. (MSE = 오차 제곱의 mean)
- **함수별 쓰임**
  - `sum`: 기울기 누적, 맞힌 개수 세기
  - `mean`: 손실 계산(MSE, CrossEntropy), 평균 정확도
  - `max`·`min`: 가장 강한 특징(Max Pooling), 데이터 범위·이상치 확인
  - `std`·`var`: 퍼진 정도 → 정규화, 가중치 초기화
- **axis(축)**: 어느 방향으로 압축할지 정한다. 2차원 기준
  - `axis=0` (세로 ↓): 행을 따라 내려가며 계산 → **열마다** 하나의 결과. 샘플 간 집계 (전체 학생의 과목별 평균)
  - `axis=1` (가로 →): 열을 따라 가며 계산 → **행마다** 하나의 결과. 샘플 안의 특징 집계 (한 학생의 평균)
  - 지정 안 하면 전체를 하나로
- **딥러닝 차원 규칙**: 보통 `axis=0`(dim=0)이 배치 차원(N), `axis=1`부터 특징 차원(D, C, H, W)
- **PyTorch**: `axis` 대신 `dim`을 쓴다. `outputs.max(dim=1)`, `torch.softmax(x, dim=1)`
- `keepdims=True`: 압축한 축을 크기 1로 남겨 [[브로드캐스팅]]에 바로 쓸 수 있다.

## 수식·원리
```
x = [[1, 2, 3],
     [4, 5, 6]]
sum(axis=0) → [5, 7, 9]   (열마다)
sum(axis=1) → [6, 15]     (행마다)
sum()       → 21
```
- 사라지는 축이 `axis`로 지정한 축이다. `(2, 3)`에서 `axis=0` → `(3,)`

## 코드 예시
```python
import numpy as np

x = np.array([[1, 2, 3], [4, 5, 6]])
print(x.sum(axis=0), x.sum(axis=1), x.sum())   # [5 7 9] [ 6 15] 21
print(x.mean(axis=1, keepdims=True).shape)     # (2, 1)

scores = np.array([[90, 80], [70, 60], [80, 100]])  # 학생 3명 x 과목 2개
print(scores.mean(axis=0))   # [80. 80.]  과목별 평균
print(scores.mean(axis=1))   # [85. 65. 90.] 학생별 평균

import torch
logits = torch.tensor([[2.0, 1.0, 0.1], [0.5, 3.0, 0.2]])
print(logits.max(dim=1))     # values=[2., 3.], indices=[0, 1]
```
