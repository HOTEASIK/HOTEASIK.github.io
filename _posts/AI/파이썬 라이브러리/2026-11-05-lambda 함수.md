# lambda 함수

## 정의·핵심
- **정의**: 이름 없이 한 줄로 만드는 작은 함수(익명 함수). `lambda 인자: 반환식`
- `def`와 같은 기능이지만 **식 하나만** 쓸 수 있다 (if문·for문 블록 불가, 조건 표현식은 가능).
- **언제 쓰나**: 함수를 다른 함수의 인자로 잠깐 넘길 때.
  - `sorted(data, key=lambda x: x[1])` 정렬 기준
  - `transforms.Lambda(lambda x: x.view(-1))` 이미지를 1차원으로 펴기 (10차시 MNIST) → [[transforms]]
  - `np.frompyfunc(lambda x: f'{x:.04f}', 1, 1)` 배열 값 포맷 (12차시)
  - 수치 미분에 넘길 함수 `f = lambda x: 2*x**2 + 2` → [[수치 미분]]
- **주의**: 복잡한 로직은 `def`로 쓰는 것이 읽기 좋다. 또 lambda로 만든 transform은 pickle이 안 되어 Windows에서 `DataLoader(num_workers>0)`일 때 오류가 날 수 있다.

## 수식·원리
```
g = lambda x: 2 * x**2 + 2
# 위와 아래는 같다
def g(x):
    return 2 * x**2 + 2
```

## 코드 예시
```python
import numpy as np
import torch

g = lambda x: 2 * x**2 + 2
print(g(3))                                   # 20

pairs = [("cat", 3), ("dog", 1), ("ant", 2)]
print(sorted(pairs, key=lambda p: p[1]))      # [('dog', 1), ('ant', 2), ('cat', 3)]

flatten = lambda x: x.view(-1)                # transforms.Lambda에 넘기는 형태
print(flatten(torch.zeros(1, 28, 28)).shape)  # torch.Size([784])

probs = np.array([0.77751, 0.22213])
fmt = np.frompyfunc(lambda x: f"{x:.04f}", 1, 1)
print(fmt(probs))                             # ['0.7775' '0.2221']
```
