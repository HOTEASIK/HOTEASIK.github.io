# 인덱싱·슬라이싱

## 정의·핵심
- **인덱싱**: 위치 번호로 요소 하나를 꺼낸다. 번호는 0부터, 음수는 뒤에서부터 (`-1`은 마지막).
- **슬라이싱**: `시작:끝:간격`으로 범위를 꺼낸다. **끝은 포함하지 않는다.** `a[1:4]` → 1, 2, 3번.
- **다차원**: 축마다 쉼표로 구분한다. `x[행, 열]`, `x[:, 0]`(모든 행의 0번 열)
- **딥러닝에서 자주 쓰는 형태**
  - `x[:, feature_names == 'RM']` 특정 열만 추출 (7차시 보스턴 집값)
  - `x[:100, :2]` 앞 100개 샘플의 2개 특징만 (8차시 iris 이진분류)
  - `raw_df.values[::2, :]` 두 줄 간격으로 행 추출
  - `images[0]` 배치에서 첫 이미지, `probs[0]` 배치 차원 제거
- **팬시 인덱싱**: 정수 배열로 여러 위치를 한꺼번에 고른다. `a[[0, 2]]` → 결과는 복사본.
- **주의**: 기본 슬라이싱 결과는 **뷰(view)** 라 원본과 메모리를 공유한다. 수정할 거면 `.copy()`. → [[얕은 복사·깊은 복사]]
- 조건으로 고르는 방법은 [[불리언 인덱싱]] 참고.

## 수식·원리
```
x = [[0, 1, 2],
     [3, 4, 5]]
x[1, 2]   → 5        (1행 2열)
x[:, 1]   → [1, 4]   (모든 행의 1열)
x[0, ::2] → [0, 2]   (0행, 2칸 간격)
```

## 코드 예시
```python
import numpy as np

a = np.arange(10)          # [0 1 2 ... 9]
print(a[1:4], a[-1], a[::3])     # [1 2 3] 9 [0 3 6 9]

x = np.arange(6).reshape(2, 3)
print(x[1, 2], x[:, 1], x[0, ::2])   # 5 [1 4] [0 2]

# 열 이름으로 특징 선택 (보스턴 데이터 방식)
names = np.array(["CRIM", "RM", "LSTAT"])
data = np.array([[0.1, 6.5, 4.9], [0.2, 7.1, 9.1]])
print(data[:, names == "RM"])        # [[6.5] [7.1]]  → (N, 1) 모양 유지
print(a[[0, 2]])                     # [0 2] 팬시 인덱싱
```
