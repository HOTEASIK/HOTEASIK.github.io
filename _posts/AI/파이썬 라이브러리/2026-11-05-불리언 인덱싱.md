# 불리언 인덱싱

## 정의·핵심
- **정의**: 배열에 조건을 걸어 True/False로 된 **마스크(Mask)** 를 만들고, True인 위치의 값만 골라내는 방법.
- 마스크는 원래 배열과 같은 모양의 bool 배열이다. `x > 0` → `[True, False, ...]`
- 조건 여러 개는 `&`(그리고), `|`(또는), `~`(부정)로 묶고 **각 조건은 괄호로 감싼다.** (`and`, `or`는 쓸 수 없음)
- **딥러닝·머신러닝 활용**
  - 노이즈 제거: 정상 범위를 벗어난 이상치(Outlier) 삭제·보정
  - 분류 결정: 확률이 0.5 이상이면 1 → `(probs >= 0.5).astype(int)`
  - 데이터 추출: 특정 클래스만 뽑기 `x[y == 0]` (iris에서 클래스별 산포도)
  - 결측치 처리: `np.isnan(x)`로 NaN 위치 찾기
  - 정확도 계산: `(pred == label).sum()` → True 개수 = 맞힌 개수
- **PyTorch도 같다**: `outputs[labels == 1]`, `(predicted == labels).sum().item()`

## 수식·원리
```
x    = [10, -5, 30, -2]
mask = x > 0          → [True, False, True, False]
x[mask]               → [10, 30]
```

## 코드 예시
```python
import numpy as np

x = np.array([10, -5, 30, -2])
mask = x > 0
print(mask, x[mask])                 # [ True False  True False] [10 30]

x2 = x.copy()
x2[x2 < 0] = 0                       # 음수를 0으로 보정
print(x2)                            # [10  0 30  0]

probs = np.array([0.1, 0.9, 0.4, 0.7])
labels = np.array([0, 1, 1, 1])
pred = (probs >= 0.5).astype(int)    # 임계값 0.5로 분류
print(pred, (pred == labels).mean()) # [0 1 0 1] 0.75

y = np.array([0, 1, 0, 2])
print(np.where((y == 0) | (y == 2))) # (array([0, 2, 3]),)
```
