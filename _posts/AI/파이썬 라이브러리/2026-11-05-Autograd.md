# Autograd

## 정의·핵심
- **정의**: PyTorch의 **자동 미분** 기능. 순전파 계산만 쓰면, 그 과정을 **계산 그래프**로 기록해 두었다가 `backward()` 한 번으로 모든 파라미터의 기울기를 계산해 준다.
- **PyTorch가 대신해 주는 것**: 복잡한 미분 계산을 개발자가 직접 할 필요가 없다 → 모델 구조·아이디어에 집중 (1차시)
- **세 가지 요소**
  1. `requires_grad=True` 텐서: 추적 시작 → [[requires_grad]]
  2. `loss.backward()`: 출력(스칼라)에서 거꾸로 **연쇄 법칙**을 적용해 기울기 계산 (역전파)
  3. `.grad`: 계산된 기울기가 저장되는 곳
  - `grad_fn`: 결과 텐서를 만든 연산(예: `MulBackward0`). 그래프의 연결고리
- **수치 미분과 비교**: 수치 미분과 결과가 같지만(12.0) 훨씬 빠르고 정확하다. → [[수치 미분]]
- **중요한 동작 규칙**
  - **기울기는 누적(+=)된다** → 매 반복 전에 `optimizer.zero_grad()`(또는 `W.grad.zero_()`)로 0으로 비워야 한다. 안 비우면 이전 기울기가 더해져 학습이 망가진다.
  - `backward()`는 **스칼라**에 대해 부른다 (손실은 mean·sum으로 하나의 값). 벡터면 `y.sum().backward()` (3차시 `z.backward()` 전에 sum)
  - 한 번 backward 하면 그래프가 해제된다 (다시 하려면 `retain_graph=True`)
- **활용**: 3차시 — 2차 함수 $y=2x^2+2$의 기울기, 시그모이드 함수의 기울기 그래프 그리기

## 수식·원리
- 연쇄 법칙: $\dfrac{\partial L}{\partial W} = \dfrac{\partial L}{\partial \hat y}\cdot\dfrac{\partial \hat y}{\partial W}$
- 시그모이드 미분: $\sigma'(x) = \sigma(x)(1-\sigma(x))$ (최댓값 0.25)

## 코드 예시
```python
import torch

x = torch.tensor(3.0, requires_grad=True)
y = 2 * x**2 + 2
y.backward()
print(x.grad)                          # tensor(12.)

# 기울기 누적 확인
y = 2 * x**2 + 2
y.backward()
print(x.grad)                          # tensor(24.) ← 12 + 12
x.grad.zero_()

# 벡터 출력은 sum 후 backward
xs = torch.linspace(-2, 2, 5, requires_grad=True)
s = torch.sigmoid(xs)
s.sum().backward()
print(xs.grad.round(decimals=4))       # tensor([0.1050, 0.1966, 0.2500, 0.1966, 0.1050])
print(s.grad_fn.__class__.__name__)    # SigmoidBackward0
```
