# 얕은 복사·깊은 복사

## 정의·핵심
- **참조 복사(대입)**: `y = x`. 새 객체를 만들지 않고 같은 객체를 가리킨다. 한쪽을 고치면 다른 쪽도 바뀐다.
- **얕은 복사(shallow copy)**: 바깥 컨테이너만 새로 만들고, **안에 든 객체는 공유**한다. `list.copy()`, `copy.copy()`, 슬라이싱 `x[:]`.
- **깊은 복사(deep copy)**: 안쪽 객체까지 모두 새로 만든다. 완전히 독립된 복사본. `copy.deepcopy()`.
- **NumPy·Tensor**
  - `arr.copy()` → 새 메모리에 값을 복사 (숫자 배열이라 사실상 깊은 복사)
  - 슬라이싱 `arr[1:3]`은 **뷰(view)** 라서 원본과 메모리를 공유한다 (리스트 슬라이싱과 다름!)
  - Tensor는 `t.clone()`으로 복사한다. 학습 그래프에서 떼어 내려면 `t.detach().clone()`
- **언제 문제가 되나**
  - 전처리에서 원본 데이터를 지키고 싶을 때
  - 학습 중 "가장 좋았던 모델 가중치"를 저장할 때: `best = model.state_dict()`만 하면 계속 바뀌는 값을 가리키므로 `copy.deepcopy(model.state_dict())`로 저장해야 한다.

## 수식·원리

| 방법 | 바깥 객체 | 안쪽 객체 |
|---|---|---|
| `y = x` | 공유 | 공유 |
| `copy.copy(x)` | 새로 만듦 | 공유 |
| `copy.deepcopy(x)` | 새로 만듦 | 새로 만듦 |

## 코드 예시
```python
import copy
import numpy as np

# 1) 리스트: 얕은 복사의 함정 (안쪽 리스트는 공유)
a = [[1, 2], [3, 4]]
s = copy.copy(a)
d = copy.deepcopy(a)
a[0][0] = 99
print(s[0][0], d[0][0])   # 99 1

# 2) NumPy: copy()로 원본 보호
x = np.array([5, 7, 9])
y = x.copy()
x[0] = 100
print(y)                  # [5 7 9]

# 3) NumPy 슬라이싱은 뷰(view)
v = x[0:2]
v[1] = -1
print(x)                  # [100  -1   9]  ← 원본도 바뀜
```
