# plt.plot·scatter

## 정의·핵심
- **Matplotlib**: 파이썬 기본 시각화 라이브러리. `import matplotlib.pyplot as plt`
- **시각화가 왜 필요한가**: 숫자로만 보이는 데이터에 형태를 준다. (2차시)
  - 데이터 탐색(EDA): 분포, 이상치, 경향 확인
  - 모델 진단: 손실 곡선, 과적합 여부 확인 → [[학습 곡선 그리기]]
- **`plt.plot(x, y)` 선 그래프**: 순서가 있는 값의 변화. 학습 곡선, 함수 그래프(시그모이드·ReLU 모양), 회귀 직선
  - 형식 문자열: `'b-'` 파란 실선, `'r--'` 빨간 점선, `'o'` 점
- **`plt.scatter(x, y)` 산점도**: 두 변수의 관계를 점으로. 머신러닝 데이터 분석에서 먼저 볼 4가지
  1. 상관관계: 비례·반비례 (방 개수 RM이 늘면 집값도 오르나 — 7차시)
  2. 군집: 끼리끼리 뭉친 그룹
  3. 이상치: 패턴에서 벗어난 점
  4. 분리 가능성: 클래스를 선으로 나눌 수 있나 → 결정 경계 (8차시 iris)
- **필수 5요소**: 제목 `title`, 축 이름 `xlabel`·`ylabel`, 범례 `legend`(plot에 `label=` 필요), 격자 `grid`
- "그래프가 스스로를 설명하지 못하면 나쁜 그래프"(2차시)
- **크기·스타일**: `plt.figure(figsize=(10, 6), dpi=100)`, `plt.style.use('seaborn-v0_8')`

## 수식·원리
- 산포도 위에 회귀 직선 겹치기: x 범위를 `np.array([x.min(), x.max()])`로 잡고 $y = wx + b$를 계산해 `plt.plot`으로 그린다. (7차시)

## 코드 예시
```python
import numpy as np
import matplotlib
matplotlib.use("Agg")               # 화면 없이 파일로 저장 (Colab·Jupyter에선 생략)
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
x = rng.uniform(4, 9, 50)                 # 방 개수(RM) 흉내
y = 9 * x - 35 + rng.normal(0, 3, 50)     # 집값

w, b = np.polyfit(x, y, 1)                # 최소제곱 직선
xr = np.array([x.min(), x.max()])

plt.figure(figsize=(6, 4))
plt.scatter(x, y, s=10, c="b", label="data")
plt.plot(xr, w * xr + b, "r-", lw=2, label="regression")
plt.title("RM vs Price"); plt.xlabel("RM"); plt.ylabel("Price")
plt.legend(); plt.grid(True)
plt.savefig("scatter.png")
print(round(w))                           # 9 (기울기 약 9)
```
