# subplots

## 정의·핵심
- **정의**: 한 그림(Figure) 안에 여러 개의 그래프 칸(Axes)을 격자로 만드는 함수. `fig, axes = plt.subplots(행, 열)`
- **Figure와 Axes**
  - Figure: 전체 도화지
  - Axes: 도화지 안의 그래프 한 칸. 축·제목·데이터를 가진다.
- **두 가지 그리기 방식**
  - `plt.plot(...)`: "지금 선택된 칸"에 그림 (간단할 때)
  - `ax.plot(...)`: 특정 칸을 골라서 그림 (여러 칸일 때). 제목은 `ax.set_title`, 축 이름은 `ax.set_xlabel`처럼 `set_`이 붙는다.
- **딥러닝에서 쓰임**
  - 학습 곡선 2개(손실·정확도) 나란히
  - 이미지 여러 장을 격자로 보기: MNIST·CIFAR 샘플 50장, 오분류 샘플 (10·12차시)
  - 손실함수 비교 4종 그래프 (6차시 실습 1-4)
- `axes`는 2차원 배열이다. 반복문에서 `axes.flat` 또는 `axes.ravel()`로 펼쳐 쓴다.
- `plt.tight_layout()`: 칸끼리 글자가 겹치지 않게 간격 조정. `ax.axis('off')`: 이미지 칸의 눈금 숨기기.

## 수식·원리
```
fig, axes = plt.subplots(2, 3)
axes.shape → (2, 3)
axes[0, 1] → 첫 줄 두 번째 칸
```

## 코드 예시
```python
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

images = np.random.rand(10, 28, 28)        # 가짜 MNIST 10장
labels = np.arange(10)

fig, axes = plt.subplots(2, 5, figsize=(10, 4))
print(axes.shape)                          # (2, 5)
for ax, img, lb in zip(axes.flat, images, labels):
    ax.imshow(img, cmap="gray")
    ax.set_title(f"label {lb}")
    ax.axis("off")
plt.tight_layout()
plt.savefig("grid.png")
```
