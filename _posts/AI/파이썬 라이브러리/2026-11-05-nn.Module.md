# nn.Module

## 정의·핵심
- **정의**: PyTorch의 모든 신경망 모델·레이어의 **부모 클래스**. 직접 만드는 모델은 `class Net(nn.Module):`로 상속한다.
- **두 부분으로 나뉜다** (7차시 "모델을 정의하는 본질적인 부분")
  1. `__init__`: **재료(레이어) 준비**. `super().__init__()`을 먼저 부르고, 학습할 레이어를 `self.l1 = nn.Linear(...)`처럼 **속성으로 저장**한다.
  2. `forward(self, x)`: **계산 순서** 정의. 입력이 레이어를 어떤 순서로 통과하는지 쓴다.
- **호출**: `net(inputs)` → `__call__` → `forward` 실행. `forward`를 직접 부르지 않는다. → [[__call__ 메서드]]
- **nn.Module이 해 주는 것**
  - `self.`에 저장한 레이어의 파라미터를 **자동 등록** → `net.parameters()`로 옵티마이저에 넘김 → [[parameters·named_parameters]]
  - `.to(device)`로 모든 파라미터를 한 번에 GPU로
  - `.train()` / `.eval()` 모드 전환 (Dropout·BN) → [[train()·eval() 모드]]
  - `state_dict()`로 저장·불러오기 → [[state_dict 저장·불러오기]]
  - `print(net)`으로 구조 출력
- **자주 하는 실수**
  - `super().__init__()` 빠뜨림 → `AttributeError: cannot assign module before Module.__init__() call`
  - 레이어를 지역 변수나 파이썬 리스트에 넣음 → 파라미터 등록 안 됨. 리스트는 `nn.ModuleList` 사용 (8차시: `self.fc1`처럼 인스턴스 변수로 저장해야 함)
  - 파라미터 없는 함수(ReLU)는 `__init__`에 만들어도 되고 forward에서 `torch.relu`로 써도 된다.

## 수식·원리
```
class Net(nn.Module):
    def __init__(self, n_input, n_output):   ← 레이어 준비
        super().__init__()
        self.l1 = nn.Linear(n_input, n_output)
    def forward(self, x):                    ← 계산 순서
        return self.l1(x)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class Net(nn.Module):
    def __init__(self, n_input, n_output, n_hidden):
        super().__init__()
        self.l1 = nn.Linear(n_input, n_hidden)
        self.l2 = nn.Linear(n_hidden, n_output)
        self.relu = nn.ReLU(inplace=True)
    def forward(self, x):
        return self.l2(self.relu(self.l1(x)))

net = Net(784, 10, 128)
print(net(torch.randn(500, 784)).shape)      # torch.Size([500, 10])
print(sum(p.numel() for p in net.parameters()))   # 101770

class Bad(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = [nn.Linear(2, 2)]       # 파이썬 리스트 → 등록 안 됨
print(len(list(Bad().parameters())))         # 0
```
