# timm

## 정의·핵심
- **정의**: PyTorch Image Models. **수백 가지 이미지 분류 모델과 사전학습 가중치**를 제공하는 라이브러리. `pip install timm`, `import timm`
- **torchvision.models와 비교**
  - torchvision: 대표 모델 위주(ResNet, VGG, MobileNet…)
  - timm: 최신 모델(ViT, ConvNeXt, EfficientNet, Swin…)과 여러 가중치 버전까지 훨씬 많다
- **핵심 함수 두 개** (강의 노트북에서 사용)
  - `timm.list_models('vit*', pretrained=True)`: 이름 패턴으로 모델 목록 검색
  - `timm.create_model(name, pretrained=True, num_classes=N)`: 모델 생성. **`num_classes`만 주면 출력층을 알아서 교체**해 준다 (torchvision은 직접 `fc` 교체)
- **전처리 정보**: `timm.data.resolve_data_config({}, model=model)` → 입력 크기·mean·std, `timm.data.create_transform(**cfg)`로 transform 생성
- `pretrained=False`면 다운로드 없이 구조만 만든다.

## 수식·원리
```
timm.create_model("resnet18", pretrained=True, num_classes=2)
  = torchvision resnet18(weights) + fc 교체(512→2)
```

## 코드 예시
```python
import timm
import torch

print(len(timm.list_models("vit_*")) > 10)            # True
model = timm.create_model("resnet18", pretrained=False, num_classes=2)
print(model(torch.randn(1, 3, 224, 224)).shape)       # torch.Size([1, 2])
print(model.get_classifier())                          # Linear(in_features=512, out_features=2, bias=True)

cfg = timm.data.resolve_data_config({}, model=model)
print(cfg["input_size"])                               # (3, 224, 224)
```
