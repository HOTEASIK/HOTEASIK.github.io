# 텐서 차원

## 정의·핵심
- **차원(축) 수에 따른 이름** (3차시)
  - **0차원 — 스칼라**: 숫자 하나. `tensor(5.)`, shape `[]`. 손실값(loss)이 0차원이다.
  - **1차원 — 벡터**: 한 축으로 나열. `[1, 2, 3]`, shape `[3]`. bias, 정답 라벨 묶음
  - **2차원 — 행렬**: 행·열. shape `[N, D]`. 표 형태 데이터 배치, Linear의 weight
  - **3차원 이상**: 컬러 이미지 `[C, H, W]`, 시계열·문장 `[N, L, D]`
  - **4차원**: 이미지 배치 `[N, C, H, W]` — CNN 입력의 표준
- **PyTorch 이미지 규칙 = CHW(채널 먼저)**
  - MNIST 한 장: `[1, 28, 28]` (흑백 1채널) / CIFAR10 한 장: `[3, 32, 32]` (RGB)
  - 배치로 묶으면 `[N, C, H, W]` — 예: `[500, 1, 28, 28]`
  - OpenCV·PIL·Matplotlib은 **HWC(채널 나중)** → `permute`로 바꿔야 한다. → [[imshow]]
- **Linear 층은 `[N, 특징]` 2차원**을 받는다. 이미지를 MLP에 넣으려면 `[N, 784]`로 펴야 한다 (Flatten, `view(-1)`). 1개 샘플이라도 `[1, D]`로 배치 차원을 둔다.
- **확인 방법**: `t.shape`(= `t.size()`), `t.ndim`(= `t.dim()`), `t.numel()`(요소 수)

## 수식·원리
```
스칼라  []            loss
벡터    [D]           bias, labels
행렬    [N, D]        tabular 배치, weight [out, in]
3D      [C, H, W]     이미지 1장
4D      [N, C, H, W]  이미지 배치
```

## 코드 예시
```python
import torch

loss = torch.tensor(0.25)
print(loss.ndim, loss.shape)          # 0 torch.Size([])

img = torch.zeros(1, 28, 28)          # MNIST 1장 (CHW)
batch = torch.zeros(500, 1, 28, 28)   # 배치 (NCHW)
print(batch.ndim, batch.numel())      # 4 392000

flat = batch.view(500, -1)            # MLP 입력용
print(flat.shape)                     # torch.Size([500, 784])

hwc = torch.zeros(3, 32, 32).permute(1, 2, 0)   # CHW → HWC
print(hwc.shape)                      # torch.Size([32, 32, 3])
```
