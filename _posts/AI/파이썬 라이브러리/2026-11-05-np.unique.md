# np.unique

## 정의·핵심
- **정의**: 배열에서 **중복을 없앤 고유값**을 정렬해서 돌려준다.
- **`return_counts=True`**: 각 고유값이 **몇 번 나왔는지**도 함께 돌려준다.
- **딥러닝에서 쓰임**
  - 라벨에 어떤 클래스가 있는지 확인 (클래스 수 정하기)
  - **클래스 분포 확인** → 클래스 불균형인지 판단 (8차시 사기거래: 정상 95%, 사기 5%)
  - 클래스 가중치·`pos_weight` 계산의 재료 (정상 수 / 사기 수)
  - `stratify` 분할 후 비율이 유지됐는지 확인
- **비슷한 도구 비교**
  - `set(x)`: 파이썬 집합, 순서 없음
  - `np.unique(x)`: 정렬된 고유값 배열
  - `pandas.Series.nunique()`: 고유값의 **개수**만
  - `torch.unique(t, return_counts=True)`: 텐서용

## 수식·원리
```
y = [0, 1, 0, 0, 2, 1]
np.unique(y)                      → [0, 1, 2]
np.unique(y, return_counts=True)  → ([0, 1, 2], [3, 2, 1])
```

## 코드 예시
```python
import numpy as np

y = np.array([0] * 95 + [1] * 5)          # 정상 95, 사기 5
classes, counts = np.unique(y, return_counts=True)
print(classes, counts)                    # [0 1] [95  5]
print(counts / counts.sum())              # [0.95 0.05]  → 불균형

pos_weight = counts[0] / counts[1]        # BCEWithLogitsLoss의 pos_weight 재료
print(pos_weight)                         # 19.0

print(set([3, 1, 3]), len(np.unique([3, 1, 3])))   # {1, 3} 2
```
