# Dataset

## 정의·핵심
- **정의**: 데이터 **한 개(샘플)를 꺼내 주는 규칙**을 정의한 클래스. `torch.utils.data.Dataset`
- **데이터 파이프라인 3단계** (10차시): Dataset(한 장씩 꺼내기) → Transforms(전처리) → DataLoader(배치로 묶기)
  - "편의점 알바 비유: Dataset은 진열대에서 물건을 하나씩 꺼내는 것, DataLoader는 그것을 바구니에 담아 나르는 것" (응용 12차시)
- **Custom Dataset 만들기** — 두 메서드만 구현하면 된다
  1. `__len__(self)`: 전체 샘플 수
  2. `__getitem__(self, idx)`: idx번째 샘플을 `(입력, 정답)`으로 돌려줌. 이미지 읽기·transform 적용을 여기서 한다
  - `__init__`에서는 파일 경로 목록·라벨 목록만 준비하고, 실제 이미지는 `__getitem__`에서 읽는다 (메모리 절약)
- **이미 만들어진 Dataset**
  - `TensorDataset(X, y)`: 텐서를 바로 Dataset으로 (표 데이터에 편리)
  - `torchvision.datasets.MNIST` 등 → [[torchvision.datasets]]
  - `ImageFolder`: 폴더 이름 = 클래스 → [[ImageFolder]]
- **분할**: `random_split(ds, [train_n, val_n])` 또는 `Subset(ds, 인덱스)`

## 수식·원리
```
class MyDataset(Dataset):
    def __init__(...):   경로·라벨 목록 준비
    def __len__(self):   return N
    def __getitem__(self, idx):  return transform(x[idx]), y[idx]
ds[i] → (x_i, y_i)       len(ds) → N
```

## 코드 예시
```python
import torch
from torch.utils.data import Dataset, TensorDataset, random_split

class SquareDataset(Dataset):
    def __init__(self, n, transform=None):
        self.x = torch.arange(n, dtype=torch.float32)
        self.transform = transform
    def __len__(self):
        return len(self.x)
    def __getitem__(self, idx):
        x, y = self.x[idx], self.x[idx] ** 2
        if self.transform:
            x = self.transform(x)          # 입력에만 전처리
        return x, y

ds = SquareDataset(10, transform=lambda v: v / 10)
print(len(ds), ds[3])                       # 10 (tensor(0.3000), tensor(9.))

td = TensorDataset(torch.randn(100, 4), torch.randint(0, 2, (100,)))
train_ds, val_ds = random_split(td, [80, 20], generator=torch.Generator().manual_seed(42))
print(len(train_ds), len(val_ds), td[0][0].shape)   # 80 20 torch.Size([4])
```
