# 텐서 dtype

## 정의·핵심
- **dtype**: 텐서 요소의 자료형. 한 텐서 안의 모든 값은 같은 dtype이다.
- **주요 dtype**

| dtype | 별칭·변환 | 쓰임 |
|---|---|---|
| `torch.float32` | `.float()` | **모델 입력·파라미터 기본** |
| `torch.float64` | `.double()` | NumPy 기본 실수 (그대로 넣으면 오류) |
| `torch.float16`·`bfloat16` | `.half()` | 혼합 정밀도(AMP) → [[AMP(혼합 정밀도)]] |
| `torch.int64` | `.long()` | **분류 정답 라벨**, 인덱스 |
| `torch.uint8` | | 이미지 픽셀 0~255 |
| `torch.bool` | | 마스크, 비교 결과 |

- **자주 나는 오류와 이유**
  1. `RuntimeError: mat1 and mat2 must have the same dtype` — 입력이 float64, 모델이 float32 → 입력에 `.float()`
  2. `CrossEntropyLoss` 정답은 **long(정수 클래스 번호)** 이어야 한다. float이면 오류 또는 엉뚱한 해석 → `labels.long()` (9차시)
  3. `BCELoss`·`BCEWithLogitsLoss` 정답은 반대로 **float** (0.0/1.0)이어야 한다. → `labels.float()`
- **변환**: `t.to(torch.float32)`, `t.float()`, `t.long()`, `t.type(torch.int64)`
- **정수끼리 나누기**: `/`는 결과가 float, `//`는 정수 몫. 정확도 계산 시 `correct / total`은 float이 된다.

## 수식·원리
```
NumPy float64 ──torch.tensor──▶ float64 ──.float()──▶ float32 (모델 입력)
분류 라벨 ──.long()──▶ int64      (CrossEntropyLoss, NLLLoss)
이진 라벨 ──.float()──▶ float32   (BCELoss, BCEWithLogitsLoss)
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn

x = torch.tensor(np.array([[1.0, 2.0]]))
print(x.dtype)                               # torch.float64
l = nn.Linear(2, 1)
try:
    l(x)
except RuntimeError as e:
    print("dtype 오류")                       # dtype 오류
print(l(x.float()).dtype)                    # torch.float32

logits = torch.randn(3, 4)
labels = torch.tensor([0.0, 2.0, 1.0])       # float 라벨
loss = nn.CrossEntropyLoss()(logits, labels.long())   # long으로
print(labels.long().dtype)                   # torch.int64
```
