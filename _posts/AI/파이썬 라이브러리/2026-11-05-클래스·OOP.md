# 클래스·OOP

## 정의·핵심
- **클래스(Class)**: 객체를 만들기 위한 **설계도**. (붕어빵 틀)
- **인스턴스(Instance)**: 설계도로 만든 **실체**. (팥 붕어빵) `p = Point(2, 3)`
- **속성(Attribute)**: 객체가 가진 데이터·상태. `self.x`, `self.weight`
- **메서드(Method)**: 객체가 하는 동작. `move()`, `forward()`
- **`__init__`(생성자)**: 인스턴스를 만들 때 자동 실행되어 속성을 초기화한다.
- **`self`**: 메서드 안에서 "지금 이 인스턴스 자신"을 가리킨다. 속성을 `self.이름`으로 저장해야 다른 메서드에서도 쓸 수 있다.
- **상속(Inheritance)**: 부모 클래스의 기능을 물려받는다. `class Net(nn.Module):`
- **`super().__init__()`**: 부모 클래스의 생성자를 먼저 실행한다. PyTorch 모델에서 이 줄을 빼면 레이어 등록이 안 되어 오류가 난다.
- **딥러닝과 연결**: PyTorch 모델은 모두 `nn.Module`을 상속한 클래스다. 레이어(재료)는 `__init__`에서 `self.l1 = ...`로 준비하고, 계산 순서는 `forward()`에 쓴다. → [[nn.Module]]
- **주의**: 학습할 레이어를 `self.`에 저장하지 않고 지역 변수로 두면 파라미터로 등록되지 않아 학습되지 않는다. (8차시 사기거래 탐지 실습)

## 수식·원리
```
클래스(설계도) ──생성──▶ 인스턴스(실체)
   ├─ 속성: 데이터 (self.x)
   └─ 메서드: 동작 (move, forward)
```

## 코드 예시
```python
class Point:
    def __init__(self, x, y):      # 생성자
        self.x = x
        self.y = y

    def move(self, dx, dy):        # 메서드
        self.x += dx
        self.y += dy

    def coord(self):
        return (self.x, self.y)

p = Point(2, 3)
p.move(1, -1)
print(p.coord())                   # (3, 2)

# 상속 예: 부모 기능 + 새 기능
class Point3D(Point):
    def __init__(self, x, y, z):
        super().__init__(x, y)     # 부모 생성자 실행
        self.z = z

q = Point3D(1, 2, 3)
q.move(1, 1)
print(q.coord(), q.z)              # (2, 3) 3
```
