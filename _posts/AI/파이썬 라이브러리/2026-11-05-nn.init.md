# nn.init

## 정의·핵심
- **정의**: 파라미터의 **초기값을 정하는 함수 모음**. `torch.nn.init`. 함수 이름 끝의 `_`는 "제자리(in-place)에서 바꾼다"는 뜻.
- **왜 초기화가 중요한가**: 처음 가중치가 너무 크면 출력·기울기가 폭주하고, 너무 작으면 층을 지날수록 신호가 사라진다(기울기 소실). 층 구조·활성화 함수에 맞는 분산으로 시작해야 깊은 망이 학습된다. (5차시)
- **주요 함수**

| 함수 | 내용 | 쓰는 곳 |
|---|---|---|
| `constant_(t, v)` | 모두 v로 | 실습에서 결과를 손으로 확인할 때 (7·8차시 weight=1, bias=1) |
| `zeros_`·`ones_` | 0 / 1 | bias 0, BN γ=1 |
| `normal_`·`uniform_` | 정규·균등 난수 | 일반 |
| `xavier_normal_`·`xavier_uniform_` | 분산 $\frac{2}{n_{in}+n_{out}}$ | **Sigmoid·Tanh** 층 |
| `kaiming_normal_`(He) | 분산 $\frac{2}{n_{in}}$ | **ReLU** 층, CNN |
| `orthogonal_` | 직교 행렬 | LSTM·GRU |

- **5차시 권장 조합**: CNN+ReLU → `kaiming_normal_(w, mode='fan_in', nonlinearity='relu')`, Linear+Tanh → `xavier_normal_`, LSTM/GRU → `orthogonal_`
- **PyTorch 기본값**: `nn.Linear`·`nn.Conv2d`는 이미 Kaiming 균등분포 계열로 초기화되어 있어 보통은 따로 안 해도 된다.
- **모델 전체에 적용**: `net.apply(init_fn)` — 모든 하위 모듈에 함수를 실행
- 개념 설명은 04의 [[Xavier(Glorot) 초기화]], [[He(Kaiming) 초기화]], [[Orthogonal 초기화]] 참고

## 수식·원리
- Xavier: $\mathrm{Var}(W)=\dfrac{2}{n_{in}+n_{out}}$
- He: $\mathrm{Var}(W)=\dfrac{2}{n_{in}}$ (ReLU가 절반을 0으로 만들어 분산을 2배로 보정)

## 코드 예시
```python
import torch
import torch.nn as nn

l1 = nn.Linear(1, 1)
nn.init.constant_(l1.weight, 2.0)
nn.init.constant_(l1.bias, 1.0)
print(l1(torch.tensor([[3.0]])).item())      # 7.0  (y = 2x + 1)

def init_fn(m):
    if isinstance(m, nn.Conv2d):
        nn.init.kaiming_normal_(m.weight, mode="fan_in", nonlinearity="relu")
        nn.init.zeros_(m.bias)
    elif isinstance(m, nn.Linear):
        nn.init.xavier_normal_(m.weight)

torch.manual_seed(0)
net = nn.Sequential(nn.Conv2d(3, 64, 3), nn.ReLU(), nn.Flatten(), nn.Linear(10, 10))
net.apply(init_fn)
std = net[0].weight.std().item()
print(round(std, 2), round((2 / (3 * 3 * 3)) ** 0.5, 2))   # 두 값이 비슷함 (He 표준편차 ≈ 0.27)
```
