# 컨테이너 타입

## 정의·핵심
- **정의**: 여러 값을 한 변수에 담는 자료형. 리스트(list), 튜플(tuple), 딕셔너리(dict), 집합(set), 넘파이 배열(ndarray), 텐서(Tensor)가 여기에 속한다.
- **참조형이라는 점이 핵심**: 컨테이너 변수는 값 자체가 아니라 **데이터가 있는 메모리 주소(참조)** 를 저장한다. 그래서 `y = x`로 대입하면 값이 복사되지 않고 두 변수가 같은 데이터를 가리킨다.
- **왜 중요한가**: 데이터 전처리 중에 복사본을 고친다고 생각했는데 원본이 함께 바뀌는 사고가 자주 난다. 원본을 지키려면 [[얕은 복사·깊은 복사]]를 알아야 한다.
- **종류별 특징**

| 종류 | 변경 가능 | 특징 | 딥러닝에서 쓰임 |
|---|---|---|---|
| list | O | 여러 타입을 섞어 담음, 느림 | 손실 기록(history), 배치 모으기 |
| tuple | X | 바꿀 수 없음 | shape 표현 `(N, C, H, W)` |
| dict | O | 키-값 쌍 | 설정값(config), `state_dict` |
| ndarray | O | 한 가지 타입, 연속 메모리, 빠름 | 전처리, 수치 연산 → [[ndarray]] |
| Tensor | O | ndarray + 자동 미분 + GPU | 모델 입력·파라미터 → [[Tensor 생성]] |

- **List → NumPy → PyTorch 흐름**: 리스트는 범용이지만 느리고, NumPy는 같은 타입을 연속 메모리에 담아 빠르며, Tensor는 NumPy에 기울기(grad)와 GPU 연산을 더한 것이다.

## 수식·원리
- 변수 = 이름표, 컨테이너 = 메모리 위의 상자. `y = x`는 상자를 하나 더 만드는 것이 아니라 **같은 상자에 이름표를 하나 더 붙이는 것**이다.
- `id()`로 메모리 주소를 확인할 수 있고, `is`는 같은 객체인지 비교한다.

## 코드 예시
```python
import numpy as np

x = np.array([5, 7, 9])
y = x               # 참조만 복사
x[0] = 100
print(y)            # [100   7   9]  ← y도 바뀜
print(x is y)       # True (같은 객체)

config = {"lr": 0.01, "epochs": 10}   # dict: 설정값 관리
shape = (100, 1, 28, 28)              # tuple: 텐서 모양
print(config["lr"], shape[0])         # 0.01 100
```
