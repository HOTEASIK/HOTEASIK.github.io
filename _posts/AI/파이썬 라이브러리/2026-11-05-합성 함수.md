# 합성 함수

## 정의·핵심
- **정의**: 한 함수의 출력을 다음 함수의 입력으로 넣어 이어 붙인 함수. $y = f_3(f_2(f_1(x)))$
- **딥러닝 = 거대한 합성 함수**: 신경망은 레이어(함수)를 순서대로 연결한 구조다. 입력이 여러 층을 통과하며 결과로 바뀌는 과정이 **순전파(Forward)** 이다.
  - 예: `Linear → ReLU → Linear` = $f_3(f_2(f_1(x)))$
- **역전파와 연결**: 합성 함수의 미분은 **연쇄 법칙(Chain Rule)** 으로 각 함수의 미분을 곱해서 구한다. 역전파는 이 합성을 출력에서 입력 방향으로 거꾸로 거슬러 올라가며 기울기를 계산하는 것이다. → [[역전파]]
- **PyTorch에서**: `nn.Sequential(l1, relu, l2)`가 레이어들을 하나의 합성 함수로 묶어 준다. → [[nn.Sequential]]

## 수식·원리
- 합성: $y = f_L(\cdots f_2(f_1(x)))$
- 연쇄 법칙: $\dfrac{dy}{dx} = \dfrac{dy}{du_2}\cdot\dfrac{du_2}{du_1}\cdot\dfrac{du_1}{dx}$ (여기서 $u_1=f_1(x)$, $u_2=f_2(u_1)$)
- 강의 예시: $f_1(x)=x^2,\ f_2(x)=2x,\ f_3(x)=x+2$
  - $f_1(3)=9 \rightarrow f_2(9)=18 \rightarrow f_3(18)=20$

## 코드 예시
```python
def f1(x): return x ** 2    # 제곱
def f2(x): return 2 * x     # 2배
def f3(x): return x + 2     # +2

y = f3(f2(f1(3)))
print(y)                    # 20

# PyTorch: 레이어를 합성 함수로
import torch
import torch.nn as nn

net = nn.Sequential(nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10))
x = torch.randn(100, 784)
print(net(x).shape)         # torch.Size([100, 10])
```
