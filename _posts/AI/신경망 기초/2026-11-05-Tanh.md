# Tanh

## 정의·핵심
- **정의**: 쌍곡탄젠트(Hyperbolic Tangent). 실수를 **−1~1 사이**로 바꾸는 S자 함수. 모양은 Sigmoid를 세로로 2배 늘리고 아래로 내린 것.
- **장점 — 출력 중심화(Zero-centered)**: 출력이 0을 중심으로 양·음 모두 나와서, 다음 층 입력의 평균이 0 근처 → Sigmoid보다 **최적화 효율이 좋다**
- **기울기 최대 1**: z=0에서 도함수 1 (Sigmoid의 4배) → 소실이 덜하다
- **단점**: 여전히 양 끝단(|z|가 큰 곳)에서 기울기가 0에 가까워지는 **포화 → 기울기 소실** 문제가 남아 있다
- **지금 쓰이는 곳**
  - **RNN·LSTM·GRU 내부**: 은닉 상태·셀 후보값을 −1~1로 제한 (값이 시간에 따라 폭주하지 않도록)
  - 출력을 −1~1 범위로 내야 할 때: GAN 생성기 출력 이미지(정규화된 −1~1 픽셀), 강화학습의 연속 행동
  - 작은 MLP(XOR 실습)

## 수식·원리
```
tanh(z) = (e^z − e^(−z)) / (e^z + e^(−z)) = 2σ(2z) − 1     범위 (−1, 1)
tanh'(z) = 1 − tanh²(z)                                  최대 1 (z = 0)
```

## 코드 예시
```python
import torch

z = torch.tensor([-3.0, -1.0, 0.0, 1.0, 3.0], requires_grad=True)
t = torch.tanh(z)
print([round(v, 3) for v in t.tolist()])                # [-0.995, -0.762, 0.0, 0.762, 0.995]
print(torch.allclose(t, 2 * torch.sigmoid(2 * z) - 1))  # True
t.sum().backward()
print([round(v, 3) for v in z.grad.tolist()])           # [0.01, 0.42, 1.0, 0.42, 0.01]
```
