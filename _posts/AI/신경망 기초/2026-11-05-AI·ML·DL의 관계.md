# AI·ML·DL의 관계

## 정의·핵심
- **포함 관계**: 인공지능(AI) ⊃ 머신러닝(ML) ⊃ 딥러닝(DL) (개론 4차시)
- **AI (인공지능)**: 사람처럼 생각·판단하는 **모든 기술**. 가장 넓은 개념. 사람이 규칙을 직접 짜 넣은 프로그램(규칙 기반)도 포함
  - 예: 체스 두는 컴퓨터, 번역기, 챗봇
- **ML (머신러닝)**: **데이터로부터 스스로 규칙을 학습**하는 AI. 사람은 규칙 대신 데이터와 정답을 준다
  - 예: 스팸 메일 필터 (스팸 예시를 보고 학습), 선형회귀, 로지스틱 회귀, 결정 트리
  - 전통 ML은 사람이 **특징(feature)을 직접 설계**해서 넣는 경우가 많다 (예: HOG, 색 히스토그램)
- **DL (딥러닝)**: 인간 뇌처럼 **여러 층(Layer)의 신경망**으로 학습하는 ML
  - 예: 얼굴 인식, 자율주행, 번역, ChatGPT
  - **특징 추출까지 스스로 학습**한다 (원본 픽셀 → 엣지 → 모양 → 물체)
  - 대신 **데이터와 연산(GPU)이 많이 필요**
- **딥러닝의 기본 블록**: `Linear(선형 변환 Wx+b) + Activation(비선형)`의 반복. MLP·CNN·Transformer 모두 이 구조의 확장 ("CNN, Transformer도 결국 이 구조의 반복입니다")

## 수식·원리
```
규칙 기반:  사람이 규칙 작성 + 데이터 → 답
머신러닝:   데이터 + 정답 → (학습) → 규칙(모델)
딥러닝:     원본 데이터 + 정답 → (여러 층이 특징까지 학습) → 모델
```

## 코드 예시
```python
import torch.nn as nn

# 머신러닝(선형 모델) = 층 1개
ml = nn.Linear(4, 1)
# 딥러닝 = Linear + 활성화 를 여러 층 쌓음
dl = nn.Sequential(nn.Linear(4, 32), nn.ReLU(), nn.Linear(32, 32), nn.ReLU(), nn.Linear(32, 1))
print(sum(p.numel() for p in ml.parameters()), sum(p.numel() for p in dl.parameters()))   # 5 1249
```
