# Softmax

## 정의·핵심
- **정의**: 클래스별 점수(로짓) 벡터를 **각 값이 0~1이고 합이 1인 확률 분포**로 바꾸는 함수. **다중분류 출력층**의 표준 (개론 9·10차시)
- **계산**: 각 점수에 지수 `e^z`를 취해 모두 양수로 만든 뒤, 전체 합으로 나눈다
  - 지수 때문에 **큰 점수는 더 크게, 작은 점수는 더 작게** 벌어진다 → 가장 큰 값이 확률을 대부분 가져감
  - 순서는 유지된다 → `argmax(softmax(z)) = argmax(z)` (예측 라벨만 필요하면 softmax 없이 argmax)
- **hard max와 비교**
  - **hard max(argmax, 원-핫)**: 가장 큰 것만 1, 나머지 0 → `[0, 1, 0]`. 미분 불가(기울기 0) → 학습에 못 씀
  - **Softmax ("부드러운 max")**: `[0.09, 0.67, 0.24]`처럼 확신 정도까지 표현, **미분 가능** → 역전파 가능
  - **Temperature T**: `softmax(z/T)` — T가 작을수록 hard max에 가까워지고, 클수록 균등해진다 (지식 증류, 생성 모델 샘플링, [[Temperature Scaling]])
- **PyTorch 사용 주의**
  - `nn.CrossEntropyLoss`는 **내부에 LogSoftmax가 들어 있다** → 모델 출력에 Softmax를 넣지 말고 **로짓 그대로** 넘긴다 (두 번 적용하면 학습이 잘 안 됨) → [[CrossEntropyLoss]]
  - 확률이 필요할 때만 `torch.softmax(logits, dim=1)` — **dim=1(클래스 축)** 지정 필수
- **수치 안정성**: `e^1000`은 overflow → 최댓값을 빼고 계산해도 결과가 같다 (`softmax(z) = softmax(z − max z)`) → [[log-sum-exp trick]]
- 이진분류는 클래스 2개 Softmax = Sigmoid와 같다

## 수식·원리
```
softmax(z)ᵢ = e^(zᵢ) / Σⱼ e^(zⱼ)          0 < pᵢ < 1,  Σ pᵢ = 1
softmax(z − c) = softmax(z)                (c = max z로 overflow 방지)
2클래스: softmax([z, 0])₀ = σ(z)
```

## 코드 예시
```python
import torch

z = torch.tensor([[1.0, 3.0, 2.0]])
p = torch.softmax(z, dim=1)
print([round(v, 2) for v in p[0].tolist()], round(p.sum().item(), 4))   # [0.09, 0.67, 0.24] 1.0
print(torch.argmax(p, dim=1).item(), torch.argmax(z, dim=1).item())   # 1 1  ← 순서 유지

hard = torch.nn.functional.one_hot(z.argmax(1), 3)
print(hard.tolist())                                            # [[0, 1, 0]]  hard max
print([round(v, 2) for v in torch.softmax(z / 0.1, 1)[0].tolist()])   # [0.0, 1.0, 0.0]  T 작으면 hard max에 가까움

big = torch.tensor([1000.0, 1001.0])
print(torch.softmax(big, 0).tolist())                           # [0.2689..., 0.7310...]  내부에서 max를 빼서 안정
```
