# 선형 모델의 한계와 비선형성

## 정의·핵심
- **선형 모델**: `y = Wx + b`. 모든 딥러닝의 시작이자 기본 단위 ("모든 딥러닝의 시작은 '선형 모델'")
- **한계 1 — 직선(평면)만 그린다**: 결정 경계가 항상 직선이라 XOR, 원형, 나선형처럼 **휘어진 경계가 필요한 데이터**를 구분할 수 없다
- **한계 2 — 쌓아도 소용없다**: **선형 함수의 합성은 여전히 선형** (Linear + Linear = Linear). 층을 100개 쌓아도 하나의 선형 회귀와 수학적으로 같다 → "Deep" Learning이 불가능
- **해결 — 비선형성(Non-linearity)**: 층 사이에 **비선형 활성화 함수**(ReLU, Sigmoid, Tanh…)를 넣는다
  - 공간을 휘고 접어서 복잡한 곡선 경계를 만든다
  - 층을 쌓을수록 표현력(Representation Power)이 커진다
- **보편 근사 정리(Universal Approximation)**: 은닉층 하나 + 비선형 활성화 + 충분한 뉴런이면 어떤 연속 함수든 원하는 만큼 가깝게 근사할 수 있다 (실제로는 깊게 쌓는 편이 효율적)

## 수식·원리
```
W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W'x + b'     ← 결국 선형 1층
W₂·ReLU(W₁x + b₁) + b₂                                   ← 더 이상 하나로 합쳐지지 않음
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
x = torch.randn(5, 3)
two = nn.Sequential(nn.Linear(3, 4), nn.Linear(4, 2))           # 활성화 없음
W = two[1].weight @ two[0].weight
b = two[1].weight @ two[0].bias + two[1].bias
print(torch.allclose(two(x), x @ W.T + b, atol=1e-6))           # True → 선형 1층과 같음

with_relu = nn.Sequential(two[0], nn.ReLU(), two[1])
print(torch.allclose(with_relu(x), x @ W.T + b, atol=1e-6))     # False
```
