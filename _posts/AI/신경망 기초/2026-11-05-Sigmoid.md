# Sigmoid

## 정의·핵심
- **정의**: 어떤 실수든 **0~1 사이 값**으로 바꾸는 S자 곡선 함수. 로지스틱 함수라고도 한다. 기호 σ.
- **확률 해석**: 출력을 "양성(1)일 확률"로 읽을 수 있다 → **이진분류 출력층**의 표준. 0.5를 기준(임계값)으로 0/1 판정 → [[이진분류 출력과 임계값]]
  - 입력 z(로짓)가 0이면 0.5, 크게 양수면 1, 크게 음수면 0에 가까워짐
- **기울기 최대 0.25**: 도함수 `σ'(z) = σ(z)(1 − σ(z))`는 z=0에서 **최댓값 0.25**. 양 끝(포화 영역)에서는 거의 0
  - 은닉층에 쓰면 층마다 0.25 이하가 곱해져 **기울기 소실(Vanishing Gradient)** → 그래서 은닉층은 ReLU로 바뀌었다
- **출력이 0 중심이 아님**: 항상 양수라 다음 층 가중치 기울기의 부호가 한쪽으로 쏠려 학습이 지그재그 → Tanh가 개선
- **지금 쓰이는 곳**: 이진분류·다중 라벨 출력, LSTM·GRU의 **게이트**(얼마나 통과시킬지 0~1), Attention 가중치 일부
- **PyTorch 주의**: 출력층에 `nn.Sigmoid` + `nn.BCELoss`보다 **Sigmoid 없이 `nn.BCEWithLogitsLoss`** 가 수치적으로 안정적 → [[BCEWithLogitsLoss]]
  - 예측 확률이 필요할 때만 `torch.sigmoid(logits)`

## 수식·원리
```
σ(z) = 1 / (1 + e^(−z))         범위 (0, 1),  σ(0) = 0.5,  σ(−z) = 1 − σ(z)
σ'(z) = σ(z)·(1 − σ(z))         최대 0.25 (z = 0)
```

## 코드 예시
```python
import torch

z = torch.tensor([-5.0, -1.0, 0.0, 1.0, 5.0], requires_grad=True)
s = torch.sigmoid(z)
print([round(v, 3) for v in s.tolist()])        # [0.007, 0.269, 0.5, 0.731, 0.993]
s.sum().backward()
print([round(v, 3) for v in z.grad.tolist()])   # [0.007, 0.197, 0.25, 0.197, 0.007]  ← 최대 0.25
print((s > 0.5).int().tolist())                 # [0, 0, 0, 1, 1]  임계값 0.5로 판정
```
