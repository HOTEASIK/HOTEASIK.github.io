# 학습 패러다임

## 정의·핵심
- **질문**: 컴퓨터가 "어떻게" 배우게 할 것인가 (개론 4차시 "학습 패러다임 변화")
- **규칙 기반 vs 데이터 학습**
  - **규칙 기반**: 사람이 `if 털이 있고 귀가 뾰족하면 → 고양이`처럼 규칙을 직접 작성. 이해하기 쉽지만 예외가 많은 현실(조명, 각도, 품종)을 모두 적을 수 없다
  - **데이터 학습**: 예시(데이터)를 많이 보여 주고 규칙을 **모델이 스스로 찾게** 한다 → 머신러닝·딥러닝
- **데이터 학습의 네 가지 방식**
  1. **지도학습**: 입력과 정답(레이블)이 쌍으로 주어짐 — "선생님이 문제와 답을 함께 알려줌"
     - 분류(스팸 여부, 고양이/강아지), 회귀(집값, 매출 예측)
  2. **비지도학습**: 정답 없이 데이터의 **숨은 패턴**을 발견
     - 군집화(고객 구매 패턴 그룹화), 차원 축소(2D 시각화)
  3. **자기지도학습**: 데이터 **자체에서 정답을 만들어** 학습
     - Masked Learning: "오늘 [MASK] 매우 좋다" → "날씨가" 예측 (BERT)
     - Contrastive Learning: 같은 고양이의 다른 각도 사진은 가깝게, 고양이·강아지는 멀게
     - 대표 모델: BERT, GPT, ViT 사전학습
  4. **강화학습**: **시행착오로 보상을 최대화**하는 행동을 학습
     - 상태(State)·행동(Action)·보상(Reward). 예: 로봇 청소기 먼지 제거 +1, 충돌 −5, 충전소 도착 +10
- 학습 방식 선택은 **정답 데이터를 얼마나 구할 수 있는가**에 크게 좌우된다

## 수식·원리
```
지도:      (x, y) 쌍         → f(x) ≈ y
비지도:    x 만               → 구조·그룹 찾기
자기지도:  x 에서 y 를 만듦   → 가린 부분 맞추기
강화:      상태 s, 행동 a     → 누적 보상 최대화
```

## 코드 예시
```python
# 규칙 기반: 사람이 임계값을 정함
def rule(height):
    return "큼" if height > 175 else "보통"

# 데이터 학습: 데이터에서 임계값을 찾음 (두 그룹 평균의 중간)
import numpy as np
h = np.array([160, 165, 168, 180, 183, 186]); y = np.array([0, 0, 0, 1, 1, 1])
th = (h[y == 0].mean() + h[y == 1].mean()) / 2
print(rule(178), round(th, 1))     # 큼 173.7
```
