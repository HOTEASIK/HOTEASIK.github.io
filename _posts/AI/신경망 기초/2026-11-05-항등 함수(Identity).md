# 항등 함수(Identity)

## 정의·핵심
- **정의**: 입력을 **아무것도 바꾸지 않고 그대로** 내보내는 함수 `f(z) = z`. "활성화 함수 없음"과 같다.
- **쓰이는 곳 1 — 회귀 출력층**: 집값·체중처럼 범위 제한이 없는 실수를 예측할 때 출력층에는 활성화를 넣지 않는다 (Sigmoid를 넣으면 0~1로 잘려 버림) → [[선형회귀]]
- **쓰이는 곳 2 — 로짓 출력**: 분류 모델도 마지막 층은 항등(로짓 그대로) 두고, Sigmoid/Softmax는 손실 함수(`BCEWithLogitsLoss`, `CrossEntropyLoss`) 안에서 처리
- **쓰이는 곳 3 — `nn.Identity()` 자리 채우기**
  - **전이학습에서 분류층 떼어 내기**: `model.fc = nn.Identity()` → 마지막 분류층 대신 **특징 벡터(ResNet18이면 512차원)를 그대로 출력** → 특징 추출기로 사용 → [[Feature Extraction vs Fine-tuning]]
  - 옵션에 따라 층을 끄고 싶을 때 (예: `nn.BatchNorm2d(c) if use_bn else nn.Identity()`)
- **ResNet의 Shortcut(항등 매핑)**: `y = F(x) + x`의 `+ x` 부분 — 입력을 그대로 더해 주는 항등 경로 덕분에 기울기가 막힘 없이 흐른다 → [[Residual Block]]
- 도함수는 항상 1

## 수식·원리
```
f(z) = z,   f'(z) = 1
ResNet: y = F(x) + identity(x)  →  ∂y/∂x = ∂F/∂x + 1  (기울기 최소 1 경로 보장)
```

## 코드 예시
```python
import torch
import torch.nn as nn
from torchvision import models

m = models.resnet18(weights=None)
m.fc = nn.Identity()                           # 분류층 제거 → 특징 추출기
print(m(torch.randn(2, 3, 224, 224)).shape)    # torch.Size([2, 512])

reg = nn.Sequential(nn.Linear(13, 32), nn.ReLU(), nn.Linear(32, 1))   # 회귀: 출력층 활성화 없음
x = torch.tensor([1.0, -2.0])
print(nn.Identity()(x).tolist())               # [1.0, -2.0]
```
