# Mish

## 정의·핵심
- **정의**: `Mish(z) = z · tanh(softplus(z))`, softplus(z) = ln(1 + eᶻ). 2019년 제안된 **부드럽고 단조롭지 않은** 활성화 함수
- **모양**: GELU·Swish와 비슷 — 양수는 거의 z, 큰 음수는 0으로 수렴, 작은 음수 구간에서 살짝 아래로 내려감(최솟값 약 −0.31)
- **특징**
  - **매끄러움(Smooth)**: 모든 곳에서 미분 가능 → 손실 지형이 부드러워 최적화가 안정적
  - **위로 무한대, 아래로 유한(bounded below)**: 큰 음수를 0 근처로 눌러 규제 효과
  - **음수 정보를 조금 남김**: Dying ReLU 문제 완화
- **쓰인 곳**: **YOLOv4의 backbone(CSPDarknet53)** — YOLOv4 논문의 "Bag of Specials"(추론 비용을 조금 늘려 정확도를 높이는 기법) 중 하나로 **Mish activation**을 채택 → [[YOLO v4]]
- **비슷한 함수 Swish(SiLU)**: `z · σ(z)` — YOLOv5·v8, EfficientNet이 사용 (`nn.SiLU`)
- 단점: 지수·tanh 계산이 있어 ReLU보다 느리다

## 수식·원리
```
softplus(z) = ln(1 + e^z)
Mish(z)  = z · tanh(softplus(z))
SiLU(z)  = z · σ(z)       (Swish, YOLOv5·v8)
```

## 코드 예시
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

z = torch.tensor([-4.0, -1.0, 0.0, 1.0, 4.0])
m = nn.Mish()(z)
print([round(v, 3) for v in m.tolist()])                          # [-0.073, -0.303, 0.0, 0.865, 3.997]
print(torch.allclose(m, z * torch.tanh(F.softplus(z))))           # True
print([round(v, 3) for v in nn.SiLU()(z).tolist()])               # [-0.072, -0.269, 0.0, 0.731, 3.928]
```
