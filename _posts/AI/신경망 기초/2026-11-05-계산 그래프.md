# 계산 그래프

## 정의·핵심
- **정의**: 계산 과정을 **노드(연산)와 엣지(값의 흐름)** 로 나타낸 그래프. 순전파는 그래프를 앞으로, 역전파는 뒤로 따라간다.
- **PyTorch의 동적 그래프(Define-by-Run)**: 코드가 **실행될 때마다** 그래프가 새로 만들어진다. 그래서 `if`, `for` 같은 파이썬 제어문을 forward에 자유롭게 쓸 수 있다.
- **구성 요소**
  - **잎(leaf) 텐서**: 사용자가 만든 `requires_grad=True` 텐서(가중치). `.grad`가 여기에 쌓인다
  - **grad_fn**: 연산 결과 텐서가 가진 "나를 만든 연산의 미분 함수" (`AddBackward0`, `MulBackward0`, `MeanBackward0` …)
  - `next_functions`: 그 이전 연산들로 이어지는 연결
- **Save for Backward**: 역전파 때 로컬 미분을 계산하려면 순전파의 **중간값이 필요**하다 (예: `z = x·y`의 ∂z/∂x = y). 그래서 순전파 중에 이 값들을 저장해 둔다
  - 학습 때 메모리가 많이 드는 이유 = 이 **저장된 활성화**
  - 사용자 정의 함수에서는 `ctx.save_for_backward(...)`로 직접 저장 (`torch.autograd.Function`)
  - `backward()` 후에는 저장값이 해제되어 같은 그래프로 두 번 backward하면 오류 (`retain_graph=True` 필요)
- **그래프 끊기**: `torch.no_grad()`(기록 안 함), `.detach()`(이 텐서부터 그래프 분리)
- 시각화 → [[torchviz]]

## 수식·원리
```
x ─┐
   ├─(×)─ u ─┐
w ─┘         ├─(+)─ z ─(²)─ L
b ───────────┘
backward: ∂L/∂z = 2z → ∂L/∂b = 2z·1, ∂L/∂u = 2z → ∂L/∂w = 2z·x (저장된 x 사용)
```

## 코드 예시
```python
import torch

class MySquare(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)          # 역전파에 쓸 값 저장
        return x ** 2

    @staticmethod
    def backward(ctx, grad_out):
        (x,) = ctx.saved_tensors
        return grad_out * 2 * x           # 로컬 미분 × 위에서 온 기울기

x = torch.tensor(3.0, requires_grad=True)
y = MySquare.apply(x)
y.backward()
print(y.grad_fn.__class__.__name__, x.grad.item())    # MySquareBackward 6.0
print(x.is_leaf, y.is_leaf)                           # True False
```
