# 퍼셉트론·뉴런

## 정의·핵심
- **뉴런(인공 뉴런)**: 신경망의 가장 작은 계산 단위. 여러 입력에 **가중치를 곱해 더하고 편향을 더한 뒤**, 활성화 함수를 통과시켜 출력한다. 생물의 신경세포(입력 신호가 일정 이상이면 발화)를 흉내 낸 것.
- **퍼셉트론**: 1958년 로젠블랫이 제안한 최초의 학습하는 뉴런 모델. 출력이 **계단 함수**(0 또는 1)
- **가중치(Weight, w)**: 각 입력이 결과에 **얼마나 중요한지**. 크면 영향이 크고, 음수면 반대 방향으로 작용
- **편향(Bias, b)**: 입력과 상관없이 더해지는 값. **얼마나 쉽게 발화(1)하는지** 조절하는 문턱 — 직선을 원점에서 평행 이동시킨다
- **학습 = 가중치와 편향을 데이터에 맞게 조정하는 것**. 이 둘을 합쳐 **파라미터**라고 부른다
- **PyTorch**: `nn.Linear(입력 수, 출력 수)` = 뉴런 여러 개를 한꺼번에 (`weight` 모양 `(out, in)`, `bias` 모양 `(out,)`)
- **한계**: 단층 퍼셉트론은 **직선(초평면) 하나로만** 나눌 수 있다 → AND·OR는 되지만 XOR는 안 된다 → [[XOR 문제]]

## 수식·원리
```
z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = w·x + b
퍼셉트론:  y = 1 (z > 0),  0 (z ≤ 0)          ← 계단 함수
현대 뉴런: y = f(z)  (f = Sigmoid, ReLU …)    ← 미분 가능 → 경사하강법 학습
```

## 코드 예시
```python
import torch

def perceptron(x, w, b):
    return (x @ w + b > 0).int()

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
w = torch.tensor([1., 1.])
print(perceptron(X, w, -1.5).tolist())   # [0, 0, 0, 1]  AND
print(perceptron(X, w, -0.5).tolist())   # [0, 1, 1, 1]  OR  ← 편향만 바꿔 문턱 조절

lin = torch.nn.Linear(2, 3)               # 뉴런 3개
print(lin.weight.shape, lin.bias.shape)   # torch.Size([3, 2]) torch.Size([3])
```
