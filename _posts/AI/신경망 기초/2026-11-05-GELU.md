# GELU

## 정의·핵심
- **정의**: Gaussian Error Linear Unit. 입력 z에 **"z가 표준정규분포에서 얼마나 큰 값인지"의 확률 Φ(z)를 곱한** 함수. `GELU(z) = z · Φ(z)`
- **직관**: ReLU는 0을 기준으로 "통과/차단"을 딱 자르지만, GELU는 값이 클수록 **확률적으로 더 많이 통과**시키는 부드러운 버전
  - 큰 양수 → 거의 z 그대로, 큰 음수 → 거의 0, 0 근처 → 부드러운 곡선 (작은 음수 구간은 살짝 음수 출력, 최솟값 약 −0.17)
- **장점**: 모든 곳에서 **매끄럽게 미분 가능** → 최적화가 안정적. 음수 쪽 기울기가 완전히 0은 아니라 Dying ReLU 문제가 적다
- **쓰이는 곳**: **Transformer 계열의 표준** — BERT, GPT, ViT의 FFN(피드포워드) 층
  - 강의: `FFN(x) = GELU(xW₁ + b₁)W₂ + b₂`, "Hidden Layer + GELU"
- 단점: ReLU보다 계산이 약간 비싸다 → 근사식(tanh 버전) 사용 가능 `nn.GELU(approximate='tanh')`

## 수식·원리
```
GELU(z) = z · Φ(z),   Φ = 표준정규분포 누적분포함수
근사: 0.5·z·(1 + tanh(√(2/π)·(z + 0.044715·z³)))
ViT·BERT FFN:  x → Linear(d → 4d) → GELU → Linear(4d → d)
```

## 코드 예시
```python
import torch
import torch.nn as nn

z = torch.tensor([-3.0, -1.0, -0.5, 0.0, 1.0, 3.0])
g = nn.GELU()(z)
print([round(v, 3) for v in g.tolist()])          # [-0.004, -0.159, -0.154, 0.0, 0.841, 2.996]
phi = 0.5 * (1 + torch.erf(z / 2 ** 0.5))         # Φ(z)
print(torch.allclose(g, z * phi, atol=1e-6))      # True

ffn = nn.Sequential(nn.Linear(768, 3072), nn.GELU(), nn.Linear(3072, 768))   # BERT-base FFN
print(ffn(torch.randn(2, 10, 768)).shape)         # torch.Size([2, 10, 768])
```
