# 다층 퍼셉트론(MLP)

## 정의·핵심
- **정의**: 입력층 → **하나 이상의 은닉층** → 출력층으로 뉴런을 여러 층 쌓은 신경망. 모든 뉴런이 다음 층 모든 뉴런과 연결되어 **완전연결(Fully Connected, Dense)** 신경망이라고도 한다.
- **층의 역할**
  - **입력층**: 데이터 그대로 (예: MNIST 28×28 → 784개). 계산 없음
  - **은닉층(Hidden Layer)**: `Linear + 활성화`. 입력을 점점 더 쓸모 있는 **특징(표현)** 으로 바꾼다. 밖에서 직접 보이지 않아 "은닉"
  - **출력층**: 문제에 맞는 개수와 형태 — 회귀 1개(활성화 없음), 이진분류 1개(Sigmoid), 다중분류 클래스 수(Softmax)
- **레이어 함수**: 한 층이 하는 일 `h = f(Wx + b)` — PyTorch의 `nn.Linear` + `nn.ReLU`
- **예측 함수**: 레이어 함수들의 **합성** `ŷ = f₃(f₂(f₁(x)))` — 딥러닝 = 거대한 합성 함수 → [[합성 함수]]
- **깊이 vs 너비**: 층 수(깊이)를 늘리면 단계적으로 복잡한 특징을 만들고, 뉴런 수(너비)를 늘리면 한 층의 표현력이 커진다. 너무 크면 과적합
- **이미지에 MLP를 쓰면**: `Flatten`으로 펴서 넣어야 해 **위치(공간) 정보가 사라지고** 파라미터가 많아진다 → CNN이 등장한 이유
- **PyTorch 작성법**: `nn.Sequential`로 쌓거나, `nn.Module`을 상속해 `__init__`에 층, `forward`에 계산 순서

## 수식·원리
```
h₁ = ReLU(W₁x + b₁)        (784 → 128)
h₂ = ReLU(W₂h₁ + b₂)       (128 → 64)
ŷ  = W₃h₂ + b₃             (64 → 10, logits)
파라미터 수 = Σ (in·out + out)
```

## 코드 예시
```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.l1 = nn.Linear(784, 128)
        self.l2 = nn.Linear(128, 64)
        self.l3 = nn.Linear(64, 10)
        self.relu = nn.ReLU(inplace=True)

    def forward(self, x):
        x = self.flatten(x)
        x = self.relu(self.l1(x))
        x = self.relu(self.l2(x))
        return self.l3(x)            # logits (Softmax는 손실함수 안에서)

model = MLP()
print(model(torch.randn(32, 1, 28, 28)).shape)          # torch.Size([32, 10])
print(sum(p.numel() for p in model.parameters()))       # 109386
```
