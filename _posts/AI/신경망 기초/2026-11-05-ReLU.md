# ReLU

## 정의·핵심
- **정의**: Rectified Linear Unit. **양수는 그대로, 음수는 0**. `ReLU(z) = max(0, z)`. CNN·MLP 은닉층의 **기본 활성화 함수**
- **장점**
  - **양수 영역 기울기가 항상 1** → 층을 깊게 쌓아도 기울기 소실이 크게 줄어든다 (AlexNet 이후 깊은 망 학습이 가능해진 이유 중 하나)
  - **연산이 매우 빠르다**: 비교 한 번 (지수 계산 없음)
  - **희소성(Sparsity)**: 음수 입력 뉴런이 0이 되어 일부만 활성화 → 효율적인 표현
- **단점 — Dying ReLU**: 입력이 계속 음수인 뉴런은 출력·기울기가 모두 0이 되어 **다시는 학습되지 않는다** (뉴런 사망). 학습률이 너무 크거나 편향이 크게 음수가 되면 발생 → [[Leaky ReLU]]
- 출력이 0 중심이 아니고, 0에서 미분 불가(구현에서는 0으로 처리)
- **`inplace=True`**: `nn.ReLU(inplace=True)` — 새 텐서를 만들지 않고 **입력 텐서를 직접 덮어써서** 메모리를 아낀다 (ResNet 구현 등에서 자주 보임)
  - 주의: 덮어쓴 원래 값이 역전파에 필요한 경우(예: 같은 텐서를 다른 곳에서도 사용) 오류가 날 수 있다. 확신이 없으면 기본값 `False`
- 함수형: `torch.relu(x)`, `F.relu(x)` / 모듈형: `nn.ReLU()`

## 수식·원리
```
ReLU(z) = max(0, z)
ReLU'(z) = 1 (z > 0),  0 (z < 0)
```

## 코드 예시
```python
import torch
import torch.nn as nn

z = torch.tensor([-2.0, -0.5, 0.0, 0.5, 2.0], requires_grad=True)
r = torch.relu(z)
r.sum().backward()
print(r.tolist(), z.grad.tolist())     # [0.0, 0.0, 0.0, 0.5, 2.0] [0.0, 0.0, 0.0, 1.0, 1.0]

x = torch.tensor([-1.0, 3.0])
out = nn.ReLU(inplace=True)(x)
print(x.tolist(), out is x)            # [0.0, 3.0] True  ← 원본이 바뀜

lin = nn.Linear(4, 100)
with torch.no_grad():
    lin.bias.fill_(-10)                # 편향이 크게 음수 → 모든 뉴런 출력 0
dead = (torch.relu(lin(torch.randn(256, 4))).sum(0) == 0).float().mean()
print(dead.item() > 0.9)               # True  ← Dying ReLU
```
