# 순전파(Forward)

## 정의·핵심
- **정의**: 입력 데이터를 모델의 **첫 층부터 마지막 층까지 차례로 통과시켜 예측값을 계산**하는 과정. 학습 4단계(예측 → 손실 → 경사 → 수정) 중 **1단계 "예측 계산"**
- **흐름**: `X(Input) → f(x)(Model) → Ŷ(Pred)` → 손실 계산
- **PyTorch에서**
  - `nn.Module`의 `forward(self, x)`에 계산 순서를 적는다
  - 호출은 `model(x)` — `__call__`이 `forward`를 부르면서 hook 등도 처리하므로 `model.forward(x)`를 직접 부르지 않는다 → [[__call__ 메서드]]
- **계산 그래프 기록**: `requires_grad=True`인 파라미터가 포함되면 순전파 중에 **어떤 연산을 했는지 기록**(grad_fn)하고, 역전파에 필요한 **중간값을 저장**한다 (Save for Backward) → [[계산 그래프]]
  - 그래서 학습 중에는 메모리를 많이 쓰고, 추론 때는 `torch.no_grad()`로 기록을 끈다
- **훈련 vs 추론**: Dropout·BatchNorm은 `model.train()`/`model.eval()`에 따라 순전파 동작이 다르다 → [[train()·eval() 모드]]

## 수식·원리
```
z₁ = W₁x + b₁,  a₁ = f(z₁)
z₂ = W₂a₁ + b₂, ŷ = z₂
loss = L(ŷ, y)          ← 여기까지가 순전파, 이후 loss.backward()가 역전파
```

## 코드 예시
```python
import torch

W = torch.tensor(1.0, requires_grad=True)
B = torch.tensor(1.0, requires_grad=True)
X = torch.tensor([-5.0, 5.0, 0.0, 2.0, -2.0])

def pred(X):
    return W * X + B          # 예측 함수 (순전파)

Yp = pred(X)
print(Yp)                     # tensor([-4.,  6.,  1.,  3., -1.], grad_fn=<AddBackward0>)
with torch.no_grad():
    print(pred(X).requires_grad)   # False → 기록 안 함 (추론용)
```
