# 멀티에이전트

## 정의·핵심
- **AI를 똑똑하게 만드는 4단계 (보충 강의 "멀티에이전트와 피지컬 AI")**
  1. **Pre-training (사전학습)** — "책 많이 읽은 신입생": 데이터·모델·연산을 키워 기본 지능 형성, 아는 건 많지만 일은 서툼
  2. **Post-training (후속학습)** — "실무 교육 받은 직원": 파인튜닝·**RLHF**로 쓸모와 정확도 ↑, ChatGPT가 쓸 만해진 비결 → [[RLHF]]
  3. **Test-time scaling (추론, 롱싱킹)** — "풀이과정 적는 학생": 답하기 전에 **더 오래 생각**, 복잡한 문제엔 단일 응답 대비 **최대 100배 연산** (o1, DeepSeek-R1, Gemini Thinking)
  4. **Agentic AI (에이전트)** — "대신 일하는 AI 직원": **도구를 써서 여러 단계를 스스로 수행**
  - 한 줄: 더 크게 배우기 → 잘 배우기 → 더 오래 생각하기 → **직접 행동하기**
- **챗봇 vs 에이전트**: 챗봇은 묻는 말에 **대답**, 에이전트는 직접 **검색·클릭·실행까지 해서 일을 끝냄**
  - 업무용 앱 중 AI 에이전트 탑재 비율: 2025년 **5% 미만 → 2026년 말 40%** (가트너 전망)
  - 사례: Devin(자율 개발자), Claude Code, Cursor — "금요일에 5개 맡기면 월요일에 결과물 5개"
- **멀티에이전트란 (강의)**: 혼자 다 하는 만능 비서 대신 **역할을 나눠 맡는 AI 팀**
  - 기획 담당 · 자료조사 담당 · 검토 담당이 나눠 일하고 **결과를 합침**
  - **사람의 역할 = 관리자**: 함께 타이핑하는 것이 아니라, 일을 **잘 나누고 검증하는** 사람 ("신입을 관리하는 감각")
- **에이전트 루프 (일반)**: 관찰 → 생각(계획) → 도구 호출(행동) → 결과 관찰 → … 목표 달성까지 반복 — 강화학습의 에이전트-환경 루프와 같은 모양 → [[강화학습 개요]]
- **좋은 프롬프트 (강의 실습)**: "**무엇을, 어떤 형식으로, 어떤 기준으로**"를 함께 알려 줌
- **하네스 엔지니어링**: AI 엔진 주위에 **가드레일·맥락·검증·사람 확인 지점**을 설계 (메모리·도구·맥락·안전장치 — "모델 빼고 전부") → [[피지컬 AI 개요]]

## 수식·원리
```
에이전트 루프:  while not done:
                  thought = LLM(목표, 기록)
                  action  = 도구 선택(thought)       # 검색, 코드 실행, 클릭 …
                  obs     = 도구 실행(action)
                  기록 += (thought, action, obs)
멀티에이전트:  결과 = 검토자( 조사자(기획자(과제)) )   → 사람이 최종 검증
```

## 코드 예시
```python
def planner(task):                                   # 기획 담당: 일을 나눔
    return [f"{task} - 후보 조사", f"{task} - 이동시간 정리", f"{task} - 준비물 정리"]

def researcher(subtask, tools):                      # 자료조사 담당: 도구를 써서 처리
    key = subtask.split(" - ")[1]
    return f"{key}: {tools[key]()}"

def reviewer(results, required=3):                   # 검토 담당: 빠진 것 확인
    ok = len(results) == required and all(":" in r and r.split(": ")[1] for r in results)
    return ok, results

tools = {"후보 조사": lambda: "공원·박물관·시장",        # 가짜 도구 (실제는 검색 API 등)
         "이동시간 정리": lambda: "20분·35분·15분",
         "준비물 정리": lambda: "돗자리·입장권·장바구니"}

task = "주말 가족 나들이 3곳"
subtasks = planner(task)
results = [researcher(s, tools) for s in subtasks]   # 역할을 나눠 처리
ok, final = reviewer(results)
print(len(subtasks), ok)                             # 3 True
for line in final: print(line)
print("사람 확인 필요:", not ok or "입장권" in final[2])   # 사람 확인 필요: True  최종 검증은 관리자(사람)
```
