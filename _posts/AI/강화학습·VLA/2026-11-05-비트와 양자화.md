# 비트와 양자화

## 정의·핵심
- **비트 (응용 16차시 선수지식)**: n비트로 표현할 수 있는 값의 개수 = **2ⁿ** → 비트 수가 늘면 표현 가능한 값이 폭증 (4비트 16개, 8비트 256개, 16비트 65,536개)
- **정밀도와 메모리 (강의 표)**

| 정밀도 | 비트 | 바이트/숫자 |
|---|---|---|
| fp32 | 32 | 4 |
| fp16 / bf16 | 16 | 2 |
| int8 | 8 | 1 |
| int4 | 4 | 0.5 |

  - **메모리 = 파라미터 수 × (비트 / 8)** — 비트를 절반으로 줄이면 메모리도 절반
  - 강의 예: **Qwen3-VL-4B** (4,437,800,000 파라미터) → fp16 약 **8.3 GiB**, int4 약 **2.1 GiB**
- **양자화 (Quantization)**: 실수 가중치를 **적은 비트의 정수 칸에 매핑**해 메모리·연산을 줄이는 것
  - `q = round(w / scale)`, 복원 `ŵ = q · scale` → **반올림 오차** 발생
  - **int4 대칭 양자화 (16차시 과제)**: `scale = max|w| / 7`, q를 **[−8, 7]** 로 clip
- **블록 단위 양자화**: 가중치를 블록(예: 64개)으로 나눠 **블록마다 scale** → 이상치(outlier) 하나가 전체 scale을 키우는 영향을 블록 안에 가둠
- **NF4 (NormalFloat4, QLoRA)**: 신경망 가중치는 **0 근처에 몰린 정규분포** → 16개 칸을 균등하게 두지 않고 **0 근처에 촘촘히** 배치 → 같은 4비트로 **평균 오차(MAE) 감소** → [[LoRA]]
- **학습 vs 추론 (강의 표)**: 학습은 가중치(fp16 2B) + 그래디언트(2B) + 옵티마이저 모멘텀·분산(fp32 4B+4B) + 마스터 가중치(fp32 4B) = 파라미터당 16B → 추론(2B)보다 **약 8배 무거움**

## 수식·원리
```
값의 개수 = 2^n
메모리(byte) = N_params × bits / 8
대칭 int4:  scale = max|w| / 7,   q = clip(round(w/scale), −8, 7),   ŵ = q·scale
학습 메모리 ≈ N × (2 + 2 + 4 + 4 + 4) = 16N byte  vs  추론 2N byte → 8배
```

## 코드 예시
```python
import numpy as np

print([2 ** n for n in (1, 4, 8, 16)])                         # [2, 16, 256, 65536]

N = 4_437_800_000                                              # Qwen3-VL-4B
for name, bits in [("fp32", 32), ("fp16", 16), ("int8", 8), ("int4", 4)]:
    print(name, round(N * bits / 8 / 1024 ** 3, 1), "GiB")     # fp16 8.3 / int4 2.1
print(round(N * 16 / 1024 ** 3, 1), (2 + 2 + 4 + 4 + 4) // 2)  # 66.1 8  학습은 추론의 8배

def quant_int4(w):                                             # 16차시 과제: int4 대칭 양자화
    scale = np.abs(w).max() / 7
    q = np.clip(np.round(w / scale), -8, 7)
    return q, q * scale

rng = np.random.default_rng(0)
w = rng.normal(0, 1, 4096)
q, w_hat = quant_int4(w)
print(len(np.unique(q)) <= 16, round(float(np.abs(w - w_hat).mean()), 4))   # True, 균등 int4 MAE

w_out = w.copy(); w_out[0] = 40.0                              # 이상치 하나 → scale 폭증
_, wh = quant_int4(w_out)
blocks = np.concatenate([quant_int4(b)[1] for b in w_out.reshape(-1, 64)])   # 블록 단위
print(round(float(np.abs(w_out - wh)[1:].mean()), 3), round(float(np.abs(w_out - blocks)[1:].mean()), 3))   # 블록 단위가 오차 훨씬 작음

levels = np.quantile(w, (np.arange(16) + 0.5) / 16)             # NF4 아이디어: 분포의 분위수에 칸 배치
nf = levels[np.abs(w[:, None] - levels[None]).argmin(1)]
print(round(float(np.abs(w - nf).mean()), 4) < round(float(np.abs(w - w_hat).mean()), 4))   # True  같은 16칸, 오차 ↓
```
