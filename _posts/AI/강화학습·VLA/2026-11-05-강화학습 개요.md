# 강화학습 개요

## 정의·핵심
- **정의 (응용 15차시)**: **에이전트(Agent)** 가 **환경(Environment)** 과 상호작용하며 **보상(Reward)을 최대화하는 행동 전략**을 스스로 학습하는 머신러닝 패러다임
  - 지도학습과 달리 **정답 레이블 없이 시행착오**로 학습 — 행동의 결과(보상)만 알려 줌, 보상이 **늦게** 올 수도 있음
- **핵심 구성 요소 (강의)**
  - **Agent**: 환경에서 행동을 결정하는 학습 주체
  - **Environment**: 에이전트가 상호작용하는 외부 세계
  - **State (상태)**: 환경의 현재 상황 (CartPole: 위치·속도·각도·각속도)
  - **Action (행동)**: 에이전트가 취할 수 있는 행동 (왼쪽/오른쪽)
  - **Reward (보상)**: 행동에 대한 즉각적인 피드백 신호
  - **Policy (정책)**: 상태 → 행동 매핑 전략 π(a|s)
  - **Value Function (가치 함수)**: 상태 또는 행동의 **장기적** 가치 → [[가치 함수·Q 함수]]
- **상호작용 루프 (강의 노트북)**: Agent —Action→ Env —State, Reward→ Agent … 반복. 한 판의 시작~종료 = **에피소드(Episode)**
  - Gymnasium API: `state, info = env.reset()` → `next_state, reward, terminated, truncated, info = env.step(action)` (terminated = 성공/실패로 끝남, truncated = 스텝 제한으로 강제 종료) → [[OpenAI Gym]]
- **실제 적용 사례 (강의)**
  - **게임 AI**: AlphaGo(딥러닝 + 몬테카를로 트리 탐색으로 세계 최고 바둑 기사 승리), Atari 인간 수준 이상
  - **로봇 제어**: 산업용 로봇 조립, 물체 파지, 이동 경로 최적화
  - **자율 주행**: 차선 변경, 장애물 회피 등 실시간 의사결정
  - **추천 시스템**: 사용자의 **장기적** 만족도 최대화
  - **RLHF**: ChatGPT 등 LLM을 사람 선호에 맞춤 → [[RLHF]]
- **알고리즘 지도**: 가치 기반(Q-learning, DQN) / 정책 기반(REINFORCE, PPO) / 둘을 결합한 Actor-Critic → [[Value-based vs Policy-based]]

## 수식·원리
```
t = 0, 1, 2, ...:   s_t →(π)→ a_t →(환경)→ r_{t+1}, s_{t+1}
목표: max_π  E[ G_0 ] = E[ Σ_t γ^t r_{t+1} ]
```

## 코드 예시
```python
import numpy as np

class FrozenLake:                                   # 4×4, 미끄러짐 없음 (강의 is_slippery=False)
    MAP = "SFFFFHFHFFFHHFFG"
    def reset(self): self.s = 0; return self.s
    def step(self, a):                              # 0 왼 1 아래 2 오른 3 위
        r, c = divmod(self.s, 4)
        r, c = [(r, max(c - 1, 0)), (min(r + 1, 3), c), (r, min(c + 1, 3)), (max(r - 1, 0), c)][a]
        self.s = r * 4 + c
        tile = self.MAP[self.s]
        return self.s, float(tile == "G"), tile in "HG"   # next_state, reward, terminated

rng = np.random.default_rng(42)
env = FrozenLake()
s, total = env.reset(), 0.0
for step in range(20):                              # 무작위 정책으로 한 에피소드
    a = int(rng.integers(4))
    s2, r, done = env.step(a)
    total += r
    if done: break
    s = s2
print(step + 1, env.MAP[s2], total)                 # 몇 스텝 만에 끝났는지, 마지막 칸, 총보상

wins = 0
for ep in range(1000):                              # 무작위 정책의 성공률 → 학습이 필요한 이유
    env.reset()
    for _ in range(100):
        _, r, done = env.step(int(rng.integers(4)))
        if done: wins += r; break
print(round(wins / 1000, 3))
```
