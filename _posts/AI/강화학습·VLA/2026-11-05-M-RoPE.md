# M-RoPE

## 정의·핵심
- **정의 (응용 16차시)**: Multimodal RoPE — 인공지능에게 **"공간 감각"을 가르치는 GPS**. 1차원 번호표 대신 **3차원 좌표 (t, h, w)** 로 회전 위치 인코딩 (Qwen2-VL부터 사용) → [[RoPE]]
- **문제 — "글은 한 줄이지만, 사진은 평면이잖아!" (강의)**
  - **텍스트 (1D)**: 한 줄로 이어짐 → 1, 2, 3… 일렬 번호표로 충분
  - **사진 (2D)**: 가로·세로 평면 / **영상 (3D)**: 평면 + 시간
  - 사진을 1, 2, 3, 4… 한 줄로 썰어 번호를 매기면 → "1번 조각 **바로 아래에 5번** 조각이 있다"는 **위아래 공간 감각을 잃음**
- **해결 — "영화관 좌석표(3D 주소)" (강의)**
  - **t (Time)**: 몇 번째 장면(프레임)인가 (영상)
  - **h (Height)**: 위에서 몇 번째 줄인가
  - **w (Width)**: 왼쪽에서 몇 번째 칸인가
- **주파수 분배 (강의 코드, head_dim 64 = 32쌍)**: 32쌍을 용도별로 잘라 **t 12쌍 (24차원) / h 10쌍 (20차원) / w 10쌍 (20차원)** → 각각 `위치 × 주파수` 각도를 계산해 **이어 붙임(concat)** → 12 + 10 + 10 = 32쌍
- **텍스트 토큰**: **t = h = w = 같은 위치 번호** → 세 좌표가 같으므로 일반 1D RoPE와 동일하게 동작 (텍스트·이미지를 한 모델에서 일관되게 처리)
- **이미지 토큰**: t = 프레임 번호(사진이면 고정), h = 행 번호, w = 열 번호 → 위·아래·좌·우 이웃 관계가 위치 인코딩에 반영
- 이후 Qwen3-VL은 주파수를 t/h/w에 **교차 배치(interleaved)** 하는 등 개선 → 긴 영상 이해 향상

## 수식·원리
```
inv_freq = 1 / 10000^(2i/64),  i = 0..31
t_freq = inv_freq[0:12],  h_freq = inv_freq[12:22],  w_freq = inv_freq[22:32]
angles = concat( t·t_freq,  h·h_freq,  w·w_freq )      ∈ R^32
텍스트 위치 p:  (t, h, w) = (p, p, p)   →  1D RoPE와 동일
```

## 코드 예시
```python
import torch

def get_m_rope_angles(position_ids_thw, head_dim=64):          # 강의·16차시 과제 함수
    t_pos, h_pos, w_pos = (position_ids_thw[i].float() for i in range(3))
    inv_freq = 1.0 / (10000 ** (torch.arange(0, head_dim, 2).float() / head_dim))
    t_freq, h_freq, w_freq = inv_freq[0:12], inv_freq[12:22], inv_freq[22:32]
    return torch.cat([torch.outer(t_pos, t_freq), torch.outer(h_pos, h_freq), torch.outer(w_pos, w_freq)], dim=-1)

angles = get_m_rope_angles(torch.tensor([[1], [2], [3]]))       # t=1, h=2, w=3
print(tuple(angles.shape), angles[0, 0].item(), angles[0, 12].item() > 0)   # (1, 32) 1.0 True

p = torch.arange(5)                                             # 텍스트: t = h = w = p
inv = 1.0 / (10000 ** (torch.arange(0, 64, 2).float() / 64))
print(torch.allclose(get_m_rope_angles(torch.stack([p, p, p])), torch.outer(p.float(), inv)))   # True  1D RoPE와 동일

gh, gw = 3, 4                                                   # 이미지 3×4 패치: (t, h, w) 좌표
hh, ww = torch.meshgrid(torch.arange(gh), torch.arange(gw), indexing="ij")
thw = torch.stack([torch.zeros(gh * gw, dtype=torch.long), hh.flatten(), ww.flatten()])
print(thw[:, 1].tolist(), thw[:, 1 + gw].tolist())              # [0, 0, 1] [0, 1, 1]  5번(인덱스 5)은 1번 바로 아래
a = get_m_rope_angles(thw)
print(torch.allclose(a[1, 22:], a[1 + gw, 22:]), torch.allclose(a[1, 12:22], a[1 + gw, 12:22]))   # True False  같은 열(w), 다른 행(h)
```
