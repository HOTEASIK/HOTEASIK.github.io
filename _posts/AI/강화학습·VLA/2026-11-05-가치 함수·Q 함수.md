# 가치 함수·Q 함수

## 정의·핵심
- **Value Function (응용 15차시)**: 특정 **상태** 또는 **상태-행동 쌍**이 얼마나 좋은지를 나타내는 **기대 누적 보상(기대 Return)**
- **상태 가치 함수 V(s)**: 상태 s에서 정책 π를 따를 때의 **기대 수익** — "이 상황이 평균적으로 얼마나 좋은가"
- **행동 가치 함수 Q(s, a)**: 상태 s에서 **행동 a를 취한 후** 정책 π를 따를 때의 기대 수익 — "이 상황에서 이 행동이 얼마나 좋은가"
  - Q를 알면 행동 선택이 간단: `a* = argmax_a Q(s, a)` → 가치 기반 방법의 핵심 → [[Q-learning]], [[DQN]]
- **V와 Q의 관계**
  - `V^π(s) = Σ_a π(a|s) Q^π(s, a)` — V는 정책에 따른 Q의 평균
  - `Q^π(s, a) = R(s, a) + γ Σ_{s'} P(s'|s, a) V^π(s')`
  - **Advantage** `A(s, a) = Q(s, a) − V(s)`: 그 행동이 **평균보다 얼마나 더 좋은가** → [[Advantage Function]]
- **최적 가치 함수**: `V*(s) = max_π V^π(s)`, `Q*(s, a) = max_π Q^π(s, a)` → 최적 정책 `π*(s) = argmax_a Q*(s, a)`
- **추정 방법**: 테이블(Q-table, 상태가 적을 때) / **신경망 근사**(DQN의 Q-network, Actor-Critic의 Critic V(s)) → [[Actor-Critic]]
- **Critic이 V(s)를 배우는 이유**: Policy Gradient의 분산을 줄이는 **Baseline**으로 쓰기 위해 → [[Baseline]]

## 수식·원리
```
V^π(s)    = E_π[ G_t | S_t = s ]
Q^π(s, a) = E_π[ G_t | S_t = s, A_t = a ]
V^π(s)    = Σ_a π(a|s) Q^π(s, a)
π*(s)     = argmax_a Q*(s, a)
A^π(s, a) = Q^π(s, a) − V^π(s)
```

## 코드 예시
```python
import numpy as np

# 직선 복도: 상태 0..4, 4가 목표(+1). 행동 0=왼쪽 1=오른쪽
S, gamma = 5, 0.9
def step(s, a):
    s2 = max(s - 1, 0) if a == 0 else min(s + 1, 4)
    return s2, float(s2 == 4)

def evaluate(pi, iters=200):                       # 정책 평가: V^π, Q^π
    V = np.zeros(S)
    for _ in range(iters):
        Q = np.zeros((S, 2))
        for s in range(4):
            for a in range(2):
                s2, r = step(s, a); Q[s, a] = r + gamma * V[s2] * (s2 != 4)
        V = (pi * Q).sum(1)
    return V, Q

uniform = np.full((S, 2), 0.5)
V, Q = evaluate(uniform)
print(V.round(3).tolist())                          # 무작위 정책의 상태 가치 (목표에 가까울수록 큼)
print(np.allclose(V, (uniform * Q).sum(1)))         # True  V = Σ π·Q
print(Q.argmax(1)[:4].tolist())                     # [1, 1, 1, 1]  Q로 greedy 정책 → 항상 오른쪽
A = Q - V[:, None]
print((A[:4, 1] > 0).all(), (A[:4, 0] < 0).all())   # True True  오른쪽은 평균보다 좋은 행동(Advantage > 0)
```
