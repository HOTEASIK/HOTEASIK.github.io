# VLM 구조

## 정의·핵심
- **VLM (Vision-Language Model, 응용 16차시)**: 이미지(영상)와 텍스트를 함께 입력받아 **텍스트로 답하는** 모델 — "이미지를 읽는 AI" (차트 질의응답, 문서 OCR, 이미지 설명 등)
- **3단 구조 (강의 Qwen3-VL 기준)**
  1. **Vision Encoder (ViT)**: 이미지를 **16×16 패치**로 자르고 각 패치를 벡터로 → 448×448 이미지 = `28 × 28 = 784개` 패치, 각 **1024차원** → [[ViT]], [[Patch Embedding·CLS 토큰]]
  2. **Connector / Merger**: 인접한 **2×2 패치 4개를 묶어 이미지 토큰 1개**로 압축 (토큰 수 **1/4**) → 1024 × 4 = **4096차원**으로 이어붙인 뒤 **MLP가 LLM 차원(2560)으로 projection**
  3. **LLM (언어 모델)**: **이미지 토큰 + 텍스트 토큰**을 하나의 시퀀스로 이어 붙여 처리 → 다음 토큰 생성으로 답변 → [[GPT]]
  - 448×448 → 784 패치 → Merger 후 **196 이미지 토큰**
- **해상도와 토큰 수 (강의)**: 토큰 수 = (H/16 × W/16) / 4 → **해상도 2배 → 토큰 4배** (제곱 관계)
  - 실제 시퀀스에서 **이미지 토큰이 90% 이상**을 차지하는 경우가 많음 → 메모리·속도의 주요 원인 → `min_pixels / max_pixels` 로 조절 → [[Qwen3-VL 실습]]
- **위치 정보**: 이미지 토큰은 2D(영상은 3D) 위치를 가짐 → **M-RoPE** (t, h, w) → [[M-RoPE]]
- **DeepStack (강의 참고)**: ViT의 마지막 층만이 아니라 **여러 층(초반·중반·후반)의 특징을 LLM의 여러 층에 주입** → 초반 층의 세밀한 정보(작은 글자, 가는 선) 활용 → **ChartQA 같은 차트·문서 작업에 유리**

## 수식·원리
```
패치 수   = (H / P) × (W / P)          P = 16
이미지 토큰 = 패치 수 / (m × m)          m = 2 (Merger)
448×448 → 28×28 = 784 패치 → 196 토큰
Merger:  [p1; p2; p3; p4] ∈ R^{4×1024 = 4096}  →  MLP  →  R^{2560}
시퀀스 = [이미지 토큰 196개 ; 텍스트 토큰 n개]
```

## 코드 예시
```python
import torch
import torch.nn as nn

def n_image_tokens(h, w, patch=16, merge=2):
    return (h // patch) * (w // patch) // (merge * merge)

print((448 // 16) ** 2, n_image_tokens(448, 448))                 # 784 196
print([n_image_tokens(s, s) for s in (128, 256, 448, 896)])     # [16, 64, 196, 784]  해상도 2배 → 4배

torch.manual_seed(0)
B, H, W, D_vit, D_llm = 1, 448, 448, 1024, 2560
patches = torch.randn(B, (H // 16) * (W // 16), D_vit)          # ViT 출력 (가정)

def merge_2x2(x, gh, gw):                                        # 16차시 과제: ((H/2)(W/2), 4D)
    b, n, d = x.shape
    x = x.view(b, gh // 2, 2, gw // 2, 2, d).permute(0, 1, 3, 2, 4, 5)
    return x.reshape(b, (gh // 2) * (gw // 2), 4 * d)

merged = merge_2x2(patches, 28, 28)
projector = nn.Sequential(nn.Linear(4 * D_vit, D_llm), nn.GELU(), nn.Linear(D_llm, D_llm))
img_tokens = projector(merged)
text_tokens = torch.randn(B, 20, D_llm)                         # 질문 텍스트 20토큰 (임베딩 가정)
seq = torch.cat([img_tokens, text_tokens], dim=1)
print(tuple(merged.shape), tuple(img_tokens.shape), tuple(seq.shape))   # (1, 196, 4096) (1, 196, 2560) (1, 216, 2560)
print(round(196 / 216 * 100, 1))                                 # 90.7  이미지 토큰이 시퀀스의 90% 이상
```
