# Baseline

## 정의·핵심
- **정의 (응용 15차시)**: Policy Gradient에서 리턴 G_t 대신 **G_t − b(s_t)** 를 써서 **분산을 줄이는** 기법. "절대 점수가 아니라 **기준보다 얼마나 잘했나**"로 평가
- **왜 필요한가 (강의 예시)**: 에피소드 리턴이 200 / 50 / 150처럼 **모두 양수**면, 나쁜 에피소드(50)의 행동까지 확률을 **올려 버림** → 학습 방향이 흔들림
  - 강의 예: 평균 점수(Baseline) **b = 125** 를 빼면 → 200점은 **+75**(확률 증가), 50점은 **−75**(확률 감소) → 평균보다 못한 에피소드의 행동은 확률을 **내림**
- **편향이 생기지 않는 이유**: b가 **행동 a와 무관(상태에만 의존)** 하면 `E[∇log π(a|s) · b(s)] = b(s) · ∇Σ_a π(a|s) = b(s) · ∇1 = 0` → 기댓값(기울기 방향)은 그대로, **분산만 감소**
  - 주의: b가 행동에 의존하면 편향이 생김
- **Baseline 선택 (강의)**
  - 상수: 리턴의 평균 (이동 평균)
  - **상태 가치 V(s)**: 가장 좋은 선택 — 상태마다 기대치가 다르므로 → **G_t − V(s_t) ≈ Advantage** → [[Advantage Function]]
  - V(s)를 신경망으로 학습하면 그것이 **Critic** → [[Actor-Critic]]
- **성능 계층 (강의)**: REINFORCE → **REINFORCE + Baseline** → Actor-Critic → A2C → PPO

## 수식·원리
```
∇_θ J = E[ ∇_θ log π_θ(a|s) · (G_t − b(s_t)) ]
E_a[ ∇_θ log π_θ(a|s) · b(s) ] = b(s) ∇_θ Σ_a π_θ(a|s) = 0       (무편향)
예: G = [200, 50, 150],  b = 125 (강의)  →  G − b = [75, −75, 25]
```

## 코드 예시
```python
import torch

G = torch.tensor([200.0, 50.0, 150.0])                 # 강의 예시 (같은 행동, 다른 결과)
b = torch.tensor(125.0)                                 # 강의의 평균 점수(Baseline)
print((G - b).tolist())                                 # [75.0, -75.0, 25.0]

torch.manual_seed(0)
theta = torch.zeros(2, requires_grad=True)              # 2행동 정책, 보상: a0 → 100±10, a1 → 110±10 (모두 양수)
def grad_samples(baseline, n=5000):
    dist = torch.distributions.Categorical(logits=theta)
    a = dist.sample((n,))
    r = torch.where(a == 0, 100.0, 110.0) + 10 * torch.randn(n)
    gs = []
    for i in range(n):                                   # 샘플별 기울기
        g, = torch.autograd.grad(dist.log_prob(a[i]) * (r[i] - baseline), theta, retain_graph=True)
        gs.append(g[1].item())
    gs = torch.tensor(gs)
    return round(gs.mean().item(), 1), round(gs.std().item(), 1)

m0, s0 = grad_samples(0.0)
m1, s1 = grad_samples(105.0)                            # b = 평균 보상
print(abs(m0 - m1) < 2, s0 > 5 * s1)                    # True True  기댓값은 같고 분산은 크게 감소
```
