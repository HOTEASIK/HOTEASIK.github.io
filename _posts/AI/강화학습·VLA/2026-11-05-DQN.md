# DQN

## 정의·핵심
- **정의 (응용 15차시)**: Deep Q-Network (DeepMind, Mnih et al., 2013/2015). Q-learning의 **테이블을 신경망으로 대체**해 고차원 상태 공간 문제를 해결 — **Atari 게임에서 인간 수준 성능**을 달성하며 딥러닝 기반 강화학습 시대를 엶
- **3가지 핵심 요소 (강의)**
  - **Deep Neural Network**: 다층 신경망으로 Q-function 근사 — 이미지 등 고차원 입력 처리. 입력 = 상태, 출력 = **행동별 Q값** (한 번의 forward로 모든 행동 평가)
  - **Experience Replay (15차시 과제 문제 2)**: 과거 경험 `(state, action, reward, next_state, done)` 을 **메모리 버퍼에 저장**하고 **무작위 샘플링**해 학습 → **데이터 간 상관관계 제거**, 학습 안정성 ↑, 같은 경험 재사용(샘플 효율)
  - **Target Network**: **일정 주기마다 업데이트**되는 별도 네트워크(θ⁻)로 목표값 계산 → 학습 중인 네트워크가 자기 타깃을 계속 움직이는 문제(움직이는 과녁)를 막아 **발산 방지**
- **손실 함수 (강의, 과제 문제 6)**
  - `Target = r + γ·max_a' Q_target(s', a') × (1 − done)` — 종료면 미래 가치 0
  - `Loss = (Target − Q(s, a; θ))²` (실무에선 Huber/SmoothL1도 사용), 샘플은 Replay Buffer D에서
- **CartPole DQN 실습 구조 (강의)**
  1. 환경·하이퍼파라미터: Gymnasium `CartPole-v1`, **학습률 0.001, 배치 64, 버퍼 10,000**
  2. 모델 (과제 문제 4): **4차원 입력 → 128 → 128 → 2** (ReLU)
  3. Replay Buffer (과제 문제 5): 튜플 저장 + 랜덤 샘플링 → 텐서 변환
  4. 학습 루프: 에피소드별 상호작용, ε-greedy, Q-network 업데이트, Target network 동기화
  5. 결과 시각화: Episode별 reward, 이동 평균, 성공률
- **개선판**: Double DQN(행동 선택은 온라인, 평가는 타깃 → 과대추정 완화), Dueling DQN(V와 A 분리), Prioritized Replay, Rainbow
- **한계**: **이산 행동**에만 바로 적용 (max_a 계산) → 연속 행동은 정책 기반 → [[Value-based vs Policy-based]]

## 수식·원리
```
y = r + γ (1 − done) max_{a'} Q(s', a'; θ⁻)
L(θ) = E_{(s,a,r,s',done)~D} [ (y − Q(s, a; θ))² ]
θ⁻ ← θ   (C 스텝마다, 또는 soft: θ⁻ ← τθ + (1−τ)θ⁻)
```

## 코드 예시
```python
import random
from collections import deque
import numpy as np
import torch
import torch.nn as nn

class DQN(nn.Module):                                     # 과제 문제 4
    def __init__(self, state_dim=4, action_dim=2):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(state_dim, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU(), nn.Linear(128, action_dim))
    def forward(self, x): return self.net(x)

class ReplayBuffer:                                       # 과제 문제 5
    def __init__(self, capacity=10000): self.buffer = deque(maxlen=capacity)
    def push(self, *transition): self.buffer.append(transition)
    def sample(self, batch_size):
        s, a, r, s2, d = zip(*random.sample(self.buffer, batch_size))
        return (torch.FloatTensor(np.array(s)), torch.LongTensor(a), torch.FloatTensor(r),
                torch.FloatTensor(np.array(s2)), torch.FloatTensor(d))
    def __len__(self): return len(self.buffer)

random.seed(0); torch.manual_seed(0); rng = np.random.default_rng(0)
q_net, target_net = DQN(), DQN()
target_net.load_state_dict(q_net.state_dict())            # Target Network 초기 동기화
buf = ReplayBuffer()
for _ in range(500):                                      # 가짜 CartPole 경험 저장
    s = rng.normal(size=4).astype(np.float32); a = int(rng.integers(2))
    buf.push(s, a, 1.0, s + rng.normal(scale=0.1, size=4).astype(np.float32), float(rng.random() < 0.05))

opt, gamma = torch.optim.Adam(q_net.parameters(), lr=0.001), 0.99
for step in range(200):
    s, a, r, s2, done = buf.sample(64)
    q = q_net(s).gather(1, a.unsqueeze(1)).squeeze(1)
    with torch.no_grad():
        target = r + gamma * target_net(s2).max(1).values * (1 - done)   # 과제 문제 6
    loss = nn.functional.mse_loss(q, target)
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 50 == 49: target_net.load_state_dict(q_net.state_dict())  # 주기적 동기화
print(len(buf), tuple(q_net(s).shape), round(loss.item(), 3) >= 0)      # 500 (64, 2) True
```
