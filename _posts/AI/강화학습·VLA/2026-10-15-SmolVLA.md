# 정의 
VLA 모델
**SmolVLA**: Hugging Face가 [[LeRobot]] 생태계용으로 공개한 **작은(Small) VLA(Vision-Language-Action) 모델**. 약 4.5억(450M) 파라미터로, 일반 소비자용 GPU나 노트북에서도 학습·추론할 수 있게 만든 것이 특징이다.

# VLA란
**V**ision(카메라 영상) + **L**anguage(「컵을 집어」 같은 지시) → **A**ction(관절 명령).
VLM(이미지를 읽는 언어모델)에 **행동 출력**을 붙인 구조다.

## VLM이 이미지를 읽는 방식 (강의 16차시)
1. **패치 자르기** — 이미지를 16×16 픽셀 조각으로 분할
2. **벡터 인코딩** — ViT가 각 패치를 숫자 벡터로 변환
3. **2×2 병합** — 인접 4개 패치를 토큰 1개로 압축 (토큰 수 1/4)
4. **LLM 입력** — 이미지 토큰과 텍스트 토큰을 한 시퀀스로

→ VLM은 이미지를 '보는' 것이 아니라 잘게 쪼개 글자처럼 변환해 처리한다.

# 구조
| 부분 | 역할 |
|---|---|
| VLM 백본 (SmolVLM 계열) | 카메라 영상 + 지시문 + 로봇 상태를 이해 |
| 액션 전문가 (Action Expert) | VLM의 특징을 받아 **연속된 행동 묶음(action chunk)** 을 생성 (flow matching) |

- 한 번에 여러 스텝의 행동을 내보내고, 로봇이 실행하는 동안 다음 묶음을 미리 계산하는 **비동기 추론**으로 반응 속도를 높인다
- 커뮤니티가 LeRobot 형식으로 공유한 데이터셋으로 사전학습되었다

# 쓰는 흐름
1. 로봇 팔(예: SO-100/SO-101)로 시연 데이터를 녹화 → LeRobotDataset
2. 사전학습된 SmolVLA를 내 데이터로 **파인튜닝**
3. 학습된 정책을 로봇에서 실행

# 강화학습과의 관계
- 강화학습: 보상을 받으며 시행착오로 정책(Policy, 상태 → 행동 매핑)을 배운다
- SmolVLA 같은 VLA: 주로 사람이 보여 준 시연을 따라 배우는 **모방학습**으로 정책을 학습한다
