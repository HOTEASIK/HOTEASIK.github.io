# RoPE

## 정의·핵심
- **정의 (응용 16차시 M-RoPE)**: Rotary Position Embedding. 각 토큰에 **순서표(번호표)** 를 달아 주는 위치 인코딩 — 벡터를 **2차원씩 짝(pair)** 지어, 위치 m에 따라 **각도 m·θ만큼 회전**시킴
  - 왜 필요한가: "개가 사람을 물었다" vs "사람이 개를 물었다" — 단어는 같아도 **순서**가 다르면 뜻이 다름. Self-Attention 자체는 순서를 모름 → [[Positional Encoding]]
- **주파수 (강의 코드)**: `inv_freq = 1 / 10000^(2i/d)` — d = head_dim(64면 **32쌍**)
  - **앞 차원 (i 작음)**: θ 큼 → **빠르게 회전** → 가까운 위치 구분 (시계의 **초침**)
  - **중간 차원**: 중간 속도 (**분침**)
  - **뒤 차원 (i 큼)**: θ 작음 → **천천히 회전** → 멀리 떨어진 위치 구분 (**시침**)
  - 여러 침을 합쳐 정확한 시간(위치)을 표현
- **핵심 성질 — 상대 위치**: Query를 m만큼, Key를 n만큼 회전하면 내적 `⟨R_m q, R_n k⟩ = ⟨q, R_{n−m} k⟩` → Attention 점수가 **상대 거리 (n − m)** 에만 의존
- **사인파 위치 인코딩과 차이**: 원래 Transformer는 위치 벡터를 **더함(add)**, RoPE는 Q·K를 **회전(multiply)** — 값(V)에는 적용 안 함, 학습 파라미터 없음, 긴 문맥 확장(NTK/YaRN 스케일링)에 유리
- **사용 모델**: LLaMA, Qwen, Mistral 등 대부분의 최신 LLM → 이미지·영상용 확장이 **M-RoPE** → [[M-RoPE]]

## 수식·원리
```
θ_i = 10000^(−2i/d),   i = 0, …, d/2 − 1
위치 m의 i번째 쌍 (x_{2i}, x_{2i+1}) 회전:
  [x'_{2i}  ]   [cos mθ_i  −sin mθ_i] [x_{2i}  ]
  [x'_{2i+1}] = [sin mθ_i   cos mθ_i] [x_{2i+1}]
⟨R_m q, R_n k⟩ = ⟨q, R_{n−m} k⟩     (상대 위치만 남음)
```

## 코드 예시
```python
import torch

def rope(x, pos, base=10000.0):                             # x: (seq, d), pos: (seq,)
    d = x.shape[-1]
    inv_freq = 1.0 / (base ** (torch.arange(0, d, 2).float() / d))   # 강의 코드와 동일
    ang = torch.outer(pos.float(), inv_freq)                 # (seq, d/2)  각도 = 위치 × 주파수
    cos, sin = ang.cos(), ang.sin()
    x1, x2 = x[..., 0::2], x[..., 1::2]
    out = torch.empty_like(x)
    out[..., 0::2] = x1 * cos - x2 * sin
    out[..., 1::2] = x1 * sin + x2 * cos
    return out

inv = 1.0 / (10000 ** (torch.arange(0, 64, 2).float() / 64))
print(len(inv), round(inv[0].item(), 4), round(inv[-1].item(), 6))   # 32 1.0 0.000133  초침 → 시침

torch.manual_seed(0)
q, k = torch.randn(1, 64), torch.randn(1, 64)
def score(m, n): return (rope(q, torch.tensor([m])) * rope(k, torch.tensor([n]))).sum().item()
print(round(score(3, 7), 4) == round(score(10, 14), 4), round(score(0, 4), 4) == round(score(100, 104), 4))   # True True  거리 4면 점수 같음
print(round(score(3, 7), 4) != round(score(3, 8), 4))       # True  거리가 다르면 점수도 다름

x = torch.randn(5, 64)
print(torch.allclose(rope(x, torch.arange(5)).norm(dim=-1), x.norm(dim=-1)))   # True  회전이라 크기 보존
```
