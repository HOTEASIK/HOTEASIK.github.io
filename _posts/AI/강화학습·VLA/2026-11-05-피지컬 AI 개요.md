# 피지컬 AI 개요

## 정의·핵심
- **정의 (보충 강의 "멀티에이전트와 피지컬 AI")**: **몸을 가진 AI** — 화면 속 AI → 현실에서 **보고·생각하고 행동하는** 로봇
  - 피지컬 AI = **하드웨어(몸) + AI(두뇌)**
- **젠슨 황의 4단계 프레임 (강의)**: **인식**(이미지·음성 인식) → **생성**(현재의 물결) → **에이전트**(떠오르는 물결) → **피지컬**(몸을 가진 AI)
  - "생성형 전환이 '필수'였다면, 에이전트·피지컬 전환은 '**혁명**'일 것"
- **현황 (강의 사례)**
  - 테슬라 **옵티머스** (공장 투입), **Figure 02** (BMW 공장에서 X3 3만 대 생산 참여)
  - 2026 상업 가동 **5만 대 이상**
- **한국의 기회 (강의)**
  - 현대차그룹 = **보스턴다이내믹스(아틀라스)** — CES 2026 전기구동 공개, **2028년 양산** 로드맵
  - 삼성·**레인보우로보틱스 RB-Y1** — 쿠팡 물류센터 실증 투입
  - 로봇·제조·반도체 **하드웨어는 세계 최고**, 두뇌(SW)는 미·중 추격 단계 → "두뇌만 따라잡으면 최대 기회"
- **환각과 안전 (강의)**
  - **환각** = 사실 아닌 걸 '자신 있게' 생성 (가짜 인용·없는 통계) — 완전히 없앨 수 없음: '없는 것도 만들어내는' 능력 = **상상·창의·탐색**의 다른 이름 ("끄면 창의도 꺼진다")
  - **화면 속 실수 vs 현실의 사고**: 화면 속 AI가 틀리면 다시 물으면 되지만, **몸을 가진 AI가 틀리면 사고** → 피지컬 AI일수록 **'고삐(하네스)'** 와 **검증이 먼저**
  - **하네스 엔지니어링**: AI를 똑똑하게(X) → AI가 **'제대로' 일하게(O)** — "야생마를 죽이지 말고 고삐를 채워라" → [[멀티에이전트]]
- **기술 구성**: 인식(카메라·센서, 비전 모델) + 판단(VLM/VLA 정책) + 제어(기구학, 관절 명령) → [[VLA(Vision-Language-Action)]], [[로봇팔 자유도(DOF)·Null space]]
  - 학습: 시뮬레이션에서 **강화학습(PPO)** + 사람 시연 **모방 학습** → 현실로 옮기기(Sim-to-Real) → [[PPO]]

## 수식·원리
```
피지컬 AI 루프 (매 제어 주기):
  관측 o_t = 센서(카메라, 관절 각도)
  행동 a_t = π(o_t, 지시)                  # VLA 정책
  안전 검사: a_t ∈ 허용 범위 ?  아니면 정지/사람 확인   # 하네스
  명령 q_t = IK(a_t) → 모터
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)
LIMIT, SPEED_MAX = np.array([1.0, 1.0, 0.5]), 0.2           # 작업 영역 경계(m), 한 스텝 최대 이동(m)

def policy(obs):                                            # 두뇌 (가끔 엉뚱한 출력 = 환각)
    a = 0.1 * (obs["target"] - obs["pos"])
    return a * 20 if rng.random() < 0.1 else a

def harness(pos, a):                                        # 고삐: 속도 제한·작업 영역·사람 확인
    if np.linalg.norm(a) > SPEED_MAX: return np.zeros(3), "속도 초과 → 정지·사람 확인"
    if np.any(np.abs(pos + a) > LIMIT): return np.zeros(3), "영역 이탈 → 정지"
    return a, "ok"

pos, target, logs = np.zeros(3), np.array([0.8, -0.5, 0.3]), []
for t in range(60):
    a, status = harness(pos, policy({"pos": pos, "target": target}))
    pos = pos + a; logs.append(status)
print(round(float(np.linalg.norm(target - pos)), 3) < 0.05, logs.count("ok") > 0)   # True True  목표 도달
print(sum(s != "ok" for s in logs) > 0, bool(np.all(np.abs(pos) <= LIMIT)))         # True True  위험 출력은 막고 영역 유지
```
