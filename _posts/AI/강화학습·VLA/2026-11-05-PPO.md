# PPO

## 정의·핵심
- **정의 (응용 15차시)**: Proximal Policy Optimization (OpenAI, Schulman 2017). Trust Region의 아이디어를 **Clipping으로 단순하게 구현** — 현재 **강화학습의 사실상 표준** 알고리즘 → [[Trust Region]]
- **확률 비율 (ratio)**: `r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)` — 새 정책이 그 행동을 이전보다 몇 배 더 선택하나 (1이면 변화 없음)
- **Clipped Objective (강의)**: `L^CLIP = E[ min( r_t·Â_t, clip(r_t, 1−ε, 1+ε)·Â_t ) ]`
  - **ε = 0.2** (보통 0.1~0.2) → ratio를 **[0.8, 1.2]** 로 제한
  - **A > 0 (좋은 행동)**: 확률을 올리되 ratio가 **1+ε를 넘으면 더 이상 이득 없음** → 과도한 증가 방지
  - **A < 0 (나쁜 행동)**: 확률을 내리되 ratio가 **1−ε 아래로는 이득 없음** → 과도한 감소 방지
  - min을 쓰므로 목표의 **비관적(하한) 추정** — 정책을 망치는 방향의 업데이트는 제한하지 않고, 지나친 개선만 잘라냄
- **장점 (강의)**
  - **샘플 효율성**: 같은 배치로 **여러 epoch(예: 4~10) 미니배치 업데이트** 가능 — ratio clip이 너무 멀리 가는 것을 막아 줌 (A2C는 1회 사용)
  - **구현 간단**: TRPO의 2차 최적화 없이 Adam만으로
  - **안정적**: 하이퍼파라미터에 덜 민감
- **전체 손실**: `L = −L^CLIP + c_1·(V − returns)² − c_2·H(π)`, Advantage는 **GAE**(γ=0.99, λ=0.95) → [[Advantage 추정]]
- **활용 (강의)**: **OpenAI Five**(Dota 2), **로봇 제어**(시뮬레이션 보행·조작), Atari, **ChatGPT의 RLHF** → [[RLHF]]

## 수식·원리
```
r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t) = exp(log π_θ − log π_θ_old)
L^CLIP(θ) = E_t[ min( r_t Â_t,  clip(r_t, 1−ε, 1+ε) Â_t ) ]
Â > 0: 이득은 r ≤ 1+ε 까지,   Â < 0: 이득은 r ≥ 1−ε 까지
L = −L^CLIP + c_1 L^VF − c_2 H(π)
```

## 코드 예시
```python
import torch

def clip_obj(ratio, A, eps=0.2):
    return torch.min(ratio * A, torch.clamp(ratio, 1 - eps, 1 + eps) * A)

ratios = torch.tensor([0.5, 0.8, 1.0, 1.2, 1.5])
print([round(x, 2) for x in clip_obj(ratios, torch.tensor(1.0)).tolist()])    # [0.5, 0.8, 1.0, 1.2, 1.2]  A>0: 1.2 이상 이득 없음
print([round(x, 2) for x in clip_obj(ratios, torch.tensor(-1.0)).tolist()])   # [-0.8, -0.8, -1.0, -1.2, -1.5]  A<0: 0.8 아래로 이득 없음

r = torch.tensor(1.5, requires_grad=True)                   # 클리핑 구간 밖이면 기울기 0 → 더 밀지 않음
clip_obj(r, torch.tensor(1.0)).backward()
print(r.grad.item())                                         # 0.0

a = torch.tensor([0, 0, 1, 2]); A = torch.tensor([1.0, 1.0, -0.5, -0.5])   # 같은 배치로 30 epoch 업데이트
for use_clip in (False, True):
    logits = torch.zeros(3, requires_grad=True)
    old_logp = torch.log_softmax(logits.detach(), 0)
    opt = torch.optim.SGD([logits], lr=0.1)
    for epoch in range(30):
        ratio = (torch.log_softmax(logits, 0)[a] - old_logp[a]).exp()
        loss = -(clip_obj(ratio, A) if use_clip else ratio * A).mean()
        opt.zero_grad(); loss.backward(); opt.step()
    ratio = (torch.log_softmax(logits, 0)[a] - old_logp[a]).exp()
    print(use_clip, [round(x, 2) for x in ratio.tolist()])
# False [2.32, 2.32, 0.34, 0.34]  클리핑 없으면 정책이 계속 멀어짐
# True [1.41, 1.41, 0.79, 0.79]   클립 구간을 벗어나면 기울기 0 → 거기서 멈춤 (마지막 한 스텝만큼 넘침)
```
