# A2C

## 정의·핵심
- **정의 (응용 15차시)**: **Advantage Actor-Critic**. Actor-Critic에 **Advantage**를 쓰고, 여러 환경을 **병렬·동기**로 돌려 안정성과 효율을 높인 알고리즘 → [[Actor-Critic]], [[Advantage Function]]
- **핵심 기법 (강의)**
  - **n-step Returns**: `G_t^(n) = r_t + γ r_{t+1} + … + γ^n V(s_{t+n})` — 1-step TD보다 정확하고 MC보다 분산이 낮음 → [[Advantage 추정]]
  - **병렬 환경 (Parallel Environments)**: 여러 환경(예: 8~16개)에서 동시에 경험 수집 → 샘플 간 **상관관계 감소**(DQN의 Replay Buffer 역할을 대신), 다양한 경험
  - **Entropy Bonus**: 정책 엔트로피 `H(π) = −Σ π log π` 를 보상처럼 더해 **조기 수렴 방지**·탐색 유지 → [[탐색과 활용]]
  - **동기적 업데이트 (Synchronous)**: 모든 환경의 n스텝이 모이면 **한 번에** 업데이트
- **A2C vs A3C (강의)**
  - **A3C** (Asynchronous, DeepMind 2016): 여러 워커가 **비동기**로 각자 기울기를 공유 모델에 반영 — 오래된 파라미터로 계산한 기울기 문제
  - **A2C**: 동기 버전 — **GPU 배치 처리에 유리**, 구현이 단순, 성능이 비슷하거나 더 좋음 → 실무에선 **A2C 선호**
- **전체 손실**: `L = L_actor + c_v · L_critic − c_e · H(π)` (예: c_v = 0.5, c_e = 0.01)
- **한계**: 업데이트 크기 제한이 없어 **큰 업데이트 한 번에 정책 붕괴** 가능 → Trust Region / PPO → [[Trust Region]]

## 수식·원리
```
A_t = Σ_{k=0}^{n−1} γ^k r_{t+k} + γ^n V(s_{t+n}) − V(s_t)
L_actor  = − mean( log π(a_t|s_t) · stopgrad(A_t) )
L_critic = mean( A_t² )
H(π) = − Σ_a π(a|s) log π(a|s)
L = L_actor + 0.5 L_critic − 0.01 H
```

## 코드 예시
```python
import numpy as np
import torch
import torch.nn as nn

N_ENVS, N_STEPS, gamma = 8, 5, 0.99
def env_step(s, a):                                          # 벡터화된 0..5 복도 환경
    s2 = np.where(a == 0, np.maximum(s - 1, 0), s + 1)
    r = (s2 == 5).astype(np.float32); done = s2 == 5
    return np.where(done, 0, s2), r, done                     # 끝나면 자동 reset

torch.manual_seed(0)
body = nn.Sequential(nn.Linear(6, 32), nn.ReLU())
pi_head, v_head = nn.Linear(32, 2), nn.Linear(32, 1)
params = list(body.parameters()) + list(pi_head.parameters()) + list(v_head.parameters())
opt = torch.optim.Adam(params, lr=0.01)
obs = lambda s: torch.eye(6)[torch.as_tensor(s)]
s, ent_hist, done_count = np.zeros(N_ENVS, dtype=int), [], 0
for update in range(150):
    logps, vals, rews, dns, ents = [], [], [], [], []
    for _ in range(N_STEPS):                                  # 병렬 환경에서 n-step 수집
        h = body(obs(s)); dist = torch.distributions.Categorical(logits=pi_head(h))
        a = dist.sample()
        s, r, d = env_step(s, a.numpy())
        logps.append(dist.log_prob(a)); vals.append(v_head(h).squeeze(-1)); ents.append(dist.entropy())
        rews.append(torch.tensor(r)); dns.append(torch.tensor(d, dtype=torch.float32)); done_count += d.sum()
    with torch.no_grad(): R = v_head(body(obs(s))).squeeze(-1)  # 부트스트랩 V(s_{t+n})
    rets = []
    for r, d in zip(reversed(rews), reversed(dns)):
        R = r + gamma * R * (1 - d); rets.insert(0, R)
    adv = torch.stack(rets) - torch.stack(vals)
    entropy = torch.stack(ents).mean()
    loss = -(torch.stack(logps) * adv.detach()).mean() + 0.5 * adv.pow(2).mean() - 0.01 * entropy
    opt.zero_grad(); loss.backward(); opt.step()              # 동기적 업데이트
    ent_hist.append(entropy.item())
print(N_ENVS * N_STEPS, ent_hist[0] > ent_hist[-1], int(done_count) > 0)   # 40 True True  배치 크기, 엔트로피 감소(정책 확신 ↑)
```
