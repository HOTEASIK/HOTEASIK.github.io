# 탐색과 활용

## 정의·핵심
- **탐색과 활용의 딜레마 (응용 15차시)**: 강화학습의 핵심 과제 — **알려진 좋은 행동을 활용(Exploitation)** 하면서 동시에 **더 나은 행동을 탐색(Exploration)** 하는 균형을 맞추는 것
  - **탐색 (Exploration)**: 새로운 상태와 행동을 시도해 환경에 대한 지식 확장 — **초기 학습 단계에서 중요**
  - **활용 (Exploitation)**: 지금까지 학습한 정보로 **최선의 행동**을 선택해 보상 최대화
  - 활용만 하면 처음 우연히 찾은 그저 그런 행동에 갇힘(국소 최적), 탐색만 하면 배운 것을 쓰지 못함
- **ε-greedy Policy (강의, 15차시 과제 문제 1)**: 가장 널리 쓰이는 탐색 전략
  - **ε 확률로 무작위 행동**, **(1 − ε) 확률로 현재 최선의 행동**(argmax Q)
  - **초기**: 높은 ε (0.9~1.0)으로 적극 탐색
  - 학습이 진행되며 ε를 점진적으로 **감소(decay)** — 강의 코드 `epsilon=1.0, epsilon_decay=0.995, epsilon_min=0.01`
  - **최종**: 낮은 ε (0.01~0.1)으로 수렴해 주로 활용
- **다른 탐색 방법**
  - **Softmax / Boltzmann**: Q값에 비례한 확률로 선택 (temperature로 조절)
  - **UCB**: 덜 시도한 행동에 보너스 `Q + c√(ln t / N(a))`
  - **정책 기반의 확률적 정책**: π(a|s)에서 샘플링 자체가 자연스러운 탐색 → [[Policy Network]]
  - **Entropy Bonus (A2C, PPO)**: 정책이 한 행동으로 조기 고착되는 것을 막음 → [[A2C]]
- **Off-policy**: Q-learning은 탐색용 행동(ε-greedy)으로 데이터를 모으면서 **greedy 정책의 가치**를 학습 → 탐색과 학습 대상을 분리 → [[Q-learning]]

## 수식·원리
```
a = random action          (확률 ε)
    argmax_a Q(s, a)       (확률 1 − ε)
ε ← max(ε_min, ε × decay)  (에피소드마다)
1.0 × 0.995^n = 0.01  →  n ≈ 919 에피소드
```

## 코드 예시
```python
import numpy as np

rng = np.random.default_rng(0)
true_means = np.array([0.2, 0.5, 0.8])                 # 3개 슬롯머신 (행동 2가 실제로 최선)

def run(eps, decay=1.0, eps_min=0.01, steps=2000):
    Q, N, total = np.zeros(3), np.zeros(3), 0.0
    for t in range(steps):
        a = int(rng.integers(3)) if rng.random() < eps else int(Q.argmax())   # ε-greedy
        r = float(rng.random() < true_means[a])
        N[a] += 1; Q[a] += (r - Q[a]) / N[a]; total += r
        eps = max(eps_min, eps * decay)
    return round(total / steps, 3), int(Q.argmax())

print(run(eps=0.0))                                    # 활용만: 처음 고른 행동에 갇힐 수 있음
print(run(eps=1.0, decay=1.0))                         # 탐색만: 평균 0.5 근처
print(run(eps=1.0, decay=0.995))                       # 강의 설정: 탐색 → 활용, 최선 행동(2) 발견

eps, n = 1.0, 0
while eps > 0.01: eps *= 0.995; n += 1
print(n)                                               # 919  ε가 최솟값까지 줄어드는 에피소드 수
```
