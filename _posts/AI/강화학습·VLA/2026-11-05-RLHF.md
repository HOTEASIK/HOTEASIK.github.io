# RLHF

## 정의·핵심
- **정의**: Reinforcement Learning from Human Feedback — **사람의 선호(피드백)를 보상으로** 삼아 LLM을 강화학습으로 미세 조정하는 방법
  - 응용 15차시: "**RLHF (ChatGPT): 인간 피드백 기반 미세 조정**" — PPO의 대표 활용처 → [[PPO]]
  - 보충 강의(멀티에이전트·피지컬 AI): "사람이 좋아하는 답에 **'잘했어' 점수를 주며 길들이는 과정**. 그래서 AI가 갑자기 **말귀를 알아듣게** 됐다" — AI를 똑똑하게 만드는 4단계 중 **2단계 Post-training(후속학습)**, "실무·예절 교육 받은 직원" → [[멀티에이전트]]
- **3단계 파이프라인 (InstructGPT, 2022)**
  1. **SFT (Supervised Fine-Tuning)**: 사람이 쓴 모범 답변으로 사전학습 모델을 지도 미세조정 → [[PLM·Pre-training·Fine-tuning]]
  2. **보상 모델(Reward Model) 학습**: 한 질문에 대한 여러 답변을 사람이 **순위/쌍 비교** → "좋은 답 > 나쁜 답" 점수를 내도록 학습 (Bradley-Terry 손실)
  3. **PPO로 정책 최적화**: LLM(정책)이 답을 생성 → 보상 모델이 점수 → PPO로 업데이트. 단, **SFT 모델에서 너무 멀어지지 않게 KL 페널티** (보상 해킹·말투 붕괴 방지) → [[KL Divergence]], [[Trust Region]]
- **강화학습 용어로 보면**: 상태 = 프롬프트 + 지금까지 생성한 토큰, 행동 = 다음 토큰, 정책 = LLM, 보상 = 보상 모델 점수(답변 끝에 한 번) → [[강화학습 개요]]
- **대안·발전**: **DPO**(보상 모델·PPO 없이 선호 쌍으로 직접 최적화), RLAIF(AI 피드백), Constitutional AI, 추론 모델의 **검증 가능한 보상 RL**(수학·코드 정답 여부)
- **한계**: 사람 라벨 비용, 보상 해킹(보상 모델의 허점을 파고듦), 아첨(sycophancy) 경향

## 수식·원리
```
보상 모델:  L_RM = − log σ( r_φ(x, y_좋음) − r_φ(x, y_나쁨) )
RL 목표:    max_θ  E[ r_φ(x, y) ] − β · KL( π_θ(·|x) ‖ π_SFT(·|x) )
토큰별 보상 = −β (log π_θ − log π_SFT),  마지막 토큰에 + r_φ(x, y)
DPO:  L = − log σ( β[ log π_θ(y_w|x)/π_ref(y_w|x) − log π_θ(y_l|x)/π_ref(y_l|x) ] )
```

## 코드 예시
```python
import torch
import torch.nn as nn

torch.manual_seed(0)
D = 8                                                        # 답변 특징 벡터 (가정)
true_w = torch.randn(D)                                       # 사람의 숨은 선호
ys = torch.randn(500, 2, D)                                   # 질문마다 답변 2개
pref = (ys @ true_w)[:, 0] > (ys @ true_w)[:, 1]              # 사람이 고른 쪽
y_w = torch.where(pref[:, None], ys[:, 0], ys[:, 1]); y_l = torch.where(pref[:, None], ys[:, 1], ys[:, 0])

rm = nn.Linear(D, 1)                                          # 2단계: 보상 모델 (Bradley-Terry)
opt = torch.optim.Adam(rm.parameters(), lr=0.05)
for _ in range(300):
    loss = -nn.functional.logsigmoid(rm(y_w) - rm(y_l)).mean()
    opt.zero_grad(); loss.backward(); opt.step()
acc = ((rm(y_w) > rm(y_l)).float().mean().item())
print(round(acc, 2) > 0.9)                                    # True  사람 선호를 맞춤

cands = torch.randn(5, D)                                     # 3단계: 정책(답변 5개 중 선택) + KL 페널티
logits = torch.zeros(5, requires_grad=True); ref = torch.zeros(5)
r = rm(cands).squeeze(-1).detach()
opt = torch.optim.Adam([logits], lr=0.1)
for beta in (0.0, 1.0):
    logits.data.zero_()
    for _ in range(300):
        p = logits.softmax(0)
        kl = (p * (p.log() - ref.log_softmax(0))).sum()
        obj = (p * r).sum() - beta * kl                        # E[r] − β·KL
        opt.zero_grad(); (-obj).backward(); opt.step()
    p = logits.softmax(0)
    print(beta, p.argmax().item() == r.argmax().item(), round(p.max().item(), 2))   # β=0: 한 답에 몰빵, β=1: 덜 극단적
```
