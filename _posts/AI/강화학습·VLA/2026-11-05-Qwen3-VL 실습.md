# Qwen3-VL 실습

## 정의·핵심
- **실습 개요 (응용 16차시 Basic VLM)**: **Qwen3-VL-4B-Instruct**(Alibaba)를 Colab **T4 GPU에 직접 올려** ChartQA 차트 이미지에 질문 → 이후 GPT-4o 답변과 비교 → [[GPT-4o API로 VLM 쓰기]]
  - 비유: Qwen3-VL = **우리 컴퓨터(GPU)에서 직접 돌아가는 AI**, GPT-4o = **서버에 질문을 보내 답을 받아오는 AI**
- **환경 준비**
  - `transformers`(최신), `accelerate`, `qwen-vl-utils`, `openai`, `pillow`
  - **토큰은 Colab Secrets(`userdata.get`)로** 불러옴 — 코드에 직접 쓰지 않음
- **모델 로드**
  - 약 **4.4B 파라미터**, **bf16**(파라미터당 2바이트) → 약 **8.3 GB** → T4(15 GB)에 들어감 → [[비트와 양자화]]
  - `device_map="auto"`(GPU 자동 배치), `low_cpu_mem_usage=True`
  - `AutoProcessor(min_pixels=256*28*28, max_pixels=512*28*28)` → 이미지 토큰을 **256~512개**로 제한 (28×28 픽셀 = 이미지 토큰 1개) → [[VLM 구조]]
- **질문하기 (`ask_qwen`)**
  1. **채팅 메시지**: `{"role": "user", "content": [{"type": "image", ...}, {"type": "text", ...}]}`
  2. `processor.apply_chat_template(..., tokenize=True, add_generation_prompt=True, return_dict=True, return_tensors="pt")` — 이미지를 패치로 자르고 텍스트를 토큰으로
  3. `model.generate(max_new_tokens=64, do_sample=False)` — **greedy**(재현 가능한 답) → [[Greedy Search·Beam Search]]
  4. **입력 부분을 잘라내고**(`o[len(i):]`) 생성된 답만 `batch_decode`
- **ChartQA 데이터셋**: 차트(막대·선 그래프)를 보고 질문에 답 — `test_human.json`, 샘플 5개 고정(`random.seed(42)`)
- **메모리 관리**: `gc.collect()`, `torch.cuda.empty_cache()`, `torch.inference_mode()`

## 수식·원리
```
메모리 ≈ 4.4B × 2 byte ≈ 8.3 GiB (bf16)
이미지 토큰 수 ≈ (H × W) / 28²,   min 256 ≤ 토큰 ≤ max 512
입력 = chat_template( [image, text] ) → input_ids (이미지 토큰 + 텍스트 토큰)
답변 = generate(...)[len(input_ids):]
```

## 코드 예시
강의 코드 (transformers 최신·GPU·HF 토큰 필요 — 이 환경 미실행):
```
from google.colab import userdata
from transformers import Qwen3VLForConditionalGeneration, AutoProcessor
import torch

HF_TOKEN = userdata.get("hf")                       # Secrets에서 불러오기 (하드코딩 금지)
MODEL_ID = "Qwen/Qwen3-VL-4B-Instruct"
model = Qwen3VLForConditionalGeneration.from_pretrained(
    MODEL_ID, torch_dtype=torch.bfloat16, device_map="auto", low_cpu_mem_usage=True, token=HF_TOKEN)
processor = AutoProcessor.from_pretrained(MODEL_ID, min_pixels=256*28*28, max_pixels=512*28*28, token=HF_TOKEN)

def ask_qwen(image, question, max_new_tokens=64):
    messages = [{"role": "user", "content": [{"type": "image", "image": image},
                                             {"type": "text", "text": question}]}]
    inputs = processor.apply_chat_template(messages, tokenize=True, add_generation_prompt=True,
                                           return_dict=True, return_tensors="pt").to(model.device)
    with torch.inference_mode():
        ids = model.generate(**inputs, max_new_tokens=max_new_tokens, do_sample=False, use_cache=True)
    trimmed = [o[len(i):] for i, o in zip(inputs["input_ids"], ids)]
    return processor.batch_decode(trimmed, skip_special_tokens=True)[0].strip()
```

실행 가능한 계산 (메모리·이미지 토큰 수 확인):
```python
N = 4_437_800_000
print(round(N * 2 / 1024 ** 3, 1), round(N * 2 / 1024 ** 3, 1) < 15)   # 8.3 True  bf16이면 T4(15GB)에 들어감

def qwen_tokens(w, h, min_pixels=256 * 28 * 28, max_pixels=512 * 28 * 28):
    pixels = min(max(w * h, min_pixels), max_pixels)              # 픽셀 수를 범위 안으로 (리사이즈 효과)
    return pixels // (28 * 28)
for size in [(320, 240), (800, 600), (1920, 1080)]:
    print(size, qwen_tokens(*size))                               # 작은 이미지 256, 큰 이미지 512로 고정

messages = [{"role": "user", "content": [{"type": "image", "image": "chart.png"},
                                         {"type": "text", "text": "What is the highest value?"}]}]
print([c["type"] for c in messages[0]["content"]])               # ['image', 'text']  채팅 형식 메시지 구조

prompt_ids, out_ids = [1, 2, 3, 4], [1, 2, 3, 4, 50, 51, 2]      # generate는 입력 + 답을 함께 반환
print(out_ids[len(prompt_ids):])                                  # [50, 51, 2]  입력 부분을 잘라 답만 남김
```
