# MDP

## 정의·핵심
- **정의 (응용 15차시)**: Markov Decision Process. **강화학습 문제를 수학적으로 정의하는 프레임워크** — 의사결정 문제의 수학적 모델
- **Markov 속성 (강의)**: **현재 상태만으로 미래를 예측할 수 있다**고 가정 — 과거 이력은 현재 상태에 모두 요약됨
  - `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, ..., s_t, a_t)`
  - 상태 설계가 중요: CartPole에서 각도만 주면 Markov가 아님 → **각속도**까지 넣어야 다음 상태 예측 가능 (Atari DQN은 프레임 4장을 쌓아 속도 정보 제공)
- **구성 요소 5가지 (강의)** — `(S, A, P, R, γ)`
  - **State (S)**: 에이전트가 관찰하는 환경의 현재 상황 (예: CartPole의 각도와 속도)
  - **Action (A)**: 선택할 수 있는 행동 집합 (왼쪽/오른쪽 이동)
  - **Reward (R)**: 특정 행동의 즉각적인 보상 — 학습의 피드백 신호
  - **Transition (P)**: 행동에 따른 다음 상태로의 **전이 확률** `P(s'|s, a)`
  - **Discount Factor (γ)**: 미래 보상의 현재 가치를 결정하는 0~1 값 — 장기적 전략 수립 → [[Return·할인율(gamma)]]
- **결정적 vs 확률적 전이**: FrozenLake `is_slippery=False`면 원하는 방향으로 확실히 이동(P = 1), `True`면 미끄러져 의도와 다른 방향으로 갈 수 있음(강의: "확률적 전이(미끄러짐)")
- **Model-based vs Model-free**: P와 R을 알면 계획(동적 계획법, 가치 반복)으로 풀 수 있음 / 모르면 **경험(샘플)으로 학습** — Q-learning·DQN·PPO 모두 Model-free → [[Q-learning]]
- **POMDP**: 상태를 일부만 관찰(카메라 한 장 등) — 실제 로봇 문제는 대개 이 경우

## 수식·원리
```
MDP = (S, A, P, R, γ)
P(s' | s, a) = Pr(S_{t+1} = s' | S_t = s, A_t = a),   Σ_{s'} P(s'|s,a) = 1
R(s, a) = E[R_{t+1} | S_t = s, A_t = a]
정책 π(a | s),  목표: max_π E_π[Σ γ^t R_{t+1}]
```

## 코드 예시
```python
import numpy as np

S, A = 3, 2                                          # 상태 0,1,2(목표), 행동 0=머무름 1=전진
P = np.zeros((S, A, S))
P[0, 0, 0] = 1; P[0, 1] = [0.2, 0.8, 0.0]            # 전진해도 20%는 미끄러져 제자리 (확률적 전이)
P[1, 0, 1] = 1; P[1, 1] = [0.0, 0.2, 0.8]
P[2, :, 2] = 1                                       # 목표는 흡수 상태
R = np.array([[0, 0], [0, 1.0], [0, 0]])             # 1에서 전진 시 기대 보상
print(np.allclose(P.sum(-1), 1))                     # True  전이 확률 합 = 1

rng = np.random.default_rng(0)
counts = np.zeros(S)
for _ in range(10000):
    counts[rng.choice(S, p=P[0, 1])] += 1            # Markov: 다음 상태는 (현재 상태, 행동)만으로 결정
print((counts / 10000).round(2).tolist())            # [0.2, 0.8, 0.0]

V = np.zeros(S); gamma = 0.9                         # 모델(P, R)을 알면 계획으로 풀 수 있음 (가치 반복)
for _ in range(100):
    V = (R + gamma * P @ V).max(1)
print(V.round(3).tolist(), (R + gamma * P @ V).argmax(1).tolist())   # 최적 가치, 최적 정책 (전진)
```
