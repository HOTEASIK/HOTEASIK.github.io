# Bellman 방정식

## 정의·핵심
- **정의 (응용 15차시)**: **현재 가치와 미래 가치의 재귀적 관계**를 정의하는 방정식 — "지금 상태의 가치 = 즉시 보상 + 할인된 다음 상태의 가치"
  - 강의: "이 방정식은 **최적 정책을 찾기 위한 모든 RL 알고리즘의 수학적 기반**"
- **두 가지 형태**
  - **Bellman 기대 방정식 (Expectation)**: 주어진 정책 π의 가치 — 정책 평가, Actor-Critic의 Critic 학습(TD)
  - **Bellman 최적 방정식 (Optimality)**: 최적 가치 — 다음 상태에서 **가장 좋은 행동(max)** 을 가정 → Q-learning·DQN의 타깃
- **Return 재귀식에서 유도**: `G_t = r_{t+1} + γ G_{t+1}` 의 기댓값을 취하면 Bellman 방정식 → [[Return·할인율(gamma)]]
- **알고리즘과의 연결**
  - **Q-learning 업데이트**: `Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s', a') − Q(s,a)]` — 괄호 안이 **TD 오차**(Bellman 최적 방정식의 좌우 차이) → [[Q-learning]]
  - **DQN 타깃**: `r + γ max_a' Q_target(s', a') × (1 − done)` — 종료 상태면 미래 가치 0 (15차시 과제 문제 6) → [[DQN]]
  - **Actor-Critic TD Error**: `δ = r + γ V(s') − V(s)` → [[Actor-Critic]]
- **풀이 방법**: 모델(P, R)을 알면 **가치 반복(Value Iteration)** — Bellman 최적 연산을 반복 적용하면 수렴 (γ < 1이면 축약 사상 → 유일한 고정점) / 모르면 샘플 기반 TD 학습

## 수식·원리
```
기대:  V^π(s) = Σ_a π(a|s) [ R(s,a) + γ Σ_{s'} P(s'|s,a) V^π(s') ]
       Q^π(s,a) = R(s,a) + γ Σ_{s'} P(s'|s,a) Σ_{a'} π(a'|s') Q^π(s',a')
최적:  V*(s) = max_a [ R(s,a) + γ Σ_{s'} P(s'|s,a) V*(s') ]
       Q*(s,a) = R(s,a) + γ Σ_{s'} P(s'|s,a) max_{a'} Q*(s',a')
TD 오차: δ = r + γ max_{a'} Q(s',a') − Q(s,a)
```

## 코드 예시
```python
import numpy as np

# 4×4 FrozenLake(결정적) 모델로 가치 반복 — Bellman 최적 방정식을 반복 적용
MAP = "SFFFFHFHFFFHHFFG"
def nxt(s, a):
    r, c = divmod(s, 4)
    r, c = [(r, max(c - 1, 0)), (min(r + 1, 3), c), (r, min(c + 1, 3)), (max(r - 1, 0), c)][a]
    return r * 4 + c

gamma, V = 0.9, np.zeros(16)
for it in range(100):
    Q = np.zeros((16, 4))
    for s in range(16):
        if MAP[s] in "HG": continue                         # 종료 상태: 미래 가치 0
        for a in range(4):
            s2 = nxt(s, a); r = float(MAP[s2] == "G")
            Q[s, a] = r + gamma * V[s2] * (MAP[s2] not in "HG")
    V_new = Q.max(1)
    if np.abs(V_new - V).max() < 1e-9: break
    V = V_new
print(it, V.reshape(4, 4).round(2).tolist()[0])             # 수렴 반복 수, 첫 줄 가치
print(round(V[0], 3), round(gamma ** 5, 3))                 # 0.59 0.59  시작점 가치 = γ^5 (최단 6스텝)

s, path = 0, [0]
while MAP[s] not in "HG":
    s = nxt(s, int(Q[s].argmax())); path.append(s)
print(path)                                                 # 최적 정책으로 구멍을 피해 목표(15) 도달
```
